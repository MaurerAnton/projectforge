File #100: DataTransferPublicServicesRest.kt

Path: plugins/datatransfer/.../restPublic/DataTransferPublicServicesRest.kt · Source: GitHub

Public REST services (all require session login): download (single file, enforces hasDownloadAccess), downloadAll / multiDownload (requires externalDownloadEnabled=true), multiDelete (per-file ownership check), upload (requires externalUploadEnabled=true, registers file ownership in session), delete (single file, ownership check), modify (rename/change description). Upload responds with filtered attachment list. All operations log external user info (IP + optional name) for audit trail.
