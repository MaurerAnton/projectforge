1012: SystemSanityCheckJob.kt

Sanity Check Job, projectforge-business/src/main/kotlin/org/projectforge/business/jobs/SystemSanityCheckJob.kt
Concrete AbstractJob implementation that validates task tree integrity in the ProjectForge task hierarchy. Detects orphaned tasks (no path to root) and multiple root tasks, which indicate database corruption in the task tree structure.

Algorithm

The job loads all tasks, indexes them by ID in a map, and for each task walks its ancestor chain (parent → parent...) up to a depth of 50. If no root task (parentTaskId == null) is found within 50 hops, the task is flagged as "abandoned" (cyclic or disconnected). A depth limit prevents infinite loops on truly circular references.
