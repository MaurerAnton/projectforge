projectforge-business/src/main/kotlin/org/projectforge/business/gantt/GanttChartDO.kt Entité JPA (Diagramme de Gantt), projectforge-business/src/main/kotlin/org/projectforge/business/gantt/GanttChartDO.kt 121 lignes · 62 code · 43 commentaires · 16 vides
Entité JPA représentant une configuration de diagramme de Gantt dans ProjectForge. Mappe la table T_GANTT_CHART et stocke les préférences de mise en page visuelle (couleurs des barres, formats d'étiquettes, échelle de temps) pour les diagrammes de Gantt de planification de projet. Annotée avec @PropertyInfo pour la génération automatique d'interface utilisateur.

Structure de l'entité

Étend DefaultBaseDO fournissant les champs standards (id, créé, dernièreMiseÀJour, supprimé). Stocke le nom, la description, la configuration JSON pour les couleurs des barres et les options d'affichage, les limites de plage de dates et les critères de filtre de tâches. Persistée dans la table T_GANTT_CHART avec indexation Hibernate Search sur les champs nom et description.
