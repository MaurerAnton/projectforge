#1012: GanttChartDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/gantt/GanttChartDO.kt JPA-сущность (диаграмма Ганта), projectforge-business/src/main/kotlin/org/projectforge/business/gantt/GanttChartDO.kt 121 строка · 62 кода · 43 комментария · 16 пустых
JPA-сущность, представляющая конфигурацию диаграммы Ганта в ProjectForge. Соответствует таблице T_GANTT_CHART и хранит настройки визуального отображения (цвета столбцов, форматы меток, временной масштаб) для диаграмм Ганта планирования проектов. Аннотирована @PropertyInfo для автоматической генерации пользовательского интерфейса.

Структура сущности

Расширяет DefaultBaseDO, предоставляя стандартные поля (id, created, lastUpdate, deleted). Хранит имя, описание, JSON-конфигурацию для цветов столбцов и параметров отображения, границы диапазона дат и критерии фильтрации задач. Сохраняется в таблице T_GANTT_CHART с индексацией Hibernate Search по полям имени и описания.
