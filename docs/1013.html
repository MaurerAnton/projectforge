1013: LdapTemplate.kt

LDAP Template Pattern, projectforge-business/src/main/kotlin/org/projectforge/business/ldap/LdapTemplate.kt
Abstract template class implementing the Template Method pattern for LDAP operations. Manages DirContext lifecycle (create, use, close) with proper cleanup in finally blocks, including tracking open connection counts.

Design

Subclasses implement call() which receives an open DirContext. The template handles:

  • Context Creation: Delegates to LdapConnector.createContext(), optionally with username/password for authenticated binds.
  • Connection Tracking: Maintains a static openConnections counter, incremented on open and decremented on close.
  • Cleanup: Finally block closes both NamingEnumeration<SearchResult> and DirContext, catching and logging any close failures.
  • Error Handling: NameNotFoundException returns null (base context not found), while other exceptions wrap in RuntimeException.
