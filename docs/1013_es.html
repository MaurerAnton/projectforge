Entidad central para la planificación semanal de recursos humanos. Se asigna a la tabla T_HR_PLANNING, con restricción única por usuario+semana. Contiene una lista de entidades hijas HRPlanningEntryDO y calcula totales de horas agregadas (diarias, no asignadas, fin de semana).

Diseño de la entidad

Extiende DefaultBaseDO. Relaciones clave:

  • user (PFUserDO, ManyToOne): El empleado al que pertenece esta semana de planificación. Serializado solo como ID mediante @IdOnlySerializer.
  • week (LocalDate): Primer día de la semana (lunes según Locale.GERMAN). Se usa en la restricción única con el usuario.
  • entries (List, OneToMany): Entidades hijas para cada asignación de proyecto/estado en esta semana. Marcadas con @PersistenceBehavior(autoUpdateCollectionEntries=true) para gestión automática de cascada.

Propiedades calculadas

Todas las propiedades @Transient calculan agregados a partir de las entradas: totalHours, totalUnassignedHours, totalMondayHours hasta totalWeekendHours. Cada una omite entradas eliminadas mediante la verificación entry.deleted. La propiedad formattedWeekOfYear delega en DateTimeFormatter.

Decisiones clave

  • Inicio de semana = lunes: Usa PFDay.beginOfWeek con Locale.GERMAN, haciendo del lunes el primer día laborable.
  • Eliminación suave para entradas: deleteEntry() marca las entradas como eliminadas en lugar de eliminarlas, permitiendo deshacer mediante la reincorporación del mismo estado/proyecto.
  • Carga diferida: Todas las relaciones usan FetchType.LAZY para evitar problemas de consultas N+1.
