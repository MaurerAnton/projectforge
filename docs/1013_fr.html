Entité centrale pour la planification hebdomadaire des ressources RH. Mappe la table T_HR_PLANNING, contrainte unique par utilisateur+semaine. Contient une liste d'entités enfants HRPlanningEntryDO et calcule des totaux d'heures agrégés (quotidiens, non attribués, week-end).

Conception de l'entité

Étend DefaultBaseDO. Relations clés :

  • user (PFUserDO, ManyToOne) : L'employé à qui appartient cette semaine de planification. Sérialisé uniquement par ID via @IdOnlySerializer.
  • week (LocalDate) : Premier jour de la semaine (lundi selon Locale.GERMAN). Utilisé dans la contrainte unique avec l'utilisateur.
  • entries (List, OneToMany) : Entités enfants pour chaque affectation projet/statut dans cette semaine. Marquées @PersistenceBehavior(autoUpdateCollectionEntries=true) pour une gestion automatique en cascade.

Propriétés calculées

Toutes les propriétés @Transient calculent des agrégats à partir des entrées : totalHours, totalUnassignedHours, totalMondayHours jusqu'à totalWeekendHours. Chacune ignore les entrées supprimées via la vérification entry.deleted. La propriété formattedWeekOfYear délègue à DateTimeFormatter.

Décisions clés

  • Début de semaine = lundi : Utilise PFDay.beginOfWeek avec Locale.GERMAN, faisant du lundi le premier jour ouvrable.
  • Suppression logicielle des entrées : deleteEntry() marque les entrées comme supprimées plutôt que de les retirer, permettant une annulation via le ré-ajout du même statut/projet.
  • Chargement paresseux : Toutes les relations utilisent FetchType.LAZY pour éviter les problèmes de requêtes N+1.
