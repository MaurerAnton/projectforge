Objeto de acceso a datos para la planificación semanal de RRHH. Extiende BaseDao<HRPlanningDO>, proporcionando operaciones CRUD, indexación de Hibernate Search, control de acceso e integración de historial para las entradas de planificación semanal de recursos de empleados.

Arquitectura

Control de acceso

Implementa una verificación de acceso de escritura detallada más allá de la comprobación estándar de USER_RIGHT_ID. Al insertar/actualizar, verifica que el usuario conectado tenga derechos específicos del proyecto para cada entrada de planificación de RRHH. Los usuarios deben ser el gestor del proyecto, el jefe de gestor de negocio, el gestor de ventas o un miembro del grupo de gestores del proyecto para modificar entradas de un proyecto determinado. Esto se aplica mediante afterDBWrite, que itera todas las entradas y valida los permisos antes de la confirmación.

Integración de historial

Sobrescribe addOwnHistoryEntries para fusionar entradas de historial de objetos HRPlanningEntryDO hijos. Utiliza HistoryFormatUtils.setNumberAsPropertyNameForListEntries para prefijar cada entrada del historial con el nombre o estado del proyecto, haciendo que los diffs del historial sean legibles.

Búsqueda de Hibernate

Define campos de búsqueda adicionales (ADDITIONAL_SEARCH_FIELDS) para la búsqueda de texto completo en el nombre del proyecto, nombre del cliente y detalles del usuario de las entradas. Registra HRPlanningEntryDO como una entidad de búsqueda adicional mediante additionalHistorySearchDOs.

Rendimiento

Sobrescribe prepareHibernateSearch para inicializar de forma eager los campos del proyecto cargados de forma perezosa (grupo de gestores del proyecto) antes de la indexación de Hibernate Search, evitando consultas N+1 durante las actualizaciones del índice de búsqueda.
