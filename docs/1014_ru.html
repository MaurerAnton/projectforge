#1014: HRPlanningDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/humanresources/HRPlanningDao.kt DAO (Планирование ЧР), projectforge-business/src/main/kotlin/org/projectforge/business/humanresources/HRPlanningDao.kt 305 строк · 220 кода · 58 комментариев · 27 пустых
Объект доступа к данным для недельного планирования ЧР. Расширяет BaseDao, предоставляя CRUD-операции, индексацию Hibernate Search, контроль доступа и интеграцию истории для записей еженедельного планирования ресурсов сотрудников.

Архитектура

Контроль доступа

Реализует детальную проверку прав на запись, выходящую за рамки стандартной проверки USER_RIGHT_ID. При вставке/обновлении проверяет, что вошедший в систему пользователь имеет права, специфичные для проекта, для каждой записи планирования ЧР. Пользователь должен быть либо менеджером проекта, руководителем бизнес-направления, менеджером по продажам, либо участником группы менеджеров проекта, чтобы изменять записи для данного проекта. Это обеспечивается через afterDBWrite, который перебирает все записи и проверяет разрешения перед фиксацией.

Интеграция истории

Переопределяет addOwnHistoryEntries для объединения записей истории из дочерних объектов HRPlanningEntryDO. Использует HistoryFormatUtils.setNumberAsPropertyNameForListEntries для добавления префикса к истории каждой записи с названием проекта или статусом, делая различия в истории читаемыми.

Hibernate Search

Определяет дополнительные поля поиска (ADDITIONAL_SEARCH_FIELDS) для полнотекстового поиска по названию проекта, имени клиента и данным пользователя в записях. Регистрирует HRPlanningEntryDO как дополнительную сущность поиска через additionalHistorySearchDOs.

Производительность

Переопределяет prepareHibernateSearch для нетерпеливой инициализации лениво загружаемых полей проекта (группа менеджеров проекта) перед индексацией Hibernate Search, предотвращая N+1 запросов во время обновления поискового индекса.
