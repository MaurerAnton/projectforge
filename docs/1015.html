Child entity of HRPlanningDO representing a single project assignment or status entry within a planned week. Stores hours per day of week (Mon-Fri + weekend), project reference, status, priority, and probability.

Entity Design

Maps to T_HR_PLANNING_ENTRY with indexes on planning_fk and projekt_fk. Key fields:

  • planning (HRPlanningDO): Parent week reference, non-null.
  • projekt (ProjektDO): Optional project this entry relates to.
  • status (HRPlanningEntryStatus): Alternative to project for non-project time (e.g., vacation, illness).
  • priority, probability: Planning metadata for project pipeline forecasting.
  • Seven BigDecimal hour fields: unassignedHours, mondayHours through fridayHours, weekendHours.
  • description: Free-text field, indexed with jiraPreservingAnalyzer for preserving issue key patterns.

Computed Properties

totalHours sums all seven hour fields. projektNameOrStatus returns localized status label or project name. projektKundeAsString delegates to ProjektFormatter.

Equality

Custom equals/hashCode based on entity ID when persisted, or field-by-field comparison (hasNoFieldChanges) for transient entries. The isEmpty check uses ObjectHelper.isEmpty across all editable fields.

Key Decisions

  • JiraPreservingAnalyzer: Custom Lucene analyzer that preserves patterns like ACME-12345 during full-text search on description.
  • clone: newClone() method copies all values except id for duplicating entries.
