Entité enfant de HRPlanningDO représentant une affectation de projet unique ou une entrée de statut dans une semaine planifiée. Stocke les heures par jour de la semaine (lun-ven + week-end), la référence du projet, le statut, la priorité et la probabilité.

Conception de l'entité

Mappe sur T_HR_PLANNING_ENTRY avec des index sur planning_fk et projekt_fk. Champs clés :

  • planning (HRPlanningDO) : Référence à la semaine parente, non nul.
  • projekt (ProjektDO) : Projet optionnel auquel cette entrée se rapporte.
  • status (HRPlanningEntryStatus) : Alternative au projet pour les temps hors projet (ex. vacances, maladie).
  • priority, probability : Métadonnées de planification pour les prévisions du pipeline de projets.
  • Sept champs d'heures BigDecimal : unassignedHours, mondayHours à fridayHours, weekendHours.
  • description : Champ texte libre, indexé avec jiraPreservingAnalyzer pour préserver les motifs de clés de ticket.

Propriétés calculées

totalHours additionne les sept champs d'heures. projektNameOrStatus retourne le libellé de statut localisé ou le nom du projet. projektKundeAsString délègue à ProjektFormatter.

Égalité

equals/hashCode personnalisés basés sur l'ID de l'entité lorsqu'elle est persistée, ou comparaison champ par champ (hasNoFieldChanges) pour les entrées transitoires. La vérification isEmpty utilise ObjectHelper.isEmpty sur tous les champs modifiables.

Décisions clés

  • JiraPreservingAnalyzer : Analyseur Lucene personnalisé qui préserve les motifs comme ACME-12345 lors de la recherche en texte intégral sur la description.
  • clone : La méthode newClone() copie toutes les valeurs sauf id pour dupliquer les entrées.
