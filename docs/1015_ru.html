Дочерняя сущность HRPlanningDO, представляющая отдельное назначение на проект или запись статуса в рамках запланированной недели. Хранит часы по дням недели (Пн-Пт + выходные), ссылку на проект, статус, приоритет и вероятность.

Дизайн сущности

Отображается на T_HR_PLANNING_ENTRY с индексами по planning_fk и projekt_fk. Ключевые поля:

  • planning (HRPlanningDO): Ссылка на родительскую неделю, не может быть null.
  • projekt (ProjektDO): Необязательный проект, к которому относится запись.
  • status (HRPlanningEntryStatus): Альтернатива проекту для непроектного времени (например, отпуск, болезнь).
  • priority, probability: Метаданные планирования для прогнозирования конвейера проектов.
  • Семь полей BigDecimal для часов: unassignedHours, mondayHours – fridayHours, weekendHours.
  • description: Текстовое поле произвольного формата, индексированное с jiraPreservingAnalyzer для сохранения шаблонов ключей задач.

Вычисляемые свойства

totalHours суммирует все семь полей часов. projektNameOrStatus возвращает локализованную метку статуса или название проекта. projektKundeAsString делегирует вызов ProjektFormatter.

Равенство

Пользовательские equals/hashCode на основе ID сущности, если она сохранена, или по полям (hasNoFieldChanges) для временных записей. Проверка isEmpty использует ObjectHelper.isEmpty по всем редактируемым полям.

Ключевые решения

  • JiraPreservingAnalyzer: Пользовательский анализатор Lucene, сохраняющий шаблоны вида ACME-12345 при полнотекстовом поиске по описанию.
  • clone: Метод newClone() копирует все значения, кроме id, для дублирования записей.
