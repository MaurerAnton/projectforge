Spring @Service, das intelligente Bildskalierung und -komprimierung für ProjectForge-Adressbuchbilder bereitstellt. Verwendet einen Multi-Strategie-Ansatz: JPEG-Qualitätsreduzierung, binäre Suche auf Abmessungen, zuerst JPEG, dann PNG als Fallback.

Architektur

Verkleinerungsalgorithmus (shrinkToMaxFileSize)

Der Dienst implementiert einen zweiphasigen Ansatz, um Bilder auf eine Ziel-Dateigröße zu verkleinern:

  1. Formatkonvertierung: Versucht zuerst die JPEG-Konvertierung (optimale Komprimierung). Fällt auf PNG zurück, wenn das Bild Transparenz (Alpha-Kanal) aufweist, die JPEG nicht verarbeiten kann. Die Bildtyperkennung verwendet Magic Bytes.
  2. Strategie 1 — JPEG-Qualitätsreduzierung: Testet nacheinander die Qualitätsstufen 0,85, 0,8, 0,7. Gibt sofort zurück, wenn eine Qualitätsstufe den optimalen Bereich (95-100 % der maximalen Größe) erreicht.
  3. Strategie 2 — Binäre Suchskalierung: Wenn die Qualitätsreduzierung allein nicht ausreicht, wird eine binäre Suche auf einem Skalierungsfaktor (0,0-1,0) durchgeführt, der auf die Bildabmessungen angewendet wird. Eine Mindestabmessungssperre bei 100px verhindert unbrauchbare Bilder. Verwendet die beste JPEG-Qualität aus Strategie 1.

Wichtige Designentscheidungen

  • Zielsetzung optimaler Bereich: Das Ziel von 95-100 % der maximalen Größe anstatt nur „unter dem Limit“ maximiert die Bildqualität innerhalb der Beschränkungen.
  • JPEG-zuerst-Strategie: JPEG komprimiert Fotos typischerweise 5-10x besser als PNG, daher wird die Konvertierung zuerst versucht.
  • Magic-Byte-Erkennung: detectImageType() prüft rohe Bytes auf JPEG- (FF D8 FF), GIF- (GIF) und PNG- (89 50 4E 47) Signaturen und vermeidet so die Abhängigkeit von Dateierweiterungen.
  • Skalierung mit Seitenverhältnis: resizeImagePreserveRatio() berechnet eine minimale Skalierung aus Breite und Höhe, um innerhalb der Grenzen zu passen und dabei das Seitenverhältnis beizubehalten.

ImageResult-Datenklasse

Enthält bytes: ByteArray und imageType: ImageType. Überschreibt equals/hashCode mit inhaltsbewusstem Vergleich unter Verwendung von contentEquals/contentHashCode.
