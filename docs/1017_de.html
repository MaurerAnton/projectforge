#1017: CronNightlyJob.kt

Geplante Komponente, die nächtlich ausgeführt wird (konfigurierbar über die Eigenschaft projectforge.cron.nightly). Führt die Hibernate-Search-Neuindizierung durch, um den Volltextsuchindex mit der Datenbank synchron zu halten.

Entwurf

Spring Boot @Component mit einem @Scheduled-Cron-Trigger. Bei der Ausführung wird ein neuer Thread (keine Kotlin-Koroutine) gestartet, um HibernateSearchReindexer.execute() asynchron auszuführen. Protokolliert Start/Ende mit Millisekunden-Zeitformatierung. Die Fehlerbehandlung fängt Throwable ab, um sicherzustellen, dass der Scheduler niemals durch eine fehlgeschlagene Neuindizierung blockiert wird.

Entwurfsentscheidung: Thread vs. Koroutine

Die ursprüngliche Implementierung verwendete Kotlin-Koroutinen, wurde jedoch aus Gründen der Einfachheit und zur Vermeidung von Koroutinen-Scope-Management im Spring-Scheduler-Kontext auf einen einfachen Thread umgestellt (Commit 1a77630dc).
