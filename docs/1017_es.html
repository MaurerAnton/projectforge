#1017: CronNightlyJob.kt

projectforge-business/src/main/kotlin/org/projectforge/business/jobs/CronNightlyJob.kt Trabajo programado, projectforge-business/src/main/kotlin/org/projectforge/business/jobs/CronNightlyJob.kt 61 líneas · 27 código · 29 comentarios · 5 en blanco
Componente programado que se ejecuta cada noche (configurable mediante la propiedad projectforge.cron.nightly). Realiza el re-indexado de Hibernate Search para mantener el índice de búsqueda de texto completo sincronizado con la base de datos.

Diseño

Componente @Component de Spring Boot con un disparador cron @Scheduled. En la ejecución, lanza un nuevo Thread (no una corrutina de Kotlin) para ejecutar HibernateSearchReindexer.execute() de forma asíncrona. Registra inicio/fin con formato de duración en milisegundos. El manejo de errores captura Throwable para garantizar que el programador nunca sea bloqueado por un re-indexado fallido.

Decisión de diseño: Thread vs Corrutina

La implementación original usaba corrutinas de Kotlin, pero se cambió a Thread simple (commit 1a77630dc) por simplicidad y para evitar la gestión del ámbito de corrutinas dentro del contexto del programador de Spring.
