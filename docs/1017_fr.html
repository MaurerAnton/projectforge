#1017 : CronNightlyJob.kt

Composant planifié qui s'exécute chaque nuit (configurable via la propriété projectforge.cron.nightly). Effectue la réindexation Hibernate Search pour maintenir l'index de recherche en texte intégral synchronisé avec la base de données.

Conception

Composant Spring Boot @Component avec un déclencheur cron @Scheduled. Lors de l'exécution, lance un nouveau Thread (pas une coroutine Kotlin) pour exécuter HibernateSearchReindexer.execute() de manière asynchrone. Enregistre le début/la fin avec un formatage en millisecondes. La gestion des erreurs intercepte Throwable pour garantir que le planificateur ne soit jamais bloqué par une réindexation échouée.

Décision de conception : Thread vs Coroutine

L'implémentation originale utilisait des coroutines Kotlin mais a été modifiée pour utiliser un simple Thread (commit 1a77630dc) par souci de simplicité et pour éviter la gestion de la portée des coroutines dans le contexte du planificateur Spring.
