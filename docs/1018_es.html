Orquestador de comprobación de cordura programado nocturno. Ejecuta una colección de instancias registradas de AbstractJob, recopila los resultados en JobListExecutionContext y envía un correo electrónico al administrador (como HTML) si se encuentran errores.

Arquitectura

Registro de trabajos

Utiliza @PostConstruct para registrar automáticamente los trabajos integrados: SystemSanityCheckJob y JCRCheckSanityCheckJob. Se pueden registrar trabajos adicionales de plugins mediante registerJob(). Los trabajos se almacenan en un mutableListOf().

Flujo de ejecución

  1. @Scheduled(cron="${projectforge.cron.sanityChecks}") activa cron(), que inicia un Thread en segundo plano.
  2. execute() itera sobre todos los trabajos registrados, envolviendo cada uno en try/catch para evitar que el fallo de un trabajo bloquee a los demás.
  3. Si el contexto agregado tiene estado ERRORS, se envía un correo a SYSTEM_ADMIN_E_MAIL con un resumen y un informe HTML completo como archivo adjunto.

Formato del informe

El cuerpo del correo electrónico utiliza clases similares a Bootstrap Html.Alert/Html.P para un formato HTML atractivo. El archivo adjunto es un informe HTML completo llamado projectforge_sanity-check_TIMESTAMP.html.
