Orchestrateur de vérification de cohérence planifié chaque nuit. Exécute une collection d'instances AbstractJob enregistrées, collecte les résultats dans JobListExecutionContext et envoie un e-mail à l'administrateur (au format HTML) si des erreurs sont trouvées.

Architecture

Enregistrement des tâches

Utilise @PostConstruct pour enregistrer automatiquement les tâches intégrées : SystemSanityCheckJob et JCRCheckSanityCheckJob. Des tâches supplémentaires de plugins peuvent être enregistrées via registerJob(). Les tâches sont stockées dans un mutableListOf().

Flux d'exécution

  1. @Scheduled(cron="${projectforge.cron.sanityChecks}") déclenche cron(), qui lance un Thread en arrière-plan.
  2. execute() parcourt toutes les tâches enregistrées, en encapsulant chacune dans un bloc try/catch pour éviter qu'un échec de tâche n'en bloque d'autres.
  3. Si le contexte agrégé a un statut ERRORS, un e-mail est envoyé à SYSTEM_ADMIN_E_MAIL avec à la fois un résumé et un rapport HTML complet en pièce jointe.

Formatage du rapport

Le corps de l'e-mail utilise des classes Html.Alert/Html.P de type Bootstrap pour un formatage HTML soigné. La pièce jointe est un rapport HTML complet nommé projectforge_sanity-check_TIMESTAMP.html.
