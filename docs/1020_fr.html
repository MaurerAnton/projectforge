Classe abstraite de modèle implémentant le patron de méthode Template pour les opérations LDAP. Gère le cycle de vie de DirContext (création, utilisation, fermeture) avec un nettoyage approprié dans les blocs finally, y compris le suivi du nombre de connexions ouvertes.

Conception

Les sous-classes implémentent call() qui reçoit un DirContext ouvert. Le modèle gère :

  • Création du contexte : Délègue à LdapConnector.createContext(), éventuellement avec nom d'utilisateur/mot de passe pour les liaisons authentifiées.
  • Suivi des connexions : Maintient un compteur statique openConnections, incrémenté à l'ouverture et décrémenté à la fermeture.
  • Nettoyage : Le bloc finally ferme à la fois NamingEnumeration<SearchResult> et DirContext, en capturant et journalisant toute erreur de fermeture.
  • Gestion des erreurs : NameNotFoundException retourne null (contexte de base non trouvé), tandis que les autres exceptions sont encapsulées dans RuntimeException.
