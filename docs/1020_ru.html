Абстрактный класс-шаблон, реализующий паттерн «Шаблонный метод» для операций LDAP. Управляет жизненным циклом DirContext (создание, использование, закрытие) с корректной очисткой в блоках finally, включая отслеживание количества открытых соединений.

Проектирование

Подклассы реализуют метод call(), который получает открытый DirContext. Шаблон обрабатывает:

  • Создание контекста: Делегируется LdapConnector.createContext(), опционально с именем пользователя/паролем для аутентифицированных привязок.
  • Отслеживание соединений: Ведётся статический счётчик openConnections, увеличивающийся при открытии и уменьшающийся при закрытии.
  • Очистка: Блок finally закрывает как NamingEnumeration<SearchResult>, так и DirContext, перехватывая и логируя ошибки закрытия.
  • Обработка ошибок: NameNotFoundException возвращает null (базовый контекст не найден), остальные исключения оборачиваются в RuntimeException.
