#1023: ContractDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/orga/ContractDO.kt JPA-Entität (Contract), projectforge-business/src/main/kotlin/org/projectforge/business/orga/ContractDO.kt 176 Zeilen · 122 Code · 25 Kommentare · 29 leer
Rechtliche Vertragsentität für das Orga-Modul. Mappt auf die Tabelle T_CONTRACT mit Feldern für beide Vertragsparteien (Mitvertragspartner, Vertragspersonen, Unterzeichner), Gültigkeitsdaten, Unterzeichnungsdatum, Status, Ablage und Wiedervorlage-Nachverfolgung. Implementiert AttachmentsInfo für die Unterstützung von Dokumentenanlagen.

Entitätsstruktur

Erweitert DefaultBaseDO und AttachmentsInfo. Zu den wichtigsten Feldern gehören number (autogeneriert), date, Felder für zwei Parteien (A/B-Seiten mit Mitvertragspartner, Vertragsperson, Unterzeichner), validFrom/Until, signingDate, status (Enum ContractStatus), type, filing, resubmissionOnDate sowie Metadaten zu Anhängen. Benannte Abfragen unterstützen die Prüfung auf doppelte Nummern und die Datumsbereichsauswahl. Die Vertragshistorie wurde in Commit 6d57579ce von einem einzelnen Gültigkeitsfeld auf validFrom/validUntil aufgeteilt.
