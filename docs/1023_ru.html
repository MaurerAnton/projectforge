#1023: ContractDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/orga/ContractDO.kt JPA-сущность (Contract), projectforge-business/src/main/kotlin/org/projectforge/business/orga/ContractDO.kt 176 строк · 122 кода · 25 комментариев · 29 пустых
Юридическая сущность договора для модуля Orga. Отображается на таблицу T_CONTRACT с полями для обеих сторон договора (соисполнители, контактные лица, подписанты), датами действия, датой подписания, статусом, архивом и отслеживанием повторной отправки. Реализует AttachmentsInfo для поддержки вложений документов.

Структура сущности

Расширяет DefaultBaseDO и AttachmentsInfo. Ключевые поля включают number (автогенерируемый), date, поля для двух сторон (стороны A/B с соисполнителем, контактным лицом, подписантом), validFrom/Until, signingDate, status (перечисление ContractStatus), type, filing, resubmissionOnDate и метаданные вложений. Именованные запросы поддерживают проверку дубликатов номеров и выборку по диапазону дат. История договора была разделена с одного поля срока действия на validFrom/validUntil в коммите 6d57579ce.
