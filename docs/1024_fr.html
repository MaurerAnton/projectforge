Entité pour le registre du courrier sortant (Postausgangsbuch). Mappe vers la table T_ORGA_POSTAUSGANG. Enregistre l'expéditeur (absender), le destinataire (empfaenger), la personne de contact, le contenu, le commentaire, la date et le type de courrier (énumération PostType). Le champ absender a été rendu nullable dans le commit 5fbc31859. Inclut une requête nommée pour la sélection de date min/max utilisée dans les vues de liste.
