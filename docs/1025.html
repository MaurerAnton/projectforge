1025: PfCaches.kt

Cache Aggregator (Singleton), projectforge-business/src/main/kotlin/org/projectforge/business/PfCaches.kt
Centralized @Service facade providing unified access to all ProjectForge business caches. Designed as a convenience layer for scripts and business logic, allowing lazy entity resolution without worrying about which cache to use.

Architecture

Cache Aggregation

Autowires all individual caches: KontoCache, AddressbookCache, EmployeeCache, KostCache, KundeCache, ProjektCache, RechnungCache, TaskTree, TeamCalCache, and UserGroupCache. Each is accessed through get*IfNotInitialized methods that resolve IDs to fully populated entities by walking the cache dependency graph.

Entity Initialization Chain

Multiple initialize(obj) overloads resolve lazy references for each entity type. For example, initialize(ProjektDO) fills headOfBusinessManager, konto, kunde, projectManager, projectManagerGroup, salesManager, and task. Each is populated via the corresponding get*IfNotInitialized method of the appropriate cache.

Generic Initialization

initializeBaseDO(obj) provides a type-safe dispatch via when block for script use. getAndPopulateKost2(id) loads then initializes a Kost2 in one call.

Singleton Pattern

Static instance field set via @PostConstruct, with companion object delegating static initialize() calls to the instance. Supports test setup via internalSetupForTestCases().
