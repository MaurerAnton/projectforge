Сущность для реестра входящей почты (Posteingangsbuch). Отображается на T_ORGA_POSTEINGANG. Записывает отправителя (absender, обязательно), контактное лицо, содержание, комментарий, дату и тип почты (перечисление PostType). Зеркальное отражение PostausgangDO, но с absender как не-null и без поля empfaenger. Включает именованный запрос для выбора по диапазону дат.
