1026: PollAssignmentFilter.kt

Custom Result Filter, projectforge-business/src/main/kotlin/org/projectforge/business/poll/filter/PollAssignmentFilter.kt
Implements CustomResultFilter to filter polls by user assignment role (OWNER, ACCESS, ATTENDEE, OTHER). Evaluates full access group membership by resolving group ID lists to actual users via GroupService, catching the case where a user has access through group membership without being in the explicit access user list.
