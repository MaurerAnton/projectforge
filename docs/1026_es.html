Caché en memoria para datos agregados del libro de visitas (fecha de última visita, número de visitas). Extiende AbstractCache para ciclo de vida de actualización automática. Proporciona resúmenes VisitorbookInfo sin consultar la base de datos por cada visualización del libro de visitas.

Arquitectura

Estrategia de actualización

En refresh(), la caché se ejecuta en una transacción de solo lectura y:

  1. Carga todos los libros de visitas no eliminados en un mapa (clave por ID) con VisitorbookInfo vacío.
  2. Carga todas las entradas del libro de visitas no eliminadas, agrupadas por ID del libro de visitas.
  3. Para cada grupo, completa la información: lastDateOfVisit (primera/última entrada por fecha descendente), latestArrived/latestDeparted y numberOfVisits (recuento).

Invalidación selectiva

setExpired(id) actualiza la información de un solo libro de visitas sin actualizar toda la caché, utilizando la consulta nombrada queryVisitEntries filtrada por ID del libro de visitas. Esto se llama después de cualquier inserción/actualización/eliminación de una entrada del libro de visitas a través de VisitorbookService.

Seguridad para hilos

El acceso a visitorbookMap está sincronizado. El método refresh() trabaja con un nuevo mapa y reemplaza atómicamente la referencia, evitando lecturas obsoletas.
