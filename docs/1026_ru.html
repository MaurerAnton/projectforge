#1026: VisitorbookCache.kt

Кэш в памяти для агрегированных данных книги посетителей (дата последнего визита, количество визитов). Расширяет AbstractCache для автоматического цикла обновления. Предоставляет сводки VisitorbookInfo без выполнения запросов к базе данных для каждого отображения книги посетителей.

Архитектура

Стратегия обновления

При refresh() кэш запускается в транзакции только для чтения и:

  1. Загружает все неудалённые книги посетителей в карту (с ключом по ID) с пустыми VisitorbookInfo.
  2. Загружает все неудалённые записи книг посетителей, сгруппированные по ID книги.
  3. Для каждой группы заполняет информацию: lastDateOfVisit (первая/последняя запись по убыванию даты), latestArrived/latestDeparted и numberOfVisits (количество).

Выборочная инвалидация

setExpired(id) обновляет информацию одной книги посетителей без полного обновления кэша, используя именованный запрос queryVisitEntries, отфильтрованный по ID книги. Вызывается после любой вставки/обновления/удаления записи книги посетителей через VisitorbookService.

Потокобезопасность

Доступ к visitorbookMap синхронизирован. Метод refresh() работает с новой картой и атомарно заменяет ссылку, избегая чтения устаревших данных.
