Entité maîtresse pour le suivi des visiteurs. Mappe vers t_orga_visitorbook. Stocke l'identité du visiteur (prénom/nom, société, type) et les liens vers les personnes de contact EmployeeDO (ManyToMany). Possède une relation OneToMany avec VisitorbookEntryDO pour les enregistrements individuels de visites.

Conception de l'entité

Relations clés : contactPersons est un @ManyToMany vers EmployeeDO via la table de jointure T_ORGA_VISITORBOOK_EMPLOYEE, sérialisé uniquement sous forme d'IDs. entries est un @OneToMany (lazy, cascade persist/merge) vers VisitorbookEntryDO, marqué @NoHistory. Utilise @NamedEntityGraph pour le chargement eager des personnes de contact. L'annotation @AUserRightId("ORGA_VISITORBOOK") déclare la clé de droit d'accès.
