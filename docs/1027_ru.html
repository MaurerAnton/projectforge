projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookDO.kt JPA-сущность (Visitorbook), projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookDO.kt 123 строки · 86 кода · 24 комментария · 13 пустых
Главная сущность для отслеживания посетителей. Сопоставляется с t_orga_visitorbook. Хранит данные о посетителе (имя/фамилия, компания, тип) и ссылки на контактных лиц EmployeeDO (ManyToMany). Имеет отношение OneToMany с VisitorbookEntryDO для отдельных записей о визитах.

Проектирование сущности

Ключевые связи: contactPersons — это @ManyToMany с EmployeeDO через соединительную таблицу T_ORGA_VISITORBOOK_EMPLOYEE, сериализуется только как ID. entries — это @OneToMany (ленивая загрузка, каскад persist/merge) с VisitorbookEntryDO, помечено @NoHistory. Использует @NamedEntityGraph для жадной загрузки контактных лиц. Аннотация @AUserRightId("ORGA_VISITORBOOK") объявляет ключ права доступа.
