#1028: VisitorbookDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookDao.kt DAO (Visitorbook), projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookDao.kt 88 líneas · 55 código · 23 comentarios · 10 en blanco
DAO para registros maestros del libro de visitas. Extiende BaseDao<VisitorbookDO> con ordenación personalizada (por fecha de última visita descendente) e integración de historial. Utiliza grafo de entidades para cargar de forma eager las personas de contacto.

Diseño

Personalización de QueryFilter

Sobrescribe createQueryFilter para establecer el grafo de entidades ENTITY_GRAPH_WITH_CONTACT_EMPLOYEES, asegurando que las personas de contacto se carguen de forma eager al listar libros de visitas.

Ordenación personalizada

Sobrescribe select para ordenar los resultados por defecto por lastDateOfVisit descendente cuando no se especifica una ordenación explícita, utilizando VisitorbookCache. Esto coloca los libros visitados recientemente al inicio de las listas.

Integración de historial

Sobrescribe getHistoryPropertyPrefix para devolver el dateOfVisit de la entrada como prefijo para las entradas de historial de entradas hijas. También maneja la delegación del seguimiento del ID del libro de visitas mediante HistoryFormatUtils.

Cableado de servicios

Utiliza @PostConstruct para inyectarse a sí mismo en VisitorbookService.visitorbookDao, permitiendo que la capa de servicio delegue en el DAO.
