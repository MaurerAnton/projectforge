#1028: VisitorbookDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookDao.kt DAO (Книга посетителей), projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookDao.kt 88 строк · 55 кода · 23 комментария · 10 пустых
DAO для основных записей книги посетителей. Расширяет BaseDao с пользовательской сортировкой выборки (по дате последнего посещения по убыванию) и интеграцией истории. Использует граф сущностей для жадной загрузки контактных лиц.

Дизайн

Настройка QueryFilter

Переопределяет createQueryFilter для установки графа сущностей ENTITY_GRAPH_WITH_CONTACT_EMPLOYEES, обеспечивая жадную загрузку контактных лиц при выводе списка книг посетителей.

Пользовательская сортировка

Переопределяет select для сортировки результатов по умолчанию по lastDateOfVisit по убыванию, если не указана явная сортировка, используя VisitorbookCache. Это помещает недавно посещённые книги в начало списков.

Интеграция истории

Переопределяет getHistoryPropertyPrefix для возврата dateOfVisit записи в качестве префикса для записей истории дочерних элементов. Также обрабатывает делегирование отслеживания ID книги посетителей через HistoryFormatUtils.

Связывание сервисов

Использует @PostConstruct для внедрения себя в VisitorbookService.visitorbookDao, что позволяет сервисному слою делегировать задачи DAO.
