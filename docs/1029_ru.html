#1029: VisitorbookEntryDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookEntryDO.kt JPA-сущность (запись книги посетителей), projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookEntryDO.kt 77 строк · 42 кода · 27 комментариев · 8 пустых
Дочерняя сущность, представляющая одно посещение посетителем. Отображается на t_orga_visitorbook_entry. Каждая запись содержит дату визита, время прибытия/убытия (в виде строк для гибкости) и необязательный комментарий. Аннотирована @WithHistory для отслеживания истории.

Дизайн

Реализует Serializable и расширяет AbstractBaseDO<Long> вместо DefaultBaseDO — что даёт вручную определённый @Id с @GeneratedValue. Ссылается на родительскую VisitorbookDO через ленивую связь ManyToOne. Поля времени (arrived, departed) являются обычными строками для свободного ввода времени.
