#1031: VisitorbookService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookService.kt Servicio (Visitorbook), projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookService.kt 246 líneas · 176 código · 47 comentarios · 23 en blanco
Capa de servicio para operaciones CRUD de entradas del libro de visitas. Implementa IDao<VisitorbookDO>, proporcionando inserción/actualización/eliminación/recuperación de entradas de visita con control de acceso. Se integra con VisitorbookCache para la invalidación de caché después de mutaciones.

Arquitectura

Capa dual

Delega el listado y las comprobaciones de acceso a VisitorbookDao (que se inyecta a sí mismo mediante @PostConstruct en visitorbookDao). Maneja las operaciones a nivel de entrada directamente usando BaseDOPersistenceService y PfPersistenceService.

Integración de caché

Cada método de mutación (insert, updateVisitorbookEntry, markVisitorbookEntryAsDeleted, undeleteVisitorbookEntry) llama a visitorbookCache.setExpired(visitorbook.id) para activar la actualización selectiva de caché de los datos agregados del libro de visitas afectado.

Métodos de gestión de entradas

  • selectAllVisitorbookEntries: Carga todas las entradas de un libro de visitas ordenadas por fecha descendente, con filtro opcional de estado eliminado.
  • findVisitorbookEntry: Busca una sola entrada por ID con verificación de acceso opcional.
  • insertVisitorbookEntry: Método de conveniencia que construye una entrada a partir de cadenas de fecha/hora.
  • markVisitorbookEntryAsDeleted/undeleteVisitorbookEntry: Operaciones de eliminación suave/restauración con invalidación de caché.
