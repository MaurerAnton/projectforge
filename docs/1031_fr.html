Couche de service pour les opérations CRUD des entrées du livre d'or. Implémente IDao, fournissant insert/update/delete/undelete pour les entrées de visite avec contrôle d'accès. S'intègre avec VisitorbookCache pour l'invalidation du cache après les mutations.

Architecture

Double couche

Délègue le listage et les vérifications d'accès à VisitorbookDao (qui s'injecte via @PostConstruct dans visitorbookDao). Gère les opérations au niveau des entrées directement en utilisant BaseDOPersistenceService et PfPersistenceService.

Intégration du cache

Chaque méthode de mutation (insert, updateVisitorbookEntry, markVisitorbookEntryAsDeleted, undeleteVisitorbookEntry) appelle visitorbookCache.setExpired(visitorbook.id) pour déclencher un rafraîchissement sélectif du cache des données agrégées du livre d'or concerné.

Méthodes de gestion des entrées

  • selectAllVisitorbookEntries : Charge toutes les entrées d'un livre d'or triées par date décroissante, avec filtre optionnel sur le statut de suppression.
  • findVisitorbookEntry : Trouve une entrée unique par son ID avec vérification d'accès optionnelle.
  • insertVisitorbookEntry : Méthode pratique construisant une entrée à partir de chaînes date/heure.
  • markVisitorbookEntryAsDeleted/undeleteVisitorbookEntry : Opérations de suppression douce/restauration avec invalidation du cache.
