projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookService.kt Сервис (Visitorbook), projectforge-business/src/main/kotlin/org/projectforge/business/orga/VisitorbookService.kt 246 строк · 176 кода · 47 комментариев · 23 пустых
Сервисный слой для CRUD-операций с записями книги посетителей. Реализует IDao, предоставляя вставку/обновление/удаление/восстановление записей с контролем доступа. Интегрируется с VisitorbookCache для инвалидации кэша после изменений.

Архитектура

Двухуровневая

Делегирует операции списка и проверки доступа VisitorbookDao (который внедряет себя через @PostConstruct в visitorbookDao). Обрабатывает операции на уровне записей напрямую, используя BaseDOPersistenceService и PfPersistenceService.

Интеграция с кэшем

Каждый метод изменения (insert, updateVisitorbookEntry, markVisitorbookEntryAsDeleted, undeleteVisitorbookEntry) вызывает visitorbookCache.setExpired(visitorbook.id) для выборочного обновления агрегированных данных соответствующей книги посетителей.

Методы управления записями

  • selectAllVisitorbookEntries: Загружает все записи для книги посетителей, отсортированные по дате по убыванию, с опциональным фильтром по статусу удаления.
  • findVisitorbookEntry: Находит одну запись по ID с опциональной проверкой доступа.
  • insertVisitorbookEntry: Удобный метод, создающий запись из строк даты/времени.
  • markVisitorbookEntryAsDeleted/undeleteVisitorbookEntry: Операции мягкого удаления/восстановления с инвалидацией кэша.
