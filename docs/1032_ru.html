#1032: PollDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/poll/PollDO.kt JPA Сущность (Poll), projectforge-business/src/main/kotlin/org/projectforge/business/poll/PollDO.kt 135 строк · 92 кода · 22 комментария · 21 пустая
Центральная сущность опроса. Соответствует таблице t_poll. Хранит метаданные опроса (название, описание, местоположение, срок), списки контроля доступа (закодированные в CSV идентификаторы пользователей и групп для участников и полного доступа), определения полей ввода и конечный автомат (RUNNING → FINISHED → FINISHED_AND_MAIL_SENT).

Дизайн сущности

Расширяет DefaultBaseDO с @AUserRightId(value="poll", checkAccess=false). Ключевые элементы дизайна:

  • Списки ID в формате CSV: attendeeIds, groupAttendeeIds, fullAccessGroupIds, fullAccessUserIds — строки с разделителями-запятыми, хранящиеся в столбцах VARCHAR, парсятся с помощью утилиты toLongArray() и StringHelper.splitToLongs.
  • Вычисляемая роль: getPollAssignment() определяет роль текущего пользователя, проверяя владельца, accessUserIds и attendeeIds относительно вошедшего в систему пользователя.
  • Состояние: Внутреннее перечисление State (RUNNING, FINISHED, FINISHED_AND_MAIL_SENT) с getPollStatus(), транслирующимся в перечисление фильтра PollState.
  • Поля ввода: inputFields хранит сериализованные определения вопросов для формы ответа на опрос.
