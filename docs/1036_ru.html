Анализ архитектуры

Находится в projectforge-business, основном модуле, содержащем доменную логику, сервисы и персистентность. Выступает в роли фильтра запросов в инфраструктуре пользовательской фильтрации результатов, используется на страницах поиска и списков для сужения результатов базы данных на основе выбранных пользователем критериев. Определяет фиксированный набор именованных констант, часто реализующий I18nEnum для интернационализированных отображаемых меток.
