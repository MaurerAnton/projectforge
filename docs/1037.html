1037: AbstractScriptDao.kt

Abstract Script DAO, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/AbstractScriptDao.kt
Abstract base class for script DAOs (ScriptDao and MyScriptDao). Extends BaseDao providing script execution infrastructure: script lookup by name/ID, variable resolution, effective script generation, and executor creation.

Architecture

Script Execution Pipeline

  1. loadByNameOrId(name): Resolves a script by numeric ID or name pattern (case-insensitive LIKE search).
  2. execute(script, parameters, variables, imports, logger): Entry point for script execution. Creates executor via createScriptExecutor, then calls executor.execute().
  3. createScriptExecutor(...): Factory method using ScriptExecutor.createScriptExecutor(script, scriptLogger) to instantiate the correct executor type (Groovy or Kotlin), then initializes with script, DAO, variables, parameters, and imports.

Script Introspection

getScriptVariableNames() and getEffectiveScript() create a temporary executor to inspect compiled script variables and the final script text (with auto-imports and bindings prepended), useful for debugging and IDE-like features.
