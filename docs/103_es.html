Notas de diseño

  • Información en tooltips: Muchas claves siguen el patrón {clave}.info, proporcionando texto de ayuda contextual que se muestra como tooltips o texto secundario junto a los campos del formulario. Este es un patrón común de UX en ProjectForge.
  • Parámetros MessageFormat: Claves como capacity.stats ({0}/{1} ({2}%)) y mail.observe.subject (Actividades en ''{0}'') utilizan marcadores de posición de MessageFormat para valores dinámicos.
  • Modelo de acceso por capas: El paquete admite cuatro niveles de acceso: usuarios internos, grupos, administradores y usuarios externos con enlace+contraseña — cada uno con etiquetas y textos informativos dedicados.
  • IU de validación: Las claves validation.error.* proporcionan mensajes de error orientados al usuario con instrucciones claras de corrección (p. ej., "Contacte al administrador para aumentarlo").
  • Renombrado de auditoría → actividades: El commit 46b3db42e renombró las claves relacionadas con auditoría de audit a activities para mayor claridad para el usuario.
69 claves — el paquete i18n más grande entre los plugins documentados: Compárese con Memo (8 claves, #219), SkillMatrix (18 claves, #271), IHK (11 claves, #132). La complejidad del plugin DataTransfer proviene de su control de acceso multicapa, funciones de uso compartido externo y capacidades de pista de auditoría.
