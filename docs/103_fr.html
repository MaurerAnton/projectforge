Bundle de internationalisation par défaut pour le plugin DataTransfer — le module de partage de fichiers de ProjectForge. Avec 69 clés, c'est l'un des bundles i18n les plus étendus parmi tous les plugins, couvrant le contrôle d'accès, la gestion des expirations, les pistes d'audit, le partage externe, les notifications par e-mail et la validation.

Notes de conception

  • Infobulles d'information : De nombreuses clés suivent le modèle {clé}.info, fournissant un texte d'aide contextuel affiché sous forme d'infobulles ou de texte secondaire à côté des champs de formulaire. C'est un modèle UX courant dans ProjectForge.
  • Paramètres MessageFormat : Les clés comme capacity.stats ({0}/{1} ({2}%)) et mail.observe.subject (Activités dans ''{0}'') utilisent des espaces réservés MessageFormat pour les valeurs dynamiques.
  • Modèle d'accès multicouche : Le bundle prend en charge quatre niveaux d'accès : utilisateurs internes, groupes, administrateurs et utilisateurs externes avec lien+mot de passe — chacun avec des libellés et des textes d'information dédiés.
  • Interface de validation : Les clés validation.error.* fournissent des messages d'erreur destinés aux utilisateurs avec des instructions claires de résolution (par exemple, « Veuillez contacter l'administrateur pour l'augmenter »).
  • Renommage audit → activités : Le commit 46b3db42e a renommé les clés liées à l'audit de audit à activities pour une meilleure convivialité.
69 clés — le plus grand bundle i18n parmi les plugins documentés : Comparez avec Memo (8 clés, #219), SkillMatrix (18 clés, #271), IHK (11 clés, #132). La complexité du plugin DataTransfer provient de son contrôle d'accès multicouche, de ses fonctionnalités de partage externe et de ses capacités de piste d'audit.
