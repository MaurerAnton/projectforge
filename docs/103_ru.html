Пакет интернационализации по умолчанию для плагина DataTransfer — модуля обмена файлами ProjectForge. Содержит 69 ключей, что делает его одним из самых обширных пакетов i18n среди всех плагинов. Охватывает управление доступом, контроль сроков действия, аудит, внешний обмен, email-уведомления и валидацию.

Заметки по дизайну

  • Информационные подсказки: Многие ключи следуют шаблону {key}.info, предоставляя контекстную справку, отображаемую в виде подсказок или дополнительного текста рядом с полями форм. Это распространённый шаблон UX в ProjectForge.
  • Параметры MessageFormat: Ключи, такие как capacity.stats ({0}/{1} ({2}%)) и mail.observe.subject (Действия в ''{0}''), используют плейсхолдеры MessageFormat для динамических значений.
  • Многоуровневая модель доступа: Пакет поддерживает четыре уровня доступа: внутренние пользователи, группы, администраторы и внешние пользователи со ссылкой+паролем — для каждого предусмотрены отдельные метки и информационные тексты.
  • Интерфейс валидации: Ключи validation.error.* предоставляют понятные пользователю сообщения об ошибках с чёткими инструкциями по исправлению (например, «Пожалуйста, свяжитесь с администратором для увеличения»).
  • Переименование аудита в действия: Коммит 46b3db42e переименовал ключи, связанные с аудитом, из audit в activities для удобства пользователей.
69 ключей — крупнейший пакет i18n среди документированных плагинов: Сравните с Memo (8 ключей, #219), SkillMatrix (18 ключей, #271), IHK (11 ключей, #132). Сложность плагина DataTransfer обусловлена его многоуровневым контролем доступа, функциями внешнего обмена и возможностями аудита.
