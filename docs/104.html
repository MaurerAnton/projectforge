Design Notes

  • Info tooltips: Many keys follow the {key}.info pattern, providing in-context help text displayed as tooltips or secondary text next to form fields. This is a common ProjectForge UX pattern.
  • MessageFormat parameters: Keys like capacity.stats ({0}/{1} ({2}%)) and mail.observe.subject (Activities in ''{0}'') use MessageFormat placeholders for dynamic values.
  • Layered access model: The bundle supports four access layers: internal users, groups, admins, and external users with link+password — each with dedicated labels and info texts.
  • Validation UI: The validation.error.* keys provide user-facing error messages with clear remediation instructions (e.g., "Please contact admin to increase").
  • Renamed audit → activities: Commit 46b3db42e renamed the audit-related keys from audit to activities for user-friendliness.
69 keys — largest i18n bundle among the documented plugins: Compare to Memo (8 keys, #219), SkillMatrix (18 keys, #271), IHK (11 keys, #132). The DataTransfer plugin's complexity stems from its multi-layered access control, external sharing features, and audit trail capabilities.
