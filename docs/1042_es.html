Implementa IPrivacyProtectionJob para eliminar eventos de calendario anteriores a un número configurable de días. Se configura mediante la propiedad JSON projectforge.privacyProtection.purgeCalendars que especifica los ID de calendario y los días de caducidad. Se usa típicamente para purgar automáticamente calendarios de enfermedad.

Arquitectura

Configuración

Lee la propiedad purgeCalendars como un array JSON de objetos {calendarId, expiryDays} mediante JsonUtils.fromJson. En @PostConstruct, analiza la configuración y se registra con CronPrivacyProtectionJob. Maneja errores de análisis de forma elegante con registro de errores.

Ejecución

Para cada calendario configurado:

  1. Carga el calendario mediante TeamCalDao.find(calendarId, checkAccess=false).
  2. Calcula expiryDate = ahora - expiryDays.
  3. Ejecuta una consulta nombrada SELECT_ENTRIES_IN_THE_PAST_TO_PURGE en una transacción para encontrar eventos que finalicen antes de la fecha de caducidad.
  4. Elimina forzosamente cada evento mediante TeamEventDao.forceDelete(event, checkAccess=false), eliminando también las entradas de historial (commit c3a3a7476).
