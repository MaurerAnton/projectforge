Implémente IPrivacyProtectionJob pour supprimer les événements de calendrier plus anciens qu'un nombre configurable de jours. Configuré via la propriété JSON projectforge.privacyProtection.purgeCalendars spécifiant les identifiants de calendrier et les jours d'expiration. Généralement utilisé pour purger automatiquement les calendriers de maladie.

Architecture

Configuration

Lit la propriété purgeCalendars sous forme de tableau JSON d'objets {calendarId, expiryDays} via JsonUtils.fromJson. Sur @PostConstruct, analyse la configuration et s'enregistre auprès de CronPrivacyProtectionJob. Gère les erreurs d'analyse avec une journalisation des erreurs.

Exécution

Pour chaque calendrier configuré :

  1. Charge le calendrier via TeamCalDao.find(calendarId, checkAccess=false).
  2. Calcule expiryDate = maintenant - expiryDays.
  3. Exécute une requête nommée SELECT_ENTRIES_IN_THE_PAST_TO_PURGE dans une transaction pour trouver les événements se terminant avant la date d'expiration.
  4. Supprime de force chaque événement via TeamEventDao.forceDelete(event, checkAccess=false), en supprimant également les entrées d'historique (commit c3a3a7476).
