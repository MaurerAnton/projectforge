#1042: PurgeCalendarEntriesJob.kt

projectforge-business/src/main/kotlin/org/projectforge/business/privacyprotection/PurgeCalendarEntriesJob.kt Задача конфиденциальности (очистка календаря), projectforge-business/src/main/kotlin/org/projectforge/business/privacyprotection/PurgeCalendarEntriesJob.kt 120 строк · 80 кода · 28 комментариев · 12 пустых
Реализует IPrivacyProtectionJob для удаления событий календаря старше заданного количества дней. Настраивается через JSON-свойство projectforge.privacyProtection.purgeCalendars, указывающее идентификаторы календарей и срок хранения в днях. Обычно используется для автоматической очистки календарей болезней.

Архитектура

Конфигурация

Читает свойство purgeCalendars как JSON-массив объектов {calendarId, expiryDays} через JsonUtils.fromJson. При @PostConstruct разбирает конфигурацию и регистрирует себя в CronPrivacyProtectionJob. Корректно обрабатывает ошибки парсинга с записью в журнал.

Выполнение

Для каждого настроенного календаря:

  1. Загружает календарь через TeamCalDao.find(calendarId, checkAccess=false).
  2. Вычисляет expiryDate = now - expiryDays.
  3. Запускает именованный запрос SELECT_ENTRIES_IN_THE_PAST_TO_PURGE в транзакции для поиска событий, завершающихся до даты истечения срока.
  4. Принудительно удаляет каждое событие через TeamEventDao.forceDelete(event, checkAccess=false), также удаляя записи истории (коммит c3a3a7476).
