Clase base abstracta para DAOs de script (ScriptDao y MyScriptDao). Extiende BaseDao<ScriptDO> proporcionando infraestructura de ejecución de scripts: búsqueda de script por nombre/ID, resolución de variables, generación de script efectivo y creación de ejecutor.

Arquitectura

Pipeline de ejecución de scripts

  1. loadByNameOrId(nombre): Resuelve un script por ID numérico o patrón de nombre (búsqueda LIKE sin distinción de mayúsculas/minúsculas).
  2. execute(script, parámetros, variables, importaciones, logger): Punto de entrada para la ejecución del script. Crea el ejecutor mediante createScriptExecutor, luego llama a executor.execute().
  3. createScriptExecutor(...): Método de fábrica que utiliza ScriptExecutor.createScriptExecutor(script, scriptLogger) para instanciar el tipo de ejecutor correcto (Groovy o Kotlin), luego inicializa con script, DAO, variables, parámetros e importaciones.

Introspección de scripts

getScriptVariableNames() y getEffectiveScript() crean un ejecutor temporal para inspeccionar las variables del script compilado y el texto final del script (con importaciones automáticas y enlaces antepuestos), útil para depuración y funciones similares a IDE.
