Classe de base abstraite pour les DAO de script (ScriptDao et MyScriptDao). Étend BaseDao en fournissant une infrastructure d'exécution de script : recherche de script par nom/ID, résolution de variables, génération de script effectif et création d'exécuteur.

Architecture

Pipeline d'exécution de script

  1. loadByNameOrId(name) : Résout un script par ID numérique ou motif de nom (recherche LIKE insensible à la casse).
  2. execute(script, parameters, variables, imports, logger) : Point d'entrée pour l'exécution du script. Crée un exécuteur via createScriptExecutor, puis appelle executor.execute().
  3. createScriptExecutor(...) : Méthode d'usine utilisant ScriptExecutor.createScriptExecutor(script, scriptLogger) pour instancier le type d'exécuteur correct (Groovy ou Kotlin), puis initialise avec le script, le DAO, les variables, les paramètres et les importations.

Introspection de script

getScriptVariableNames() et getEffectiveScript() créent un exécuteur temporaire pour inspecter les variables de script compilées et le texte final du script (avec les auto-importations et les liaisons ajoutées), utile pour le débogage et les fonctionnalités de type IDE.
