#1043: AbstractScriptDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/AbstractScriptDao.kt Абстрактный DAO скриптов, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/AbstractScriptDao.kt 101 строка · 61 код · 31 комментарий · 9 пустых
Абстрактный базовый класс для DAO скриптов (ScriptDao и MyScriptDao). Расширяет BaseDao, предоставляя инфраструктуру выполнения скриптов: поиск скрипта по имени/ID, разрешение переменных, генерация эффективного скрипта и создание исполнителя.

Архитектура

Конвейер выполнения скриптов

  1. loadByNameOrId(name): Разрешает скрипт по числовому ID или шаблону имени (регистронезависимый поиск LIKE).
  2. execute(script, parameters, variables, imports, logger): Точка входа для выполнения скрипта. Создаёт исполнителя через createScriptExecutor, затем вызывает executor.execute().
  3. createScriptExecutor(...): Фабричный метод, использующий ScriptExecutor.createScriptExecutor(script, scriptLogger) для создания экземпляра правильного типа исполнителя (Groovy или Kotlin), затем инициализирует его скриптом, DAO, переменными, параметрами и импортами.

Интроспекция скриптов

getScriptVariableNames() и getEffectiveScript() создают временный исполнитель для проверки скомпилированных переменных скрипта и финального текста скрипта (с автоматически добавленными импортами и привязками), что полезно для отладки и функций, подобных IDE.
