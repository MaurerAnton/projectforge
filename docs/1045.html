1045: KotlinScriptContext.kt

Script Variable Container, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/KotlinScriptContext.kt
Workaround for Kotlin scripting's property binding limitations. Wraps a MutableMap<String, Any?> with setProperty/getProperty methods. Registered as a providedProperty in the Kotlin script compilation configuration, enabling scripts to access variables via context.getProperty("name").
