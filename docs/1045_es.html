Constructor para scripts que construyen archivos ZIP de múltiples archivos como salida de ejecución. Soporta añadir libros de Excel (tanto el legado ExportWorkbook como el más reciente ExcelWorkbook), imágenes JFreeChart, cadenas de texto y arreglos de bytes sin procesar. Cifrado opcional AES-256 de todo el archivo.

Arquitectura

Agregación de archivos

Múltiples sobrecargas de add() aceptan varios tipos de exportación. Los archivos se recogen en un MutableCollection<ExportZipFile>. El método write() transmite las entradas a un ZipOutputStream.

Cifrado

Si se establece encryptionPassword, el archivo se escribe primero como un ZIP sin cifrar en memoria, luego se cifra mediante ZipUtils.encryptZipFile() con modo configurable (por defecto AES-256). El cifrado se aplica a todo el ZIP, no por archivo.

Control de estructura

La bandera flatStructure controla si los archivos se añaden a la raíz del ZIP o se envuelven en un subdirectorio con el nombre del archivo. El valor predeterminado crea una entrada de directorio nombrearchivo/.

Integración con Excel

Soporta tanto el legado ExportWorkbook como el más reciente ExcelWorkbook (biblioteca Merlin). Para ExcelWorkbook, evalúa todas las fórmulas antes de la serialización.
