#1045: ExportZipArchive.kt

Построитель для скриптов, создающих многотомные ZIP-архивы в качестве результата выполнения. Поддерживает добавление книг Excel (как устаревших ExportWorkbook, так и новых ExcelWorkbook), изображений JFreeChart, строк и необработанных байтовых массивов. Опциональное шифрование AES-256 всего архива.

Архитектура

Агрегация файлов

Несколько перегрузок add() принимают различные типы экспорта. Файлы собираются в MutableCollection<ExportZipFile>. Метод write() передаёт записи в ZipOutputStream.

Шифрование

Если задан encryptionPassword, архив сначала записывается как незашифрованный ZIP в память, затем шифруется через ZipUtils.encryptZipFile() с настраиваемым режимом (по умолчанию AES-256). Шифрование применяется ко всему ZIP, а не к отдельным файлам.

Управление структурой

Флаг flatStructure определяет, добавляются ли файлы в корень ZIP или помещаются в подкаталог, названный по имени архива. По умолчанию создаётся запись каталога filename/.

Интеграция с Excel

Поддерживаются как устаревшие ExportWorkbook, так и новые ExcelWorkbook (библиотека Merlin). Для ExcelWorkbook перед сериализацией вычисляются все формулы.
