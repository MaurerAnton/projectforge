Motor de plantillas que proporciona interpolación de cadenas basada en Groovy y formato i18n para la salida de scripts. Expuesto a los scripts como la variable pf. Soporta inclusiones de plantillas (#INCLUDE{filename}), preprocesamiento XML (etiquetas <groovy>) y sobrecargas completas de getString() para formatear entidades, fechas, monedas y números.

Arquitectura

Procesamiento de plantillas

executeTemplate(template) primero procesa las directivas #INCLUDE{filename} (cargando recursos a través de ConfigurationService), luego delega en GroovyExecutor.executeTemplate() para la interpolación de cadenas Groovy. Los marcadores especiales (#HURZ1#, #HURZ2#) evitan el tratamiento que Groovy da a la barra invertida y los signos de dólar en el reemplazo de expresiones regulares.

Preprocesamiento XML

Para plantillas XML bien formadas, las etiquetas <groovy>...</groovy> se convierten en <% ... %> y <groovy-out>...</groovy-out> en <%= ... %>, permitiendo scriptlets de Groovy dentro de documentos XML.

Métodos de formato

getString() sobrecargado maneja: KundeDO, ProjektDO, PFUserDO, TaskDO, Number, BigDecimal, LocalDate, Date, I18nEnum — cada uno delegado a la clase de formateo correspondiente. getCurrency(value) utiliza CurrencyFormatter. formatBytes() utiliza FormatterUtils.

Manejo de nulos

Las sobrecargas explícitas isNull(), isBlank() e isEmpty() manejan NullObject de Groovy para evitar errores de script al acceder a variables no establecidas.
