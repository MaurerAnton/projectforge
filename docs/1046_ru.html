#1046: GroovyEngine.kt

Шаблонизатор, обеспечивающий интерполяцию строк на основе Groovy и форматирование i18n для вывода скриптов. Доступен скриптам как переменная pf. Поддерживает включение шаблонов (#INCLUDE{filename}), предобработку XML (теги <groovy>) и всесторонние перегрузки getString() для форматирования сущностей, дат, валют и чисел.

Архитектура

Обработка шаблонов

executeTemplate(template) сначала обрабатывает директивы #INCLUDE{filename} (загружая ресурсы через ConfigurationService), затем делегирует выполнение GroovyExecutor.executeTemplate() для интерполяции строк Groovy. Специальные маркеры (#HURZ1#, #HURZ2#) обходят особенности обработки обратной косой черты и знаков доллара в регулярных выражениях Groovy.

Предобработка XML

Для корректно сформированных XML-шаблонов теги <groovy>...</groovy> преобразуются в <% ... %>, а <groovy-out>...</groovy-out> — в <%= ... %>, что позволяет использовать скриптлеты Groovy внутри XML-документов.

Методы форматирования

Перегруженный getString() обрабатывает: KundeDO, ProjektDO, PFUserDO, TaskDO, Number, BigDecimal, LocalDate, Date, I18nEnum — каждый делегирован соответствующему классу форматирования. getCurrency(value) использует CurrencyFormatter. formatBytes() использует FormatterUtils.

Обработка null

Явные перегрузки isNull(), isBlank() и isEmpty() обрабатывают NullObject Groovy, предотвращая ошибки скриптов при доступе к неустановленным переменным.
