ScriptExecutor concreto para scripts Kotlin. Compila y evalúa código fuente Kotlin usando la API kotlin.script.experimental. Maneja la resolución del classpath en JAR gordo mediante JarExtractor, el enlace de variables mediante KotlinScriptContext y la ejecución de scripts con un tiempo de espera de 300 segundos y diagnóstico de errores adecuado.

Arquitectura

Configuración de compilación

Configura el scripting de Kotlin con:

  • Classpath: Si se ejecuta en un JAR gordo, usa URLClassLoader con JarExtractor.classpathUrls y updateClasspath(JarExtractor.classpathFiles). De lo contrario, usa dependenciesFromCurrentContext(wholeClasspath=true).
  • Propiedades proporcionadas: Registra "context" como tipo KotlinScriptContext, permitiendo context.getProperty("nombre") en los scripts.
  • Opciones del compilador: -nowarn para suprimir ruido.

Ejecución con tiempo de espera

Usa Executors.newSingleThreadExecutor() con un tiempo de espera de 300 segundos mediante Future.get(300, SECONDS). Al agotarse el tiempo, cancela el futuro, registra el error y establece scriptExecutionResult.exception. El ejecutor siempre se cierra en finally.

Enlace de variables

Puebla un KotlinScriptContext con todas las variables y parámetros, que luego KotlinScriptUtils.appendBlockAfterImports genera declaraciones de propiedades Kotlin para ellos.

Importaciones estándar

Añade importaciones específicas de Kotlin más allá de las STANDARD_IMPORTS base: funciones de localización (translate, translateMsg), extensiones de formato de números (format, formatCurrency, formatBytes) y PfCaches.initialize.
