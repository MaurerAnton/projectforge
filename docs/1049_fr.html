ScriptExecutor concret pour les scripts Kotlin. Compile et évalue le code source Kotlin en utilisant l'API kotlin.script.experimental. Gère la résolution du classpath JAR via JarExtractor, la liaison des variables via KotlinScriptContext, et l'exécution des scripts avec un délai d'attente de 300 secondes et des diagnostics d'erreur appropriés.

Architecture

Configuration de la compilation

Configure le scripting Kotlin avec :

  • Classpath : Si exécuté dans un JAR épais, utilise URLClassLoader avec JarExtractor.classpathUrls et updateClasspath(JarExtractor.classpathFiles). Sinon, utilise dependenciesFromCurrentContext(wholeClasspath=true).
  • Propriétés fournies : Enregistre "context" comme type KotlinScriptContext, permettant context.getProperty("name") dans les scripts.
  • Options du compilateur : -nowarn pour supprimer le bruit.

Exécution avec délai d'attente

Utilise Executors.newSingleThreadExecutor() avec un délai d'attente de 300 secondes via Future.get(300, SECONDS). En cas de dépassement, annule le futur, enregistre l'erreur et définit scriptExecutionResult.exception. L'exécuteur est toujours arrêté dans finally.

Liaison des variables

Remplit un KotlinScriptContext avec toutes les variables et paramètres, que KotlinScriptUtils.appendBlockAfterImports utilise ensuite pour générer des déclarations de propriétés Kotlin.

Importations standard

Ajoute des importations spécifiques à Kotlin au-delà des STANDARD_IMPORTS de base : fonctions de localisation (translate, translateMsg), extensions de formatage des nombres (format, formatCurrency, formatBytes), et PfCaches.initialize.
