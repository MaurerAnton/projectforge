#1049: KotlinScriptExecutor.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/KotlinScriptExecutor.kt Исполнитель Kotlin-скриптов, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/KotlinScriptExecutor.kt 139 строк · 106 кода · 25 комментариев · 8 пустых
Конкретный ScriptExecutor для Kotlin-скриптов. Компилирует и выполняет Kotlin-исходники с использованием API kotlin.script.experimental. Обрабатывает разрешение classpath для fat JAR через JarExtractor, привязку переменных через KotlinScriptContext и выполнение скрипта с таймаутом 300 секунд и надлежащей диагностикой ошибок.

Архитектура

Конфигурация компиляции

Настраивает написание скриптов на Kotlin с:

  • Classpath: При запуске в fat JAR используется URLClassLoader с JarExtractor.classpathUrls и updateClasspath(JarExtractor.classpathFiles). В противном случае используется dependenciesFromCurrentContext(wholeClasspath=true).
  • Предоставленные свойства: Регистрирует "context" как тип KotlinScriptContext, что позволяет использовать context.getProperty("name") в скриптах.
  • Параметры компилятора: -nowarn для подавления лишних предупреждений.

Выполнение с таймаутом

Использует Executors.newSingleThreadExecutor() с таймаутом 300 секунд через Future.get(300, SECONDS). При таймауте отменяет future, логирует ошибку и устанавливает scriptExecutionResult.exception. Исполнитель всегда завершается в блоке finally.

Привязка переменных

Заполняет KotlinScriptContext всеми переменными и параметрами, после чего KotlinScriptUtils.appendBlockAfterImports генерирует для них объявления свойств Kotlin.

Стандартные импорты

Добавляет специфические для Kotlin импорты поверх базовых STANDARD_IMPORTS: функции локализации (translate, translateMsg), расширения форматирования чисел (format, formatCurrency, formatBytes) и PfCaches.initialize.
