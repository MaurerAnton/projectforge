DAO para scripts ejecutables por usuarios no privilegiados (no finanzas/controlling). Extiende AbstractScriptDao. Otorga acceso de ejecución basado en los campos executableByUserIds o executableByGroupIds del script, en lugar de requerir membresía en el grupo de finanzas/controlling.

Control de acceso

Solo permite operaciones SELECT para usuarios no privilegiados. En SELECT, verifica:

  1. El script no está eliminado.
  2. El ID del usuario conectado está en la lista CSV de executableByUserIds.
  3. El usuario conectado es miembro de un grupo listado en la lista CSV de executableByGroupIds (resuelto mediante userGroupCache).
Todas las demás operaciones (insertar, actualizar, eliminar) son denegadas con AccessException.
