DAO pour les scripts exécutables par les utilisateurs non privilégiés (hors finance/contrôle). Étend AbstractScriptDao. Accorde l'accès à l'exécution en fonction des champs executableByUserIds ou executableByGroupIds du script, plutôt que d'exiger l'appartenance au groupe finance/contrôle.

Contrôle d'accès

Autorise uniquement les opérations SELECT pour les utilisateurs non privilégiés. Lors d'un SELECT, vérifie :

  1. Le script n'est pas supprimé.
  2. L'ID de l'utilisateur connecté figure dans la liste CSV executableByUserIds.
  3. L'utilisateur connecté est membre d'un groupe listé dans la liste CSV executableByGroupIds (résolu via userGroupCache).
Toutes les autres opérations (insertion, mise à jour, suppression) sont refusées avec une AccessException.
