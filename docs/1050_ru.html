DAO для скриптов, выполняемых непривилегированными пользователями (не финансы/контроллинг). Расширяет AbstractScriptDao. Предоставляет доступ на выполнение на основе полей executableByUserIds или executableByGroupIds скрипта, а не требования членства в группе финансов/контроллинга.

Контроль доступа

Разрешает только операции SELECT для непривилегированных пользователей. При SELECT проверяет:

  1. Скрипт не удалён.
  2. ID вошедшего пользователя присутствует в CSV-списке executableByUserIds.
  3. Вошедший пользователь является членом группы, указанной в CSV-списке executableByGroupIds (разрешение через userGroupCache).
Все остальные операции (вставка, обновление, удаление) запрещены с AccessException.
