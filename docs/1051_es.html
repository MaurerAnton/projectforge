Entidad central para scripts almacenados. Se asigna a la tabla T_SCRIPT. Soporta tres tipos de script (KOTLIN, GROOVY, INCLUDE), seis ranuras de parámetros, ejecución como otro usuario (sudo), restricciones de ejecución por usuario/grupo, almacenamiento de copia de seguridad del script, archivos adjuntos y resolución recursiva de inclusiones.

Diseño de la entidad

Tipos de script

Enum ScriptType: KOTLIN (Kotlin .kts), GROOVY e INCLUDE (fragmento de script, no ejecutable de forma independiente).

Control de ejecución

  • executeAsUser: si se establece, el script se ejecuta con los permisos completos de este usuario (sudo).
  • executableByGroupIds, executableByUserIds: listas CSV que controlan qué usuarios no administradores pueden ejecutar (usado por MyScriptDao).

Sistema de parámetros

Seis ranuras de parámetros estáticas (parameter1-6Name, parameter1-6Type, parameter1-6Description). getParameterList() construye una List<ScriptParameter> con seguridad de tipos. setParameterList() reconstruye los campos individuales a partir de una lista.

Contenido del script

El cuerpo del script se almacena como ByteArray BLOB con @NoHistory (no se rastrea en el historial). En su lugar, scriptBackup almacena la versión anterior. scriptAsString es una propiedad @Transient con conversión UTF-8 por conveniencia. Soporta AttachmentsInfo para archivos adjuntos.

Sistema de inclusión

includes (transitorio) almacena objetos ScriptDO referenciados. includesRecursive recorre el árbol de inclusión con detección de referencias circulares (por ID), produciendo un conjunto plano de todos los scripts incluidos transitivamente.
