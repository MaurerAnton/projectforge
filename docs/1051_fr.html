Entité centrale pour les scripts stockés. Correspond à la table T_SCRIPT. Prend en charge trois types de script (KOTLIN, GROOVY, INCLUDE), six emplacements de paramètres, l'exécution en tant qu'un autre utilisateur (sudo), les restrictions d'exécution par utilisateur/groupe, le stockage de sauvegarde des scripts, les pièces jointes et la résolution récursive des inclusions.

Conception de l'entité

Types de script

Énumération ScriptType : KOTLIN (Kotlin .kts), GROOVY et INCLUDE (extrait de script, non exécutable de manière autonome).

Contrôle d'exécution

  • executeAsUser : si défini, le script s'exécute avec les autorisations complètes de cet utilisateur (sudo).
  • executableByGroupIds, executableByUserIds : listes CSV contrôlant quels utilisateurs non administrateurs peuvent exécuter (utilisé par MyScriptDao).

Système de paramètres

Six emplacements de paramètres statiques (parameter1-6Name, parameter1-6Type, parameter1-6Description). getParameterList() construit une List<ScriptParameter> avec sécurité de type. setParameterList() reconstruit les champs individuels à partir d'une liste.

Contenu du script

Corps du script stocké sous forme de BLOB ByteArray avec @NoHistory (non suivi dans l'historique). À la place, scriptBackup stocke la version précédente. scriptAsString est une propriété @Transient avec commodité de conversion UTF-8. Prend en charge AttachmentsInfo pour les pièces jointes.

Système d'inclusion

includes (transitoire) stocke les objets ScriptDO référencés. includesRecursive parcourt l'arbre d'inclusion avec détection de référence circulaire (par ID), produisant un ensemble aplati de tous les scripts inclus transitivement.
