#1051: ScriptDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptDO.kt JPA-сущность (Script), projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptDO.kt 436 строк · 321 код · 54 комментария · 61 пустая
Центральная сущность для хранимых скриптов. Соответствует таблице T_SCRIPT. Поддерживает три типа скриптов (KOTLIN, GROOVY, INCLUDE), шесть слотов параметров, выполнение от имени другого пользователя (sudo), ограничения по выполнению пользователем/группой, резервное копирование скриптов, прикрепление файлов и рекурсивное разрешение включений.

Дизайн сущности

Типы скриптов

Перечисление ScriptType: KOTLIN (Kotlin .kts), GROOVY и INCLUDE (фрагмент скрипта, не исполняется отдельно).

Управление выполнением

  • executeAsUser: если установлено, скрипт выполняется с полными правами этого пользователя (sudo).
  • executableByGroupIds, executableByUserIds: списки CSV, определяющие, какие не-администраторы могут выполнять (используется MyScriptDao).

Система параметров

Шесть статических слотов параметров (parameter1-6Name, parameter1-6Type, parameter1-6Description). getParameterList() создаёт List<ScriptParameter> с типобезопасностью. setParameterList() перестраивает отдельные поля из списка.

Содержимое скрипта

Тело скрипта хранится как ByteArray BLOB с @NoHistory (не отслеживается в истории). Вместо этого scriptBackup хранит предыдущую версию. scriptAsString — это @Transient свойство с удобным преобразованием UTF-8. Поддерживает AttachmentsInfo для прикрепления файлов.

Система включений

includes (транзиентное) хранит ссылки на объекты ScriptDO. includesRecursive обходит дерево включений с обнаружением циклических ссылок (по ID), создавая уплощённый набор всех транзитивно включённых скриптов.
