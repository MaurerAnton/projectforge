DAO für Skripte, die von Mitgliedern der Finanz-/Controlling-Gruppe ausgeführt werden können. Erweitert AbstractScriptDao. Bietet Skript-Backup-Verwaltung (automatisches Backup bei Aktualisierung auf die Festplatte), Backup-Dateiabruf und Anpassung der Historiendarstellung (Auflösung von Gruppen-/Benutzer-ID-Referenzen).

Architektur

Zugriffskontrolle

Beschränkt den Zugriff auf Mitglieder von CONTROLLING_GROUP oder FINANCE_GROUP über accessChecker.isUserMemberOfGroup.

Skript-Backup

onUpdate(obj, dbObj) vergleicht den Skript-Inhalt mittels Arrays.equals. Bei Änderung wird das alte Skript in das Feld scriptBackup kopiert und ein Festplatten-Backup unter {backupDir}/scripts/script-{id}_{name}_{timestamp}.{ext} geschrieben. Backups können über getBackupFiles() abgerufen werden, das sowohl aktuelle als auch ältere Benennungsmuster auflistet.

Historie-Formatierung

Überschreibt customizeDisplayHistoryEntry, um an historyFormatUtils.replaceGroupAndUserIdsValues zu delegieren, welches ID-Referenzen in Historieeinträgen in lesbare Gruppen-/Benutzernamen auflöst.
