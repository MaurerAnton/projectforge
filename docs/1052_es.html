DAO para scripts ejecutables por miembros del grupo de finanzas/controlling. Extiende AbstractScriptDao. Proporciona gestión de copias de seguridad de scripts (copia de seguridad automática al actualizar en disco), recuperación de archivos de respaldo y personalización de visualización del historial (resolviendo referencias de ID de grupo/usuario).

Arquitectura

Control de Acceso

Restringe el acceso a miembros de CONTROLLING_GROUP o FINANCE_GROUP mediante accessChecker.isUserMemberOfGroup.

Copia de Seguridad de Scripts

onUpdate(obj, dbObj) compara el contenido del script mediante Arrays.equals. Si cambió, copia el script anterior al campo scriptBackup y escribe una copia de seguridad en disco en {backupDir}/scripts/script-{id}_{name}_{timestamp}.{ext}. Las copias de seguridad se pueden recuperar mediante getBackupFiles(), que lista tanto los patrones de nomenclatura actuales como los heredados.

Formato del Historial

Sobrescribe customizeDisplayHistoryEntry para delegar en historyFormatUtils.replaceGroupAndUserIdsValues, que resuelve las referencias de ID en las entradas del historial a nombres legibles de grupo/usuario.
