DAO pour les scripts exécutables par les membres du groupe finance/contrôle. Étend AbstractScriptDao. Fournit la gestion des sauvegardes de scripts (sauvegarde automatique lors de la mise à jour sur disque), la récupération des fichiers de sauvegarde et la personnalisation de l'affichage de l'historique (résolution des références d'ID de groupe/utilisateur).

Architecture

Contrôle d'accès

Limite l'accès aux membres de CONTROLLING_GROUP ou FINANCE_GROUP via accessChecker.isUserMemberOfGroup.

Sauvegarde des scripts

onUpdate(obj, dbObj) compare le contenu du script via Arrays.equals. Si modifié, copie l'ancien script dans le champ scriptBackup et écrit une sauvegarde disque dans {backupDir}/scripts/script-{id}_{name}_{timestamp}.{ext}. Les sauvegardes sont récupérables via getBackupFiles() qui liste les motifs de nommage actuels et hérités.

Formatage de l'historique

Remplace customizeDisplayHistoryEntry pour déléguer à historyFormatUtils.replaceGroupAndUserIdsValues, qui résout les références d'ID dans les entrées d'historique en noms lisibles de groupes/utilisateurs.
