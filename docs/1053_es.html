Contenedor de resultados devuelto por la ejecución del script. Contiene la salida de la ejecución, información de excepciones, el texto efectivo del script (con importaciones automáticas), mensajes de disponibilidad de descarga y el objeto de resultado sin procesar. Proporciona formato de salida con escape HTML para su visualización en la interfaz de usuario.

Métodos auxiliares

hasResult() verifica si el resultado no es nulo. hasException() verifica tanto exception como si result mismo es un Throwable. resultAsHtmlString escapa caracteres HTML y reemplaza saltos de línea con <br/>.
