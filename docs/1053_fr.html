Conteneur de résultat retourné par l'exécution du script. Contient la sortie d'exécution, les informations d'exception, le texte effectif du script (avec auto-importations), les messages de disponibilité de téléchargement et l'objet résultat brut. Fournit un formatage de sortie échappé HTML pour l'affichage dans l'interface utilisateur.

Méthodes auxiliaires

hasResult() vérifie si le résultat est non nul. hasException() vérifie à la fois exception et si result lui-même est un Throwable. resultAsHtmlString échappe les caractères HTML et remplace les nouvelles lignes par <br/>.
