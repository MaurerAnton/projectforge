#1053: ScriptExecutionResult.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptExecutionResult.kt Объект результата скрипта, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptExecutionResult.kt 68 строк · 26 кода · 33 комментария · 9 пустых
Контейнер результата, возвращаемый при выполнении скрипта. Содержит вывод выполнения, информацию об исключении, фактический текст скрипта (с автоимпортами), сообщения о доступности загрузки и необработанный объект результата. Предоставляет форматирование вывода с экранированием HTML для отображения в интерфейсе.

Поля

ПолеТипНазначение
scriptLoggerScriptLoggerЗахватывает сообщения журнала из выполнения скрипта
resultAny?Необработанное возвращаемое значение скрипта
exceptionThrowable?Исключение (если скрипт его вызвал)
outputString?Стандартный вывод, захваченный во время выполнения
scriptStringФактический текст скрипта с автоимпортами
downloadAvailableString?Понятное пользователю сообщение, если загрузка готова
resultAsUserFriendlyStringString?Форматированное строковое представление

Вспомогательные методы

hasResult() проверяет, не является ли результат null. hasException() проверяет как exception, так и то, является ли сам result типом Throwable. resultAsHtmlString экранирует HTML-символы и заменяет новые строки на <br/>.
