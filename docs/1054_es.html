projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptExecutor.kt Servicio principal / Motor de scripts, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptExecutor.kt 376 líneas · 274 código · 71 comentarios · 31 en blanco
Clase base abstracta para todos los ejecutores de scripts (Groovy y Kotlin). Gestiona la compilación de scripts desde el código fuente con resolución de #INCLUDE, inyección de importaciones automáticas, enlace de variables (daos, appId, taskTree, cachés, etc.) y manejo de parámetros de script. Construye el script efectivo fusionando el código de usuario con importaciones generadas automáticamente y enlaces específicos del lenguaje. También alberga el método de fábrica createScriptExecutor() que detecta automáticamente Kotlin vs Groovy basándose en la presencia de palabras clave val/var/fun y el conjunto complementario STANDARD_IMPORTS para todos los tipos de dominio scriptables.
