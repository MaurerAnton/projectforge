projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptExecutor.kt Service central / Moteur de script, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptExecutor.kt 376 lignes · 274 code · 71 commentaires · 31 vides
Classe de base abstraite pour tous les exécuteurs de script (Groovy et Kotlin). Gère la compilation de scripts à partir de la source avec résolution #INCLUDE, injection d'importations automatiques, liaison de variables (daos, appId, taskTree, caches, etc.) et gestion des paramètres de script. Construit le script effectif en fusionnant le code utilisateur avec les importations générées automatiquement et les liaisons spécifiques au langage. Contient également la méthode d'usine createScriptExecutor() qui détecte automatiquement Kotlin ou Groovy en fonction de la présence des mots-clés val/var/fun et l'ensemble compagnon STANDARD_IMPORTS pour tous les types de domaine scriptables.
