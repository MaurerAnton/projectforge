#1054: ScriptExecutor.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptExecutor.kt Основной сервис / Скриптовый движок, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptExecutor.kt 376 строк · 274 кода · 71 комментарий · 31 пустая
Абстрактный базовый класс для всех исполнителей скриптов (Groovy и Kotlin). Управляет компиляцией скриптов из исходного кода с разрешением #INCLUDE, автоматической вставкой импортов, привязкой переменных (daos, appId, taskTree, кэши и т.д.) и обработкой параметров скрипта. Формирует итоговый скрипт путём объединения пользовательского кода с автоматически сгенерированными импортами и привязками, специфичными для языка. Также содержит фабричный метод createScriptExecutor(), который автоматически определяет Kotlin или Groovy на основе наличия ключевых слов val/var/fun, и сопутствующий набор STANDARD_IMPORTS для всех скриптовых доменных типов.
