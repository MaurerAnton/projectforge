#1055: ScriptLogger.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptLogger.kt Logging-Dienstprogramm / Skript-Engine, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptLogger.kt 110 Zeilen · 66 Code · 25 Kommentare · 19 leer
Sammelt Protokollmeldungen während der Skriptausführung mit Schweregraden (FEHLER, WARNUNG, INFO, DEBUG). Jede Nachricht ist mit einem Zeitstempel versehen. Stellt error()-, warn()-, info()- und debug()-Methoden bereit, die sowohl direkte Werte als auch Lambdas akzeptieren. Die Eigenschaft hasErrors prüft auf Meldungen auf Fehlerebene. Eine interne add()-Methode verbindet Kotlin-Skript-Compiler-Diagnosen (ScriptDiagnostic.Severity) mit diesem Logger. Wird Skripten über die Variable log im ScriptExecutor zur Verfügung gestellt.
