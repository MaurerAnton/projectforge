projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptingDao.kt Generischer DAO-Wrapper / Scripting-Fassade, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptingDao.kt 88 Zeilen · 37 Code · 39 Kommentare · 12 leer
Generisches Scripting-DAO, das jedes BaseDao kapselt, um Skriptautoren eine vereinfachte API bereitzustellen. Stellt getList(filter) (Abwärtskompatibilität), select(filter), die Eigenschaft list (alle Einträge) und getById(id) zur Verfügung. Initialisiert DOs nach jeder Auswahl automatisch über PfCaches.initializeBaseDO(), um lazy-geladene Felder zu hydrieren. Die Eigenschaft dOClass gibt die Entitätsklasse frei. Ermöglicht Skripten die Interaktion mit beliebigen Domänenentitäten über eine einheitliche Schnittstelle ohne direkte BaseDao-Exposition.
