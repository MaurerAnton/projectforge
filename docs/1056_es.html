DAO de scripting genérico que envuelve cualquier BaseDao para proporcionar una API simplificada para los autores de scripts. Expone getList(filter) (compatibilidad hacia atrás), select(filter), la propiedad list (todas las entradas) y getById(id). Inicializa automáticamente los DOs mediante PfCaches.initializeBaseDO() después de cada selección para hidratar campos de carga diferida. La propiedad dOClass expone la clase de la entidad. Permite que los scripts interactúen con cualquier entidad de dominio a través de una interfaz uniforme sin exposición directa a BaseDao.
