projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptingDao.kt Wrapper DAO générique / Façade de script, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptingDao.kt 88 lignes · 37 code · 39 commentaires · 12 vides
DAO de script générique qui encapsule n'importe quel BaseDao pour fournir une API simplifiée aux auteurs de scripts. Expose getList(filter) (rétrocompatibilité), select(filter), la propriété list (toutes les entrées) et getById(id). Initialise automatiquement les DO via PfCaches.initializeBaseDO() après chaque sélection pour hydrater les champs chargés paresseusement. La propriété dOClass expose la classe d'entité. Permet aux scripts d'interagir avec n'importe quelle entité du domaine via une interface uniforme sans exposition directe à BaseDao.
