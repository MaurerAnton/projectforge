#1056: ScriptingDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptingDao.kt Универсальная обёртка DAO / Фасад для скриптов, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/ScriptingDao.kt 88 строк · 37 кода · 39 комментариев · 12 пустых
Универсальный DAO для скриптов, который оборачивает любой BaseDao, предоставляя упрощённый API для авторов скриптов. Предоставляет getList(filter) (обратная совместимость), select(filter), свойство list (все записи) и getById(id). Автоматически инициализирует DO через PfCaches.initializeBaseDO() после каждого select для гидратации лениво загружаемых полей. Свойство dOClass предоставляет класс сущности. Позволяет скриптам взаимодействовать с любой доменной сущностью через единый интерфейс без прямого доступа к BaseDao.
