#1058 : CustomScriptingHost.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/kotlin/CustomScriptingHost.kt Hôte de script Kotlin, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/kotlin/CustomScriptingHost.kt 52 lignes · 26 code · 22 commentaires · 4 vides
Étend BasicJvmScriptingHost pour injecter le contexte ThreadLocal de ProjectForge (utilisateur connecté et journaliseur de script) dans les threads d'évaluation de script Kotlin. Garantit que les scripts s'exécutent avec l'identité utilisateur correcte et ont accès au ScriptLogger via ThreadLocalScriptingContext.

Conception

La substitution de eval capture l'utilisateur connecté actuel et le journaliseur avant l'évaluation, les définit dans le stockage ThreadLocal, puis les restaure/efface dans le bloc finally. Ceci est essentiel car l'exécution de scripts Kotlin se fait dans un pool de threads séparé où le contexte de sécurité Spring normal n'est pas disponible.
