#1059: JarExtractor.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/kotlin/JarExtractor.kt Обходной путь для classpath в Fat JAR, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/kotlin/JarExtractor.kt 128 строк · 81 код · 35 комментариев · 12 пустых
Внутренний синглтон, решающий проблему classpath для скриптов Kotlin в fat JAR-файлах Spring Boot. Скрипты Kotlin не могут напрямую обращаться к классам, упакованным в fat JAR. Этот извлекатель копирует требуемые JAR-файлы (projectforge, плагины, merlin, poi) из fat JAR во временную директорию и предоставляет их как URLClassLoader для движка скриптов.

Архитектура

Обнаружение

Проверяет, начинается ли расположение исходного кода с "jar:", что указывает на выполнение из fat JAR. Если нет (например, при запуске в IDE), пропускает извлечение и использует текущий classpath.

Процесс извлечения

  1. Создаёт временную директорию ProjectForge-extracted-jar, удаляя предыдущую копию.
  2. Открывает fat JAR с помощью JarFile.
  3. Перебирает записи; для каждого .jar файла, соответствующего настроенным шаблонам регулярных выражений (projectforge-business, projectforge-common, poi, poi-ooxml, merlin-core и JAR-файлы плагинов), извлекает во временную директорию.
  4. Формирует список classpathFiles и массив classpathUrls для использования URLClassLoader.

История борьбы

История git показывает длительные попытки (коммиты de4d8d2af, 302470ef9, 7617cf5da, 31545575d) заставить скрипты Kotlin работать в fat JAR. Было опробовано несколько подходов, прежде чем остановиться на извлечении JAR.
