Objeto de utilidad interno para la ejecución de scripts Kotlin. Maneja el formateo de diagnósticos de error (con marcadores de línea de origen y filtrado por severidad), la generación de enlaces automáticos (generando declaraciones val x = context.getProperty("x") as Type) y el reemplazo de nombres de clase para primitivas Java en declaraciones de tipo Kotlin.

Funciones clave

handleResult

Itera los informes de ResultWithDiagnostics<EvaluationResult>, filtra por severidad, formatea la información de ubicación con línea/columna y fragmentos de código fuente marcados con >>>...<<<, y los registra en el logger del script. Extrae el valor de retorno mediante extractResult().

appendBlockAfterImports

Genera declaraciones de propiedades Kotlin para todas las variables y parámetros del script, insertándolas como un bloque de enlaces generado automáticamente después de las importaciones. Utiliza el mapa bindingsClassReplacements para convertir nombres de clase Java a equivalentes Kotlin (ej., java.lang.String → String). Omite variables ya presentes en el código fuente del script.

bindingsClassReplacements

Mapea: java.lang.String → String, java.lang.Integer → Int, java.lang.Boolean → Boolean, java.util.HashMap → MutableMap<*, *>.
