#1060 : KotlinScriptUtils.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/kotlin/KotlinScriptUtils.kt Utilitaires de script Kotlin, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/kotlin/KotlinScriptUtils.kt 166 lignes · 130 code · 26 commentaires · 10 vides
Objet utilitaire interne pour l'exécution de scripts Kotlin. Gère le formatage des diagnostics d'erreur (avec marqueurs de ligne source et filtrage par sévérité), la génération de liaisons automatiques (génération de déclarations val x = context.getProperty("x") as Type) et le remplacement des noms de classes pour les primitives Java dans les déclarations de types Kotlin.

Fonctions clés

handleResult

Parcourt les rapports ResultWithDiagnostics<EvaluationResult>, filtre par sévérité, formate les informations de localisation avec ligne/colonne et extraits de source marqués par >>>...<<<, et les enregistre dans le journal du script. Extrait la valeur de retour via extractResult().

appendBlockAfterImports

Génère des déclarations de propriétés Kotlin pour toutes les variables et paramètres du script, en les insérant sous forme de bloc de liaisons généré automatiquement après les imports. Utilise la table bindingsClassReplacements pour convertir les noms de classes Java en équivalents Kotlin (ex. java.lang.String → String). Ignore les variables déjà présentes dans le code source du script.

bindingsClassReplacements

Correspondances : java.lang.String → String, java.lang.Integer → Int, java.lang.Boolean → Boolean, java.util.HashMap → MutableMap<*, *>.
