#1060: KotlinScriptUtils.kt

Внутренний объект-утилита для выполнения Kotlin-скриптов. Обрабатывает форматирование диагностики ошибок (с маркерами строк исходного кода и фильтрацией по серьёзности), генерацию автоматической привязки (создание объявлений val x = context.getProperty("x") as Type) и замену имён классов для Java-примитивов в объявлениях типов Kotlin.

Ключевые функции

handleResult

Перебирает отчёты ResultWithDiagnostics<EvaluationResult>, фильтрует по серьёзности, форматирует информацию о местоположении с номером строки/столбца и фрагментами исходного кода, помеченными >>>...<<<, и записывает их в логгер скрипта. Извлекает возвращаемое значение через extractResult().

appendBlockAfterImports

Генерирует объявления свойств Kotlin для всех переменных и параметров скрипта, вставляя их как автоматически сгенерированный блок привязок после импортов. Использует карту bindingsClassReplacements для преобразования имён классов Java в эквиваленты Kotlin (например, java.lang.String → String). Пропускает переменные, уже присутствующие в исходном коде скрипта.

bindingsClassReplacements

Соответствия: java.lang.String → String, java.lang.Integer → Int, java.lang.Boolean → Boolean, java.util.HashMap → MutableMap<*, *>.
