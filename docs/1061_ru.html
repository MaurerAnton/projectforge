#1061: AccountingRecord.kt

projectforge-business/src/main/kotlin/org/projectforge/business/scripting/support/AccountingRecord.kt Помощник агрегации данных / Поддержка скриптов, projectforge-business/src/main/kotlin/org/projectforge/business/scripting/support/AccountingRecord.kt 188 строк · 145 кода · 28 комментариев · 15 пустых
Финансовый помощник агрегации для отчётности на основе скриптов. Содержит доходы и расходы по проекту/клиенту/бизнес-единице с датой. Поддерживает три типа записей: RECORD (общая проводка), INVOICE и TIMESHEET. Вычисляет производные значения: profit (доход + расходы, где расходы отрицательны) и percentage. Фабричные методы компаньона создают записи из BuchungssatzDO (бухгалтерские проводки), RechnungDO (счета) и TimesheetDO (табели с почасовой ставкой). Предоставляет статическую агрегацию: groupByProject() фильтрует по диапазону дат и суммирует по проекту, groupByMonth() группирует по AccountingRecordMonthKey.
