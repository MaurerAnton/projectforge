projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateConfiguration.kt Spring-Konfiguration / Sipgate-Integration, projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateConfiguration.kt 91 Zeilen · 29 Code · 51 Kommentare · 11 leer
Spring @Configuration-Klasse, die Sipgate-API-Einstellungen aus application.properties bindet. Felder: baseUri, tokenId, token (Authentifizierung), defaultDevice (für Anrufe), basePhoneNumber und boolesche Flags: updateLocalAddresses, updateSipgateContacts, cronActive. Erforderliche Berechtigungen sind inline dokumentiert (contacts:read/write, devices:read, sessions:calls:write, usw.). Die Methode isConfigured() prüft, ob baseUri, token und tokenId alle nicht leer sind.
