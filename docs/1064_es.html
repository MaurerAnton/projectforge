Clase Spring @Configuration que vincula la configuración de la API de Sipgate desde application.properties. Campos: baseUri, tokenId, token (autenticación), defaultDevice (para llamadas), basePhoneNumber, y banderas booleanas: updateLocalAddresses, updateSipgateContacts, cronActive. Los alcances requeridos están documentados en línea (contacts:read/write, devices:read, sessions:calls:write, etc.). El método isConfigured() valida que baseUri, token y tokenId no estén en blanco.
