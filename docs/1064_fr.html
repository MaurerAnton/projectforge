projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateConfiguration.kt Configuration Spring / Intégration Sipgate, projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateConfiguration.kt 91 lignes · 29 code · 51 commentaires · 11 vides
Classe Spring @Configuration liant les paramètres de l'API Sipgate depuis application.properties. Champs : baseUri, tokenId, token (authentification), defaultDevice (pour les appels), basePhoneNumber, et les indicateurs booléens : updateLocalAddresses, updateSipgateContacts, cronActive. Les scopes requis sont documentés en ligne (contacts:read/write, devices:read, sessions:calls:write, etc.). La méthode isConfigured() valide que baseUri, token et tokenId ne sont pas vides.
