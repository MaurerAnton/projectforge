projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateConfiguration.kt Spring Конфигурация / Интеграция Sipgate, projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateConfiguration.kt 91 строка · 29 кода · 51 комментарий · 11 пустых
Класс Spring @Configuration, связывающий настройки API Sipgate из application.properties. Поля: baseUri, tokenId, token (аутентификация), defaultDevice (для звонков), basePhoneNumber и логические флаги: updateLocalAddresses, updateSipgateContacts, cronActive. Требуемые области доступа задокументированы в коде (contacts:read/write, devices:read, sessions:calls:write и т.д.). Метод isConfigured() проверяет, что baseUri, token и tokenId не пусты.
