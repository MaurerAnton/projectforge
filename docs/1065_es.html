projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateContact.kt Objeto de transferencia de datos / Integración Sipgate, projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateContact.kt 357 líneas · 268 código · 43 comentarios · 46 en blanco
DTO enriquecido para contactos de Sipgate con mapeo JSON de Jackson, incluyendo clases anidadas Address, Email y Number. Utiliza @JsonIgnore/@JsonProperty para puentear el sistema de tipos basado en arrays de Sipgate (ej. organización como array-de-arrays, tipos de número como arrays de cadenas) a propiedades convenientes de Kotlin. Proporciona accesores calculados (work, home, cell, faxWork, email, privateEmail) que buscan en las listas de números/correos por tipo. fixNumbers() y fixEmails() deduplican entradas. El companion de Number define arrays de tipos estándar (WORK_ARRAY, CELL_ARRAY, FAX_WORK_ARRAY, etc.) para comparación de tipos.
