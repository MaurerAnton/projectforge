projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateContact.kt Objet de transfert de données / Intégration Sipgate, projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateContact.kt 357 lignes · 268 code · 43 commentaires · 46 vides
DTO riche pour les contacts Sipgate avec mappage JSON Jackson, incluant les classes imbriquées Address, Email et Number. Utilise @JsonIgnore/@JsonProperty pour faire le pont entre le système de types basé sur les tableaux de Sipgate (ex. organisation sous forme de tableau de tableaux, types de numéros sous forme de tableaux de chaînes) et les propriétés pratiques de Kotlin. Fournit des accesseurs calculés (work, home, cell, faxWork, email, privateEmail) qui parcourent les listes de numéros/e-mails par type. fixNumbers() et fixEmails() dédupliquent les entrées. Le compagnon Number définit des tableaux de types standard (WORK_ARRAY, CELL_ARRAY, FAX_WORK_ARRAY, etc.) pour la comparaison de types.
