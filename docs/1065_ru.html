#1065: SipgateContact.kt

projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateContact.kt Объект передачи данных / Интеграция Sipgate, projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateContact.kt 357 строк · 268 кода · 43 комментария · 46 пустых
Богатый DTO для контактов Sipgate с маппингом JSON Jackson, включая вложенные классы Address, Email и Number. Использует @JsonIgnore/@JsonProperty для преобразования массивной системы типов Sipgate (например, организация как массив массивов, типы номеров как строковые массивы) в удобные свойства Kotlin. Предоставляет вычисляемые аксессоры (work, home, cell, faxWork, email, privateEmail), которые ищут в списках номеров/email по типу. fixNumbers() и fixEmails() удаляют дубликаты. Компаньон Number определяет стандартные массивы типов (WORK_ARRAY, CELL_ARRAY, FAX_WORK_ARRAY и т.д.) для сравнения типов.
