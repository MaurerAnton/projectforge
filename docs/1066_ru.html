#1066: SipgateContactSyncDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateContactSyncDO.kt JPA-сущность / Интеграция Sipgate, projectforge-business/src/main/kotlin/org/projectforge/business/sipgate/SipgateContactSyncDO.kt 247 строк · 175 кода · 45 комментариев · 27 пустых
JPA-сущность, отображающая состояние синхронизации между удалёнными контактами Sipgate и локальными записями AddressDO. Хранится в таблице T_SIPGATE_CONTACT_SYNC с уникальными ограничениями на sipgate_contact_id и address_id. Отслеживает перечисление RemoteStatus (OK, CREATED_BY_LOCAL, CREATED_BY_REMOTE, DELETED_BY_LOCAL), временную метку lastSync и JSON-хэш-карту SyncInfo для обнаружения изменений на уровне полей. SyncInfo хэширует значения полей ContactDO и адресных полей, игнорируя текстовые поля адреса (слишком сложны для синхронизации). Именованные запросы поддерживают удаление по адресу, поиск по адресу, поиск по контакту или адресу и загрузку всех записей. Методы readJson()/updateJson() сериализуют/десериализуют SyncInfo из/в JSON-столбец.
