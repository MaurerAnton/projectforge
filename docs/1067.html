1067: SystemInfoCache.kt

Cache / System Service, projectforge-business/src/main/kotlin/org/projectforge/business/system/SystemInfoCache.kt
Spring @Component extending AbstractCache that determines whether fundamental business entities exist in the database. Checks for customer (KundeDO), project (ProjektDO), and cost2 (Kost2DO) entries via COUNT queries. Used by the system to determine if the instance is "ready" (has been configured with initial data). Singleton access pattern with static instance() method and internalInitialize() for startup wiring.
