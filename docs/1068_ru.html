DTO, представляющий устройство Sipgate с идентификатором, псевдонимом, типом, статусом онлайн/не беспокоить. Содержит вложенные классы: ActiveRouting (для активных телефонных линий/групп) и Credentials (SIM/PUK). Метод deleteSecrets() скрывает значения PUK для безопасного логирования. ActivePhonelines и ActiveGroups ссылаются на информацию о маршрутизации.
