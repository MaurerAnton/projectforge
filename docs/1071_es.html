DTO para datos de usuario de Sipgate. Campos: id, nombre, apellido, email, dispositivoPredeterminado, ocupadoSiOcupado, idDirección, zonaHoraria, indicador de administrador y directDialIds (lista de ids de SipgateNumber). Propiedad calculada nombreCompleto que concatena nombre y apellido. Se utiliza para la sincronización de usuarios entre ProjectForge y Sipgate.
