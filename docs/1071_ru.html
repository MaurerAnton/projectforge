DTO для данных пользователя Sipgate. Поля: id, имя, фамилия, email, defaultDevice, busyOnBusy, addressId, часовой пояс, флаг admin и directDialIds (список идентификаторов SipgateNumber). Вычисляемое свойство fullname объединяет имя и фамилию. Используется для синхронизации пользователей между ProjectForge и Sipgate.
