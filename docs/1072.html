1072: TaskDao.kt

DAO / Task Management, projectforge-business/src/main/kotlin/org/projectforge/business/task/TaskDao.kt
Core DAO for task management extending BaseDao<TaskDO>. Implements complex access control logic: tasks have hierarchical permissions via hasUpdateAccess() (checks cyclic references, admin/finance group membership, and parent task insert/delete permissions) and hasInsertAccess() (validates parent task existence). Field-level access control via checkInsertAccess()/checkUpdateAccess() restricts kost2BlackWhiteList and timesheetBookingStatus changes to project managers. onInsertOrModify() (synchronized) checks constraint violations and cyclic references under lock. Reads total timesheet durations via database interval functions or manual aggregation. select() filters by TaskStatus (N, O, C) using TaskFilter. copyValues() handles nullable priority and responsibleUser fields. wantsReindexAllDependentObjects() only triggers reindexing on title changes.
