Spring @Service que proporciona rutinas de administración a nivel de sistema. exportSchema() genera SQL del esquema de base de datos mediante SchemaExport, restringido al grupo de administradores. checkSystemIntegrity() delega en CronSanityCheckJob para tareas abandonadas, comprobaciones de JCR/DataTransfer corruptos y escribe los resultados en el cuadro de transferencia de datos del usuario (se ejecuta en un hilo separado para evitar bloqueos). refreshCaches() recarga forzosamente todos los cachés principales: UserGroupCache, TaskTree, KontoCache, KostCache, RechnungCache, AuftragsCache, AuftragsRechnungCache, SystemInfoCache y BirthdayCache. Devuelve HTML formateado para los resultados de integridad del sistema.
