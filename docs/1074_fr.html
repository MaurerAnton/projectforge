projectforge-business/src/main/kotlin/org/projectforge/business/system/SystemService.kt Service / Administration système, projectforge-business/src/main/kotlin/org/projectforge/business/system/SystemService.kt 185 lignes · 131 code · 36 commentaires · 18 vides
Spring @Service fournissant des routines d'administration au niveau système. exportSchema() génère le SQL du schéma de base de données via SchemaExport, restreint au groupe admin. checkSystemIntegrity() délègue à CronSanityCheckJob pour les tâches abandonnées, les vérifications JCR/DataTransfer corrompus, et écrit les résultats dans la boîte de transfert de données de l'utilisateur (s'exécute dans un thread séparé pour éviter le blocage). refreshCaches() recharge de force tous les caches principaux : UserGroupCache, TaskTree, KontoCache, KostCache, RechnungCache, AuftragsCache, AuftragsRechnungCache, SystemInfoCache et BirthdayCache. Retourne du HTML formaté pour les résultats d'intégrité système.
