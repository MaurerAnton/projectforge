projectforge-business/src/main/kotlin/org/projectforge/business/system/SystemService.kt Сервис / Системное администрирование, projectforge-business/src/main/kotlin/org/projectforge/business/system/SystemService.kt 185 строк · 131 код · 36 комментариев · 18 пустых
Spring @Service, предоставляющий процедуры системного администрирования. exportSchema() генерирует SQL схемы базы данных через SchemaExport, доступ ограничен группой администраторов. checkSystemIntegrity() делегирует выполнение CronSanityCheckJob для проверки заброшенных задач, повреждённых JCR/DataTransfer, и записывает результаты в папку передачи данных пользователя (выполняется в отдельном потоке во избежание блокировок). refreshCaches() принудительно перезагружает все основные кэши: UserGroupCache, TaskTree, KontoCache, KostCache, RechnungCache, AuftragsCache, AuftragsRechnungCache, SystemInfoCache и BirthdayCache. Возвращает отформатированный HTML с результатами проверки целостности системы.
