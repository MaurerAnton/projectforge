Мост Hibernate Search TypeBridge для индексации информации о пути задачи. Во время записи он определяет узел задачи из TaskTree.instance, обходит путь до корня и формирует строку, разделённую вертикальной чертой, из заголовков родительских задач. Результирующее поле индекса ("taskpath") обеспечивает полнотекстовый поиск по иерархии задач (например, поиск задачи по заголовку любого предка).
