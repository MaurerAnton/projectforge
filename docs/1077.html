1077: HibernateSearchUsersGroupsBridge.kt

Hibernate Search Bridge / TeamCal Indexing, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/admin/model/HibernateSearchUsersGroupsBridge.kt
Hibernate Search TypeBridge for indexing user/group access rights on BaseUserGroupRightsDO entities (TeamCalDO, etc.). At write time, it resolves all group IDs and user IDs from the entity's fullAccess/readonlyAccess/minimalAccess fields (CSV strings), looks them up in UserGroupCache, sorts by name via custom comparators, and concatenates into a pipe-delimited "usersgroups" index field. Skips HSQL dialect. Enables full-text search for calendars by associated users and groups.
