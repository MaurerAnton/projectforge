projectforge-business/src/main/kotlin/org/projectforge/business/task/ScriptingTaskTree.kt Scripting-Proxy / Aufgabenbaum, projectforge-business/src/main/kotlin/org/projectforge/business/task/ScriptingTaskTree.kt 192 Zeilen · 126 Code · 42 Kommentare · 24 leer
Skriptsicherer Proxy, der TaskTree für die Skriptausführung kapselt. Konvertiert interne TaskNode-Objekte in ScriptingTaskNode-Wrapper, die versehentliche Änderungen verhindern. Bietet: Pfadnavigation (getPath(), getPathToRoot()), Aufgabensuche per ID, matchesMarker() zum Durchsuchen von Aufgaben/Unteraufgaben nach Text in Titel/Beschreibung/Referenz, filterTimesheets() zum Filtern von Zeiterfassungen nach Marker-übereinstimmenden Aufgaben, Projektsuche, Positionsprüfungen und Personentage-Berechnungen. Für Skripte als Variable taskTree verfügbar. Enthält die innere Klasse FilteredTimesheets zur Ergebnisgruppierung.
