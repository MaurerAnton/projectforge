#1077: ScriptingTaskTree.kt

projectforge-business/src/main/kotlin/org/projectforge/business/task/ScriptingTaskTree.kt Прокси для скриптов / Дерево задач, projectforge-business/src/main/kotlin/org/projectforge/business/task/ScriptingTaskTree.kt 192 строки · 126 кода · 42 комментария · 24 пустых
Безопасный прокси для скриптов, оборачивающий TaskTree для выполнения скриптов. Преобразует внутренние объекты TaskNode в обёртки ScriptingTaskNode, предотвращающие случайные изменения. Предоставляет: навигацию по пути (getPath(), getPathToRoot()), поиск задачи по идентификатору, matchesMarker() для поиска задач/подзадач по тексту в названии/описании/ссылке, filterTimesheets() для фильтрации табелей по задачам, соответствующим маркеру, поиск проекта, проверку позиции в порядке и расчёт человеко-дней. Доступен скриптам как переменная taskTree. Включает внутренний класс FilteredTimesheets для группировки результатов.
