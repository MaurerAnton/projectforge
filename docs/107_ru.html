Создание начальной схемы для основной таблицы плагина DataTransfer t_plugin_datatransfer_area. Это базовая миграция в init/common/ — переопределения, зависящие от диалекта, находятся в подкаталогах init/{vendor}/ (например, типы индексов для PostgreSQL, движки хранения MySQL).

Ограничения и индексы

  • t_plugin_datatransfer_area_pkey — первичный ключ по pk
  • idx_fk_t_plugin_datatransfer_area_tenant_id — индекс по tenant_id для мультиарендных запросов
  • t_plugin_datatransfer_fk_tenant — внешний ключ tenant_id → t_tenant(pk)

Примечание: В этой таблице хранятся сериализованные списки ID (admin_ids, access_group_ids, access_user_ids) в виде VARCHAR через запятую, а не в виде таблиц связей — дизайнерское решение для простоты, типичное для ранних схем плагинов ProjectForge. Поле external_access_logs хранит журнал аудита как сырой JSON/строку в одном столбце, а не в нормализованной таблице аудита.
