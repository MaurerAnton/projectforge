Path: plugins/...datatransfer/src/main/resources/flyway/datatransfer/migrate/hsqldb/V1.1.0__RELEASE-RemoveMGC.sql · Lines: 6 · Type: Flyway migration — HSQLDB dialect

HSQLDB migration v1.1.0 — part of the RemoveMGC (remove Micromata GmbH & Co. KG references) release. Widens primary key and foreign key columns from INTEGER to BIGINT.

Columns migrated:

  • t_plugin_datatransfer_area.pk → BIGINT
  • t_plugin_datatransfer_audit.pk → BIGINT
  • t_plugin_datatransfer_audit.area_fk → BIGINT
  • t_plugin_datatransfer_audit.by_user_fk → BIGINT
  • t_plugin_datatransfer_audit.upload_by_user_fk → BIGINT

Uses HSQLDB ALTER COLUMN ... bigint syntax. PostgreSQL variant requires ALTER COLUMN ... TYPE bigint. The BIGINT migration was a system-wide change — all plugins and core tables migrated simultaneously to support larger ID ranges after the company rebranding.
