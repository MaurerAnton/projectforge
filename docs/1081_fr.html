#1081 : TaskFavoritesService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/task/TaskFavoritesService.kt Service / Favoris, projectforge-business/src/main/kotlin/org/projectforge/business/task/TaskFavoritesService.kt 75 lignes · 43 code · 22 commentaires · 10 vides
Composant Spring @Component gérant les favoris de tâches spécifiques à l'utilisateur via UserPrefDao. Utilise le stockage UserPref hérité (zone "TASK_FAVORITE", paramètre "task"). getList() renvoie les éléments TaskFavorite à partir des préférences utilisateur, selectTaskId() récupère le taskId stocké pour un favori, createFavorite()/deleteFavorite()/renameFavorite() utilisent l'assistant Favorites pour gérer les entrées. TaskId est stocké sous forme de chaîne et analysé à nouveau lors de la récupération.
