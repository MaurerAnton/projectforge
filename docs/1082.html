1082: CalendarHelper.kt

Utility / Calendar Display, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/CalendarHelper.kt
Static utility object for formatting timesheet information for calendar display. getTitle() builds a display title from a timesheet: if kost2 is set, uses project identifier or name; otherwise abbreviates the task title to 60 chars. getDescription() combines the timesheet's location and short description separated by newline, each abbreviated to 60 chars. Uses PfCaches to initialize lazy fields before access.
