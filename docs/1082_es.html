Utilidad estática para formatear rutas de tareas y estados. getTaskPath() construye rutas estilo "tarea1 -> tarea2 -> tarea3" a partir de un id de tarea, opcionalmente hasta un ancestro específico, con modos de salida HTML/XML/PLAIN y una función de abreviatura (extrae las primeras letras para compactar). getFormattedTaskStatus() renderiza TaskStatus como un span HTML con clases CSS. El ayudante privado asShortForm() comprime elementos de arreglo a secuencias de primeras letras cuando la longitud total excede el límite. Extiende AbstractFormatter para acceso i18n.
