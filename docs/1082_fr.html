projectforge-business/src/main/kotlin/org/projectforge/business/task/TaskFormatter.kt Utilitaire de formatage / Affichage des tâches, projectforge-business/src/main/kotlin/org/projectforge/business/task/TaskFormatter.kt 156 lignes · 107 code · 41 commentaires · 8 vides
Utilitaire statique pour formater les chemins et statuts des tâches. getTaskPath() construit des chemins de style "tâche1 -> tâche2 -> tâche3" à partir d'un identifiant de tâche, éventuellement jusqu'à un ancêtre spécifique, avec des modes de sortie HTML/XML/PLAIN et une fonction d'abréviation (extraction des premières lettres pour compaction). getFormattedTaskStatus() affiche TaskStatus sous forme de span HTML avec classes CSS. L'assistant privé asShortForm() compresse les éléments d'un tableau en séquences de premières lettres lorsque la longueur totale dépasse la limite. Étend AbstractFormatter pour l'accès i18n.
