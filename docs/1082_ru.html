#1082: TaskFormatter.kt

projectforge-business/src/main/kotlin/org/projectforge/business/task/TaskFormatter.kt Утилита форматирования / Отображение задач, projectforge-business/src/main/kotlin/org/projectforge/business/task/TaskFormatter.kt 156 строк · 107 кода · 41 комментарий · 8 пустых
Статическая утилита для форматирования путей задач и статусов. getTaskPath() строит пути вида "задача1 -> задача2 -> задача3" на основе идентификатора задачи, опционально до конкретного предка, с режимами вывода HTML/XML/PLAIN и функцией сокращения (извлекает первые буквы для компактности). getFormattedTaskStatus() отображает TaskStatus как HTML-элемент span с CSS-классами. Приватный помощник asShortForm() сжимает элементы массива до последовательностей из первых букв, когда общая длина превышает лимит. Расширяет AbstractFormatter для доступа к i18n.
