projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/admin/TeamCalDao.kt DAO / Team-Kalender, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/admin/TeamCalDao.kt 199 Zeilen · 135 Code · 45 Kommentare · 19 Leer
DAO für TeamCalDO, erweitert BaseDao. Zugriffsgesteuertes select() filtert Kalender nach Besitzer-Typ (Alle/Eigene/Andere), Zugriffsstufe (Vollzugriff/Lesezugriff/Minimalzugriff) und Admin-Flag. Verwendet TeamCalRight für Besitzerprüfungen. onInsertOrModify() erzwingt ein minimales Aktualisierungsintervall von 15 Minuten für Abonnements. afterInsert()/afterUpdate() verwalten den TeamEventExternalSubscriptionCache: Aktualisierung zwischengespeicherter Abonnements, Löschen von Binär-/URL-/Hash-Werten, wenn das externe Abonnement deaktiviert ist. Die Eigenschaft allCalendarsWithFullAccess gibt Kalender zurück, auf die der angemeldete Benutzer vollen Zugriff hat. Passt die Formatierung der Historie über HistoryFormatUtils an. Die Suche umfasst Besitzer- und Benutzergruppenfelder.
