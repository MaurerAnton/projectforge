#1085: TeamCalDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/admin/TeamCalDao.kt DAO / Командный календарь, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/admin/TeamCalDao.kt 199 строк · 135 кода · 45 комментариев · 19 пустых
DAO для TeamCalDO, расширяющий BaseDao. Контролируемый доступом select() фильтрует календари по типу владельца (Все/Свои/Другие), уровню доступа (Полный доступ/Только чтение/Минимальный доступ) и флагу только для администраторов. Использует TeamCalRight для проверок владения. onInsertOrModify() обеспечивает минимальный интервал обновления подписки в 15 минут. afterInsert()/afterUpdate() управляют TeamEventExternalSubscriptionCache: обновление кэшированных подписок, очистка binary/url/hash при отключении внешней подписки. Свойство allCalendarsWithFullAccess возвращает календари, к которым у текущего пользователя есть полный доступ. Настраивает форматирование отображения истории через HistoryFormatUtils. Поиск включает поля владельцев и групп пользователей.
