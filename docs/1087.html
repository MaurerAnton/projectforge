1087: TeamEventRecurrenceData.kt

Data Model / Calendar Recurrence, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/TeamEventRecurrenceData.kt
Serializable data class capturing all recurrence configuration for a calendar event. Fields: frequency (NONE/DAILY/WEEKLY/MONTHLY/YEARLY), interval, until date, untilDays. Weekly mode stores day-of-week flags in BooleanArray(7), monthly mode has day-of-month flags BooleanArray(31) and mode selection (EACH specific days vs. ATTHE nth weekday), yearly mode has month flags BooleanArray(12) and optional yearMode with weekday-of-month specification. Mode enums: RecurrenceFrequencyModeOne (FIRST/SECOND/THIRD/FOURTH/LAST), RecurrenceFrequencyModeTwo (MONDAY-SUNDAY, DAY/WEEKEND_DAY), RecurrenceMonthMode (NONE/EACH/ATTHE). The isCustomized flag auto-computes true when interval > 1. Used as the DTO between UI, DAO, and iCal RRULE generation.
