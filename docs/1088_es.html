Entidad JPA para calendarios de equipo (tabla T_CALENDAR), que extiende BaseUserGroupRightsDO para control de acceso por grupo/usuario. Características: título, propietario (PFUserDO, lazy), descripción, includeLeaveDaysForUsers/groups (IDs CSV de usuario/grupo para visualización de vacaciones), soporte de suscripción externa (externalSubscription booleano, externalSubscriptionUrl, externalSubscriptionUpdateInterval, externalSubscriptionCalendarBinary como BLOB lazy, externalSubscriptionHash para detección de cambios). La propiedad calculada externalSubscriptionUrlAnonymized acorta URLs para registro. Indexado con Hibernate Search mediante @TypeBinding para el puente de usuarios/grupos. La fábrica @JsonCreator de Jackson permite la deserialización desde un ID Long.
