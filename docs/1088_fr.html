Entité JPA pour les calendriers d'équipe (table T_CALENDAR), étendant BaseUserGroupRightsDO pour le contrôle d'accès par groupe/utilisateur. Fonctionnalités : titre, propriétaire (PFUserDO, lazy), description, includeLeaveDaysForUsers/groups (identifiants CSV d'utilisateurs/groupes pour l'affichage des congés), support d'abonnement externe (externalSubscription booléen, externalSubscriptionUrl, externalSubscriptionUpdateInterval, externalSubscriptionCalendarBinary en BLOB lazy, externalSubscriptionHash pour la détection de changements). La propriété calculée externalSubscriptionUrlAnonymized raccourcit les URL pour la journalisation. Indexé par Hibernate Search avec @TypeBinding pour le pont usersgroups. La fabrique Jackson @JsonCreator permet la désérialisation à partir d'un identifiant Long.
