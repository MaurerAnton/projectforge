JPA сущность для командных календарей (таблица T_CALENDAR), расширяющая BaseUserGroupRightsDO для контроля доступа групп/пользователей. Особенности: заголовок, владелец (PFUserDO, ленивая загрузка), описание, includeLeaveDaysForUsers/groups (CSV идентификаторы пользователей/групп для отображения отпусков), поддержка внешних подписок (externalSubscription boolean, externalSubscriptionUrl, externalSubscriptionUpdateInterval, externalSubscriptionCalendarBinary как ленивый BLOB, externalSubscriptionHash для обнаружения изменений). Вычисляемое свойство externalSubscriptionUrlAnonymized сокращает URL для логирования. Индексировано Hibernate Search с @TypeBinding для моста usersgroups. Фабрика Jackson @JsonCreator обеспечивает десериализацию из Long id.
