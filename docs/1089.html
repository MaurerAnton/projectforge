1089: ICalGenerator.kt

Generator / iCal Export, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/ical/ICalGenerator.kt
Generates iCal (.ics) data from TeamEventDO and ICalendarEvent objects using ical4j. Builds a Calendar object with PRODID identifying ProjectForge version. Methods: add(event) converts events to VEvent using VEventUtils, addAllDayEvent() and addEvent() create simple events directly. add(events: List) batch-adds. Output as byte array via asByteArray (uses CalendarOutputter), as stream via writeToOutputStream(), or as string via asString. ensureNotEmpty() adds a setup event if calendar is empty. Constructor accepts exportVAlarms and editable flags.
