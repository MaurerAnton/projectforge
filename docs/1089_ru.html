#1089: TeamEventDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/TeamEventDao.kt DAO / Событие командного календаря, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/TeamEventDao.kt 770 строк · 583 кода · 131 комментарий · 56 пустых
Сложный DAO для TeamEventDO, расширяющий BaseDao с обширной логикой управления событиями. getEventList() — основной метод запроса: обрабатывает повторяющиеся события, разворачивая повторяющиеся экземпляры через rollOutRecurrenceEvents(), объединяя внешние события подписки из TeamEventExternalSubscriptionCache. Поддерживает фильтрацию по идентификаторам календарей, диапазонам дат (расширенным на один день для всемирных событий UTC). handleSeriesUpdates() реализует модификацию серий RRULE: ALL (изменить всю серию), FUTURE (разделить: сократить UNTIL мастера, вставить новое событие), SINGLE (добавить EXDATE к мастеру, вставить новое событие). markAsDeleted() зеркально отражает это для удалений. onInsert() устанавливает владельца, dtStamp и генерирует UID. onInsertOrModify() проверяет нормализацию полуночи для всемирных событий и минимальную продолжительность в 60 секунд. onUpdate() отслеживает изменения напоминаний и автоматически увеличивает последовательность при обнаружении значимых изменений полей. removeAttendeeByAddressIdFromAllEvents() для принудительной очистки при удалении адреса. Предоставляет автозаполнение местоположения.
