Crée la table de journal d'audit t_plugin_datatransfer_audit — ajoute le suivi des activités et la prise en charge des notifications par e-mail au plugin DataTransfer. Située dans migrate/common/, elle s'exécute donc sur tous les fournisseurs de bases de données sans variantes dialectales spécifiques.

Table t_plugin_datatransfer_audit — 13 colonnes

Conception : enregistre chaque opération sur fichier (téléversement, téléchargement, renommage, suppression) dans une zone de transfert de données. Fait la distinction entre les utilisateurs internes (by_user_fk → t_pf_user) et externes (by_external_user VARCHAR(4000) — stocke le nom/email/IP en texte libre).

pkINTEGER PKClé primaire
timestampTIMESTAMPMoment où l'événement s'est produit
area_fkINTEGER (indexé)FK → t_plugin_datatransfer_area
upload_by_user_fkINTEGERFK du téléverseur d'origine — persiste lorsque le fichier est téléchargé ultérieurement par un autre utilisateur
by_user_fkINTEGERQui a effectué cette action (utilisateur interne)
by_external_userVARCHAR(4000)Informations sur l'utilisateur externe (IP + nom/email facultatif depuis l'écran de connexion)
filename / filename_oldVARCHAR(1000)Nouveau et ancien nom de fichier (pour le suivi des renommages)
event_typeVARCHAR(20)Type d'action (UPLOAD, DOWNLOAD, DELETE, RENAME, etc.)
description / description_oldVARCHAR(4000)Nouvelle et ancienne description (pour le suivi des modifications)
notifiedBOOLEAN NOT NULLIndique si les observateurs ont été informés par e-mail de cet événement — évite les notifications en double

Index

  • idx_t_plugin_datatransfer_audit — sur area_fk — optimise les requêtes « afficher tous les événements pour la zone X » utilisées par l'interface Afficher les activités et la tâche de notification des observateurs

Le journal d'audit est consommé par : la boîte de dialogue d'affichage des activités (DataTransferPublicServicesRest), la tâche planifiée de notification par e-mail des observateurs (interroge les événements avec notified=false), et l'affichage glissant sur 30 jours (les anciennes entrées sont purgées).
