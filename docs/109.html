PostgreSQL variant of the same v1.0.1 migration as the HSQLDB version. Three schema changes on t_plugin_datatransfer_area:

  1. RENAME COLUMN attachments_size TO attachments_counter
  2. ADD COLUMN attachments_size BIGINT
  3. ADD COLUMN observer_ids VARCHAR(4000)

Key difference: PostgreSQL uses RENAME COLUMN ... TO ... while HSQLDB uses ALTER COLUMN ... RENAME TO .... This is why ProjectForge maintains per-vendor migration scripts — each dialect has subtly different DDL syntax.
