JPA-Entität für Ereignisteilnehmer (Tabelle T_PLUGIN_CALENDAR_EVENT_ATTENDEE), erweitert DefaultBaseDO. Ein Teilnehmer kann entweder ein ProjectForge-Benutzer (über Benutzer-FK), ein Adressbuchkontakt (über Adress-FK) oder eine externe URL (mailto-Link) sein. Felder: number (Reihenfolge), url, Adress-/Benutzerbeziehungen, loginToken, status (TeamEventAttendeeStatus-Enum), comment/commentOfAttendee, commonName, cuType, rsvp, role, additionalParams. Berechnete Eigenschaften: eMailAddress wird aus Adresse oder Benutzer aufgelöst. clone() erstellt getrennte Kopien. Implementiert Comparable nach id oder toString. Verfügt über eine benannte Abfrage zum Massenlöschen von Teilnehmern nach addressId. Equals/hashCode sind aus technischen Gründen absichtlich fehlerhaft – vergleicht nach url, addressId, userId oder id.
