Entidad JPA para asistentes a eventos (tabla T_PLUGIN_CALENDAR_EVENT_ATTENDEE), que extiende DefaultBaseDO. Un asistente puede ser un usuario de ProjectForge (mediante FK de usuario), un contacto de la libreta de direcciones (mediante FK de dirección) o una URL externa (enlace mailto). Campos: number (orden), url, relaciones address/user, loginToken, status (enum TeamEventAttendeeStatus), comment/commentOfAttendee, commonName, cuType, rsvp, role, additionalParams. Propiedades computadas: eMailAddress se resuelve desde la dirección o el usuario. clone() crea copias separadas. Implementa Comparable por id o toString. Tiene consulta nombrada para eliminar en masa asistentes por addressId. Equals/hashCode están intencionalmente rotos por requisitos técnicos — compara por url, addressId, userId o id.
