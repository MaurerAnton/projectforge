JPA сущность для участников событий (таблица T_PLUGIN_CALENDAR_EVENT_ATTENDEE), расширяющая DefaultBaseDO. Участник может быть либо пользователем ProjectForge (через внешний ключ пользователя), либо контактом из адресной книги (через внешний ключ адреса), либо внешним URL (ссылка mailto). Поля: number (порядок), url, связи адреса/пользователя, loginToken, статус (перечисление TeamEventAttendeeStatus), comment/commentOfAttendee, commonName, cuType, rsvp, роль, additionalParams. Вычисляемые свойства: eMailAddress определяется из адреса или пользователя. clone() создаёт отсоединённые копии. Реализует Comparable по id или toString. Имеет именованный запрос для массового удаления участников по addressId. Equals/hashCode намеренно нарушены по техническим требованиям — сравниваются по url, addressId, userId или id.
