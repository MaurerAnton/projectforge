projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/model/TeamEventDO.kt JPA-Entität / Team-Kalender-Ereignis, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/model/TeamEventDO.kt 1005 Zeilen · 753 Code · 166 Kommentare · 86 leer
Zentrale JPA-Entität für Kalenderereignisse (Tabelle T_PLUGIN_CALENDAR_EVENT), implementiert ICalendarEvent und Cloneable. Umfassendes iCal-kompatibles Ereignis mit: Betreff, Ort, allDay-Flag, startDate/endDate (Datum in UTC), dtStamp, Kalender-FK, originalIcsEntry (bewahrt noch nicht unterstützte iCal-Eigenschaften), Wiederholungsunterstützung (recurrenceRule als RRULE-String, recurrenceExDate als CSV, recurrenceUntil, recurrenceReferenceDate/Id), Notiz/Beschreibung, Teilnehmer (transientes Set von TeamEventAttendeeDO), Organisator mit zusätzlichen Parametern, Sequenz (für iCal-Updates), UID, Erinnerungen (Dauer, Einheit, Aktionstyp), Anhänge (transientes Set). Wiederholungsmethoden: setRecurrence(rRule), setRecurrence(data) erstellt Recur aus TeamEventRecurrenceData mit vollständiger Unterstützung für wöchentliche/monatliche/jährliche Muster, getRecurrenceData() kehrt zu Datenobjekt zurück, addRecurrenceExDate() fügt Ausschlussdaten hinzu. clearFields() schwärzt sensible Daten für Betrachter mit minimalem Zugriff. mustIncSequence() prüft, ob sich ein Feld geändert hat, das eine Sequenzerhöhung erfordert. Eindeutige Einschränkung auf (uid, calendar_fk).
