projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/model/TeamEventDO.kt JPA-сущность / Событие командного календаря, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/model/TeamEventDO.kt 1005 строк · 753 кода · 166 комментариев · 86 пустых
Основная JPA-сущность для событий календаря (таблица T_PLUGIN_CALENDAR_EVENT), реализующая ICalendarEvent и Cloneable. Комплексное iCal-совместимое событие с: темой, местоположением, флагом allDay, startDate/endDate (Date в UTC), dtStamp, внешним ключом календаря, originalIcsEntry (сохраняет неподдерживаемые iCal-свойства), поддержкой повторений (recurrenceRule как строка RRULE, recurrenceExDate как CSV, recurrenceUntil, recurrenceReferenceDate/Id), заметкой/описанием, участниками (временный набор TeamEventAttendeeDO), организатором с дополнительными параметрами, sequence (для iCal-обновлений), UID, напоминаниями (длительность, единица, тип действия), вложениями (временный набор). Методы повторений: setRecurrence(rRule), setRecurrence(data) строит Recur из TeamEventRecurrenceData с полной поддержкой еженедельных/ежемесячных/ежегодных шаблонов, getRecurrenceData() обратно преобразует в объект данных, addRecurrenceExDate() добавляет даты исключения. clearFields() удаляет конфиденциальные данные для зрителей с минимальным доступом. mustIncSequence() проверяет, изменилось ли какое-либо поле, требующее увеличения sequence. Уникальное ограничение на (uid, calendar_fk).
