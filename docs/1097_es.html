Objeto de utilidad estático para procesamiento de RRULE. getRecurUntil() extrae el valor UNTIL de una RRule. parseExcludeDates() analiza cadenas EXDATE en formato CSV (separadores: coma, punto y coma, barra vertical) en una lista de objetos Temporal mediante DateParser, eliminando el prefijo "EXDATE:". isEventExcluded() verifica si una fecha de evento dada está en la lista exDates usando ICalDateUtils.isSameDay para comparación a nivel de día. Utilizado por TeamEventDao.rollOutRecurrenceEvents() para filtrar ocurrencias excluidas.
