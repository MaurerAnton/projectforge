projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/ical/VEventUtils.kt Utilidad / Conversión iCal VEvent, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/ical/VEventUtils.kt 234 líneas · 166 código · 46 comentarios · 22 en blanco
Utilidad central para convertir entre objetos ical4j VEvent y el modelo TeamEventDO de ProjectForge. convertToEventDO() analiza un VEvent en TeamEventDO, extrayendo resumen, ubicación, descripción, fechas-hora (detección de día completo mediante verificación LocalDate), regla de recurrencia, exdates, organizador, secuencia y UID. Opcionalmente almacena la cadena ICS original. convertToVEvent() va en la otra dirección: conserva el ICS original si está disponible, de lo contrario construye VEvent a partir de fechas (LocalDate para día completo, ZonedDateTime en caso contrario), agregando ubicación, descripción, organizador y RRULE. temporalToUTCDate() convierte cualquier Temporal a una fecha UTC. También proporciona: parseVEventFromIcs() (envoltorio alrededor de CalendarBuilder para un solo evento), createSetupEvent() para calendarios vacíos, createAllDayEvent()/createEvent() para eventos simples, setUid(), addLocation(), addDescription(), getPropertyValue(), getRRuleString() y extractExdates(). Habilita el análisis iCal relajado mediante CompatibilityHints.
