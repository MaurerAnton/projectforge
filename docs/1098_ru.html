#1098: VEventUtils.kt

Центральная утилита для преобразования между объектами ical4j VEvent и моделью TeamEventDO ProjectForge. convertToEventDO() разбирает VEvent в TeamEventDO, извлекая заголовок, местоположение, описание, даты-время (определение целодневных событий через проверку LocalDate), правило повторения, исключённые даты, организатора, последовательность и UID. Опционально сохраняет исходную ICS-строку. convertToVEvent() работает в обратном направлении: сохраняет исходный ICS, если доступен, иначе создаёт VEvent из дат (LocalDate для целодневных, ZonedDateTime для остальных), добавляя местоположение, описание, организатора и RRULE. temporalToUTCDate() преобразует любой Temporal в дату UTC. Также предоставляет: parseVEventFromIcs() (обёртка вокруг CalendarBuilder для одного события), createSetupEvent() для пустых календарей, createAllDayEvent()/createEvent() для простых событий, setUid(), addLocation(), addDescription(), getPropertyValue(), getRRuleString() и extractExdates(). Включает ослабленный разбор iCal через CompatibilityHints.
