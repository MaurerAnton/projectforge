Manuales operativos — conocimiento tribal codificado

La sección operativa es la parte más valiosa para los nuevos desarrolladores. Contiene:

  • Importaciones rápidas de PostgreSQL (líneas 64-74): ALTER SYSTEM SET fsync = off; ALTER SYSTEM SET synchronous_commit = off; — sacrifica durabilidad por velocidad de importación. Estos ajustes DEBEN revertirse después de la importación.
  • Contraseña de desarrollo estándar (línea 84): SHA{BC871652288E56E306CFA093BEFC3FFCD0ED8872} = test123. Usada en todas partes — ejemplos SQL, configuración de Docker, scripts de CI.
  • Limpieza de calendario (línea 86): update t_calendar set ext_subscription=false — evita llamadas masivas a la API de calendarios externos al usar datos de producción para desarrollo.
  • Limpieza de Rancher (líneas 55-62): docker system prune -a --volumes — recolección completa de basura de Docker. Peligroso en producción, esencial en desarrollo.

Conclusiones clave

  • Hibernate Search está roto: La sección "Reindexierung" documenta múltiples fallos en el índice de búsqueda — CronReindexingHourlyJob no tiene efecto, faltan entradas en el historial, solo funciona la reindexación masiva. Esto es una preocupación significativa para producción.
  • test123 en todas partes: El hash SHA de la contraseña de desarrollo aparece en cada ejemplo SQL. Si lo cambias, actualiza todas las referencias.
  • Mezcla de alemán/inglés: Tareas en alemán, SQL en inglés, términos técnicos en inglés. Normal para el equipo de Micromata.
