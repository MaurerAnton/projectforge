Manuels opérationnels — connaissances tacites codifiées

La section opérationnelle est la partie la plus précieuse pour les nouveaux développeurs. Elle contient :

  • Imports PostgreSQL rapides (lignes 64-74) : ALTER SYSTEM SET fsync = off; ALTER SYSTEM SET synchronous_commit = off; — sacrifie la durabilité pour la vitesse d'import. Ces paramètres DOIVENT être rétablis après l'import.
  • Mot de passe développeur standard (ligne 84) : SHA{BC871652288E56E306CFA093BEFC3FFCD0ED8872} = test123. Utilisé partout — exemples SQL, configuration Docker, scripts CI.
  • Nettoyage du calendrier (ligne 86) : update t_calendar set ext_subscription=false — empêche les appels API massifs aux calendriers externes lors de l'utilisation de données de production pour le développement.
  • Nettoyage Rancher (lignes 55-62) : docker system prune -a --volumes — nettoyage complet des déchets Docker. Dangereux en production, essentiel en développement.

Points clés à retenir

  • Hibernate Search est défaillant : La section "Reindexierung" documente plusieurs échecs d'index de recherche — CronReindexingHourlyJob n'a aucun effet, entrées d'historique manquantes, seule la réindexation de masse fonctionne. C'est un problème de production significatif.
  • test123 partout : Le hachage SHA pour le mot de passe développeur apparaît dans chaque exemple SQL. Si vous le modifiez, mettez à jour toutes les références.
  • Mélange allemand/anglais : Tâches en allemand, SQL en anglais, termes techniques en anglais. Normal pour l'équipe Micromata.
