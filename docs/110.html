PostgreSQL variant of the v1.1.0 RemoveMGC migration (HSQLDB version). Widens five PK/FK columns from INTEGER to BIGINT:

  • t_plugin_datatransfer_area.pk → TYPE bigint
  • t_plugin_datatransfer_audit.pk → TYPE bigint
  • t_plugin_datatransfer_audit.area_fk → TYPE bigint
  • t_plugin_datatransfer_audit.by_user_fk → TYPE bigint
  • t_plugin_datatransfer_audit.upload_by_user_fk → TYPE bigint

PostgreSQL requires explicit ALTER COLUMN ... TYPE bigint syntax — the TYPE keyword is mandatory, unlike HSQLDB's simpler ALTER COLUMN ... bigint.
