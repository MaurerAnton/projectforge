#1100: TimesheetDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDO.kt JPA-Entität / Timesheet-Domäne, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDO.kt 322 Zeilen · 218 Code · 70 Kommentare · 34 leer
Zentrale JPA-Entität für Zeiterfassungsblätter (Tabelle T_TIMESHEET), erweitert DefaultBaseDO und implementiert Comparable (nach startTime). Felder: task (lazy ManyToOne, indexiert eingebettet), user (lazy ManyToOne, indexiert eingebettet mit objectId), timeZone, startTime/stopTime (Date mit Minutenpräzision, gerundet auf 5-Minuten-Vielfache via setStartDate/setStopDate), location (100 Zeichen), reference (1000 Zeichen, jiraPreservingAnalyzer), tag, description (4000 Zeichen). Kost2-Assoziation (lazy ManyToOne, nullable). KI-Zeitersparnis-Unterstützung: timeSavedByAI (BigDecimal), timeSavedByAIUnit-Enum (PERCENTAGE/HOURS), timeSavedByAIDescription. Berechnete Eigenschaften: duration (Millisekunden aus TimePeriod), durationAsString (formatierte Stunden:Minuten), workFractionDuration (gewichtet nach kost2/kost2Art workFraction), timePeriod, userId/taskId/kost2Id. marked transientes Boolean zur Kollisionsmarkierung. getFormattedWeekOfYear() und getShortDescription() (50-Zeichen-Abkürzung). Benannte Abfragen für Start/Stopp nach Aufgabe, Min/Max-Daten, Orts-/Verwendete-Orte-Suche und Referenzen nach Aufgabe.
