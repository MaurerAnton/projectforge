projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDO.kt Entidad JPA / Dominio de Timesheet, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDO.kt 322 líneas · 218 código · 70 comentarios · 34 en blanco
Entidad JPA principal para hojas de tiempo (tabla T_TIMESHEET), que extiende DefaultBaseDO e implementa Comparable (por startTime). Campos: task (lazy ManyToOne, indexado embebido), user (lazy ManyToOne, indexado embebido con objectId), timeZone, startTime/stopTime (Date con precisión de minutos, redondeado a múltiplos de 5 mediante setStartDate/setStopDate), location (100 caracteres), reference (1000 caracteres, jiraPreservingAnalyzer), tag, description (4000 caracteres). Asociación Kost2 (lazy ManyToOne, nullable). Soporte de ahorro de tiempo por IA: timeSavedByAI (BigDecimal), timeSavedByAIUnit enum (PERCENTAGE/HOURS), timeSavedByAIDescription. Propiedades computadas: duration (milisegundos desde TimePeriod), durationAsString (formateado horas:minutos), workFractionDuration (ponderado por kost2/kost2Art workFraction), timePeriod, userId/taskId/kost2Id. marked booleano transitorio para marcado de colisiones. getFormattedWeekOfYear() y getShortDescription() (abreviatura de 50 caracteres). Consultas nombradas para inicio/parada por tarea, fechas mín/máx, búsqueda de ubicación/ubicaciones usadas y referencias por tarea.
