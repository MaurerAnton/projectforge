projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDO.kt Entité JPA / Domaine Timesheet, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDO.kt 322 lignes · 218 code · 70 commentaires · 34 vides
Entité JPA centrale pour les feuilles de temps (table T_TIMESHEET), étendant DefaultBaseDO et implémentant Comparable (par startTime). Champs : tâche (lazy ManyToOne, indexé embarqué), utilisateur (lazy ManyToOne, indexé embarqué avec objectId), fuseau horaire, startTime/stopTime (Date avec précision à la minute, arrondi aux multiples de 5 minutes via setStartDate/setStopDate), emplacement (100 caractères), référence (1000 caractères, jiraPreservingAnalyzer), tag, description (4000 caractères). Association Kost2 (lazy ManyToOne, nullable). Support AI pour économies de temps : timeSavedByAI (BigDecimal), timeSavedByAIUnit enum (PERCENTAGE/HOURS), timeSavedByAIDescription. Propriétés calculées : duration (millisecondes depuis TimePeriod), durationAsString (formaté heures:minutes), workFractionDuration (pondéré par kost2/kost2Art workFraction), timePeriod, userId/taskId/kost2Id. marked booléen transitoire pour marquage de collision. getFormattedWeekOfYear() et getShortDescription() (abréviation de 50 caractères). Requêtes nommées pour début/fin par tâche, dates min/max, recherche d'emplacement/emplacements utilisés, et références par tâche.
