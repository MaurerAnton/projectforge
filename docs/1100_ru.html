#1100: TimesheetDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDO.kt JPA-сущность / Домен Timesheet, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDO.kt 322 строки · 218 кода · 70 комментариев · 34 пустых
Основная JPA-сущность для табелей (таблица T_TIMESHEET), расширяет DefaultBaseDO и реализует Comparable (по startTime). Поля: task (ленивый ManyToOne, индексированный встроенный), user (ленивый ManyToOne, индексированный встроенный с objectId), timeZone, startTime/stopTime (Date с точностью до минуты, округление до кратных 5 минут через setStartDate/setStopDate), location (100 символов), reference (1000 символов, jiraPreservingAnalyzer), tag, description (4000 символов). Связь Kost2 (ленивый ManyToOne, nullable). Поддержка экономии времени ИИ: timeSavedByAI (BigDecimal), timeSavedByAIUnit enum (PERCENTAGE/HOURS), timeSavedByAIDescription. Вычисляемые свойства: duration (миллисекунды из TimePeriod), durationAsString (форматированные часы:минуты), workFractionDuration (взвешенное по kost2/kost2Art workFraction), timePeriod, userId/taskId/kost2Id. marked — временный boolean для маркировки коллизий. getFormattedWeekOfYear() и getShortDescription() (сокращение до 50 символов). Именованные запросы для start/stop по задаче, min/max дат, поиска location/использованных location и ссылок по задаче.
