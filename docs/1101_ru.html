#1101: TimesheetDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDao.kt DAO / Управление табелями, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetDao.kt 784 строки · 596 кода · 143 комментария · 45 пустых
Основной DAO для управления табелями, расширяющий BaseDao. Реализует комплексный контроль доступа: собственные табели vs чужие табели (финансовая группа имеет полный доступ), руководители проектов/HR/контроллинг могут просматривать, но со скрытым описанием/местоположением (HIDDEN_FIELD_MARKER). checkTimesheetProtection() проверяет ограничение protectTimesheetsUntil на родительских задачах (предотвращает бронирование до даты заморозки). checkTaskBookable() обеспечивает соблюдение 4 правил: задача/предки не закрыты/не удалены, нет статуса TREE_CLOSED, нет ONLY_LEAFS на родительских задачах с дочерними, нет позиций заказа в дочерних задачах. onInsertOrModify() проверяет: миллисекунды/секунды должны быть 0, минуты кратны 5, минимальная длительность 60 с, максимум 14 ч, обнаружение пересечений по времени (через hasTimeOverlap() в транзакции), проверка kost2 (должен быть в списке kost2 задачи). validateTimeSavingsByAI() гарантирует, что единица измерения установлена при указании экономии, процент ограничен 99%. prepareHibernateSearch() повторно инициализирует ленивые ссылки на пользователя/задачу для индексации. Поддерживает настраиваемые теги, автозаполнение местоположения, автозаполнение ссылок и запросы по диапазону лет.
