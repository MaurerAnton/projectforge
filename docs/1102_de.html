#1102: TimesheetExport.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetExport.kt Service / Excel-Export, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetExport.kt 159 Zeilen · 120 Code · 30 Kommentare · 9 leer
Spring @Service, das gefilterte Zeiterfassungslisten als Excel-Arbeitsmappen (.xlsx) über die Merlin-Excel-Bibliothek exportiert. export() erstellt eine Arbeitsmappe mit den Spalten: Benutzervollname, Kunde, Projekt, Kost2-Anzeigename, Wochentag-/Wochentag-Bezeichnungen, Start-/Stopp-Zeit (in Benutzerzeitzone, HH:mm-Format), Dauer (Excel-Bruchteil eines Tages, [h]:mm-Format), Stunden (dezimal, #,##0.00), optionale KI-Zeitersparnis-Spalten (Stunden + Prozentsatz), Ort, Referenz, Aufgabenbezeichnung, Aufgabenreferenz, Kurzbeschreibung (Textumbruch), Beschreibung (Textumbruch), Aufgabenpfad, ID, erstellt, letzte Aktualisierung. Setzt Autofilter und eingefrorenen Bereich. Verwendet fette Kopfzeile. Referenziert taskTree und userGroupCache zur Auflösung von Aufgabenpfaden und Benutzernamen.
