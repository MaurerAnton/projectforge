#1102 : TimesheetExport.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetExport.kt Service / Export Excel, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetExport.kt 159 lignes · 120 code · 30 commentaires · 9 vides
Spring @Service qui exporte des listes de feuilles de temps filtrées sous forme de classeurs Excel (.xlsx) via la bibliothèque Merlin Excel. export() crée un classeur avec les colonnes : nom complet de l'utilisateur, client, projet, nom d'affichage kost2, étiquettes jour/semaine, heure de début/fin (dans le fuseau horaire de l'utilisateur, format HH:mm), durée (fraction de jour Excel, format [h]:mm), heures (décimal, #,##0.00), colonnes optionnelles d'économies de temps IA (heures + pourcentage), lieu, référence, titre de la tâche, référence de la tâche, description courte (texte avec retour à la ligne), description (texte avec retour à la ligne), chemin de la tâche, id, créé, dernière mise à jour. Définit le filtre automatique et le volet gelé. Utilise une ligne d'en-tête en gras. Référence taskTree et userGroupCache pour résoudre les chemins de tâches et les noms d'utilisateurs.
