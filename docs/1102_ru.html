#1102: TimesheetExport.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetExport.kt Сервис / Excel-экспорт, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetExport.kt 159 строк · 120 кода · 30 комментариев · 9 пустых
Spring @Service, который экспортирует отфильтрованные списки табелей учета рабочего времени в виде книг Excel (.xlsx) с помощью библиотеки Merlin Excel. export() создает книгу со столбцами: полное имя пользователя, заказчик, проект, отображаемое имя kost2, метки недели/дня недели, время начала/окончания (в часовом поясе пользователя, формат HH:mm), продолжительность (доля дня в Excel, формат [h]:mm), часы (десятичные, #,##0.00), дополнительные столбцы экономии времени ИИ (часы + процент), местоположение, ссылка, название задачи, ссылка на задачу, краткое описание (перенос текста), описание (перенос текста), путь задачи, id, дата создания, последнее обновление. Устанавливает автофильтр и замороженную панель. Использует жирную строку заголовка. Обращается к taskTree и userGroupCache для разрешения путей задач и имен пользователей.
