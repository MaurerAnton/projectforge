#1103: TimesheetFavorite.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavorite.kt Datenklasse / Favoriten, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavorite.kt 103 Zeilen · 69 Code · 29 Kommentare · 5 leer
Datenklasse, die AbstractFavorite erweitert und eine Zeiterfassungsvorlage/einen Favoriten eines Benutzers abbildet. Felder: taskId, userId, Ort, Tag, Referenz, Beschreibung, cost2Id, timeSavedByAIUnit. KI-Einsparungen (absolute Werte und Beschreibung) werden absichtlich ausgeschlossen (sollten manuell eingegeben werden). fillFromTimesheet() kopiert nicht-null/leere Felder aus einem TimesheetDO. copyToTimesheet() wendet gespeicherte Werte auf eine TimesheetDO-Instanz an (erstellt Proxy-Objekte für Aufgabe, Benutzer, kost2, bei denen nur die ID gesetzt ist). Leere Felder werden auf leere Zeichenketten gesetzt, um etwaige clientseitige Werte zu überschreiben.
