#1103: TimesheetFavorite.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavorite.kt Clase de datos / Favoritos, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavorite.kt 103 líneas · 69 código · 29 comentarios · 5 en blanco
Clase de datos que extiende AbstractFavorite capturando la plantilla/favorito de hoja de tiempo de un usuario. Campos: taskId, userId, location, tag, reference, description, cost2Id, timeSavedByAIUnit. Los valores absolutos de ahorro de IA y la descripción se excluyen intencionalmente (el usuario debe ingresarlos manualmente). fillFromTimesheet() copia campos no nulos/vacíos desde un TimesheetDO. copyToTimesheet() aplica los valores almacenados a una instancia de TimesheetDO (crea objetos proxy para task, user, kost2 con solo el id establecido). Los campos en blanco se establecen como cadenas vacías para sobrescribir cualquier valor del lado del cliente.
