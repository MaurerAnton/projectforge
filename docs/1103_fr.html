projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavorite.kt Classe de données / Favoris, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavorite.kt 103 lignes · 69 code · 29 commentaires · 5 vides
Classe de données étendant AbstractFavorite capturant le modèle/favori de feuille de temps d'un utilisateur. Champs : taskId, userId, location, tag, reference, description, cost2Id, timeSavedByAIUnit. Les valeurs absolues d'économies d'IA et la description sont intentionnellement exclues (l'utilisateur doit les saisir manuellement). fillFromTimesheet() copie les champs non nuls/vides depuis un TimesheetDO. copyToTimesheet() applique les valeurs stockées à une instance TimesheetDO (crée des objets proxy pour task, user, kost2 avec seulement l'id défini). Les champs vides sont définis comme chaînes vides pour remplacer toute valeur côté client.
