#1103: TimesheetFavorite.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavorite.kt Класс данных / Избранное, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavorite.kt 103 строки · 69 кода · 29 комментариев · 5 пустых
Класс данных, расширяющий AbstractFavorite, фиксирующий шаблон/избранное пользователя для табеля. Поля: taskId, userId, location, tag, reference, description, cost2Id, timeSavedByAIUnit. Абсолютные значения экономии ИИ и описание намеренно исключены (должны вводиться вручную). fillFromTimesheet() копирует не-null/непустые поля из TimesheetDO. copyToTimesheet() применяет сохранённые значения к экземпляру TimesheetDO (создаёт прокси-объекты для task, user, kost2 только с установленным id). Пустые поля устанавливаются в пустые строки для переопределения любых значений на стороне клиента.
