#1104: TimesheetFavoritesService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavoritesService.kt Service / Favoriten, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavoritesService.kt 175 Zeilen · 119 Code · 34 Kommentare · 22 leer
Spring @Service zur Verwaltung von Benutzer-Zeiterfassungsfavoriten. Verwendet hybriden Speicher: neue Favoriten werden als Favorites<TimesheetFavorite> JSON über UserPrefService im Bereich "timesheet" gespeichert, während die Migration von Legacy-UserPrefDao-Vorlagen (Bereich TIMESHEET_TEMPLATE) unterstützt wird. getFavorites() versucht, das neue Format zu laden, und fällt auf migrateFromLegacyFavorites() zurück, das alte UserPref-Einträge in Favorites-Objekte konvertiert. Der innere MigrationCache (erweitert AbstractCache) speichert pro Benutzer die Prüfung auf vorhandene Legacy-Favoriten zwischen. createFavorite()/deleteFavorite()/renameFavorite() verwenden den Favorites-Helfer. refreshMigrationCache() ungültig nach Änderungen. Legacy-Favoriten werden bei Bedarf migriert (überschreibt niemals vorhandene neue Favoriten).
