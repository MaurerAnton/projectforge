#1104: TimesheetFavoritesService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavoritesService.kt Service / Favoris, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetFavoritesService.kt 175 lignes · 119 code · 34 commentaires · 22 vides
Spring @Service gérant les favoris de feuilles de temps utilisateur. Utilise un stockage hybride : les nouveaux favoris sont stockés sous forme de JSON Favorites<TimesheetFavorite> via UserPrefService dans la zone "timesheet", tout en prenant en charge la migration depuis les modèles UserPrefDao hérités (zone TIMESHEET_TEMPLATE). getFavorites() tente de charger le nouveau format, et se rabat sur migrateFromLegacyFavorites() qui convertit les anciennes entrées UserPref en objets Favorites. Le MigrationCache interne (étend AbstractCache) met en cache par utilisateur les vérifications d'existence de favoris hérités. createFavorite()/deleteFavorite()/renameFavorite() utilisent l'assistant Favorites. refreshMigrationCache() invalide après les modifications. Les favoris hérités sont migrés à la demande (n'écrase jamais les nouveaux favoris existants).
