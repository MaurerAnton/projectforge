#1104: TimesheetFavoritesService.kt

Spring @Service, управляющий избранными табелями пользователя. Использует гибридное хранение: новые избранные сохраняются как Favorites<TimesheetFavorite> в формате JSON через UserPrefService в области "timesheet", с поддержкой миграции из устаревших шаблонов UserPrefDao (область TIMESHEET_TEMPLATE). getFavorites() пытается загрузить новый формат, при неудаче вызывает migrateFromLegacyFavorites(), который преобразует старые записи UserPref в объекты Favorites. Внутренний MigrationCache (расширяет AbstractCache) кэширует проверки наличия устаревших избранных для каждого пользователя. createFavorite()/deleteFavorite()/renameFavorite() используют вспомогательный класс Favorites. refreshMigrationCache() сбрасывает кэш после изменений. Устаревшие избранные мигрируются по требованию (никогда не перезаписывают существующие новые избранные).
