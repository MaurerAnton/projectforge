#1105: TimesheetRecentEntry.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentEntry.kt Datenklasse / Letzte Einträge, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentEntry.kt 75 Zeilen · 41 Code · 30 Kommentare · 4 leer
Kotlin-Datenklasse, annotiert für XStream-Serialisierung (wird in der Legacy-UserPref-Speicherung verwendet). Speichert einen Schnappschuss eines zuletzt verwendeten Zeiterfassungsblatts für die schnelle Wiederauswahl. Felder: taskId, userId, kost2Id, location, reference, tag, description (alle nullable, die meisten mit @XStreamAsAttribute). KI-Sparfelder (timeSavedByAI, timeSavedByAIUnit, timeSavedByAIDescription) sind @XStreamOmitField — explizit von der Serialisierung ausgeschlossen, um die Privatsphäre zu schützen und die manuelle Eingabe zu fördern. Konstruktor von TimesheetDO kopiert alle Nicht-KI-Felder. Implementiert equals/hashCode über Datenklassen-Semantik. Wird von der RecentQueue des TimesheetRecentService verwendet.
