#1105: TimesheetRecentEntry.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentEntry.kt Clase de datos / Entradas recientes, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentEntry.kt 75 líneas · 41 código · 30 comentarios · 4 en blanco
Clase de datos de Kotlin anotada para serialización XStream (usada en almacenamiento legacy de UserPref). Almacena una instantánea de una hoja de tiempo usada recientemente para una rápida re-selección. Campos: taskId, userId, kost2Id, location, reference, tag, description (todos anulables, la mayoría con @XStreamAsAttribute). Los campos de ahorro de IA (timeSavedByAI, timeSavedByAIUnit, timeSavedByAIDescription) tienen @XStreamOmitField — explícitamente excluidos de la serialización para preservar la privacidad y fomentar la entrada manual. El constructor desde TimesheetDO copia todos los campos no relacionados con IA. Implementa equals/hashCode mediante semántica de clase de datos. Usado por RecentQueue de TimesheetRecentService.
