Classe de données Kotlin annotée pour la sérialisation XStream (utilisée dans le stockage hérité UserPref). Stocke un instantané d'une feuille de temps récemment utilisée pour une re-sélection rapide. Champs : taskId, userId, kost2Id, location, reference, tag, description (tous nullables, la plupart avec @XStreamAsAttribute). Les champs d'économies IA (timeSavedByAI, timeSavedByAIUnit, timeSavedByAIDescription) sont @XStreamOmitField — explicitement exclus de la sérialisation pour préserver la confidentialité et encourager la saisie manuelle. Constructeur à partir de TimesheetDO copie tous les champs non-IA. Implémente equals/hashCode via la sémantique des classes de données. Utilisé par RecentQueue de TimesheetRecentService.
