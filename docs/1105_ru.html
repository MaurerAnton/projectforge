#1105: TimesheetRecentEntry.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentEntry.kt Класс данных / Недавние записи, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentEntry.kt 75 строк · 41 код · 30 комментариев · 4 пустых
Класс данных Kotlin с аннотациями для сериализации XStream (используется в устаревшем хранилище UserPref). Хранит снимок недавно использованного табеля для быстрого повторного выбора. Поля: taskId, userId, kost2Id, location, reference, tag, description (все nullable, большинство с @XStreamAsAttribute). Поля AI-экономии (timeSavedByAI, timeSavedByAIUnit, timeSavedByAIDescription) помечены @XStreamOmitField — явно исключены из сериализации для сохранения конфиденциальности и поощрения ручного ввода. Конструктор из TimesheetDO копирует все не-AI поля. Реализует equals/hashCode через семантику data class. Используется RecentQueue сервиса TimesheetRecentService.
