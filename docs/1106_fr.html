#1106: TimesheetRecentService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentService.kt Service / Entrées récentes, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentService.kt 195 lignes · 142 code · 30 commentaires · 23 vides
Spring @Service gérant les entrées de feuille de temps récentes par utilisateur. Maintient trois files d'attente RecentQueues distinctes (max 50 entrées chacune) stockées de manière volatile via UserPrefService : recent.timesheets (objets TimesheetRecentEntry), recent.locations (chaînes) et recent.taskIds (Longs). addRecentTimesheet() ajoute une nouvelle entrée à la file d'attente des feuilles de temps, à la file d'attente des lieux et à la file d'attente des tâches. Lors du premier accès (file vide), le service peuple depuis la base de données : interroge la dernière année de feuilles de temps de l'utilisateur, déduplique (par égalité de champ) et remplit les files jusqu'à 50 éléments. getRecentTimesheets()/getRecentTimesheet() retournent le contenu de la file. getRecentLocations() et getRecentTaskIds() retournent des files typées. Utilise getRecentQueue() générique avec un motif lambda d'initialisation paresseuse. La clé de zone de préférence utilisateur est TimesheetRecentService::class.java.name pour l'espacement des noms.
