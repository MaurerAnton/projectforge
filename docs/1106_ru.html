#1106: TimesheetRecentService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentService.kt Сервис / Последние записи, projectforge-business/src/main/kotlin/org/projectforge/business/timesheet/TimesheetRecentService.kt 195 строк · 142 кода · 30 комментариев · 23 пустых
Spring @Service, управляющий последними записями табеля для каждого пользователя. Поддерживает три отдельных RecentQueue (максимум 50 записей каждая), хранящихся в энергозависимой памяти через UserPrefService: recent.timesheets (объекты TimesheetRecentEntry), recent.locations (строки) и recent.taskIds (Long). addRecentTimesheet() добавляет новую запись в очередь табелей, очередь местоположений и очередь задач. При первом обращении (пустая очередь) сервис заполняется из базы данных: запрашивает табели пользователя за последний год, удаляет дубликаты (по равенству полей) и заполняет очереди до 50 элементов. getRecentTimesheets()/getRecentTimesheet() возвращают содержимое очереди. getRecentLocations() и getRecentTaskIds() возвращают типизированные очереди. Использует общий getRecentQueue() с шаблоном лямбда-выражения ленивой инициализации. Ключ области пользовательских настроек — TimesheetRecentService::class.java.name для пространства имён.
