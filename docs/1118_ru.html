#1118: UserDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/user/UserDao.kt Объект доступа к данным, projectforge-business/src/main/kotlin/org/projectforge/business/user/UserDao.kt 358 строк · 233 кода · 94 комментария · 31 пустая
Основной DAO для сохранения сущности пользователя, предоставляющий поиск пользователей по различным критериям (имя пользователя, email, ID), запросы аутентификации и CRUD-операции с пользователями с контролем доступа.

Архитектура

Наследование

Расширяет BaseDao. Добавляет специфичные для пользователя запросы: findByUsername(), findByEmail(), findActiveUsers(), authenticate() (проверка пароля).

Интеграция с безопасностью

Реализует проверки доступа: только администраторы могут видеть всех пользователей; обычные пользователи видят себя и пользователей в общих группах. Обновления вызывают инвалидацию кэша в UserGroupCache и UserPrefCache.

Обоснование дизайна

Основное сохранение пользователей централизовано здесь для обеспечения единообразного хеширования паролей, проверки статуса и контроля доступа во всех операциях с пользователями.

Анализ архитектуры

Находится в projectforge-business, основном модуле, содержащем доменную логику, сервисы и сохранение. Обычно аннотируется @Service или @Component, управляется контейнером Spring IoC с внедрением зависимостей.
