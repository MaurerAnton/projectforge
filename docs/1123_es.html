#1123: UserPrefCache.kt

projectforge-business/src/main/kotlin/org/projectforge/business/user/UserPrefCache.kt Caché, projectforge-business/src/main/kotlin/org/projectforge/business/user/UserPrefCache.kt 96 líneas · 46 código · 36 comentarios · 14 en blanco
Implementación de caché para preferencias de usuario, extendiendo AbstractUserPrefCache con lógica concreta de almacenamiento y recuperación para entidades UserPrefEntryDO.

Arquitectura

Jerarquía de caché

Extiende AbstractUserPrefCache. Utiliza ConcurrentHashMap en memoria por usuario para acceso rápido. Recurre a consultas de base de datos mediante UserPrefDao en caso de fallo de caché.

Seguridad de tipos

Proporciona métodos genéricos getEntry(clave, tipo) usando genéricos reificados de Kotlin. Soporta valores String, Integer, Boolean y objetos serializados.

Justificación del diseño

Las preferencias se leen en prácticamente cada carga de página pero cambian con poca frecuencia. La caché elimina lecturas redundantes de BD mientras que putValue() garantiza consistencia de escritura directa.

Análisis de arquitectura

Reside en projectforge-business, el módulo principal que contiene lógica de dominio, servicios y persistencia. Típicamente anotado con @Service o @Component, gestionado por el contenedor IoC de Spring con inyección de dependencias.
