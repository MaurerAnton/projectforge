#1123 : UserPrefCache.kt

projectforge-business/src/main/kotlin/org/projectforge/business/user/UserPrefCache.kt Cache, projectforge-business/src/main/kotlin/org/projectforge/business/user/UserPrefCache.kt 96 lignes · 46 code · 36 commentaires · 14 vides
Implémentation de cache pour les préférences utilisateur, étendant AbstractUserPrefCache avec une logique concrète de stockage et de récupération pour les entités UserPrefEntryDO.

Architecture

Hiérarchie du cache

Étend AbstractUserPrefCache. Utilise une ConcurrentHashMap en mémoire par utilisateur pour un accès rapide. En cas d'échec du cache, interroge la base de données via UserPrefDao.

Sécurité des types

Fournit des méthodes génériques getEntry(clé, type) utilisant les génériques réifiés de Kotlin. Prend en charge les valeurs de type String, Integer, Boolean et les objets sérialisés.

Justification de la conception

Les préférences sont lues sur pratiquement chaque chargement de page mais changent rarement. Le cache élimine les lectures redondantes en base de données tandis que putValue() assure une cohérence en écriture immédiate.

Analyse de l'architecture

Réside dans projectforge-business, le module central contenant la logique métier, les services et la persistance. Généralement annoté avec @Service ou @Component, géré par le conteneur IoC Spring avec injection de dépendances.
