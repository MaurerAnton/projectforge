Реализация кэша для пользовательских настроек, расширяющая AbstractUserPrefCache с конкретной логикой хранения и извлечения для сущностей UserPrefEntryDO.

Архитектура

Иерархия кэша

Расширяет AbstractUserPrefCache. Использует в памяти ConcurrentHashMap для каждого пользователя для быстрого доступа. При отсутствии в кэше обращается к базе данных через UserPrefDao.

Типобезопасность

Предоставляет обобщённые методы getEntry(key, type) с использованием реифицированных обобщений Kotlin. Поддерживает значения String, Integer, Boolean и сериализованные объекты.

Обоснование дизайна

Настройки считываются практически при каждой загрузке страницы, но изменяются редко. Кэш устраняет избыточные чтения БД, а putValue() обеспечивает согласованность при сквозной записи.

Анализ архитектуры

Находится в projectforge-business, основном модуле, содержащем доменную логику, сервисы и персистентность. Обычно аннотируется @Service или @Component, управляется контейнером Spring IoC с внедрением зависимостей.
