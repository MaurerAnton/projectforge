projectforge-business/src/main/kotlin/org/projectforge/business/user/UserPrefDao.kt Objeto de acceso a datos, projectforge-business/src/main/kotlin/org/projectforge/business/user/UserPrefDao.kt 750 líneas · 587 código · 102 comentarios · 61 en blanco
DAO para la persistencia de preferencias de usuario, que proporciona operaciones CRUD sobre entidades UserPrefDO y UserPrefEntryDO con alcance basado en áreas.

Arquitectura

Herencia

Extiende BaseDao<UserPrefDO>. Proporciona getUserPrefs(usuario, área), getEntry(usuario, área, clave), saveEntry() para la persistencia de preferencias.

Alcance por área

Todas las consultas están delimitadas por UserPrefArea para evitar colisiones de claves entre áreas. Las preferencias se organizan como UserPrefDO (contenedor) → UserPrefEntryDO (entradas individuales).

Justificación del diseño

La estructura de dos niveles (DO → EntryDO) permite la carga atómica de todas las preferencias para un área, manteniendo las actualizaciones de entradas individuales ligeras.

Análisis de arquitectura

Reside en projectforge-business, el módulo central que contiene la lógica de dominio, servicios y persistencia. Define un conjunto fijo de constantes nombradas, implementando a menudo I18nEnum para etiquetas de visualización internacionalizadas.
