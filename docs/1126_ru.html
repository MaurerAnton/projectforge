#1126: UserPrefDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/user/UserPrefDao.kt Объект доступа к данным, projectforge-business/src/main/kotlin/org/projectforge/business/user/UserPrefDao.kt 750 строк · 587 кода · 102 комментария · 61 пустая
DAO для сохранения пользовательских настроек, предоставляющий CRUD-операции над сущностями UserPrefDO и UserPrefEntryDO с областью видимости на основе зон.

Архитектура

Наследование

Расширяет BaseDao<UserPrefDO>. Предоставляет getUserPrefs(user, area), getEntry(user, area, key), saveEntry() для сохранения настроек.

Область видимости по зонам

Все запросы ограничены UserPrefArea для предотвращения коллизий ключей между зонами. Настройки организованы как UserPrefDO (контейнер) → UserPrefEntryDO (отдельные записи).

Обоснование дизайна

Двухуровневая структура (DO → EntryDO) позволяет атомарно загружать все настройки для зоны, сохраняя лёгкость обновления отдельных записей.

Анализ архитектуры

Находится в projectforge-business, основном модуле, содержащем доменную логику, сервисы и персистентность. Определяет фиксированный набор именованных констант, часто реализующих I18nEnum для интернационализированных отображаемых меток.
