Caché para preferencias de usuario almacenadas en formato XML, proporcionando acceso tipado a estructuras de preferencias complejas con serialización/deserialización XML.

Arquitectura

Backend de almacenamiento XML

Implementa AbstractUserPrefCache usando archivos XML almacenados en disco por usuario. Utiliza JAXB o kotlinx.serialization para el enlace XML.

Estrategia de caché

Carga el archivo completo de preferencias en memoria en el primer acceso, escribe en disco en los cambios y usa marcas de tiempo de modificación de archivos para la validación de caché entre solicitudes.

Justificación de diseño

Proporciona una alternativa basada en archivos al almacenamiento en base de datos para preferencias, permitiendo portabilidad de configuración y escenarios de despliegue más simples sin necesidad de base de datos.

Análisis de arquitectura

Reside en projectforge-business, el módulo central que contiene lógica de dominio, servicios y persistencia. Típicamente anotado con @Service o @Component, gestionado por el contenedor Spring IoC con inyección de dependencias.
