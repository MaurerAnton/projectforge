Сервис для обработки HTTP-куки в цепочке фильтров аутентификации, управление созданием, проверкой и удалением куки сессии и "запомнить меня".

Архитектура

Жизненный цикл куки

Управляет созданием подписанных куки, содержащих идентификатор пользователя, токен серии и порядковый номер. Проверяет куки на соответствие сохранённым токенам при каждом запросе, пересоздаёт при изменениях и обрабатывает удаление при выходе из системы или аннулировании токена.

Дизайн безопасности

Использует шаблон постоянного токена: каждая серия имеет вращающийся случайный токен. При предъявлении старого токена (обнаружена кража куки) вся серия аннулируется, защищая сессию легитимного пользователя.

Обоснование дизайна

Выделен из цепочки фильтров, чтобы операции с куки можно было тестировать независимо. Разделение на уровне сервиса позволяет реализовать различные варианты для конечных точек Wicket и REST.

Анализ архитектуры

Находится в projectforge-business, основном модуле, содержащем доменную логику, сервисы и персистентность. Выступает в роли Фильтра запросов в инфраструктуре пользовательской фильтрации результатов, используется на страницах поиска и списков для сужения результатов базы данных на основе выбранных пользователем критериев. Обычно аннотируется @Service или @Component, управляется контейнером Spring IoC с внедрением зависимостей.
