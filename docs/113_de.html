E-Mail zur Ablaufbenachrichtigung – wird von einem geplanten Job an Bereichsverantwortliche gesendet, wenn Dateien sich ihrem automatischen Löschdatum nähern. Verwendet ProjectForge's Freemarker-basiertes E-Mail-System mit #INCLUDE{...}-Direktiven für gemeinsame Kopf-/Fußzeilen-Komponenten (mailHead.html, mailOpening.html, mailClosing.html, mailFooter.html).

Vorlagenvariablen

  • pf – ProjectForge-Freemarker-Kontext, stellt getI18nString() und formatBytes() bereit
  • attachments – Liste von AttachmentInfo-Objekten mit Feldern: link (direkte URL zum Bereich), dataTransferArea.getDisplayName(locale), attachment.name, attachment.size, expiryDate, expiresInTimeLeft
  • locale – Gebietsschema des Benutzers für i18n-Abfragen

Inhaltsstruktur

  1. i18n-Überschrift: „Liste der zu löschenden Dateien:“ – aus Schlüssel plugins.datatransfer.mail.notificationBeforeDeletion.info
  2. Tabellenspalten: Bereichsname, Dateiname, Dateigröße, Ablaufdatum, Verbleibende Zeit
  3. Jede Datei ist ein klickbarer Link zu ihrem Datenübertragungsbereich (target="_blank" rel="noreferrer")
  4. Info-Absatz am Ende: Erklärt, dass ein Klick auf eine Datei und Drücken von „Aktualisieren“ den Ablauf verlängert – aus Schlüssel plugins.datatransfer.mail.notificationBeforeDeletion.hint

Die verwendeten i18n-Schlüssel sind in DataTransferI18nResources.properties definiert (Schlüssel 46-48).

Rendering-Engine

Verwendet Freemarker (<%= ... %> Ausgabeausdrücke, <% ... %> Kontrollfluss) – abweichend von ProjectForge's Groovy-Scripting-Engine. Die #INCLUDE{...}-Syntax ist eine ProjectForge-Erweiterung für Freemarker zur Wiederverwendung von E-Mail-Komponenten. Das pf-Objekt wird vom MailService im Kernframework an den Freemarker-Kontext gebunden.
