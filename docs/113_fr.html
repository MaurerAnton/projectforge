#113 : dataTransferFilesBeingDeletedMail.html

plugins/org.projectforge.plugins.datatransfer/src/main/resources/mail/dataTransferFilesBeingDeletedMail.html Chemin : plugins/...datatransfer/src/main/resources/mail/dataTransferFilesBeingDeletedMail.html · Lignes : 43 · Type : Modèle d'email HTML Freemarker 43 lignes · 39 code · 4 commentaires · 0 vide

Email de notification d'expiration — envoyé par une tâche planifiée aux propriétaires de zone lorsque des fichiers approchent de leur date de suppression automatique. Utilise le système de messagerie Freemarker de ProjectForge avec les directives #INCLUDE{...} pour les composants d'en-tête/pied de page partagés (mailHead.html, mailOpening.html, mailClosing.html, mailFooter.html).

Variables du modèle

  • pf — Contexte Freemarker de ProjectForge, expose getI18nString() et formatBytes()
  • attachments — liste d'objets AttachmentInfo avec les champs : link (URL directe vers la zone), dataTransferArea.getDisplayName(locale), attachment.name, attachment.size, expiryDate, expiresInTimeLeft
  • locale — langue de l'utilisateur pour les recherches i18n

Structure du contenu

  1. En-tête i18n : « Liste des fichiers en cours de suppression : » — depuis la clé plugins.datatransfer.mail.notificationBeforeDeletion.info
  2. Colonnes du tableau : Nom de la zone, Nom du fichier, Taille du fichier, Date d'expiration, Temps restant
  3. Chaque fichier est un lien cliquable vers sa zone de transfert de données (target="_blank" rel="noreferrer")
  4. Paragraphe d'information en bas : explique que cliquer sur un fichier et appuyer sur « Mettre à jour » renouvelle l'expiration — depuis la clé plugins.datatransfer.mail.notificationBeforeDeletion.hint

Les clés i18n utilisées sont définies dans DataTransferI18nResources.properties (clés 46-48).

Moteur de rendu

Utilise Freemarker (expressions de sortie <%= ... %>, flux de contrôle <% ... %>) — distinct du moteur de script Groovy de ProjectForge. La syntaxe #INCLUDE{...} est une extension ProjectForge de Freemarker pour les composants email réutilisables. L'objet pf est lié au contexte Freemarker par MailService dans le framework central.
