#113: dataTransferFilesBeingDeletedMail.html

plugins/org.projectforge.plugins.datatransfer/src/main/resources/mail/dataTransferFilesBeingDeletedMail.html Путь: plugins/...datatransfer/src/main/resources/mail/dataTransferFilesBeingDeletedMail.html · Строк: 43 · Тип: HTML-шаблон письма Freemarker 43 строки · 39 кода · 4 комментария · 0 пустых

Уведомление об истечении срока — отправляется плановым заданием владельцам областей, когда файлы приближаются к дате автоматического удаления. Использует почтовую систему ProjectForge на основе Freemarker с директивами #INCLUDE{...} для общих компонентов заголовка/подвала (mailHead.html, mailOpening.html, mailClosing.html, mailFooter.html).

Переменные шаблона

  • pf — контекст Freemarker ProjectForge, предоставляет getI18nString() и formatBytes()
  • attachments — список объектов AttachmentInfo с полями: link (прямой URL к области), dataTransferArea.getDisplayName(locale), attachment.name, attachment.size, expiryDate, expiresInTimeLeft
  • locale — локаль пользователя для интернационализации

Структура содержимого

  1. Интернационализированный заголовок: «Список файлов, подлежащих удалению:» — из ключа plugins.datatransfer.mail.notificationBeforeDeletion.info
  2. Колонки таблицы: Имя области, Имя файла, Размер файла, Дата истечения, Оставшееся время
  3. Каждый файл представляет собой кликабельную ссылку на его область передачи данных (target="_blank" rel="noreferrer")
  4. Информационный абзац внизу: объясняет, что нажатие на файл и кнопка «Обновить» продлевает срок действия — из ключа plugins.datatransfer.mail.notificationBeforeDeletion.hint

Используемые ключи интернационализации определены в DataTransferI18nResources.properties (ключи 46-48).

Движок рендеринга

Использует Freemarker (выражения вывода <%= ... %>, управляющие конструкции <% ... %>) — отличается от скриптового движка Groovy в ProjectForge. Синтаксис #INCLUDE{...} является расширением ProjectForge для Freemarker, предназначенным для переиспользуемых компонентов писем. Объект pf привязывается к контексту Freemarker сервисом MailService в ядре фреймворка.
