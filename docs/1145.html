1145: UserRightService.java

Service, projectforge-business/src/main/java/org/projectforge/framework/persistence/api/UserRightService.java
Service for user right management, providing methods to check, assign, and revoke rights, integrating with the access control framework and group-based permissions.

Architecture

Service Layer

Spring @Service providing hasRight(user, rightId), getRights(user), assignRight(user, rightId), revokeRight(). Delegates to UserDao for persistence and UserGroupCache for group-based right resolution.

Access Control Flow

Checks: 1) Direct user rights, 2) Group-inherited rights, 3) Admin override. Results are cached short-term to avoid repeated expensive joins.

Design Rationale

Centralized rights service decouples permission logic from individual DAOs and controllers, enabling consistent enforcement and future RBAC extensions.

 *

public interface UserRightService
{

   * FALSE, TRUE;

  public static final UserRightValue[] FALSE_TRUE = new UserRightValue[] { UserRightValue.FALSE, UserRightValue.TRUE };

  /**
   * FALSE, READONLY, READWRITE;
   */
  public static final UserRightValue[] FALSE_READONLY_READWRITE = new UserRightValue[] { UserRightValue.FALSE,
