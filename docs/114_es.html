plugins/org.projectforge.plugins.datatransfer/src/main/resources/mail/dataTransferMail.html Ruta: plugins/...datatransfer/src/main/resources/mail/dataTransferMail.html · Líneas: 64 · Tipo: Plantilla de correo electrónico HTML Freemarker 64 líneas · 58 código · 4 comentarios · 2 en blanco

Correo de notificación de actividad del observador — enviado a los usuarios que están observando un área de transferencia de datos (tienen userWantsToObserve=true). Les notifica sobre acciones de archivos realizadas por otros usuarios: subidas, renombrados, eliminaciones y descargas externas.

Variables de la plantilla

  • message — mensaje dinámico (típicamente: "Se detectaron las siguientes actividades en el área de transferencia de datos 'NombreDelÁrea' que observas.") — clave plugins.datatransfer.mail.observe.message con sustitución {0}
  • auditEntries — lista de entradas de registro de auditoría recientes para el área (actividad completa, no solo descargas)
  • downloadAuditEntries — lista filtrada: solo eventos de DESCARGA, mostrados en una sección separada debajo
  • link — URL directa al área de transferencia de datos
  • pf — contexto de formateo: getI18nString() para etiquetas i18n, getString() para formato de fecha

Estructura del contenido

  1. Mensaje de saludo i18n (variable message, prelocalizada por recursos i18n)
  2. Tabla de actividad (todos los eventos recientes):
    • Columnas: Fecha, Nombre del archivo, Descripción, Acción (tipo de evento), Modificado por
      • <> Itera sobre auditEntries — cada entrada tiene timestamp, filenameAsString, descriptionAsString, eventType, byUserAsString
  3. Botón de acción: "Enlace de transferencia de datos" — con estilo de botón cliqueable con class="button", enlaza a ${link}
  4. Tabla de eventos de descarga (filtrada solo a DESCARGA):
    • Columnas: Fecha, Nombre del archivo, Acción, Descargado por
    • Itera sobre downloadAuditEntries
  5. Cierre/pie de página de correo compartido mediante directivas #INCLUDE

La separación de auditEntries frente a downloadAuditEntries permite al destinatario escanear "quién descargó qué" sin tener que desplazarse por el ruido de subidas/renombrados.

Disparador

Esta plantilla es renderizada por DataTransferObserverNotificationJob (un trabajo programado que se ejecuta periódicamente, consulta entradas de auditoría con notified=false, las agrupa por área y envía un correo por observador). Después del envío, la bandera notified en cada entrada de auditoría se establece a true para evitar duplicados.
