1158: VacationFilter.kt

Filter (Java source, no Kotlin file found), projectforge-business/src/main/java/org/projectforge/business/vacation/VacationFilter.java
Search filter for vacation list pages supporting filtering by employee ID, vacation status, and vacation mode (OWN/MANAGER/REPLACEMENT).

Architecture

VacationFilter extends BaseSearchFilter, inheriting standard search fields (free-text search string, max rows, offset). It adds three vacation-specific filter fields: employeeId (Integer), vacationstatus (VacationStatus enum), and vacationmode (VacationMode enum).

The class offers two constructors: one taking an employeeId for direct construction, and one accepting any BaseSearchFilter for conversion (copying all inherited search fields). The reset() method extends the parent reset by also nullifying vacationstatus and vacationmode.

Usage

Used in VacationDao.select(filter) — if the incoming filter is not already a VacationFilter, it wraps it. The filter's employeeId, vacationstatus, and vacationmode are applied as query restrictions. The @XStreamAlias("VacationFilter") annotation supports serialization for user preference persistence.

Design Rationale

Kept as a simple Java POJO (not migrated to Kotlin) due to its role as a serializable filter that plugs into the BaseSearchFilter hierarchy. The two-constructor pattern allows the DAO to accept either a plain BaseSearchFilter from the generic search infrastructure or a pre-built VacationFilter from vacation-specific pages.
