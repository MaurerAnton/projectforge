Test d'intégration pour le contrôle d'accès à DataTransfer — vérifie que les administrateurs, les membres de groupes et les utilisateurs individuels disposent des droits d'accès corrects aux fichiers. Étend AbstractTestBase qui fournit l'injection du contexte Spring (@Autowired), le changement d'utilisateur (logon()) et l'initialisation du référentiel de test JCR.

Configuration du test

  • Beans Spring injectés : DataTransferTestService (crée les zones de test et les utilisateurs), DataTransferPageRest (contrôleur REST testé)
  • Deux utilisateurs de test (testUser1, testUser2) créés via DataTransferTestService
  • Référentiel de test JCR : initJCRTestRepo(MODUL_NAME, "accessTestRepo") — fournit un référentiel de contenu Jackrabbit isolé pour les tests de pièces jointes
  • Initialisation paresseuse : initialize() est appelée lors de la première utilisation (pas @PostConstruct — la base de données n'est pas encore prête à ce moment-là), crée la zone de test

Couverture des tests

Les tests utilisent DataTransferPageRest directement — le contrôleur REST interne (pas celui public au #100) — pour vérifier la logique de contrôle d'accès au niveau de l'API :

  • Accès administrateur : testUser1 défini comme administrateur — doit avoir un accès CRUD complet sur la zone
  • Accès groupe : testUser2 ajouté à accessGroupIds — doit avoir accès aux fichiers
  • Accès au niveau utilisateur : utilisateurs spécifiques dans accessUserIds peuvent accéder aux fichiers
  • Absence d'accès : les utilisateurs ne figurant dans aucune liste d'accès doivent se voir refuser l'accès
  • Accès public : vérifie que les indicateurs external_download_enabled / external_upload_enabled fonctionnent

Dépendances

  • DataTransferPageRest — le contrôleur REST interne testé
  • DataTransferTestService — assistant de test qui pré-remplit la base de données et JCR
  • AbstractTestBase — base de test Spring Boot de ProjectForge (annulation de transaction DB, simulation utilisateur)
  • FileObject (JCR) — objets fichier simulés pour les tests de pièces jointes
