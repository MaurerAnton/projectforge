#115: DataTransferAccessTest.kt

Интеграционный тест для контроля доступа DataTransfer — проверяет, что администраторы, участники групп и отдельные пользователи имеют корректные права доступа к файлам. Расширяет AbstractTestBase, который обеспечивает внедрение контекста Spring (@Autowired), переключение пользователей (logon()) и инициализацию тестового репозитория JCR.

Настройка теста

  • Внедрённые Spring-бины: DataTransferTestService (создаёт тестовые области и пользователей), DataTransferPageRest (тестируемый REST-контроллер)
  • Два тестовых пользователя (testUser1, testUser2) созданы через DataTransferTestService
  • Тестовый репозиторий JCR: initJCRTestRepo(MODUL_NAME, "accessTestRepo") — предоставляет изолированный репозиторий контента Jackrabbit для тестирования вложений
  • Ленивая инициализация: initialize() вызывается при первом использовании (не @PostConstruct — база данных в этот момент ещё не готова), создаёт тестовую область

Покрытие тестами

Тесты используют DataTransferPageRest напрямую — внутренний REST-контроллер (не публичный из #100) — для проверки логики контроля доступа на уровне API:

  • Доступ администратора: testUser1 назначен администратором — должен иметь полный CRUD в области
  • Доступ группы: testUser2 добавлен в accessGroupIds — должен иметь доступ к файлам
  • Доступ на уровне пользователя: конкретные пользователи в accessUserIds могут получать доступ к файлам
  • Отсутствие доступа: пользователям, не входящим ни в один список доступа, должно быть отказано
  • Публичный доступ: проверяет работу флагов external_download_enabled / external_upload_enabled

Зависимости

  • DataTransferPageRest — тестируемый внутренний REST-контроллер
  • DataTransferTestService — тестовый помощник, предварительно заполняющий БД и JCR
  • AbstractTestBase — тестовая база Spring Boot от ProjectForge (откат транзакций БД, симуляция пользователей)
  • FileObject (JCR) — имитация файловых объектов для тестов вложений
