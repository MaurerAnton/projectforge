1162: VacationStatus.kt

Enum (Java source, no Kotlin file found), projectforge-business/src/main/java/org/projectforge/business/vacation/model/VacationStatus.java
Enumeration of vacation request statuses: APPROVED, REJECTED, IN_PROGRESS — implementing I18nEnum for localized display labels.

Definition

A simple three-value enum with i18n key generation. Each constant maps to a key suffix used for composing the full i18n key "vacation.status.{key}":

  • APPROVED → key "approved" → i18n key "vacation.status.approved"
  • REJECTED → key "rejected" → i18n key "vacation.status.rejected"
  • IN_PROGRESS → key "inProgress" → i18n key "vacation.status.inProgress"

Usage

Referenced throughout the vacation system: VacationDO.status field (persisted as VARCHAR via @Enumerated(EnumType.STRING)), VacationDao's access control state machine, VacationService's statistics filtering, VacationSendMailService's notification logic, and VacationFilter's search criteria.

Design Rationale

Implements I18nEnum to provide consistent localization across the application's i18n framework (Wicket, REST, mail templates). String-based persistence prevents ordinal fragility when reordering enum constants. The three-value model reflects German labor law where vacation requests pass through submission (IN_PROGRESS), approval (APPROVED), or rejection (REJECTED).
