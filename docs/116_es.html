Prueba de integración para DataTransferAuditDao — verifica la gestión de colas del DAO de registro de auditoría, el seguimiento de notificaciones y la recuperación de entradas. Extiende AbstractTestBase con DAOs autoconectados de Spring y recreateDataBase() para aislamiento de pruebas.

Métodos de prueba (del análisis de código fuente)

  • removeFromQueueTest() — crea entradas de auditoría con diferentes marcas de tiempo, verifica que internalGetEntriesByAreaId() devuelve las 3, luego prueba la lógica de recuperación de cola: las entradas más antiguas que un umbral deberían ser elegibles para notificación, las entradas recientes deberían permanecer en cola
  • Las pruebas usan PFDateTime.now().minus(D, ChronoUnit.DAYS/MINUTES) para simular entradas de auditoría con desplazamiento temporal
  • internalGetQueuedEntriesByAreaId() — consulta filtrada que devuelve solo entradas pendientes de notificación
  • Verifica la transición de la bandera notified: en cola → notificado → eliminado de la cola

Configuración de la prueba

  • @Autowired DataTransferAuditDao — el DAO bajo prueba (gestiona la tabla t_plugin_datatransfer_audit)
  • @Autowired DataTransferAreaDao — inyectado solo para satisfacer la dependencia DataTransferAuditDao.dataTransferAreaDao
  • override fun beforeAll() — llama a recreateDataBase() para limpiar cualquier dato de prueba de otras clases de prueba
  • init { DataTransferTestService.addPluginEntitiesForTestMode() } — registra las entidades del plugin con la capa de persistencia

Sistema de cola de auditoría

La cola de auditoría es el mecanismo para las notificaciones de observadores (ver plantilla de correo #112):

  1. Las acciones sobre archivos (subir/descargar/eliminar) llaman a dataTransferAuditDao.insert() con notified=false
  2. Un trabajo programado llama a internalGetQueuedEntriesByAreaId() para encontrar entradas no notificadas
  3. Después de enviar correos electrónicos, el trabajo marca las entradas como notified=true (a través de removeFromQueue())
  4. Las entradas antiguas (>30 días) se purgan periódicamente
