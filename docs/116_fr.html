Test d'intégration pour DataTransferAuditDao — vérifie la gestion de la file d'attente du DAO de journal d'audit, le suivi des notifications et la récupération des entrées. Étend AbstractTestBase avec des DAO autowired Spring et recreateDataBase() pour l'isolation des tests.

Méthodes de test (d'après l'analyse du code source)

  • removeFromQueueTest() — crée des entrées d'audit avec différents horodatages, vérifie que internalGetEntriesByAreaId() retourne les 3 entrées, puis teste la logique de récupération de la file d'attente : les entrées plus anciennes qu'un seuil doivent être éligibles à la notification, les entrées récentes doivent rester en file d'attente
  • Les tests utilisent PFDateTime.now().minus(D, ChronoUnit.DAYS/MINUTES) pour simuler des entrées d'audit décalées dans le temps
  • internalGetQueuedEntriesByAreaId() — requête filtrée retournant uniquement les entrées en attente de notification
  • Vérifie la transition du drapeau notified : en file d'attente → notifié → retiré de la file d'attente

Configuration du test

  • @Autowired DataTransferAuditDao — le DAO testé (gère la table t_plugin_datatransfer_audit)
  • @Autowired DataTransferAreaDao — injecté uniquement pour satisfaire la dépendance DataTransferAuditDao.dataTransferAreaDao
  • override fun beforeAll() — appelle recreateDataBase() pour effacer toute donnée de test provenant d'autres classes de test
  • init { DataTransferTestService.addPluginEntitiesForTestMode() } — enregistre les entités du plugin auprès de la couche de persistance

Système de file d'attente d'audit

La file d'attente d'audit est le mécanisme pour les notifications des observateurs (voir modèle de courriel #112) :

  1. Les actions sur les fichiers (téléchargement/téléversement/suppression) appellent dataTransferAuditDao.insert() avec notified=false
  2. Un travail planifié appelle internalGetQueuedEntriesByAreaId() pour trouver les entrées non notifiées
  3. Après l'envoi des courriels, le travail marque les entrées comme notified=true (via removeFromQueue())
  4. Les anciennes entrées (>30 jours) sont purgées périodiquement
