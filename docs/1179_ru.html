#1179: ToStringUtil.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/ToStringUtil.kt Сервис, projectforge-business/src/main/kotlin/org/projectforge/framework/ToStringUtil.kt 355 строк · 276 кода · 44 комментария · 35 пустых
Фреймворк JSON-сериализации для методов toString(). Обеспечивает кэширование ObjectMapper со встроенными сериализаторами для ключевых доменных объектов (PFUserDO, GroupDO, TaskDO, ProjektDO, KundeDO, Kost1DO/Kost2DO, EmployeeDO, AddressbookDO). Включает классы сериализаторов для Date, Timestamp, LocalDate, LocalTime, PFDateTime и обработку Hibernate-прокси. Поддерживает конфигурацию предпочтения встроенных сериализаторов против вывода только идентификаторов.
