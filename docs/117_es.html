Prueba de integración para DataTransferJCRCleanUpJob — el trabajo programado que elimina archivos cuya fecha de vencimiento ha pasado. Prueba el ciclo de vida del archivo: crear → expirar → verificar eliminación. Utiliza el repositorio de prueba JCR mediante initJCRTestRepo(MODUL_NAME, "cleanUpTestRepo").

Flujo de la prueba

  1. Configura un usuario de prueba con un área configurada con expiryDays
  2. Sube archivos de prueba al área a través de JCR RepoService
  3. Simula el paso del tiempo — establece fechas de creación de archivos en el pasado más allá del umbral de vencimiento
  4. Ejecuta DataTransferJCRCleanUpJob.execute()
  5. Verifica que los archivos vencidos se eliminen de JCR y que attachments_counter disminuya
  6. Verifica que los archivos no vencidos permanezcan intactos

Dependencias clave

  • DataTransferJCRCleanUpJob — el trabajo programado bajo prueba (implementa JobHandler)
  • RepoService — repositorio JCR (Apache Jackrabbit) para almacenamiento de archivos
  • DataTransferAreaDao, DataTransferAreaDO — datos del área (contiene expiryDays)
  • DataTransferAreaPagesRest — controlador REST utilizado para consultar archivos
  • FileObject — objeto de dominio JCR que representa un archivo almacenado
