Test d'intégration pour DataTransferJCRCleanUpJob — la tâche planifiée qui supprime les fichiers dont la date d'expiration est dépassée. Teste le cycle de vie des fichiers : création → expiration → vérification de la suppression. Utilise le référentiel de test JCR via initJCRTestRepo(MODUL_NAME, "cleanUpTestRepo").

Déroulement du test

  1. Configure un utilisateur de test avec une zone configurée avec expiryDays
  2. Télécharge des fichiers de test dans la zone via le RepoService JCR
  3. Simule le passage du temps — définit les dates de création des fichiers dans le passé au-delà du seuil d'expiration
  4. Exécute DataTransferJCRCleanUpJob.execute()
  5. Vérifie que les fichiers expirés sont supprimés du JCR et que attachments_counter est décrémenté
  6. Vérifie que les fichiers non expirés restent intacts

Dépendances clés

  • DataTransferJCRCleanUpJob — la tâche planifiée testée (implémente JobHandler)
  • RepoService — référentiel JCR (Apache Jackrabbit) pour le stockage des fichiers
  • DataTransferAreaDao, DataTransferAreaDO — données de zone (contient expiryDays)
  • DataTransferAreaPagesRest — contrôleur REST utilisé pour interroger les fichiers
  • FileObject — objet domaine JCR représentant un fichier stocké
