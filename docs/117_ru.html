Интеграционный тест для DataTransferJCRCleanUpJob — запланированной задачи, которая удаляет файлы с истекшим сроком хранения. Тестирует жизненный цикл файла: создание → истечение срока → проверка удаления. Использует тестовое JCR-хранилище через initJCRTestRepo(MODUL_NAME, "cleanUpTestRepo").

Поток тестирования

  1. Настраивает тестового пользователя с областью, настроенной с expiryDays
  2. Загружает тестовые файлы в область через JCR RepoService
  3. Имитирует течение времени — устанавливает даты создания файлов в прошлом, за пределами порога истечения
  4. Запускает DataTransferJCRCleanUpJob.execute()
  5. Проверяет, что файлы с истекшим сроком удалены из JCR и attachments_counter уменьшен
  6. Проверяет, что файлы с неистекшим сроком остались нетронутыми

Ключевые зависимости

  • DataTransferJCRCleanUpJob — тестируемая запланированная задача (реализует JobHandler)
  • RepoService — JCR-хранилище (Apache Jackrabbit) для хранения файлов
  • DataTransferAreaDao, DataTransferAreaDO — данные области (содержит expiryDays)
  • DataTransferAreaPagesRest — REST-контроллер для запросов к файлам
  • FileObject — доменный объект JCR, представляющий сохранённый файл
