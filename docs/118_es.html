Prueba de integración de extremo a extremo para el sistema de correo de notificación de observadores — ejercita el pipeline completo: crear área con observadores → subir archivos → ejecutar trabajo de notificación → verificar contenido del correo. La prueba más grande de DataTransfer con 205 líneas. Utiliza autoconfiguración de Spring, repositorio de prueba JCR y representación de plantillas de correo Groovy.

Flujo de la prueba

  1. Crea dos usuarios de prueba (user1 = administrador del área, user2 = observador)
  2. Crea un área de transferencia de datos con user2 como observador (observerIds) y user2.userWantsToObserve = true
  3. user1 sube varios archivos, generando entradas de auditoría
  4. user1 renombra un archivo — verifica que filename_old se conserva en la auditoría
  5. user1 elimina un archivo — verifica que se registró el evento de eliminación
  6. Ejecuta DataTransferNotificationJob que:
    • Consulta entradas de auditoría con notified=false
    • Representa la plantilla Freemarker dataTransferMail.html con datos de auditoría
    • Utiliza DomainService para generar la URL del enlace del área
    • Marca las entradas como notified=true
  7. Verifica el contenido del correo: comprueba que message (cadena i18n de plugin i18n), tabla de auditoría (columnas: Fecha, Nombre de archivo, Descripción, Acción, Usuario), tabla de eventos de descarga y botón de enlace están todos presentes

Afirmaciones de contenido del correo

  • Utiliza StringUtils — verifica que el cuerpo del correo contiene las cadenas traducibles esperadas de DataTransferI18nResources.properties
  • Verifica que aparece el encabezado de sección pf.getI18nString("plugins.datatransfer.audit.downloadEvents")
  • Verifica que aparece la etiqueta del botón "plugins.datatransfer.mail.link"
  • La URL del dominio utiliza DomainService.getDomain() (ej. https://your-server.com/) + PagesResolver.getPageUrl()

Dependencias

  • DataTransferPageRest — controlador REST interno para operaciones CRUD
  • DataTransferAreaDO, DataTransferAuditDao — persistencia de área y auditoría
  • AttachmentsService — operaciones de archivos JCR (respaldado por repositorio de prueba)
  • DomainService — resuelve la URL base del servidor para enlaces de correo
  • PagesResolver — construye URLs de páginas frontend
  • DataTransferNotificationJob — el trabajo bajo prueba (programación de notificaciones)
