Test d'intégration de bout en bout pour le système de notification par e-mail des observateurs — exécute le pipeline complet : créer une zone avec des observateurs → télécharger des fichiers → exécuter le job de notification → vérifier le contenu de l'e-mail. Le plus grand test DataTransfer avec 205 lignes. Utilise l'autowiring Spring, le référentiel de test JCR et le rendu de modèle Groovy.

Déroulement du test

  1. Crée deux utilisateurs de test (user1 = administrateur de zone, user2 = observateur)
  2. Crée une zone de transfert de données avec user2 comme observateur (observerIds) et user2.userWantsToObserve = true
  3. user1 télécharge plusieurs fichiers, déclenchant des entrées d'audit
  4. user1 renomme un fichier — vérifie que filename_old est conservé dans l'audit
  5. user1 supprime un fichier — vérifie que l'événement de suppression est enregistré
  6. Exécute DataTransferNotificationJob qui :
    • Interroge les entrées d'audit avec notified=false
    • Génère le modèle Freemarker dataTransferMail.html avec les données d'audit
    • Utilise DomainService pour générer l'URL du lien de la zone
    • Marque les entrées comme notified=true
  7. Vérifie le contenu de l'e-mail : s'assure que le message (chaîne i18n provenant du plugin i18n), le tableau d'audit (colonnes : Date, Nom du fichier, Description, Action, Utilisateur), le tableau des événements de téléchargement et le bouton de lien sont tous présents

Assertions sur le contenu de l'e-mail

  • Utilise StringUtils — vérifie que le corps de l'e-mail contient les chaînes traduisibles attendues depuis DataTransferI18nResources.properties
  • Vérifie que l'en-tête de section pf.getI18nString("plugins.datatransfer.audit.downloadEvents") apparaît
  • Vérifie que le libellé du bouton "plugins.datatransfer.mail.link" apparaît
  • L'URL du domaine utilise DomainService.getDomain() (ex. https://votre-serveur.com/) + PagesResolver.getPageUrl()

Dépendances

  • DataTransferPageRest — contrôleur REST interne pour les opérations CRUD
  • DataTransferAreaDO, DataTransferAuditDao — persistance des zones et des audits
  • AttachmentsService — opérations sur les fichiers JCR (basées sur le référentiel de test)
  • DomainService — résout l'URL de base du serveur pour les liens e-mail
  • PagesResolver — construit les URL des pages frontend
  • DataTransferNotificationJob — le job testé (planification des notifications)
