#118: DataTransferNotificationMailTest.kt

plugins/org.projectforge.plugins.datatransfer/src/test/kotlin/org/projectforge/plugins/datatransfer/DataTransferNotificationMailTest.kt Путь: plugins/...datatransfer/src/test/kotlin/.../DataTransferNotificationMailTest.kt · Строк: 205 · Тип: Интеграционный тест Kotlin JUnit 5 205 строк · 171 код · 22 комментария · 12 пустых

Сквозной интеграционный тест для системы уведомлений наблюдателей по почте — проверяет полный конвейер: создание области с наблюдателями → загрузка файлов → запуск задания уведомления → проверка содержимого письма. Самый большой тест DataTransfer (205 строк). Использует Spring-автосвязывание, тестовое JCR-репозиторий и рендеринг почтовых шаблонов Groovy.

Поток теста

  1. Создаёт двух тестовых пользователей (user1 = администратор области, user2 = наблюдатель)
  2. Создаёт область передачи данных с user2 в качестве наблюдателя (observerIds) и user2.userWantsToObserve = true
  3. user1 загружает несколько файлов, что вызывает записи аудита
  4. user1 переименовывает файл — проверяет, что filename_old сохраняется в аудите
  5. user1 удаляет файл — проверяет, что событие удаления зафиксировано
  6. Запускает DataTransferNotificationJob, который:
    • Запрашивает записи аудита с notified=false
    • Рендерит шаблон Freemarker dataTransferMail.html с данными аудита
    • Использует DomainService для генерации URL ссылки на область
    • Помечает записи как notified=true
  7. Проверяет содержимое письма: убеждается, что message (i18n-строка из i18n плагина), таблица аудита (колонки: Дата, Имя файла, Описание, Действие, Пользователь), таблица событий загрузки и кнопка-ссылка присутствуют

Проверки содержимого письма

  • Использует StringUtils — проверяет, что тело письма содержит ожидаемые переводимые строки из DataTransferI18nResources.properties
  • Проверяет появление заголовка раздела pf.getI18nString("plugins.datatransfer.audit.downloadEvents")
  • Проверяет появление текста кнопки "plugins.datatransfer.mail.link"
  • URL домена использует DomainService.getDomain() (например, https://your-server.com/) + PagesResolver.getPageUrl()

Зависимости

  • DataTransferPageRest — внутренний REST-контроллер для CRUD-операций
  • DataTransferAreaDO, DataTransferAuditDao — персистентность областей и аудита
  • AttachmentsService — операции с файлами JCR (на базе тестового репозитория)
  • DomainService — определяет базовый URL сервера для ссылок в письмах
  • PagesResolver — формирует URL страниц фронтенда
  • DataTransferNotificationJob — тестируемое задание (планирование уведомлений)
