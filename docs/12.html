File #12: docker/compose/.env

Path: ./docker/compose/.env · Type: Docker Compose environment file · Lines: 8 · Source: GitHub

What it does

This file provides default environment variables for docker-compose.yml. Docker Compose automatically reads .env from the same directory and substitutes ${VARIABLE} references in the compose file.

The file is deliberately committed to the repository — it contains default/placeholder values suitable for development. In production, you override these via a local .env.local or shell export.

⚠️ Important: Line 2 contains a dummy password (supersecurepassword) — this is a development default, not a production secret. In production, override this via environment or a separate .env.production file that is never committed.

Key takeaways

  • 8 lines, all defaults: Deliberately committed with placeholder values — not production secrets.
  • DB credentials are shared: Both projectforge-app AND projectforge-db use the same POSTGRES_* variables — the DB container creates the user, the app container connects with it.
  • APP_PORT=8080: This is the Spring Boot default — consistent with the build config and the embedded HSQLDB dev setup.
  • Production override: docker compose --env-file .env.production up or shell export POSTGRES_PASSWORD=... before docker compose up.
