#1207: AbstractJob.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/jobs/AbstractJob.kt Каркас заданий, projectforge-business/src/main/kotlin/org/projectforge/framework/jobs/AbstractJob.kt 429 строк · 280 кода · 93 комментария · 56 пустых
Абстрактный базовый класс для фоновых заданий в ProjectForge. Поддерживает стратегии постановки в очередь (нет, по очереди, по очереди и пользователю, отказ), опциональный тайм-аут (по умолчанию 120 с), отслеживание прогресса (общее/обработанное количество) и отмену через корутины Kotlin. Задания имеют жизненный цикл и предоставляют readAccess / writeAccess для проверки прав. Интегрируется с UserGroupCache для отображения владельца.

Архитектура

Иерархия классов

  • AbstractJob — абстрактный класс, реализующий Comparable<AbstractJob>
  • Подклассы должны реализовать suspend fun run()

Жизненный цикл задания

Жизненный цикл управляется JobHandler:

  1. addJob() — задание добавлено в обработчик, статус = WAITING
  2. Проверка очереди — сравнение с выполняющимися заданиями через isBlocking()
  3. onBeforeStart() — хук перед выполнением
  4. start() — устанавливает статус RUNNING, вызывает run()
  5. При успехе: onFinish() → onAfterFinish() → onAfterTermination()
  6. При отмене: cancel() → onBeforeCancel() → onAfterCancel() → onAfterTermination()
  7. При сбое: markJobAsFailed() → onAfterException() → onAfterTermination()

Права доступа

  • readAccess(user) — по умолчанию делегирует writeAccess(user)
  • writeAccess(user) — абстрактный, должен быть реализован подклассом
  • isOwner — проверяет, совпадает ли текущий вошедший пользователь с ownerId

Точки интеграции

  • JobHandler — управляет заданиями, вызывает методы жизненного цикла
  • JobHandlerScheduler — запускает tidyUp() каждую минуту
  • AccessChecker — внедряется через @Autowired
  • Корутины — дескриптор Job хранится как coroutinesJob
  • I18n — метки статусов через I18nEnum.i18nKey
