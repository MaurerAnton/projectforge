#1209: JobHandlerScheduler.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/jobs/JobHandlerScheduler.kt Spring Component / Scheduler, projectforge-business/src/main/kotlin/org/projectforge/framework/jobs/JobHandlerScheduler.kt 43 Zeilen · 16 Code · 23 Kommentare · 4 leer
Spring @Scheduled-Komponente, die JobHandler.tidyUp() jede Minute mit einer anfänglichen Verzögerung von 1 Minute auslöst. Jede Ausführung läuft in einem separaten Thread, um den Spring-Scheduler-Thread nicht zu blockieren.

Architektur

Klassendetails

  • @Component — Spring-verwalteter Singleton
  • Injiziert JobHandler über @Autowired
  • Einzelne Methode: execute()

Planung (Scheduling)

AnnotationWert
@Scheduled(fixedDelay)Constants.MILLIS_PER_MINUTE
@Scheduled(initialDelay)Constants.MILLIS_PER_MINUTE

Thread-Modell

Die Methode execute() startet einen neuen Thread { jobHandler.tidyUp() }.start(), um sicherzustellen, dass der Spring-Scheduler-Thread niemals durch potenziell langlaufende Bereinigungsvorgänge blockiert wird.
