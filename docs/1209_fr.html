Composant Spring @Scheduled qui déclenche JobHandler.tidyUp() chaque minute avec un délai initial d'une minute. Chaque exécution s'effectue dans un thread séparé pour éviter de bloquer le thread du planificateur Spring.

Architecture

Détails de la classe

  • @Component — Singleton géré par Spring
  • Injecte JobHandler via @Autowired
  • Méthode unique : execute()

Planification

AnnotationValeur
@Scheduled(fixedDelay)Constants.MILLIS_PER_MINUTE
@Scheduled(initialDelay)Constants.MILLIS_PER_MINUTE

Modèle de threads

La méthode execute() lance un nouveau Thread { jobHandler.tidyUp() }.start() pour garantir que le thread du planificateur Spring ne soit jamais bloqué par des opérations de nettoyage potentiellement longues.
