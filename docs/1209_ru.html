Spring @Scheduled компонент, который запускает JobHandler.tidyUp() каждую минуту с начальной задержкой в 1 минуту. Каждое выполнение запускается в отдельном потоке, чтобы не блокировать поток планировщика Spring.

Архитектура

Детали класса

  • @Component — управляемый Spring синглтон
  • Внедряет JobHandler через @Autowired
  • Единственный метод: execute()

Планирование

АннотацияЗначение
@Scheduled(fixedDelay)Constants.MILLIS_PER_MINUTE
@Scheduled(initialDelay)Constants.MILLIS_PER_MINUTE

Модель потоков

Метод execute() создаёт новый поток Thread { jobHandler.tidyUp() }.start(), чтобы гарантировать, что поток планировщика Spring никогда не будет заблокирован потенциально долгими операциями очистки.
