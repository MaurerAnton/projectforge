Интеграционный тест для публичного (внешнего) REST-слоя DataTransfer — самый полный тест DataTransfer на 227 строк. Тестирует поток анонимного доступа: внешняя ссылка → вход → загрузка/скачивание/удаление → выход, с использованием имитированных HTTP-запросов и JCR-файлов.

Тестируемые компоненты

  • DataTransferPublicSession (#101) — управление сессиями, защита от перебора
  • DataTransferPublicPageRest — возвращает JSON макета страницы для анонимного React-интерфейса
  • DataTransferPublicServicesRest (#100) — конечные точки загрузки, скачивания, удаления, множественной загрузки
  • LoginProtection — принудительная временная задержка при переборе паролей

Тестовые сценарии (~10 тестовых методов)

  • Вход с действительными учётными данными: создаёт область с external_download_enabled=true, externalAccessToken, externalPassword, вызывает DataTransferPublicSession.login() — проверяет, что сессия содержит данные области
  • Вход с неверным паролем: проверяет, что LoginProtection увеличивает счётчик неудачных попыток, и после повторных неудач срабатывает временная задержка
  • Блокировка при переборе: после достаточного количества неудач login() возвращает статус LOGIN_TIME_OFFSET — проверяется вызовом login 3+ раз быстрее, чем окно задержки
  • Личный ящик исключён из публичного доступа: области с isPersonalBox() всегда возвращают LoginResultStatus.FAILED — параноидальная проверка в checkDataBaseEntry()
  • Загрузка: имитирует MultipartFile (обёртка загруженного файла Spring), вызывает конечную точку загрузки REST, проверяет, что ID файла появляется в списке ownedFiles
  • Скачивание: загружает файл как внешний пользователь, затем скачивает его — проверяет соответствие содержимого InputStreamResource
  • Удаление собственного файла: проверяет, что isOwnerOfFile() возвращает true, и удаление выполняется успешно
  • Невозможность удалить чужой файл: внешний пользователь2 пытается удалить загрузку пользователя1 — проверяет, что isOwnerOfFile() возвращает false
  • Множественное скачивание: загрузить 3 файла, скачать все как ZIP — проверяет, что ZipInputStream содержит все 3 записи
  • Фиксация сессии: проверяет, что после входа JSESSIONID изменяется (старая сессия аннулируется, создаётся новая с перенесёнными данными области)

Имитированный HTTP-слой

Использует Mockito для имитации HttpServletRequest и HttpSession — это критично, поскольку DataTransferPublicSession хранит данные напрямую в атрибутах HTTP-сессии. Имитированная сессия симулирует getSession(false), getSession(true), getAttribute("transferAreas"), setAttribute() и invalidate() — всё это используется в тесте фиксации сессии.

Также имитируются MultipartFile для тестов загрузки и HttpServletResponse + ServletOutputStream → ByteArrayOutputStream для захвата содержимого при скачивании.
