#121: build.gradle.kts

Path: plugins/org.projectforge.plugins.ihk/build.gradle.kts · Lines: 20 · Type: Gradle Kotlin DSL build script

Build configuration for the IHK plugin (Industrie- und Handelskammer — German Chamber of Commerce apprenticeship reports).

Dependencies

  • projectforge-wicket (api) — plugin uses Apache Wicket for its UI (IHKForm, IHKPage)
  • projectforge-rest (api) — REST endpoint for Excel download
  • projectforge-business (testImplementation) — access to TimesheetDO, AddressDO in tests only

Plugins

  • buildlogic.pf-module-conventions — applies standard ProjectForge module settings (Kotlin compilation, licensing, publishing)
  • org.jetbrains.kotlin.jvm — Kotlin compilation targeting JVM 17

Architecture note

This plugin is notable for being written in Java (all other plugins are Kotlin). The kotlin.jvm plugin is still applied because the convention plugin requires it — the actual source code is in src/main/java/ not src/main/kotlin/.
