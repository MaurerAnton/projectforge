Envoltorio de resultado genérico simple para operaciones de trabajo. Encapsula un estado (OK/ERROR), un objeto resultado de tipo T y una cadena de error opcional.

Arquitectura

Resumen de la clase

CampoTipoDescripción
statusStatus?OK o ERROR; se establece mediante setStatus() fluido
resultObjectT?Carga útil de resultado genérico; se establece mediante setResultObject()
errorStringString?Descripción del error; se establece mediante setErrorString()

API fluida

Todos los setters devuelven JobResult<T> para encadenamiento: JobResult<Foo>().setStatus(Status.OK).setResultObject(foo)
