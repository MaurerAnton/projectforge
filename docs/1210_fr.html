Wrapper de résultat générique simple pour les opérations de tâche. Encapsule un statut (OK/ERREUR), un objet résultat de type T, et une chaîne d'erreur optionnelle.

Architecture

Résumé de la classe

ChampTypeDescription
statusStatus?OK ou ERREUR ; défini via setStatus() fluide
resultObjectT?Charge utile générique du résultat ; défini via setResultObject()
errorStringString?Description de l'erreur ; définie via setErrorString()

API fluide

Tous les mutateurs retournent JobResult<T> pour le chaînage : JobResult<Foo>().setStatus(Status.OK).setResultObject(foo)
