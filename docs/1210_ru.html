Простая универсальная обёртка результата для операций заданий. Инкапсулирует статус (OK/ERROR), объект результата типа T и необязательную строку ошибки.

Архитектура

Сводка класса

ПолеТипОписание
statusStatus?OK или ERROR; устанавливается через текучий setStatus()
resultObjectT?Универсальная полезная нагрузка результата; устанавливается через setResultObject()
errorStringString?Описание ошибки; устанавливается через setErrorString()

Текучий API

Все сеттеры возвращают JobResult<T> для цепочечного вызова: JobResult<Foo>().setStatus(Status.OK).setResultObject(foo)
