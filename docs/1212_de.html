#1212: IdOnlySerializer.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdOnlySerializer.kt JSON-Serializer, projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdOnlySerializer.kt 67 Zeilen · 37 Code · 24 Kommentare · 6 leer
Jackson JsonSerializer<IdObject<*>>, der Entitätsreferenzen in ein kompaktes {"id": ...} JSON-Objekt serialisiert. Konsultiert JsonThreadLocalContext, um das Verhalten zu bestimmen: Wenn preferEmbeddedSerializers oder ignoreIdOnlySerializers gesetzt ist, wird auf die vollständige Serialisierung oder einen anderen registrierten Serializer zurückgegriffen. Verhindert standardmäßig tiefe Objektgraphen.

Architektur

Entscheidungsbaum für die Serialisierung

  1. Wenn value == null: null schreiben
  2. Wenn JsonThreadLocalContext.get() != null:
    • Wenn preferEmbeddedSerializers == true und ein anderer Serializer für die Klasse existiert: diesen verwenden
    • Wenn ignoreIdOnlySerializers == true: Jacksons Standard-Serialisierung verwenden
  3. Standard: {"id": value.id} schreiben (id kann null sein, wird als entsprechender JSON-Typ über JsonUtils.writeField geschrieben)

Integration

  • Global in der Jackson ObjectMapper-Konfiguration verwendet
  • writeObject() des Begleitobjekts wird mit IdsOnlySerializer geteilt
  • JsonThreadLocalContext bietet threadspezifische Überschreibungsflags für die Serialisierung
