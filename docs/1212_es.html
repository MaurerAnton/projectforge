#1212: IdOnlySerializer.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdOnlySerializer.kt Serializador JSON, projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdOnlySerializer.kt 67 líneas · 37 código · 24 comentarios · 6 en blanco
Jackson JsonSerializer<IdObject<*>> que serializa referencias de entidades a un objeto JSON compacto {"id": ...}. Consulta JsonThreadLocalContext para determinar el comportamiento: si preferEmbeddedSerializers o ignoreIdOnlySerializers está activado, recurre a la serialización completa o a otro serializador registrado. Evita grafos de objetos profundos por defecto.

Arquitectura

Árbol de decisión de serialización

  1. Si value == null: escribe null
  2. Si JsonThreadLocalContext.get() != null:
    • Si preferEmbeddedSerializers == true y existe otro serializador para la clase: lo usa
    • Si ignoreIdOnlySerializers == true: usa la serialización por defecto de Jackson
  3. Por defecto: escribe {"id": value.id} (id puede ser null, escrito como tipo JSON apropiado mediante JsonUtils.writeField)

Integración

  • Usado globalmente en la configuración de Jackson ObjectMapper
  • El writeObject() del objeto complementario se comparte con IdsOnlySerializer
  • JsonThreadLocalContext proporciona banderas de anulación de serialización por hilo
