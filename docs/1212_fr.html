#1212 : IdOnlySerializer.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdOnlySerializer.kt Sérialiseur JSON, projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdOnlySerializer.kt 67 lignes · 37 code · 24 commentaires · 6 vides
Jackson JsonSerializer<IdObject<*>> qui sérialise les références d'entités en un objet JSON compact {"id": ...}. Consulte JsonThreadLocalContext pour déterminer le comportement : si preferEmbeddedSerializers ou ignoreIdOnlySerializers est défini, il revient à la sérialisation complète ou à un autre sérialiseur enregistré. Empêche les graphes d'objets profonds par défaut.

Architecture

Arbre de décision de sérialisation

  1. Si value == null : écrire null
  2. Si JsonThreadLocalContext.get() != null :
    • Si preferEmbeddedSerializers == true et qu'un autre sérialiseur existe pour la classe : l'utiliser
    • Si ignoreIdOnlySerializers == true : utiliser la sérialisation par défaut de Jackson
  3. Par défaut : écrire {"id": value.id} (id peut être null, écrit comme type JSON approprié via JsonUtils.writeField)

Intégration

  • Utilisé globalement dans la configuration ObjectMapper de Jackson
  • Le writeObject() de l'objet compagnon partagé avec IdsOnlySerializer
  • JsonThreadLocalContext fournit des indicateurs de remplacement de sérialisation par thread
