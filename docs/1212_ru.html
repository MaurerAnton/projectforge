#1212: IdOnlySerializer.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdOnlySerializer.kt JSON-сериализатор, projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdOnlySerializer.kt 67 строк · 37 кода · 24 комментария · 6 пустых
Jackson JsonSerializer<IdObject<*>>, который сериализует ссылки на сущности в компактный JSON-объект {"id": ...}. Обращается к JsonThreadLocalContext для определения поведения: если установлены preferEmbeddedSerializers или ignoreIdOnlySerializers, выполняется полная сериализация или используется другой зарегистрированный сериализатор. По умолчанию предотвращает глубокие графы объектов.

Архитектура

Дерево принятия решений при сериализации

  1. Если value == null: записать null
  2. Если JsonThreadLocalContext.get() != null:
    • Если preferEmbeddedSerializers == true и существует другой сериализатор для класса: использовать его
    • Если ignoreIdOnlySerializers == true: использовать стандартную сериализацию Jackson
  3. По умолчанию: записать {"id": value.id} (id может быть null, записывается как соответствующий JSON-тип через JsonUtils.writeField)

Интеграция

  • Используется глобально в конфигурации Jackson ObjectMapper
  • Метод writeObject() объекта-компаньона используется совместно с IdsOnlySerializer
  • JsonThreadLocalContext предоставляет флаги переопределения сериализации для каждого потока
