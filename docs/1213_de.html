#1213: IdsOnlySerializer.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdsOnlySerializer.kt JSON-Serializer, projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdsOnlySerializer.kt 54 Zeilen · 27 Code · 24 Kommentare · 3 leer
Jackson JsonSerializer<Collection<*>>, der Sammlungen von IdObject-Entitäten als Arrays von {"id": ...}-Objekten serialisiert. Verwendet HibernateUtils.isFullyInitialized(), um zu prüfen, ob die Sammlung geladen ist; schreibt andernfalls null, um versehentliche Datenbankabfragen während der JSON-Serialisierung zu verhindern.

Architektur

Serialisierungslogik

  1. value == null: null schreiben
  2. !HibernateUtils.isFullyInitialized(value): null schreiben (verhindert verzögertes Laden)
  3. Andernfalls: Elemente durchlaufen; IdObject-Elemente verwenden IdOnlySerializer.writeObject(), andere verwenden die Standardserialisierung

Wichtige Details

  • HibernateUtils.isFullyInitialized() wird Hibernate.isInitialized() vorgezogen, da einige ManyToOne-Lazy-Objekte möglicherweise nicht vollständig geladen sind, selbst wenn Hibernate sie als initialisiert meldet
  • Delegiert die Serialisierung einzelner IdObject-Elemente an IdOnlySerializer.writeObject() (gemeinsame Begleitmethode)
