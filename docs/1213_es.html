#1213: IdsOnlySerializer.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdsOnlySerializer.kt Serializador JSON, projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdsOnlySerializer.kt 54 líneas · 27 código · 24 comentarios · 3 en blanco
Jackson JsonSerializer<Collection<*>> que serializa colecciones de entidades IdObject como arreglos de objetos {"id": ...}. Utiliza HibernateUtils.isFullyInitialized() para verificar si la colección está cargada; escribe null si no, evitando recuperaciones accidentales de la base de datos durante la serialización JSON.

Arquitectura

Lógica de serialización

  1. value == null: escribe null
  2. !HibernateUtils.isFullyInitialized(value): escribe null (evita recuperación perezosa)
  3. De lo contrario: itera elementos; los elementos IdObject usan IdOnlySerializer.writeObject(), otros usan serialización predeterminada

Detalles clave

  • HibernateUtils.isFullyInitialized() se prefiere sobre Hibernate.isInitialized() porque algunos objetos perezosos ManyToOne pueden no estar completamente cargados incluso cuando Hibernate los reporta como inicializados
  • Delega la serialización de elementos IdObject individuales a IdOnlySerializer.writeObject() (método compañero compartido)
