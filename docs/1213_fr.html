#1213 : IdsOnlySerializer.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdsOnlySerializer.kt Sérialiseur JSON, projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdsOnlySerializer.kt 54 lignes · 27 code · 24 commentaires · 3 vides
Jackson JsonSerializer<Collection<*>> qui sérialise les collections d'entités IdObject sous forme de tableaux d'objets {"id": ...}. Utilise HibernateUtils.isFullyInitialized() pour vérifier si la collection est chargée ; écrit null dans le cas contraire, empêchant les accès accidentels à la base de données pendant la sérialisation JSON.

Architecture

Logique de sérialisation

  1. value == null : écrit null
  2. !HibernateUtils.isFullyInitialized(value) : écrit null (empêche le chargement paresseux)
  3. Sinon : parcourt les éléments ; les éléments IdObject utilisent IdOnlySerializer.writeObject(), les autres utilisent la sérialisation par défaut

Détails clés

  • HibernateUtils.isFullyInitialized() est préféré à Hibernate.isInitialized() car certains objets paresseux ManyToOne peuvent ne pas être complètement chargés même lorsque Hibernate les signale comme initialisés
  • Délègue la sérialisation individuelle des éléments IdObject à IdOnlySerializer.writeObject() (méthode compagnon partagée)
