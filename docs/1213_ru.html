#1213: IdsOnlySerializer.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdsOnlySerializer.kt JSON-сериализатор, projectforge-business/src/main/kotlin/org/projectforge/framework/json/IdsOnlySerializer.kt 54 строки · 27 кода · 24 комментария · 3 пустых
Jackson JsonSerializer<Collection<*>>, который сериализует коллекции сущностей IdObject как массивы объектов {"id": ...}. Использует HibernateUtils.isFullyInitialized() для проверки загрузки коллекции; записывает null, если не загружена, предотвращая случайные обращения к базе данных во время JSON-сериализации.

Архитектура

Логика сериализации

  1. value == null: записать null
  2. !HibernateUtils.isFullyInitialized(value): записать null (предотвращает ленивую загрузку)
  3. Иначе: перебрать элементы; элементы IdObject используют IdOnlySerializer.writeObject(), остальные — стандартную сериализацию

Ключевые детали

  • HibernateUtils.isFullyInitialized() предпочтительнее Hibernate.isInitialized(), поскольку некоторые ленивые объекты ManyToOne могут быть не полностью загружены, даже если Hibernate сообщает о них как об инициализированных
  • Делегирует сериализацию отдельных элементов IdObject методу IdOnlySerializer.writeObject() (общий метод компаньона)
