#1214: JsonThreadLocalContext.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/JsonThreadLocalContext.kt Contexto de hilo local, projectforge-business/src/main/kotlin/org/projectforge/framework/json/JsonThreadLocalContext.kt 54 líneas · 23 código · 26 comentarios · 5 en blanco
Contexto de hilo local que controla el comportamiento de serialización JSON de IdOnlySerializer. Proporciona dos indicadores booleanos: preferEmbeddedSerializers (usa serialización completa si está disponible) y ignoreIdOnlySerializers (usa el valor predeterminado de Jackson). Gestionado mediante set(), get(), clear() estáticos en un ThreadLocal.

Arquitectura

Indicadores

IndicadorPredeterminadoEfecto en IdOnlySerializer
preferEmbeddedSerializersfalseSi es true, intenta encontrar otro serializador Jackson registrado para la clase de entidad
ignoreIdOnlySerializersfalseSi es true, usa la serialización de objetos predeterminada de Jackson

Patrón de uso

JsonThreadLocalContext.set(preferEmbeddedSerializers = true)
try {
    JsonUtils.toJson(someEntity) // serializará completamente
} finally {
    JsonThreadLocalContext.clear()
}
