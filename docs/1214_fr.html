projectforge-business/src/main/kotlin/org/projectforge/framework/json/JsonThreadLocalContext.kt Contexte thread-local, projectforge-business/src/main/kotlin/org/projectforge/framework/json/JsonThreadLocalContext.kt 54 lignes · 23 code · 26 commentaires · 5 vides
Contexte thread-local contrôlant le comportement de sérialisation JSON de IdOnlySerializer. Fournit deux indicateurs booléens : preferEmbeddedSerializers (utiliser la sérialisation complète si disponible) et ignoreIdOnlySerializers (utiliser le comportement par défaut de Jackson). Géré via les méthodes statiques set(), get(), clear() sur un ThreadLocal.

Architecture

Indicateurs

IndicateurDéfautEffet sur IdOnlySerializer
preferEmbeddedSerializersfalseSi vrai, tente de trouver un autre sérialiseur Jackson enregistré pour la classe d'entité
ignoreIdOnlySerializersfalseSi vrai, utilise la sérialisation d'objet par défaut de Jackson

Modèle d'utilisation

JsonThreadLocalContext.set(preferEmbeddedSerializers = true)
try {
    JsonUtils.toJson(uneEntité) // sera entièrement sérialisé
} finally {
    JsonThreadLocalContext.clear()
}
