#1214: JsonThreadLocalContext.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/JsonThreadLocalContext.kt Потоковый контекст, projectforge-business/src/main/kotlin/org/projectforge/framework/json/JsonThreadLocalContext.kt 54 строки · 23 кода · 26 комментариев · 5 пустых
Потоковый контекст, управляющий поведением JSON-сериализации IdOnlySerializer. Предоставляет два логических флага: preferEmbeddedSerializers (использовать полную сериализацию, если доступно) и ignoreIdOnlySerializers (использовать стандартное поведение Jackson). Управляется через статические методы set(), get(), clear() на ThreadLocal.

Архитектура

Флаги

ФлагПо умолчаниюВлияние на IdOnlySerializer
preferEmbeddedSerializersfalseЕсли true, пытается найти другой зарегистрированный сериализатор Jackson для класса сущности
ignoreIdOnlySerializersfalseЕсли true, использует стандартную объектную сериализацию Jackson

Шаблон использования

JsonThreadLocalContext.set(preferEmbeddedSerializers = true)
try {
    JsonUtils.toJson(someEntity) // будет полностью сериализовано
} finally {
    JsonThreadLocalContext.clear()
}
