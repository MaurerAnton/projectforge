#1215: JsonUtils.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/JsonUtils.kt Объект утилит JSON, projectforge-business/src/main/kotlin/org/projectforge/framework/json/JsonUtils.kt 153 строки · 102 кода · 34 комментария · 17 пустых
Центральная утилита сериализации/десериализации JSON. Поддерживает три экземпляра Jackson ObjectMapper: по умолчанию, игнорирование nullable-свойств и игнорирование неизвестных свойств. Регистрирует KotlinModule, Hibernate6Module и пользовательские сериализаторы/десериализаторы для LocalDate, LocalTime, PFDateTime, PFDay, java.util.Date, Timestamp и java.sql.Date.

Архитектура

Экземпляры ObjectMapper

ЭкземплярКонфигурацияСценарий использования
objectMapperKotlinModule + Hibernate6Module + пользовательские сериализаторыСтандартные операции JSON
objectMapperIgnoreNullablePropsТо же + Include.NON_NULLИсключает null-свойства из вывода
objectMapperIgnoreUnknownPropsТо же + FAIL_ON_UNKNOWN_PROPERTIES = falseЛиберальная десериализация

PFDateTimePFDateTimeSerializerPFDateTimeDeserializer

Обработка ошибок

  • toJson перехватывает JsonProcessingException и возвращает пустую строку при ошибке
  • fromJson пробрасывает IOException вызывающему коду
