projectforge-business/src/main/kotlin/org/projectforge/framework/json/LocalDateConverter.kt JSON Serializer/Deserializer, projectforge-business/src/main/kotlin/org/projectforge/framework/json/LocalDateConverter.kt 67 lines · 29 code · 30 comments · 8 blank
Provides Jackson LocalDateSerializer (ISO format yyyy-MM-dd) and LocalDateDeserializer (flexible parsing via PFDayUtils.parseDate accepting user locale formats). Registered in JsonUtils.initializeMapper().

Architecture

LocalDateSerializer

  • Uses DateTimeFormatter.ofPattern("yyyy-MM-dd")
  • Null-safe: writes null if value is null

LocalDateDeserializer

  • Delegates to PFDayUtils.parseDate(p.text) for flexible date parsing
  • Supports user's locale date format in addition to ISO
