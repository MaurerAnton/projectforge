projectforge-business/src/main/kotlin/org/projectforge/framework/json/LocalDateConverter.kt JSON-Serialisierer/Deserialisierer, projectforge-business/src/main/kotlin/org/projectforge/framework/json/LocalDateConverter.kt 67 Zeilen · 29 Code · 30 Kommentare · 8 leer
Stellt Jackson LocalDateSerializer (ISO-Format yyyy-MM-dd) und LocalDateDeserializer (flexibles Parsen via PFDayUtils.parseDate mit Akzeptanz von Benutzer-Locale-Formaten) bereit. Registriert in JsonUtils.initializeMapper().

Architektur

LocalDateSerializer

  • Verwendet DateTimeFormatter.ofPattern("yyyy-MM-dd")
  • Null-sicher: schreibt null, wenn der Wert null ist

LocalDateDeserializer

  • Delegiert an PFDayUtils.parseDate(p.text) für flexibles Datum-Parsen
  • Unterstützt zusätzlich zum ISO-Format das Datumsformat des Benutzers
