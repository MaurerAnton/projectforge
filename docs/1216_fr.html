#1216 : LocalDateConverter.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/LocalDateConverter.kt Sérialiseur/Désérialiseur JSON, projectforge-business/src/main/kotlin/org/projectforge/framework/json/LocalDateConverter.kt 67 lignes · 29 code · 30 commentaires · 8 vides
Fournit le LocalDateSerializer Jackson (format ISO aaaa-MM-jj) et le LocalDateDeserializer (analyse flexible via PFDayUtils.parseDate acceptant les formats de locale utilisateur). Enregistré dans JsonUtils.initializeMapper().

Architecture

LocalDateSerializer

  • Utilise DateTimeFormatter.ofPattern("aaaa-MM-jj")
  • Sécurisé pour les valeurs nulles : écrit null si la valeur est nulle

LocalDateDeserializer

  • Délègue à PFDayUtils.parseDate(p.text) pour une analyse flexible des dates
  • Prend en charge le format de date de la locale utilisateur en plus de l'ISO
