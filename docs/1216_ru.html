#1216: LocalDateConverter.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/json/LocalDateConverter.kt JSON-сериализатор/десериализатор, projectforge-business/src/main/kotlin/org/projectforge/framework/json/LocalDateConverter.kt 67 строк · 29 кода · 30 комментариев · 8 пустых
Предоставляет Jackson LocalDateSerializer (формат ISO yyyy-MM-dd) и LocalDateDeserializer (гибкий разбор через PFDayUtils.parseDate с поддержкой локали пользователя). Зарегистрирован в JsonUtils.initializeMapper().

Архитектура

LocalDateSerializer

  • Использует DateTimeFormatter.ofPattern("yyyy-MM-dd")
  • Null-безопасный: записывает null, если значение равно null

LocalDateDeserializer

  • Делегирует PFDayUtils.parseDate(p.text) для гибкого разбора дат
  • Поддерживает формат даты локали пользователя в дополнение к ISO
