1218: BaseDO.kt

Domain Object Interface, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/api/BaseDO.kt
Core domain object interface extending IdObject<I>. Defines transient attribute storage, minor change tracking, and value-copy semantics from source objects (excluding created/lastUpdate). Used as the base interface for all database-backed entity objects in ProjectForge.

Architecture

Interface Methods

Key Design Decisions

  • Generic ID type: I extends Serializable allows Long, Int, or String IDs
  • Minor change flag: Prevents expensive re-indexing for trivial updates
  • Transient attributes: In-memory key-value store for temporary data (not persisted)
  • Null-excluding copy: copyValuesFrom skips null values to preserve existing data
