1227: QueryFilter.kt

Query Builder, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/api/QueryFilter.kt
Builder-style API for constructing database queries with abstract predicates. Automatically selects the appropriate query engine (criteria, full-text search via Hibernate Search, or in-memory filtering). Extends from BaseSearchFilter for legacy compatibility. Provides static factory methods for all predicate types (eq, ne, like, between, ge, le, isIn, isNull, and, or, not).

Architecture

Query Engine Selection

  • Criteria queries: DBQueryBuilderByCriteria — for structured predicates
  • Full-text search: Hibernate Search — when fullTextSearchFields are provided
  • In-memory filtering: Applied on result sets when both strategies are combined

Integration with BaseSearchFilter

Constructor accepts BaseSearchFilter? and copies: searchFields, searchString (via addFullTextSearch), deleted flag, modifiedSince/startTimeOfModification/stopTimeOfModification, and maxRows.

Join Management

  • createJoin(attr, joinType, fetch, parent) — adds a DBJoin for criteria queries
  • Supports nested properties via dot-notation (e.g., order.positions)

Time-based Filtering

  • setYearAndMonth(dateField, year, month) — generates a between predicate using PFDay for begin/end-of-month or begin/end-of-year boundaries
