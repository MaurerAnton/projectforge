Guide de configuration utilisateur pour le plugin IHK. Rédigé en allemand — le plugin est spécifiquement destiné au système de formation par apprentissage de la Chambre de commerce et d'industrie allemande (IHK) (Ausbildungsnachweis — rapports hebdomadaires obligatoires que les apprentis soumettent à leur responsable de formation).

Objectif du plugin

Exporte les saisies de temps hebdomadaires sous forme de feuille de calcul Excel formatée correspondant au format de rapport exigé par l'IHK. Les apprentis saisissent leurs heures de travail dans le relevé de temps de ProjectForge ; ce plugin génère le fichier Excel du rapport hebdomadaire qui doit être soumis à l'IHK.

Configuration (JSON dans le champ de commentaire de l'adresse)

Le plugin lit la configuration depuis la fiche de contact du carnet d'adresses de l'apprenti — plus précisément le Bemerkungsfeld (champ de commentaire/remarque). Le JSON doit y être placé :

{
  "ausbildungsbeginn" : "aaaa-mm-jj",
  "ausbildungsjahr" : "-1",
  "teamname" : "NomDeTonÉquipe"
}
  • ausbildungsbeginn — date de début de l'apprentissage (utilisée pour calculer l'année de formation dans laquelle se trouve l'apprenti)
  • ausbildungsjahr — remplacement manuel de l'année de formation. La valeur par défaut -1 signifie un calcul automatique à partir de la date de début. Utilisé pour les apprentis qui ont sauté la première année ou raccourci leur programme
  • teamname — nom de l'équipe/département affiché dans l'en-tête Excel

Contrainte importante

Le prénom et le nom de l'utilisateur doivent correspondre exactement au prénom et au nom de sa fiche de contact dans le carnet d'adresses. Le plugin fait correspondre les saisies de temps en comparant le nom de l'utilisateur connecté avec le nom du contact.

Note historique

Ceci est l'un des rares plugins purement Java restants dans ProjectForge (voir build.gradle.kts). Créé par des stagiaires (mweishaar, jhpeters, mopreusser) en mai 2020, basé sur des travaux antérieurs de mnuhn (décembre 2019).
