Руководство по настройке плагина IHK для пользователей. Написано на немецком — плагин предназначен специально для немецкой системы профессионального обучения IHK (Ausbildungsnachweis — обязательные еженедельные отчёты, которые стажёры предоставляют своему руководителю практики).

Назначение плагина

Экспортирует еженедельные записи табеля рабочего времени в отформатированную электронную таблицу Excel, соответствующую требуемому формату отчёта IHK. Стажёры вводят свои рабочие часы в табель ProjectForge; этот плагин генерирует еженедельный файл Excel, который необходимо отправлять в IHK.

Конфигурация (JSON в поле комментария адреса)

Плагин считывает конфигурацию из контактной записи адресной книги стажёра — а именно из поля Bemerkungsfeld (поле комментария/примечания). JSON должен быть размещён там:

{
  "ausbildungsbeginn" : "yyyy-mm-dd",
  "ausbildungsjahr" : "-1",
  "teamname" : "Название вашей команды"
}
  • ausbildungsbeginn — дата начала обучения (используется для расчёта текущего года обучения стажёра)
  • ausbildungsjahr — ручное переопределение года обучения. Значение по умолчанию -1 означает автоматический расчёт от даты начала. Используется для стажёров, которые пропустили первый год или сократили программу
  • teamname — название команды/отдела, отображаемое в заголовке Excel

Важное ограничение

Имя и фамилия пользователя должны точно совпадать с именем и фамилией в его контактной записи адресной книги. Плагин сопоставляет записи табеля, сравнивая имя вошедшего пользователя с именем контакта.

Примечание о наследии

Это один из немногих оставшихся чисто Java плагинов в ProjectForge (см. build.gradle.kts). Создан стажёрами (mweishaar, jhpeters, mopreusser) в мае 2020 года на основе более ранней работы mnuhn (декабрь 2019).
