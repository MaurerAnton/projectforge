Étend BaseDO<I> avec la suppression logique et le support des horodatages d'audit. Ajoute deleted (de MarkDeletableRecord), l'horodatage created, l'horodatage lastUpdate, et un hook recalculate() pour le calcul des champs dérivés/transitoires avant l'affichage ou l'indexation.

Architecture

Hiérarchie des interfaces

Serializable
  └── BaseDO<I : Serializable>
        └── ExtendedBaseDO<I : Serializable>
              (étend également MarkDeletableRecord<I>)

Champs et méthodes du contrat

MembreTypeDescription
deletedBoolean (surcharge)Indicateur de suppression logique. Lorsqu'il est vrai, l'entité est logiquement supprimée mais conservée dans la base de données. Surchargé depuis BaseDO.
createdDate?Horodatage de la création initiale. Défini automatiquement via setCreated().
lastUpdateDate?Horodatage de la dernière modification. Mis à jour automatiquement par la couche de persistance à chaque écriture. Défini automatiquement via setLastUpdate().
recalculate()UnitHook pour les calculs avant affichage / après chargement. Utilisé pour les champs transitoires calculés à partir de champs persistants (par exemple, nom complet à partir du prénom + nom).
setCreated()UnitRaccourci : définit created à l'heure actuelle
setLastUpdate()UnitRaccourci : définit lastUpdate à l'heure actuelle

Contexte d'utilisation

La plupart des entités du domaine dans ProjectForge implémentent ExtendedBaseDO plutôt que le BaseDO brut. L'infrastructure BaseDao s'appuie sur ces champs pour :

  • Filtrage de suppression logique : l'indicateur deleted est vérifié par QueryFilter, MagicFilter et toutes les pages de liste
  • Suivi de l'historique : lastUpdate est utilisé par l'intégration Hibernate Envers et la fonctionnalité de recherche d'historique
  • Pistes d'audit : created et les horodatages de modification sont affichés dans les formulaires d'édition d'entité
  • Recalcul : recalculate() est appelé par les DAO avant de renvoyer les entités aux couches UI

Annotations pertinentes

Les classes d'implémentation annotent généralement ces champs avec des annotations JPA : @Basic, @Column pour le mappage de base de données ; @PropertyInfo(i18nKey = "...") pour le système de propriétés de l'interface utilisateur.
