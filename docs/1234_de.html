Fundamentale Schnittstelle für alle Datenbankentitäten. Definiert eine einzelne generische Eigenschaft: id: I? wobei I extends Serializable. Erweitert Serializable. Dient als Basis der gesamten Entitätshierarchie — BaseDO, HistoryEntry und alle Hibernate-Entitäten implementieren diese Schnittstelle.

Architektur

Schnittstellenvertrag

interface IdObject<I : Serializable> : Serializable {
    var id: I?
}

Verwendung im System

  • BaseDO erweitert IdObject<I> — alle persistenten Entitäten
  • HistoryEntry erweitert IdObject<Long> — Verlaufsdatensätze
  • IdOnlySerializer — Jackson-Serializer, der id aus jedem IdObject liest
  • BaseDao — verwendet IdObject.serializableId für Suchen/Aktualisieren/Löschen-Operationen

ID-Typ-Flexibilität

  • I ist ein generischer Typparameter, der durch Serializable eingeschränkt wird
  • Ermöglicht Long-, Int-, String- oder zusammengesetzte IDs
  • Die meisten Entitäten verwenden IdObject<Long> nach der großen Migration von Integer- zu Long-IDs
