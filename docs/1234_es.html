Interfaz fundamental para todas las entidades de base de datos. Define una única propiedad genérica: id: I? donde I extends Serializable. Extiende Serializable. Sirve como base de toda la jerarquía de entidades — BaseDO, HistoryEntry y todas las entidades Hibernate implementan esta interfaz.

Arquitectura

Contrato de la interfaz

interface IdObject<I : Serializable> : Serializable {
    var id: I?
}

Uso en el sistema

  • BaseDO extiende IdObject<I> — todas las entidades persistentes
  • HistoryEntry extiende IdObject<Long> — registros de historial
  • IdOnlySerializer — serializador Jackson que lee id de cualquier IdObject
  • BaseDao — utiliza IdObject.serializableId para operaciones de búsqueda/actualización/eliminación

Flexibilidad del tipo de ID

  • I es un parámetro de tipo genérico limitado por Serializable
  • Permite IDs Long, Int, String o compuestos
  • La mayoría de las entidades usan IdObject<Long> después de la migración importante de Integer a Long IDs
