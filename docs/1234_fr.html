Interface fondamentale pour toutes les entités de base de données. Définit une seule propriété générique : id: I? où I extends Serializable. Étend Serializable. Sert de base à toute la hiérarchie des entités — BaseDO, HistoryEntry et toutes les entités Hibernate implémentent cette interface.

Architecture

Contrat de l'interface

interface IdObject<I : Serializable> : Serializable {
    var id: I?
}

Utilisation dans le système

  • BaseDO étend IdObject<I> — toutes les entités persistantes
  • HistoryEntry étend IdObject<Long> — enregistrements historiques
  • IdOnlySerializer — sérialiseur Jackson qui lit id depuis n'importe quel IdObject
  • BaseDao — utilise IdObject.serializableId pour les opérations de recherche/mise à jour/suppression

Flexibilité du type d'ID

  • I est un paramètre de type générique limité par Serializable
  • Permet les IDs Long, Int, String ou composites
  • La plupart des entités utilisent IdObject<Long> après la migration majeure des IDs Integer vers Long
