Фундаментальный интерфейс для всех сущностей базы данных. Определяет одно обобщённое свойство: id: I?, где I extends Serializable. Расширяет Serializable. Служит основой всей иерархии сущностей — BaseDO, HistoryEntry и все сущности Hibernate реализуют этот интерфейс.

Архитектура

Контракт интерфейса

interface IdObject<I : Serializable> : Serializable {
    var id: I?
}

Использование в системе

  • BaseDO расширяет IdObject<I> — все постоянные сущности
  • HistoryEntry расширяет IdObject<Long> — записи истории
  • IdOnlySerializer — сериализатор Jackson, который читает id из любого IdObject
  • BaseDao — использует IdObject.serializableId для операций поиска/обновления/удаления

Гибкость типа ID

  • I — параметр обобщённого типа, ограниченный Serializable
  • Позволяет использовать Long, Int, String или составные ID
  • Большинство сущностей используют IdObject<Long> после крупной миграции с Integer на Long ID
