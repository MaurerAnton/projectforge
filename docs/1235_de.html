Das zentrale Filtermodell für ProjectForge-Listenseiten und die Suche. Stellt benutzerdefinierte Suchkriterien als Sammlung typisierter MagicFilterEntry-Objekte dar und unterstützt Feldsuche, Bereichssuche, Volltextsuche, Verlaufssuche, Sortierung, Paginierung und Soft-Delete-Filterung. Erweitert AbstractFavorite für die Benutzervoreinstellungs-Persistenz über UserPrefDao.

Architektur

Klassenhierarchie

AbstractFavorite (Name, ID)
  └── MagicFilter

Als AbstractFavorite kann MagicFilter als benannter Filtervorzug für jeden Benutzer und jeden Entitätstyp gespeichert/geladen werden. Die Jackson-JSON-Serialisierung wird über @JsonTypeInfo für polymorphe Deserialisierung konfiguriert.

MagicFilterEntry-Struktur

Jeder Eintrag hat: field — der Eigenschaftsname der Entität (oder ein spezieller Wert für die Verlaufssuche), value — ein Value-Objekt mit value (exakt), fromValue/toValue (Bereich), values (Mehrfachauswahlliste), id, label, displayName, synthetic — ob der Eintrag automatisch generiert wurde (nicht vom Benutzer erstellt).

Spezielle Eintragsfelder

  • "deleted" — wird als gelöschtes Flag behandelt, nicht als regulärer Feldfilter
  • MODIFIED_HISTORY_VALUE / MODIFIED_INTERVAL / MODIFIED_BY_USER — Hibernate Envers Verlaufssuche
  • "pageSize" — Legacy-Name, wird in MagicFilterProcessor automatisch in paginationPageSize umbenannt

Serialisierung & Persistenz

UserPrefDao speichert MagicFilter-Instanzen als JSON. Die clone()-Methode verwendet denselben ObjectMapper für das Tiefenklonen. Nach der Deserialisierung muss init() aufgerufen werden, da bestimmte Felder (wie Benutzer-Anzeigenamen) nicht serialisiert werden.
