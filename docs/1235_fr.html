Le modèle de filtre central pour les pages de liste et la recherche de ProjectForge. Représente les critères de recherche définis par l'utilisateur sous forme d'une collection d'objets MagicFilterEntry typés, prenant en charge la recherche par champ, la recherche par plage, la recherche en texte intégral, la recherche dans l'historique, le tri, la pagination et le filtrage des suppressions logiques. Étend AbstractFavorite pour la persistance des préférences utilisateur via UserPrefDao.

Architecture

Hiérarchie des classes

AbstractFavorite (nom, id)
  └── MagicFilter

En tant qu'AbstractFavorite, MagicFilter peut être sauvegardé/chargé comme une préférence de filtre nommée pour chaque utilisateur et chaque type d'entité. La sérialisation JSON Jackson est configurée via @JsonTypeInfo pour la désérialisation polymorphe.

Structure de MagicFilterEntry

Chaque entrée possède : field — le nom de la propriété de l'entité (ou une valeur spéciale pour la recherche dans l'historique), value — un objet Value avec value (exact), fromValue/toValue (plage), values (liste multi-sélection), id, label, displayName, synthetic — indique si l'entrée est générée automatiquement (non créée par l'utilisateur).

Champs d'entrée spéciaux

  • "deleted" — traité comme l'indicateur de suppression plutôt que comme un filtre de champ régulier
  • MODIFIED_HISTORY_VALUE / MODIFIED_INTERVAL / MODIFIED_BY_USER — recherche dans l'historique Hibernate Envers
  • "pageSize" — nom hérité, automatiquement renommé en paginationPageSize dans MagicFilterProcessor

Sérialisation et persistance

UserPrefDao stocke les instances MagicFilter au format JSON. La méthode clone() utilise le même ObjectMapper pour le clonage profond. Après la désérialisation, init() doit être appelée car certains champs (comme les noms d'affichage des utilisateurs) ne sont pas sérialisés.
