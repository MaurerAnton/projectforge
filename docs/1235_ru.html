Центральная модель фильтра для страниц списков и поиска ProjectForge. Представляет определяемые пользователем критерии поиска в виде коллекции типизированных объектов MagicFilterEntry, поддерживающих поиск по полю, диапазонный поиск, полнотекстовый поиск, поиск по истории, сортировку, пагинацию и фильтрацию мягкого удаления. Расширяет AbstractFavorite для сохранения пользовательских предпочтений через UserPrefDao.

Архитектура

Иерархия классов

AbstractFavorite (имя, id)
  └── MagicFilter

Будучи AbstractFavorite, MagicFilter может быть сохранён/загружен как именованное предпочтение фильтра для каждого пользователя и каждого типа сущности. Сериализация Jackson JSON настраивается через @JsonTypeInfo для полиморфной десериализации.

Структура MagicFilterEntry

Каждая запись имеет: field — имя свойства сущности (или специальное значение для поиска по истории), value — объект Value с value (точное), fromValue/toValue (диапазон), values (список множественного выбора), id, label, displayName, synthetic — является ли запись автоматически сгенерированной (не созданной пользователем).

Специальные поля записей

  • "deleted" — обрабатывается как флаг удаления, а не как обычный фильтр поля
  • MODIFIED_HISTORY_VALUE / MODIFIED_INTERVAL / MODIFIED_BY_USER — поиск по истории Hibernate Envers
  • "pageSize" — устаревшее имя, автоматически переименовывается в paginationPageSize в MagicFilterProcessor

Сериализация и сохранение

UserPrefDao хранит экземпляры MagicFilter в формате JSON. Метод clone() использует тот же ObjectMapper для глубокого клонирования. После десериализации необходимо вызывать init(), поскольку некоторые поля (например, отображаемые имена пользователей) не сериализуются.
