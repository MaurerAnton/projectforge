Objeto singleton de Kotlin que transforma objetos MagicFilter orientados al usuario en QueryFilter listo para base de datos. Interpreta cada MagicFilterEntry usando reflexión del metamodelo JPA (PropUtils) y metadatos de Hibernate Search (HibernateSearchMeta) para construir predicados tipados: búsquedas LIKE en cadenas, rangos de fecha/número, igualdad booleana, búsquedas en árbol de tareas, filtros de valor I18nEnum y consultas de historial de Hibernate Envers.

Arquitectura

Tubería de Procesamiento

MagicFilter  ──►  MagicFilterProcessor.doIt()  ──►  QueryFilter  ──►  DBFilter  ──►  JPA/Hibernate

El procesador cierra la brecha entre el MagicFilter orientado a la interfaz de usuario (que puede representar filtros de frontends React/AG-Grid) y el QueryFilter orientado a la base de datos (que construye consultas JPA Criteria API y consultas de texto completo de Hibernate Search).

Punto de Entrada Principal

fun doIt(entityClass: Class<*>, magicFilter: MagicFilter, queryFilter: QueryFilter = QueryFilter()): QueryFilter

Toma una clase de entidad para reflexión, un MagicFilter del usuario y opcionalmente un QueryFilter existente para poblarlo. Devuelve el QueryFilter completamente poblado.

Pasos de Procesamiento

  1. Extracción de campos especiales: deleted, searchHistory, MODIFIED_HISTORY_VALUE se extraen de las entradas y se manejan directamente
  2. Transferencia de filtro central: deleted, maxRows, searchHistory, sortProperties, extended se copian a QueryFilter
  3. Búsqueda de texto completo: Si searchString no está en blanco, se agrega un DBPredicate.FullSearch con soporte de comodines
  4. Iteración de búsqueda de campo: Cada MagicFilterEntry se clasifica y transforma en createFieldSearchEntry()

Puntos Clave de Integración

  • PropUtils.getField(): Descubrimiento de tipo de campo basado en reflexión para clases de entidad
  • HibernateSearchMeta.getClassInfo(): Metadatos de índice de Hibernate Search para campos no persistentes
  • PFDateTimeUtils / PFDayUtils: Análisis de cadenas de fecha para los tipos de fecha/hora del framework
  • TaskTree: Jerarquía de tareas para resolución recursiva de filtros de tareas
  • UserGroupCache: Información de usuario para filtros de historial MODIFIED_BY_USER (llamado durante MagicFilter.init())
