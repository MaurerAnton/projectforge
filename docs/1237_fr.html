Objet singleton Kotlin qui transforme les objets MagicFilter orientés utilisateur en QueryFilter prêt pour la base de données. Interprète chaque MagicFilterEntry à l'aide de la réflexion du métamodèle JPA (PropUtils) et des métadonnées Hibernate Search (HibernateSearchMeta) pour construire des prédicats typés : recherches LIKE sur les chaînes, plages de dates/numériques, égalité booléenne, recherches dans l'arborescence des tâches, filtres de valeurs I18nEnum et requêtes d'historique Hibernate Envers.

Architecture

Pipeline de traitement

MagicFilter  ──►  MagicFilterProcessor.doIt()  ──►  QueryFilter  ──►  DBFilter  ──►  JPA/Hibernate

Le processeur fait le pont entre le MagicFilter orienté interface utilisateur (qui peut représenter des filtres provenant de frontends React/AG-Grid) et le QueryFilter orienté base de données (qui construit des requêtes JPA Criteria API et des requêtes plein texte Hibernate Search).

Point d'entrée principal

fun doIt(entityClass: Class<*>, magicFilter: MagicFilter, queryFilter: QueryFilter = QueryFilter()): QueryFilter

Prend une classe d'entité pour la réflexion, un MagicFilter de l'utilisateur, et optionnellement un QueryFilter existant à remplir. Retourne le QueryFilter entièrement rempli.

Étapes de traitement

  1. Extraction des champs spéciaux : deleted, searchHistory, MODIFIED_HISTORY_VALUE sont extraits des entrées et traités directement
  2. Transfert du filtre principal : deleted, maxRows, searchHistory, sortProperties, extended sont copiés dans QueryFilter
  3. Recherche plein texte : Si searchString n'est pas vide, un DBPredicate.FullSearch est ajouté avec prise en charge des caractères génériques
  4. Itération de recherche par champ : Chaque MagicFilterEntry est classifié et transformé dans createFieldSearchEntry()

Points d'intégration clés

  • PropUtils.getField() : Découverte du type de champ par réflexion pour les classes d'entité
  • HibernateSearchMeta.getClassInfo() : Métadonnées d'index Hibernate Search pour les champs non persistants
  • PFDateTimeUtils / PFDayUtils : Analyse des chaînes de date pour les types date/heure du framework
  • TaskTree : Hiérarchie des tâches pour la résolution récursive des filtres de tâches
  • UserGroupCache : Informations utilisateur pour les filtres d'historique MODIFIED_BY_USER (appelé lors de MagicFilter.init())
