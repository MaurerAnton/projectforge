Объект-одиночка на Kotlin, преобразующий пользовательские объекты MagicFilter в готовый для базы данных QueryFilter. Интерпретирует каждый MagicFilterEntry с помощью рефлексии JPA-метамодели (PropUtils) и метаданных Hibernate Search (HibernateSearchMeta) для построения типизированных предикатов: строковые поиски LIKE, диапазоны дат/чисел, равенство булевых значений, поиск по дереву задач, фильтры значений I18nEnum и запросы истории Hibernate Envers.

Архитектура

Конвейер обработки

MagicFilter  ──►  MagicFilterProcessor.doIt()  ──►  QueryFilter  ──►  DBFilter  ──►  JPA/Hibernate

Обработчик устраняет разрыв между ориентированным на UI MagicFilter (который может представлять фильтры из React/AG-Grid фронтендов) и ориентированным на базу данных QueryFilter (который строит запросы JPA Criteria API и полнотекстовые запросы Hibernate Search).

Основная точка входа

fun doIt(entityClass: Class<*>, magicFilter: MagicFilter, queryFilter: QueryFilter = QueryFilter()): QueryFilter

Принимает класс сущности для рефлексии, MagicFilter от пользователя и опционально существующий QueryFilter для заполнения. Возвращает полностью заполненный QueryFilter.

Шаги обработки

  1. Извлечение специальных полей: deleted, searchHistory, MODIFIED_HISTORY_VALUE извлекаются из записей и обрабатываются напрямую
  2. Перенос основных фильтров: deleted, maxRows, searchHistory, sortProperties, extended копируются в QueryFilter
  3. Полнотекстовый поиск: Если searchString не пустая, добавляется DBPredicate.FullSearch с поддержкой подстановочных знаков
  4. Итерация по поиску полей: Каждый MagicFilterEntry классифицируется и преобразуется в createFieldSearchEntry()

Ключевые точки интеграции

  • PropUtils.getField(): Определение типа поля на основе рефлексии для классов сущностей
  • HibernateSearchMeta.getClassInfo(): Метаданные индекса Hibernate Search для неперсистентных полей
  • PFDateTimeUtils / PFDayUtils: Разбор строк даты для типов даты/времени фреймворка
  • TaskTree: Иерархия задач для рекурсивного разрешения фильтра задач
  • UserGroupCache: Информация о пользователе для фильтров истории MODIFIED_BY_USER (вызывается во время MagicFilter.init())
