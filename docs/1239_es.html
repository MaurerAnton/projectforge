La especificación central de consultas a la base de datos para ProjectForge. Acumula objetos DBPredicate, propiedades de ordenación, uniones, directivas de búsqueda de texto completo, parámetros de búsqueda en historial y controles de paginación. Detecta automáticamente qué estrategia de consulta utilizar (API de Criteria JPA para campos indexados, búsqueda de texto completo de Hibernate Search para no indexados, filtrado de lista de resultados como alternativa). Sirve como puente entre la salida de MagicFilterProcessor y la ejecución de consultas de BaseDao/DBFilter.

Arquitectura

Detección automática de estrategia de consulta

QueryFilter acumula predicados sin especificar la estrategia de ejecución. Las clases BaseDao y DBFilter determinan en tiempo de consulta qué enfoque usar: - API de Criteria (JPA): Para predicados indexados/tipados en campos persistentes - Hibernate Search (texto completo): Para DBPredicate.FullSearch usando el índice Lucene - Filtrado de lista de resultados: Como último recurso para predicados que no pueden expresarse en SQL/HQL

Conveniencia de período de tiempo

setYearAndMonth(dateField, year, month) construye un predicado between para un año/mes específico. Si month <= 0, se usa el rango de año completo.

Compatibilidad con filtros heredados

El constructor acepta un BaseSearchFilter opcional para compatibilidad hacia atrás. Copia searchFields, deleted, searchString, modifiedSince, modifiedByUserId y maxRows del filtro heredado.

Finalización del filtro

createDBFilter(): DBFilter materializa el estado acumulado en un objeto DBFilter, añadiendo el predicado deleted implícito si aún no está presente. Este es el punto donde QueryFilter se convierte en su forma ejecutable final.
