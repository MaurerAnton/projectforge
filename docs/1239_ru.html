Центральная спецификация запросов к базе данных для ProjectForge. Накапливает объекты DBPredicate, свойства сортировки, объединения, директивы полнотекстового поиска, параметры поиска по истории и элементы управления пагинацией. Автоматически определяет, какую стратегию запроса использовать (JPA Criteria API для индексированных полей, Hibernate Search для полнотекстового поиска по неиндексированным полям, фильтрацию списка результатов как запасной вариант). Служит мостом между выходными данными MagicFilterProcessor и выполнением запросов BaseDao/DBFilter.

Архитектура

Автоматическое определение стратегии запроса

QueryFilter накапливает предикаты без указания стратегии выполнения. Классы BaseDao и DBFilter определяют во время запроса, какой подход использовать: - Criteria API (JPA): Для индексированных/типизированных предикатов по полям персистентности - Hibernate Search (полнотекстовый): Для DBPredicate.FullSearch с использованием индекса Lucene - Фильтрация списка результатов: Как крайняя мера для предикатов, которые нельзя выразить в SQL/HQL

Объединения

createJoin(attr, joinType, fetch, parent) добавляет DBJoin в список объединений, поддерживая: - Пути к вложенным свойствам (например, "order.positions") - Типы объединений INNER/LEFT/FETCH - Необязательный псевдоним родителя для подчинённых объединений

Удобство работы с временными периодами

setYearAndMonth(dateField, year, month) создаёт предикат between для конкретного периода год/месяц. Если month <= 0, используется весь годовой диапазон.

Совместимость с устаревшими фильтрами

Конструктор принимает опциональный BaseSearchFilter для обратной совместимости. Он копирует searchFields, deleted, searchString, modifiedSince, modifiedByUserId и maxRows из устаревшего фильтра.

Финализация фильтра

createDBFilter(): DBFilter материализует накопленное состояние в объект DBFilter, добавляя неявный предикат deleted, если он ещё не присутствует. Это точка, в которой QueryFilter преобразуется в свою окончательную исполняемую форму.
