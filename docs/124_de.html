Konfigurations-DTO für das IHK-Plugin. Einfaches Java-Bean mit drei Feldern, keine Annotationen – wird verwendet, um das JSON zu deserialisieren, das im Kommentarfeld der Adressbuchdatenbank des Auszubildenden gespeichert ist (siehe README). Deserialisiert durch IHKForm mittels JsonUtils.fromJson().

Felder

  • ausbildungsbeginn (String) — Startdatum der Ausbildung als ISO-String (yyyy-MM-dd). Wird verwendet, um das aktuelle Ausbildungsjahr zu berechnen: Period.between(start, now).getYears()
  • ausbildungsjahr (int) — Manuelle Überschreibung für das Ausbildungsjahr. -1 bedeutet automatische Berechnung. Wird verwendet, wenn das Programm des Auszubildenden vom Standard abweicht (verkürzen / überspringen)
  • teamname (String) — Team-/Abteilungsname, erscheint im exportierten Excel-Kopf

Design

Einfaches JavaBean mit zwei Konstruktoren (Standard + Alle-Argumente) sowie Gettern und Settern. Keine JPA-Annotationen – dies ist keine persistente Entität. Das JSON wird als roher String in der Datenbankspalte AddressDO.comment gespeichert und zur Laufzeit geparst. Erstellt von drei Praktikanten im Mai 2020 – die Einfachheit spiegelt seinen Ursprung als Praktikumsprojekt wider.

Verwendungskette

AddressDO.comment → JsonUtils.fromJson(json, IHKCommentObject.class) → IHKExporter verwendet Felder, um Zeiterfassungen zu filtern und Excel-Köpfe zu befüllen.
