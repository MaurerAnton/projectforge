DTO de configuración para el plugin IHK. Bean Java simple con tres campos, sin anotaciones — utilizado para deserializar el JSON almacenado en el campo de comentario de la libreta de direcciones del aprendiz (ver README). Deserializado por IHKForm usando JsonUtils.fromJson().

Campos

  • ausbildungsbeginn (String) — fecha de inicio del aprendizaje como cadena ISO (yyyy-MM-dd). Se usa para calcular el año de formación actual: Period.between(start, now).getYears()
  • ausbildungsjahr (int) — anulación manual del año de formación. -1 significa cálculo automático. Se usa cuando el programa del aprendiz se desvía del estándar (verkürzen / überspringen)
  • teamname (String) — nombre del equipo/departamento, aparece en el encabezado del Excel exportado

Diseño

JavaBean simple con dos constructores (predeterminado + todos los argumentos) y getters/setters. Sin anotaciones JPA — no es una entidad persistente. El JSON se almacena como una cadena sin formato en la columna de base de datos AddressDO.comment y se analiza en tiempo de ejecución. Creado por tres becarios en mayo de 2020 — la simplicidad refleja su origen como proyecto de prácticas.

Cadena de uso

AddressDO.comment → JsonUtils.fromJson(json, IHKCommentObject.class) → IHKExporter utiliza los campos para filtrar hojas de tiempo y llenar encabezados de Excel.
