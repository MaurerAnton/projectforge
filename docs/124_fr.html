DTO de configuration pour le plugin IHK. Bean Java simple avec trois champs, sans annotations — utilisé pour désérialiser le JSON stocké dans le champ de commentaire du carnet d'adresses du stagiaire (voir README). Désérialisé par IHKForm via JsonUtils.fromJson().

Champs

  • ausbildungsbeginn (String) — date de début d'apprentissage sous forme de chaîne ISO (yyyy-MM-dd). Utilisée pour calculer l'année de formation en cours : Period.between(start, now).getYears()
  • ausbildungsjahr (int) — remplacement manuel de l'année de formation. -1 signifie calcul automatique. Utilisé lorsque le programme du stagiaire s'écarte du standard (verkürzen / überspringen)
  • teamname (String) — nom de l'équipe/département, apparaît dans l'en-tête Excel exporté

Conception

JavaBean simple avec deux constructeurs (par défaut + tous les arguments) et des getters/setters. Pas d'annotations JPA — ce n'est pas une entité persistante. Le JSON est stocké sous forme de chaîne brute dans la colonne AddressDO.comment de la base de données et analysé à l'exécution. Créé par trois stagiaires en mai 2020 — la simplicité reflète son origine en tant que projet de stage.

Chaîne d'utilisation

AddressDO.comment → JsonUtils.fromJson(json, IHKCommentObject.class) → IHKExporter utilise les champs pour filtrer les feuilles de temps et remplir les en-têtes Excel.
