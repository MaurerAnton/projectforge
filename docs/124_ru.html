#124: IHKCommentObject.java

plugins/org.projectforge.plugins.ihk/src/main/java/org/projectforge/plugins/ihk/IHKCommentObject.java Путь: plugins/...ihk/src/main/java/.../IHKCommentObject.java · Строк: 70 · Тип: Java POJO — модель десериализации JSON 70 строк · 31 код · 25 комментариев · 14 пустых

DTO конфигурации для плагина IHK. Простой Java-бин с тремя полями, без аннотаций — используется для десериализации JSON, хранящегося в поле комментария адресной книги стажёра (см. README). Десериализуется IHKForm с помощью JsonUtils.fromJson().

Поля

  • ausbildungsbeginn (String) — дата начала обучения в формате ISO (yyyy-MM-dd). Используется для расчёта текущего года обучения: Period.between(start, now).getYears()
  • ausbildungsjahr (int) — ручное переопределение года обучения. -1 означает автоматический расчёт. Используется, когда программа стажёра отклоняется от стандартной (сокращение / перескок)
  • teamname (String) — название команды/отдела, отображается в заголовке экспортируемого Excel

Дизайн

Простой JavaBean с двумя конструкторами (по умолчанию + со всеми аргументами) и геттерами/сеттерами. Без JPA-аннотаций — это не постоянная сущность. JSON хранится как сырая строка в столбце базы данных AddressDO.comment и парсится во время выполнения. Создан тремя стажёрами в мае 2020 года — простота отражает его происхождение как стажёрского проекта.

Цепочка использования

AddressDO.comment → JsonUtils.fromJson(json, IHKCommentObject.class) → IHKExporter использует поля для фильтрации табелей и заполнения заголовков Excel.
