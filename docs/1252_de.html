Interner JPA-Criteria-API-Abfrage-Builder, der von QueryFilter für strukturierte Datenbankabfragen verwendet wird. Übersetzt DBPredicate-Objekte über CriteriaBuilder in JPA-Predicate-Instanzen, verwaltet Joins und erstellt einen DBCriteriaResultIterator zur Ergebnisiteration mit In-Memory-Filterung.

Architektur

Konstruktor-Abhängigkeiten

  • baseDao BaseDao<O> — stellt die Entitätsklasse für die Root-Abfrage bereit
  • entityManager — JPA-EntityManager für CriteriaBuilder/CriteriaQuery
  • queryFilter — der QueryFilter, der Join-Definitionen und Prädikate bereitstellt

Faule Initialisierung

private val ctx: DBCriteriaContext<O> by lazy {
    val cb = entityManager.criteriaBuilder
    val cr = cb.createQuery(baseDao.doClass)
    DBCriteriaContext(cb, cr, cr.from(baseDao.doClass), baseDao.doClass).also {
        queryFilter.joinList.forEach { join -> it.addJoin(join) }
    }
}

Der DBCriteriaContext wird faul konstruiert, um JPA root.from() bis zum Bedarfsfall zu verzögern.

Kernmethoden

MethodeBeschreibung
add(matcher: DBPredicate)Konvertiert DBPredicate über matcher.asPredicate(ctx) in JPA-Predicate
addOrder(sortProperty)Fügt ASC/DESC-Sortierung mittels ctx.cb.asc() oder ctx.cb.desc() hinzu
createResultIterator(predicates, queryFilter)Erstellt die finale CriteriaQuery mit where/orderBy-Klauseln, verpackt in DBCriteriaResultIterator

Fehlerbehandlung

  • addOrder fängt Ausnahmen ab und protokolliert Fehler für unbekannte Eigenschaftsnamen anstatt stillschweigend zu scheitern
