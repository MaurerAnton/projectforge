Constructor de consultas interno de la API de Criteria JPA utilizado por QueryFilter para consultas estructuradas a la base de datos. Traduce objetos DBPredicate a instancias de Predicate de JPA mediante CriteriaBuilder, gestiona uniones y crea un DBCriteriaResultIterator para la iteración de resultados con filtrado en memoria.

Arquitectura

Dependencias del constructor

  • baseDao BaseDao<O> — proporciona la clase de entidad para la consulta raíz
  • entityManager — EntityManager de JPA para CriteriaBuilder/CriteriaQuery
  • queryFilter — el QueryFilter que proporciona definiciones de uniones y predicados

Inicialización perezosa

private val ctx: DBCriteriaContext<O> by lazy {
    val cb = entityManager.criteriaBuilder
    val cr = cb.createQuery(baseDao.doClass)
    DBCriteriaContext(cb, cr, cr.from(baseDao.doClass), baseDao.doClass).also {
        queryFilter.joinList.forEach { join -> it.addJoin(join) }
    }
}

El DBCriteriaContext se construye de forma perezosa para diferir JPA root.from() hasta que sea necesario.

Métodos principales

MétodoDescripción
add(matcher: DBPredicate)Convierte DBPredicate a Predicate de JPA mediante matcher.asPredicate(ctx)
addOrder(sortProperty)Añade ordenación ASC/DESC usando ctx.cb.asc() o ctx.cb.desc()
createResultIterator(predicates, queryFilter)Construye la CriteriaQuery final con cláusulas where/orderBy, envuelta en DBCriteriaResultIterator

Manejo de errores

  • addOrder captura excepciones y registra el error para nombres de propiedad desconocidos en lugar de fallar silenciosamente
