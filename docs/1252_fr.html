Constructeur de requêtes interne de l'API JPA Criteria utilisé par QueryFilter pour les requêtes structurées en base de données. Traduit les objets DBPredicate en instances JPA Predicate via CriteriaBuilder, gère les jointures et crée un DBCriteriaResultIterator pour l'itération des résultats avec filtrage en mémoire.

Architecture

Dépendances du constructeur

  • baseDao BaseDao<O> — fournit la classe d'entité pour la requête racine
  • entityManager — EntityManager JPA pour CriteriaBuilder/CriteriaQuery
  • queryFilter — le QueryFilter fournissant les définitions de jointure et les prédicats

Initialisation paresseuse

private val ctx: DBCriteriaContext<O> by lazy {
    val cb = entityManager.criteriaBuilder
    val cr = cb.createQuery(baseDao.doClass)
    DBCriteriaContext(cb, cr, cr.from(baseDao.doClass), baseDao.doClass).also {
        queryFilter.joinList.forEach { join -> it.addJoin(join) }
    }
}

Le DBCriteriaContext est construit de manière paresseuse pour différer l'appel à JPA root.from() jusqu'au moment nécessaire.

Méthodes principales

MéthodeDescription
add(matcher: DBPredicate)Convertit un DBPredicate en Predicate JPA via matcher.asPredicate(ctx)
addOrder(sortProperty)Ajoute un ordre ASC/DESC en utilisant ctx.cb.asc() ou ctx.cb.desc()
createResultIterator(predicates, queryFilter)Construit la CriteriaQuery finale avec les clauses where/orderBy, encapsulée dans DBCriteriaResultIterator

Gestion des erreurs

  • addOrder intercepte les exceptions et enregistre une erreur pour les noms de propriétés inconnus au lieu d'échouer silencieusement
