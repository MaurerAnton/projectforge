Внутренний построитель запросов JPA Criteria API, используемый QueryFilter для структурированных запросов к базе данных. Преобразует объекты DBPredicate в экземпляры JPA Predicate через CriteriaBuilder, управляет объединениями и создаёт DBCriteriaResultIterator для итерации по результатам с фильтрацией в памяти.

Архитектура

Зависимости конструктора

  • baseDao BaseDao<O> — предоставляет класс сущности для корневого запроса
  • entityManager — JPA EntityManager для CriteriaBuilder/CriteriaQuery
  • queryFilter — QueryFilter, предоставляющий определения объединений и предикаты

Ленивая инициализация

private val ctx: DBCriteriaContext<O> by lazy {
    val cb = entityManager.criteriaBuilder
    val cr = cb.createQuery(baseDao.doClass)
    DBCriteriaContext(cb, cr, cr.from(baseDao.doClass), baseDao.doClass).also {
        queryFilter.joinList.forEach { join -> it.addJoin(join) }
    }
}

DBCriteriaContext создаётся лениво, чтобы отложить вызов JPA root.from() до момента необходимости.

Основные методы

МетодОписание
add(matcher: DBPredicate)Преобразует DBPredicate в JPA Predicate через matcher.asPredicate(ctx)
addOrder(sortProperty)Добавляет сортировку ASC/DESC с помощью ctx.cb.asc() или ctx.cb.desc()
createResultIterator(predicates, queryFilter)Строит финальный CriteriaQuery с условиями where/orderBy, оборачивает в DBCriteriaResultIterator

Обработка ошибок

  • addOrder перехватывает исключения и логирует ошибку для неизвестных имён свойств вместо молчаливого отказа
