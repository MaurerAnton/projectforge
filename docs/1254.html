1254: DisplayHistoryEntry.kt

DTO / Display Model, projectforge-business/.../persistence/history/DisplayHistoryEntry.kt
JSON-serializable data transfer object that renders a single history entry for the React frontend. Includes localized timestamps, user attribution, operation type, diff summaries, and child attribute diffs.

Architecture & Role

DisplayHistoryEntry is the public-facing representation of database entity HistoryEntryDO. It is built by HistoryService converters and consumed directly by the React UI (HistoryEntry.jsx). It provides computed fields (operation, diffSummary) alongside raw data.

Key Properties

PropertyTypeDescription
idLong?Primary key of the history entry
modifiedAtDate?Timestamp of the modification
timeAgoString?Human-readable, localized "X minutes ago" via TimeAgo
modifiedByUserIdLong?User database ID

attributesMutableList<DisplayHistoryEntryAttr>Per-property change details

Inner Class: DiffCount

DiffCount(type: EntityOpType, count: Int, operation: String) — describes how many attributes were inserted/updated/deleted for display in the diff summary bar.

Factory Method

Companion.create(historyEntry, context) constructs a DisplayHistoryEntry from a raw HistoryEntry plus the load context. It resolves the modifying user via UserGroupCache and computes timeAgo.
