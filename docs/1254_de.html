Generisches Interface und Implementierungen zum Iterieren über Datenbanksuchergebnisse. Bietet DBCriteriaResultIterator unter Verwendung von Hibernate ScrollableResults mit Entity-Graph-Unterstützung und DBEmptyResultIterator für leere Abfrageergebnisse.

Architektur

Interface

interface DBResultIterator<O : ExtendedBaseDO<Long>> {
    fun next(): O?
    fun sort(list: List<O>): List<O>
}

Implementierungen

KlasseBeschreibung
DBEmptyResultIteratorGibt null für next() zurück; Identitätssortierung. Wird für Abfragen ohne Ergebnisse verwendet.
DBCriteriaResultIteratorKapselt ScrollableResults von jakarta.persistence.Query. Unterstützt Entity-Graph-Hinweise (jakarta.persistence.loadgraph) und leert den Entity-Manager alle 100 Iterationen. Fängt Ausnahmen in next() mit Fehlerprotokollierung ab.

Konstruktorabhängigkeiten (DBCriteriaResultIterator)

  • entityManager — JPA EntityManager für Abfrageerstellung und -bereinigung
  • criteria CriteriaQuery<O> — die JPA Criteria-Abfrage
  • resultPredicates List<DBPredicate> — Post-Query-In-Memory-Prädikate
  • queryFilter QueryFilter — stellt den Entity-Graph-Namen über entityGraphName bereit
