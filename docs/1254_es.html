Interfaz genérica e implementaciones para iterar sobre resultados de búsqueda en base de datos. Proporciona DBCriteriaResultIterator usando ScrollableResults de Hibernate con soporte de grafo de entidades, y DBEmptyResultIterator para resultados de consulta vacíos.

Arquitectura

Interfaz

interface DBResultIterator<O : ExtendedBaseDO<Long>> {
    fun next(): O?
    fun sort(list: List<O>): List<O>
}

Implementaciones

ClaseDescripción
DBEmptyResultIteratorRetorna null para next(); ordenación identidad. Usado para consultas sin resultados.
DBCriteriaResultIteratorEnvuelve ScrollableResults de jakarta.persistence.Query. Soporta sugerencias de grafo de entidades (jakarta.persistence.loadgraph) y vacía el entity manager cada 100 iteraciones. Captura excepciones en next() con registro de errores.

Dependencias del constructor (DBCriteriaResultIterator)

  • entityManager — EntityManager JPA para creación y limpieza de consultas
  • criteria CriteriaQuery<O> — la consulta de criterios JPA
  • resultPredicates List<DBPredicate> — predicados en memoria posteriores a la consulta
  • queryFilter QueryFilter — proporciona el nombre del grafo de entidades mediante entityGraphName
