Interface générique et implémentations pour itérer sur les résultats de recherche en base de données. Fournit DBCriteriaResultIterator utilisant ScrollableResults d'Hibernate avec support des graphes d'entités, et DBEmptyResultIterator pour les résultats de requêtes vides.

Architecture

Interface

interface DBResultIterator<O : ExtendedBaseDO<Long>> {
    fun next(): O?
    fun sort(list: List<O>): List<O>
}

Implémentations

ClasseDescription
DBEmptyResultIteratorRetourne null pour next() ; tri identitaire. Utilisé pour les requêtes sans résultats.
DBCriteriaResultIteratorEncapsule ScrollableResults de jakarta.persistence.Query. Prend en charge les indications de graphe d'entités (jakarta.persistence.loadgraph) et vide le gestionnaire d'entités toutes les 100 itérations. Capture les exceptions dans next() avec journalisation des erreurs.

Dépendances du constructeur (DBCriteriaResultIterator)

  • entityManager — EntityManager JPA pour la création et le nettoyage des requêtes
  • criteria CriteriaQuery<O> — la requête Criteria JPA
  • resultPredicates List<DBPredicate> — prédicats en mémoire post-requête
  • queryFilter QueryFilter — fournit le nom du graphe d'entités via entityGraphName
