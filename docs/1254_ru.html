Общий интерфейс и реализации для итерации по результатам поиска в базе данных. Предоставляет DBCriteriaResultIterator, использующий Hibernate ScrollableResults с поддержкой графа сущностей, и DBEmptyResultIterator для пустых результатов запроса.

Архитектура

Интерфейс

interface DBResultIterator<O : ExtendedBaseDO<Long>> {
    fun next(): O?
    fun sort(list: List<O>): List<O>
}

Реализации

КлассОписание
DBEmptyResultIteratorВозвращает null для next(); сортировка по идентичности. Используется для запросов без результатов.
DBCriteriaResultIteratorОборачивает ScrollableResults из jakarta.persistence.Query. Поддерживает подсказки графа сущностей (jakarta.persistence.loadgraph) и очищает менеджер сущностей каждые 100 итераций. Перехватывает исключения в next() с записью ошибок.

Зависимости конструктора (DBCriteriaResultIterator)

  • entityManager — JPA EntityManager для создания и очистки запросов
  • criteria CriteriaQuery<O> — JPA Criteria запрос
  • resultPredicates List<DBPredicate> — пост-запросные предикаты в памяти
  • queryFilter QueryFilter — предоставляет имя графа сущностей через entityGraphName
