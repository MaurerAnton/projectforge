Inspecciona una clase DO y sus accesores para construir una lista de entradas HibernateSearchFieldInfo. Escanea las anotaciones @FullTextField, @GenericField, @KeywordField y @DocumentId en campos, getters y setters. También incorpora additionalSearchFields del DAO y anotaciones @ClassBridge para soporte de búsqueda en objetos embebidos.

Arquitectura

Dependencias del constructor

  • baseDao BaseDao<*> — proporciona la clase DO y campos de búsqueda adicionales

Proceso de descubrimiento de campos

  1. Itera todos los campos declarados mediante BeanHelper.getAllDeclaredFields(clazz)
  2. Escanea métodos getter/setter públicos para nombres con prefijo get/is/set
  3. Verifica additionalSearchFields del DAO, soportando notación de puntos para objetos embebidos
  4. Escanea anotaciones @ClassBridge en la clase de entidad
  5. Cada campo se verifica contra HibernateMetaModel.getEntityInfo para marcar persistencia
