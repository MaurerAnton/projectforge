projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/api/impl/HibernateSearchClassInfo.kt Метаданные поиска (уровень класса), projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/api/impl/HibernateSearchClassInfo.kt 254 строки · 205 кода · 26 комментариев · 23 пустых
Анализирует класс DO и его аксессоры для построения списка записей HibernateSearchFieldInfo. Сканирует аннотации @FullTextField, @GenericField, @KeywordField и @DocumentId на полях, геттерах и сеттерах. Также включает additionalSearchFields из DAO и аннотации @ClassBridge для поддержки поиска во встроенных объектах.

Архитектура

Зависимости конструктора

  • baseDao BaseDao<*> — предоставляет класс DO и дополнительные поля поиска

Процесс обнаружения полей

  1. Перебирает все объявленные поля через BeanHelper.getAllDeclaredFields(clazz)
  2. Сканирует публичные методы геттеров/сеттеров с префиксами get/is/set
  3. Проверяет additionalSearchFields из DAO, поддерживая точечную нотацию для встроенных объектов
  4. Сканирует аннотации @ClassBridge на классе сущности
  5. Каждое поле проверяется через HibernateMetaModel.getEntityInfo для отметки о сохранении
