Registro singleton seguro para hilos de instancias de HibernateSearchClassInfo, indexadas por clase de entidad. Construye de forma perezosa HibernateSearchClassInfo en el primer acceso mediante ensureClassInfo(). Expone getSearchFields() utilizado por las páginas de lista de Wicket para tooltips de campos de búsqueda, fusionando campos de búsqueda adicionales del DAO.

Arquitectura

Métodos clave

MétodoDescripción
getSearchFields(dao)Devuelve un array ordenado y sin duplicados de todos los nombres de campos de búsqueda + adicionales para tooltips de Wicket
getClassInfo(baseDO)Obtiene la información de clase existente; lanza IllegalArgumentException si no se encuentra
ensureClassInfo(baseDao)Obtiene o crea de forma perezosa la información de clase, almacenada en bloque synchronized(classInfos)

Utiliza synchronized(classInfos) para inicialización segura para hilos. Llama a HibernateSearchClassInfo(baseDao) que inspecciona anotaciones y registra información de búsqueda.
