Registre singleton thread-safe d'instances HibernateSearchClassInfo, indexé par classe d'entité. Construit paresseusement HibernateSearchClassInfo lors du premier accès via ensureClassInfo(). Expose getSearchFields() utilisé par les pages de liste Wicket pour les infobulles des champs de recherche, en fusionnant les champs de recherche supplémentaires du DAO.

getClassInfo(baseDO)Obtient les informations de classe existantes ; lève IllegalArgumentException si non trouvé

Utilise synchronized(classInfos) pour une initialisation thread-safe. Appelle HibernateSearchClassInfo(baseDao) qui inspecte les annotations et enregistre les informations de recherche.
