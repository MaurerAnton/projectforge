projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/api/impl/HibernateSearchMeta.kt Реестр метаданных поиска (синглтон), projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/api/impl/HibernateSearchMeta.kt 65 строк · 32 кода · 26 комментариев · 7 пустых
Потокобезопасный синглтон-реестр экземпляров HibernateSearchClassInfo, ключом которых является класс сущности. Лениво создаёт HibernateSearchClassInfo при первом обращении через ensureClassInfo(). Предоставляет getSearchFields(), используемый страницами списков Wicket для подсказок полей поиска, объединяя дополнительные поля поиска DAO.

Архитектура

Ключевые методы

МетодОписание
getSearchFields(dao)Возвращает отсортированный, дедуплицированный массив всех + дополнительных имён полей поиска для подсказок Wicket
getClassInfo(baseDO)Получает существующую информацию о классе; выбрасывает IllegalArgumentException, если не найдено
ensureClassInfo(baseDao)Получает или лениво создаёт информацию о классе, сохраняя в блоке synchronized(classInfos)

Использует synchronized(classInfos) для потокобезопасной инициализации. Вызывает HibernateSearchClassInfo(baseDao), который анализирует аннотации и логирует информацию поиска.
