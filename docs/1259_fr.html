Énumération interne classifiant le type d'opération de recherche : NONE, STRING_SEARCH (texte intégral sur tous les champs), FIELD_STRING_SEARCH (texte intégral sur un champ spécifique), FIELD_RANGE_SEARCH (plage numérique) et FIELD_VALUES_SEARCH (valeurs discrètes). Utilisée par les sous-classes de DBPredicate pour indiquer leur comportement de requête.

Valeurs

ValeurDescription
NONEAucune opération de recherche
STRING_SEARCHRequête plein texte sur tous les champs indexés
FIELD_STRING_SEARCHRequête plein texte sur un champ spécifique
FIELD_RANGE_SEARCHRequête de plage numérique sur un champ
FIELD_VALUES_SEARCHCorrespondance de valeurs discrètes (ex. enum/dans une liste)
