Внутреннее перечисление, классифицирующее тип операции поиска: NONE, STRING_SEARCH (полнотекстовый по всем полям), FIELD_STRING_SEARCH (полнотекстовый по конкретному полю), FIELD_RANGE_SEARCH (числовой диапазон) и FIELD_VALUES_SEARCH (дискретные значения). Используется подклассами DBPredicate для указания их поведения при запросах.

Значения

ЗначениеОписание
NONEНет операции поиска
STRING_SEARCHПолнотекстовый запрос по всем индексированным полям
FIELD_STRING_SEARCHПолнотекстовый запрос по конкретному полю
FIELD_RANGE_SEARCHЗапрос числового диапазона по полю
FIELD_VALUES_SEARCHСопоставление дискретных значений (например, перечисление/список)
