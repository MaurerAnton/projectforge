Handler für Eigenschaften vom Typ BaseDO im Copy-and-History (CandH)-Framework. Erweitert DefaultHandler, akzeptiert jede Eigenschaft, deren Rückgabetyp eine BaseDO-Unterklasse ist. Der Gleichheitsvergleich vergleicht Entitätskennungen mittels HibernateUtils.getIdentifier() anstelle von Objektgleichheit.

Architektur

Vererbung

BaseDOHandler erweitert DefaultHandler. Die Methode process() wird von DefaultHandler geerbt (in dieser Klasse auskommentiert). Die wesentliche Überschreibung ist propertyValuesEqual(), welche idModified() verwendet.

Wichtige Methoden

MethodeBeschreibung
accept(property)Wahr, wenn der Rückgabetyp eine Unterklasse von BaseDO ist
propertyValuesEqual(src, dest)Vergleicht Entitäts-IDs; wahr, wenn die IDs übereinstimmen (keine Änderung)

Begleitobjekt

fun idModified(srcObject: Any, destObject: Any): Boolean {
    val srcId = HibernateUtils.getIdentifier(srcObject)
    val destId = HibernateUtils.getIdentifier(destObject)
    return if (srcId != null) srcId != destId else false
}
