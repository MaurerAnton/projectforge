Manejador para propiedades de tipo BaseDO en el marco de copia e historial (CandH). Extiende DefaultHandler, acepta cualquier propiedad cuyo tipo de retorno sea una subclase de BaseDO. La comprobación de igualdad compara los identificadores de entidad mediante HibernateUtils.getIdentifier() en lugar de igualdad de objetos.

Arquitectura

Herencia

BaseDOHandler extiende DefaultHandler. El método process() se hereda de DefaultHandler (comentado en esta clase). La anulación clave es propertyValuesEqual() que utiliza idModified().

Métodos clave

MétodoDescripción
accept(property)Verdadero si el tipo de retorno es subclase de BaseDO
propertyValuesEqual(src, dest)Compara IDs de entidad; verdadero si los IDs coinciden (sin modificación)

Compañero

fun idModified(srcObject: Any, destObject: Any): Boolean {
    val srcId = HibernateUtils.getIdentifier(srcObject)
    val destId = HibernateUtils.getIdentifier(destObject)
    return if (srcId != null) srcId != destId else false
}
