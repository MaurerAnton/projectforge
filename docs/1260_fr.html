Gestionnaire pour les propriétés de type BaseDO dans le framework copie-et-historique (CandH). Étend DefaultHandler, accepte toute propriété dont le type de retour est une sous-classe de BaseDO. La vérification d'égalité compare les identifiants d'entité via HibernateUtils.getIdentifier() au lieu de l'égalité d'objet.

Architecture

Héritage

BaseDOHandler étend DefaultHandler. La méthode process() est héritée de DefaultHandler (commentée dans cette classe). La substitution clé est propertyValuesEqual() qui utilise idModified().

Méthodes clés

MéthodeDescription
accept(property)Vrai si le type de retour est une sous-classe de BaseDO
propertyValuesEqual(src, dest)Compare les ID d'entité ; vrai si les ID correspondent (aucune modification)

Companion

fun idModified(srcObject: Any, destObject: Any): Boolean {
    val srcId = HibernateUtils.getIdentifier(srcObject)
    val destId = HibernateUtils.getIdentifier(destObject)
    return if (srcId != null) srcId != destId else false
}
