Обработчик свойств типа BaseDO в фреймворке копирования и истории (CandH). Расширяет DefaultHandler, принимает любое свойство, чей возвращаемый тип является подклассом BaseDO. Проверка равенства сравнивает идентификаторы сущностей через HibernateUtils.getIdentifier() вместо сравнения объектов.

Архитектура

Наследование

BaseDOHandler расширяет DefaultHandler. Метод process() наследуется от DefaultHandler (закомментирован в этом классе). Ключевое переопределение — propertyValuesEqual(), которое использует idModified().

Ключевые методы

МетодОписание
accept(property)Возвращает true, если возвращаемый тип является подклассом BaseDO
propertyValuesEqual(src, dest)Сравнивает ID сущностей; возвращает true, если ID совпадают (изменений нет)

Компаньон

fun idModified(srcObject: Any, destObject: Any): Boolean {
    val srcId = HibernateUtils.getIdentifier(srcObject)
    val destId = HibernateUtils.getIdentifier(destObject)
    return if (srcId != null) srcId != destId else false
}
