#1263 : CandHHistoryAttrWrapper.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/candh/CandHHistoryAttrWrapper.kt Wrapper d'attribut d'historique, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/candh/CandHHistoryAttrWrapper.kt 91 lignes · 52 code · 32 commentaires · 7 vides
Encapsule un changement d'attribut d'historique unique (ancienne valeur → nouvelle valeur) dans le cadre du framework Copy-and-History. Contient la classe de type de propriété, le nom de la propriété, le type d'opération et les valeurs ancienne/nouvelle. La méthode prepareAndGetAttr() crée un HistoryEntryAttrDO et l'ajoute à un HistoryEntryDO parent, incluant un rappel optionnel CandHHistoryEntryICustomizer.
