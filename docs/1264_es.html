Interfaz para entidades que necesitan personalizar la creación de entradas de historial. Implementada por clases DO, el método único customizeHistoryAttrs() se llama durante CandHHistoryAttrWrapper.prepareAndGetAttr(), permitiendo a las entidades modificar el HistoryEntryAttrDO antes de que sea persistido. Usado, por ejemplo, por EmployeeDO para la visualización de atributos de tiempo.
