Interface pour les entités nécessitant une personnalisation de la création d'entrées d'historique. Implémentée par les classes DO, la méthode unique customizeHistoryAttrs() est appelée lors de CandHHistoryAttrWrapper.prepareAndGetAttr(), permettant aux entités de modifier le HistoryEntryAttrDO avant sa persistance. Utilisée par exemple par EmployeeDO pour l'affichage des attributs temporels.
