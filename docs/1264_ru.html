Интерфейс для сущностей, которым требуется настройка создания записей истории. Реализуется классами DO, единственный метод customizeHistoryAttrs() вызывается во время CandHHistoryAttrWrapper.prepareAndGetAttr(), позволяя сущностям изменять HistoryEntryAttrDO перед сохранением. Используется, например, EmployeeDO для отображения атрибутов времени.

Интерфейс

interface CandHHistoryEntryICustomizer {
    fun customizeHistoryAttrs(historyEntryAttr: HistoryEntryAttrDO)
}
