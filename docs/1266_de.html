Kernschnittstelle für handler auf Eigenschaftsebene im Kopieren-und-Historie-Framework. Jeder Handler entscheidet über accept(), ob er eine bestimmte veränderbare Eigenschaft behandelt, und verarbeitet sie dann über process(). Gibt true zurück, wenn behandelt (Verarbeitung stoppt), false, um den nächsten registrierten Handler zu versuchen.

Schnittstelle

interface CandHIHandler {
    fun accept(property: KMutableProperty1<*, *>): Boolean
    fun process(propertyContext: PropertyContext, context: CandHContext): Boolean
}

Implementierungen

  • DefaultHandler — primitive/Zeichenketten-Typen (Fallback)
  • BigDecimalHandler — skalenunabhängiger Vergleich
  • SqlDateHandler — java.sql.Date
  • UtilDateHandler — java.util.Date
  • CollectionHandler — Sammlungen mit Tiefenkopie
  • BaseDOHandler — BaseDO-Untertypen (Vergleich nach ID)
