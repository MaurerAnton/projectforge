Основной интерфейс для обработчиков на уровне свойств в фреймворке Копирования-и-Истории. Каждый обработчик через accept() определяет, обрабатывает ли он данное изменяемое свойство, затем обрабатывает его через process(). Возвращает true, если обработано (обработка останавливается), false — для перехода к следующему зарегистрированному обработчику.

Интерфейс

interface CandHIHandler {
    fun accept(property: KMutableProperty1<*, *>): Boolean
    fun process(propertyContext: PropertyContext, context: CandHContext): Boolean
}

Реализации

  • DefaultHandler — примитивные/строковые типы (запасной)
  • BigDecimalHandler — сравнение без учёта масштаба
  • SqlDateHandler — java.sql.Date
  • UtilDateHandler — java.util.Date
  • CollectionHandler — коллекции с глубоким копированием
  • BaseDOHandler — подтипы BaseDO (сравнение по ID)
