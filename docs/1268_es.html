El motor central para las operaciones de Copia e Historial. Un singleton que orquesta los manejadores a nivel de propiedad para fusionar objetos fuente en objetos destino y crear entradas de historial. Primero copia las propiedades persistidas, luego las propiedades transitorias (porque las transitorias pueden depender de valores persistidos). Solo se admiten clases Kotlin; las clases Java emiten una advertencia.

Arquitectura

Cadena de Manejadores

Registrados en el bloque init, se prueban en orden:

  1. BigDecimalHandler — comparación de BigDecimal insensible a escala
  2. SqlDateHandler — java.sql.Date
  3. UtilDateHandler — java.util.Date
  4. CollectionHandler — copia profunda de colecciones con seguimiento de añadir/eliminar/modificar
  5. BaseDOHandler — entidades BaseDO (comparar por ID)
  6. DefaultHandler — respaldo para todos los demás tipos

Proceso de Copia

  1. Inicializar proxy de Hibernate si es necesario
  2. Copiar ID si no está en la lista de ignorados y los IDs difieren
  3. Copiar primero las propiedades persistidas (usando KClassUtils.filterPublicMutableProperties)
  4. Copiar segundo las propiedades no persistidas/transitorias
  5. Omitir propiedades anotadas con @CandHIgnore, transitorias, estáticas o miembros de clase interna
