Центральный движок для операций копирования и истории. Синглтон, который координирует обработчики на уровне свойств для слияния исходных объектов с целевыми и создания записей истории. Сначала копируются сохраняемые свойства, затем временные (поскольку временные могут зависеть от сохраняемых значений). Поддерживаются только классы Kotlin; классы Java вызывают предупреждение.

Архитектура

Цепочка обработчиков

Зарегистрированы в блоке init, проверяются по порядку:

  1. BigDecimalHandler — сравнение BigDecimal без учёта масштаба
  2. SqlDateHandler — java.sql.Date
  3. UtilDateHandler — java.util.Date
  4. CollectionHandler — глубокое копирование коллекций с отслеживанием добавления/удаления/изменения
  5. BaseDOHandler — сущности BaseDO (сравнение по ID)
  6. DefaultHandler — резервный обработчик для всех остальных типов

Процесс копирования

  1. Инициализация прокси Hibernate при необходимости
  2. Копирование ID, если не в списке игнорирования и ID различаются
  3. Сначала копирование сохраняемых свойств (с помощью KClassUtils.filterPublicMutableProperties)
  4. Затем копирование несохраняемых/временных свойств
  5. Пропуск свойств, аннотированных @CandHIgnore, временных, статических или членов внутренних классов
