Gère les collections mutables (TreeSet, ArrayList, HashSet, PersistentSet, PersistentList) dans le framework CandH. Compare les collections source et destination pour détecter les entrées ajoutées, supprimées et conservées. Prend en charge la copie profonde des entrées de collection (lorsqu'elles sont gérées par l'entité propriétaire via @PersistenceBehavior(autoUpdateCollectionEntries=true)), la suppression logicielle via @SoftDeleteCollection, et le suivi historique des modifications de collection.

Architecture

Détection de gestion de collection

collectionManagedBySrcClazz() renvoie vrai lorsque :

  • La propriété n'est pas annotée avec @NoHistory
  • Possède @JoinColumn, @JoinTable, ou @OneToMany(mappedBy=...)

Fonctionnalités clés

FonctionnalitéDescription
Moteur de diffUtilise CollectionUtils.compareCollections() pour séparer les entrées ajoutées/supprimées/conservées
Suppression logicielle@SoftDeleteCollection marque les entrées comme supprimées au lieu de les retirer, préservant l'historique et évitant les violations de contrainte d'unicité
Réactivation d'entréeDétecte les entrées supprimées logiquement qui sont ré-ajoutées et les réactive
Copie profondeLorsque autoUpdateCollectionEntries=true, utilise copyValues() récursivement sur les entrées conservées pour détecter les modifications imbriquées
Instanciation de collectionCrée automatiquement le type de collection correspondant (TreeSet->TreeSet, HashSet->HashSet, ArrayList->ArrayList) lorsque la destination est nulle

Complément : Historique des nouvelles entrées

writeInsertHistoryEntriesForNewCollectionEntries() parcourt récursivement les collections fusionnées pour créer des entrées d'historique pour les entités enfants nouvellement insérées (dont les ID étaient nuls avant la fusion). Gère les hiérarchies de collections imbriquées (ex. facture → positions → affectations de coûts).
