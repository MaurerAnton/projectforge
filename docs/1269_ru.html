Обрабатывает изменяемые коллекции (TreeSet, ArrayList, HashSet, PersistentSet, PersistentList) в фреймворке CandH. Сравнивает исходную и целевую коллекции для обнаружения добавленных, удалённых и сохранённых записей. Поддерживает глубокое копирование записей коллекций (когда управляется сущностью-владельцем через @PersistenceBehavior(autoUpdateCollectionEntries=true)), мягкое удаление через @SoftDeleteCollection и отслеживание истории изменений коллекций.

Архитектура

Обнаружение управления коллекцией

collectionManagedBySrcClazz() возвращает true, когда:

  • Свойство не аннотировано @NoHistory
  • Имеет @JoinColumn, @JoinTable или @OneToMany(mappedBy=...)

Ключевые возможности

ВозможностьОписание
Механизм сравненияИспользует CollectionUtils.compareCollections() для разделения добавленных/удалённых/сохранённых записей
Мягкое удаление@SoftDeleteCollection помечает записи как удалённые вместо их удаления, сохраняя историю и избегая нарушений уникальных ограничений
Реактивация записейОбнаруживает повторно добавленные мягко удалённые записи и реактивирует их
Глубокое копированиеКогда autoUpdateCollectionEntries=true, рекурсивно использует copyValues() для сохранённых записей, чтобы обнаружить вложенные изменения
Создание коллекцииАвтоматически создаёт соответствующий тип коллекции (TreeSet->TreeSet, HashSet->HashSet, ArrayList->ArrayList), когда целевая коллекция равна null

Сопутствующий: история новых записей

writeInsertHistoryEntriesForNewCollectionEntries() рекурсивно обходит объединённые коллекции для создания записей истории для вновь вставленных дочерних сущностей (чьи ID были null до объединения). Обрабатывает вложенные иерархии коллекций (например, счёт → позиции → распределение затрат).
