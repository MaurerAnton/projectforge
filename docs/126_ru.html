plugins/org.projectforge.plugins.ihk/src/main/java/org/projectforge/plugins/ihk/IHKForm.java Путь: plugins/...ihk/src/main/java/.../IHKForm.java · Строк: 248 · Тип: Java Wicket Form — расширяет AbstractStandardForm 248 строк · 182 кода · 27 комментариев · 39 пустых

Wicket-форма для UI плагина IHK — предоставляет выбор недели, редактор конфигурации и кнопку экспорта. Расширяет AbstractStandardForm<Object, IHKPage> — базовый класс форм Wicket от ProjectForge с сеткой Bootstrap. 248 строк Java.

Элементы управления формы

  • Выбор недели (QuickSelectWeekPanel) — календарный виджет для выбора отчётной недели. Включает навигацию по предыдущей/следующей неделе и кнопку быстрого выбора «текущая неделя»
  • Отображение дат начала/окончания (LocalDatePanel + LocalDateModel) — показывает понедельник и пятницу выбранной недели как поля только для чтения
  • Раздел конфигурации — редактируемые поля для:
    • ausbildungsbeginn — дата начала обучения (с выбором даты)
    • ausbildungsjahr — переопределение года обучения (числовой ввод, по умолчанию -1)
    • teamname — название команды/отдела (текстовый ввод)
    Привязаны к IHKCommentObject через Wicket PropertyModel
  • Кнопка экспорта (SingleButtonPanel с SubmitLink) — запускает IHKExporter.export() и передаёт Excel-файл для скачивания через HTTP
  • Кнопка сохранения конфигурации — сериализует IHKCommentObject обратно в JSON и записывает его в поле комментария адресной книги (AddressDO.comment) через AddressDao

Процесс загрузки данных

  1. При инициализации формы считывает ThreadLocalUserContext.getLoggedInUser()
  2. Запрашивает AddressDao для поиска соответствующей записи в адресной книге (поиск по имени/фамилии)
  3. Если запись найдена и поле комментария содержит JSON, десериализует IHKCommentObject через JsonUtils.fromJson()
  4. Автоматически определяет, отсутствует ли у стажёра конфигурация — показывает подсказку по настройке

Wicket-разметка

Использует пакет flowlayout от ProjectForge для разметки формы на основе сетки Bootstrap:

  • FieldsetPanel — группирует связанные поля с заголовком
  • DivPanel / DivTextPanel — контейнеры сетки Bootstrap
  • GridSize.COL50 / COL100 — адаптивная ширина колонок
  • WicketUtils.getImageIcon() — иконки для кнопок (скачать, сохранить)
  • CSSColor — константы стилей для информационных сообщений и предупреждений

Валидация

  • ausbildungsbeginn должен быть корректной датой — вызывает UserException с локализованным сообщением, если дата отсутствует или неверна
  • Требуется, чтобы имя/фамилия стажёра совпадали с записью AddressDO — если совпадение не найдено, отображается предупреждение

Цикл запроса

Отправка Wicket-формы → onSubmit() → вызывает IHKExporter.export() → возвращает byte[] → оборачивает в IResourceStream → запускает скачивание браузером файла Berichtsheft_KW{week}_{Name}.xlsx.
