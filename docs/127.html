#127: IHKPlugin.java

Plugin entry point, plugins/org.projectforge.plugins.ihk/src/main/java/org/projectforge/plugins/ihk/IHKPlugin.java
Main plugin class for the IHK (Industrie- und Handelskammer) module. Extends AbstractPlugin to register the plugin in ProjectForge's plugin system via the Java ServiceLoader mechanism. Provides week-based timesheet export as IHK-compliant training reports (Ausbildungsnachweise) for German vocational trainees.

Architecture

IHKPlugin is the bootstrap class for the IHK plugin. It subclasses AbstractPlugin and is discovered through the META-INF/services file at META-INF/services/org.projectforge.plugins.core.AbstractPlugin, which contains the single line org.projectforge.plugins.ihk.IHKPlugin.

Plugin Registration Lifecycle

The constructor calls super("ihk", "IHK", "..."), passing the plugin ID, short name, and a German-language description. The initialize() method (called by AbstractPlugin's lifecycle) performs these registrations in order:

  1. DAO registration: register(getId(), TimesheetDao.class, ...) — makes the timesheet DAO available to the IHK module, scoped under "plugins.ihk".
  2. Wicket web registration: pluginWicketRegistrationService.registerWeb(getId()) — mounts the plugin's Wicket web resources.
  3. Menu registration: Registers an IHK-Report menu under the Misc menu (MenuItemDefId.MISC), pointing to IHKPage.class with i18n key "plugins.ihk.menu".
  4. Access rights: registerRight(new IHKRight()) — installs the plugin's access control (see #128).
  5. i18n resources: addResourceBundle(RESOURCE_BUNDLE_NAME) with bundle name "IHKI18nResources" — loads the default and _de locale property files.

Log Subscription Utility

The static method ensureUserLogSubscription() creates or retrieves a LogSubscription scoped to "org.projectforge.plugins.ihk" loggers, tied to the currently logged-in user. This enables the IHK page to offer a direct link to the log viewer for troubleshooting export operations.

Design Decisions

  • Explicit DAO registration vs. Spring auto-wiring: The plugin manually registers TimesheetDao through WicketSupport.get() rather than relying on @Autowired. This follows the AbstractPlugin pattern where DAO registrations map to scripting engine namespaces and dump/import ordering.
  • Static log subscription: The subscription is created per-user on page load via IHKPage, not eagerly at plugin init. This avoids creating subscriptions for users who never visit the IHK page.
  • No persistent entities: Unlike plugins such as ToDo or Memo, the IHK plugin doesn't define its own PERSISTENT_ENTITIES array — it operates entirely on existing TimesheetDO objects. The plugin is a pure read/export layer.
