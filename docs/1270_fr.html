Le gestionnaire de repli dans la chaîne de gestion CandH. Accepte tous les types de propriétés et fournit une comparaison d'égalité simple via propertiesValuesEqual() (remplaçable par les sous-classes). Gère la comparaison de chaînes null-safe (les chaînes null et vides sont considérées comme égales). Définit la propriété de destination sur la valeur source si différente, puis appelle propertyWasModified() pour le suivi historique.

Architecture

Méthodes clés

MéthodeDescription
accept(property)Retourne toujours true — attrape-tout après les gestionnaires spécialisés
propertyValuesEqual(src, dest)Comparaison simple == ; remplacée par BigDecimalHandler et BaseDOHandler
process(ctx, context)Compare les valeurs, définit la destination si modifiée, déclenche l'historique via propertyWasModified()

La méthode privée propertyNullableValuesEqual() gère la null-sécurité et l'égalité null/vide spécifique aux chaînes via l'extension isEqualsTo.
