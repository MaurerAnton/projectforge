#1271: HistoryContext.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/candh/HistoryContext.kt Построитель записей истории, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/candh/HistoryContext.kt 186 строк · 114 кода · 58 комментариев · 14 пустых
Внутренний контекст для накопления записей истории во время операции CandH. Поддерживает стек объектов CandHHistoryEntryWrapper (для вложенной обработки сущностей) и плоский список всех обёрток. При финализации преобразует все обёртки в объекты HistoryEntryDO и рекурсивно обнаруживает новые записи коллекций для вставки в историю.

Архитектура

Стековая вложенная история

Использует historyEntryWrapperStack (push/pop) для обработки вложенных сущностей (например, позиции счёта внутри счёта). currentHistoryEntryWrapper — вершина стека; атрибуты добавляются к текущей обёртке.

Ключевые методы

МетодОписание
pushHistoryEntryWrapper(entity, opType)Помещает новую обёртку уровня сущности в стек
popHistoryEntryWrapper()Извлекает и при необходимости удаляет обёртку, если не было добавлено атрибутов
add(propertyContext, opType)Добавляет атрибут истории уровня свойства из PropertyContext
getPreparedHistoryEntries(mergedObj, srcObj)Финализация: подготавливает все записи и обнаруживает новые записи коллекций

Вызывает CollectionHandler.writeInsertHistoryEntriesForNewCollectionEntries() для рекурсивного поиска событий вставки сущностей в иерархиях коллекций.
