Data-класс, фиксирующий состояние одного свойства во время обработки копирования/истории. Содержит исходный и целевой объекты, метаданные свойства (имя, KMutableProperty1) и текущие значения для сравнения. Также отслеживает, являются ли элементы коллекции историзируемыми, и предоставляет класс типа свойства для создания атрибутов истории.
