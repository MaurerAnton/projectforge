1275: I18nHelper.kt

Utility Object, projectforge-business/.../i18n/I18nHelper.kt
Central i18n resolution utility. Manages a prioritized list of resource bundle names, resolves localized messages with MessageFormat parameter substitution, and supports per-user locale resolution.

Architecture & Role

I18nHelper is a Kotlin object (singleton) that sits between the application code and the Spring-managed I18nService. It maintains an ordered set of bundle names and iterates through them to find translations, falling through to the next bundle if a key is not found.

Bundle Priority System

  • Bundles are stored in a LinkedHashSet<String> preserving insertion order.
  • addBundleName(bundleName) adds at the end (lower priority).
  • addBundleNameWithHighestPriority(bundleName) inserts at the front — used for customer-specific overrides that should win over built-in translations.
  • Special handling for "CustomerI18nResources": loaded via I18nService from the file-system resource directory rather than from the classpath.

Localization Resolution

MethodDescription
getLocalizedMessage(i18nKey, vararg params)Resolves key for ThreadLocalUserContext.locale and formats with parameters via MessageFormat. Unknown keys get "???" prefix.
getLocalizedMessage(user, i18nKey, vararg params)Resolves key for a specific user's locale (used for email notifications).
getLocalizedMessage(locale, i18nKey, vararg params)Direct locale-based resolution with formatting.
getLocalizedString(locale, i18nKey)Iterates bundle list; returns the key itself if no bundle matches (no "???" prefix for already-translated text).

Companion Integration

The I18nService instance is injected via setI18nService(). Standard bundles are loaded from the classpath via ResourceBundle.getBundle(); only CustomerI18nResources uses the external file-system directory through I18nService.
