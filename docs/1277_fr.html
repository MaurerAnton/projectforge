projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/database/DatabaseDao.kt Service d'index et de réindexation, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/database/DatabaseDao.kt 131 lignes · 83 code · 38 commentaires · 10 vides
Classe de service fournissant la gestion des index Hibernate Search. Les fonctionnalités clés incluent la reconstruction des index de recherche de la base de données via rebuildDatabaseSearchIndices() en utilisant le MassIndexer de Hibernate Search avec des ReindexSettings et un IndexProgressMonitor configurables. Empêche les exécutions de réindexation concurrentes et fournit des messages d'état formatés avec le timing et le nombre d'entités.

Dépendances du constructeur

  • entityManagerFactory — JPA EntityManagerFactory pour la création de session Search
