1278: NumberHelper.kt

Utility Object, projectforge-business/.../utils/NumberHelper.kt
Comprehensive numeric utility: parsing (strict/lax int, long, BigDecimal, currency), formatting (bytes, fractions, currency), arithmetic, secure random generation (password tokens), phone-number extraction, and comparison helpers.

Architecture & Role

NumberHelper is a Kotlin object and the go-to numeric utility for all ProjectForge modules. It bridges Java's NumberUtils/NumberFormat with Kotlin idioms and ProjectForge-specific conventions (German currency format, phone number extraction, locale-aware formatting).

Parsing Methods

MethodDescription
parseInteger(value, logMessage?)Parses string to Int, suppressing warnings optionally.
parseLocalizedInt(input, strict?)Parses locale-formatted strings (German/English thousand separators). Strict mode rejects decimals and mixed separators.
parseLong(value, logMessage?)Parses string to Long.
parseShort(value)Parses string to Short.
parseBigDecimal(value)Parses with comma-to-dot replacement (German decimal support).
parseCurrency(value, locale)Parses a locale-formatted currency string to BigDecimal(2).

Formatting & Display

  • formatBytes(bytes: Int? / Long?) — "1023 bytes", "1.1 KB", "523 KB", "1.7 MB" via FormatterUtils.
  • formatFraction2(value) — locale-aware 2-digit fraction formatting.
  • getAsString(value, format?) — null-safe string conversion.
  • setDefaultScale(number) — scale 0 for ≥100, scale 1 for ≥20, scale 2 otherwise.

Phone Number Utils

  • extractPhonenumber(str, countryPrefix?) — strips formatting, replaces +XX with 00XX (international) or 0 (national match). Removes hidden UTF control chars (Apple Contacts).
  • formatPhonenumber(str) — delegates to PhoneNumberUtils.normalizePhoneNumber().
  • matchesPhoneNumber(str) — regex check for plausible phone strings.

Secure Random Generation

MethodCharsetUse Case

getSecureRandomReducedAlphanumericWithSpecialChars(length)Reduced + * # + - etc.DataTransfer passwords (guarantees ≥1 special char)

Each generator has a corresponding check* validation method.

Comparison & Math

  • isEqual(value1, value2) — null-safe compareTo for BigDecimal, Int, Long.
  • isZeroOrNull(value) / isNotZero(value) — null-safe zero checks.
  • add(v1, v2) — null-safe BigDecimal addition.
  • getPercent(part, total, scale?) / getFraction(part, total, scale?) — safe division.
  • splitToInts / splitToLongs — digit-string splitting (e.g., 11110511 → {1, 111, 5, 11}).
  • ensureRange(min, max, value) — clamps to range.
