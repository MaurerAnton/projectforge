projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/database/DatabaseService.kt Service d'administration de base de données, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/database/DatabaseService.kt 484 lignes · 350 code · 86 commentaires · 48 vides
Service administratif pour les opérations de base de données incluant la configuration des utilisateurs/groupes/tâches, la vérification des accès et la gestion du schéma de base de données. Fournit des méthodes pour créer des utilisateurs administrateurs, vérifier les contraintes, lister les tâches/utilisateurs et gérer les connexions à la base de données. Utilise JDBC via DatabaseSupport et DatabaseExecutor pour les opérations SQL directes aux côtés de JPA.
