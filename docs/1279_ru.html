projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/database/DatabaseService.kt Сервис администрирования базы данных, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/database/DatabaseService.kt 484 строки · 350 кода · 86 комментариев · 48 пустых
Административный сервис для операций с базой данных, включая настройку пользователей/групп/задач, проверку доступа и управление схемой базы данных. Предоставляет методы для создания администраторов, проверки ограничений, вывода списка задач/пользователей и управления подключениями к БД. Использует JDBC через DatabaseSupport и DatabaseExecutor для прямых SQL-операций наряду с JPA.
