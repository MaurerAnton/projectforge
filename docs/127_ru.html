Главная страница плагина IHK — позволяет стажёрам (Auszubildende) выбрать неделю, просмотреть свои записи в табеле и экспортировать их в виде отчёта Excel, соответствующего требованиям IHK. Является частью системы дуального профессионального обучения (Duale Ausbildung), предписанной немецким законодательством.

Архитектура

Расширяет AbstractStandardFormPage (базовую страницу Wicket в ProjectForge) и реализует ISelectCallerPage (для виджета быстрого выбора календаря). Страница содержит компонент IHKForm в своём теле.

Жизненный цикл:
1. Конструктор: создаёт IHKForm, инициализирует его, добавляет ссылку LogViewer в меню содержимого
2. select(): обрабатывает клики быстрого выбора календаря — устанавливает диапазон дат на неделю выбранной даты (понедельник–воскресенье)
3. export(): запрашивает табели за выбранную неделю, проверяет наличие описаний, делегирует генерацию Excel-файла в IHKExporter, инициирует загрузку
4. edit(): переходит на TimesheetEditPage для исправления отсутствующих описаний

Процесс валидации

Метод export() имеет два этапа проверки:
1. Табели не найдены: Если findTimesheets() возвращает пустой результат, выводится ошибка "plugins.ihk.noitemsfound"
2. Отсутствуют описания: IHK требует, чтобы каждая запись табеля имела описание. Если у какой-либо записи description == null, выводится ошибка "plugins.ihk.nodescriptionfound" и отображается список проблемных записей. Пользователь может вызвать export(true) для обхода проверки (на свой страх и риск).

Эта двухэтапная валидация представляет собой UX-паттерн: сначала быстрый отказ с вежливой ошибкой, затем точное указание записей, требующих исправления, и предоставление запасного варианта для случаев, когда описание действительно не нужно.

Важный нюанс — Обработка часовых поясов: Расчёт недельного диапазона использует ThreadLocalUserContext.getTimeZone(), чтобы границы понедельника–воскресенья вычислялись в часовом поясе пользователя. Использование серверного часового пояса привело бы к ошибке смещения на один день для пользователей в других часовых поясах. Коммит bf872fc9a (PROJECTFORGE-2524) специально исправил ошибку часового пояса в экспорте IHK.
Почему Wicket, а не React? Плагин IHK — один из старых плагинов, который всё ещё использует Apache Wicket для своего интерфейса. Новые плагины используют стек REST+React. IHKPage остаётся на Wicket, потому что: (а) это одностраничная форма без сложного взаимодействия, (б) плагин имеет низкий трафик (используется только стажёрами, а не всеми сотрудниками), и (в) затраты на миграцию не оправдывают выгоду от переписывания.
