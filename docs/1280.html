1280: PhoneNumberUtils.kt

Utility Object, projectforge-business/.../utils/PhoneNumberUtils.kt
International phone number normalization and comparison. Converts varied input formats (national, international, with extensions) into a canonical +CC AAA NNNNNNN[-EXT] format using a comprehensive country-code lookup table.

Architecture & Role

PhoneNumberUtils provides the canonical phone number representation used throughout ProjectForge — in SIP/VoIP integration, address book vCard import, and the React UI. It decouples raw user input (with parentheses, slashes, "Tel:" prefixes) from the normalized storage format.

Normalization Pipeline

  1. Cleanup: Remove "Tel:", "Phone:", "Mobil:", "Fax:" prefixes; strip UTF control chars; remove (0) trunk prefix; remove parentheses and slashes.
  2. Short number pass-through: Numbers with 1–3 digits (emergency/extension numbers) are returned unchanged unless they start with 00 or +.
  3. Country code extraction — extractCountryCode() handles three input styles:
    • +CC ... — Already international. Matches against known country codes (1–3 digits) using longest-match-first.
    • 00CC ... — International prefix format. Converts to +CC.
    • 0AAA ... — National format. Prepends default country prefix from Configuration (default +49).
    • No prefix — Returns cleaned number with normalized spaces.
  4. Extension detection: Last hyphen followed by 1–4 digits is treated as an extension and appended after the main number.
  5. Whitespace normalization: Dots and hyphens replaced with spaces; multiple spaces collapsed.

Country Code Database

A hard-coded KNOWN_COUNTRY_CODES set containing ~200 country codes (1-digit through 3-digit), organized by world region. Used for detecting the country code boundary in international numbers.

Example Transformations

"0561 316793-0"           → "+49 561 316793-0"
"+49 (0) 561 / 316793-0"  → "+49 561 316793-0"
"0170 1234567"            → "+49 170 1234567"
"+1 415 555-1234"         → "+1 415 5551234"
"112"                     → "112" (short number passthrough)
