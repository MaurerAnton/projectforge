Servicio para probar la seguridad en hilos y la corrección del caché. Inicia 10 hilos concurrentes, cada uno realizando 1000 iteraciones de lecturas de caché de usuarios, comparando los resultados con una instantánea JSON para detectar inconsistencias. Se utiliza desde la AdminPage para depurar el comportamiento de UserGroupCache bajo acceso concurrente.
