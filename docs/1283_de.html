Hilfsobjekt, das typsichere Extraktionsmethoden aus JDBC ResultSet bereitstellt. Behandelt SQL-NULL-Erkennung über rs.wasNull() und bietet Getter für String, Long, BigDecimal, Date, Timestamp, LocalDate, Boolean und byte[]-Typen. Enthält einen debugColumnResult()-Helfer für die Diagnoseprotokollierung von Ergebnismengenspalten.
