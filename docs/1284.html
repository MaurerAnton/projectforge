1284: SendMail.kt

Core Service, projectforge-business/.../mail/SendMail.kt
Central email sending service with SMTP configuration, MIME multipart support (calendar invites, attachments), Groovy template rendering for dynamic emails, and async delivery via CompletableFuture.

Architecture & Role

SendMail is a Spring @Service that encapsulates all outbound email in ProjectForge. It reads SMTP settings from application.properties, builds Jakarta Mail MimeMessages with optional iCal content and arbitrary attachments, renders email bodies through Groovy templates, and provides both async (default) and synchronous sending modes.

MIME Multipart Handling

The private createMailAttachmentContent() builds multipart messages:

  • Body part: HTML or text content with charset.
  • iCal part (optional): Calendar invite with method=REQUEST header and text/calendar content type.
  • Attachments: Each IMailAttachment is added as a MIME body part with auto-detected content type via MimetypesFileTypeMap.

Protocol: Plain / StartTLS / SSL

The Protocol enum controls the transport security. In session property setup, StartTLS enables mail.smtp.starttls.enable, SSL enables mail.smtp.ssl.enable. Plain uses no encryption.

Test Mode

Companion.internalSetTestMode() sets a static flag that prevents actual Transport.send(), logging instead. Used by test cases.
