Classe de données définissant la stratégie de réindexation pour un type d'entité : clause HQL de jointure optionnelle (par ex. "left join fetch t.attributes"), le nom de la propriété ID ("id" pour la plupart des entités, "pk" pour HistoryEntryDO), et la propriété de dernière modification pour la réindexation incrémentielle ("lastUpdate" pour AbstractBaseDO). Utilisée par ReindexerRegistry et HibernateSearchReindexer.
