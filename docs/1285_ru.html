Класс данных, определяющий стратегию переиндексации для типа сущности: необязательное HQL-выражение JOIN (например, "left join fetch t.attributes"), имя свойства ID ("id" для большинства сущностей, "pk" для HistoryEntryDO) и свойство последнего изменения для инкрементальной переиндексации ("lastUpdate" для AbstractBaseDO). Используется ReindexerRegistry и HibernateSearchReindexer.
