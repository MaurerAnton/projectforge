Motor de serialización central para volcado/restauración JSON de base de datos. Configura ObjectMapper de Jackson con serializadores personalizados (UtilDateSerializer, TimestampSerializer), el MyJacksonModule para el manejo de referencias circulares de AbstractBaseDO y soporte del módulo Kotlin. Escribe un encabezado JSON con la versión de ProjectForge y la marca de tiempo, luego itera todas las entidades registradas y las serializa con inicialización de Hibernate.
