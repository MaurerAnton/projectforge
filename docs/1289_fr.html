Moteur de sérialisation central pour l'export/import JSON de base de données. Configure Jackson ObjectMapper avec des sérialiseurs personnalisés (UtilDateSerializer, TimestampSerializer), le MyJacksonModule pour la gestion des références circulaires AbstractBaseDO, et le support du module Kotlin. Écrit un en-tête JSON avec la version de ProjectForge et l'horodatage, puis parcourt toutes les entités enregistrées et les sérialise avec l'initialisation Hibernate.
