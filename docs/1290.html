1290: Configuration.kt

Cache / Facade, projectforge-business/.../configuration/Configuration.kt
In-memory cache of all database-stored system parameters (ConfigurationParam enum), backed by AbstractCache. Provides typed accessors (String, Boolean, BigDecimal, TimeZone, DateFormat) and validates domain names and calendar domains.

Architecture & Role

Configuration extends AbstractCache with a 1-hour expiry. It loads all ConfigurationParam values from the database (via ConfigurationService.daoInternalLoadAll()) into a Map<ConfigurationParam, Any?>. It is a singleton accessible via Configuration.instance.

Constructor & Initialization

Created by ConfigurationService.postConstruct(). Takes a ConfigurationService reference (for DAO access) and an optional PfPersistenceService (for isolated transaction refresh). In test mode, persistenceService is null and refresh runs in the calling thread.

Refresh Lifecycle

  1. checkRefresh() (inherited from AbstractCache) checks expiry.
  2. refresh() either calls doRefresh() directly (test mode) or runs it in an isolated read-only transaction via PfPersistenceService.runIsolatedReadOnly().
  3. doRefresh() loads all ConfigurationDO rows, maps each ConfigurationParam enum to its typed value via ConfigurationService.getDaoValue(), and atomically replaces the map.

    4. Manual Updates

    putParameterManual(param, value) allows direct insertion into the cache without a database write — used during initialization before the DB is available. ConfigurationDao.afterInsertOrModify() calls setExpired() to invalidate the cache on writes.
