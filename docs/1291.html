1291: ConfigurationDao.kt

DAO / Data Access Object, projectforge-business/.../configuration/ConfigurationDao.kt
Data access service for ConfigurationDO entities. Extends BaseDao and provides typed value retrieval, database entry synchronization (create missing, update stale, delete obsolete), and access control restricted to admin group members.

Architecture & Role

ConfigurationDao is a Spring @Service extending BaseDao<ConfigurationDO>. It is the sole writer of configuration rows and the authoritative source for typed value conversion. The higher-level Configuration cache delegates to it indirectly via ConfigurationService.getDaoValue().

Key Methods

MethodDescription
checkAndUpdateDatabaseEntries()Iterates all ConfigurationParam enum values: creates missing entries with defaults, fixes stale types, restores soft-deleted entries, and marks orphaned rows as deleted. Runs in a transaction.
getEntry(param)Looks up a single ConfigurationDO by parameter key using the FIND_BY_PARAMETER named query.
getValue(parameter, configurationDO?)Type-aware value extraction: STRING→String, FLOAT/PERCENT→BigDecimal, LONG→Long (nullable), BOOLEAN→Boolean, CALENDAR→Long, TIME_ZONE→TimeZone. Falls back to defaults when entry is null.
getValue(parameter)Convenience: fetches entry then extracts value.

Type Resolution

The value extraction maps ConfigurationType to the appropriate ConfigurationDO field (stringValue, longValue, floatValue). Special handling for TIME_ZONE (resolves TimeZone.getTimeZone(id)), CALENDAR (returns calendar ID as Long), and PERCENT (alias for FLOAT).

Access Control

Overrides BaseDao.hasAccess(): only members of the ADMIN_GROUP have read/write access to configuration entries. All other users are rejected.

Cache Coordination

afterInsertOrModify(obj, operationType) calls Configuration.instance.setExpired() after every write, ensuring the cache is stale and will reload on next checkRefresh().

Disabled Operations

newInstance() throws UnsupportedOperationException — new configuration entries are managed exclusively by checkAndUpdateDatabaseEntries().
