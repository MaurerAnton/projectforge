Отслеживает уже сериализованные объекты AbstractBaseDO во время дампа базы данных в JSON. Ведёт карту класс → список записанных ID. Метод wasWritten() проверяет, была ли сущность с тем же классом и ID уже сериализована; markAsWritten() регистрирует ID сущности, чтобы предотвратить рекурсию циклических ссылок в сериализаторе Jackson.
