1292: ConfigurationDO.kt

JPA Entity, projectforge-business/.../configuration/entities/ConfigurationDO.kt
Hibernate ORM entity mapped to T_CONFIGURATION. Stores typed configuration parameters using separate columns per type (string, long, float), with a configurationType discriminator and type-safety assertions on access.

Architecture & Role

ConfigurationDO is a JPA entity extending DefaultBaseDO (which provides id, created, lastUpdate, deleted). It uses Hibernate Search annotations (@Indexed, @FullTextField) and has an @AUserRightId("ADMIN_CORE") annotation for access control. Each row is uniquely constrained on parameter.

Type System

Rather than storing all values as strings, the entity has three physical columns:

ColumnJava TypeUsed By
stringValue (4000 chars)String?STRING, TEXT, BOOLEAN, TIME_ZONE

Each typed getter/setter validates that the entity's configurationType is compatible before allowing access. Compatibility allows some type aliases (e.g., STRING can read TEXT/BOOLEAN/TIME_ZONE; LONG can read CALENDAR; FLOAT can read PERCENT).

Type Mutability Rules

The configurationType setter and setType() method enforce that a type can only be changed to a compatible type (STRING ↔ TEXT/BOOLEAN/TIME_ZONE, LONG ↔ CALENDAR, FLOAT ↔ PERCENT). Cross-type changes throw UnsupportedOperationException. internalSetConfigurationType() bypasses checks and clears incompatible columns.
