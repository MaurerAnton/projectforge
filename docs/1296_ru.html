Модель для отображения одной записи истории на стороне фронтенда. Содержит ID, временную метку изменения, локализованную строку «время назад», информацию о пользователе, внёсшем изменения, тип операции, комментарий пользователя, сводку изменений атрибутов, количество различий и список дочерних элементов DisplayHistoryEntryAttr. Используется в представлениях истории на React.
