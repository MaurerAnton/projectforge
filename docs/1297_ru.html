Модель для внешнего интерфейса, представляющая изменение одного свойства в записи истории. Содержит идентификатор атрибута, тип операции (с переведённой отображаемой строкой), имя свойства, переведённое отображаемое имя свойства (через I18n), а также отформатированные старые/новые значения. Создаётся из HistoryEntryAttrDO с помощью статического фабричного метода create().
