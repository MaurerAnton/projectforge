1298: ConfigurationService.kt

Core Bootstrap Service, projectforge-business/.../configuration/ConfigurationService.kt
Central configuration bootstrap and runtime facade. Initializes directories, SSL keystores, the Configuration cache, and exposes all system properties (from application.properties) plus DB-backed parameters through typed accessors.

Architecture & Role

ConfigurationService is a Spring @Service that acts as the bridge between Spring's property injection (@Value) and the database-backed Configuration cache. It is bootstrapped via @PostConstruct init() and is accessible globally through ConfigurationServiceAccessor.

Bootstrap Sequence (init())

  1. Registers itself in ConfigurationServiceAccessor
  2. Loads ConfigXml from the application home directory (contract types, etc.)
  3. Creates the resources directory, fonts directory, and plugins directory
  4. Creates environment.sh for Docker installations
  5. Initializes SSL keystore if configured
  6. Instantiates the Configuration cache singleton

Resource & Template Resolution

  • getResourceContentAsString(filename) — loads a file from the resource directory (file system first, then classpath fallback) as UTF-8 String.
  • getResourceAsInputStream(filename) — returns InputStream + URL pair, with logging of whether the file was found.
  • getTemplateFile(dir, filename, resourceFilename) — resolves template files from file system or classpath officeTemplates.
  • getOfficeTemplateFile(filename) — convenience for office template resolution.

SSL Keystore Setup

setupKeyStores() loads a custom certificate keystore and builds an SSLSocketFactory via createSSLSocketFactory(), stored as usersSSLSocketFactory for external HTTPS connections.
