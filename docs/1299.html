1299: DatabaseService.kt

Core Bootstrap Service, projectforge-business/.../persistence/database/DatabaseService.kt
Database initialization, schema management, and administrative utility service. Handles first-run data seeding (admin user, root task, groups, global addressbook), index creation, schema updates, and database shutdown. Access-restricted to admin users.

Architecture & Role

DatabaseService is a Spring @Service that serves as the administrative gateway for database-level operations. It integrates UserDao, GroupDao, UserRightDao, TaskTree, AddressbookDao, UserGroupCache, and HibernateSearchReindexer for initialization. All public methods call accessCheck(), which requires admin group membership.

Database Engine Support

Wraps a DatabaseSupport instance keyed by the Hibernate databaseDialect (PostgreSQL, HSQLDB, etc.) and a DatabaseExecutor (JDBC) for raw SQL execution.

Admin User Initialization

The seeded admin user (admin) gets full read-write rights on all major modules: financial accounting (FIBU), HR, organization, project management, and order book. Groups are created as local (non-synchronized) and assigned to the admin. The ThreadLocalUserContext is set to the admin user during initialization to avoid access exceptions.

Access Control

accessCheck() allows the SYSTEM_ADMIN_PSEUDO_USER (internal system user) to bypass checks. For real users, it verifies admin group membership via Login.isAdminUser() and also checks AccessChecker.checkRestrictedOrDemoUser() to prevent operations on demo/restricted installations.

Internal Facilities

Methods with internal prefix (internalDoesTableExist, internalIsTableEmpty) skip accessCheck() and are used during initialization before the user system is available.
