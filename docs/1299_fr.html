Modèle sérialisable représentant une entrée d'historique aplatie (une ligne par modification d'attribut). Utilisé par les pages de liste Wicket et les notifications par e-mail (par exemple, AuftragDao, TodoDao). Contient l'ID d'entrée, l'ID d'attribut, les informations utilisateur, les horodatages, les noms/valeurs de propriétés et le nom de l'entité. Dérivé de DisplayHistoryEntry par FlatHistoryFormatService.
