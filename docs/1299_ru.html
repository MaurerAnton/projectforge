projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/history/FlatDisplayHistoryEntry.kt Модель плоского отображения истории, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/history/FlatDisplayHistoryEntry.kt 193 строки · 97 кода · 78 комментариев · 18 пустых
Сериализуемая модель, представляющая сглаженную запись истории (одна строка на изменение атрибута). Используется в списковых страницах Wicket и email-уведомлениях (например, AuftragDao, TodoDao). Содержит ID записи, ID атрибута, информацию о пользователе, временные метки, имя/значения свойства и имя сущности. Производная от DisplayHistoryEntry через FlatHistoryFormatService.
