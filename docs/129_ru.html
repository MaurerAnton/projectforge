plugins/org.projectforge.plugins.ihk/src/main/java/org/projectforge/plugins/ihk/IHKRight.java Контроль доступа, plugins/org.projectforge.plugins.ihk/src/main/java/org/projectforge/plugins/ihk/IHKRight.java 59 строк · 26 кода · 28 комментариев · 5 пустых
Проверка прав доступа для плагина IHK. Расширяет UserRightAccessCheck<TimesheetDO>, чтобы гарантировать, что пользователи могут просматривать и экспортировать только свои собственные табели учёта рабочего времени через отчёт об обучении IHK.

Архитектура

IHKRight регистрируется в IHKPlugin.initialize() через registerRight(new IHKRight()) и управляет всем доступом к данным табелей в контексте модуля IHK.

Конструктор

public IHKRight() {
    super(IHKPluginUserRightId.IHK, UserRightCategory.PLUGINS, UserRightValue.TRUE);
}

Привязывается к значению перечисления IHKPluginUserRightId.IHK (идентификатор "PLUGIN_IHK"), категоризированному как PLUGINS, со значением по умолчанию TRUE (включено для всех пользователей по умолчанию). Это означает, что право отображается в интерфейсе администрирования пользователей в категории «Плагины» и изначально предоставляется каждому.

Логика доступа

Метод hasAccess(PFUserDO user, TimesheetDO obj, TimesheetDO oldObj, OperationType operationType) реализует простую проверку владельца:

  • Если и obj, и oldObj равны null, возвращает true — общий доступ на вставку/выбор предоставляется по умолчанию.
  • В противном случае сравнивает user.getId() с timesheet.getUserId() с помощью Objects.equals() — только владелец табеля может получить к нему доступ через модуль IHK.

Проектные решения

  • Право, включённое по умолчанию: Использование UserRightValue.TRUE означает, что все пользователи по умолчанию имеют право IHK. Администраторы могут отозвать его для отдельных пользователей или групп в интерфейсе управления доступом, но обычному стажёру не требуется явное назначение.
  • Доступ только владельцу: Проверка намеренно проста. Стажёр может экспортировать только свои собственные табели. В этом классе нет переопределения для руководителя/менеджера — более широкий доступ предоставляется через другие механизмы доступа ProjectForge (например, собственные проверки доступа TimesheetDao).
  • Безопасность при null: Использует oldObj != null ? oldObj : obj для обработки сценариев обновления, где исходный объект может содержать соответствующий идентификатор пользователя.
