Objeto de utilidad que puentea las operaciones de BaseDao con el sistema de historial. Verifica si una entidad es historizable (mediante herencia de AbstractHistorizableBaseDO o anotación @WithHistory), crea registros HistoryEntryDO para operaciones de inserción/actualización y soporta entradas de historial de un solo atributo. Contiene extenso código heredado comentado para seguimiento completo del historial con comparación de propiedades antiguas/nuevas.

Arquitectura

Detección de historizabilidad

  • isHistorizable(bean: Any?) — verifica el objeto en tiempo de ejecución
  • isHistorizable(entityClass: Class<*>) — verifica si la clase extiende AbstractHistorizableBaseDO o tiene anotación @WithHistory

Creación de entradas de historial

MétodoDescripción
createHistoryEntry(entity, opType)Crea un HistoryEntryDO con ID de entidad, nombre de entidad, tipo de operación, marca de tiempo y usuario actual
createHistoryUpdateEntryWithSingleAttribute(entity, propertyName, propertyTypeClass, oldValue, newValue)Crea una entrada de historial con un único HistoryEntryAttrDO comparando valores antiguos vs nuevos
insertHistoryEntry(entity, historyEntry, context)Persiste la entrada de historial; soporta CandHHistoryEntryICustomizer para personalización específica de entidad
insertHistoryUpdateEntryWithSingleAttribute(...)Combinación crear+insertar para actualizaciones de un solo atributo

Métodos hook públicos (usados por BaseDao)

MétodoLlamado cuando
inserted(obj, context)Después de insertar entidad; crea entrada de historial INSERT si es historizable
updated(obj, historyEntries, context)Después de actualizar entidad; persiste todas las entradas de historial proporcionadas si es historizable y no vacío

Código heredado (comentado)

El archivo contiene ~200 líneas de métodos Java comentados (wrapHistoryUpdate, getSubEntitiesToHistoricizeDeep, getSubEntitiesToHistoricize, etc.) que anteriormente manejaban el cálculo automático de diferencias y el historial profundo de entidades para colecciones anotadas con @PFPersistancyBehavior(autoUpdateCollectionEntries=true). Esta funcionalidad fue refactorizada en HistoryService u otros componentes de historial.

Tipos de operación

  • EntityOpType.Insert — nueva entidad creada
  • EntityOpType.Update — entidad existente modificada
  • PropertyOpType.Update — propiedad individual cambiada (usado en entradas de atributo)
