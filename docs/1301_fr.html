Objet utilitaire faisant le pont entre les opérations BaseDao et le système d'historique. Vérifie si une entité est historisable (via l'héritage de AbstractHistorizableBaseDO ou l'annotation @WithHistory), crée des enregistrements HistoryEntryDO pour les opérations d'insertion/mise à jour, et prend en charge les entrées d'historique à attribut unique. Contient un vaste code legacy commenté pour le suivi complet de l'historique avec comparaison des propriétés anciennes/nouvelles.

Architecture

Détection d'historisabilité

  • isHistorizable(bean: Any?) — vérifie l'objet à l'exécution
  • isHistorizable(entityClass: Class<*>) — vérifie si la classe étend AbstractHistorizableBaseDO ou possède l'annotation @WithHistory

Création d'entrées d'historique

MéthodeDescription
createHistoryEntry(entity, opType)Crée un HistoryEntryDO avec l'ID de l'entité, le nom de l'entité, le type d'opération, l'horodatage et l'utilisateur actuel
createHistoryUpdateEntryWithSingleAttribute(entity, propertyName, propertyTypeClass, oldValue, newValue)Crée une entrée d'historique avec un seul HistoryEntryAttrDO comparant les valeurs anciennes et nouvelles
insertHistoryEntry(entity, historyEntry, context)Persiste l'entrée d'historique ; prend en charge CandHHistoryEntryICustomizer pour une personnalisation spécifique à l'entité
insertHistoryUpdateEntryWithSingleAttribute(...)Combine création+insertion pour les mises à jour d'attribut unique

Méthodes d'accroche publiques (utilisées par BaseDao)

MéthodeAppelée lors de
inserted(obj, context)Après l'insertion de l'entité ; crée une entrée d'historique INSERT si historisable
updated(obj, historyEntries, context)Après la mise à jour de l'entité ; persiste toutes les entrées d'historique fournies si historisable et non vide

Code legacy (commenté)

Le fichier contient environ 200 lignes de méthodes Java commentées (wrapHistoryUpdate, getSubEntitiesToHistoricizeDeep, getSubEntitiesToHistoricize, etc.) qui géraient auparavant le calcul automatique des différences et l'historique profond des entités pour les collections annotées avec @PFPersistancyBehavior(autoUpdateCollectionEntries=true). Cette fonctionnalité a été refactorisée dans HistoryService ou d'autres composants d'historique.

Types d'opérations

  • EntityOpType.Insert — nouvelle entité créée
  • EntityOpType.Update — entité existante modifiée
  • PropertyOpType.Update — propriété unique modifiée (utilisée dans les entrées d'attributs)
