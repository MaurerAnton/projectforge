Утилитный объект, связывающий операции BaseDao с системой истории. Проверяет, является ли сущность историзируемой (через наследование AbstractHistorizableBaseDO или аннотацию @WithHistory), создаёт записи HistoryEntryDO для операций вставки/обновления и поддерживает записи истории для одного атрибута. Содержит обширный закомментированный унаследованный код для полного отслеживания истории со сравнением старых и новых свойств.

Архитектура

Определение историзируемости

  • isHistorizable(bean: Any?) — проверяет объект во время выполнения
  • isHistorizable(entityClass: Class<*>) — проверяет, расширяет ли класс AbstractHistorizableBaseDO или имеет аннотацию @WithHistory

Создание записей истории

МетодОписание
createHistoryEntry(entity, opType)Создаёт HistoryEntryDO с ID сущности, именем сущности, типом операции, временной меткой и текущим пользователем
createHistoryUpdateEntryWithSingleAttribute(entity, propertyName, propertyTypeClass, oldValue, newValue)Создаёт запись истории с одним HistoryEntryAttrDO, сравнивающим старые и новые значения
insertHistoryEntry(entity, historyEntry, context)Сохраняет запись истории; поддерживает CandHHistoryEntryICustomizer для настройки под конкретную сущность
insertHistoryUpdateEntryWithSingleAttribute(...)Объединённое создание+вставка для обновлений одного атрибута

Публичные методы-хуки (используются BaseDao)

МетодВызывается когда
inserted(obj, context)После вставки сущности; создаёт запись истории INSERT, если сущность историзируема
updated(obj, historyEntries, context)После обновления сущности; сохраняет все предоставленные записи истории, если сущность историзируема и список не пуст

Унаследованный код (закомментирован)

Файл содержит ~200 строк закомментированных Java-методов (wrapHistoryUpdate, getSubEntitiesToHistoricizeDeep, getSubEntitiesToHistoricize и т.д.), которые ранее обрабатывали автоматическое вычисление различий и глубокую историю сущностей для коллекций, аннотированных @PFPersistancyBehavior(autoUpdateCollectionEntries=true). Эта функциональность была реорганизована в HistoryService или другие компоненты истории.

Типы операций

  • EntityOpType.Insert — создана новая сущность
  • EntityOpType.Update — изменена существующая сущность
  • PropertyOpType.Update — изменено одно свойство (используется в записях атрибутов)
