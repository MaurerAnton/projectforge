projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/history/HistoryEntry.kt Interfaz de dominio, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/history/HistoryEntry.kt 81 líneas · 12 código · 60 comentarios · 9 en blanco
Interfaz que representa un registro de cambio para cualquier entidad. Extiende IdObject<Long> y define el contrato para las entradas de historial: marca de tiempo de modificación, nombre del modificador, tipo de operación (INSERT/UPDATE/DELETE), identificación de la entidad, comentario opcional del usuario y un conjunto de entradas de diferencias a nivel de atributo.

Arquitectura

Propiedades de la interfaz

PropiedadTipoDescripción
idLong? (de IdObject)Clave primaria
modifiedAtDate?Marca de tiempo del cambio
modifiedByString?Nombre de usuario o nombre visible del usuario que modificó
attributesSet<HistoryEntryAttr>?Diferencias a nivel de atributo; nulo si solo hay cambio a nivel de entidad
entityOpTypeEntityOpType?INSERT, UPDATE o DELETE
entityNameString?Nombre de clase completamente calificado o identificador de tipo de entidad
entityIdLong?Clave primaria de la entidad modificada
userCommentString?Comentario opcional legible que explica el cambio

Detalles clave

  • Ya no es genérico: Anteriormente HistoryEntry<T>, ahora fijado a IdObject<Long> tras la migración de ID a Long
  • Comentario de usuario: Añadido para transparencia administrativa — p. ej., cuando se editan grupos/usuarios, el administrador puede registrar el motivo
  • Atributos: Set<HistoryEntryAttr> — cada atributo representa una propiedad modificada con valores antiguos/nuevos y el tipo de operación de la propiedad
