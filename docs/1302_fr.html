Interface représentant un enregistrement de modification pour toute entité. Étend IdObject<Long> et définit le contrat pour les entrées d'historique : horodatage de modification, nom du modificateur, type d'opération (INSERT/UPDATE/DELETE), identification de l'entité, commentaire utilisateur optionnel, et un ensemble d'entrées de différences au niveau des attributs.

Architecture

Propriétés de l'interface

PropriétéTypeDescription
idLong? (depuis IdObject)Clé primaire
modifiedAtDate?Horodatage de la modification
modifiedByString?Nom d'utilisateur ou nom affiché de l'utilisateur ayant modifié
attributesSet<HistoryEntryAttr>?Différences au niveau des attributs ; null si seule l'entité a changé
entityOpTypeEntityOpType?INSERT, UPDATE ou DELETE
entityNameString?Nom de classe complet ou identifiant de type d'entité
entityIdLong?Clé primaire de l'entité modifiée
userCommentString?Commentaire optionnel lisible expliquant la modification

Détails clés

  • N'est plus générique : Auparavant HistoryEntry<T>, désormais fixé à IdObject<Long> après la migration des identifiants vers Long
  • Commentaire utilisateur : Ajouté pour la transparence administrative — par exemple, lorsque des groupes/utilisateurs sont modifiés, l'administrateur peut enregistrer la raison
  • Attributs : Set<HistoryEntryAttr> — chaque attribut représente une propriété modifiée avec les anciennes/nouvelles valeurs et le type d'opération sur la propriété
