#1302: HistoryEntry.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/history/HistoryEntry.kt Интерфейс домена, projectforge-business/src/main/kotlin/org/projectforge/framework/persistence/history/HistoryEntry.kt 81 строка · 12 кода · 60 комментариев · 9 пустых
Интерфейс, представляющий запись об изменении для любой сущности. Расширяет IdObject<Long> и определяет контракт для записей истории: временная метка изменения, имя модификатора, тип операции (INSERT/UPDATE/DELETE), идентификация сущности, необязательный комментарий пользователя и набор записей различий на уровне атрибутов.

Архитектура

Свойства интерфейса

СвойствоТипОписание
idLong? (из IdObject)Первичный ключ
modifiedAtDate?Временная метка, когда произошло изменение
modifiedByString?Имя пользователя или отображаемое имя изменившего пользователя
attributesSet<HistoryEntryAttr>?Различия на уровне атрибутов; null, если изменение только на уровне сущности
entityOpTypeEntityOpType?INSERT, UPDATE или DELETE
entityNameString?Полное имя класса или идентификатор типа сущности
entityIdLong?Первичный ключ изменённой сущности
userCommentString?Необязательный читаемый комментарий, объясняющий изменение

Ключевые детали

  • Больше не обобщённый: Ранее HistoryEntry<T>, теперь фиксирован как IdObject<Long> после миграции ID на Long
  • Комментарий пользователя: Добавлен для прозрачности администрирования — например, при редактировании групп/пользователей администратор может указать причину
  • Атрибуты: Set<HistoryEntryAttr> — каждый атрибут представляет одно изменённое свойство со старыми/новыми значениями и типом операции над свойством
