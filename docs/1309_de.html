Spring @Service, das Formatierungsdienstprogramme für die Historie-Anzeige bereitstellt. Übersetzt Gruppen-/Benutzer-ID-Listen in lesbare Namen, behandelt die Übersetzung von Eigenschaftsnamen via i18n, formatiert eingebettete Sammlungseinträge mit Positionspräfixen (z. B. pos#1:eigenschaftsname) und verarbeitet DisplayHistoryEntry-Objekte für die Frontend-Darstellung.

Architektur

ID-zu-Name-Auflösung

Injiziert GroupService und UserService, um ID-Listen in sortierte, kommagetrennte Namen aufzulösen:

  • Eigenschaften, die auf "GroupIds" enden: Auflösung zu Gruppennamen via groupService.getGroupNames(value)
  • Eigenschaften, die auf "UserIds" enden: Auflösung zu Benutzernamen via userService.getUserNames(value)
  • Behandelt leere/null/"null"-Werte fehlertolerant

Behandlung von Eigenschaftsnamen

MethodeBeschreibung
getPlainPropertyName(attr)Entfernt internes Format; delegiert an HistoryOldFormatConverter falls veraltet
translatePropertyName(clazz, propertyName)Sucht nach @PropertyInfo-Annotation für i18n-Schlüssel, übersetzt diesen oder gibt den rohen Namen zurück

Formatierung eingebetteter Sammlungen

Wird für Listeneigenschaften (z. B. AuftragDO.positionen) verwendet, um den Positionskontext in der Historie anzuzeigen:

getPropertyNameForEmbedded(eigenschaftsname, "pos", 1) → "pos#1" oder "pos#1:eigenschaftsname"
getPropertyNameForEmbedded(eigenschaftsname, Pair("pos", 1), Pair("kost1", 3)) → "pos#1.kost1#3:eigenschaftsname"

Stapeloperationen

  • setNumberAsPropertyNameForListEntries(historyEntries, prefix, number) — wendet Anzeigenamen auf alle Einträge/Attribute einer Sammlung an
  • Variadische vararg prefixes: Pair<String, Number?>-Überladung für mehrstufige Verschachtelung

Formatierungspipeline

  1. HistoryOldFormatConverter.getPlainPropertyName() — normalisiert Legacy-Format
  2. translatePropertyName() — i18n-Übersetzung via @PropertyInfo-Annotation
  3. replaceGroupAndUserIdsValues() — löst ID-Listen in Namen auf
  4. setNumberAsPropertyNameForListEntries() — fügt Positionsnummern als Präfix hinzu
