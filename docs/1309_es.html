Spring @Service que proporciona utilidades de formato para la visualización del historial. Traduce listas de ID de grupo/usuario a nombres legibles, maneja la traducción de nombres de propiedades mediante i18n, formatea entradas de colecciones incrustadas con prefijos posicionales (ej., pos#1:nombrePropiedad), y procesa objetos DisplayHistoryEntry para el renderizado en el frontend.

Arquitectura

Resolución ID a Nombre

Inyecta GroupService y UserService para resolver listas de ID en nombres ordenados y separados por comas:

  • Propiedades que terminan en "GroupIds": resuelve a nombres de grupo mediante groupService.getGroupNames(valor)
  • Propiedades que terminan en "UserIds": resuelve a nombres de usuario mediante userService.getUserNames(valor)
  • Maneja valores vacíos/nulos/"null" de forma elegante

Manejo de Nombres de Propiedad

MétodoDescripción
getPlainPropertyName(attr)Elimina el formato interno; delega a HistoryOldFormatConverter si está desactualizado
translatePropertyName(clazz, propertyName)Busca la anotación @PropertyInfo para la clave i18n, la traduce, o devuelve el nombre original

Formateo de Colecciones Incrustadas

Se utiliza para propiedades de tipo lista (ej., AuftragDO.positionen) para mostrar contexto posicional en el historial:

getPropertyNameForEmbedded(nombrePropiedad, "pos", 1) → "pos#1" o "pos#1:nombrePropiedad"
getPropertyNameForEmbedded(nombrePropiedad, Pair("pos", 1), Pair("kost1", 3)) → "pos#1.kost1#3:nombrePropiedad"

Operaciones por Lote

  • setNumberAsPropertyNameForListEntries(historyEntries, prefijo, numero) — aplica nombres de visualización a todas las entradas/atributos en una colección
  • Sobrecarga variádica vararg prefijos: Pair<String, Number?> para anidamiento de múltiples niveles

Pipeline de Formateo

  1. HistoryOldFormatConverter.getPlainPropertyName() — normaliza el formato heredado
  2. translatePropertyName() — traducción i18n mediante anotación @PropertyInfo
  3. replaceGroupAndUserIdsValues() — resuelve listas de ID a nombres
  4. setNumberAsPropertyNameForListEntries() — antepone números de posición
