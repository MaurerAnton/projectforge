Service Spring @Service fournissant des utilitaires de formatage pour l'affichage de l'historique. Traduit les listes d'ID de groupes/utilisateurs en noms lisibles, gère la traduction des noms de propriétés via i18n, formate les entrées de collections intégrées avec des préfixes positionnels (ex. pos#1:nomPropriété), et traite les objets DisplayHistoryEntry pour le rendu frontal.

Architecture

Résolution ID-vers-Nom

Injecte GroupService et UserService pour résoudre les listes d'ID en noms triés, séparés par des virgules :

  • Propriétés se terminant par "GroupIds" : résout en noms de groupes via groupService.getGroupNames(value)
  • Propriétés se terminant par "UserIds" : résout en noms d'utilisateurs via userService.getUserNames(value)
  • Gère les valeurs vides/nulles/"null" avec élégance

Gestion des noms de propriétés

MéthodeDescription
getPlainPropertyName(attr)Supprime le format interne ; délègue à HistoryOldFormatConverter si obsolète
translatePropertyName(clazz, propertyName)Recherche l'annotation @PropertyInfo pour la clé i18n, la traduit, ou retourne le nom brut

Formatage des collections intégrées

Utilisé pour les propriétés de type liste (ex. AuftragDO.positionen) afin d'afficher le contexte positionnel dans l'historique :

getPropertyNameForEmbedded(propertyName, "pos", 1) → "pos#1" ou "pos#1:nomPropriété"
getPropertyNameForEmbedded(propertyName, Pair("pos", 1), Pair("kost1", 3)) → "pos#1.kost1#3:nomPropriété"

Opérations par lots

  • setNumberAsPropertyNameForListEntries(historyEntries, prefix, number) — applique les noms d'affichage à toutes les entrées/attributs d'une collection
  • Surcharge variadique vararg prefixes: Pair<String, Number?> pour l'imbrication multi-niveaux

Pipeline de formatage

  1. HistoryOldFormatConverter.getPlainPropertyName() — normalise le format hérité
  2. translatePropertyName() — traduction i18n via l'annotation @PropertyInfo
  3. replaceGroupAndUserIdsValues() — résout les listes d'ID en noms
  4. setNumberAsPropertyNameForListEntries() — préfixe les numéros de position
