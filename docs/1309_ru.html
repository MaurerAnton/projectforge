Spring @Service, предоставляющий утилиты форматирования для отображения истории. Преобразует списки ID групп/пользователей в читаемые имена, обрабатывает перевод названий свойств через i18n, форматирует записи встроенных коллекций с позиционными префиксами (например, pos#1:propertyName) и обрабатывает объекты DisplayHistoryEntry для отображения на фронтенде.

Архитектура

Преобразование ID в имя

Внедряет GroupService и UserService для преобразования списков ID в отсортированные имена, разделённые запятыми:

  • Свойства, оканчивающиеся на "GroupIds": преобразуются в имена групп через groupService.getGroupNames(value)
  • Свойства, оканчивающиеся на "UserIds": преобразуются в имена пользователей через userService.getUserNames(value)
  • Корректно обрабатывает пустые/null/"null" значения

Обработка названий свойств

МетодОписание
getPlainPropertyName(attr)Удаляет внутренний формат; делегирует HistoryOldFormatConverter если устарел
translatePropertyName(clazz, propertyName)Ищет аннотацию @PropertyInfo для ключа i18n, переводит его или возвращает исходное имя

Форматирование встроенных коллекций

Используется для свойств типа списка (например, AuftragDO.positionen) для отображения позиционного контекста в истории:

getPropertyNameForEmbedded(propertyName, "pos", 1) → "pos#1" или "pos#1:propertyName"
getPropertyNameForEmbedded(propertyName, Pair("pos", 1), Pair("kost1", 3)) → "pos#1.kost1#3:propertyName"

Пакетные операции

  • setNumberAsPropertyNameForListEntries(historyEntries, prefix, number) — применяет отображаемые имена ко всем записям/атрибутам в коллекции
  • Вариативная перегрузка vararg prefixes: Pair<String, Number?> для многоуровневой вложенности

Конвейер форматирования

  1. HistoryOldFormatConverter.getPlainPropertyName() — нормализует устаревший формат
  2. translatePropertyName() — перевод i18n через аннотацию @PropertyInfo
  3. replaceGroupAndUserIdsValues() — преобразует списки ID в имена
  4. setNumberAsPropertyNameForListEntries() — добавляет префиксы номеров позиций
