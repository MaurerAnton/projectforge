Потокобезопасный изменяемый контекст, используемый во время загрузки и преобразования записей истории. Хранит сырые записи истории, загруженные сущности и отображения запись-атрибут; предоставляет состояние итерации (текущая запись/атрибут) для конвертеров и форматтеров отображения.

Архитектура и роль

HistoryLoadContext служит центральным хранилищем состояния при загрузке данных истории из базы данных и преобразовании их в человеко-/JSON-читаемые объекты DisplayHistoryEntry. Он создаётся для каждой операции загрузки (не синглтон) и передаётся по цепочке конвертеров истории.

Ключевые внутренние классы

КлассНазначение
HistoryEntryMapСвязывает сырой HistoryEntryDO с его отображаемым аналогом и изменяемой картой расширений для пользовательских данных.
HistoryEntryAttrMapСвязывает сырой HistoryEntryAttrDO с его отображаемым аналогом и изменяемой картой расширений.

Управление состоянием

Контекст поддерживает:

  • historyEntries — объединённый список HistoryEntryDO, дедуплицированный по id
  • loadedEntities — уже загруженные сущности (BaseDO), используемые для избежания повторных загрузок
  • historyEntryAttrMap — карты свойств для каждого атрибута, индексированные по ID атрибута (Long → HistoryEntryAttrMap)
  • Текущее состояние итерации: currentHistoryEntry, currentHistoryEntryAttr, currentDisplayHistoryEntry, currentDisplayHistoryEntryAttr
  • Ссылки на UserGroupCache, HistoryValueService и владеющий BaseDao

Методы делегирования

Делегирует разрешение значений historyValueService: getObjectValue() преобразует строковые значения в типизированные объекты; getClass() преобразует имена классов в Class<?>. Разрешение пользователей делегируется UserGroupCache через getUser(id).
