Categorías de claves

  • Etiquetas de interfaz: download, downloadAnyway, edit, menu, title, title.heading — se renderizan en la página Wicket y en los componentes de formulario.
  • Mensajes de error: jsonError.empty, jsonError.parsing, userError.notFound — lanzados mediante UserException cuando falta la configuración JSON del comentario de dirección o está mal formada.
  • Mensajes de validación: nodescriptionfound, noitemsfound — se muestran cuando falla la validación de exportación en IHKPage.export().
Resolución de configuración regional: El ResourceBundle de Java carga IHKI18nResources_de.properties para configuraciones regionales alemanas y recurre a este archivo para todas las demás. No existe una variante _en porque el inglés es el predeterminado.
