Fichier de ressources d'internationalisation par défaut pour le plugin IHK. Sert de locale de repli (anglais) et est chargé en parallèle de IHKI18nResources_de.properties via IHKPlugin.addResourceBundle("IHKI18nResources").

Catégories de clés

  • Étiquettes d'interface : download, downloadAnyway, edit, menu, title, title.heading — affichées dans la page Wicket et les composants de formulaire.
  • Messages d'erreur : jsonError.empty, jsonError.parsing, userError.notFound — levés via UserException lorsque la configuration JSON dans le commentaire d'adresse est absente ou mal formée.
  • Messages de validation : nodescriptionfound, noitemsfound — affichés lorsque la validation d'exportation échoue dans IHKPage.export().
Résolution de locale : Le ResourceBundle de Java charge IHKI18nResources_de.properties pour les locales allemandes et utilise ce fichier comme repli pour toutes les autres. Il n'existe pas de variante _en car l'anglais est la langue par défaut.
