plugins/org.projectforge.plugins.ihk/src/main/resources/IHKI18nResources.properties Пакет ресурсов i18n по умолчанию (английский), plugins/org.projectforge.plugins.ihk/src/main/resources/IHKI18nResources.properties 11 строк · 11 строк кода · 0 комментариев · 0 пустых строк
Пакет ресурсов интернационализации по умолчанию для плагина IHK. Служит запасной локалью (английский) и загружается вместе с IHKI18nResources_de.properties через IHKPlugin.addResourceBundle("IHKI18nResources").

Категории ключей

  • Метки интерфейса: download, downloadAnyway, edit, menu, title, title.heading — отображаются на странице Wicket и в компонентах форм.
  • Сообщения об ошибках: jsonError.empty, jsonError.parsing, userError.notFound — выбрасываются через UserException, когда JSON-конфигурация в комментарии к адресу отсутствует или имеет неверный формат.
  • Сообщения валидации: nodescriptionfound, noitemsfound — отображаются, когда проверка экспорта в IHKPage.export() завершается неудачей.
Определение локали: Java-класс ResourceBundle загружает IHKI18nResources_de.properties для немецкой локали и использует данный файл как запасной для всех остальных. Вариант _en отсутствует, поскольку английский является языком по умолчанию.
