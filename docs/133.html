Usage Context

  • download, downloadAnyway, edit — button labels in IHKForm
  • menu — menu entry text registered in IHKPlugin.initialize()
  • title, title.heading — page title and heading in IHKPage
  • jsonError.*, userError.notFound — error messages thrown as UserException in IHKForm.init() when the trainee's address comment is missing or malformed JSON
  • nodescriptionfound, noitemsfound — validation messages in IHKPage.export()

Design Notes

  • The JSON error messages contain a literal JSON example embedded in the error text — a pragmatic approach for a trainee-facing feature where the audience is expected to follow setup instructions from peers.
  • Keys missing from this file fall back to the default IHKI18nResources.properties (English).
  • UTF-8 encoded since the migration commit 6fd4462f8 (Java 9+ supports UTF-8 properties natively).
