Central persistence service managing JPA EntityManager lifecycle via PfPersistenceContext with ThreadLocal tracking. Provides methods to run code in transactional or read-only contexts, reusing existing contexts when available. Uses kotlinx.coroutines-compatible design. Tracks connection stats for testing/debugging.

Architecture

Context Management

Transactional Implementation (internalRunInNewTransaction)

  1. Saves current transactional context from ThreadLocal
  2. Creates new PfPersistenceContext with type TRANSACTION
  3. Sets it in ThreadLocal via PfPersistenceContextThreadLocal.setTransactional()
  4. Begins transaction: em.transaction.begin()
  5. Executes the block; on success: commit; on exception: rollback
  6. Finally: removes context from ThreadLocal, restores saved context

ReadOnly Implementation (internalRunReadOnly)

  1. Saves current readonly context
  2. Creates new PfPersistenceContext with type READONLY
  3. Sets Hibernate session defaultReadOnly = true (no flushing, prevents accidental writes)
  4. Executes block without transaction
  5. Finally: removes context, restores saved context
