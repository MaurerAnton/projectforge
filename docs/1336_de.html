Zentraler Persistenzdienst, der den JPA-EntityManager-Lebenszyklus über PfPersistenceContext mit ThreadLocal-Verfolgung verwaltet. Bietet Methoden zur Ausführung von Code in transaktionalen oder schreibgeschützten Kontexten, wobei vorhandene Kontexte wiederverwendet werden, wenn verfügbar. Verwendet ein kotlinx.coroutines-kompatibles Design. Zeichnet Verbindungsstatistiken für Tests/Fehlersuche auf.

Transaktionale Implementierung (internalRunInNewTransaction)

  1. Sichert den aktuellen transaktionalen Kontext aus ThreadLocal
  2. Erstellt neuen PfPersistenceContext vom Typ TRANSACTION
  3. Setzt ihn in ThreadLocal über PfPersistenceContextThreadLocal.setTransactional()
  4. Beginnt Transaktion: em.transaction.begin()
  5. Führt den Block aus; bei Erfolg: Commit; bei Ausnahme: Rollback
  6. Im Finally-Block: Entfernt Kontext aus ThreadLocal, stellt gesicherten Kontext wieder her

Schreibgeschützte Implementierung (internalRunReadOnly)

  1. Sichert den aktuellen schreibgeschützten Kontext
  2. Erstellt neuen PfPersistenceContext vom Typ READONLY
  3. Setzt Hibernate-Session defaultReadOnly = true (kein Flushen, verhindert versehentliche Schreibvorgänge)
  4. Führt Block ohne Transaktion aus
  5. Im Finally-Block: Entfernt Kontext, stellt gesicherten Kontext wieder her
