Servicio central de persistencia que gestiona el ciclo de vida de EntityManager JPA mediante PfPersistenceContext con seguimiento ThreadLocal. Proporciona métodos para ejecutar código en contextos transaccionales o de solo lectura, reutilizando contextos existentes cuando están disponibles. Utiliza un diseño compatible con kotlinx.coroutines. Realiza seguimiento de estadísticas de conexión para pruebas/depuración.

Arquitectura

Gestión de contexto

Método Tipo de contexto ¿Reutiliza existente? ¿Crea transacción?
runInTransaction(run) Transaccional Sí (si ya está en ThreadLocal) Sí (si es nuevo contexto)
runInNewTransaction(run) Transaccional No (siempre crea nuevo, restaura después) Sí
runReadOnly(block) Solo lectura Sí (Transaccional o Solo lectura) No
runIsolatedReadOnly(block) Solo lectura No (siempre crea nuevo) No

Implementación transaccional (internalRunInNewTransaction)

  1. Guarda el contexto transaccional actual de ThreadLocal
  2. Crea un nuevo PfPersistenceContext con tipo TRANSACTION
  3. Lo establece en ThreadLocal mediante PfPersistenceContextThreadLocal.setTransactional()
  4. Inicia la transacción: em.transaction.begin()
  5. Ejecuta el bloque; en éxito: confirma; en excepción: revierte
  6. Finalmente: elimina el contexto de ThreadLocal, restaura el contexto guardado

Implementación de solo lectura (internalRunReadOnly)

  1. Guarda el contexto de solo lectura actual
  2. Crea un nuevo PfPersistenceContext con tipo READONLY
  3. Establece la sesión de Hibernate defaultReadOnly = true (sin vaciado, evita escrituras accidentales)
  4. Ejecuta el bloque sin transacción
  5. Finalmente: elimina el contexto, restaura el contexto guardado

Métodos de consulta convenientes (todos delegados a runReadOnly)

Método Parámetros Descripción
find(entityClass, id) class, id, attached, entityGraphName Búsqueda JPA por clave primaria
selectAll(entityClass) class, attached, lockModeType, entityGraphName Seleccionar todas las entidades del tipo
selectSingleResult(sql, resultClass) query, class, params, nullAllowed, etc. Consulta nombrada/HQL que devuelve un único resultado
selectNamedSingleResult(namedQuery, resultClass) query, class, params, nullAllowed, etc. Conveniencia con namedQuery=true
executeQuery(sql, resultClass) query, class, params, attached, namedQuery, etc. Ejecuta consulta devolviendo lista
executeNamedQuery(namedQuery, resultClass) query, class, params, attached, etc. Conveniencia con namedQuery=true
getNextNumber(table, attribute) table, attribute, startNumber SELECT MAX(attribute)+1 para generación de ID

  • getActivitiesForTesting(oldState) — diferencia entre estadísticas antiguas y actuales
  • Parámetros recordCallStats / recordCallStatsExtended en runInNewTransaction y runIsolatedReadOnly
