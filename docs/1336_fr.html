Service de persistance central gérant le cycle de vie de l'EntityManager JPA via PfPersistenceContext avec suivi ThreadLocal. Fournit des méthodes pour exécuter du code dans des contextes transactionnels ou en lecture seule, en réutilisant les contextes existants lorsque c'est possible. Utilise une conception compatible avec kotlinx.coroutines. Suit les statistiques de connexion pour les tests et le débogage.

Implémentation transactionnelle (internalRunInNewTransaction)

  1. Sauvegarde le contexte transactionnel actuel depuis ThreadLocal
  2. Crée un nouveau PfPersistenceContext de type TRANSACTION
  3. Le définit dans ThreadLocal via PfPersistenceContextThreadLocal.setTransactional()
  4. Débute la transaction : em.transaction.begin()
  5. Exécute le bloc ; en cas de succès : commit ; en cas d'exception : rollback
  6. Enfin : supprime le contexte de ThreadLocal, restaure le contexte sauvegardé

Implémentation en lecture seule (internalRunReadOnly)

  1. Sauvegarde le contexte en lecture seule actuel
  2. Crée un nouveau PfPersistenceContext de type READONLY
  3. Définit la session Hibernate defaultReadOnly = true (pas de vidage, empêche les écritures accidentelles)
  4. Exécute le bloc sans transaction
  5. Enfin : supprime le contexte, restaure le contexte sauvegardé
