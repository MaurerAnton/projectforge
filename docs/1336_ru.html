Центральный сервис персистентности, управляющий жизненным циклом JPA EntityManager через PfPersistenceContext с отслеживанием ThreadLocal. Предоставляет методы для выполнения кода в транзакционном или read-only контексте, повторно используя существующие контексты, когда это возможно. Использует дизайн, совместимый с kotlinx.coroutines. Отслеживает статистику соединений для тестирования/отладки.

Реализация транзакции (internalRunInNewTransaction)

  1. Сохраняет текущий транзакционный контекст из ThreadLocal
  2. Создаёт новый PfPersistenceContext с типом TRANSACTION
  3. Устанавливает его в ThreadLocal через PfPersistenceContextThreadLocal.setTransactional()
  4. Начинает транзакцию: em.transaction.begin()
  5. Выполняет блок; при успехе: commit; при исключении: rollback
  6. В finally: удаляет контекст из ThreadLocal, восстанавливает сохранённый контекст

Реализация только для чтения (internalRunReadOnly)

  1. Сохраняет текущий read-only контекст
  2. Создаёт новый PfPersistenceContext с типом READONLY
  3. Устанавливает Hibernate session defaultReadOnly = true (без сброса, предотвращает случайные записи)
  4. Выполняет блок без транзакции
  5. В finally: удаляет контекст, восстанавливает сохранённый контекст

Поддержка тестирования

  • getCopyOfCurrentStateForTesting() — снимок PersistenceConnectionStats
  • getActivitiesForTesting(oldState) — разница между старыми и текущими статистиками
  • recordCallStats / recordCallStatsExtended параметры в runInNewTransaction и runIsolatedReadOnly
