Envuelve un EntityType de JPA para proporcionar acceso introspectivo a los metadatos de la entidad: descubrimiento de propiedades, inspección de anotaciones, búsquedas de longitud de columna y comprobaciones de persistencia. Utilizado por el subsistema de importación y la capa de persistencia para mapear dinámicamente entre datos importados y propiedades de entidades JPA.

Arquitectura

Diseño de la clase

EntityInfo envuelve un EntityType<*> de JPA y llena de forma eager una lista de objetos EntityPropertyInfo para cada atributo JPA que tenga un javaMember. Sirve como puente entre el metamodelo de JPA y las necesidades de reflexión en tiempo de ejecución de ProjectForge.

Integración con reflexión de Kotlin

La clase soporta tanto búsquedas de propiedades basadas en cadenas como reflexión de Kotlin (KCallable, KMutableProperty1). Las sobrecargas de isPersistedProperty permiten a los llamantes verificar si una propiedad de Kotlin corresponde a una columna JPA, lo cual es esencial para el mapeo automático de propiedades del subsistema de importación.

Caché para longitud de columna

getColumnLength() utiliza un conjunto interno columnWithoutLength para evitar mensajes de registro repetidos cuando una propiedad no tiene anotación @Column. Las propiedades que terminan en "DO" se registran a nivel ERROR, otras a nivel INFO — tratando las entidades DO como si se esperara que tuvieran anotaciones JPA completas.

Relaciones

  • EntityPropertyInfo: Creado para cada atributo JPA durante init
  • EntityType: La fuente del metamodelo JPA (normalmente AbstractManagedType de Hibernate)
  • Subsistema de importación: Utilizado por los importadores para validar los mapeos de campos contra la estructura de la entidad
  • HibernateSearchMeta: Complementa esto proporcionando metadatos del índice de búsqueda de Hibernate
