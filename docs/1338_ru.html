#1338: EntityInfo.kt

Обёртка над JPA EntityType, обеспечивающая интроспективный доступ к метаданным сущности: обнаружение свойств, проверка аннотаций, поиск длины столбцов и проверки персистентности. Используется подсистемой импорта и уровнем персистентности для динамического сопоставления импортированных данных со свойствами JPA-сущностей.

Архитектура

Дизайн класса

EntityInfo оборачивает JPA EntityType<*> и с готовностью заполняет список объектов EntityPropertyInfo для каждого атрибута JPA, имеющего javaMember. Он служит мостом между мета-моделью JPA и потребностями ProjectForge в рефлексии времени выполнения.

Интеграция с рефлексией Kotlin

Класс поддерживает как поиск свойств по строке, так и рефлексию Kotlin (KCallable, KMutableProperty1). Перегрузки isPersistedProperty позволяют вызывающим сторонам проверять, соответствует ли свойство Kotlin столбцу JPA, что необходимо для автоматического сопоставления свойств в подсистеме импорта.

Кэширование длины столбца

getColumnLength() использует внутренний набор columnWithoutLength для предотвращения повторных сообщений лога, когда свойство не имеет аннотации @Column. Свойства, оканчивающиеся на "DO", логируются на уровне ERROR, остальные — на уровне INFO — предполагается, что DO-сущности имеют полные JPA-аннотации.

Связи

  • EntityPropertyInfo: Создаётся для каждого атрибута JPA во время init
  • EntityType: Источник мета-модели JPA (обычно AbstractManagedType от Hibernate)
  • Подсистема импорта: Используется импортёрами для проверки соответствия полей структуре сущности
  • HibernateSearchMeta: Дополняет это, предоставляя метаданные индекса Hibernate Search
