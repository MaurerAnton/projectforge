Contexto de uso

  • download, downloadAnyway, edit — etiquetas de botón en IHKForm
  • menu — texto de entrada de menú registrado en IHKPlugin.initialize()
  • title, title.heading — título de página y encabezado en IHKPage
  • jsonError.*, userError.notFound — mensajes de error lanzados como UserException en IHKForm.init() cuando el comentario de dirección del aprendiz falta o tiene JSON mal formado
  • nodescriptionfound, noitemsfound — mensajes de validación en IHKPage.export()

Notas de diseño

  • Los mensajes de error JSON contienen un ejemplo JSON literal incrustado en el texto del error — un enfoque pragmático para una función orientada a aprendices, donde se espera que la audiencia siga instrucciones de configuración de sus compañeros.
  • Las claves que faltan en este archivo recurren al IHKI18nResources.properties predeterminado (inglés).
  • Codificado en UTF-8 desde el commit de migración 6fd4462f8 (Java 9+ soporta propiedades UTF-8 de forma nativa).
