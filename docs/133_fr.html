Contexte d'utilisation

  • download, downloadAnyway, edit — libellés des boutons dans IHKForm
  • menu — texte de l'entrée de menu enregistrée dans IHKPlugin.initialize()
  • title, title.heading — titre de page et en-tête dans IHKPage
  • jsonError.*, userError.notFound — messages d'erreur levés sous forme de UserException dans IHKForm.init() lorsque le commentaire d'adresse de l'apprenti est manquant ou que le JSON est mal formé
  • nodescriptionfound, noitemsfound — messages de validation dans IHKPage.export()

Notes de conception

  • Les messages d'erreur JSON contiennent un exemple JSON littéral intégré dans le texte d'erreur — une approche pragmatique pour une fonctionnalité destinée aux apprentis, où l'on attend du public qu'il suive les instructions de configuration de ses pairs.
  • Les clés absentes de ce fichier utilisent par défaut le fichier IHKI18nResources.properties (anglais).
  • Encodé en UTF-8 depuis le commit de migration 6fd4462f8 (Java 9+ prend en charge nativement les propriétés UTF-8).
