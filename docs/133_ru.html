Немецкая локализация для плагина IHK. Загружается IHKPlugin через addResourceBundle("IHKI18nResources"). Предоставляет 11 переведённых ключей для интерфейса учебных отчётов IHK.

Контекст использования

  • download, downloadAnyway, edit — подписи кнопок в IHKForm
  • menu — текст пункта меню, зарегистрированного в IHKPlugin.initialize()
  • title, title.heading — заголовок страницы и heading в IHKPage
  • jsonError.*, userError.notFound — сообщения об ошибках, выбрасываемые как UserException в IHKForm.init(), когда комментарий в адресе стажёра отсутствует или содержит некорректный JSON
  • nodescriptionfound, noitemsfound — сообщения валидации в IHKPage.export()

Заметки по дизайну

  • Сообщения об ошибках JSON содержат буквальный пример JSON, встроенный в текст ошибки — прагматичный подход для функции, ориентированной на стажёров, где предполагается, что аудитория будет следовать инструкциям по настройке от коллег.
  • Ключи, отсутствующие в этом файле, возвращаются к стандартному IHKI18nResources.properties (английский).
  • Кодировка UTF-8, начиная с коммита миграции 6fd4462f8 (Java 9+ поддерживает свойства UTF-8 нативно).
