#1340: HibernateSearchUserRightIdBridge.kt

Type Bridge — Hibernate Search / User Rights, projectforge-business/src/main/kotlin/org/projectforge/business/user/HibernateSearchUserRightIdBridge.kt
Hibernate Search TypeBridge implementation that bridges UserRightId enum values to their string ID representation for full-text indexing. Enables users to search for entities by user right ID strings in Hibernate Search queries.

Architecture

Class Design

class HibernateSearchUserRightIdBridge : TypeBridge<UserRightId>

Implements the Hibernate Search 6 TypeBridge interface. This is a POJO mapper bridge — it runs whenever a UserRightId value is indexed by Hibernate Search.

Bridge Operation

override fun write(target: DocumentElement, bridgedElement: UserRightId, context: TypeBridgeWriteContext) {
    target.addValue(idField, bridgedElement.id)
}

During index writing, the bridge extracts the id property (a string identifier) from the UserRightId enum value and adds it to the indexed document. This allows full-text search queries to match against user right ID strings rather than the raw enum ordinal or name.

Integration

  • UserRightId: The enum whose values are bridged. Each constant has a unique string id.
  • Hibernate Search 6: The bridge is registered on entity properties of type UserRightId via annotations or programmatic mapping
  • User rights entities: Used in entities like UserRightDO where user rights need to be searchable

Note on idField

The idField is declared as null (IndexFieldReference<String?>? = null). In the current implementation, the field reference appears unused/incomplete — the write method passes a null field reference. This may be intentional if the bridge registration happens via annotations that auto-bind the field reference, or it may be a placeholder for future implementation.
