Binary Excel workbook serving as the template for IHK-compliant weekly training reports. The IHK plugin populates this template with timesheet data (work description, hours, dates) for trainees to submit to their vocational school and the Chamber of Commerce. The template contains pre-formatted columns, headers, and styling required by IHK reporting standards.

Role in IHK Plugin

The IHK plugin (#127) enables trainees (Auszubildende) to generate weekly reports from their ProjectForge timesheets. The flow:
1. User selects a week on IHKPage (#126)
2. IHKExporter reads the template from VorlageWochenbericht.xlsx via classpath
3. Timesheet entries for the selected week are written into the template rows
4. The filled workbook is downloaded as WB-Nr_{nr}_{date}.xlsx

The template is a static resource bundled with the plugin — no database storage needed.

Why .xlsx Instead of Generated?

The template is a pre-built Excel file rather than code-generated because IHK reporting requires specific formatting (column widths, merged cells, header styling, footer information) that is complex to express programmatically with Apache POI. A human-designed Excel template ensures compliance with IHK formatting requirements and allows non-developers to update the template without code changes.
