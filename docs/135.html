Path: plugins/org.projectforge.plugins.licensemanagement/build.gradle.kts · Lines: 20 · Type: Gradle Kotlin DSL build script

Build configuration for the LicenseManagement plugin. Identical structure to the IHK plugin build — uses buildlogic.pf-module-conventions for standard ProjectForge module settings, Kotlin JVM target 17, and depends on projectforge-wicket (UI layer) and projectforge-rest (REST endpoints) at compile scope, projectforge-business for test scope only.

The LicenseManagement plugin manages software license keys — storing licenses, tracking activations, and controlling visibility via user rights. Supports both Wicket (legacy) and React (new) UIs.
