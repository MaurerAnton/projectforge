Classeur Excel binaire servant de modèle pour les rapports de formation hebdomadaires conformes à l'IHK. Le plugin IHK remplit ce modèle avec les données des feuilles de temps (description du travail, heures, dates) pour que les stagiaires les soumettent à leur école professionnelle et à la Chambre de commerce. Le modèle contient des colonnes, en-têtes et styles pré-formatés requis par les normes de rapport IHK.

Rôle dans le plugin IHK

Le plugin IHK (#127) permet aux stagiaires (Auszubildende) de générer des rapports hebdomadaires à partir de leurs feuilles de temps ProjectForge. Le flux :
1. L'utilisateur sélectionne une semaine sur IHKPage (#126)
2. IHKExporter lit le modèle depuis VorlageWochenbericht.xlsx via le classpath
3. Les saisies de la feuille de temps pour la semaine sélectionnée sont écrites dans les lignes du modèle
4. Le classeur rempli est téléchargé sous le nom WB-Nr_{nr}_{date}.xlsx

Le modèle est une ressource statique fournie avec le plugin — aucun stockage en base de données nécessaire.

Pourquoi .xlsx plutôt qu'une génération ?

Le modèle est un fichier Excel pré-construit plutôt que généré par code car les rapports IHK nécessitent un formatage spécifique (largeurs de colonnes, cellules fusionnées, style des en-têtes, informations de pied de page) qui est complexe à exprimer par programmation avec Apache POI. Un modèle Excel conçu par un humain garantit la conformité avec les exigences de formatage IHK et permet aux non-développeurs de mettre à jour le modèle sans modification du code.
