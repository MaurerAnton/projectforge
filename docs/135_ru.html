Двоичный файл Excel, служащий шаблоном для еженедельных отчётов об обучении, соответствующих требованиям IHK. Плагин IHK заполняет этот шаблон данными из табеля учёта рабочего времени (описание работ, часы, даты) для последующей отправки стажёрами в профессиональное училище и Торгово-промышленную палату. Шаблон содержит предварительно отформатированные столбцы, заголовки и стили, необходимые для соответствия стандартам отчётности IHK.

Роль в плагине IHK

Плагин IHK (#127) позволяет стажёрам (Auszubildende) формировать еженедельные отчёты на основе своих табелей учёта времени в ProjectForge. Процесс:
1. Пользователь выбирает неделю на странице IHKPage (#126)
2. IHKExporter считывает шаблон из VorlageWochenbericht.xlsx через classpath
3. Записи табеля за выбранную неделю вносятся в строки шаблона
4. Заполненная книга скачивается как WB-Nr_{nr}_{date}.xlsx

Шаблон является статическим ресурсом, входящим в состав плагина — хранение в базе данных не требуется.

Почему .xlsx, а не сгенерированный?

Шаблон представляет собой предварительно созданный файл Excel, а не сгенерированный программно, поскольку отчётность IHK требует специфического форматирования (ширина столбцов, объединённые ячейки, стили заголовков, информация в нижнем колонтитуле), которое сложно реализовать программно с помощью Apache POI. Шаблон Excel, разработанный человеком, гарантирует соответствие требованиям форматирования IHK и позволяет обновлять шаблон без изменения кода.
