#136: LicenseDao.java

Path: plugins/...licensemanagement/src/main/java/.../LicenseDao.java · Lines: 93 · Author: Kai Reinhard · Type: Java DAO — extends BaseDao<LicenseDO>

Data access layer for software license keys. Extends BaseDao<LicenseDO> — the standard ProjectForge DAO base providing CRUD, search, history tracking, and access checks out of the box. 93 lines.

Unlike most ProjectForge file-handling plugins (which use JCR), this plugin stores license key files as database BLOBs — the original design choice before JCR became the standard for file attachments. The DAO stores the license key binary directly in the LicenseDO entity column.

Key dependency: UserDao (autowired) — resolves user IDs to PFUserDO objects for the "visible to" owner display.
