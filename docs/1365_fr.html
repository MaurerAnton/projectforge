#1365 : IPFDate.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/time/IPFDate.kt Interface, projectforge-business/src/main/kotlin/org/projectforge/framework/time/IPFDate.kt 165 lignes · 71 code · 52 commentaires · 42 vides
Interface de date centrale pour les types de date de ProjectForge. Définit le contrat pour l'année, le mois, le jour, la semaine, le formatage, la comparaison (isBefore/isAfter/isSameDay), l'arithmétique (plusDays, minusMonths, etc.) et les vérifications de jours fériés/week-end. Implémentée à la fois par PFDateTime et PFDay.
