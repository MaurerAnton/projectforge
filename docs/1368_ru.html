projectforge-business/src/main/kotlin/org/projectforge/framework/time/PFDateTime.kt Сервис, projectforge-business/src/main/kotlin/org/projectforge/framework/time/PFDateTime.kt 844 строки · 469 кода · 256 комментариев · 119 пустых
Неизменяемый держатель даты-времени, оборачивающий ZonedDateTime. Основной класс даты/времени, предоставляющий аксессоры для года, месяца, дня, часа, минуты, секунды, наносекунды; арифметику (плюс/минус дни, недели, месяцы, годы, часы); форматирование (локаль пользователя, ISO, JS, HTTP-дата, безопасное для имени файла); округление точности; и преобразование в java.util.Date, java.sql.Date/Timestamp. Объект-компаньон предоставляет обширные фабричные методы (from/orNull/orNow) для Long, Instant, ZonedDateTime, LocalDateTime, LocalDate, Date, java.sql.Date и Temporal.
