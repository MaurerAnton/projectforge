#1370: PFDay.kt

projectforge-business/src/main/kotlin/org/projectforge/framework/time/PFDay.kt Сервис, projectforge-business/src/main/kotlin/org/projectforge/framework/time/PFDay.kt 426 строк · 246 кода · 106 комментариев · 74 пустых
Неизменяемый держатель даты, оборачивающий LocalDate. Аналог PFDateTime только для дат, реализующий IPFDate<PFDay>. Предоставляет аксессоры года, месяца, дня, недели; арифметику (плюс/минус дни, недели, месяцы, годы); форматирование (локаль пользователя, ISO); и преобразование в java.util.Date и java.sql.Date. Объект-компаньон предоставляет фабричные методы (from/orNull/orNow) для LocalDate, Date, java.sql.Date и PFDateTime. Настраиваемые поля недели через projectforge.properties.
