Constructor fluido para generar contenido Markdown con coloración opcional de span HTML. Soporta encabezados, tablas (con formato de fila de encabezado), elementos de lista, texto multilínea y pares clave-valor separados por tubería. Proporciona escape de Markdown y HTML por seguridad. Se utiliza para la salida del monitor de trabajos, renderizado de correos electrónicos y registros de actividad.
