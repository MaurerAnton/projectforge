Constructeur fluide pour générer du contenu Markdown avec coloration optionnelle par balises HTML span. Prend en charge les titres, les tableaux (avec formatage de la ligne d'en-tête), les éléments de liste, le texte multiligne et les paires clé-valeur séparées par des barres verticales. Fournit un échappement Markdown et HTML pour la sécurité. Utilisé pour la sortie du moniteur de travaux, le rendu des e-mails et les journaux d'activité.
