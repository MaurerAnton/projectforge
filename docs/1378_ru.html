projectforge-business/src/main/kotlin/org/projectforge/framework/utils/MarkdownBuilder.kt Утилиты, projectforge-business/src/main/kotlin/org/projectforge/framework/utils/MarkdownBuilder.kt 227 строк · 156 кода · 46 комментариев · 25 пустых
Плавный построитель для генерации Markdown-контента с опциональной раскраской HTML-спанов. Поддерживает заголовки, таблицы (с форматированием строки заголовка), элементы списков, многострочный текст и пары ключ-значение, разделённые вертикальной чертой. Обеспечивает экранирование Markdown и HTML для безопасности. Используется для вывода монитора заданий, рендеринга писем и журналов активности.
