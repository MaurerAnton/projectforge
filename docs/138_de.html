Wicket-Formular zum Erstellen/Bearbeiten eines Lizenz-Eintrags. Erweitert AbstractEditForm<LicenseDO, LicenseEditPage> — ProjectForge's Standard-Bearbeitungsformular mit Bootstrap-Grid-Layout. 246 Zeilen.

Felder:

  • name — Textfeld, maximale Länge via PFAutoCompleteMaxLengthTextField
  • version — Textfeld
  • licenseKey — Datei-Upload-Feld via FileUploadPanel — speichert die Lizenzdatei als BLOB in der Datenbank
  • owners — Select2MultiChoice-Dropdown, befüllt über UsersProvider — Benutzer, die diese Lizenz sehen/bearbeiten können
  • visibleTo — Select2MultiChoice — Gruppen, die diese Lizenz sehen können (Sichtbarkeitssteuerung)
  • created, modified — schreibgeschützte Datumsfelder via LocalDatePanel

Verwendet UserRightService und UsersComparator für die Befüllung der Besitzer-/Gruppenliste. Das Lizenzschlüssel-Feld speichert den Byte-Inhalt der hochgeladenen Datei in LicenseDO.data (eine DB-BLOB-Spalte).
