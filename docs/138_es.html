Formulario Wicket para crear/editar una entrada de licencia. Extiende AbstractEditForm<LicenseDO, LicenseEditPage> — el formulario de edición estándar de ProjectForge con diseño de cuadrícula Bootstrap. 246 líneas.

Campos:

  • name — campo de texto, longitud máxima mediante PFAutoCompleteMaxLengthTextField
  • version — campo de texto
  • licenseKey — campo de carga de archivo mediante FileUploadPanel — almacena el archivo de licencia como un BLOB en la base de datos
  • owners — menú desplegable Select2MultiChoice, poblado desde UsersProvider — usuarios que pueden ver/editar esta licencia
  • visibleTo — Select2MultiChoice — grupos que pueden ver esta licencia (control de visibilidad)
  • created, modified — campos de fecha de solo lectura mediante LocalDatePanel

Utiliza UserRightService y UsersComparator para poblar la lista de propietarios/grupos. El campo de clave de licencia almacena el contenido en bytes del archivo cargado en LicenseDO.data (una columna BLOB de la base de datos).
