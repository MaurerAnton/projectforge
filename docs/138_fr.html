plugins/org.projectforge.plugins.licensemanagement/src/main/java/org/projectforge/plugins/licensemanagement/LicenseEditForm.java Chemin : plugins/...licensemanagement/src/main/java/.../LicenseEditForm.java · Lignes : 246 · Type : Java Wicket AbstractEditForm 246 lignes · 191 code · 43 commentaires · 12 vides

Formulaire Wicket pour créer/modifier une entrée de licence. Étend AbstractEditForm<LicenseDO, LicenseEditPage> — le formulaire d'édition standard de ProjectForge avec une disposition en grille Bootstrap. 246 lignes.

Champs :

  • name — champ texte, longueur max via PFAutoCompleteMaxLengthTextField
  • version — champ texte
  • licenseKey — champ de téléchargement de fichier via FileUploadPanel — stocke le fichier de licence sous forme de BLOB dans la base de données
  • owners — liste déroulante Select2MultiChoice, alimentée par UsersProvider — utilisateurs pouvant voir/modifier cette licence
  • visibleTo — Select2MultiChoice — groupes pouvant voir cette licence (contrôle de visibilité)
  • created, modified — champs de date en lecture seule via LocalDatePanel

Utilise UserRightService et UsersComparator pour le peuplement de la liste des propriétaires/groupes. Le champ de clé de licence stocke le contenu binaire du fichier téléchargé dans LicenseDO.data (une colonne BLOB de la base de données).
