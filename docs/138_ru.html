Wicket-форма для создания/редактирования записи лицензии. Расширяет AbstractEditForm<LicenseDO, LicenseEditPage> — стандартную форму редактирования ProjectForge с сеткой Bootstrap. 246 строк.

Поля:

  • name — текстовое поле, максимальная длина через PFAutoCompleteMaxLengthTextField
  • version — текстовое поле
  • licenseKey — поле загрузки файла через FileUploadPanel — сохраняет файл лицензии как BLOB в базе данных
  • owners — выпадающий список Select2MultiChoice, заполняется из UsersProvider — пользователи, которые могут видеть/редактировать эту лицензию
  • visibleTo — Select2MultiChoice — группы, которые могут видеть эту лицензию (контроль видимости)
  • created, modified — поля даты только для чтения через LocalDatePanel

Использует UserRightService и UsersComparator для заполнения списка владельцев/групп. Поле лицензионного ключа сохраняет байтовое содержимое загруженного файла в LicenseDO.data (столбец BLOB в БД).
