#139: LicenseListForm.java

Path: plugins/...licensemanagement/src/main/java/.../LicenseListForm.java · Lines: 59 · Author: Kai Reinhard · Type: Java Wicket AbstractListForm

Wicket list form for the LicenseManagement plugin. Extends AbstractListForm<BaseSearchFilter, LicenseListPage>. The simplest possible list form — contains no filter fields. Only 59 lines.

The form exists mainly to provide the "New license" (+) button and the search bar. The actual filter logic is minimal: search text is passed to BaseSearchFilter.searchString, which LicenseDao interprets as a full-text match on license name and version fields. There are no date range, owner, or category filters — contrast with more complex list forms in other plugins.
