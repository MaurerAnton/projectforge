#1399: MenuItem.kt

projectforge-business/src/main/kotlin/org/projectforge/menu/MenuItem.kt Datenklasse/Dienst, projectforge-business/src/main/kotlin/org/projectforge/menu/MenuItem.kt 146 Zeilen · 98 Code · 35 Kommentare · 13 leer
Serialisierbares Menüelement, das einen Knoten im Menübaum darstellt. Enthält ID, Titel, i18nKey, Tooltip, URL, eindeutigen Schlüssel (für React), Badge und Zieltyp. Unterstützt hierarchische Struktur über die subMenu-Liste. Die Methode postProcess() übersetzt Titel, übersetzt Tooltips automatisch, akkumuliert Badge-Zähler von Kindern zu Eltern und entfernt leere Elternknoten. Bietet außerdem eine Nachkommen-Traversierung für eine flache Auflistung.
