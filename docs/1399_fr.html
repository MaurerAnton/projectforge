projectforge-business/src/main/kotlin/org/projectforge/menu/MenuItem.kt Classe de données/Service, projectforge-business/src/main/kotlin/org/projectforge/menu/MenuItem.kt 146 lignes · 98 code · 35 commentaires · 13 vides
Élément de menu sérialisable représentant un nœud dans l'arborescence du menu. Contient l'identifiant, le titre, la clé i18n, l'infobulle, l'URL, la clé unique (pour React), le badge et le type de cible. Prend en charge la structure hiérarchique via la liste subMenu. La méthode postProcess() traduit les titres, traduit automatiquement les infobulles, accumule les compteurs de badge des enfants vers les parents et supprime les nœuds parents vides. Fournit également un parcours des descendants pour un listage à plat.
