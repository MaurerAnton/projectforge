What it does

A quick-start guide for the Docker Compose deployment. Tells you which files to edit, where to put SSL certificates, and how to launch the stack. Marked "In progress" — clearly unfinished.

The file covers three other files we've already documented: docker-compose.yml, .env, and nginx.conf.

Section-by-section

Directory structure (lines 3–9)

project/ ├── ProjectForge/ ← Application data (uploaded files, config) ├── ProjectForge/database ← Database files (not mapped in current compose!) ├── nginx/ ← nginx.conf + certs + keys ├── docker-compose.yml ← Docker Compose setup └── .env ← Environment variables

Discrepancy: The README mentions ProjectForge/database but the compose file maps the DB volume to ./ProjectForgeDB, not ProjectForge/database. This README is out of sync with the actual configuration.

Setup instructions (lines 12–24)

  1. Edit .env — change DOMAIN=mydomain.com and POSTGRES_PASSWORD
  2. Edit nginx.conf — adjust server_name if needed
  3. Deploy SSL certificates — use Let's Encrypt + Certbot, place in nginx/certs/ and nginx/keys/
  4. docker compose up -d — launch in detached mode
  5. Verify: docker ps (running containers), docker compose logs (troubleshooting)
