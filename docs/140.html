#140: LicenseListPage.java

Path: plugins/...licensemanagement/src/main/java/.../LicenseListPage.java · Lines: 165 · Type: Java Wicket AbstractListPage

Wicket list page for browsing license keys. Extends AbstractListPage<LicenseDao, LicenseDO, LicenseEditPage, BaseSearchFilter> — the standard CRUD list page. 165 lines. Provides a 5-column sortable DataTable.

Table columns:

  • Name (license.name) — sortable, links to edit page
  • Version (license.version) — sortable
  • License key — renders file name and size via Label with FileUtils.byteCountToDisplaySize(), or "not available" if no key was uploaded
  • Owners — comma-separated list of owner usernames, truncated via StringUtils.abbreviate()
  • Modified at — formatted date via DateFormat.getDateInstance(DateFormat.MEDIUM, locale)

The list uses Wicket's DefaultDataTable with SortableLicenseProvider (inner class implementing ISortableDataProvider) for database-level sorting — each column click triggers a re-query with the appropriate SortOrder rather than sorting in memory.
