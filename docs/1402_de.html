Spring @Component zur Verwaltung von benutzerdefinierbaren Favoritenmenüs. Liest/schreibt die Favoritenmenü-Konfiguration aus Benutzer-XML-Einstellungen über FavoritesMenuReaderWriter. Erstellt Standard-Favoritenmenüs basierend auf Benutzerrollen (Administratoren sehen Verwaltungseinträge, eingeschränkte Benutzer sehen nur Passwortänderung, normale Benutzer sehen Projektmanagement, Kalender, Aufgaben usw.). Integriert Plugins für benutzerdefinierte Menüeinträge.
