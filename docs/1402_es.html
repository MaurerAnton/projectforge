Spring @Component que gestiona menús favoritos personalizables por el usuario. Lee/escribe la configuración del menú de favoritos desde las preferencias XML del usuario a través de FavoritesMenuReaderWriter. Crea menús favoritos predeterminados basados en los roles del usuario (admin ve entradas de administración, usuarios restringidos ven solo cambio de contraseña, usuarios regulares ven gestión de proyectos, calendario, tareas, etc.). Se integra con plugins para entradas de menú personalizadas.
