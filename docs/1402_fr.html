projectforge-business/src/main/kotlin/org/projectforge/menu/builder/FavoritesMenuCreator.kt Service, projectforge-business/src/main/kotlin/org/projectforge/menu/builder/FavoritesMenuCreator.kt 114 lignes · 72 code · 30 commentaires · 12 vides
Composant Spring @Component gérant les menus favoris personnalisables par l'utilisateur. Lit/écrit la configuration des menus favoris à partir des préférences XML utilisateur via FavoritesMenuReaderWriter. Crée des menus favoris par défaut basés sur les rôles utilisateur (l'administrateur voit les entrées d'administration, les utilisateurs restreints voient uniquement le changement de mot de passe, les utilisateurs réguliers voient la gestion de projet, le calendrier, les tâches, etc.). S'intègre avec les plugins pour des entrées de menu personnalisées.
