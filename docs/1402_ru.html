#1402: FavoritesMenuCreator.kt

projectforge-business/src/main/kotlin/org/projectforge/menu/builder/FavoritesMenuCreator.kt Сервис, projectforge-business/src/main/kotlin/org/projectforge/menu/builder/FavoritesMenuCreator.kt 114 строк · 72 кода · 30 комментариев · 12 пустых
Spring @Component, управляющий настраиваемыми пользовательскими меню избранного. Читает/записывает конфигурацию меню избранного из пользовательских XML-настроек через FavoritesMenuReaderWriter. Создает стандартные меню избранного на основе ролей пользователя (администратор видит записи администрирования, ограниченные пользователи видят только смену пароля, обычные пользователи видят управление проектами, календарь, задачи и т.д.). Интегрируется с плагинами для пользовательских записей меню.
