#1404: MenuCreator.kt

projectforge-business/src/main/kotlin/org/projectforge/menu/builder/MenuCreator.kt Service, projectforge-business/src/main/kotlin/org/projectforge/menu/builder/MenuCreator.kt 663 Zeilen · 517 Code · 98 Kommentare · 48 leer
Spring @Component, das die Hauptmenübaumstruktur definiert. Initialisiert alle MenuItemDef-Einträge in einer Hierarchie (COMMON, PROJECT_MANAGEMENT, HR, FIBU, COST, REPORTING, ORGA, ADMINISTRATION, MISC) mit Untermenüpunkten. Jeder Menüpunkt verfügt über konfigurierbare Zugriffsprüfungen (erforderliche Gruppen, Benutzerrechte, benutzerdefinierte Lambda-Prüfungen), Badge-Zähler (z. B. ausstehende Urlaubsgenehmigungen, zu fakturierende Aufträge) und unterstützt die Plugin-Menüregistrierung. Die build()-Methode erstellt ein benutzerspezifisches Menü, indem sie basierend auf Zugriffsrechten filtert.
