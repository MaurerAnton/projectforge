Definición de un único elemento de menú utilizado por MenuCreator para construir dinámicamente menús de usuario. Contiene id, i18nKey, url, función badgeCounter, badgeTooltipKey, lambda de verificación de acceso, grupos requeridos y derechos de usuario. Soporta estructura jerárquica con hijos. El método createMenu() instancia un MenuItem con título traducido, clave única y badge opcional.
