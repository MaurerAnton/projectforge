Определение одного пункта меню, используемого MenuCreator для динамического построения пользовательских меню. Содержит id, i18nKey, url, функцию badgeCounter, badgeTooltipKey, лямбду проверки доступа, обязательные группы и права пользователя. Поддерживает иерархическую структуру с дочерними элементами. Метод createMenu() создаёт экземпляр MenuItem с переведённым заголовком, уникальным ключом и опциональным значком.
