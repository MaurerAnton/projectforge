#142: LicenseManagementRight.java

Path: plugins/...licensemanagement/src/main/java/.../LicenseManagementRight.java · Lines: 97 · Type: Java — extends UserRightAccessCheck<LicenseDO>

Two-level access control: (1) general plugin access via LicensePluginService.hasAccess() — returns true if user has PLUGIN_LICENSE_MANAGEMENT right; (2) license key visibility via isLicenseKeyVisible() — the actual license file content (BLOB) is hidden from users who are not owners or admins.

Visibility rules for license keys:

  • New objects: always visible (the creator must see what they're uploading)
  • Admins: always visible (via AccessChecker.isLoggedInUserMemberOfAdminGroup())
  • No owners defined: hidden (if ownerIds is blank, no one can see the key)
  • Owner match: visible if user ID is in the comma-separated ownerIds list (parsed via StringHelper.splitToLongs())

This is the key security feature of the plugin — license metadata (name, version, organization) is visible to all authorized users, but the actual license key file content is restricted to owners and admins only.
