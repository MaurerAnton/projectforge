Two-value status enum for license lifecycle tracking. Implements I18nEnum for automatic i18n lookup via getI18nKey():

  • UPTODATE("uptodate") — license is current and valid
  • OVERRATED("overrated") — license has been superseded/upgraded/exceeded

I18n keys resolve to plugins.licensemanagement.status.uptodate and plugins.licensemanagement.status.overrated. The isIn() varargs helper provides concise multi-value matching: status.isIn(UPTODATE, OVERRATED).
