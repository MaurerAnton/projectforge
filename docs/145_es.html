Entidad JPA para registros de licencias. Mapea a la tabla T_PLUGIN_LM_LICENSE. Extiende DefaultBaseDO (proporciona id, created, lastUpdate, deleted). 154 líneas, 16 campos de datos + 1 propiedad calculada.

Campos de texto/búsqueda (15 campos con @FullTextField para indexación Hibernate Search):

  • organization — nombre de la empresa (VARCHAR 1000)
  • product — nombre del producto de software (VARCHAR 1000)
  • version — versión del software (VARCHAR 1000)
  • updateFromVersion — versión de origen de actualización (VARCHAR 1000, columna update_from_version)
  • licenseHolder — titular de la licencia (VARCHAR 10000)
  • key — clave de licencia como texto (VARCHAR 10000) — permite copiar y pegar claves basadas en texto
  • ownerIds — IDs de usuarios propietarios separados por comas (VARCHAR 4000) — utilizado por LicenseManagementRight para control de visibilidad
  • device — dispositivo/hostname asociado (VARCHAR 4000)
  • comment — notas de texto libre (Constants.LENGTH_TEXT)
  • numberOfLicenses — recuento concurrente/de asientos (Integer)
  • validSince, validUntil — rango de fechas de validez de la licencia (LocalDate)
  • status — @Enumerated(STRING) — ver LicenseStatus

Almacenamiento de archivos BLOB (2 espacios para adjuntos binarios — nota: no JCR, utiliza BLOBs directos de base de datos):

  • file1 / filename1 — primer BLOB adjunto + nombre de archivo (ej. certificado de licencia PDF)
  • file2 / filename2 — segundo BLOB adjunto + nombre de archivo (ej. acuerdo de licencia)

Ambos campos BLOB están anotados con @NoHistory (excluidos del seguimiento de historial/delta — los diffs binarios no tendrían sentido) y FetchType.LAZY (se cargan solo cuando se accede explícitamente, no en cada consulta). Usa @JdbcTypeCode(SqlTypes.BLOB) para un manejo adecuado de BLOB JDBC.

Propiedad calculada: orderString (@Transient) — devuelve "$organization-$product-$version" para ordenación y visualización.
