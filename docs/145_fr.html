Entité JPA pour les enregistrements de licences. Mappe la table T_PLUGIN_LM_LICENSE. Étend DefaultBaseDO (fournit id, created, lastUpdate, deleted). 154 lignes, 16 champs de données + 1 propriété calculée.

Champs texte/interrogeables (15 champs avec @FullTextField pour l'indexation Hibernate Search) :

  • organization — nom de l'entreprise (VARCHAR 1000)
  • product — nom du logiciel (VARCHAR 1000)
  • version — version du logiciel (VARCHAR 1000)
  • updateFromVersion — version source de mise à niveau (VARCHAR 1000, colonne update_from_version)
  • licenseHolder — titulaire de la licence (VARCHAR 10000)
  • key — clé de licence sous forme de texte (VARCHAR 10000) — permet le copier-coller des clés textuelles
  • ownerIds — identifiants des propriétaires séparés par des virgules (VARCHAR 4000) — utilisé par LicenseManagementRight pour le contrôle de visibilité
  • device — appareil/nom d'hôte associé (VARCHAR 4000)
  • comment — notes en texte libre (Constants.LENGTH_TEXT)
  • numberOfLicenses — nombre de licences concurrentes/sièges (Integer)
  • validSince, validUntil — plage de dates de validité de la licence (LocalDate)
  • status — @Enumerated(STRING) — voir LicenseStatus

Stockage de fichiers BLOB (2 emplacements de pièces jointes binaires — note : pas JCR, utilise directement les BLOB de la base de données) :

  • file1 / filename1 — première pièce jointe BLOB + nom de fichier (ex. certificat de licence PDF)
  • file2 / filename2 — deuxième pièce jointe BLOB + nom de fichier (ex. contrat de licence)

Les deux champs BLOB sont annotés @NoHistory (exclus du suivi d'historique/delta — les diffs binaires n'auraient pas de sens) et FetchType.LAZY (chargés uniquement lorsqu'ils sont explicitement accédés, pas à chaque requête). Utilise @JdbcTypeCode(SqlTypes.BLOB) pour une gestion correcte des BLOB JDBC.

Propriété calculée : orderString (@Transient) — retourne "$organization-$product-$version" pour le tri et l'affichage.

toString() : implémentation personnalisée utilisant ReflectionToString qui exclut file1 et file2 (le contenu binaire produirait des vidages hexadécimaux sans signification).
