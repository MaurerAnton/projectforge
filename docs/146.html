Plugin entry point — hybrid Wicket + React architecture. Extends AbstractPlugin with ID "licenseManagement". Notable for being one of the first plugins to support both Wicket (legacy) and React (modern) UIs simultaneously.

initialize() registration:

  • Scripting support: registers LicenseDao in the RegistryEntry so it's accessible via Groovy scripting engine — scripts can query/manage licenses programmatically
  • Wicket web: registers LicenseListPage, LicenseEditPage (#140, #138)
  • React web: registers LicensePagesRest — the React frontend REST controller
  • Menu: placed under MenuItemDefId.MISC with i18n key "plugins.licensemanagement.menu"
  • 2FA shortcuts: registers write access with path /wa/licenseManagement — used by ProjectForge's two-factor authentication to allow/disallow access to the React UI
  • Rights: registerRight(LicenseManagementRight())
  • I18n: addResourceBundle("LicenseManagementI18nResources")
