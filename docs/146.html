#146: LicensePluginService.kt

Path: plugins/...licensemanagement/src/main/kotlin/.../LicensePluginService.kt · Lines: 61 · Type: Kotlin @Service singleton

Access control service via menu visibility. Uses MenuConfiguration (a framework service that determines menu visibility based on user rights) to check whether the current user has access to the LicenseManagement plugin. The singleton is stored via instance = this in @PostConstruct (a deliberate anti-pattern — circumvents Spring DI for access from Java code like LicenseManagementRight). The hasAccess() method delegates to menuVisibility?.isVisible() — the same check that controls whether the menu item appears.
