Plugin-Einstiegspunkt — hybride Wicket + React-Architektur. Erweitert AbstractPlugin mit der ID "licenseManagement". Bemerkenswert als eines der ersten Plugins, das sowohl Wicket (Legacy) als auch React (modern) UIs gleichzeitig unterstützt.

initialize()-Registrierung:

  • Scripting-Unterstützung: Registriert LicenseDao im RegistryEntry, sodass es über die Groovy-Scripting-Engine zugänglich ist – Skripte können Lizenzen programmatisch abfragen/verwalten
  • Wicket-Web: Registriert LicenseListPage, LicenseEditPage (#140, #138)
  • React-Web: Registriert LicensePagesRest – den REST-Controller für das React-Frontend
  • Menü: Platziert unter MenuItemDefId.MISC mit i18n-Schlüssel "plugins.licensemanagement.menu"
  • 2FA-Verknüpfungen: Registriert Schreibzugriff mit Pfad /wa/licenseManagement – wird von der Zwei-Faktor-Authentifizierung von ProjectForge verwendet, um den Zugriff auf die React-Oberfläche zu erlauben/zu verweigern
  • Rechte: registerRight(LicenseManagementRight())
  • I18n: addResourceBundle("LicenseManagementI18nResources")
