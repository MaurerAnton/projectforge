Point d'entrée du plugin — architecture hybride Wicket + React. Étend AbstractPlugin avec l'ID "licenseManagement". Notable pour être l'un des premiers plugins à prendre en charge simultanément les interfaces utilisateur Wicket (héritée) et React (moderne).

Enregistrement initialize() :

  • Support de script : enregistre LicenseDao dans le RegistryEntry afin qu'il soit accessible via le moteur de script Groovy — les scripts peuvent interroger/gérer les licences par programmation
  • Web Wicket : enregistre LicenseListPage, LicenseEditPage (#140, #138)
  • Web React : enregistre LicensePagesRest — le contrôleur REST du frontend React
  • Menu : placé sous MenuItemDefId.MISC avec la clé i18n "plugins.licensemanagement.menu"
  • Raccourcis 2FA : enregistre un accès en écriture avec le chemin /wa/licenseManagement — utilisé par l'authentification à deux facteurs de ProjectForge pour autoriser/interdire l'accès à l'interface React
  • Droits : registerRight(LicenseManagementRight())
  • I18n : addResourceBundle("LicenseManagementI18nResources")
