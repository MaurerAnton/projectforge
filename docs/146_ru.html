plugins/org.projectforge.plugins.licensemanagement/src/main/kotlin/org/projectforge/plugins/licensemanagement/LicenseManagementPlugin.kt Путь: plugins/...licensemanagement/src/main/kotlin/.../LicenseManagementPlugin.kt · Строк: 88 · Автор: Kai Reinhard · Тип: подкласс AbstractPlugin на Kotlin 88 строк · 46 кода · 33 комментария · 9 пустых

Точка входа плагина — гибридная архитектура Wicket + React. Расширяет AbstractPlugin с идентификатором "licenseManagement". Примечателен тем, что является одним из первых плагинов, поддерживающих одновременно как Wicket (устаревший), так и React (современный) интерфейсы.

Регистрация в initialize():

  • Поддержка скриптов: регистрирует LicenseDao в RegistryEntry, чтобы он был доступен через движок сценариев Groovy — скрипты могут программно запрашивать/управлять лицензиями
  • Wicket web: регистрирует LicenseListPage, LicenseEditPage (#140, #138)
  • React web: регистрирует LicensePagesRest — REST-контроллер для фронтенда на React
  • Меню: размещено в MenuItemDefId.MISC с i18n-ключом "plugins.licensemanagement.menu"
  • Ярлыки 2FA: регистрирует доступ на запись с путём /wa/licenseManagement — используется двухфакторной аутентификацией ProjectForge для разрешения/запрета доступа к React-интерфейсу
  • Права: registerRight(LicenseManagementRight())
  • I18n: addResourceBundle("LicenseManagementI18nResources")
