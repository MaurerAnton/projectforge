REST controller for the React frontend at ${Rest.URL}/license. Extends AbstractDOPagesRest<LicenseDO, LicenseDao> which auto-generates list/create/read/update/delete endpoints. 73 lines — small because most logic is inherited.

List layout (8 columns): organization, product, version, numberOfLicenses, ownerIds, device, key, comment — rendered as a sortable data table in the React UI.

Edit layout: 5 text fields (organization, product, version, updateFromVersion, device, numberOfLicenses) in a row. Contains a TODO marker: UILabel("TODO: Owner selection") — the owner multi-select widget was never implemented in the React UI. Below that: validSince/validUntil date range fields, file1/file2 upload fields (for license certificate/supplier agreement PDFs), and a comment text area.

The controller is registered in LicenseManagementPlugin via registerShortCutClasses(My2FAShortCut.FINANCE, LicensePagesRest::class.java) for 2FA access control.
