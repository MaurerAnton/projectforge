#153: LiquidityChartBuilder.java

Lines: 171 · Author: Kai Reinhard · Type: Java JFreeChart plot builder

Builds XY time-series liquidity forecast charts. Takes LiquidityForecast (daily credit/debit projections) and LiquidityForecastSettings (next N days, max forecast days = 365) and produces a JFreeChart with three renderers:

  • XYLineAndShapeRenderer — credit line (green, above zero), debit line (red, below zero), total line (combined)
  • XYDifferenceRenderer — colored area between credit and debit lines (visualizes the liquidity gap)
  • XYBarRenderer — optional bar chart mode for discrete daily values

Uses TimeSeries / TimeSeriesCollection with Day as the time unit. X-axis: dates from tomorrow to nextDays days ahead. Y-axis: amounts in euros. Chart title includes i18n via I18n.getLocalizedString(). Built on ProjectForge's XYChartBuilder framework base class. Default forecast: 90 days.
