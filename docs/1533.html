1533: AccessException.java

Java class (Exception), projectforge-business/src/main/java/org/projectforge/framework/access/AccessException.java
Exception thrown by the access checker when a user lacks permission for a requested action. Extends UserException. Supports task-based, operation-type-based, and generic I18N-key-based error messages. Logs access violations at INFO level.
