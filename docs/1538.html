1538: AddressDao.kt

Kotlin @Service DAO, projectforge-business/src/main/kotlin/org/projectforge/business/address/AddressDao.kt

Purpose

Data access object for AddressDO entities. Extends BaseDao<AddressDO>. Manages CRUD operations, search/filter, vCard export, birthday lookup, internal phone number lookup, duplicate detection, and addressbook access rights.

Key Dependencies

  • AddressbookDao / AddressbookCache — addressbook membership
  • AddressbookRight — per-addressbook access control
  • PersonalAddressDao — user favorites/vCards
  • TeamEventDao — attendee cleanup on deletion
  • SipgateDeleteContactService — SIP contact cleanup
  • AddressImageDao — lazy via ApplicationContext (circular dependency)
  • BirthdayCache — cached birthday lookups

Key Methods

  • select(filter, checkAccess) — filters by addressbooks, contact status, address status; supports doublet/favorite result filtering
  • hasAccess(user, obj, oldObj, opType, throwExc) — checks per-addressbook access rights; SELECT requires any access, write ops require full access
  • beforeInsertOrModify(obj, opType) — ensures global addressbook on insert; prevents removal of restricted addressbooks on modify
  • onDelete(obj) — cascades to personal addresses, team events, SIP contacts, images; notifies deletion listeners
  • onInsert(obj) — auto-generates UUID if uid is blank
  • getBirthdays(from, to, all) — returns cached birthday list filtered by date range and favorites
  • exportVCard(addressDO, embedImage, vCardVersion) — exports single vCard with optional embedded image
  • exportFavoriteVCards(out, favorites, embedImage, vCardVersion) — batch vCard export
  • internalPhoneLookUp(phoneNumber) — reverse phone lookup across all addresses
  • findByNameAndFirstName(name, firstName, checkAccess) — duplicate detection helper
  • usedCommunicationLanguages — distinct list of communication languages across all addresses

Design Notes

Uses lazy bean resolution for AddressImageDao to break circular dependency. Addressbook access is enforced via addAddressbookRestriction(filter) which joins addressbookList and filters by the user's authorized addressbook IDs. The global addressbook (ID from AddressbookDao.GLOBAL_ADDRESSBOOK_ID) is always included.
