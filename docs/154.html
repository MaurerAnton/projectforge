#154: LiquidityEntriesStatistics.java

Lines: 111 · Type: Java Serializable POJO — financial aggregation

Aggregates liquidity entries into summary statistics. Maintains four BigDecimal accumulators: paid, open, total, overdue (entries past their expected payment date). Two counters: counter (total entries), counterPaid (settled entries). Has add(LiquidityEntry) and add(LiquidityEntryDO) overloads that increment counters and accrete amounts based on entry type (credit/debit → in/out) and paid status. Stores today for overdue calculations. Used by LiquidityEntryDao.buildStatistics() (#155) to populate dashboard summaries.
