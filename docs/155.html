Lines: 111 · Type: Java @Service DAO — extends BaseDao<LiquidityEntryDO>

Data access for liquidity planning entries. Extends BaseDao<LiquidityEntryDO> requiring PLUGIN_LIQUIDITY_PLANNING right. Provides buildStatistics(list) which iterates entries and accumulates into LiquidityEntriesStatistics: totals by type (in/out based on AmountType CREDIT vs DEBIT), paid vs open vs overdue status.

Forecast query: getList(BaseSearchFilter) supports date range filtering — fetches all entries within a period for the chart builder. Respects the DAO-level access check so users only see entries they're authorized for. Uses Hibernate QueryFilter for server-side filtering (date ranges on dateOfPayment / expectedDateOfPayment, paid status filter, amount type filter).
