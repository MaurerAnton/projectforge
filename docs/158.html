#158: LiquidityEntry.java

Lines: 157 · Author: Kai Reinhard · Type: Java Serializable DTO — unified cash flow entry

Aggregate model for liquidity forecasting. A Serializable DTO, NOT a JPA @Entity — wraps three source types into a unified view: LiquidityEntryDO (manual liquidity entry), RechnungDO (outgoing customer invoice), EingangsrechnungDO (incoming supplier invoice). The chart builder uses this DTO to plot everything on the same time-series chart.

Fields: dateOfPayment (actual), expectedDateOfPayment (projected), amount (BigDecimal with PropertyType.CURRENCY), paid (boolean), subject (description from source), type (LiquidityEntryType: MANUAL, RECHNUNG, EINGANGSRECHNUNG), amountType (AmountType: CREDIT/DEBIT), status (PaymentStatus), reference IDs and business partner name. All annotated with @PropertyInfo for i18n-aware display.
