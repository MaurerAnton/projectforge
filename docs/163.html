#163: LiquidityForecastForm.java

Lines: 123 · Type: Java Wicket AbstractStandardForm

Forecast settings form. Extends AbstractStandardForm<LiquidityForecastSettings, LiquidityForecastPage>. Controls displayed on the forecast page above the chart:

  • baseDate — LocalDatePanel date picker — starting date of the forecast (default: today)
  • nextDays — RequiredMinMaxNumberField (1-365, default 90) — how many days to forecast
  • showPaidEntries — checkbox — whether to include already-settled entries in the chart
  • amount — read-only current balance display
  • Export and Refresh buttons

The form binds to LiquidityForecastSettings via Wicket PropertyModel. On submit, re-generates the forecast and re-renders the chart image.
