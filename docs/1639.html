#1639: AddressDO.kt

Entity, projectforge-business/src/main/kotlin/org/projectforge/business/address/AddressDO.kt
JPA entity for addresses mapped to T_ADDRESS. Extends DefaultBaseDO, implements DisplayNameCapable. Fields: contact status, address status, UID, name, first name, organization, form of address, birthday, communication fields (email, phone, mobile, website), postal/private/business address fields, images. Full-text indexed via Hibernate Search. Supports JSON serialization with IdsOnlySerializer.
