#164: LiquidityForecastPage.html

Wicket HTML template. Companion markup for LiquidityForecastPage.java. Contains <wicket:panel> tags for the form (top), chart images (center), and Excel export button (bottom). Uses Bootstrap grid classes for responsive layout. Minimal markup — the chart images are rendered by Wicket's ImagePanel component pointing to dynamically generated JFreeChartImage PNG resources.
