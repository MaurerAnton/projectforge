#1640: AddressFilter.java

Filter, projectforge-business/src/main/java/org/projectforge/business/address/AddressFilter.java
Search filter for addresses extending BaseSearchFilter. Supports filtering by status flags (uptodate, outdated, leaved, active, nonActive, uninteresting, personaIngrata, departed), list type (FILTER_DOUBLETS, FILTER_FILTER, FILTER_MY_FAVORITES, FILTER_NEWEST), and addressbook IDs.
