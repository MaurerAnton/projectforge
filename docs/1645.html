#1645: AddressbookDO.kt

Entity, projectforge-business/src/main/kotlin/org/projectforge/business/address/AddressbookDO.kt
JPA entity for address books mapped to T_ADDRESSBOOK. Extends BaseUserGroupRightsDO, implements DisplayNameCapable. Fields: title, owner (PFUserDO), description, and user/group access rights. Full-text indexed via Hibernate Search with HibernateSearchUsersGroupsTypeBinder for user/group search.
