#1647: BookDO.kt

Entity, projectforge-business/src/main/kotlin/org/projectforge/business/book/BookDO.kt
JPA entity for library books mapped to T_BOOK. Extends DefaultBaseDO, implements DisplayNameCapable and AttachmentsInfo. Fields: signature (unique), title, authors, ISBN, lending details (lend out by user, date, comment), and a custom display name as "authors: title". Supports Hibernate Search indexing.
