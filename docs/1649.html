#1649: ContractDao.java

DAO/Service, projectforge-business/src/main/java/org/projectforge/business/orga/ContractDao.java
Data access object for ContractDO extending BaseDao with user right ORGA_CONTRACTS. Auto-generates contract numbers starting at 1000. Filters by status, type, year/month. Supports autocompletion for title, co-contractors, contract persons, and signers. Number uniqueness validation via FIND_OTHER_BY_NUMBER.
