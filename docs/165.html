#165: LiquidityForecastPage.java

Lines: 127 · Type: Java Wicket AbstractStandardFormPage

Forecast visualization page. Hosts LiquidityForecastForm (settings) and two chart images: xyPlotImage (line chart of credit/debit/balance) and barChartImage (bar chart of daily net flow). Both are ImagePanel components rendering JFreeChartImage at 800×400 pixels.

Page flow:

  1. On load, creates LiquidityForecast with default settings (90 days, today as base)
  2. Computes LiquidityForecastCashFlow (#162) from forecast data
  3. Renders XY plot via LiquidityChartBuilder.createXYPlot() (#153)
  4. Renders bar chart via LiquidityChartBuilder.createBarChart()
  5. On settings change, re-computes and refreshes chart images via Wicket AJAX
  6. Excel export button: generates LiquidityForecastCashFlow as MyExcelExporter spreadsheet

Charts are cached per forecast settings via LoadableDetachableModel — avoids re-rendering on every page refresh.
