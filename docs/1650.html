#1650: ContractDO.kt

Entity, projectforge-business/src/main/kotlin/org/projectforge/business/orga/ContractDO.kt
JPA entity for contracts mapped to T_CONTRACT. Extends DefaultBaseDO, implements AttachmentsInfo. Fields: number (auto-generated), date, valid from/to, title, type, status, co-contractors (A/B), contract persons (A/B), signers (A/B), and file attachments. Named queries: FIND_OTHER_BY_NUMBER and SELECT_MIN_MAX_DATE. Full-text indexed via Hibernate Search.
