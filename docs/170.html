#170: LiquidityForecastBuilder.kt

Lines: 121 · Type: Kotlin @Service — forecast computation engine

Builds a LiquidityForecast from three data sources. Autowires EingangsrechnungDao, RechnungDao, and LiquidityEntryDao — the three sources of cash flow data. The build(baseDate) method:

  1. Historical mode (baseDate < now): includes already-paid invoices to show what actually happened, helpful for comparing forecasted vs. realized cash flow
  2. Future mode (baseDate ≥ now): uses only UNPAID entries (via LiquidityFilter.paymentStatus = UNPAID), but first queries paid invoices to estimate expected payment timing using forecast.calculateExpectedTimeOfPayments() — the DSO-style average payment period analysis

Data window: from 12 months before baseDate to 3 months after. Invoices outside this range are excluded. handleHistoricalInvoices() removes already-settled invoices older than 45 days from the forecast window. createRechnungFilter() builds RechnungFilter with appropriate date ranges and paid/unpaid toggles.

This is the Kotlin counterpart to the Java LiquidityForecastCashFlow (#162) — the builder gathers data from DAOs, while LiquidityForecastCashFlow computes the day-by-day arrays and generates the Excel export.
