#178: org.projectforge.plugins.core.AbstractPlugin

Service Descriptor, plugins/org.projectforge.plugins.banking/src/main/resources/META-INF/services/org.projectforge.plugins.core.AbstractPlugin

Java SPI service loader descriptor for the Banking plugin. Maps org.projectforge.plugins.banking.BankingPlugin to the AbstractPlugin interface, enabling the plugin framework to auto-discover and register plugins.

Architecture

Uses java.util.ServiceLoader mechanism. Each plugin provides this descriptor in META-INF/services/. The core framework scans classpath for these files and instantiates the declared plugin classes.
