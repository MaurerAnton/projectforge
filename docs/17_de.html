Deutschsprachige Anleitung zur Installation einer Testinstanz von ProjectForge. Behandelt Download, Java 17 Einrichtung, eingebettete Datenbank, Entwicklungskonfiguration, 2FA-Simulation und Rücksetzanweisungen.

Behandelte Abschnitte

  1. Download der JAR-Datei
  2. Java 17 Installation
  3. Erststart mit konsolenbasiertem Assistenten
  4. Eingebettete Datenbank vs. PostgreSQL
  5. Testsystem-Auswahl und Passwortvergabe
  6. Herunterfahren mit STRG-C
  7. Konfiguration (development.mode, SMS-URL)
  8. 2-Faktor-Authentifizierung simulieren
  9. Zurücksetzen (Datenbank löschen)
  10. Weiterführende Dokumentationslinks
