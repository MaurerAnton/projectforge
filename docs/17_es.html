Guía en alemán para instalar una instancia de prueba de ProjectForge. Cubre descarga, configuración de Java 17, base de datos integrada, configuración de modo de desarrollo, simulación de 2FA e instrucciones de reinicio.

Secciones cubiertas

  1. Descarga del archivo JAR
  2. Instalación de Java 17
  3. Primer inicio con el asistente basado en consola
  4. Base de datos integrada vs. PostgreSQL
  5. Selección del sistema de prueba y asignación de contraseña
  6. Apagado con CTRL-C
  7. Configuración (development.mode, URL de SMS)
  8. Simular autenticación de dos factores
  9. Reinicio (eliminar base de datos)
  10. Enlaces a documentación adicional

Propiedades clave de configuración

PropiedadPropósito
projectforge.development.mode=trueActiva el registro detallado e imprime códigos 2FA
projectforge.sms.urlURL de la puerta de enlace SMS para la simulación de 2FA
