Guide en allemand pour installer une instance de test de ProjectForge. Couvre le téléchargement, la configuration de Java 17, la base de données embarquée, la configuration en mode développement, la simulation 2FA et les instructions de réinitialisation.

Sections couvertes

  1. Téléchargement du fichier JAR
  2. Installation de Java 17
  3. Premier démarrage avec l'assistant en console
  4. Base de données embarquée vs PostgreSQL
  5. Sélection du système de test et attribution du mot de passe
  6. Arrêt avec CTRL-C
  7. Configuration (development.mode, URL SMS)
  8. Simulation de l'authentification à deux facteurs
  9. Réinitialisation (suppression de la base de données)
  10. Liens vers la documentation complémentaire
