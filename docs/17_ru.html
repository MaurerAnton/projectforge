doc/Testinstallation-deutsch.adoc Документация, doc/Testinstallation-deutsch.adoc 72 строки · 45 кода · 2 комментария · 25 пустых
Руководство на немецком языке по установке тестового экземпляра ProjectForge. Охватывает загрузку, настройку Java 17, встроенную базу данных, конфигурацию режима разработки, симуляцию 2FA и инструкции по сбросу.

Охваченные разделы

  1. Загрузка JAR-файла
  2. Установка Java 17
  3. Первый запуск с консольным мастером
  4. Встроенная база данных vs. PostgreSQL
  5. Выбор тестовой системы и назначение пароля
  6. Остановка с помощью CTRL-C
  7. Конфигурация (development.mode, SMS-URL)
  8. Симуляция двухфакторной аутентификации
  9. Сброс (удаление базы данных)
  10. Ссылки на дополнительную документацию

Ключевые свойства конфигурации

СвойствоНазначение
projectforge.development.mode=trueВключает подробное логирование и вывод кодов 2FA
projectforge.sms.urlURL SMS-шлюза для симуляции 2FA
