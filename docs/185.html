Two-tier access control for address campaigns. Registered with MarketingPluginUserRightId.PLUGIN_MARKETING_ADDRESS_CAMPAIGN (category PLUGINS, default TRUE). hasAccess() checks: (1) user has the marketing right AND (2) user has AddressbookRight — campaign access depends on address book access because campaigns target contacts from address books. This creates a dependency chain: no address book access → no campaign access.
