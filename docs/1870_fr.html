La Licence Publique Générale GNU version 3 (GPLv3) — le texte juridique complet de la licence sous laquelle l'édition communautaire du module projectforge-common est distribuée. Il s'agit du texte standard GPLv3 tel que publié par la Free Software Foundation le 29 juin 2007, avec un préambule spécifique à ProjectForge par Kai Reinhard (Micromata GmbH).

Architecture

Ce fichier contient le texte complet de la Licence Publique Générale GNU version 3 (environ 670 lignes). Le texte de la licence est la GPLv3 standard, non modifiée, telle que publiée par la Free Software Foundation.

Contexte de double licence

ProjectForge est sous double licence. Cette édition communautaire est disponible sous GPLv3. Une licence commerciale/propriétaire distincte est disponible pour les utilisateurs professionnels qui ne peuvent pas se conformer aux termes de la GPLv3 (par exemple, ceux qui ont besoin d'intégrer ProjectForge dans un logiciel propriétaire sans ouvrir leur propre code source).

Relation avec les autres modules ProjectForge

Chaque module ProjectForge (projectforge-common, projectforge-application, projectforge-business, plugins) contient son propre fichier LICENCE.txt, bien que les termes de la licence soient généralement le même texte GPLv3. Les fichiers source eux-mêmes portent un en-tête succinct faisant référence à la GPLv3 avec une URL renvoyant vers le site GNU.

Remarque : Le préambule mentionne le copyright 2001-2014 par Kai Reinhard individuellement, tandis que les en-têtes de code source dans la base de code réelle indiquent le copyright 2001-2026 par Micromata GmbH. Cela reflète la transition organisationnelle au cours de l'historique de développement de ProjectForge — Kai Reinhard était l'auteur original et le fondateur ; le copyright a ensuite été attribué à Micromata GmbH.
La GPLv3 diffère notablement de la GPLv2 dans plusieurs domaines clés : elle inclut des octrois explicites de licences de brevet (section 11), des dispositions anti-tivoisation/DRM (section 6 sur les « Informations d'installation »), et une compatibilité avec l'Affero GPL (section 13). Ces ajouts la rendent plus adaptée aux logiciels basés sur le web comme ProjectForge.
