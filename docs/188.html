Campaign entity. Maps to T_PLUGIN_MARKETING_ADDRESS_CAMPAIGN. 2 data fields: title (full-text indexed, Constants.LENGTH_TITLE ~255 chars) and description (full-text indexed text). Plus a @Transient computed property: val orderString get() = title ?: "" for sorting. Simple entity — the campaign is just a grouping label; the actual address-to-campaign mapping is stored in AddressCampaignValueDO (junction entity).
