Interface marqueur pour les énumérations avec clés i18n. Fournit une fabrique compagnon qui résout les constantes d'énumération par nom, avec journalisation des erreurs pour les valeurs non correspondantes.

Conception

Les énumérations implémentent cette interface en fournissant i18nKey — une clé de localisation utilisée par l'interface utilisateur et l'affichage de l'historique pour traduire les valeurs d'énumération. La fabrique compagnon I18nEnum.create(clazz: Class<*>, value: String?) utilise la réflexion pour trouver la constante d'énumération correspondante par comparaison du nom toString(), en journalisant un avertissement si aucune correspondance n'est trouvée.

Contexte d'utilisation

Principalement utilisé par HistoryService et les convertisseurs de la couche d'affichage. Lorsqu'un attribut d'entrée d'historique contient une valeur d'énumération (par exemple, TaskStatus.N), le système utilise I18nEnum.create() pour reconstruire la constante d'énumération, puis lit son i18nKey pour un affichage localisé.
