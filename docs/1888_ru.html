#1888: I18nEnum.kt

projectforge-common/src/main/java/org/projectforge/common/i18n/I18nEnum.kt Интерфейс, projectforge-common/.../i18n/I18nEnum.kt 52 строки · 17 кода · 30 комментариев · 5 пустых
Маркерный интерфейс для перечислений с i18n-ключами. Предоставляет фабричный метод-компаньон, который разрешает константы перечисления по имени, с логированием ошибок для несоответствующих значений.

Дизайн

Перечисления реализуют этот интерфейс, предоставляя i18nKey — ключ локализации, используемый пользовательским интерфейсом и отображением истории для перевода значений перечисления. Фабричный метод-компаньон I18nEnum.create(clazz: Class<*>, value: String?) использует рефлексию для поиска соответствующей константы перечисления по сравнению имени toString(), записывая предупреждение, если совпадение не найдено.

Контекст использования

В основном используется HistoryService и конвертерами уровня отображения. Когда атрибут записи истории содержит значение перечисления (например, TaskStatus.N), система использует I18nEnum.create() для восстановления константы перечисления, затем считывает её i18nKey для локализованного отображения.
