#189: AddressCampaignValueDao.kt

Lines: 248 · Type: Kotlin @Service DAO — extends BaseDao<AddressCampaignValueDO>

Complex DAO for address campaign assignments. 248 lines — one of the more sophisticated plugin DAOs. Manages the many-to-many relationship between addresses and campaigns (stored as explicit junction entity AddressCampaignValueDO rather than a simple join table — each assignment has its own value and comment fields).

Key methods:

  • get(addressId, addressCampaignId) — finds a single campaign value by named query FIND_BY_ADDRESS_AND_CAMPAIGN. Uses persistenceService.selectNamedSingleResult()
  • selectAddressesForCampaign(campaignId, filter, customResultFilters, checkAccess) — the main query. Loads ALL addresses (including those without campaign values) for a campaign with filters. Algorithm: (1) queries AddressDao for all matching addresses with access control, (2) queries campaign values for the given campaign, (3) joins them — addresses without campaign values get a AddressCampaignValueDO with null value/comment and only address data filled. This enables the list UI to show every address in the address book alongside their campaign status
  • getList(filter) — standard filtered list with campaign ID restriction via QueryFilter.eq("addressCampaign.id", campaignId)

Autowires both addressDao and addressCampaignDao — crosses module boundaries between address book and marketing plugins. The CustomResultFilter mechanism bridges address filters (favorites, doublets, images) to the campaign view.
