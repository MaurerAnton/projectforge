#191: AddressCampaignValueExport.kt

Lines: 77 · Type: Kotlin Excel exporter

Exports address campaign values to Excel. 77 lines. Generates a spreadsheet with columns: address name, organization, email, phone, campaign value, comment, and address status. Uses ProjectForge's MyExcelExporter framework with DOListExcelExporter. The export is triggered from the campaign list page and respects the same access controls as the DAO — only addresses visible to the user appear in the export.
