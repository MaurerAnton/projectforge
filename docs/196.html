#196: MarketingPluginAddressDeletionListener.kt

Lines: 47 · Type: Kotlin Hibernate event listener

Cascading cleanup when addresses are deleted. Listens to Hibernate PostDeleteEvent. When an AddressDO is deleted, this listener executes the DELETE_BY_ADDRESS named query on AddressCampaignValueDO — removes all campaign assignments for the deleted contact. Prevents orphaned campaign value rows referencing non-existent addresses. Uses Spring @Component + manual Hibernate listener registration rather than JPA @PreRemove (which wouldn't work on bulk deletes).
