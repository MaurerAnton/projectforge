Guía de configuración orientada al usuario para el plugin IHK. Escrita en alemán — el plugin está diseñado específicamente para el sistema de aprendizaje alemán IHK (Ausbildungsnachweis — informes semanales obligatorios que los aprendices entregan a su supervisor de formación).

Propósito del plugin

Exporta las entradas de la hoja de tiempos semanal como una hoja de cálculo Excel formateada que coincide con el formato de informe requerido por la IHK. Los aprendices registran sus horas de trabajo en la hoja de tiempos de ProjectForge; este plugin genera el archivo Excel del informe semanal que debe enviarse a la IHK.

Configuración (JSON en el campo de comentario de dirección)

El plugin lee la configuración del registro de contacto de la libreta de direcciones del aprendiz — específicamente el campo Bemerkungsfeld (campo de comentario/observación). El JSON debe colocarse allí:

{
  "ausbildungsbeginn" : "yyyy-mm-dd",
  "ausbildungsjahr" : "-1",
  "teamname" : "Tu nombre de equipo"
}
  • ausbildungsbeginn — fecha de inicio del aprendizaje (se utiliza para calcular el año de formación en el que se encuentra el aprendiz)
  • ausbildungsjahr — anulación manual del año de formación. El valor predeterminado -1 significa cálculo automático desde la fecha de inicio. Se utiliza para aprendices que saltaron el primer año o acortaron su programa
  • teamname — nombre del equipo/departamento que se muestra en el encabezado del Excel

Restricción importante

El nombre y apellido del usuario deben coincidir exactamente con el nombre y apellido en su registro de contacto de la libreta de direcciones. El plugin empareja las entradas de la hoja de tiempos comparando el nombre del usuario conectado con el nombre del contacto.
