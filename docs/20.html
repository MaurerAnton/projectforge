What it does

A 9-line AsciiDoc page that stitches the LICENSE.txt file into the generated documentation site. Uses AsciiDoc's include:: directive rather than duplicating the license text — a single-source-of-truth pattern: the root LICENSE.txt is the canonical copy, and this page is an AsciiDoc wrapper with navigation and metadata.

AsciiDoc mechanics
