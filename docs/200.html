#200: AddressCampaignValueMultiSelectedPageRest.kt

REST controller for campaign value multi-selection in React UI. Extends AbstractMultiSelectedPageRest<AddressCampaignValueDO, AddressCampaignValueDao> at ${Rest.URL}/addressCampaignValue. Provides the grid UI with address columns + value/comment fields. Supports filtered loading (by campaign ID) and all the standard result filters (favorites, my entries, invalid, images). The "multi-selected page" pattern allows editing multiple campaign values in a grid without opening individual edit dialogs.
