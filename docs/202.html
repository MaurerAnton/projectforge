#202: CampaignValueFilterAdapter.kt

REST filter adapter. Bridges AddressCampaignValueFilter (Java) to AddressCampaignValueMultiSelectedPageRest (Kotlin). Converts the REST query parameters (campaign ID, search string, filters) into the DAO filter object. Handles result filter adaptation — maps address-side filters (favorites, doublets, images, my entries, invalid) to campaign value queries.
