Archivo de recursos i18n en español para el plugin de Marketing. No contiene entradas porque el español se resuelve mediante el mecanismo de fallback del framework.

Arquitectura

Este es el paquete de recursos para el locale de español del plugin de Marketing. ProjectForge utiliza paquetes de recursos .properties de Java con las convenciones de nomenclatura estándar: I18nResources.properties para el locale base/fallback, y variantes con sufijo (_en, _de, etc.) para las traducciones. Dado que el español no es el locale por defecto, este archivo puede estar vacío o contener solo sobrescrituras específicas — todas las claves i18n se resuelven desde las anotaciones @I18n en el código fuente Kotlin/Java. Cuando se solicita una clave de traducción para el locale es, el framework primero verifica este archivo, luego recurre al base MarketingI18nResources.properties y finalmente a los valores por defecto de las anotaciones.
