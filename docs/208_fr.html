Fichier de ressources i18n français pour le plugin Marketing. Ne contient aucune entrée car le français est la locale par défaut — toutes les clés se replient sur leurs définitions dans le code source du plugin.

Architecture

Ceci est le bundle de ressources pour la locale française du plugin Marketing. ProjectForge utilise des bundles de ressources Java .properties avec des conventions de nommage standard : I18nResources.properties pour la locale de base/fallback, et des variantes suffixées (_en, _de, etc.) pour les traductions. Puisque le français est la locale par défaut, ce fichier est intentionnellement vide — toutes les clés i18n sont résolues à partir des annotations @I18n dans le code source Kotlin/Java. Lorsqu'une clé de traduction est demandée pour la locale fr, le framework vérifie d'abord ce fichier, puis se replie sur le fichier de base MarketingI18nResources.properties, et enfin sur les valeurs par défaut des annotations.
