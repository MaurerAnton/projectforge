Файл ресурсов i18n на русском языке для плагина Marketing. Не содержит записей, так как русский язык не является базовой локалью — все ключи берутся из определений в исходном коде плагина.

Архитектура

Это пакет ресурсов для русской локали плагина Marketing. ProjectForge использует Java-пакеты ресурсов .properties со стандартными соглашениями об именовании: I18nResources.properties для базовой/запасной локали и варианты с суффиксами (_en, _de и т.д.) для переводов. Поскольку русский язык не является языком по умолчанию, этот файл намеренно пуст — все ключи i18n разрешаются из аннотаций @I18n в исходном коде на Kotlin/Java. Когда ключ перевода запрашивается для локали ru, фреймворк сначала проверяет этот файл, затем переходит к базовому MarketingI18nResources.properties и, наконец, к значениям по умолчанию из аннотаций.
