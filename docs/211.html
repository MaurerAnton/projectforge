#211: MemoDao.java

Lines: 71 · Type: Java @Service DAO

DAO for sticky notes. Overrides getList() to enforce owner-only filtering — queries only memos belonging to ThreadLocalUserContext.getUserId() via QueryFilter.eq("owner.id", userId). No admin override — even admins see only their own memos. This is one of the simplest DAOs in the project, but the owner-only filtering makes it conceptually similar to the IHK plugin's right check.
