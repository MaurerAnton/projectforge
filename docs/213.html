Lines: 75 · Type: Kotlin JPA @Entity — AbstractBaseDO<Long> subclass

Sticky note entity. Maps to T_PLUGIN_MEMO. Notable for extending AbstractBaseDO<Long> instead of DefaultBaseDO — this means: no history/delta tracking (changes are not recorded), no soft delete (physical deletion — "there is no undo!" per Javadoc), and the primary key is pk (generated by @GeneratedValue). Index on owner_fk.

Fields: owner (@ManyToOne(fetch=LAZY) → PFUserDO, serialized as ID-only in JSON), title (full-text indexed, max 255 chars), description (full-text indexed text field).

This is the simplest entity in ProjectForge plugin space — chosen deliberately as a reference implementation/reference plugin.
