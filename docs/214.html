#214: MemoPlugin.kt

Lines: 75 · Type: Kotlin AbstractPlugin

Memo plugin entry point. ID: "memo", name: "Memo". The simplest plugin — no React REST, no scripting, no JCR. Registers only: Wicket pages (MemoListPage, MemoEditPage), DAO for scripting access, menu under MISC with icon "fa-sticky-note", and one user right. This is the reference plugin used as a template when creating new plugins — its simplicity makes it the canonical example of the minimum viable plugin.
