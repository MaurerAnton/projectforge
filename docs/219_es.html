Paquete de internacionalización predeterminado para el plugin Memo. Proporciona 8 claves en inglés para la interfaz de gestión de memos: un plugin simple para crear, editar y listar memos internos propiedad de usuarios.

Categorías de claves

  • Etiquetas de entidad: memo, owner, subject — utilizadas como etiquetas de campo en formularios y encabezados de columna en tablas de datos.
  • Navegación: menu — registrada mediante MenuItemDef en el método initialize() del plugin.
  • Títulos de página: title.add, title.edit, title.heading, title.list — siguen la convención CRUD estándar de 4 títulos de ProjectForge que cubren las vistas de crear, editar, encabezado y listar.
Plugin minimalista: El plugin Memo es uno de los más simples en ProjectForge, con solo 8 claves i18n. Compárese con DataTransfer (69 claves, #104) o el plugin IHK (11 claves). El conjunto reducido de claves refleja el alcance enfocado del plugin: memos propietarios con un asunto.
