Bundle d'internationalisation par défaut pour le plugin Memo. Fournit 8 clés anglaises pour l'interface de gestion des mémos — un plugin simple pour créer, éditer et lister les mémos internes appartenant aux utilisateurs.

Catégories de clés

  • Libellés d'entité : memo, owner, subject — utilisés comme libellés de champ dans les formulaires et en-têtes de colonne dans les tableaux de données.
  • Navigation : menu — enregistré via MenuItemDef dans la méthode initialize() du plugin.
  • Titres de page : title.add, title.edit, title.heading, title.list — suivent la convention standard CRUD à 4 titres de ProjectForge couvrant les vues de création, édition, en-tête et liste.
Plugin minimaliste : Le plugin Memo est l'un des plus simples de ProjectForge, avec seulement 8 clés i18n. Comparez avec DataTransfer (69 clés, #104) ou le plugin IHK (11 clés). Le petit ensemble de clés reflète le périmètre ciblé du plugin : mémos possédés avec un sujet.
