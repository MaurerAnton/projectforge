Localización alemana para el plugin Memo. Proporciona 8 claves traducidas para la interfaz de gestión de memos, cargadas cuando el idioma del usuario es alemán.

Traducciones notables

  • owner → "Eigner" — coherente con SkillMatrix (#269) y otros plugins, usando "Eigner" en lugar de "Besitzer" como término estándar alemán de ProjectForge.
  • subject → "Betreff" — el término alemán estándar para asuntos de correo/mensajes, apropiado para entidades de memo.
  • title.add → "Memo hinzufügen" — usa "hinzufügen" (añadir) en lugar de "erstellen" (crear), coincidiendo con el patrón inglés "Add new memo".
  • title.list → "Memoliste" — sustantivo compuesto típico de las convenciones de interfaz de usuario alemanas.
  • memo y menu permanecen sin traducir — "Memo" y "Memos" son términos internacionales utilizados tal cual en alemán.
