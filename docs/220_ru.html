Немецкая локализация для плагина Memo. Предоставляет 8 переведённых ключей для интерфейса управления записками, загружаемых, когда локаль пользователя — немецкая.

Примечательные переводы

  • owner → "Eigner" — согласовано с SkillMatrix (#269) и другими плагинами, используется "Eigner" вместо "Besitzer" как стандартный немецкий термин ProjectForge.
  • subject → "Betreff" — стандартный немецкий термин для тем писем/сообщений, подходит для сущностей записок.
  • title.add → "Memo hinzufügen" — используется "hinzufügen" (добавить), а не "erstellen" (создать), соответствует английскому шаблону "Add new memo".
  • title.list → "Memoliste" — сложное существительное, типичное для немецких UI-соглашений.
  • memo и menu остаются непереведёнными — "Memo" и "Memos" являются международными терминами, используемыми как есть в немецком языке.
