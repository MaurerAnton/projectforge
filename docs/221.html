#221: build.gradle.kts

Merlin plugin build. This plugin wraps Micromata Merlin — Excel/DOCX templating engine. Dependencies: projectforge-wicket, projectforge-rest, plus Merlin libraries (de.micromata.merlin:merlin-excel, merlin-word) and com.lowagie:itext (OpenPDF) for font rendering in PDF exports. Also includes fr.opensagres.xdocreport for DOCX-to-PDF conversion.
