Archivo de localización en español vacío para el plugin Memo. Contiene solo el comentario de marcador de posición estándar # Vacío, es es el predeterminado.

Rol en la localización

Sigue la convención de ProjectForge: el archivo _es.properties está vacío y sirve únicamente como marcador de ruta de configuración regional. Las cadenas en español son proporcionadas por el paquete predeterminado MemoI18nResources.properties (ver #219). Cuando el ResourceBundle de Java resuelve la configuración regional es, este archivo vacío se encuentra primero; como no tiene claves, la resolución pasa al paquete base.

Patrón estándar: Todos los plugins de ProjectForge con solo configuraciones regionales inglés + español utilizan este mismo patrón de archivo vacío. Ver también #270 (SkillMatrix) para la misma convención.
