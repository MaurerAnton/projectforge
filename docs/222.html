#222: MerlinConditional.kt

Lines: 63 · Type: Kotlin DTO

DTO for Merlin template conditional expressions. Wraps de.micromata.merlin.word.AbstractConditional from the Merlin library — represents if/else-if/else blocks in DOCX templates. Fields: statement (conditional expression string), variable (associated variable name), childConditionals (recursive list of nested conditionals — e.g. else-if and else blocks under an if). Used by the REST layer to expose template structure to the React UI for preview.
