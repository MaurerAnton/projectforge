#223: MerlinExecutionData.kt

Lines: 32 · Type: Kotlin DTO

Execution result container. Holds the output of a Merlin template execution: debugInfos (list of strings — execution log entries), executedMillis (execution duration), templateDefinition (the template that was used), resultFile (the generated output file as File). Used by the REST layer to return execution results + optionally the generated file for download.
