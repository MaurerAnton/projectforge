#224: MerlinFontProvider.kt

Lines: 51 · Type: Kotlin @Component — implements IFontProvider

iText/OpenPDF font provider for DOCX-to-PDF conversion. Implements fr.opensagres.xdocreport.itext.extension.font.IFontProvider — the bridge between XDocReport (DOCX processing) and iText 2.x/OpenPDF (PDF generation). Delegates to MerlinFontService for BaseFont resolution. This is required because DOCX templates can use any system font; the PDF renderer needs explicit font registration. Uses FontFactory and com.lowagie.text.Font (the LGPL OpenPDF fork of iText).
