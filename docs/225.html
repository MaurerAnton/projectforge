#225: MerlinFontService.kt

Lines: 73 · Type: Kotlin @Service — font registry

Font registry for Merlin template rendering. 73 lines. Maintains a MutableMap<String, BaseFont> registry. On @PostConstruct, attempts to load fonts from the configured ConfigurationService directory — typically a path like /fonts/ on the server containing .ttf files. If the config path fails, falls back to scanning the system fonts directory (/usr/share/fonts/ on Linux, C:\Windows\Fonts\ on Windows). Each found font file is loaded via BaseFont.createFont() and registered under its canonical (lowercased, spaces-to-hyphens) name. The getFont(name) method handles null-safe lookup with name normalization.
