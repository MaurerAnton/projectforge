Clase base abstracta para todas las implementaciones de almacenamiento de importación. Gestiona la reconciliación de importaciones entre datos cargados y entidades de base de datos, mapeo/detección de columnas, ciclo de vida de pares de entrada con seguimiento de errores/advertencias y filtrado de visualización para interfaces de importación. Parametrizada por el tipo de entidad modificada O (que extiende ImportPairEntry.Modified<O>).

Arquitectura

Jerarquía de clases

ImportStorage<O : ImportPairEntry.Modified<O>> es la clase abstracta central en el subsistema de importación. Los importadores concretos extienden esta clase para definir cómo los datos cargados se asignan a las entidades de dominio. Opera junto con ImportSettings, ImportPairEntry, AbstractImportJob y AbstractImportPageRest.

Flujo de reconciliación

El mecanismo central de reconciliación sigue un patrón de método plantilla:

  1. reconcileImportStorage(rereadDatabaseEntries) — método final, establece hasBeenReconciled = true, llama al hook, marca todas las entradas como reconciliadas
  2. doReconcileImportStorage(rereadDatabaseEntries) — hook abierto protegido para implementación en subclases (sin operación por defecto)
  3. Después de la reconciliación, pairEntries muestra el estado por entrada: NUEVA, MODIFICADA, SIN CAMBIOS, IMPORTADA, ELIMINADA, ERRÓNEA

Seguridad en hilos

Las listas errors y warnings están protegidas por bloques synchronized. El acceso de lectura público devuelve copias defensivas. La lista pairEntries también se sincroniza durante la asignación de ID.

Exportación de información

ImportStorageInfo se genera sobre la marcha mediante la propiedad info, proporcionando una instantánea de conteos (nuevo, modificado, sin cambios, importado, eliminado, erróneo, desconocido) para la representación en la interfaz de usuario.
