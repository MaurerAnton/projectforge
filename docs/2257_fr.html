Classe de base abstraite pour toutes les implémentations de stockage d'import. Gère le rapprochement entre les données téléchargées et les entités de la base de données, la détection/mappage des colonnes, le cycle de vie des paires d'entrées avec suivi des erreurs/avertissements, et le filtrage d'affichage pour les interfaces d'import. Paramétrée par le type d'entité modifiée O (étendant ImportPairEntry.Modified<O>).

Architecture

Hiérarchie des classes

ImportStorage<O : ImportPairEntry.Modified<O>> est la classe abstraite centrale du sous-système d'import. Les importateurs concrets étendent cette classe pour définir comment les données téléchargées correspondent aux entités du domaine. Elle fonctionne aux côtés de ImportSettings, ImportPairEntry, AbstractImportJob et AbstractImportPageRest.

Flux de rapprochement

Le mécanisme de rapprochement central suit un modèle de méthode template :

  1. reconcileImportStorage(rereadDatabaseEntries) — méthode finale, définit hasBeenReconciled = true, appelle le hook, marque toutes les entrées comme rapprochées
  2. doReconcileImportStorage(rereadDatabaseEntries) — hook ouvert protégé pour l'implémentation des sous-classes (par défaut sans opération)
  3. Après le rapprochement, pairEntries affiche le statut par entrée : NOUVELLE, MODIFIÉE, NON MODIFIÉE, IMPORTÉE, SUPPRIMÉE, DÉFECTUEUSE

Sécurité des threads

Les listes errors et warnings sont protégées par des blocs synchronized. L'accès en lecture publique retourne des copies défensives. La liste pairEntries est également synchronisée lors de l'attribution des ID.

Export d'informations

ImportStorageInfo est généré à la volée via la propriété info, fournissant un instantané des compteurs (nouvelles, modifiées, non modifiées, importées, supprimées, défectueuses, inconnues) pour le rendu de l'interface utilisateur.
