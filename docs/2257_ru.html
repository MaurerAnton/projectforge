Абстрактный базовый класс для всех реализаций хранилищ импорта. Управляет сверкой импорта между загруженными данными и сущностями базы данных, сопоставлением/определением столбцов, жизненным циклом парных записей с отслеживанием ошибок/предупреждений, а также фильтрацией отображения для интерфейсов импорта. Параметризован типом изменяемой сущности O (расширяющим ImportPairEntry.Modified<O>).

Архитектура

Иерархия классов

ImportStorage<O : ImportPairEntry.Modified<O>> — основной абстрактный класс в подсистеме импорта. Конкретные импортёры расширяют его, чтобы определить, как загруженные данные сопоставляются с доменными сущностями. Он работает совместно с ImportSettings, ImportPairEntry, AbstractImportJob и AbstractImportPageRest.

Процесс сверки

Основной механизм сверки реализован по шаблонному методу:

  1. reconcileImportStorage(rereadDatabaseEntries) — финальный метод, устанавливает hasBeenReconciled = true, вызывает хук, помечает все записи как сверенные
  2. doReconcileImportStorage(rereadDatabaseEntries) — защищённый открытый хук для реализации в подклассах (по умолчанию ничего не делает)
  3. После сверки pairEntries показывают статус каждой записи: НОВАЯ, ИЗМЕНЁННАЯ, НЕИЗМЕНЁННАЯ, ИМПОРТИРОВАННАЯ, УДАЛЁННАЯ, ОШИБОЧНАЯ

Потокобезопасность

Списки errors и warnings защищены блоками synchronized. Публичное чтение возвращает защитные копии. Список pairEntries также синхронизируется при назначении ID.

Экспорт информации

ImportStorageInfo генерируется на лету через свойство info, предоставляя снимок количества (новые, изменённые, неизменённые, импортированные, удалённые, ошибочные, неизвестные) для отрисовки в интерфейсе.

Подклассы (в этой ветке)

  • BankingImportStorage — импорт банковских транзакций (плагин Banking)
  • AddressImportStorage — импорт адресов/контактов из CSV/Excel
  • EingangsrechnungImportStorage — импорт входящих счетов
  • ImportStorage в пакете rest/importer/
