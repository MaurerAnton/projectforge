#226: MerlinHandler.kt

Lines: 176 · Type: Kotlin @Service — orchestration layer

Coordinator between Merlin templates, JCR storage, and template checking. Autowires AttachmentsService (JCR), MerlinTemplateDefinitionHandler, and MerlinTemplateDao. Provides methods: uploadOrReplaceTemplate() (stores a .xlsx/.docx template as JCR attachment + parses its structure), checkTemplate() (runs Merlin's WordTemplateChecker to validate template syntax), deleteTemplate(), getTemplates() (list with statistics). The jcrPath and attachmentsAccessChecker fields are set by MerlinPagesRest at request time — not autowired — because the JCR path varies per plugin usage context.
