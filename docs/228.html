#228: MerlinRunner.kt

Lines: 548 · Type: Kotlin @Service — template execution engine

The execution engine — 548 lines, the biggest Merlin file. Runs Merlin templates against data and produces output files. Supports three template types:

1. Excel (.xlsx) templates: loads via ExcelWorkbook, injects variables from DataTransferBridge (address book data, timesheet data, fibu data) into named sheet/cell ranges, applies formatting, produces populated workbook. Uses MerlinCoreI18n for locale-aware date/number formatting.

2. Word (.docx) templates: loads via WordTemplate from Merlin, processes conditional blocks (if/else-if/else via MerlinConditional), loop blocks, and variable substitutions. Produces populated .docx.

3. DOCX → PDF conversion: after Word template execution, optionally converts the .docx to .pdf using PdfConverter + PdfOptions + MerlinFontService for font embedding. This is critical for IHK reports and certificates that need to be submitted as PDF.

ZIP mode: if the template produces multiple files (e.g. one Excel file per address in a campaign), MerlinRunner packages all outputs into a ZipOutputStream with proper ZipEntry names.

Variable injection: the runner uses DataTransferBridge to pull live data into template variables — e.g. {{customer.name}} maps to the current address's organization, {{employee.salary}} maps to the employee's current salary from fibu. The replace() utility from Merlin handles recursive variable resolution.

Statistics: every execution produces a MerlinStatistics object with file count, execution time, sheet/row counts, and error log — returned to the caller for display in the UI or stored via the job system.
