Path: ./doc/misc/nginx_sites-available_projectforge · Type: nginx site configuration · Lines: 42 · Source: GitHub

What it does

A production-grade nginx reverse-proxy configuration for ProjectForge. Handles HTTP→HTTPS redirect and TLS termination with hardened SSL settings (Mozilla Intermediate compatibility). This is a more complete version of the compose nginx.conf (#13) — adds OCSP stapling, HSTS (commented out), security headers, and basic auth support. Designed for bare-metal deployment (unlike the compose version).

Section-by-section

Lines 1–4: HTTP → HTTPS redirect

1  server {
2    listen 80;
3    listen [::]:80;                               ← IPv6
4    server_name projectforge.example.com;
5    location / { return 301 https://$host$request_uri; }
6  }

Standard permanent redirect (301) for all HTTP traffic → HTTPS. Includes IPv6 binding ([::]:80). The hostname projectforge.example.com is a placeholder — real deployments replace this with the actual FQDN.

Lines 8–32: HTTPS server with hardened SSL

8  server {
9    listen              443 ssl;
10   listen              [::]:443 ssl;
11   server_name         projectforge.example.com;
12   ssl_certificate     /etc/ssl/projectforge.crt;
13   ssl_certificate_key /etc/ssl/projectforge.key;
15   ssl_protocols TLSv1.2;                        ← TLS 1.2 only (no 1.0/1.1)
16   ssl_prefer_server_ciphers on;
17   ssl_dhparam /etc/nginx/dhparam.pem;           ← custom DH params
18   ssl_ciphers EECDH+AESGCM:EDH+AESGCM;          ← only AEAD ciphers
19   ssl_ecdh_curve secp384r1;
20   ssl_session_timeout  10m;
21   ssl_session_cache shared:SSL:10m;
22   ssl_session_tickets off;                      ← disable session tickets (PFS)
23   ssl_stapling on;                              ← OCSP stapling
24   ssl_stapling_verify on;
25   add_header X-Frame-Options DENY;              ← prevent clickjacking
26   add_header X-Content-Type-Options nosniff;    ← prevent MIME sniffing
27   add_header X-XSS-Protection "1; mode=block";  ← XSS filter

SSL/TLS settings follow Mozilla's Intermediate compatibility recommendations. Key security decisions:

DirectiveValueWhy
ssl_protocolsTLSv1.2Disables TLS 1.0/1.1 (vulnerable to BEAST/POODLE)
ssl_ciphersEECDH+AESGCM:EDH+AESGCMOnly AEAD ciphers — forward secrecy + authenticated encryption
ssl_session_ticketsoffDisables session tickets for perfect forward secrecy
ssl_staplingonOCSP stapling — reduces latency, improves privacy

Lines 33–43: Proxy configuration

33 location / {
34   proxy_set_header        Host $host;
35   proxy_set_header        X-Real-IP $remote_addr;
36   proxy_set_header        X-Forwarded-For $proxy_add_x_forwarded_for;
37   proxy_set_header        X-Forwarded-Proto $scheme;
39   proxy_pass              http://localhost:8080;  ← upstream (ProjectForge)
40   proxy_read_timeout      90;
41   proxy_redirect          http://localhost:8080 https://projectforge.example.com;
43   # auth_basic            "Username and Password Required";
44   # auth_basic_user_file  /etc/nginx/.htpasswd;
45 }

Reverse proxy to ProjectForge running on localhost:8080. proxy_redirect rewrites HTTP Location headers from the upstream (http://localhost:8080) to the public HTTPS URL — critical for redirect-after-login flows. Basic auth (lines 43–44) is commented out — uncomment to add an nginx-level authentication layer before traffic reaches ProjectForge.

Key takeaways

  • Production-grade TLS: OCSP stapling, session tickets disabled, custom DH parameters — ready for security audits.
  • Mozilla Intermediate baseline: Follows well-established server TLS recommendations.
  • IPv6 dual-stack: Binds on both IPv4 and IPv6.
  • HSTS commented out: Line 29 has HSTS preloaded — intentionally disabled until DNS/SSL are proven stable.
  • More complete than compose version: The Docker compose nginx.conf (#13) is a minimal proxy; this is a full production config.
