#230: MerlinTemplateDao.kt

Lines: 97 · Type: Kotlin @Service DAO

DAO for Merlin template metadata. Extends BaseDao<MerlinTemplateDO>. Unlike most plugin entities (which store data in database tables), Merlin templates store the actual .xlsx/.docx files in JCR — this DAO manages only the metadata (template name, description, type, creation date, file size, last used date) in the database table T_PLUGIN_MERLIN_TEMPLATE. The binary template files themselves are managed by MerlinHandler via AttachmentsService. Custom queries: getTemplatesByType(type) (Excel vs Word) and getRecentlyUsed(limit) for the template picker UI.
