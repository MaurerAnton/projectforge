#231: MerlinTemplateDefinitionHandler.kt

Lines: 167 · Type: Kotlin @Service

Parses and manages Merlin template definitions. 167 lines. When a .docx template is uploaded, this handler extracts its structure using Merlin's TemplateDefinition parser: identifies variables ({{name}}), loops ({{#foreach}}), conditionals ({{#if}}), and images. For .xlsx templates, it uses ExcelWorkbook to enumerate sheets and named ranges.

Key methods: getTemplateDefinition(attachment) — reads the uploaded .docx/.xlsx from JCR AttachmentsService, passes it through Merlin's TemplateDefinition.parse(), and returns a structured MerlinTemplate DTO with variable definitions. saveDefinition() persists variable metadata back to the database. Handles circular reference between MerlinHandler (via autowired merlinHandler field) — used to access template DAO for cache invalidation.
