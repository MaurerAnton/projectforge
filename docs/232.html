#232: MerlinTemplateDO.kt

Lines: 144 · Type: Kotlin JPA @Entity — AbstractBaseDO<Long> subclass

Database entity for Merlin template metadata. Maps to t_plugin_merlin_template. Extends AbstractBaseDO<Long> (no history, no soft delete — like MemoDO). Implements AttachmentsInfo — the entity carries JCR attachment metadata (attachmentsCounter, attachmentsIds, attachmentsNames, attachmentsSize) rather than the entity itself being a JCR node.

Fields: name, description, fileNamePattern (output filename with placeholders like ${name}_${date}), stronglyRestrictedFilenames (security flag — sanitizes output filenames), pdfExport (whether to also generate PDF from DOCX), dataTransferUsage (whether used in DataTransfer plugin for automated mail merge), adminIds / accessGroupIds / accessUserIds (comma-separated IDs for access control), lastVariableUpdate (timestamp of last variable definition change). The actual template binary lives in JCR, not in this entity.
