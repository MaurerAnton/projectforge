#234: MerlinVariableBase.kt

Abstract base for Merlin template variables. Defines common variable properties: name (the {{name}} in templates), description, type (String, Number, Date, Boolean), required flag, defaultValue, i18nKey. Both MerlinVariable (REST DTO) and MerlinVariableDefinition (Merlin-native) extend this.
