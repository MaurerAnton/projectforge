#235: MerlinVariable.kt

Concrete variable DTO. Extends MerlinVariableBase. Adds: id (database identifier for persistence), templateId (FK to MerlinTemplateDO), sortOrder (display order in variable config UI), dataTransferMapping (maps template variable to DataTransferBridge data source — e.g. address.organization), mapped (whether this variable has been mapped to a data source), formula (optional Groovy expression for computed values). Persisted as a separate entity, referenced by MerlinTemplate.currentVariable for the variable config UI.
