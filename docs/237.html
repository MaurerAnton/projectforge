#237: MerlinExecutionPageRest.kt

REST controller for template execution UI at ${Rest.URL}/merlinExecution. Extends AbstractDOPagesRest<MerlinExecutionDO, MerlinExecutionDao>. Provides the execution history list (past runs with template name, result, statistics, timestamp) and the execution trigger UI. Users select a template, fill in variables, and click "Execute" — the REST endpoint calls MerlinRunner and returns the generated file(s) for download.
