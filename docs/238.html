#238: MerlinPagesRest.kt

REST controller for template management at ${Rest.URL}/merlin. Extends AbstractDOPagesRest<MerlinTemplateDO, MerlinTemplateDao>. List columns: name, description, type (Excel/Word). Edit form: name, description, fileNamePattern, pdfExport toggle, dataTransferUsage toggle, stronglyRestrictedFilenames toggle. Includes JCR attachment upload/download/delete endpoints for template files. Sets up JCR path and access checker on MerlinHandler at request time.
