#239: MerlinTestServicesRest.kt

REST controller for testing/debugging at ${Rest.URL}/merlinTest. Provides endpoints for: checking Merlin installation, listing available fonts (from MerlinFontService), testing a template with mock data, and validating template syntax. Only accessible in development mode or to admin users. Used during plugin development and template authoring.
