#240: MerlinVariablePageRest.kt

REST controller for variable configuration at ${Rest.URL}/merlinVariable. Manages MerlinVariable list/edit for a selected template. Provides a data transfer mapping UI: each template variable can be mapped to a DataTransferBridge source (address fields, fibu fields, timesheet fields) or defined as a constant/calculated formula. The UI shows the template's variable structure with current mappings highlighted.
