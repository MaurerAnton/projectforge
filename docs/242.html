#242: LetterTemplate.docx

Resource / Template, plugins/org.projectforge.plugins.merlin/src/main/resources/examples/LetterTemplate.docx

Binary Microsoft Word document serving as an example letter template for the Merlin plugin. Demonstrates document template functionality — users can upload custom templates and merge them with system data via variable placeholders.

Architecture

Stored in src/main/resources/examples/ as a reference for users. Templates support variable substitution — see variables and dependent_variables columns added in V1.0.2 migration (#245).
