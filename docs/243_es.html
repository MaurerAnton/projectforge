Archivo de recursos i18n base (fallback) para el plugin de plantillas Word de Merlin. Contiene traducciones predeterminadas en inglés para todas las cadenas de la interfaz de Merlin: gestión de plantillas, tipos de variables, flujos de trabajo de ejecución en serie, control de acceso y reglas de validación.

Arquitectura

Este es el archivo de recursos i18n base para el plugin Merlin: el fallback utilizado cuando no se encuentra una traducción específica de locale (_de, _ru, etc.). Define más de 80 claves para la interfaz completa de Merlin: listado de plantillas, edición, configuración de variables (tipos STRING/INT/FLOAT/DATE), relaciones de variables maestro-dependientes, ejecución en serie con carga de Excel, integración de bandeja personal a través del plugin DataTransfer y salida Word/PDF. Convertido de ISO-8859-1 a codificación UTF-8 en el commit 6fd4462f8. Revisado y refinado en el commit 7cedb5bc8.
