Fichier de ressources I18n de base (de secours) pour le plugin Merlin Word-template. Contient les traductions anglaises par défaut pour toutes les chaînes de l'interface Merlin : gestion des modèles, types de variables, workflows d'exécution en série, contrôle d'accès et règles de validation.

Architecture

Il s'agit du fichier de ressources I18n de base pour le plugin Merlin — le fichier de secours utilisé lorsqu'aucune traduction spécifique à une locale (_de, _ru, etc.) n'est trouvée. Il définit plus de 80 clés pour l'interface complète de Merlin : liste des modèles, édition, configuration des variables (types STRING/INT/FLOAT/DATE), relations maître-dépendant entre variables, exécution en série avec import Excel, intégration de la boîte personnelle via le plugin DataTransfer, et sortie Word/PDF. Converti de l'encodage ISO-8859-1 vers UTF-8 dans le commit 6fd4462f8. Relu et affiné dans le commit 7cedb5bc8.
