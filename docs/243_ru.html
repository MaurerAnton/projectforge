Базовый (резервный) файл ресурсов i18n для плагина Merlin Word-template. Содержит английские переводы по умолчанию для всех строк интерфейса Merlin: управление шаблонами, типы переменных, последовательное выполнение рабочих процессов, контроль доступа и правила валидации.

Архитектура

Это базовый файл ресурсов i18n для плагина Merlin — резервный, используемый, когда не найдена локаль-специфичная (_de, _ru и т.д.) локализация. Он определяет более 80 ключей для полного интерфейса Merlin: список шаблонов, редактирование, настройка переменных (типы STRING/INT/FLOAT/DATE), связи главных и зависимых переменных, последовательное выполнение с загрузкой Excel, интеграция с личным боксом через плагин DataTransfer и вывод Word/PDF. Конвертирован из ISO-8859-1 в кодировку UTF-8 в коммите 6fd4462f8. Вычитан и доработан в коммите 7cedb5bc8.
