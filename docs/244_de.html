Deutsche (de) i18n-Übersetzungsdatei für das Merlin-Word-Vorlagen-Plugin. Enthält deutsche Übersetzungen für alle Merlin-UI-Zeichenfolgen: Vorlagenverwaltung, Variablenkonfiguration, serielle Ausführung, Zugriffskontrolle und Validierungsmeldungen.

Architektur

Diese Datei stellt die deutschen Gebietsschema-Übersetzungen für das Merlin-Plugin bereit. Jeder Schlüssel entspricht einer Wicket-Komponentenbeschriftung, einem Tooltip oder einer Validierungsmeldung, die in der Merlin-Benutzeroberfläche angezeigt wird. Die Datei enthält über 80 Übersetzungseinträge, die die Vorlagenverwaltung, Variablentypen (STRING, INT, FLOAT, DATE), Abhängigkeitskonfiguration, serielle Ausführung, persönliche Box-Zustellung und Upload-Validierung abdecken. Die Kodierung wurde im Commit 6fd4462f8 von ISO-8859-1 auf UTF-8 (Java 9+) umgestellt.
