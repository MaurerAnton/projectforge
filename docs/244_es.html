Archivo de traducción i18n al alemán (de) para el plugin Merlin Word-template. Contiene traducciones al alemán para todas las cadenas de la interfaz de Merlin: gestión de plantillas, configuración de variables, ejecución en serie, control de acceso y mensajes de validación.

Arquitectura

Este archivo proporciona las traducciones al locale alemán para el plugin Merlin. Cada clave corresponde a una etiqueta de componente Wicket, tooltip o mensaje de validación mostrado en la interfaz de Merlin. El archivo contiene más de 80 entradas de traducción que cubren administración de plantillas, tipos de variables (STRING, INT, FLOAT, DATE), configuración de dependencias, ejecución en serie, entrega en bandeja personal y validación de carga. La codificación se cambió de ISO-8859-1 a UTF-8 (Java 9+) en el commit 6fd4462f8.
