Fichier de traduction i18n allemand (de) pour le plugin Merlin Word-template. Contient les traductions allemandes pour toutes les chaînes de l'interface utilisateur Merlin : gestion des modèles, configuration des variables, exécution en série, contrôle d'accès et messages de validation.

Architecture

Ce fichier fournit les traductions pour la locale allemande du plugin Merlin. Chaque clé correspond à un libellé de composant Wicket, une info-bulle ou un message de validation affiché dans l'interface utilisateur Merlin. Le fichier contient plus de 80 entrées de traduction couvrant l'administration des modèles, les types de variables (STRING, INT, FLOAT, DATE), la configuration des dépendances, l'exécution en série, la livraison en boîte personnelle et la validation des téléchargements. L'encodage est passé de l'ISO-8859-1 à l'UTF-8 (Java 9+) dans le commit 6fd4462f8.
