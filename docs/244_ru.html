Немецкий (de) файл перевода i18n для плагина Merlin Word-template. Содержит немецкие переводы для всех строк интерфейса Merlin: управление шаблонами, настройка переменных, последовательное выполнение, контроль доступа и сообщения валидации.

Архитектура

Этот файл предоставляет переводы для немецкой локали плагина Merlin. Каждый ключ соответствует метке компонента Wicket, подсказке или сообщению валидации, отображаемому в интерфейсе Merlin. Файл содержит более 80 записей перевода, охватывающих администрирование шаблонов, типы переменных (STRING, INT, FLOAT, DATE), настройку зависимостей, последовательное выполнение, доставку в личный ящик и валидацию загрузки. Кодировка была изменена с ISO-8859-1 на UTF-8 (Java 9+) в коммите 6fd4462f8.
