Archivo de recursos i18n en español para el plugin Merlin. Vacío porque el español no es el locale predeterminado; todas las claves recurren a las anotaciones en el código fuente del plugin.

Arquitectura

Este es el paquete de recursos para el locale en español del plugin Merlin. Al igual que otros paquetes _es, está intencionadamente vacío. El framework resuelve las claves i18n en español mediante las anotaciones @I18n definidas directamente en el código fuente Kotlin/Java del plugin, recurriendo al archivo base MerlinI18nResources.properties y finalmente a los valores predeterminados de las anotaciones.
