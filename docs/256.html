#256: SkillEntryDao.kt

Lines: 88 · Type: Kotlin DAO

DAO for skill entries. Extends BaseDao<SkillEntryDO>. Provides getSkillsOfUser(userId) via named query FIND_OF_OWNER. Overrides getList() to filter by owner + search text on skill name/description. The DAO is also used by the privacy cleanup job which calls DELETE_ALL_OF_USER when an employee's data must be removed for GDPR compliance.
