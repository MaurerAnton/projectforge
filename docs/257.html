#257: SkillEntryDO.kt

Lines: 127 · Type: Kotlin JPA @Entity — AbstractBaseDO<Long>

Employee skill record. Maps to T_PLUGIN_SKILLMATRIX_ENTRY. Index on owner_fk. Fields: owner (@ManyToOne → PFUserDO, JSON serialized as ID only), skillName (full-text indexed — the skill/competency name, e.g. "Java", "Project Management"), rating (Integer — skill level 1-5), experience (years of experience), description (text), lastUsed (LocalDate — when skill was last applied), certificate (Boolean — whether the skill is certified), sinceYear (Integer — since when the skill is held).

Named queries: FIND_OF_OWNER (load skills for a user with deleted=false filter), DELETE_ALL_OF_USER (bulk delete for privacy cleanup — removes all skills when a user's data is purged for GDPR). Uses AbstractBaseDO — no history tracking on skills.
