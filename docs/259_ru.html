Проектные решения

  • Расширяет BaseDao от ProjectForge для типизированных CRUD-операций, полнотекстовых запросов Hibernate Search и управления транзакциями.
  • Использует DSL Hibernate Search с путями полей, специфичными для сущности, для оптимизированной по производительности фильтрации.

Ошибки и подводные камни

  • Лениво загружаемые коллекции выбрасывают LazyInitializationException вне активных сессий Hibernate. Используйте @Transactional или Hibernate.initialize().
