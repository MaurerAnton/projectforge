#25: nginx_sites-available_projectforge

doc/misc/nginx_sites-available_projectforge Referencia de configuración, doc/misc/nginx_sites-available_projectforge 45 líneas · 36 código · 3 comentarios · 6 en blanco
Plantilla de configuración de proxy inverso Nginx para ProjectForge. Maneja redirección HTTP→HTTPS, TLS 1.2, cabeceras de seguridad (X-Frame-Options, X-Content-Type-Options, X-XSS-Protection) y proxy hacia localhost:8080.

Detalles de configuración de Nginx

Bloques de servidor

  1. HTTP (puerto 80): Redirige todo el tráfico a HTTPS
  2. HTTPS (puerto 443): TLS 1.2, cabeceras de seguridad, proxy hacia localhost:8080

Cabeceras de seguridad

CabeceraValor
X-Frame-OptionsDENY
X-Content-Type-Optionsnosniff
X-XSS-Protection1; mode=block

Configuración SSL

  • Solo TLS 1.2
  • Cifrados EECDH+AESGCM
  • Curva secp384r1
  • OCSP stapling habilitado
  • Parámetros DH desde /etc/nginx/dhparam.pem
