#25 : nginx_sites-available_projectforge

doc/misc/nginx_sites-available_projectforge Référence de configuration, doc/misc/nginx_sites-available_projectforge 45 lignes · 36 code · 3 commentaires · 6 vides
Modèle de configuration de proxy inverse Nginx pour ProjectForge. Gère la redirection HTTP→HTTPS, TLS 1.2, les en-têtes de sécurité (X-Frame-Options, X-Content-Type-Options, X-XSS-Protection) et le proxy vers localhost:8080.

Détails de la configuration Nginx

Blocs de serveur

  1. HTTP (port 80) : Redirige tout le trafic vers HTTPS
  2. HTTPS (port 443) : TLS 1.2, en-têtes de sécurité, proxy vers localhost:8080

En-têtes de sécurité

En-têteValeur
X-Frame-OptionsDENY
X-Content-Type-Optionsnosniff
X-XSS-Protection1; mode=block

Configuration SSL

  • TLS 1.2 uniquement
  • Chiffrements EECDH+AESGCM
  • Courbe secp384r1
  • OCSP stapling activé
  • Paramètres DH depuis /etc/nginx/dhparam.pem
