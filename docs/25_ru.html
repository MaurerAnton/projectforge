#25: nginx_sites-available_projectforge

doc/misc/nginx_sites-available_projectforge Справочник конфигурации, doc/misc/nginx_sites-available_projectforge 45 строк · 36 кода · 3 комментария · 6 пустых
Шаблон конфигурации обратного прокси-сервера Nginx для ProjectForge. Обрабатывает перенаправление HTTP→HTTPS, TLS 1.2, заголовки безопасности (X-Frame-Options, X-Content-Type-Options, X-XSS-Protection) и проксирует на `localhost:8080`.

Детали конфигурации Nginx

Блоки сервера

  1. HTTP (порт 80): Перенаправляет весь трафик на HTTPS
  2. HTTPS (порт 443): TLS 1.2, заголовки безопасности, проксирует на localhost:8080

Заголовки безопасности

ЗаголовокЗначение
X-Frame-OptionsDENY
X-Content-Type-Optionsnosniff
X-XSS-Protection1; mode=block

Конфигурация SSL

  • Только TLS 1.2
  • Шифры EECDH+AESGCM
  • Кривая secp384r1
  • OCSP stapling включён
  • Параметры DH из /etc/nginx/dhparam.pem
