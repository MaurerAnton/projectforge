#2615: Dropdown.jsx

projectforge-webapp/src/components/base/navigation/Dropdown.jsx Composant React JSX (Dropdown de navigation), projectforge-webapp/src/components/base/navigation/Dropdown.jsx 67 lignes · 62 code · 0 commentaires · 5 vides
Wrapper de navigation UncontrolledDropdown Bootstrap. Le bouton bascule affiche le texte du titre (ou l'icône d'engrenage pour l'ID GEAR) avec un badge optionnel + chevron. Le menu déroulant rend NavigationAction pour chaque entrée subMenu à l'intérieur de DropdownItem. Prend en charge la propriété right pour les menus alignés à droite (mon compte, etc.). Le badge a isFlying=false dans le contexte du dropdown. Importations : FontAwesome, PropTypes, UncontrolledDropdown/DropdownItem/DropdownMenu/DropdownToggle depuis design, NavigationAction, MenuBadge.
