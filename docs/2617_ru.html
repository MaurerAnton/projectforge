#2617: GlobalNavigation.jsx

projectforge-webapp/src/components/base/navigation/GlobalNavigation.jsx React JSX компонент (глобальная верхняя навигация), projectforge-webapp/src/components/base/navigation/GlobalNavigation.jsx 61 строка · 54 кода · 0 комментариев · 7 пустых
Адаптивная навигационная панель верхнего уровня. Использует хранилище Redux (state.menu): mainMenu, favoritesMenu, myAccountMenu, badge. При монтировании через useEffect отправляет loadMenu(). Мобильная версия: переключение через NavbarToggler + Bootstrap Collapse. Отображает три секции: CategoriesDropdown (категории главного меню с выпадающим списком), Navigation (панель избранного, выравнивание me-auto), Navigation (мой аккаунт, выравнивание вправо ml-auto text-nowrap). Каждая секция отображается только при наличии данных. Стилизация через Navigation.module.scss. Импорты: useSelector/useDispatch из react-redux, Collapse/Navbar/NavbarToggler из дизайна, CategoriesDropdown, Navigation, SCSS-модуль.
