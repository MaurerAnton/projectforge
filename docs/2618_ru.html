SCSS-стили для глобальной системы навигации. Ключевые классы: .globalNavigation — основа навбара (шрифт 1.1em, отступы). .categoryContainer — отступы блока категорий. .categoryTitle — заглавные, насыщенность 900, межбуквенный интервал, тёмно-синий #031b4e. .categoryLinks — ненумерованный список с левым отступом, ссылки 14px (#5b6987 → #1a293b при наведении). .categories — flex-колонка → строка на среднем брейкпоинте; .categoryColumn flex:1. .categoryListDropdownMenu — скрыт по умолчанию (visibility:hidden, width:1px), расширяется до 730px/980px при открытии с белым фоном, рамкой, z-index 9999. span.badge — счётчики-пилюли (#dc3545 опасный, радиус 1em, летающий вариант с scale(0.75) + абсолютное позиционирование). Импортирует примеси для медиа-запросов и трансформаций.
