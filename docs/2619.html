Single category column in the categories dropdown mega-menu. Collapsible on mobile (<735px threshold), always expanded on desktop. Listens to window resize via useEffect with add/removeEventListener. Desktop: clicking the title button is a no-op (returns early). Mobile: toggles reactstrap Collapse. Renders category title button with optional MenuBadge + subMenu list of react-router Link items (each with optional badge). closeMenu callback invoked on link click (for mobile UX). Imports: classnames, PropTypes, react-router Link, reactstrap Collapse, SCSS module, MenuBadge.
