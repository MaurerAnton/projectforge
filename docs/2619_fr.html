Colonne de catégorie unique dans le méga-menu déroulant des catégories. Repliable sur mobile (seuil <735px), toujours déployé sur bureau. Écoute le redimensionnement de la fenêtre via useEffect avec add/removeEventListener. Sur bureau : cliquer sur le bouton titre est sans effet (retour anticipé). Sur mobile : bascule le reactstrap Collapse. Affiche le bouton titre de la catégorie avec MenuBadge optionnel + liste de sous-menus d'éléments react-router Link (chacun avec badge optionnel). Le rappel closeMenu est invoqué lors du clic sur un lien (pour l'UX mobile). Importations : classnames, PropTypes, react-router Link, reactstrap Collapse, module SCSS, MenuBadge.
