#2619: Category.jsx

projectforge-webapp/src/components/base/navigation/categories-dropdown/Category.jsx React JSX компонент (колонка категорий), projectforge-webapp/src/components/base/navigation/categories-dropdown/Category.jsx 106 строк · 94 кода · 0 комментариев · 12 пустых
Одиночная колонка категорий в мега-меню выпадающего списка категорий. Сворачивается на мобильных устройствах (порог <735px), на десктопе всегда развёрнута. Слушает изменение размера окна через useEffect с add/removeEventListener. На десктопе: нажатие на кнопку заголовка не выполняет никаких действий (ранний возврат). На мобильных: переключает reactstrap Collapse. Отображает кнопку заголовка категории с опциональным MenuBadge + список подменю из элементов react-router Link (каждый с опциональным значком). Колбэк closeMenu вызывается при клике по ссылке (для мобильного UX). Импорты: classnames, PropTypes, react-router Link, reactstrap Collapse, SCSS модуль, MenuBadge.
