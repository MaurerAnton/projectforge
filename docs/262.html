#262: SkillMatrixServicesRest.kt

REST controller for extra skill matrix services. Provides endpoints: statistics (total skills, top skills, skills per department, skill gaps), matrix view data (cross-tab: employees × skills with ratings), and export to Excel. Separate from SkillEntryPagesRest (CRUD) — this is the analytics/reporting layer.
