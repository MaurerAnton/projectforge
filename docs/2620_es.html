Componente de insignia reutilizable para contadores de menú de navegación (tareas pendientes, notificaciones no leídas, etc.). Renderiza una píldora coloreada <span> con clases CSS de Navigation.module.scss: .badge (estilo base de píldora), .isFlying (variante animada con posicionamiento absoluto y transformación de escala), clase de color (ej. .danger para rojo). ID DOM único mediante elementKey (menu-badge-{elementKey}) habilita UncontrolledTooltip opcional al pasar el ratón. Children acepta cadena o número. Props: elementKey (obligatorio), color (danger por defecto), isFlying (booleano), tooltip (cadena). Importaciones: classnames, PropTypes, colorPropType, UncontrolledTooltip de design, módulo SCSS.
