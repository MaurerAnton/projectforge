#2620: MenuBadge.jsx

projectforge-webapp/src/components/base/navigation/categories-dropdown/MenuBadge.jsx React JSX компонент (счётчик-значок меню), projectforge-webapp/src/components/base/navigation/categories-dropdown/MenuBadge.jsx 51 строка · 47 кода · 0 комментариев · 4 пустых
Многоразовый компонент-значок для счётчиков навигационного меню (ожидающие задачи, непрочитанные уведомления и т.д.). Отображает цветную пилюлю <span> с CSS-классами из Navigation.module.scss: .badge (базовый стиль пилюли), .isFlying (абсолютно позиционированный анимированный вариант с масштабным преобразованием), цветовой класс (например, .danger для красного). Уникальный DOM-идентификатор через elementKey (menu-badge-{elementKey}) обеспечивает опциональный UncontrolledTooltip при наведении. Дочерние элементы принимают строку или число. Свойства: elementKey (обязательный), color (по умолчанию danger), isFlying (логический), tooltip (строка). Импорты: classnames, PropTypes, colorPropType, UncontrolledTooltip из design, SCSS-модуль.
