Barre de sous-navigation au niveau de la page — distincte de la GlobalNavigation globale. Affiche une Navbar Bootstrap montrant le titre de la page current comme NavItem plus les enfants (généralement des liens d'onglets/boutons d'action). Adaptative mobile avec NavbarToggler + Collapse. Utilisée dans les composants de mise en page de page pour fournir une navigation par section. Stylisée via Page.module.scss. Importations : PropTypes, Collapse/Nav/Navbar/NavbarToggler/NavItem de reactstrap depuis design, module SCSS.
