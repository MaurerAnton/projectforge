#2623: Navigation.jsx

projectforge-webapp/src/components/base/page/Navigation.jsx React JSX компонент (поднавигация страницы), projectforge-webapp/src/components/base/page/Navigation.jsx 33 строки · 28 кода · 0 комментариев · 5 пустых
Панель поднавигации на уровне страницы — отличается от глобальной GlobalNavigation. Отображает Bootstrap Navbar, показывающий заголовок текущей страницы как NavItem плюс дочерние элементы (обычно вкладки/кнопки действий). Адаптивна для мобильных устройств с помощью NavbarToggler + Collapse. Используется внутри компонентов макета страницы для обеспечения навигации по разделам. Стилизована через Page.module.scss. Импортирует: PropTypes, reactstrap Collapse/Nav/Navbar/NavbarToggler/NavItem из дизайна, SCSS модуль.
