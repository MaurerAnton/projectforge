#2625: TabNavigation.jsx

projectforge-webapp/src/components/base/page/edit/TabNavigation.jsx React JSX компонент (навигация по вкладкам), projectforge-webapp/src/components/base/page/edit/TabNavigation.jsx 48 строк · 42 кода · 1 комментарий · 5 пустых
Навигация по вкладкам для страниц редактирования (несколько форм-вкладок). Рендерит Nav tabs с NavItem/NavLink для каждой вкладки. Активная вкладка выделяется через CSS-класс style.active. Использует React Router navigate(tabLink, { state: location.state }) для сохранения состояния маршрута — включая модальный background — при переключении между вкладками. Принимает массив tabs из {id, title, link} и строку идентификатора activeTab. Импорты: classnames, PropTypes, react-router (useNavigate/useLocation), Nav/NavItem/NavLink из design, Page.module.scss.
