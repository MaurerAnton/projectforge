#263: SkillRightId.kt

Enum / User Right, plugins/org.projectforge.plugins.skillmatrix/src/main/kotlin/org/projectforge/plugins/skillmatrix/SkillRightId.kt

Defines PLUGIN_SKILL_MATRIX user right. Unlike other rights, this right is not configurable per user (orderString and i18nKey are null) — it only controls whether the skill matrix plugin is accessible.

Architecture

Hibernate Search-indexed enum with @TypeBinding(HibernateSearchUserRightIdTypeBinder). Non-configurable rights with null metadata are used for plugin-level access gating rather than fine-grained per-user permission controls.
