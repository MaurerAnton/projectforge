Componente de entrada de rango de fecha/hora para la interfaz de calendario. Renderiza campos `DateTimeInput` emparejados para fechas 'desde' y 'hasta' con entradas de hora opcionales, botones de limpieza (icono de tiempos de FontAwesome) y alternancias para ocultar el selector de día o la entrada de hora. Soporta la prop label, id para accesibilidad y validación completa de PropTypes para todas las propiedades de fecha/hora.
