Décisions de conception

  • Cache en mémoire conservant les données fréquemment consultées. Invalidé lors des modifications de données pertinentes. Thread-safe pour les lectures concurrentes.
  • Calcule des statistiques agrégées à partir des données du domaine. Peut utiliser les projections Hibernate Search ou du SQL direct pour les performances.

Pièges et écueils

  • Le timing d'invalidation du cache est critique pour la cohérence. Les conditions de concurrence entre les rédacteurs et l'éviction du cache peuvent servir des données obsolètes.
