Module CSS pour le conteneur principal de l'application ProjectForge. Stylise la disposition du contenu à onglets avec la classe `.tabContent` définissant un fond blanc, un remplissage, un style de bordure Bootstrap et une suppression de la bordure supérieure pour des transitions fluides entre onglets et contenu. Fait partie de l'interface de navigation par onglets principale.
