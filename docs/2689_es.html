Componente de redirección React que enruta a los usuarios desde la nueva interfaz React a páginas heredadas de Wicket cuando las funcionalidades aún no han sido migradas.

Estructura del código

Hooks utilizados: Location, Effect

Importaciones desde: ../utilities/rest, react-router

Código fuente (resumido)

import React, { useEffect } from 'react';
import { useLocation } from 'react-router';
import { getServiceURL } from '../utilities/rest';

function RedirectToWicket() {
    const location = useLocation();

    useEffect(() => {
        if (!import.meta.env.DEV) {
            window.location.reload();
        }
    }, []);

    return (
        <a href={getServiceURL(`..${location.pathname}`)}>Redirigir a Wicket</a>
    );
}

export default RedirectToWicket;
