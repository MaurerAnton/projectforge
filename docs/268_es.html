Categorías de claves

  • Escalas de valoración: interest.0-3 y rating.0-3 definen escalas de 4 niveles para interés y autoevaluación. La escala de interés utiliza etiquetas lúdicas ("¡Apasionado!") mientras que la escala de valoración utiliza etiquetas profesionales ("Básico", "Avanzado", "Experto").
  • Filtro: filter.mySkills permite un interruptor para mostrar solo las habilidades del usuario conectado.
  • Títulos: title.add, title.edit, title.list siguen la convención de nomenclatura estándar de ProjectForge para títulos de páginas CRUD.
  • Validación: error.doublet evita crear habilidades con nombres duplicados utilizando el parámetro {0} de MessageFormat.
Resolución de configuración regional: La configuración regional alemana carga SkillMatrixI18nResources_de.properties; todas las demás recurren a este archivo. El archivo _en.properties está vacío (ver #270).
