Пакет интернационализации по умолчанию для плагина SkillMatrix. Содержит 18 английских ключей для интерфейса матрицы навыков — инструмента для отслеживания навыков сотрудников, самооценок и уровней заинтересованности.

Категории ключей

  • Шкалы оценок: interest.0-3 и rating.0-3 определяют 4-уровневые шкалы для интереса и самооценки. Шкала интереса использует игривые метки («Без ума!»), в то время как шкала оценки использует профессиональные метки («Базовый», «Продвинутый», «Эксперт»).
  • Фильтр: filter.mySkills позволяет переключать отображение только навыков текущего пользователя.
  • Заголовки: title.add, title.edit, title.list следуют стандартному соглашению об именовании заголовков страниц CRUD в ProjectForge.
  • Проверка: error.doublet предотвращает создание навыков с дублирующимися именами с использованием параметра MessageFormat {0}.
Определение локали: Немецкая локаль загружает SkillMatrixI18nResources_de.properties; все остальные используют этот файл как резервный. Файл _en.properties пуст (см. #270).
