Notable Translations

  • interest.3 ("Going crazy!") is left untranslated — the English idiom is kept as-is in the German locale.
  • skill is the same word in both English and German, so the key maps to "Skill" in both bundles.
  • owner → "Eigner" (rather than the more common "Besitzer") follows ProjectForge's established convention across all plugins.
  • self-rating → "Selbsteinschätzung" accurately conveys the self-assessment nature of the rating.
UTF-8 encoding: Migrated from ISO-8859-1 to UTF-8 in commit 6fd4462f8. German umlauts (ö, ü, ß) are now stored as literal UTF-8 characters rather than \uXXXX escape sequences.
