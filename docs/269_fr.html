Traductions notables

  • interest.3 ("Going crazy!") est laissé non traduit — l'expression anglaise est conservée telle quelle dans la locale française.
  • skill est traduit par "Compétence" en français, tandis que le terme anglais est conservé dans la version originale.
  • owner → "Propriétaire" (plutôt que "Eigner" en allemand) suit la convention établie par ProjectForge pour la version française.
  • self-rating → "Auto-évaluation" traduit fidèlement la nature d'auto-évaluation de la notation.
Encodage UTF-8 : Migré de l'ISO-8859-1 vers l'UTF-8 dans le commit 6fd4462f8. Les caractères accentués français (é, è, ê, ô, û, etc.) sont désormais stockés sous forme de caractères UTF-8 littéraux plutôt que de séquences d'échappement \uXXXX.
