Leere deutsche Lokalisierungsdatei für das SkillMatrix-Plugin. Enthält nur einen Kommentar: # Leer, de ist Standard. Deutsche Zeichenketten werden durch das Standard-SkillMatrixI18nResources.properties bereitgestellt.

Rolle in der Lokalisierung

In der ResourceBundle-Suchkette von Java sucht das System bei der Locale de oder de_DE zunächst nach SkillMatrixI18nResources_de.properties. Da diese Datei keine Schlüssel-Wert-Paare enthält, fällt das Bündel auf das Standard-SkillMatrixI18nResources.properties zurück (welches die deutschen Zeichenketten enthält).

Diese leere Datei dient ausschließlich als Locale-Markierung – sie verhindert, dass das System in bestimmten Classloader-Konfigurationen direkt am Deutschen vorbei zum Standard-Bündel springt, und gewährleistet so eine konsistente Bündelauflösung.

Muster: Dies ist das Standardmuster, das von allen ProjectForge-Plugins verwendet wird, die nur die Locales Englisch + Deutsch haben. Die _de.properties-Datei ist immer leer mit dem Kommentar # Leer, de ist Standard., während die Basis-.properties-Datei die deutschen Zeichenketten enthält.
