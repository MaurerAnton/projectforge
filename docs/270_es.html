Archivo de localización en español vacío para el plugin SkillMatrix. Contiene solo un comentario: # Empty, en is default. Las cadenas en español se sirven mediante el archivo predeterminado SkillMatrixI18nResources.properties.

Rol en la localización

En la cadena de búsqueda de ResourceBundle de Java, cuando la configuración regional es es o es_ES, el sistema primero busca SkillMatrixI18nResources_es.properties. Dado que este archivo no tiene pares clave-valor, el paquete recurre al archivo predeterminado SkillMatrixI18nResources.properties (que contiene las cadenas en español).

Este archivo vacío existe puramente como un marcador de configuración regional: evita que el sistema omita directamente el español y pase al paquete predeterminado en ciertas configuraciones del cargador de clases, asegurando una resolución consistente del paquete.

Patrón: Este es el patrón estándar utilizado por todos los plugins de ProjectForge que tienen solo configuraciones regionales en español y alemán. El archivo _es.properties siempre está vacío con el comentario # Empty, en is default., mientras que el archivo base .properties contiene las cadenas en español.
