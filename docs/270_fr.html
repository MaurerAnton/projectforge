Fichier de localisation français vide pour le plugin SkillMatrix. Contient uniquement un commentaire : # Empty, en is default. Les chaînes françaises sont servies par le fichier par défaut SkillMatrixI18nResources.properties.

Rôle dans la localisation

Dans la chaîne de recherche ResourceBundle de Java, lorsque la locale est fr ou fr_FR, le système cherche d'abord SkillMatrixI18nResources_fr.properties. Comme ce fichier ne contient aucune paire clé-valeur, le bundle se rabat sur le fichier par défaut SkillMatrixI18nResources.properties (qui contient les chaînes françaises).

Ce fichier vide existe uniquement comme marqueur de locale — il empêche le système de sauter directement par-dessus le français pour atteindre le bundle par défaut dans certaines configurations de classloader, garantissant ainsi une résolution cohérente du bundle.

Modèle : C'est le modèle standard utilisé par tous les plugins ProjectForge qui n'ont que les locales anglaise + allemande. Le fichier _fr.properties est toujours vide avec le commentaire # Empty, en is default., tandis que le fichier de base .properties contient les chaînes françaises.
