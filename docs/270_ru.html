Пустой файл локализации на русском для плагина SkillMatrix. Содержит только комментарий: # Empty, ru is default. Русские строки предоставляются базовым файлом SkillMatrixI18nResources.properties.

Роль в локализации

В цепочке поиска ResourceBundle в Java, когда локаль установлена на ru или ru_RU, система сначала ищет SkillMatrixI18nResources_ru.properties. Поскольку этот файл не содержит пар ключ-значение, пакет переходит к базовому SkillMatrixI18nResources.properties (который содержит русские строки).

Этот пустой файл существует исключительно как маркер локали — он предотвращает пропуск русской локали и прямой переход к базовому пакету в некоторых конфигурациях загрузчика классов, обеспечивая последовательное разрешение пакетов.

Шаблон: Это стандартный шаблон, используемый всеми плагинами ProjectForge, которые поддерживают только русскую и немецкую локали. Файл _ru.properties всегда пуст с комментарием # Empty, ru is default., в то время как базовый файл .properties содержит русские строки.
