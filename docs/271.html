Default (English) i18n resource bundle, plugins/org.projectforge.plugins.skillmatrix/src/main/resources/SkillMatrixI18nResources.properties
Default internationalization bundle for the SkillMatrix plugin. Provides 18 English keys for the skill matrix UI — a tool for tracking employee skills, self-ratings, and interest levels.

Key Categories

  • Rating scales: interest.0-3 and rating.0-3 define 4-level scales for interest and self-assessment. The interest scale uses playful labels ("Going crazy!") while the rating scale uses professional labels ("Basic", "Advanced", "Expert").
  • Filter: filter.mySkills enables a toggle to show only the logged-in user's skills.
  • Titles: title.add, title.edit, title.list follow ProjectForge's standard naming convention for CRUD page titles.
  • Validation: error.doublet prevents creating skills with duplicate names using MessageFormat parameter {0}.
Locale resolution: German locale loads SkillMatrixI18nResources_de.properties; all others fall back to this file. The _en.properties is empty (see #270).
