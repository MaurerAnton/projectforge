Componente de navegación de árbol para la barra lateral del panel de tareas. Define las constantes `TreeStatus` (ABIERTO, CERRADO, HOJA) con métodos auxiliares `isLeaf()` y `getIcon()` para renderizar iconos de chevron de FontAwesome (abajo/derecha) que indican el estado de expansión/contracción del nodo. Se utiliza en la navegación jerárquica del árbol de tareas para permitir a los usuarios explorar relaciones de tareas padre/hijo con indicadores visuales de estado.
