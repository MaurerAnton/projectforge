#274: ToDoDao.java

Java DAO. Extends BaseDao<ToDoDO>. The most complex plugin DAO — provides getOpenToDos() for badge count, getRecentlyModified(), multi-filter queries (by status, type, assignee, due date range), and the toDoCache integration. Uses rights from ToDoRight for row-level access: users see ToDos they own or are assigned to.
