Partie du plugin ToDo. Gestionnaire de cache.

Implémentation de cache stockant en mémoire les données fréquemment consultées.

Structure

ToDoCache — classe : AbstractCache.

Dépendances clés : org.projectforge.framework.cache.AbstractCache

Décisions de conception

  • Cache en mémoire conservant les données fréquemment consultées. Invalidé lors des modifications de données pertinentes. Thread-safe pour les lectures concurrentes.

Pièges et écueils

  • Le timing d'invalidation du cache est critique pour la cohérence. Les conditions de concurrence entre les écritures et l'éviction du cache peuvent servir des données obsolètes.
