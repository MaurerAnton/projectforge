#276: ToDoEditPage.java

Wicket Page / UI, plugins/org.projectforge.plugins.todo/src/main/java/org/projectforge/plugins/todo/ToDoEditPage.java

Apache Wicket page for creating and editing to-do entries. Handles form submission, notification sending (when assignee/status changes), user preference storage for favorites, and selection callbacks for task/group linking.

Architecture

Extends AbstractEditPage with generics for ToDoDO, ToDoEditForm, ToDoDao. Implements ISelectCallerPage for task/group selection. Key flow: init, pref-fill (new) or copy-existing (edit), save, sendNotification on assignee/status change, optionally save as user template. Deferred 'recent' flag clearing via onAfterRender.
