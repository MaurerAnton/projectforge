#277: ToDoFilter.java

Search filter. Extends BaseSearchFilter with: status (OPEN/IN_PROGRESS/CLOSED), type (ToDoType), priority (HIGH/MEDIUM/LOW), assigneeId, dueDateFrom/dueDateTo, showOnlyOwn (checkbox — shows only tasks owned by current user). Supports all CRUD filter combinations for the list view.
