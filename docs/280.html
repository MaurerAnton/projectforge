#280: ToDoPlugin.java

Java plugin entry point. ID: "todo". Named "ToDo" with description "ToDo's for assigning tasks to users". Registers: DAO for scripting, Wicket pages (ToDoListPage, ToDoEditPage), menu under MISC (with unread count badge via ToDoCache), right (PLUGIN_TODO), i18n. Also registers React REST (ToDoPagesRest) for the modern UI. Notable: one of the first plugins with a Chinese (zh) i18n translation alongside German and English.
