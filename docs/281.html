#281: ToDoRight.java

Lines: 142 · Type: Java — most complex plugin access right

Three-tier access control — the most sophisticated right in plugin space. 142 lines. hasAccess() implements:

  • Tier 1 — Owner: the user who created the ToDo always has full access
  • Tier 2 — Assignee: the user assigned to the ToDo has read/write access
  • Tier 3 — Task-based: if the ToDo is linked to a WBS task (TaskDO), any user with TaskRight access to that task also has access to the ToDo — this chains ToDo access to the task/WBS access control system

Admin override: users in the admin group always have access (full CRUD). Select access: override hasSelectAccess() returns true for all authenticated users — basic list view is open, row-level filtering happens on individual ToDos. History access: override hasHistoryAccess() — delegates to hasAccess() so the same 3-tier logic applies to viewing change history.

Registered with TodoPluginUserRightId.PLUGIN_TODO, category PLUGINS, default TRUE (all users can see the ToDo menu — access to individual tasks is row-level).
