ToDoDO — открытый класс : DefaultBaseDO().

Проектные решения

  • Сущность с аннотациями Hibernate с @Field/@IndexedEmbedded для поиска Lucene. Веса полей в аннотациях определяют релевантность результатов.

Ошибки и подводные камни

  • Поисковый индекс устаревает после массовых обновлений SQL/HQL. Выполняйте ручную переиндексацию или контролируйте глубину @IndexedEmbedded.
