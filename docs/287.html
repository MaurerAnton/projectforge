#287: org.projectforge.plugins.core.AbstractPlugin (ToDo ServiceLoader)

ServiceLoader registration for ToDoPlugin, plugins/org.projectforge.plugins.todo/src/main/resources/META-INF/services/org.projectforge.plugins.core.AbstractPlugin
Java ServiceLoader configuration file registering ToDoPlugin as an implementation of AbstractPlugin. This single-line SPI file is the entry point for the ToDo plugin's auto-discovery in ProjectForge.

Architecture

Content

org.projectforge.plugins.todo.ToDoPlugin

This file enables the Java ServiceLoader to discover and instantiate ToDoPlugin at application startup. The ToDo plugin is one of the oldest and most feature-rich plugins in ProjectForge, providing shared to-do lists with task integration, group assignment, email notifications, and Wicket-based list/edit pages.

Registration Lifecycle

When discovered, ToDoPlugin extends AbstractPlugin and in its initialize() method registers:

  • Persistent entity: ToDoDO.class — the plugin's single domain object, used for XML dump/import ordering.
  • DAO: ToDoDao via RegistryEntry, making it available to the scripting engine.
  • Web pages: ToDoListPage.class and ToDoEditPage.class via registerWeb().
  • Menu: Under MenuItemDefId.MISC with a live badge counter showing open to-do count.
  • Access right: ToDoRight with multi-level access logic (assignee, reporter, group membership, task access).
  • i18n: ToDoI18nResources resource bundle.
  • User preferences: USER_PREF_AREA for to-do favorites, registered in UserPrefAreaRegistry.

Design Decisions

  • ServiceLoader over Spring scanning: Like all ProjectForge plugins, ToDoPlugin uses Java SPI rather than @Component. This allows plugins to be loaded from external JARs without modifying Spring configuration.
  • Static ID constant: ToDoPlugin.ID = "toDo" is used consistently across the plugin (DAO registration, menu items, registry entries) to avoid string duplication.
  • Badge counter on menu: The menu item sets a badgeCounter lambda calling toDoDao.getOpenToDoEntries(null), providing a live count of open to-dos directly in the navigation menu.
  • Plugin admin ID: Uses PluginAdminService.PLUGIN_TODO_ID as its identifier, linking it to the ProjectForge admin panel's plugin management system.
Historical note: The ToDo plugin was present from the initial commit of ProjectForge. Its service loader file has evolved from the original class name Projectforge to ProjectForge (capital F), reflecting the project's renaming.
