Two critical development-mode properties added to projectforge.properties:

PropertyEffect
projectforge.development.mode=trueLogs 2FA codes instead of sending SMS; enables verbose logging
projectforge.sms.url=http://smsgw.localhost/api.phpFakes an SMS gateway — prevents startup errors but doesn't actually send SMS

Lines 50–57: Two-factor auth simulation

Without a real SMS gateway or mail server, 2FA requires workarounds: the admin sets a fake mobile number (123456789), triggers SMS, and reads the 2FA code from the log file (enabled by development.mode=true). This section also notes that YubiKey, Google Authenticator, and other 2FA methods can be configured subsequently.

Points to the main Spring Boot config file as the canonical reference for all configurable properties. The "Reset" section (line 65) is refreshingly direct: delete ~/ProjectForge and start over — the embedded HSQLDB database is file-based, so deleting the directory truly resets everything.

Language note

This is the only non-English file in the doc/ directory. All other documentation files are English-language. The filename suffix -deutsch suggests this was written by a German-speaking developer for an internal German-speaking audience — possibly before the project's documentation was internationalized.

Key takeaways
