#291: GroovyEngineTest.java

Integration test for ProjectForge's GroovyExecutor — tests that Groovy scripts can access the ToDo plugin's DAO via the scripting bridge, create/modify tasks programmatically, and evaluate expressions. Uses test scripting templates (#292, #293) loaded from classpath. One of the few tests that exercises the full Groovy scripting engine with a real plugin DAO.
