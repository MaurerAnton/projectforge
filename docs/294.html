#294: build.gradle.kts

ProjectForge Application module build. The Spring Boot application entry point module. Applies pf-module-conventions + org.springframework.boot plugin. Dependencies: projectforge-business, projectforge-wicket, projectforge-webapp, all plugins (banking, datatransfer, ihk, licensemanagement, liquidityplanning, marketing, memo, merlin, skillmatrix, todo), plus Spring Boot starters (web, security, actuator), PostgreSQL driver, HSQLDB for testing. Also declares spring-boot-devtools for hot reload in development.
