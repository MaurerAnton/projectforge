#297: WebApplicationConfig.java

Lines: 60 · Type: Java @Configuration

Spring Boot web configuration. Sets up: @EnableWebMvc, @EnableScheduling, task scheduler with pool size 5, async support, MVC content negotiation (JSON + HTML), RestTemplate bean, MultipartResolver (file upload max size from config), and Wicket filter integration. This is the bridge between Spring Boot's servlet container and ProjectForge's Wicket/React dual frontend.
