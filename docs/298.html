#298: WebXMLInitializer.java

Lines: 115 · Type: Java — programmatic web.xml replacement

Replaces traditional web.xml with Java config. Implements WebApplicationInitializer — the Spring Boot way of configuring servlet container settings. Sets up: session timeout (30 min, configurable), cookie settings (HttpOnly, Secure, SameSite), Wicket filter with init params (configuration type = deployment, filter path = /wa/*, /upload/*, /servlet/*), H2 console servlet (for dev), CORS filter, and static resource caching (1 year for immutable assets, 1 day for dynamic). Also configures error pages (404, 500 → React SPA fallback) and the welcome file list.

This is the single place where Wicket filter mapping happens — the path prefix /wa/ is defined here as an init-param, routing all Wicket pages through this servlet filter. The React SPA (/) is served by the default servlet.
