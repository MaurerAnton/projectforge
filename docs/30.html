Instructions for the Docker Compose setup. Directories: ProjectForge (app), database, nginx. Steps: edit `.env` and `nginx.conf`, deploy SSL certs, start with `docker-compose up -d`.

Directory Structure

project/
├── ProjectForge/          # Application data
├── ProjectForge/database  # Database files
├── nginx/                 # Nginx configuration
├── docker-compose.yml     # Docker Compose setup
└── .env                   # Environment variables

Deployment Steps

  1. Edit .env and ./nginx/nginx.conf
  2. Deploy SSL certificates
  3. Start: docker-compose up -d
  4. Check: docker ps, docker-compose logs
