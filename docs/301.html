#301: CorsPreflightFilter.kt

Lines: 53 · Type: Kotlin Filter

CORS preflight handler. Intercepts OPTIONS requests and adds CORS headers: Access-Control-Allow-Origin, Allow-Methods (GET/POST/PUT/DELETE/PATCH), Allow-Headers (Authorization, Content-Type, X-Requested-With, X-CSRF-TOKEN), Max-Age (3600s). Reads allowed origins from PFSpringConfiguration (configurable via projectforge.cors.allowed-origins). Returns 200 OK immediately for preflight requests without forwarding to controllers — reduces latency for OPTIONS calls from the React frontend.
