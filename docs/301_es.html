#301: ProjectForgeStartupListener.java

projectforge-application/src/main/java/org/projectforge/start/ProjectForgeStartupListener.java Líneas: 89 · Tipo: Java ApplicationListener<ApplicationPreparedEvent> 89 líneas · 53 código · 26 comentarios · 10 en blanco

Listener de inicialización previa al arranque. Se dispara en ApplicationPreparedEvent — después de que el contexto de Spring se inicializa pero antes de que el Tomcat embebido comience a aceptar conexiones. 89 líneas.

  • Creación de directorios base: asegura que los directorios logs/, temp/, fonts/, attachments/ existan bajo el directorio base configurado
  • Banner de versión: lee /META-INF/projectforge-version.properties del classpath, registra el número de versión, la marca de tiempo de compilación y la revisión de Git en un banner formateado
  • Directorio de fuentes: escribe archivos de fuente empaquetados en fonts/ para MerlinFontService
  • Información de JVM: registra el nombre de JVM, versión, configuración de memoria (heap + no heap), PID y versión de classpath usando ManagementFactory.getRuntimeMXBean()
  • Activación de plugins: dispara la inicialización de plugins de ProjectForgeApp — descubre todos los plugins mediante ServiceLoader y llama a sus métodos initialize()
  • Precalentamiento de caché: llama al calentamiento de UserGroupCache para precargar las asignaciones de grupos de usuarios antes de la primera solicitud

El banner de inicio se imprime usando EmphasizedLogSupport con bordes de arte ASCII — visible en el registro de la aplicación inmediatamente después de que se dispara ApplicationPreparedEvent.
