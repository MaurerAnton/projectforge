#301: ProjectForgeStartupListener.java

projectforge-application/src/main/java/org/projectforge/start/ProjectForgeStartupListener.java Строк: 89 · Тип: Java ApplicationListener<ApplicationPreparedEvent> 89 строк · 53 кода · 26 комментариев · 10 пустых

Слушатель инициализации перед запуском. Срабатывает на ApplicationPreparedEvent — после инициализации контекста Spring, но до того, как встроенный Tomcat начнёт принимать соединения. 89 строк.

  • Создание базовых каталогов: гарантирует существование каталогов logs/, temp/, fonts/, attachments/ в настроенном базовом каталоге
  • Баннер версии: читает /META-INF/projectforge-version.properties из classpath, выводит в лог номер версии, временную метку сборки и ревизию Git в форматированном баннере
  • Каталог шрифтов: записывает встроенные файлы шрифтов в fonts/ для MerlinFontService
  • Информация о JVM: выводит в лог имя JVM, версию, настройки памяти (heap + non-heap), PID и версию classpath с помощью ManagementFactory.getRuntimeMXBean()
  • Активация плагинов: запускает инициализацию плагинов ProjectForgeApp — обнаруживает все плагины через ServiceLoader и вызывает их методы initialize()
  • Прогрев кэша: вызывает прогрев UserGroupCache для предварительной загрузки отображений пользователь-группа до первого запроса

Стартовый баннер выводится с помощью EmphasizedLogSupport с границами в стиле ASCII-арта — виден в логе приложения сразу после срабатывания ApplicationPreparedEvent.
