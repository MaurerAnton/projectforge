#302: MyErrorController.kt

Lines: 52 · Type: Kotlin @Controller — implements ErrorController

Custom error page controller. Redirects HTTP 404 errors to the React SPA's root (redirect:/) — allows the React Router to handle "page not found" on the client side. For non-404 errors (400, 403, 500), returns the Wicket error page (/wa/errorPage). Also handles the /error path registered by Spring Boot's default BasicErrorController. The attribute jakarta.servlet.error.status_code from the RequestDispatcher is used to determine the status code.
