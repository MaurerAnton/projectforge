#303: I18nKeysSourceAnalyzer.kt

Lines: 522 · Type: Kotlin developer tool

Static analysis tool for i18n key usage. 522 lines. Scans the entire ProjectForge source tree to find: which i18n keys are defined in .properties files, which are used in Java/Kotlin code (via translate("key") calls), and which are orphaned (defined but never used). Uses org.reflections library with Scanners.Resources to find all *.properties files, and regex scanning of source files to find .getI18nKey() calls, @PropertyInfo(i18nKey = "...") annotations, and PropertyInfo usage.

Outputs three JSON reports: i18n-keys-usage.json, i18n-keys-missing.json, i18n-keys-unused.json. This is a development-time tool — not part of the runtime application. Can be run via the I18nKeysSourceAnalyzer.main() method or as a Gradle task.
