#304: I18nKeysUsage.kt

Data model for i18n analysis results. Contains: allKeys (set of all defined keys), usedKeys (keys found in source), unusedKeys (defined but unused), missingKeys (used but not in any .properties), keyUsages (list of I18nKeyUsageEntry — per-file usage data). Serialized to JSON by I18nKeysSourceAnalyzer.
