#306: LuceneIndexTester.kt

Development tool. Utility class for testing Hibernate Search / Lucene indexing in development. Provides methods to: reindex all entities, search by keyword, verify index contents, benchmark query performance. Not part of the production runtime — used during development and debugging of search functionality. Uses Search.session(entityManager).massIndexer() for full reindexing.
