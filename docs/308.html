#308: SpringSecurityConfig.kt

Spring Security configuration. @Configuration + @EnableWebSecurity. Defines: CSRF protection (token-based, cookie name XSRF-TOKEN), session management (stateless for REST, cookie-based for Wicket), login page (/login → React), logout URL (/logout), remember-me cookie, password encoder (BCryptPasswordEncoder with strength 12), and URL-level security: /rest/** requires authentication, /wa/** (Wicket) handled by Wicket's own auth filter, /resources/** is public. Also configures OAuth2 login for external IDP support (Keycloak).
