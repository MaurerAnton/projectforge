#309: ProjectForgeInitializer.kt

Setup wizard entry point. CommandLineRunner that runs on first startup. Detects if ProjectForge needs initialization (no admin user exists, no configuration database). If yes, starts the interactive SetupContext wizard: create admin user, configure database, set base URL, import initial data. After successful setup, writes a .initialized marker file in the base directory to skip the wizard on subsequent starts. The wizard supports both console (Lanterna) and Swing desktop modes.
