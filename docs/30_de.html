Anleitung für das Docker-Compose-Setup. Verzeichnisse: ProjectForge (App), Datenbank, nginx. Schritte: .env und nginx.conf bearbeiten, SSL-Zertifikate bereitstellen, mit docker-compose up -d starten.

project/
├── ProjectForge/          # Anwendungsdaten
├── ProjectForge/database  # Datenbankdateien
├── nginx/                 # Nginx-Konfiguration

└── .env                   # Umgebungsvariablen

Bereitstellungsschritte

  1. .env und ./nginx/nginx.conf bearbeiten
  2. SSL-Zertifikate bereitstellen
  3. Starten: docker-compose up -d
  4. Überprüfen: docker ps, docker-compose logs
