Instrucciones para la configuración de Docker Compose. Directorios: ProjectForge (app), base de datos, nginx. Pasos: editar .env y nginx.conf, implementar certificados SSL, iniciar con docker-compose up -d.

Estructura de directorios

project/
├── ProjectForge/          # Datos de la aplicación
├── ProjectForge/database  # Archivos de la base de datos
├── nginx/                 # Configuración de Nginx
├── docker-compose.yml     # Configuración de Docker Compose
└── .env                   # Variables de entorno

Pasos de implementación

  1. Editar .env y ./nginx/nginx.conf
  2. Implementar certificados SSL
  3. Iniciar: docker-compose up -d
  4. Verificar: docker ps, docker-compose logs
