Instructions pour la configuration Docker Compose. Répertoires : ProjectForge (app), base de données, nginx. Étapes : modifier .env et nginx.conf, déployer les certificats SSL, démarrer avec docker-compose up -d.

Structure des répertoires

project/
├── ProjectForge/          # Données de l'application
├── ProjectForge/database  # Fichiers de la base de données
├── nginx/                 # Configuration Nginx
├── docker-compose.yml     # Configuration Docker Compose
└── .env                   # Variables d'environnement

Étapes de déploiement

  1. Modifier .env et ./nginx/nginx.conf
  2. Déployer les certificats SSL
  3. Démarrer : docker-compose up -d
  4. Vérifier : docker ps, docker-compose logs
