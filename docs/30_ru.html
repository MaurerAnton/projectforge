Инструкции по настройке Docker Compose. Каталоги: ProjectForge (приложение), база данных, nginx. Шаги: отредактируйте `.env` и `nginx.conf`, разверните SSL-сертификаты, запустите с помощью `docker-compose up -d`.

Структура каталогов

project/
├── ProjectForge/          # Данные приложения
├── ProjectForge/database  # Файлы базы данных
├── nginx/                 # Конфигурация Nginx
├── docker-compose.yml     # Настройка Docker Compose
└── .env                   # Переменные окружения

Шаги развёртывания

  1. Отредактируйте .env и ./nginx/nginx.conf
  2. Разверните SSL-сертификаты
  3. Запустите: docker-compose up -d
  4. Проверьте: docker ps, docker-compose logs
