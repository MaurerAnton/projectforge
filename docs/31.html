File #31: .github/workflows/gradle.yml

Path: ./.github/workflows/gradle.yml · Type: GitHub Actions CI workflow · Lines: 46 · Source: GitHub

What it does

Runs the full Gradle build (./gradlew build) on every push and pull request to develop — excluding site-only changes (which are handled by #30). This is the primary CI pipeline: compiles all modules, runs tests, checks code quality. Java 17 + Eclipse Temurin + Gradle wrapper + SPRING_PROFILES_ACTIVE: ci.

Section-by-section

Lines 1–10: Triggers

2  on:
3    push:
4      branches: [ develop ]
5      paths-ignore:
6        - 'site/**'
7    pull_request:
8      branches: [ develop ]

Fires on both push and pull_request to develop. The paths-ignore: site/** is the inverse of #30's filter — this prevents redundant CI runs when only the website changes (no code to build). This is important for monorepos where doc-only commits should not waste CI minutes.

Lines 17–20: Checkout

18 - name: Checkout code
19   uses: actions/checkout@v3
20 - uses: actions/checkout@v3                    ← DUPLICATE
Duplicate checkout: Line 19 and 20 both invoke actions/checkout@v3. Line 18 has a name, line 20 doesn't — the second checkout is redundant and doubles the checkout time unnecessarily. The first checkout (line 19, with name "Checkout code") is sufficient.

Lines 22–34: Java and caching

Eclipse Temurin is the reference OpenJDK distribution — matches the openjdk:17-slim base image in Dockerfile line 1. Gradle cache keyed on *.gradle* + gradle-wrapper.properties — any dependency or plugin change invalidates the cache.

Lines 39–43: Build

39 - name: Test and build with Gradle
40   run: ./gradlew build
41   env:
42     SPRING_PROFILES_ACTIVE: ci

./gradlew build runs the full pipeline: compile, test, check, assemble. The SPRING_PROFILES_ACTIVE: ci environment variable tells Spring Boot to load application-ci.properties — likely disables features that require external services (SMS gateway, mail server) and configures in-memory databases for testing.

Key takeaways

  • 46 lines, standard CI: Java 17 Temurin + Gradle wrapper + cache — textbook GitHub Actions Java CI.
  • Site-aware filtering: paths-ignore: site/** prevents redundant builds on doc-only commits — complements #30.
  • Duplicate checkout: Lines 19-20 check out the repo twice — harmless but wasteful.
  • CI Spring profile: SPRING_PROFILES_ACTIVE: ci isolates tests from external dependencies.
  • No separate test step: Lines 45-46 have a commented-out ./gradlew test — tests run as part of build, so the separate step is unnecessary.
