#310: SetupContext.kt

Setup wizard context/state. Holds all data collected during the initial setup: admin username/password/email, database connection settings (JDBC URL, username, password), SMTP settings, base URL, default locale/timezone. Passed between setup wizard steps. The wizard structure: Welcome → Database → Admin User → SMTP → Review → Execute. Supports both console (Lanterna TUI) and Swing GUI with fallback — detects if running in a terminal or headless mode.
