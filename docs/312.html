#312: AbstractSetupWizard.kt

Abstract base for setup wizard screens. Defines the wizard step interface: getTitle(), render(), validate(), onNext(), onPrevious(). Manages step navigation (back/next buttons), validation error display, and the step progress indicator. Both Lanterna (console) and Swing (desktop) wizards extend this with their respective rendering code.
