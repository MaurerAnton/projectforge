#313: FinalizeScreenSupport.kt

Final wizard step helper. Provides the "Review & Execute" screen logic: displays a summary of all entered settings, validates the configuration one final time, and executes the setup (creates admin user, initializes database schema, writes config files). Shows a progress spinner/bar during execution with step-by-step log output. Handles rollback on failure.
