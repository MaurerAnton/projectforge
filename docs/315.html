#315: JdbcConnectionTest.kt

JDBC connectivity tester. Tests the database connection during setup: attempts DriverManager.getConnection() with the configured JDBC URL/username/password, verifies the connection is valid (connection.isValid(5) seconds), checks database version (shows PostgreSQL/HSQLDB version), and verifies required extensions are available (e.g. pgcrypto for PostgreSQL). Displays success/failure with specific error messages (wrong password, host unreachable, database not found).
