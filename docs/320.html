#320: LantFinalizeScreen.kt

Lanterna final wizard step. Renders the review summary using FinalizeScreenSupport, then shows a progress animation during setup execution. Uses Lanterna's ProgressBar component dynamically updated as each setup step completes. On error, shows the error in red and offers retry/abort. On success, displays "Setup complete — restart to begin using ProjectForge" message.
