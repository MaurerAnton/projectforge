#323: LantSetupWizard.kt

Lanterna wizard coordinator. Orchestrates all Lanterna wizard steps: Directory → Database → Admin User → SMTP → Review → Execute. Creates LantAbstractWizardWindow instances in sequence, manages the step list, and handles the transition between steps. The main entry point for the Lanterna setup flow — instantiated by ProjectForgeInitializer when it detects a terminal environment.
