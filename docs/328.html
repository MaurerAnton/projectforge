#328: SwingJdbcSettingsDialog.kt

Swing JDBC config panel. JPanel with labeled text fields for JDBC URL, username, JPasswordField for password. "Test Connection" button with color feedback (green = success, red = error with message). Includes vendor preset dropdown: PostgreSQL, HSQLDB, MySQL — auto-fills the JDBC URL template.
