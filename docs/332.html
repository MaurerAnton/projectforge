#332: ConsoleTimeoutReader.kt

Console input with timeout. Reads from System.in (stdin) with a configurable timeout. Used during startup for "Press ENTER to open browser, or wait 10 seconds..." type prompts. Uses a daemon thread that reads from stdin and interrupts after the timeout. If the console is not a tty (e.g., running as systemd service), returns immediately without blocking.
