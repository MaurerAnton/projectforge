#333: ProjectForgeEndpoints.kt

Application endpoint info. Extends Spring Boot's ApplicationContext to log the application's URLs after startup: local address (http://localhost:8080), external address (from config), Wicket base URL, REST API base, and database connection info. Printed after the startup banner so users know where to connect. Also checks if the configured port is accessible and warns if there's a firewall.
