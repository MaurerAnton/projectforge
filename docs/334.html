#334: ProjectForgeHomeFinder.kt

Home directory resolver. Determines the ProjectForge home directory in priority order: (1) --base-dir command-line argument, (2) projectforge.base-dir system property, (3) PROJECTFORGE_BASE_DIR environment variable, (4) ~/.projectforge (default). Validates the directory exists or can be created, has write permissions, and has enough free space. Returns a canonical path for logging. Used by ProjectForgeApplication on startup.
