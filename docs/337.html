#337: logback-spring.xml

Logback logging configuration. Spring Boot-aware (logback-spring.xml allows <springProfile> tags). Defines: console appender (colored output), file appender (logs/projectforge.log with daily rotation and 30-day retention), async appender for performance. Log levels: INFO for ProjectForge packages, WARN for Hibernate SQL, DEBUG for Spring Security. Includes <springProfile name="dev"> block for verbose SQL logging in development.
