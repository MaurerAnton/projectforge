File #34: gradle.properties

Path: ./gradle.properties · Type: Gradle configuration · Lines: 4 · Source: GitHub

What it does

4-line Gradle properties file setting JVM options for Gradle and Kotlin daemons, enabling the configuration cache, and keeping the Gradle daemon alive for faster subsequent builds. Shorter than even #20 (9 lines) — but every line matters for a 20-module project with Kotlin scripting.

Line-by-line

1  org.gradle.configuration-cache=true
2  kotlin.daemon.jvmargs=-Xmx4G -XX:MaxMetaspaceSize=1G -XX:+UseG1GC -XX:ReservedCodeCacheSize=1G
3  org.gradle.jvmargs=-Xmx4G -XX:MaxMetaspaceSize=1G -XX:+UseG1GC
4  org.gradle.daemon=true
LinePropertyEffect
1 org.gradle.configuration-cache=true Enables Gradle's configuration cache — caches the result of the configuration phase (resolving plugins, evaluating build scripts). In a 20-module project, this can save 10-30 seconds per build.
2 kotlin.daemon.jvmargs=... Kotlin compiler daemon gets 4GB heap, 1GB metaspace, G1GC, and 1GB code cache. The Kotlin daemon compiles .kt files incrementally — enough memory prevents OOM on multi-module compilation.
3 org.gradle.jvmargs=... Gradle daemon JVM: 4GB heap, 1GB metaspace, G1GC. Identical heap config to the Kotlin daemon — total potential memory usage: ~9GB (4GB Gradle + 4GB Kotlin + 1GB overhead).
4 org.gradle.daemon=true Keeps the Gradle daemon process alive after builds — reduces cold-start overhead from ~8s to ~0.5s.

Memory sizing

The 4GB allocation is notable — it matches the startProjectForge.sh (#24) runtime heap of 4GB. For a build tool, 4GB is on the high side, indicating a large dependency graph with 20+ modules and heavy use of annotation processing (Hibernate, Flyway, Spring). The MaxMetaspaceSize=1G prevents class metadata from consuming unlimited native memory — critical for Groovy 4.x and Kotlin scripting which load many classes dynamically.

Key takeaways

  • 4 lines, ~9GB RAM footprint: 4GB for Gradle daemon + 4GB for Kotlin daemon + 1GB for Gradle daemon metaspace.
  • Configuration cache: The single biggest build-time optimization — enabled, not experimental.
  • G1GC: The modern default for Java 17+ — low-pause collector well-suited for build tools with many short-lived objects.
  • Kotlin daemon code cache: ReservedCodeCacheSize=1G caches compiled bytecode across incremental compilations — reducing recompilation time.
