#340: LoggingFilterTest.kt

Unit test for LoggingFilter. Verifies: request URI and method are logged, response status appears in log output, static resources are excluded from logging, MDC requestId is set and cleared per request, client IP is extracted (including X-Forwarded-For header handling). Uses Mockito for HttpServletRequest/HttpServletResponse.
