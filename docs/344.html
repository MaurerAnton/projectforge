#344: SortAndCheckI18nPropertiesMain.kt

I18n properties sorter. Development tool that reads all *.properties files in the project, sorts keys alphabetically, removes duplicates, and checks that all locale-specific files (_de, _es, etc.) have the same keys as the default file. Outputs a report of missing/extra keys per locale. Used during development to maintain i18n consistency.
