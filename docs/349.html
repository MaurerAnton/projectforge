#349: build.gradle.kts

ProjectForge Business module build. The core business logic module. Applies pf-module-conventions. Dependencies include: Spring Boot starters (JPA, Security, Mail, Validation), Hibernate ORM + Search, Apache Jackrabbit (JCR), JFreeChart, Groovy (scripting engine), iText/OpenPDF, Apache POI, Flying Saucer (HTML→PDF), Freemarker, Ehcache, Lucene, and dozens of other libraries. This module has the heaviest dependency tree — it's the backbone of the entire application.
