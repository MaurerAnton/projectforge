#352: Aggregation.groovy

Groovy aggregation script base. Part of the scripting engine's data aggregation framework. Provides base methods for summing, averaging, and grouping data across DAOs. Used by the ProjectForge scripting engine to enable Groovy-based report generation (e.g. "sum all timesheets for employee X in month Y").
