#354: Md4.java

Java MD4 hash implementation. From package arlut.csd.crypto — an external crypto library for Samba/CIFS password hashing. Used by the LDAP/Active Directory integration module to compute Samba NT password hashes (NT Hash) for POSIX account provisioning. MD4 is required because Samba uses it for NTLM authentication — not used for any other purpose in ProjectForge.
