#355: SmbEncrypt.java

Samba password encryption. From arlut.csd.crypto — computes Samba LM Hash and NT Hash from plaintext passwords. Uses Md4 for NT Hash. Called by LdapService when creating or updating POSIX/Samba accounts via LDAP — the encrypted hashes are written to sambaNTPassword and sambaLMPassword LDAP attributes for CIFS file sharing authentication. This is a port of the Samba encryption algorithm to Java.
