#358: DeltaSetCalculator.java

Hibernate history engine — computes the delta between the old entity state (before save) and new entity state (after save). Iterates all properties of the entity, comparing old vs. new values. For simple types → creates PropertyDelta, for associations → creates AssociationPropertyDelta, for collections → creates CollectionPropertyDelta. Fields annotated @NoHistory are skipped. This is the core algorithm of ProjectForge's custom Hibernate change tracking — a lightweight alternative to Hibernate Envers.
