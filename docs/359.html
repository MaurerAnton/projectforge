#359: DeltaSet.java

Hibernate history container — holds the set of all PropertyDelta objects for one entity save operation. Annotated fields: entityId, entityClass, timestamp, userId (who made the change), operationType (INSERT/UPDATE/DELETE), deltas (list of individual property changes). Serialized and stored as a HistoryEntry in the database. Rendered in the "History" tab of entity edit pages.
