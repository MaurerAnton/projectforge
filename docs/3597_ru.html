Что это делает

Языковой режим редактора ACE — подсветка синтаксиса для asciidoc во встроенном редакторе скриптов. Используется редактором ACE, встроенным в веб-приложение Wicket для функции встроенных скриптов Kotlin/Groovy. Редактор поддерживает подсветку синтаксиса для десятков языков — каждый файл режима определяет шаблоны токенов, ключевые слова и правила подсветки.
