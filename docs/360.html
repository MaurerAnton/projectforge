#360: PropertyDelta.java

Hibernate history delta base — represents a single property change. Fields: propertyName (e.g. "subject", "amount"), oldValue (before save, formatted as string), newValue (after save), propertyType (STRING, DATE, CURRENCY, etc. — determines formatting). Base class for AssociationPropertyDelta and CollectionPropertyDelta. Also used directly for simple fields (text, number, boolean, date).
