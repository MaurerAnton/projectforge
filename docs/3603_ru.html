Назначение

Языковой режим редактора ACE — подсветка синтаксиса для cirru во встроенном редакторе скриптов. Используется редактором ACE, встроенным в веб-приложение Wicket для функции встроенных скриптов на Kotlin/Groovy. Редактор поддерживает подсветку синтаксиса для десятков языков — каждый файл режима определяет шаблоны токенов, ключевые слова и правила подсветки.
