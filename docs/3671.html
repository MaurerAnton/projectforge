What it does

ACE Editor language mode — syntax highlighting for r in the built-in scripting editor. Used by the ACE Editor embedded in the Wicket webapp for the built-in Kotlin/Groovy scripting feature. The editor supports syntax highlighting for dozens of languages — each mode file defines token patterns, keywords, and highlighting rules.
