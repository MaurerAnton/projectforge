File #37: gradle/wrapper/gradle-wrapper.properties

Path: ./gradle/wrapper/gradle-wrapper.properties · Type: Gradle wrapper configuration · Lines: 7 · Source: GitHub

What it does

7-line wrapper properties file that controls how gradlew downloads and installs Gradle.

Properties

distributionBase=GRADLE_USER_HOME
distributionPath=wrapper/dists
distributionUrl=https\://services.gradle.org/distributions/gradle-8.12.1-all.zip
networkTimeout=10000
validateDistributionUrl=true
zipStoreBase=GRADLE_USER_HOME
zipStorePath=wrapper/dists
PropertyValueMeaning
distributionUrlgradle-8.12.1-all.zipGradle 8.12.1 with sources and docs (-all variant). The -all suffix means IDE integration gets javadoc + source code for Gradle APIs.
networkTimeout1000010-second timeout for downloading the distribution ZIP
validateDistributionUrltrueVerifies the SHA-256 checksum before extracting (Gradle 7.5+ feature)
distributionBase/zipStoreBaseGRADLE_USER_HOMEStores in ~/.gradle/wrapper/dists

Key takeaways

  • Gradle 8.12.1: Matches the Kotlin 2.0.21 compiler from #33 — Gradle 8.12 is the minimum version supporting Kotlin 2.0.
  • -all distribution: Heavier download (~140MB vs ~100MB for -bin) but enables IDE source navigation into Gradle APIs.
  • 10s timeout: Short — if Gradle servers are slow, the build fails before the wrapper can download.
