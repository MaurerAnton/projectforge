Qué hace

Modo de lenguaje del editor ACE: resaltado de sintaxis para gherkin en el editor de scripts integrado. Utilizado por el editor ACE incrustado en la aplicación web Wicket para la funcionalidad de scripting integrada en Kotlin/Groovy. El editor admite resaltado de sintaxis para docenas de lenguajes: cada archivo de modo define patrones de tokens, palabras clave y reglas de resaltado.
