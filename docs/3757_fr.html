Ce qu'il fait

Mode de langage de l'éditeur ACE — coloration syntaxique pour LiveScript dans l'éditeur de script intégré. Utilisé par l'éditeur ACE intégré dans l'application web Wicket pour la fonctionnalité de script Kotlin/Groovy intégrée. L'éditeur prend en charge la coloration syntaxique pour des dizaines de langages — chaque fichier de mode définit des motifs de jetons, des mots-clés et des règles de coloration.
