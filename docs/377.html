#377: DOConverter.java

Java interface — generic converter between DO (Domain Object / JPA entity) and DTO (Data Transfer Object / REST model). Defines toDTO(DO) and fromDTO(DTO, DO). Implemented by plugin-specific converters (e.g. AddressDOConverter) to transform entities for the REST API. Bridges JPA session scope (DOs tied to Hibernate) with serializable JSON DTOs.
