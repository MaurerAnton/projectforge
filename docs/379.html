#379: CellFormat.java

Java model — Excel cell formatting descriptor. Part of the Excel export engine. Fields: format (number format string like "#,##0.00"), type (NUMBER, DATE, CURRENCY, PERCENTAGE, TEXT), alignment (LEFT, CENTER, RIGHT), width (column width in characters), wrap (text wrapping). Applied to Cell objects in the Workbook → Sheet → Row → Cell Excel model hierarchy during export generation.
