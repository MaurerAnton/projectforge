#383: ExcelDateFormats.java

Java constants — Excel date format strings. Maps Java date format patterns to Excel DataFormat string codes: dd.MM.yyyy → "DD.MM.YYYY", yyyy-MM-dd → "YYYY-MM-DD", MM/yyyy → "MM/YYYY", plus datetime variants. Used by CellFormat to apply proper date formatting when writing LocalDate/Date values to cells.
