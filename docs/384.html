#384: ExcelExporter.java

Java export engine base. The core Excel generation class. Wraps Apache POI's HSSFWorkbook/XSSFWorkbook with ProjectForge's abstraction layer. Takes ContentProvider(s), CellFormat descriptors, and a DefaultExportContext, then generates an .xlsx/.xls file as a byte array or stream. Handles: column widths, cell styling (borders, fonts, colors), merged cells, freeze panes, auto-filters, and data validation (dropdowns). All ProjectForge Excel exports flow through this class or MyExcelExporter (#645).
