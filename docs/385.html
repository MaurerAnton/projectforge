#385: ExcelImportException.java

Java exception — thrown by the Excel import engine on parse errors. Carries: sheetIndex, rowIndex, columnIndex (precise location of the error in the import file), expectedType (what type was expected), actualValue (what was actually in the cell). Rendered as a user-friendly error message in the import dialog: "Row 42, Column 5: Expected number, found 'abc'".
