#386: ExcelImport.java

Java import engine. Reads Excel files and converts rows to domain objects. Uses Apache POI to parse .xlsx/.xls, then maps columns to DO fields via @PropertyInfo annotations on the DO class. Supports: header row detection (first row = column names → property mapping), date parsing (multiple formats), number parsing (localized decimal separators), mandatory field validation, and row-level error handling (continues processing on errors, reports all issues at once). Implemented by specific importers like KontoExcelImporter.
