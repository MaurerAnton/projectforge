Часть оригинальной кодовой базы ProjectForge с 2016 года. Пережила переписывание 7.x, миграцию с CRA на Vite и переход с Wicket на React.

Почему в программе для управления проектами есть игра? Это пасхальное яйцо для разработчиков — когда Wicket-веб-приложение сталкивается с необработанным исключением (ошибка 500), вместо скучного стек-трейса страница ошибки предлагает сыграть в Pac-Man. Это превращает разочарование в веселье. В игру также можно попасть напрямую по адресу /wa/pacman для быстрых перерывов во время разработки.

Архитектура игры — 11 состояний, 4 призрака, 30 FPS

var NONE = 4, UP = 3, LEFT = 2, DOWN = 1, RIGHT = 11,
    WAITING = 5, PAUSE = 6, PLAYING = 7,
    COUNTDOWN = 8, EATEN_PAUSE = 9, DYING = 10;
Pacman.FPS = 30;

11 состояний игры: Игра отслеживает состояние с помощью числовых констант — не перечисление (JS появился до широкого использования перечислений). Переходы состояний: WAITING → COUNTDOWN → PLAYING → (DYING | EATEN_PAUSE) → PLAYING. Состояние EATEN_PAUSE — это краткая заморозка, когда Пакман съедает призрака — классическая аркадная деталь.

Система ИИ призраков: Каждый призрак (Pacman.Ghost) отслеживает: позицию, направление, съедобность (уязвим после энерджайзера), съеден (возвращается на базу) и задержку (таймер появления). Скорость движения варьируется в зависимости от состояния — уязвимые призраки движутся со скоростью 1 (медленно), скрытые — 4 (быстро, чтобы вернуться на базу), нормальные — 2.

Игровой цикл 30 FPS: Игра работает с частотой 30 кадров в секунду через setInterval. Обнаружение коллизий использует привязку к сетке — призраки привязываются к ячейкам сетки 10px, чтобы не перепрыгивать через стены. Функция addBounded() обрабатывает крайние случаи, когда скорость призрака может привести к проскакиванию границы стены.

Слой рендеринга — Canvas + аудио-спрайты

Игра рендерится на элемент HTML5 <canvas>. Лабиринт, таблетки, Пакман и призраки рисуются программно. Аудио использует 20+ файлов .ogg и .mp3 в папке scripts/pacman/audio/ — сирена (преследование призраков), чавканье (поедание таблеток), смерть (смерть Пакмана), поедание призрака, дополнительная жизнь. Оба формата предоставлены для совместимости с браузерами (OGG для Firefox, MP3 для Chrome/Safari).

Известные ошибки (из комментариев в исходнике, строки 4-9): Зацикленное аудио работает некорректно, фрукты и уровни не завершены, состояние съеденного призрака сломано (призрак должен возвращаться на базу, но не возвращается), а правильные механики личности призраков (Блинки преследует, Пинки устраивает засаду, Инки случайный, Клайд бродит) реализованы не полностью.
