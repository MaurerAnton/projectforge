What it does

Eclipse IDE code templates for Java and JavaScript — auto-generated file headers, method comments, constructor stubs, and catch-block bodies. Committed to the repo so every developer using Eclipse gets consistent file headers and code style even before linters or CI run.

Historical context

These templates predate Kotlin adoption — the project was originally pure Java. The copyright year (2010) and author email (k.reinhard@micromata.de) suggest these templates were last updated when the project was Java-only and Kai Reinhard was the sole developer. The CLAUDE.md (#6) requires "Include standard ProjectForge license header in all new files" — these Eclipse templates automate that for Java files.
