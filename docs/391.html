#391: ExportRow.java

Service / Export, projectforge-business/src/main/java/org/projectforge/business/excel/ExportRow.java

Wraps an Apache POI Row for the Excel export framework. Manages column cells via ExportCell wrappers, supports bean property filling, style updates, merged regions, capitalized headers, and cell array access. 264 lines.

Architecture

Key component of org.projectforge.business.excel export pipeline. Wraps POI rows with: lazy cell array (cells with null-fill), fillBean using BeanHelper.getNestedProperty, ContentProvider-driven styling, and CellRangeAddress merging.
