El manifiesto de dependencias de compilación. Ejecutar bundle install lee este archivo e instala versiones exactas de gemas en Gemfile.lock. Ejecutar bundle exec jekyll serve inicia el servidor de desarrollo usando estas versiones bloqueadas. El ecosistema: Ruby → Bundler → Jekyll → Liquid → HTML.

Las 8 gemas que impulsan el sitio

gem "jekyll", "4.4.1"                          # Generador de sitios estáticos
group :jekyll_plugins do
  gem "jekyll-feed", "~> 0.17.0"              # Generación de feeds RSS/Atom
  gem 'jekyll-paginate', '~> 1.1'             # División de páginas para listas de blog
  gem 'jekyll-seo-tag', '~> 2.8.0'            # Metaetiquetas SEO (og:, twitter:)
  gem 'jekyll-gist', '~> 1.5.0'               # Incrustar Gists de GitHub en páginas
  gem 'jekyll-avatar', '~> 0.8.0'             # Imágenes de avatar de GitHub
  gem 'jekyll-asciidoc', '~> 3.0.1'           # Conversión AsciiDoc → HTML ⭐
  gem 'jekyll-numbered-headings', '~> 0.1.1'  # Encabezados de sección numerados automáticamente
  gem 'kramdown-parser-gfm', '~> 1.1.0'       # Analizador Markdown estilo GitHub
end
gem "webrick", "~> 1.9.0"                     # Servidor HTTP Ruby para desarrollo

jekyll-asciidoc es el plugin crítico: Sin él, los 63 archivos de documentación .adoc (installation.adoc, userguide.adoc, etc.) no se renderizarían. Esta gema puentea el templating Liquid de Jekyll con el marcado de AsciiDoc — es la razón por la que los documentos de ProjectForge pueden usar tanto {% include %} (Liquid) como == Sección == (AsciiDoc) en el mismo archivo.

Compañero Gemfile.lock: El archivo Gemfile.lock (también en site/) registra las versiones EXACTAS instaladas, incluyendo dependencias transitivas. Esto asegura compilaciones reproducibles entre máquinas. Es el equivalente Ruby de package-lock.json.

Estrategia de fijación de versiones

OperadorEjemploSignificado
Exacto"4.4.1"jekyll 4.4.1 exactamente — ninguna otra versión
Pesimista"~> 0.17.0">= 0.17.0 Y < 0.18.0 — actualizaciones de parche permitidas, menor congelado
Pesimista"~> 3.0.1">= 3.0.1 Y < 3.1.0 — para jekyll-asciidoc

Jekyll mismo está fijado a la versión EXACTA 4.4.1 — las actualizaciones mayores de Jekyll a menudo rompen temas y plugins. Los plugins usan versionado pesimista (~>) para permitir parches de seguridad sin arriesgar cambios disruptivos.

Alternativas comentadas: Las líneas 15-19 muestran el boilerplate estándar de Jekyll para GitHub Pages — descomenta la gema github-pages si alojas directamente en GitHub Pages. El sitio de ProjectForge usa una configuración Jekyll personalizada (no el Jekyll integrado de GitHub Pages), por lo que estas se dejan comentadas.
