Le manifeste des dépendances de construction. L'exécution de bundle install lit ce fichier et installe les versions exactes des gems dans Gemfile.lock. L'exécution de bundle exec jekyll serve démarre le serveur de développement en utilisant ces versions verrouillées. L'écosystème : Ruby → Bundler → Jekyll → Liquid → HTML.

Les 8 gems qui alimentent le site

gem "jekyll", "4.4.1"                          # Générateur de site statique
group :jekyll_plugins do
  gem "jekyll-feed", "~> 0.17.0"              # Génération de flux RSS/Atom
  gem 'jekyll-paginate', '~> 1.1'             # Pagination pour les listes de blog
  gem 'jekyll-seo-tag', '~> 2.8.0'            # Balises méta SEO (og:, twitter:)
  gem 'jekyll-gist', '~> 1.5.0'               # Intégration de Gists GitHub dans les pages
  gem 'jekyll-avatar', '~> 0.8.0'             # Images d'avatar GitHub
  gem 'jekyll-asciidoc', '~> 3.0.1'           # Conversion AsciiDoc → HTML ⭐
  gem 'jekyll-numbered-headings', '~> 0.1.1'  # Titres de section numérotés automatiquement
  gem 'kramdown-parser-gfm', '~> 1.1.0'       # Analyseur Markdown au format GitHub
end
gem "webrick", "~> 1.9.0"                     # Serveur HTTP Ruby pour le développement

jekyll-asciidoc est le plugin critique : Sans lui, les 63 fichiers de documentation .adoc (installation.adoc, userguide.adoc, etc.) ne s'afficheraient pas. Cette gem fait le pont entre le templating Liquid de Jekyll et le balisage AsciiDoc — c'est la raison pour laquelle la documentation de ProjectForge peut utiliser à la fois {% include %} (Liquid) et == Section == (AsciiDoc) dans le même fichier.

Compagnon Gemfile.lock : Le fichier Gemfile.lock (également dans site/) enregistre les versions EXACTES installées, y compris les dépendances transitives. Cela garantit des constructions reproductibles sur différentes machines. C'est l'équivalent Ruby de package-lock.json.

Stratégie de verrouillage des versions

OpérateurExempleSignification
Exact"4.4.1"jekyll 4.4.1 exactement — aucune autre version
Pessimiste"~> 0.17.0">= 0.17.0 ET < 0.18.0 — mises à jour de correctifs autorisées, version mineure figée
Pessimiste"~> 3.0.1">= 3.0.1 ET < 3.1.0 — pour jekyll-asciidoc

Jekyll lui-même est verrouillé sur la version EXACTE 4.4.1 — les mises à jour majeures de Jekyll cassent souvent les thèmes et les plugins. Les plugins utilisent un versionnage pessimiste (~>) pour permettre les correctifs de sécurité sans risquer de changements cassants.

Alternatives commentées : Les lignes 15-19 montrent le code standard Jekyll pour GitHub Pages — décommentez la gem github-pages si vous hébergez directement sur GitHub Pages. Le site ProjectForge utilise une configuration Jekyll personnalisée (pas le Jekyll intégré de GitHub Pages), donc celles-ci restent commentées.
