#395: I18nExportColumn.java

Java model — i18n-aware export column. Extends ExportColumn with i18nKey — the column header is resolved at export time using I18nService with the user's locale. Used by DOListExcelExporter — each column gets its header from the corresponding @PropertyInfo(i18nKey = "...") annotation on the DO field.
