site/_includes/hero.html

Incluye su propia barra de navegación. A diferencia de las páginas sin hero (que obtienen la barra de navegación de default.html), la plantilla hero incluye navbar.html en la línea 14. Esta es la razón por la que default.html tiene la condición: "si hero, omitir barra de navegación". La barra de navegación se renderiza DENTRO de la superposición del hero, dándole un fondo transparente que se mezcla con la imagen del hero.

Sistema de imagen de fondo — dos fuentes

{% if page.header.image %}
  {% assign image = page.header.image %}     // De los metadatos de la página
{% endif %}
// Alternativa: usa page.hero.image si header.image no está configurado

<header style="background-image: url({{ image }});">  // CSS en línea
  <div style="background: {{ page.header.overlay }};">  // Superposición de color

El hero tiene DOS fuentes posibles de imagen de fondo:

FuenteClave de metadatosUtilizado por
Imagen de cabecerapage.header.imageEntradas de blog, entradas de changelog — fondo específico de cabecera
Imagen heropage.hero.imagePáginas de documentación — la ilustración de la sección hero (ej., search.png)

Las URL se resuelven mediante {% if image contains 'http' %} — las imágenes externas usan URL absolutas, las imágenes internas tienen {{ site.uploads | absolute_url }} antepuesto. La superposición se aplica como un color semitransparente sobre la imagen para la legibilidad del texto.

Animación Scrollspy — efecto de entrada

data-uk-scrollspy="cls: uk-animation-slide-bottom-medium; repeat: true"

El contenido del hero (título, subtítulo) se desliza hacia arriba desde la parte inferior cuando el usuario se desplaza hacia él. repeat: true significa que la animación se reproduce cada vez que el elemento entra en el viewport, no solo una vez. Esto es un pulido sutil de UX: en páginas largas, regresar al hero reactiva la animación.

uk-animation-slide-bottom-medium es una clase de animación de UIkit: los elementos comienzan 50 píxeles por debajo de su posición final y se deslizan hacia arriba con una transición de duración media. Esto está tematizado por animation.scss (#4028).

Barra de búsqueda — SimpleJekyllSearch (igual que la barra de navegación)

La barra de búsqueda del hero es idéntica a la búsqueda de la barra de navegación (#3905) — misma librería (SimpleJekyllSearch), misma fuente de datos (search.json), misma función personalizada searchResults(). La única diferencia: la búsqueda del hero usa id="search-hero" en lugar de id="search-navbar", y solo se renderiza cuando page.hero.search es verdadero.

En la página de inicio: search: false — no hay barra de búsqueda en el hero. La propuesta de valor es más fuerte sin un campo de búsqueda compitiendo por la atención.

En la página de búsqueda (#4093): search: true — la barra de búsqueda ES el propósito del hero. El hero proporciona el contexto visual para la experiencia de búsqueda.
