#4014: hero.html

site/_includes/hero.html

Путь: site/_includes/hero.html · Строк: 56 · Тип: Jekyll Liquid include

Назначение: Отображает hero-баннер в верхней части ключевых страниц — фоновое изображение на всю ширину с наложением, заголовок страницы, подзаголовок, опциональное hero-изображение и опциональную строку поиска SimpleJekyllSearch. Используется на главной странице, странице поиска и на любой странице с front matter hero:.

Включает собственную навигационную панель. В отличие от страниц без hero (которые получают навбар из default.html), шаблон hero включает navbar.html в строке 14. Именно поэтому в default.html есть условие: "если hero, пропустить навбар". Навбар отображается ВНУТРИ наложения hero, что даёт ему прозрачный фон, сливающийся с изображением hero.

Система фоновых изображений — два источника

{% if page.header.image %}
  {% assign image = page.header.image %}     // Из front matter страницы
{% endif %}
// Запасной вариант: использует page.hero.image, если header.image не задан

<header style="background-image: url({{ image }});">  // Встроенный CSS
  <div style="background: {{ page.header.overlay }};">  // Цветовое наложение

Hero имеет ДВА возможных источника фонового изображения:

ИсточникКлюч front matterИспользуется
Изображение заголовкаpage.header.imageЗаписи блога, записи журнала изменений — фон, специфичный для заголовка
Hero-изображениеpage.hero.imageСтраницы документации — иллюстрация секции hero (например, search.png)

URL-адреса разрешаются через {% if image contains 'http' %} — внешние изображения используют абсолютные URL, внутренние получают префикс {{ site.uploads | absolute_url }}. Наложение применяется как полупрозрачный цвет поверх изображения для улучшения читаемости текста.

Анимация Scrollspy — эффект появления

data-uk-scrollspy="cls: uk-animation-slide-bottom-medium; repeat: true"

Содержимое hero (заголовок, подзаголовок) выезжает снизу вверх, когда пользователь прокручивает до него. repeat: true означает, что анимация воспроизводится каждый раз, когда элемент попадает в область просмотра — а не только один раз. Это тонкая полировка UX: на длинных страницах возвращение к hero повторно запускает анимацию.

uk-animation-slide-bottom-medium — это класс анимации UIkit: элементы начинают движение на 50 пикселей ниже своего конечного положения и выезжают вверх с переходом средней длительности. Тема оформляется через animation.scss (#4028).

Строка поиска — SimpleJekyllSearch (как в навбаре)

Строка поиска в hero идентична поиску в навбаре (#3905) — та же библиотека (SimpleJekyllSearch), тот же источник данных (search.json), та же пользовательская функция searchResults(). Единственное отличие: поиск в hero использует id="search-hero" вместо id="search-navbar" и отображается только когда page.hero.search истинно.

На главной странице: search: false — строка поиска в hero отсутствует. Ценностное предложение сильнее без конкурирующего поля поиска.

На странице поиска (#4093): search: true — строка поиска и есть цель hero. Hero обеспечивает визуальный контекст для процесса поиска.
