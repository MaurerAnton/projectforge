#402: AuftragUIStatus.java

Java enum — order UI status: NONE, IN_WORK, INQUIRY, PROSPECTIVE. Display-only enum — maps to visual indicators on the order list page. Not stored in DB — computed at display time from order state + invoicing status + project assignment. A UI-only concept separate from AuftragsStatus (#901).
