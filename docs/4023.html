#4023: mixins.scss

SCSS Component, projectforge-webapp/src/assets/style/mixins.scss
This file is the core counterpart to mixins-theme.scss (#4024). It defines empty hook mixins for all components plus the complete inverse component implementations. While mixins-theme.scss contains visual styling, this file provides the architectural scaffolding that makes the hook system work even when no theme is loaded.
