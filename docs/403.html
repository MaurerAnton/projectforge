#403: EmployeeSalaryExportDao.java

Java DAO — DATEV salary export queries. Extends BaseDao. Provides methods for aggregating employee salary data for DATEV export: salary per employee per month, total costs by cost center, employer contributions (social security). Used by DatevImportService (#909) and the DATEV salary Excel export.
