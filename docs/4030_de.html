Was es tut

Jekyll Liquid-Include-Partial. Rendert eine wiederverwendbare UI-Komponente auf Seiten, die {% include related-posts.html %} aufrufen. Teil des komponentenbasierten Seitenaufbausystems. Wird von anderen Vorlagen über das Liquid-include-Tag eingebunden. Wird als Teil des Seitenaufbausystems gerendert, bei dem das Standard-Layout (#3923) Includes, Layouts und Inhalte zum endgültigen HTML zusammenfügt.

Wichtige Erkenntnisse

  • Hinzugefügt: ac75fabf3 (2021-08-10) während der Migration der Jekyll-Site von HTML zu AsciiDoc.
  • Rolle im Aufbau: Teil der wiederverwendbaren Komponentenbibliothek. Eine Änderung dieser Datei betrifft ALLE Seiten, die sie einbinden.
