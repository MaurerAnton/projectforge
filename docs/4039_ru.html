Корень дерева наследования шаблонов. Все остальные шаблоны (page.html, doc.html, post.html, changelog.html) объявляют layout: default в своей front matter, что означает, что их вывод вставляется в {{ content }} на строке 14 этого файла. Это дно цепочки наследования — он выводит итоговый HTML-документ.

Полный жизненный цикл страницы — 12 включений по порядку

1. {% include head.html %}               // <meta>, <title>, CSS, JS (в <head>)
2. {% include hero.html %} ИЛИ navbar      // Условно: секция героя или обычный навбар
3. {{ content }}                          // Контент конкретной страницы (из дочернего шаблона)
4. {% include offcanvas-docs.html %}      // Мобильная панель меню документации
5. {% include offcanvas.html %}           // Мобильная панель меню сайта
6. {% include footer.html %}              // Условно: только если НЕ шаблон doc
7. {% include hook-pre-closing-body-doc.html %}  // Условно: только для шаблона doc
8. {% include hook-pre-closing-body.html %}      // Всегда: глобальные скрипты перед </body>

Порядок важен — offcanvas-панели должны быть после контента (они имеют position:fixed и перекрывают), подвал условно скрывается для страниц документации, а hook-включения вставляются непосредственно перед </body> для производительности (скрипты в конце body).

Система хуков — расширяемость без редактирования шаблонов

Три включения hook-*.html — это версия Jekyll для хуков WordPress — точки вставки, где плагины или типы страниц могут добавлять скрипты/стили без изменения шаблона:

ХукТочка вставкиИспользуется
hook-head.htmlВнутри <head> (через head.html)Специфичные для страницы CSS, мета-теги
hook-post-content-doc.htmlПосле контента, только страницы docСкрипты после контента для doc
hook-pre-closing-body.htmlПеред </body>, всегдаГлобальный JS: аналитика, инициализация поиска, инициализация UIkit
hook-pre-closing-body-doc.htmlПеред </body>, только страницы docСпецифичный для doc JS: scroll spy оглавления, клавиатурная навигация пред./след.

Это та же архитектурная схема, что и система хуков/миксинов UIkit в SCSS (#4061) — пустые точки расширения, которые дочерние шаблоны могут реализовать без изменения родительского.
