#404: EingangsrechnungListFilter.java

Java filter — incoming invoice list filter. Extends BaseSearchFilter with: creditor (supplier name), paidStatus (PAID/UNPAID), dateFrom/dateTo, kontoId (general ledger account), kost1Id (cost center), kost2Id (cost item), searchString. One of the richer filter classes in the fibu module.
