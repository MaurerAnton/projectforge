#405: EingangsrechnungsStatistik.java

Java statistics — aggregates incoming invoice data: totalGross, paidGross, unpaidGross, overdueGross, count, overdueCount. Similar to AuftragsStatistik (#882) but for supplier invoices. Used by the dashboard and liquidity planning to show how much we owe suppliers.
