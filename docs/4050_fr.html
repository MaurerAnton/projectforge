<h1>
	System Font CSS
</h1>

<p>
	System Font CSS est un ensemble de règles <code>@font-face</code> qui vous permettent d'utiliser la police système native du système d'exploitation exécutant le navigateur.
</p>

<pre>
<span class="token-selector">body</span> {
    <span class="token-property-name">font-family</span>: <span class="token-property-value">system</span>;
}
</pre>

<p>
	<a href="https://github.com/jonathantneal/system-font-css">system-font.css</a> propose huit variantes de la famille de polices <code>system</code> ; <strong>light</strong> (300) <strong>light italic</strong>, <strong>normal</strong> (400), <strong>normal italic</strong>, <strong>medium</strong>
