Utilities MÜSSEN zuletzt geladen werden. Dies ist beabsichtigt — CSS-Utility-Klassen (.uk-margin, .uk-text-center, .uk-hidden@m) benötigen maximale Spezifität, um jeden Komponentenstil zu überschreiben. Wenn sie zuletzt geladen werden, gewinnen sie in der Kaskade immer.

Die 16 Importe — geordnet nach Spezifität

@import "animation.scss";    // Ein-, Ausblenden, Schieben, Skalieren Keyframes
@import "width.scss";        // .uk-width-1-2, .uk-child-width-1-3
@import "text.scss";         // .uk-text-center, .uk-text-bold, .uk-text-muted
@import "column.scss";       // CSS-Mehrspalten-Layout

@import "print.scss";        // GANZ ZULETZT — muss ALLE Bildschirm-Stile überschreiben

Die Import-Reihenfolge ist NICHT alphabetisch — sie ist beabsichtigt:

  • flex.scss nach utility.scss (Zeile 10): Der Kommentar sagt „Nach: Utility“ — Flex-Ausrichtungs-Klassen benötigen höhere Spezifität als generische Utilities. Wenn sowohl .uk-flex als auch eine Utility-Klasse display setzen, muss Flex gewinnen.
  • print.scss GANZ ZULETZT (Zeile 19): Der Kommentar „Muss zuletzt geladen werden“ ist entscheidend. Druckstile verwenden @media print-Abfragen, die ALLE Bildschirmstile überschreiben müssen. Wenn sie früher geladen würden, würde eine spätere Bildschirmstil-Regel mit gleicher Spezifität gewinnen. Das Laden zuletzt stellt sicher, dass Druckregeln Kaskaden-Priorität haben.
  • margin.scss und padding.scss vor position.scss: Abstands-Utilities sollten verfügbar sein, bevor Positionierungs-Utilities geladen werden, die möglicherweise auf Abstands-/Innenabstandswerte verweisen.
