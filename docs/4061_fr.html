Les utilitaires DOIVENT être chargés en dernier. C'est une décision de conception — les classes CSS utilitaires (.uk-margin, .uk-text-center, .uk-hidden@m) nécessitent une spécificité maximale pour remplacer tout style de composant. Les charger en dernier garantit qu'elles l'emportent toujours dans la cascade.

Les 16 importations — ordonnées pour la spécificité

@import "animation.scss";    // Images clés de fondu, glissement, zoom
@import "width.scss";        // .uk-width-1-2, .uk-child-width-1-3
@import "text.scss";         // .uk-text-center, .uk-text-bold, .uk-text-muted
@import "column.scss";       // Disposition multi-colonnes CSS
@import "cover.scss";        // Couverture d'arrière-plan plein écran
@import "background.scss";   // .uk-background-primary, .uk-background-muted
@import "align.scss";        // Utilitaires d'alignement vertical
@import "utility.scss";      // Utilitaires divers (clearfix, etc.)
@import "flex.scss";         // Alignement flex — APRÈS utility pour la priorité de remplacement
@import "margin.scss";       // .uk-margin, .uk-margin-small, marges responsives
@import "padding.scss";      // .uk-padding, .uk-padding-small
@import "position.scss";     // .uk-position-top, .uk-position-center
@import "transition.scss";   // Classes utilitaires de transition
@import "visibility.scss";   // .uk-visible@s, .uk-hidden@m — visibilité responsive
@import "inverse.scss";      // Remplacements de couleurs pour le mode sombre
@import "print.scss";        // EN DERNIER — doit remplacer TOUS les styles d'écran

L'ordre d'importation n'est PAS alphabétique — il est intentionnel :

  • flex.scss après utility.scss (ligne 10) : Le commentaire dit « Après : Utility » — les classes d'alignement flex ont besoin d'une spécificité plus élevée que les utilitaires génériques. Si à la fois .uk-flex et une classe utilitaire définissent display, flex doit l'emporter.
  • print.scss EN DERNIER (ligne 19) : Le commentaire « Doit être chargé en dernier » est crucial. Les styles d'impression utilisent des requêtes @media print qui doivent remplacer TOUS les styles d'écran. S'il était chargé plus tôt, une règle de style d'écran ultérieure avec une spécificité égale l'emporterait. Le charger en dernier garantit que les règles d'impression ont la priorité dans la cascade.
  • margin.scss et padding.scss avant position.scss : Les utilitaires d'espacement doivent être disponibles avant les utilitaires de positionnement, qui peuvent référencer les valeurs de marge/remplissage.
