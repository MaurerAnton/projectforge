Утилиты ДОЛЖНЫ загружаться последними. Это сделано намеренно — CSS-утилиты (.uk-margin, .uk-text-center, .uk-hidden@m) требуют максимальной специфичности для переопределения любых стилей компонентов. Загрузка их последними гарантирует, что они всегда выигрывают в каскаде.

16 импортов — упорядочены по специфичности

@import "animation.scss";    // Ключевые кадры: затухание, слайд, масштаб
@import "width.scss";        // .uk-width-1-2, .uk-child-width-1-3
@import "text.scss";         // .uk-text-center, .uk-text-bold, .uk-text-muted
@import "column.scss";       // CSS-макет с несколькими колонками

@import "background.scss";   // .uk-background-primary, .uk-background-muted
@import "align.scss";        // Утилиты вертикального выравнивания
@import "utility.scss";      // Разные утилиты (clearfix и т.д.)
@import "flex.scss";         // Flex-выравнивание — ПОСЛЕ utility для приоритета переопределения
@import "margin.scss";       // .uk-margin, .uk-margin-small, адаптивные отступы

@import "inverse.scss";      // Переопределения цветов для тёмной темы
@import "print.scss";        // САМЫЙ ПОСЛЕДНИЙ — должен переопределять ВСЕ экранные стили

Порядок импорта НЕ алфавитный — он намеренный:

  • flex.scss после utility.scss (строка 10): Комментарий гласит «После: Utility» — классы flex-выравнивания требуют более высокой специфичности, чем общие утилиты. Если и .uk-flex, и утилитный класс задают display, flex должен победить.
  • print.scss САМЫЙ ПОСЛЕДНИЙ (строка 19): Комментарий «Должен загружаться последним» критически важен. Стили печати используют запросы @media print, которые должны переопределять ВСЕ экранные стили. Если загрузить раньше, более позднее правило экранного стиля с равной специфичностью победит. Загрузка последним гарантирует приоритет правил печати в каскаде.
  • margin.scss и padding.scss перед position.scss: Утилиты интервалов должны быть доступны до утилит позиционирования, которые могут ссылаться на значения отступов/полей.
