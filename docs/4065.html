Two color variants: default (transparent) and primary (brand-color tint). Screenshot captions in the user guide use position overlay — semi-transparent black (rgba(0,0,0,0.5)) at image bottom for readable white caption text. Hero image darkening uses cover overlay. Icon overlay controls the magnifying glass/link icon on gallery hover.
