Position utilities handle position: absolute, top/left/right/bottom, transform: translate() for centering, and z-index layering. These are pure layout — no colors, no shadows. The hook is for edge cases (e.g., adding a background tint to fixed backdrops). If you're styling something positional, you likely want overlay or sticky instead.
