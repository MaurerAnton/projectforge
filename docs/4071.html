$search-default-background:   transparent !default;     // No fill — page shows through
$search-default-border-width: $global-border-width !default; // Visible border
$search-default-border:       $global-border !default;      // Subtle gray border

Transparent background is a deliberate design choice — the search field feels integrated with the page rather than being a distinct "form element." The visible border provides discoverability ("you can type here") while the transparent background keeps it unobtrusive. The hero section on /search/ uses a background image — a solid search box would look like a sticker on top.

Three size variants: Default (search page), Navbar (in top bar), Large (hero sections). Each with separate hooks. Toggle variant: magnifying glass icon that expands to input on click — space-saving for mobile nav.

Inverse: Even on dark backgrounds ($inverse-search-default-background: transparent), stays transparent — important for hero sections with background images.
