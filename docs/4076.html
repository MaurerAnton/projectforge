Purpose: Themes sticky-positioned elements — the visual state transition when navbars/sidebars become "stuck" to the viewport during scroll. Single hook for the shadow/background that appears when an element transitions from normal flow to position: fixed.

Source: GitHub

ac75fabf3Github pages migrated to Asciidoc

JavaScript-driven: UIkit's Scrollspy detects scroll position and adds .uk-sticky-fixed class. The single hook hook-sticky() provides CSS for the "stuck" state. Without implementation, the navbar transitions silently — no shadow, no background change. To add a subtle shadow when the navbar sticks (standard UX), implement: @mixin hook-sticky(){ box-shadow: 0 2px 8px rgba(0,0,0,0.15); }. Currently all styles are core defaults.
