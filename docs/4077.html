Pill modifier: .uk-subnav-pill gets 4 dedicated hooks — more than default subnav — because it transforms links into button-like "pills" with background colors, hover effects, and click feedback. This is fundamentally different visual treatment than the text-only default style. The -onclick hook is unusual — most components only have hover/active, but pills get a momentary "pressed" state like a real button.
