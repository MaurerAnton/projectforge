Core, no tema. Este archivo contiene reglas CSS reales (no solo hooks o variables). Define el CSS estructural para el componente Cover. La contraparte de tema en site/_sass/uikit/theme/ agregaría estilo visual — pero NO existe theme/cover.scss en el sitio ProjectForge. El cover usa los valores predeterminados de UIkit para su apariencia.

La técnica de centrado — un clásico de CSS

.uk-cover {
  max-width: none;                           // 1. Eliminar límite de ancho responsivo
  position: absolute;                        // 2. Sacar del flujo del documento
  left: 50%; top: 50%;                       // 3. Posicionar esquina superior izquierda en el centro
  transform: translate(-50%, -50%);          // 4. Desplazar hacia atrás la mitad del ancho/alto
}

.uk-cover-container {
  overflow: hidden;                          // Recortar contenido que excede el contenedor
  position: relative;                        // Establecer contexto de posicionamiento para .uk-cover
}

iframe.uk-cover { pointer-events: none; }    // Los clics pasan al padre

Línea por línea del truco de centrado:

  1. max-width: none: Elimina cualquier restricción de ancho responsivo. El elemento cover debe ser libre de expandirse para cubrir el contenedor, incluso si excede el ancho de la ventana gráfica.
  2. position: absolute: Saca el elemento del flujo normal del documento. Esto es necesario para que left/top funcionen, y necesita que el contenedor padre tenga position: relative (línea 47).
  3. left: 50%; top: 50%: Posiciona la esquina SUPERIOR IZQUIERDA del elemento en el centro del contenedor. En este punto, el elemento está desplazado — su esquina superior izquierda está centrada, no el elemento en sí.
  4. transform: translate(-50%, -50%): Desplaza el elemento HACIA ATRÁS la mitad de su propio ancho y alto. El resultado: el CENTRO del elemento está ahora en el centro del contenedor. Esto funciona porque los valores porcentuales en translate() se refieren a las dimensiones del propio elemento, no a las del padre.

Este es posiblemente el patrón de centrado CSS más famoso. Utilizado en el sitio de ProjectForge para imágenes de fondo hero — los encabezados de página de documentación con fotos de fondo.

Cómo las secciones hero usan esto

En el sitio de ProjectForge, los heroes de las páginas de documentación se renderizan como:

<div class="uk-cover-container">
  <img src="search.png" data-uk-cover>    <!-- Esto se convierte en .uk-cover -->
  <div class="uk-position-relative">        <!-- El contenido se sitúa encima -->
    <h1>Search</h1>
  </div>
</div>

El JavaScript de UIkit agrega la clase .uk-cover y calcula las dimensiones dinámicamente. El CSS de este archivo proporciona el posicionamiento. El overflow: hidden en el contenedor asegura que la imagen de portada no se desborde si es más grande que el contenedor.

Conclusiones clave

  • Core, no tema: Esto es CSS de diseño puro. Sin colores, sin sombras — solo matemáticas de posicionamiento.
  • Truco de pointer-events en iframe (línea 33): pointer-events: none en iframes evita que el iframe capture clics. Esencial para videos incrustados de YouTube/Vimeo usados como fondos — los usuarios deben poder interactuar con el contenido SOBRE el video.
  • Sin contraparte de tema: A diferencia de la mayoría de los componentes de UIkit que tienen archivos core y de tema, Cover no tiene theme/cover.scss. Todo su estilo visual proviene del contenido en sí (la imagen) y de los componentes de tile/section que lo envuelven.
  • Dependencia de JavaScript: El atributo data-uk-cover activa el JS de UIkit para medir el contenedor y establecer las dimensiones apropiadas. El CSS solo no logra que cubra — necesita el JS para el tamaño dinámico.
