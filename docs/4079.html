Key variables

$tab-border:              $global-border !default;              // Container bottom border
$tab-item-text-transform:  uppercase !default;                   // FOURTH uppercase component!
$tab-item-active-border:   $global-primary-background !default;  // Brand-color active underline

Fourth UPPERCASE component: Tab labels use the same uppercase+small-font pattern as navbar (#4061), subnav (#4077), and button (#4034). All four must stay consistent — changing one breaks visual coherence.

Active = brand color: The currently-selected tab gets a bottom border in $global-primary-background — ProjectForge's accent color. This directly ties tab interactivity to brand identity. Without this override, the active indicator would use a muted default.

Two borders: $tab-border (full-width, separates tabs from content) and $tab-item-active-border (per-item, highlights selected tab). Same width ($global-border-width, 1px), different colors.
