This file controls the entire typographic experience of the ProjectForge documentation. With 1508-line user guides and 1326-line admin guides, typography decisions here directly affect readability: heading hierarchy determines how users scan long documents, lead paragraphs set the tone of introduction sections, meta text distinguishes dates/authors from body content, and code block styling affects the readability of hundreds of inline code references and syntax-highlighted blocks. The muted header style (small, normal-weight, gray) from table.scss (#4078) is complemented by heading styles defined here — together they create the complete text hierarchy.
