Purpose: Themes full-width colored horizontal bands that divide page sections — hero banners on documentation pages, call-to-action sections, feature highlights, and the site footer. Unlike sections (content-width), tiles span the entire viewport.

Tiles are the visual backbone of page structure. Three color variants: .uk-tile-primary (brand color — used for hero sections like "/search/" with the search icon background), .uk-tile-secondary (dark sections), .uk-tile-muted (light gray). Each gets large vertical padding (60-80px) for breathing room between content sections. Typography inside tiles adjusts for contrast — light text on dark tiles, dark text on light tiles. Hero images (search.png, defined in Jekyll front matter like hero.image: search.png in #4093) are combined with tile backgrounds for visual impact. Imported in Layer 3 (Layout) of _import.scss (#4052) — after grid and container, before cards.
