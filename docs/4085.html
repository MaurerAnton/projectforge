Purpose: Themes CSS transitions for all animated elements — fade, slide, scale effects on modals, dropdowns, tooltips, offcanvas panels, and notification banners. Controls easing curves, durations, and visual properties of entering/exiting elements.

Source: GitHub

Transitions are JavaScript-driven — UIkit's JS adds/removes CSS classes (.uk-transition-fade, .uk-transition-slide-*), and this file provides the CSS that makes those classes visually effective. Used everywhere on the ProjectForge site: dropdown menus fade in, the mobile offcanvas slides from the left, modals scale up from center, notification banners slide down from the top. All use GPU-accelerated properties (opacity, transform) for smooth 60fps animation. Imported in Layer 7 (Utilities) of _import.scss (#4052) — loaded last alongside other utilities.
