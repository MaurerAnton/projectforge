Path: site/_sass/uikit/theme/utility.scss · Type: SCSS theme partial · UIkit global utility classes theming

Purpose: Theme extension for UIkit's broadest category of CSS helpers — .uk-text-* (text colors), .uk-background-* (backgrounds), .uk-padding-*, .uk-margin-*, .uk-visible-*, .uk-hidden-*, .uk-border-*. Unlike component-specific theme files that target one component, this file themes utilities used across every page.
