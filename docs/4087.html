Three variables.scss files exist: Don't confuse this with _sass/uikit/variables.scss (#4091) or _sass/uikit/components/variables.scss (#4020). This one specifically serves the theme layer — imported by _import.scss (#4052) as the very first file (Layer 1: Base), before any component theme file.

This file defines variables prefixed with $theme-* that are used ONLY by theme/*.scss files. It sits in the import chain between the core variables (which define $global-*) and the individual theme components (which reference both). Variables here can override core defaults or introduce new theme-only tokens. The separation prevents theme-specific variables from leaking into core components — a key architectural principle of UIkit's theming system.
