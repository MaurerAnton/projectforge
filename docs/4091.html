The global design token registry

This file is the single source of truth for all design tokens used on the ProjectForge website. It defines approximately 200+ SCSS variables organized by category:

CategoryKey variablesControls
Breakpoints$breakpoint-small (640px), -medium (960px), -large (1200px), -xlarge (1600px)When responsive layouts switch between mobile/tablet/desktop
Colors$global-primary-background, -secondary, -success, -warning, -danger, -muted, -emphasisBrand colors + semantic state colors + text hierarchy
Typography$global-font-family, $global-font-size, $global-line-height, $h1-font-size through $h6Every text element on the site
Spacing$global-margin, $global-gutter, $global-small-margin, -medium, -largePadding/margin utility classes, card padding, section spacing
Z-indices$z-index-tooltip, -modal, -offcanvasStacking order — ensures dropdowns appear above content, modals above dropdowns

Import chain position: This is imported FIRST by uikit-theme.scss (#4090), before variables-theme.scss (#4092). Core variables establish baseline values; theme variables selectively override them with ProjectForge's brand. Individual component SCSS files are imported last and inherit whichever values are current.

Key takeaways

  • Do NOT edit directly: Customize in variables-theme.scss (#4092), not here. This file should stay close to upstream UIkit for clean upgrades.
  • Import order is critical: Core variables → theme overrides → components. Reordering breaks the cascade.
  • Responsive foundations: The 4 breakpoints defined here control the entire site's responsive behavior. Changing $breakpoint-medium from 960px affects every component.
