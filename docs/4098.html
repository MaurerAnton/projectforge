Operational runbooks — tribal knowledge codified

The operational section is the most valuable part for new developers. It contains:

  • Fast PostgreSQL imports (lines 64-74): ALTER SYSTEM SET fsync = off; ALTER SYSTEM SET synchronous_commit = off; — sacrifices durability for import speed. These settings MUST be reverted after import.
  • Standard dev password (line 84): SHA{BC871652288E56E306CFA093BEFC3FFCD0ED8872} = test123. Used everywhere — SQL examples, Docker setup, CI scripts.
  • Calendar cleanup (line 86): update t_calendar set ext_subscription=false — prevents mass API calls to external calendars when using production data for development.
  • Rancher cleanup (lines 55-62): docker system prune -a --volumes — complete Docker garbage collection. Dangerous in production, essential in dev.
