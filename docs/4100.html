Only 4 lines — significantly shorter than the production config because it inherits almost everything from the root local-settings.properties via the include directive. The sole purpose is switching the data source from postgres to postgres2.

The postgres2 convention: The ProjectForge team maintains two PostgreSQL databases: postgres (primary development, holds current data) and postgres2 (clean/disposable, used for import tests). The FromXmlTest (#4106) also uses postgres2 via a runtime system property override. This config file is a template/alternative — developers use it by either (1) renaming it to local-settings.properties or (2) running their IDE with this file as the active config.

Lines 2 and 4: Commented-out alternatives serve as documentation. Developers can switch data sources by commenting/uncommenting single lines rather than remembering property names.
