Line 1: The include=../../local-settings.properties directive is the Genome framework's property inheritance mechanism. It navigates two directories up from tools/org.projectforge.tools.schemaexp/ to the repository root, loading the parent config which contains JDBC connection URLs, database credentials, and shared Hibernate settings. This avoids duplicating credentials across tool config files.

Line 3: projectForgeDs=postgres — the key that differentiates this file from the dev config (#4100 which uses postgres2). This tells Spring which DataSource bean to inject.

Lines 6-11: Hibernate and ProjectForge settings. All paths are under ./target/SchemaExport/ — Maven's clean goal resets everything. The hbm2ddl.auto=update is commented out because the SchemaExp tool handles schema explicitly through clearDb() — automatic updates could cause unexpected schema changes during export/import.
