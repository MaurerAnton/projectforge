Ruta: site/_sass/uikit/theme/navbar.scss · Líneas: 136 · Variables activas: 12 · Placeholders de hooks: 25

Propósito: Tema la barra de navegación principal — el componente de interfaz más visible. Controla: elementos de navegación en MAYÚSCULAS con fuente pequeña, menús desplegables con padding de 25px y sombra con desenfoque de 12px, separación de 15px entre la navegación y el menú desplegable, divisores de cuadrícula en el menú desplegable y sombra de la barra desplegable. LOS 25 hooks mixins están comentados — el estilo se logra únicamente mediante la sobrescritura de variables.

Sistema de variables — 12 sobrescrituras activas

$navbar-nav-item-font-size:         $global-small-font-size !default;     // Etiquetas de navegación pequeñas
$navbar-nav-item-text-transform:    uppercase !default;                   // Marcas en MAYÚSCULAS
$navbar-dropdown-margin:            15px !default;                        // Separación: nav → menú desplegable
$navbar-dropdown-padding:           25px !default;                        // Menús desplegables espaciosos
$navbar-dropdown-box-shadow:        0 5px 12px rgba(0,0,0,0.15) !default; // Efecto flotante
$navbar-dropbar-box-shadow:         0 5px 7px rgba(0,0,0,0.05) !default;  // Barra desplegable sutil
$navbar-dropdown-grid-divider-border-width: $global-border-width !default;

Los 25 hooks mixins están comentados — esto es una SEÑAL de diseño limpio. La barra de navegación logra toda su apariencia de marca únicamente a través de variables SCSS. No se necesitan reglas CSS personalizadas. Categorías de hooks: Componente (nivel superior), Contenedor (div envolvente), Elementos de navegación (estados hover/onclick/activo), Alternar (hamburguesa móvil — 4 hooks incluido el icono), Menú desplegable (4 hooks para elementos/encabezados/divisores dentro del menú desplegable), Inverso (6 hooks para modo oscuro — ninguno implementado).

Sistema de sombras: Los menús desplegables obtienen 0 5px 12px rgba(0,0,0,0.15) — el desenfoque de 12px crea un efecto "flotante" suave. El desplazamiento vertical de 5px coincide con la separación del margen de 15px, colocando el pico de la sombra justo entre la navegación y el menú desplegable. Esto crea la ilusión de que el menú desplegable flota sobre el contenido de la página — un patrón estándar de material design.
