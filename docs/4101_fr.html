#4101 : navbar.scss

site/_sass/uikit/components/navbar.scss

Chemin : site/_sass/uikit/theme/navbar.scss · Lignes : 136 · Variables actives : 12 · Emplacements de crochets : 25

Objectif : Thématise la barre de navigation principale — le composant d'interface le plus visible. Contrôle : éléments de navigation en MAJUSCULES avec petite police, menus déroulants avec padding de 25px et ombre floutée de 12px, espacement de 15px entre la navigation et le menu déroulant, séparateurs de grille dans les menus déroulants, et ombre de la barre déroulante. TOUS les 25 crochets de mixins sont commentés — le style est obtenu uniquement par des surcharges de variables.

Système de variables — 12 surcharges actives

$navbar-nav-item-font-size:         $global-small-font-size !default;     // Petites étiquettes de navigation
$navbar-nav-item-text-transform:    uppercase !default;                   // MARQUE EN MAJUSCULES
$navbar-dropdown-margin:            15px !default;                        // Espacement : navigation → menu déroulant
$navbar-dropdown-padding:           25px !default;                        // Menus déroulants spacieux
$navbar-dropdown-box-shadow:        0 5px 12px rgba(0,0,0,0.15) !default; // Effet flottant
$navbar-dropbar-box-shadow:         0 5px 7px rgba(0,0,0,0.05) !default;  // Barre déroulante subtile
$navbar-dropdown-grid-divider-border-width: $global-border-width !default;

25 crochets de mixins tous commentés — c'est un SIGNE de conception propre. La barre de navigation obtient toute son apparence de marque uniquement via les variables SCSS. Aucune règle CSS personnalisée nécessaire. Catégories de crochets : Composant (niveau supérieur), Conteneur (div englobant), Éléments de navigation (états survol/clic/actif), Bascule (hamburger mobile — 4 crochets incluant l'icône), Menu déroulant (4 crochets pour éléments/en-têtes/séparateurs dans les menus déroulants), Inverse (6 crochets pour le mode sombre — aucun implémenté).

Système d'ombres : Les menus déroulants reçoivent 0 5px 12px rgba(0,0,0,0.15) — le flou de 12px crée un effet "flottant" doux. Le décalage vertical de 5px correspond à l'espacement de marge de 15px, plaçant le pic de l'ombre juste entre la navigation et le menu déroulant. Cela crée l'illusion que le menu déroulant flotte au-dessus du contenu de la page — un motif standard de Material Design.
