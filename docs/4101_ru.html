Путь: site/_sass/uikit/theme/navbar.scss · Строк: 136 · Активных переменных: 12 · Хуков-заполнителей: 25

Назначение: Темизация основной панели навигации — самого заметного UI-компонента. Управляет: пунктами навигации в ВЕРХНЕМ РЕГИСТРЕ мелким шрифтом, выпадающими меню с отступом 25px и тенью с размытием 12px, зазором 15px между навигацией и выпадающим меню, разделителями сетки выпадающих меню и тенью дропбара. ВСЕ 25 хуков-миксинов закомментированы — стилизация достигается исключительно переопределением переменных.

Система переменных — 12 активных переопределений

$navbar-nav-item-font-size:         $global-small-font-size !default;     // Мелкие подписи навигации
$navbar-nav-item-text-transform:    uppercase !default;                   // БРЕНДИРОВАНИЕ ЗАГЛАВНЫМИ
$navbar-dropdown-margin:            15px !default;                        // Зазор: навигация→выпадающее меню
$navbar-dropdown-padding:           25px !default;                        // Просторные выпадающие меню
$navbar-dropdown-box-shadow:        0 5px 12px rgba(0,0,0,0.15) !default; // Эффект парения
$navbar-dropbar-box-shadow:         0 5px 7px rgba(0,0,0,0.05) !default;  // Тонкая тень дропбара
$navbar-dropdown-grid-divider-border-width: $global-border-width !default;

25 хуков-миксинов полностью закомментированы — это ПРИЗНАК чистого дизайна. Панель навигации достигает всего фирменного вида исключительно через SCSS-переменные. Никаких пользовательских CSS-правил не требуется. Категории хуков: Компонент (верхний уровень), Контейнер (обёртка div), Элементы навигации (состояния наведения/клика/активности), Переключатель (мобильное гамбургер-меню — 4 хука, включая иконку), Выпадающее меню (4 хука для элементов/заголовков/разделителей внутри выпадающего меню), Инверсный (6 хуков для тёмной темы — не реализованы).

Система теней: Выпадающие меню получают 0 5px 12px rgba(0,0,0,0.15) — размытие 12px создаёт мягкий эффект «парения». Вертикальное смещение 5px соответствует зазору 15px, размещая пик тени прямо между навигацией и выпадающим меню. Это создаёт иллюзию парения выпадающего меню над содержимым страницы — стандартный паттерн material-дизайна.
