Définitions globales de mixins. Toutes les définitions @mixin hook-*() sont déclarées ici comme mixins vides. Chaque fichier de thème référence ces hooks. C'est le pont entre les composants principaux (qui appellent les hooks) et les fichiers de thème (qui les implémentent).

Ce qu'il fait

MIXINS DE THÈME GLOBAL — définit TOUTES les définitions @mixin hook-*(). Tous les hooks des fichiers de thème sont déclarés ici sous forme de mixins vides. Fichier architectural critique importé avant tout composant de thème. Fait partie de l'intégration du framework CSS UIkit pour le site de documentation ProjectForge.

Chaîne d'importation

Flux de compilation : assets/css/main.scss → uikit-theme.scss (#4090) → ce fichier. Les variables de variables.scss (#4091) et variables-theme.scss (#4092) sont disponibles pour tous les composants.

Points clés à retenir

  • Historique Git : Ajouté dans ac75fabf3 (2021-08-10) avec la migration du site Jekyll. Corrections de fautes de frappe dans acb790ad2.
  • Couche de thème : Il s'agit du style visuel au niveau du thème, par-dessus le composant principal. Les mixins de hooks sont définies dans mixins-theme.scss (#4024).
  • Framework UIkit : Fait partie du framework CSS UIkit (getuikit.com). Lors de la mise à niveau d'UIkit, comparez ce fichier avec la nouvelle version pour détecter les changements d'API.
