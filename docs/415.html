#415: BusinessAssessmentConfig.java

Java config — BWA (Business Assessment) configuration. Defines which Konto ranges map to BWA positions: revenue (Konten 8000-8999), expenses (4000-4999, 6000-6999), etc. Used by ReportBwa (#798) to generate the monthly management report. Configurable per company because SKR03 vs SKR04 have different account number ranges.
