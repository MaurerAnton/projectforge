Qué hace

Tema para divisores horizontales — 40 líneas. Controla el estilo de línea, divisores con icono (línea con icono en el medio), variante pequeña. Parte de la integración del framework CSS UIkit para el sitio de documentación de ProjectForge. Importado por _import.scss (#4052) en la cadena de compilación del tema.

Cadena de importación

Flujo de compilación: assets/css/main.scss → uikit-theme.scss (#4090) → _import.scss (#4052) → este archivo. Las variables de variables.scss (#4091) y variables-theme.scss (#4092) están disponibles para todos los componentes.

Conclusiones clave

  • Historial de Git: Añadido en ac75fabf3 (2021-08-10) con la migración del sitio Jekyll. Correcciones tipográficas en acb790ad2.
  • Capa de tema: Este es un estilo visual a nivel de tema sobre el componente principal. Los mixins de enlace se definen en mixins-theme.scss (#4024).
  • Framework UIkit: Parte del framework CSS UIkit (getuikit.com). Al actualizar UIkit, compare este archivo con la nueva versión para detectar cambios en la API.
