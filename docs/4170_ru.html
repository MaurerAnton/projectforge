site/_sass/uikit/theme/modal.scss

Путь: site/_sass/uikit/theme/modal.scss · Строк: 84 · Активных переменных: 8 · Хуков: 14

Назначение: Темизация модальных окон — полноэкранное наложение с центрированной карточкой. Управление: единый фон заголовка/тела/подвала (все совпадают для бесшовности), разделители границ, положение/размер/фон кнопки закрытия для 3 вариантов (по умолчанию внутри, снаружи, полноэкранный). Баннер согласия на cookie и лайтбоксы изображений зависят от этого.

$modal-header-background: $modal-dialog-background !default;  // Заголовок = тело = бесшовно
$modal-footer-background: $modal-dialog-background !default;  // Подвал тоже совпадает
$modal-header-border:     $global-border !default;            // Тонкая линия-разделитель
$modal-close-full-padding: $global-margin !default;           // Отступ кнопки закрытия в полноэкранном режиме

Единый дизайн фона: Фон заголовка и подвала совпадает с фоном тела диалога — модальное окно выглядит как единая бесшовная карточка, а не как отдельные секции. Это уместно для минимального использования модальных окон на сайте ProjectForge (согласие на cookie, лайтбокс). Визуально различные заголовок/тело/подвал были бы уместны для сложных модальных окон с формами.

14 хуков — второе место среди всех компонентов после кнопки — потому что кнопки закрытия имеют 5 вариантов позиционирования (по умолчанию во внутреннем углу, снаружи диалога, в полноэкранном углу) + состояния наведения для каждого. Полноэкранная кнопка закрытия получает дополнительную темизацию (фон, совпадающий с диалогом для эффекта слияния).
