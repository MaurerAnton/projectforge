site/_sass/uikit/theme/navbar.scss

Путь: site/_sass/uikit/theme/navbar.scss · Строк: 136 · Активных переменных: 12 · Хуков-плейсхолдеров: 25

Назначение: Темизирует главную панель навигации — самый заметный UI-компонент. Управляет: пунктами меню в ВЕРХНЕМ РЕГИСТРЕ мелким шрифтом, выпадающими списками с отступом 25px и тенью с размытием 12px, зазором 15px между панелью и выпадающим списком, разделителями сетки выпадающих списков и тенью дропбара. ВСЕ 25 миксинов-хуков закомментированы — стилизация достигается исключительно переопределением переменных.

Система переменных — 12 активных переопределений

$navbar-nav-item-font-size:         $global-small-font-size !default;     // Маленькие подписи навигации
$navbar-nav-item-text-transform:    uppercase !default;                   // БРЕНДИРОВАНИЕ ЗАГЛАВНЫМИ
$navbar-dropdown-margin:            15px !default;                        // Зазор: панель → выпадающий список
$navbar-dropdown-padding:           25px !default;                        // Просторные выпадающие списки
$navbar-dropdown-box-shadow:        0 5px 12px rgba(0,0,0,0.15) !default; // Эффект парения
$navbar-dropbar-box-shadow:         0 5px 7px rgba(0,0,0,0.05) !default;  // Тонкая тень дропбара
$navbar-dropdown-grid-divider-border-width: $global-border-width !default;

25 миксинов-хуков все закомментированы — это ПРИЗНАК чистого дизайна. Панель навигации достигает всего своего фирменного вида исключительно через SCSS-переменные. Никаких пользовательских CSS-правил не требуется. Категории хуков: Компонент (верхний уровень), Контейнер (обёртка), Элементы навигации (состояния наведения/клика/активности), Переключатель (мобильное гамбургер-меню — 4 хука, включая иконку), Выпадающая навигация (4 хука для элементов/заголовков/разделителей внутри выпадающих списков), Инверсный (6 хуков для тёмной темы — ни один не реализован).

Система теней: Выпадающие списки получают 0 5px 12px rgba(0,0,0,0.15) — размытие 12px создаёт мягкий эффект «парения». Вертикальное смещение 5px совпадает с зазором 15px, размещая пик тени прямо между панелью и выпадающим списком. Это создаёт иллюзию, что выпадающий список парит над содержимым страницы — стандартный паттерн material-дизайна.
