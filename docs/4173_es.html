Cuatro hooks semánticos — más que la mayoría de los componentes — porque el color ES el diferenciador principal para las notificaciones. Cada variante necesita estilo independiente (fondo, icono, borde). Los colores se heredan de variables globales ($global-primary-background → $notification-primary-background) — cambiar la paleta global actualiza automáticamente las notificaciones.
