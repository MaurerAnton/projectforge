#419: BusinessAssessmentTable.java

Java model — Wicket table model for BWA display. Renders business assessment results as a sortable, hierarchical table with expandable sub-rows. Maps BusinessAssessmentRow tree to Wicket DefaultDataTable columns: Position → Amount → Percentage of revenue. Supports period comparison (this month vs last month vs last year).
