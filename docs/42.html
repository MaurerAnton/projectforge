File #42: misc/scripts/timesheet_yearly_export.kts

Path: ./misc/scripts/timesheet_yearly_export.kts · Type: Kotlin script (.kts) · Source: GitHub

What it does

A Kotlin script (.kts) that exports all timesheet data for a given year as an Excel workbook — one sheet per month, with 20 columns including user, customer, project, cost center, duration, hours, and AI time savings. Executed via ProjectForge's built-in scripting engine (line 1 imports from org.projectforge namespace).

Key facts

Sheet columns20User, customer, project, cost center, week, day, start, stop, duration, hours, AI savings (optional), location, reference, task, task reference, short description, description, task path, ID, created, last update
Months12January–December, each with auto-filter and frozen header row
Start parameterstartdatumjava.util.Date — defaults to current year's January 1st
AI integrationOptionalIf AITimeSavings.timeSavingsByAIEnabled, columns for AI time saved + percentage are added
Output.xlsxWorkbook named Timesheets_{year}.xlsx, returned as the script's final expression
LoggingGermanLog messages in German ("Schreibe Monat…", "Monat … mit … Zeitberichten")
