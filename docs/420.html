#420: Kost1ScriptingDao.java

Java DAO — cost center (Kostenstelle 1) access for Groovy scripting. Wraps Kost1Dao with scripting-safe methods: no Hibernate lazy-loading issues, returns detached DTOs, handles null gracefully. Provides getKost1List(), getKost1ById(), searchKost1ByName(). One of several ScriptingDao classes that bridge JPA entities to the Groovy scripting engine.
