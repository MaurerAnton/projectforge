Sistema de sobrescritura de variables SCSS

UIkit utiliza una arquitectura de variables de dos capas:

ArchivoRolCuándo se importa
variables.scss (#4091)Valores predeterminados del núcleo — puntos de ruptura, cuadrícula, índices z, colores basePrimero
variables-theme.scss (este archivo)Sobrescrituras de marca de ProjectForge — colores, fuentes, estilo específico de componentesSegundo (sobrescribe el núcleo)

Debido a que SCSS utiliza la semántica de "la última definición gana", cada variable definida aquí que también existe en el variables.scss principal sobrescribe el valor del núcleo. Las variables definidas solo aquí son nuevas adiciones para el tema. Este archivo es el punto de personalización principal — para cambiar la apariencia del sitio web, edite este archivo, no las variables del núcleo.

Qué se personaliza típicamente aquí

CategoríaVariablesEfecto en el sitio de ProjectForge
Colores de marca$global-primary-background, $global-secondary-backgroundColores de botones, colores de enlaces, subrayado de pestaña activa, anillos de enfoque
Tipografía$global-font-family, $base-heading-*Pila de fuentes (fuentes del sistema para velocidad), tamaños de encabezado para legibilidad de documentación
Espaciado$global-margin, $global-gutterEscala de espaciado consistente para tarjetas, secciones, navegación
Componentes$navbar-*, $card-*, $button-*Valores predeterminados específicos de componentes para los componentes más utilizados

Cadena de importación: uikit-theme.scss (#4090) importa variables.scss primero → luego este archivo → luego todos los archivos de componentes. Esto asegura que las sobrescrituras del tema estén disponibles para cada componente.
