Système de surcharge des variables SCSS

UIkit utilise une architecture à deux couches pour les variables :

FichierRôleQuand il est importé
variables.scss (#4091)Valeurs par défaut du framework — points de rupture, grille, indices z, couleurs de baseEn premier
variables-theme.scss (ce fichier)Surcharges de la marque ProjectForge — couleurs, polices, style spécifique aux composantsEn second (remplace le fichier central)

Comme SCSS utilise la sémantique de « la dernière définition l'emporte », chaque variable définie ici qui existe également dans le fichier central variables.scss remplace la valeur centrale. Les variables définies uniquement ici sont de nouveaux ajouts pour le thème. Ce fichier est le point de personnalisation principal — pour modifier l'apparence du site web, modifiez ce fichier, pas les variables centrales.

Ce qui est généralement personnalisé ici

CatégorieVariablesEffet sur le site ProjectForge
Couleurs de marque$global-primary-background, $global-secondary-backgroundCouleurs des boutons, couleurs des liens, soulignement des onglets actifs, anneaux de focus
Typographie$global-font-family, $base-heading-*Pile de polices (polices système pour la rapidité), tailles des titres pour la lisibilité de la documentation
Espacement$global-margin, $global-gutterÉchelle d'espacement cohérente pour les cartes, les sections, la navigation
Composants$navbar-*, $card-*, $button-*Valeurs par défaut spécifiques aux composants les plus utilisés

Chaîne d'importation : uikit-theme.scss (#4090) importe d'abord variables.scss → puis ce fichier → puis tous les fichiers de composants. Cela garantit que les surcharges du thème sont disponibles pour chaque composant.
