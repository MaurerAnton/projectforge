Назначение: Определяет тематические SCSS-переменные, которые настраивают внешний вид всех компонентов UIkit — фирменные цвета, радиусы скругления, типографские шкалы, размеры компонентов. Переопределяет стандартные значения из variables.scss (#4091) в соответствии с брендом ProjectForge.

Система переопределения SCSS-переменных

UIkit использует двухуровневую архитектуру переменных:

ФайлРольКогда импортируется
variables.scss (#4091)Базовые значения фреймворка — точки останова, сетка, z-индексы, основные цветаПервым
variables-theme.scss (этот файл)Переопределения бренда ProjectForge — цвета, шрифты, стили конкретных компонентовВторым (переопределяет базовые)

Поскольку в SCSS действует принцип «последнее определение побеждает», каждая переменная, определённая здесь и существующая в базовом variables.scss, переопределяет базовое значение. Переменные, определённые только здесь, являются новыми дополнениями для темы. Этот файл является основной точкой настройки — чтобы изменить внешний вид сайта, редактируйте этот файл, а не базовые переменные.

Что обычно настраивается здесь

КатегорияПеременныеВлияние на сайт ProjectForge
Фирменные цвета$global-primary-background, $global-secondary-backgroundЦвета кнопок, цвет ссылок, подчёркивание активной вкладки, кольца фокуса
Типографика$global-font-family, $base-heading-*Набор шрифтов (системные шрифты для скорости), размеры заголовков для читаемости документации
Отступы$global-margin, $global-gutterСогласованная шкала отступов для карточек, секций, навигации
Компоненты$navbar-*, $card-*, $button-*Значения по умолчанию для наиболее используемых компонентов

Цепочка импорта: uikit-theme.scss (#4090) сначала импортирует variables.scss → затем этот файл → затем все файлы компонентов. Это гарантирует, что переопределения темы доступны каждому компоненту.
