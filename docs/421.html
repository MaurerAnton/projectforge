#421: Kost2ArtDao.java

Java DAO — cost type categories (Kostenarten). Extends BaseDao. Manages Kost2Art — the classification dimension for cost items (e.g. "Hardware", "Software licenses", "Travel expenses", "Consulting"). Each Kost2 (cost item) belongs to one Kost2Art. Used in the cost accounting hierarchy: Kost1 (cost center) → Kost2Art (cost type) → Kost2 (specific cost item).
