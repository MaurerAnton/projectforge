Das JAR mit 130 MB ist das vollständige Spring-Boot-Fat-JAR – es enthält eingebetteten Tomcat, alle Abhängigkeiten und das React-Frontend. Das Docker-Image mit 530 MB enthält eine vollständige OS-Ebene + JDK + das JAR.

Internationalisierung (i18n) – das Übersetzungsformat

Die Seite dokumentiert das i18n-System im Detail (Zeilen 55-89). Jede Übersetzung ist ein Schlüssel=Wert-Paar in einer .properties-Datei. Derzeit Englisch und Deutsch. Um eine Sprache hinzuzufügen: I18nResources.properties als Vorlage nehmen, die rechte Seite von = übersetzen, Schlüssel unverändert lassen. Das System fällt bei fehlenden Übersetzungen auf Englisch zurück. Dateien werden in src/main/resources abgelegt und zur Aufnahme an k.reinhard at me.com gesendet. Neue Versionen bieten eine Liste unübersetzter Schlüssel (über das Admin-Menü).
