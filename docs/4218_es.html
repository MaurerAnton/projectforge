Internacionalización (i18n) — el formato de traducción

La página documenta el sistema i18n en detalle (líneas 55-89). Cada traducción es un par clave=valor en un archivo .properties. Actualmente inglés y alemán. Para agregar un idioma: tomar I18nResources.properties como plantilla, traducir el lado derecho de =, mantener las claves sin cambios. El sistema recurre al inglés para traducciones faltantes. Los archivos van a src/main/resources y se envían a k.reinhard at me.com para su inclusión. Las nuevas versiones proporcionan una lista de claves no traducidas (a través del menú de administración).
