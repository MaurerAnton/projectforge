Trois options de téléchargement — JAR, Docker, Source

Le tableau de téléchargement principal propose trois voies :

TypeTailleLienPour
JAR130 MoSourceForgeWindows/macOS/Linux — java -jar
Docker530 MoDocker HubConteneur unique ou pile docker-compose
Source—GitHubDéveloppeurs — cloner et construire avec Gradle

Le JAR de 130 Mo est le JAR complet Spring Boot fat — inclut Tomcat embarqué, toutes les dépendances et le frontend React. L'image Docker de 530 Mo comprend une couche OS complète + JDK + le JAR.

L'archive des versions — 21 versions sur 14 ans

La section archive liste chaque version publique de 2010 à 2016, hébergée sur SourceForge. Il s'agit d'un enregistrement historique — le tableau commence à ProjectForge 3.4 (nov. 2010) et va jusqu'à 6.1 (juil. 2016). Après 2016, les versions ont été déplacées vers GitHub Releases et Docker Hub. Jalons clés :

Les liens d'archive utilisent les URL de téléchargement brut SourceForge — ceux-ci peuvent être rompus si SourceForge réorganise son CDN.

Internationalisation (i18n) — le format de traduction

La page documente le système i18n en détail (lignes 55-89). Chaque traduction est une paire clé=valeur dans un fichier .properties. Actuellement anglais et allemand. Pour ajouter une langue : prendre I18nResources.properties comme modèle, traduire le côté droit de =, conserver les clés inchangées. Le système revient à l'anglais pour les traductions manquantes. Les fichiers vont dans src/main/resources et sont soumis à k.reinhard at me.com pour inclusion. Les nouvelles versions fournissent une liste de clés non traduites (via le menu admin).
