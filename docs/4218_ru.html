Интернационализация (i18n) — формат перевода

Страница подробно документирует систему i18n (строки 55-89). Каждый перевод представляет собой пару ключ=значение в файле .properties. В настоящее время доступны английский и немецкий языки. Чтобы добавить язык: возьмите I18nResources.properties в качестве шаблона, переведите правую часть =, оставив ключи без изменений. Система использует английский язык для отсутствующих переводов. Файлы помещаются в src/main/resources и отправляются на k.reinhard at me.com для включения. Новые версии предоставляют список непереведённых ключей (через меню администратора).
