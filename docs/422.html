#422: KostentraegerStatus.java

Java enum — cost object status (Kostenträger). Values: OPEN, CLOSED. Used on Kost2DO — a cost item can be open (actively receiving cost assignments) or closed (historical only, no new postings allowed). Equivalent to KontoStatus (#413) but for cost items rather than general ledger accounts.
