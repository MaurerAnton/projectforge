11 разделов немецкого закона о защите данных

Этот документ оформлен как официальная политика конфиденциальности в соответствии с немецким/европейским законодательством, разделённая на 11 пронумерованных разделов. Каждый раздел касается конкретного юридического требования:

Правовая основа — TMG и DSGVO

§15 Abs. 3 TMG (Telemediengesetz — Немецкий закон о телемедиа) явно цитируется в разделе 6. Этот раздел разрешает псевдонимные профили использования для рекламы, маркетинговых исследований и дизайна, ориентированного на спрос — но только если пользователь не возражает. Политика предусматривает механизм отказа.

DSGVO (Datenschutz-Grundverordnung — GDPR) соблюдается неявно на всём протяжении: минимизация данных (сбор только необходимого), ограничение цели (использование только для заявленных целей), ограничение хранения (автоудаление серверных логов), прозрачность (объяснение в 11 разделах) и права пользователей (доступ, исправление, удаление).

Micromata GmbH является юридическим лицом. Политика утверждает, что персональные данные НЕ передаются третьим лицам, НЕ используются для профилирования, кроме псевдонимной аналитики, и пользователи могут в любое время отказаться, написав на info(at)micromata.de.

Детали технической реализации

  • Серверные логи: Сайт хранит стандартные логи доступа Apache/nginx: IP, временная метка, URL, объём данных, код состояния, браузер/ОС, реферер, провайдер. Они «временно хранятся и автоматически удаляются».
  • Только сессионные cookie: «Nur ausnahmsweise Cookies» — cookie используются только в исключительных случаях для технического управления сессией. Нет отслеживающих cookie, нет сторонних cookie. Удаляются при закрытии браузера.
  • Веб-аналитика через псевдонимные профили: Сайт использует аналитическое ПО, которое создаёт профили использования под псевдонимом. Пользователи НЕ идентифицируются лично. Данные НЕ объединяются с персональными данными. Межсайтовое отслеживание НЕ выполняется.
  • Социальные плагины: Кнопки Facebook, Twitter, Google+, XING создают прямые соединения от браузера пользователя к серверам социальной сети. Политика предупреждает, что провайдер узнаёт, какая страница ProjectForge была посещена, и если пользователь вошёл в социальную сеть, посещение может быть связано с его учётной записью.

Ключевые выводы

  • Только на немецком языке: Английский перевод отсутствует. Это юридический документ, подпадающий под юрисдикцию Германии — переводы могут внести двусмысленность.
  • Стандартный юридический шаблон: Многое читается как стандартный шаблон немецкой политики конфиденциальности. Разделы 1-3, 5, 8-11 являются общими. Раздел 7 (социальные плагины) наиболее специфичен для сайта.
  • Требования контактной формы: Имя, фамилия и email обязательны. Дополнительные поля добровольны. Данные используются только с явного согласия.
  • Отказ по email: Нет автоматического баннера согласия на cookie или центра предпочтений — пользователи должны написать в Micromata по email, чтобы отказаться от аналитики. Это может не соответствовать современным стандартам GDPR (которые требуют явного согласия, а не отказа).
