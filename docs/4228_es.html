Tres tecnologías en un solo archivo

Esta página combina de manera única tres capas:

  1. Front matter de Jekyll (líneas 1-10): Configuración YAML — layout: page usa _layouts/page.html, width: small estrecha el contenido, tipue_search_active: true activa la inclusión de los assets CSS/JS de Tipue, hero configura el banner con el título "Buscar" y la imagen de fondo search.png, permalink: /search/ establece la URL.
  2. Bloque de paso directo ++++ de AsciiDoc (líneas 14-31): El contenido entre los marcadores ++++ se pasa directamente a la salida HTML sin procesamiento de AsciiDoc. Esto permite incrustar HTML puro y JavaScript en un documento AsciiDoc — necesario porque AsciiDoc no puede expresar widgets de búsqueda interactivos.
  3. Inicialización de JavaScript (líneas 26-29): jQuery $(document).ready() vincula Tipue Search a #tipue_search_input con .tipuesearch() — la única línea que activa la búsqueda del lado del cliente.
<form class="uk-search uk-search-default uk-width-1-1">
  <span class="uk-search-icon-flip" data-uk-search-icon></span>
  <input id="tipue_search_input" pattern=".{3,}" required>
  <div id="tipue_search_content"></div>
</form>

<script>
$(document).ready(function() {
  $('#tipue_search_input').tipuesearch();
});
</script>

Estilo UIkit: Clases uk-search, uk-search-default, uk-width-1-1, uk-search-icon-flip del framework UIkit. Tematizado por el tema search.scss (#4071) — fondo transparente, borde visible, variante de foco discontinuo.

pattern=".{3,}": Validación del lado del cliente HTML5 — requiere al menos 3 caracteres antes del envío del formulario. Tipue Search también aplica esto del lado del servidor.

Fuente de datos: El índice de búsqueda proviene de search.json (#4094) — se obtiene una vez cuando el usuario escribe por primera vez, luego se filtra del lado del cliente.
