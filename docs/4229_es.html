Cómo funciona la búsqueda estática — la arquitectura Jekyll+TipueSearch

Este archivo NO es un archivo JSON estático — es una plantilla de Jekyll procesada en tiempo de compilación. El flujo de trabajo:

  1. Tiempo de compilación: Jekyll procesa {% for doc in site.docs %} — itera cada documento en la colección _docs/ (installation.adoc, userguide.adoc, development.adoc, etc.) — y genera un archivo search.json estático en el directorio de salida.
  2. Tiempo de ejecución: Cuando un usuario escribe en el cuadro de búsqueda en /search/ (#4093), el plugin jQuery Tipue Search obtiene /search.json, filtra las entradas del lado del cliente y muestra los resultados — sin servidor, sin base de datos, sin API.

Esto es búsqueda en sitio estático — todo el corpus de búsqueda es un único archivo JSON precomputado. Rápido, económico, pero no escala más allá de unos cientos de páginas.

---
layout: null         # Crítico: sin esto, el JSON se envolvería en HTML
---
[
  {% for doc in site.docs %}
    {
      "title": "{{ doc.title | escape }}",
      "category": "{{ doc.category }}",
      "tags": "{{ doc.tags | join: ', ' }}",
      "url": "{{ site.baseurl }}{{ doc.url }}",
      "date": "{{ doc.date }}"
    } {% unless forloop.last %},{% endunless %}
  {% endfor %}
]

layout: null: Sin esto, Jekyll envuelve el JSON en la plantilla HTML del sitio (encabezado, navegación, pie de página) — produciendo JSON inválido. El diseño null genera contenido sin procesar.

{% unless forloop.last %},{% endunless %}: Agrega comas entre los elementos del array pero NO después del último elemento. Una coma final produciría JSON inválido. Liquid no tiene un filtro integrado de "generar JSON válido" — este control manual de comas es necesario.

Limitaciones: Solo se indexa la colección site.docs — las publicaciones del blog, preguntas frecuentes y registros de cambios NO se pueden buscar. Solo coincidencia de título/etiquetas — sin búsqueda de texto completo del contenido del documento. Todos los metadatos se cargan en el navegador en la primera búsqueda — no escalable a miles de páginas.
