Comment fonctionne la recherche statique — l'architecture Jekyll+TipueSearch

Ce fichier n'est PAS un fichier JSON statique — c'est un modèle Jekyll traité au moment de la construction. Le flux de travail :

  1. Au moment de la construction : Jekyll traite {% for doc in site.docs %} — parcourt chaque document de la collection _docs/ (installation.adoc, userguide.adoc, development.adoc, etc.) — et génère un fichier search.json statique dans le répertoire de sortie.
  2. À l'exécution : Lorsqu'un utilisateur tape dans la zone de recherche sur /search/ (#4093), le plugin jQuery Tipue Search récupère /search.json, filtre les entrées côté client et affiche les résultats — pas de serveur, pas de base de données, pas d'API.

C'est ce qu'on appelle la recherche de site statique — l'ensemble du corpus consultable est un seul fichier JSON pré-calculé. Rapide, économique, mais ne passe pas à l'échelle au-delà de quelques centaines de pages.

---
layout: null         # Critique : sans cela, le JSON serait enveloppé dans du HTML
---
[
  {% for doc in site.docs %}
    {
      "title": "{{ doc.title | escape }}",
      "category": "{{ doc.category }}",
      "tags": "{{ doc.tags | join: ', ' }}",
      "url": "{{ site.baseurl }}{{ doc.url }}",
      "date": "{{ doc.date }}"
    } {% unless forloop.last %},{% endunless %}
  {% endfor %}
]

layout: null : Sans cela, Jekyll enveloppe le JSON dans le modèle HTML du site (en-tête, navigation, pied de page) — produisant un JSON invalide. Le modèle null génère un contenu brut.

{% unless forloop.last %},{% endunless %} : Ajoute des virgules entre les éléments du tableau mais PAS après le dernier élément. Une virgule finale produirait un JSON invalide. Liquid n'a pas de filtre intégré « générer du JSON valide » — ce contrôle manuel des virgules est nécessaire.

Limitations : Seule la collection site.docs est indexée — les articles de blog, FAQ et journaux des modifications ne sont PAS consultables. Correspondance uniquement sur le titre/les étiquettes — pas de recherche en texte intégral du contenu des documents. Toutes les métadonnées sont chargées dans le navigateur lors de la première recherche — non extensible à des milliers de pages.
