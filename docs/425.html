#425: KostZuweisungenCopyHelper.java

Java helper — copies cost assignments from one invoice/order to another. Used when an order is converted to an invoice — the cost assignments are cloned rather than re-entered manually. Validates that target entity supports the same cost dimensions and that amounts sum to 100% (or warns if not). Uses Hibernate detach() to avoid duplicate key issues.
