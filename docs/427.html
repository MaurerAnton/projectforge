#427: ReportGenerator.java

Java engine — cost report generator base. Superclass for specific report types (ReportGeneratorList). Takes Report definition, queries data via ReportDao, applies filters and groupings, and produces the Report output model. Supports: grouping by Kost1/Kost2Art/project/customer, date range filtering, comparison periods (previous month/year), and percentage calculations.
