#430: ReportObjective.java

Java model — one row filter in a cost report. Specifies which entity to report on: objectiveType (KOST1, KOST2_ART, PROJECT, CUSTOMER), objectiveId (the specific entity ID), includeSubItems (for hierarchical Kost1 — include child cost centers?). Used by Report to define the scope. Multiple objectives = multi-entity report.
