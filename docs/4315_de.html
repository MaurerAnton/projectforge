Die 11 Zeilen, die alles steuern

@Configuration
@ComponentScan({ "org.projectforge", "de.micromata.mgc.jpa.spring" })
public class SchemaExpContext { }

Obwohl es nur 11 Zeilen sind, ist dies wohl die kritischste Datei im SchemaExp-Tool. Ihr @ComponentScan bestimmt, welche Spring-Beans entdeckt und verfügbar sind:

PaketWas es mitbringt
org.projectforgeALLE ProjectForge-Komponenten – SchemaExpService (#4104), XmlDump, ConfigurationDao, PfEmgrFactory, alle DAOs, alle DOs, alle Wicket-Seiten, alle REST-Controller. Tausende von Beans.
de.micromata.mgc.jpa.springGenome JPA-Framework – JpaXmlDumpService, JpaSchemaService, Transaktionsverwaltung, EntityManagerFactory-Konfiguration. Die kritische Abhängigkeit für XML-Dump/Wiederherstellung.

Umfangsbedenken: Der Scan von "org.projectforge" ist übermäßig breit – er entdeckt alle Wicket-Seiten, REST-Controller, Quartz-Scheduler, E-Mail-Dienste und Sicherheitsfilter. Die meisten werden vom SchemaExp-Tool nie verwendet, aber trotzdem instanziiert. Dies erklärt, warum das Tool selbst für Exportvorgänge eine Datenbankverbindung benötigt (DAOs benötigen eine DB zur Initialisierung). Ein engerer Scan würde die Startzeit und Abhängigkeiten reduzieren.
