Las 11 líneas que lo controlan todo

@Configuration
@ComponentScan({ "org.projectforge", "de.micromata.mgc.jpa.spring" })
public class SchemaExpContext { }

A pesar de tener solo 11 líneas, este es posiblemente el archivo más crítico en la herramienta SchemaExp. Su @ComponentScan determina qué beans de Spring se descubren y están disponibles:

PaqueteQué aporta
org.projectforgeTODOS los componentes de ProjectForge — SchemaExpService (#4104), XmlDump, ConfigurationDao, PfEmgrFactory, todos los DAOs, todos los DOs, todas las páginas Wicket, todos los controladores REST. Miles de beans.
de.micromata.mgc.jpa.springFramework Genome JPA — JpaXmlDumpService, JpaSchemaService, gestión de transacciones, configuración de EntityManagerFactory. La dependencia crítica para volcado/restauración XML.

Problema de alcance: El escaneo "org.projectforge" es excesivamente amplio — descubre todas las páginas Wicket, controladores REST, schedulers Quartz, servicios de correo electrónico y filtros de seguridad. La mayoría nunca son utilizados por la herramienta SchemaExp pero se instancian de todas formas. Esto explica por qué la herramienta requiere una conexión a la base de datos incluso para operaciones de exportación (los DAOs necesitan una BD para inicializarse). Un escaneo más reducido disminuiría el tiempo de inicio y las dependencias.
