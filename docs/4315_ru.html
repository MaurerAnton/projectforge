@Configuration
@ComponentScan({ "org.projectforge", "de.micromata.mgc.jpa.spring" })
public class SchemaExpContext { }

Несмотря на то, что файл состоит всего из 11 строк, это, пожалуй, самый критический файл в инструменте SchemaExp. Его @ComponentScan определяет, какие Spring-бины будут обнаружены и доступны:

ПакетЧто он привносит
org.projectforgeВСЕ компоненты ProjectForge — SchemaExpService (#4104), XmlDump, ConfigurationDao, PfEmgrFactory, все DAO, все DO, все страницы Wicket, все REST-контроллеры. Тысячи бинов.
de.micromata.mgc.jpa.springФреймворк Genome JPA — JpaXmlDumpService, JpaSchemaService, управление транзакциями, конфигурация EntityManagerFactory. Критическая зависимость для дампа/восстановления XML.

Проблема области видимости: Сканирование "org.projectforge" чрезмерно широкое — оно обнаруживает все страницы Wicket, REST-контроллеры, планировщики Quartz, почтовые сервисы и фильтры безопасности. Большинство из них никогда не используется инструментом SchemaExp, но всё равно инстанцируется. Это объясняет, почему инструмент требует подключения к базе данных даже для операций экспорта (DAO нуждаются в БД для инициализации). Более узкое сканирование сократило бы время запуска и количество зависимостей.
