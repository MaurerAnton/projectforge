Arquitectura: Sistema de importación de motor dual

La característica arquitectónica más notable de la clase es su sistema de importación de motor dual, controlado por useJpaXmlDumpService = true (línea 47):

MotorIndicadorBibliotecaCaracterísticas
Genome JPAtrue (predeterminado)de.micromata.genome.db.jpa.xmldumpAnálisis con conocimiento de JPA, resolución de tipos de entidad, manejo de relaciones, soporte de RestoreMode (InsertNew/OverWrite/InsertAll), asignación de clave primaria mediante generadores de secuencia
Legacy XStreamfalseThoughtWorks XStream a través de XmlDumpSerialización XStream pura, verificación manual mediante verifyDump(), comprobaciones de integridad posteriores a la importación a través de ConfigurationDao

El motor Genome es preferido porque entiende los metadatos de entidad JPA — maneja correctamente las cascadas @OneToMany, las estrategias @Inheritance y las relaciones de clave foránea durante la importación. El motor heredado se conserva para compatibilidad hacia atrás.

Métodos clave

clearDb() (líneas 49-52): Llama a emfac.getJpaSchemaService().clearDatabase() — elimina todas las tablas en orden inverso de dependencia. Esta es una operación destructiva sin deshacer. Se usa tanto de forma independiente (indicador -cleardb) como como requisito previo para importaciones (-cleardb -imp).

doImport(boolean clearDb, String clientFileName, RestoreMode modus) (líneas 54-87): La tubería de importación principal: (1) opcionalmente limpia la base de datos, (2) valida la existencia del archivo, (3) detecta el formato del archivo (.xml vs .xml.gz) y descomprime si es necesario, (4) delega al motor seleccionado, (5) maneja la limpieza en el bloque finally. El enum RestoreMode controla la resolución de conflictos: InsertNew omite registros existentes, OverWrite los actualiza, InsertAll inserta todo (falla en duplicados).

doExport(String fileName) (líneas 89-94): Delega a jpaXmlDumpService.dumpToXml(emfac, file). A diferencia de la importación, la exportación siempre usa la biblioteca Genome — no hay una ruta de exportación XStream heredada. Consulta todos los tipos de entidad de los metadatos JPA, carga todos los registros (escaneos completos de tablas) y serializa a XML con marshalling compatible con JPA.

Notas de calidad del código

  • Campo no utilizado: TransactionTemplate txTemplate (línea 32) se inyecta pero nunca se usa — código muerto.
  • API obsoleta: IOUtils.closeQuietly() (línea 84) está obsoleto en Apache Commons IO 2.7+. Debería usar try-with-resources.
  • Error tipográfico en clase padre: SchemaExpMain.initApplicatinContext() (falta la 'o' en "Application") es llamado por todas las pruebas.
  • Indicador codificado: useJpaXmlDumpService = true idealmente debería ser una propiedad Spring @Value para configuración en tiempo de ejecución.
  • Sin compresión de exportación: La ruta de exportación no comprime con gzip la salida. Para volcados de producción, comprima manualmente con gzip después de la exportación.
