DESTRUCTIVO: Utiliza -cleardb — elimina TODAS las tablas antes de importar. Ejecutar solo contra postgres2, nunca contra postgres.

Qué hace

La contraparte de importación de ToXmlTest. Fuerza la fuente de datos postgres2 (una instancia PostgreSQL separada y desechable), luego invoca SchemaExpMain con tres banderas: -imp (importar), -cleardb (eliminar todas las tablas primero) y -insertall (insertar todas las entidades desde XML). El código actual importa desde init-test-data-new.xml — el archivo de datos de prueba pregenerado distribuido con la aplicación web. Una línea anterior comentada muestra la misma prueba importando desde target/pf-dump.xml (la salida de ToXmlTest).

//  @Test
public void testImp() {
  System.getProperties().setProperty("projectForgeDs", "postgres2");
  //SchemaExpMain.main(new String[] { "-imp", "-cleardb", "-insertall", "target/pf-dump.xml" });
  SchemaExpMain.main(new String[] { "-imp", "-cleardb", "-insertall",
      "../../projectforge-webapp/src/main/resources/data/init-test-data-new.xml" });
}

Línea 8: postgres2 — deliberadamente una base de datos DIFERENTE a la postgres de la prueba de exportación. Esto evita destruir accidentalmente tu base de datos de desarrollo principal.

Línea 10: La ruta alternativa comentada documenta el flujo de trabajo exportación→importación: primero ejecutar ToXmlTest para generar pf-dump.xml, luego ejecutar esta prueba para importarlo.

Líneas 10-11: Importa desde init-test-data-new.xml — el archivo de semillas de prueba canónico. Cuando un usuario selecciona "Sistema de prueba" durante la configuración de ProjectForge, el asistente importa este archivo exacto para poblar la base de datos con datos de muestra. Esta prueba valida que el pipeline de importación maneje correctamente datos de semilla del mundo real.

Recorrido de ruta: ../../projectforge-webapp/src/main/resources/data/ — navega desde tools/org.projectforge.tools.schemaexp/ dos directorios arriba, luego dentro del módulo webapp. Ruta relativa frágil — depende del directorio de trabajo siendo la raíz de la herramienta.
