Was es tut

Dies ist der exportseitige Entwicklertest – das Gegenstück zu FromXmlTest (#4106). Er initialisiert einen Spring-Kontext, überschreibt die Datenquelle mit PostgreSQL und ruft dann SchemaExpMain.main() mit -exp auf, um die gesamte Datenbank nach target/pf-dump.xml zu exportieren. Die @Test-Annotation ist auskommentiert, da dieser Test eine laufende, befüllte PostgreSQL-Datenbank erfordert – er kann in CI ohne Datenbank-Fixture nicht ausgeführt werden.

Die resultierende XML-Datei kann für eine Produktionsdatenbank hunderte Megabyte groß sein und alle Entitäten (Benutzer, Gruppen, Adressen, Zeiterfassungen, Aufgaben, Rechnungen, Verlaufseinträge) enthalten, serialisiert über die Genome JPA XML Dump Library mit XStreams ReferenceByIdMarshallingStrategy.

//  @Test                           // Auskommentiert – erfordert Live-DB
public void testExp() {
  System.getProperties().setProperty("projectForgeDs", "postgres");
  SchemaExpMain.main(new String[] { "-exp", "target/pf-dump.xml" });
}

Zeile 8: Setzt die Systemeigenschaft projectForgeDs auf "postgres" – dies wählt aus, welcher Spring DataSource-Bean aktiviert wird. Der Wert postgres entspricht der primären Entwicklungsdatenbank, die in local-settings.properties (#4101) definiert ist.

Zeile 9: Übergibt zwei Argumente: -exp (das Export-Operations-Flag) und target/pf-dump.xml (der Ausgabepfad, relativ zum Maven-Build-Verzeichnis). Das -exp-Flag wird von SchemaExpMain.parseOption() geparst, was op = Operation.Export setzt, und delegiert dann an SchemaExpService.doExport(), welches jpaXmlDumpService.dumpToXml() aufruft.

Wichtige Erkenntnisse

  • NICHT für CI: Das auskommentierte @Test ist beabsichtigt. Nur auskommentieren, wenn eine befüllte PostgreSQL-Datenbank verfügbar ist.
  • Export → Import-Paar: Export mit diesem Test, Import mit FromXmlTest (#4106). Zusammen bilden sie einen vollständigen Migrationsworkflow.
  • Pfad ist relativ: target/pf-dump.xml setzt voraus, dass das Arbeitsverzeichnis das Wurzelverzeichnis des Tools ist. Ein Ausführen aus dem falschen Verzeichnis erstellt die Datei woanders.
  • Genome-Bibliothek: Die eigentliche Serialisierung verwendet de.micromata.genome.db.jpa.xmldump.api.JpaXmlDumpService – nicht rohes XStream. Die Genome-Bibliothek fügt JPA-Entitätsmetadaten zum XML hinzu für korrekte Beziehungshandhabung.
