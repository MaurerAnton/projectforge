Qué hace

Esta es la prueba de desarrollador del lado de exportación — la contraparte de FromXmlTest (#4106). Inicializa un contexto Spring, sobrescribe la fuente de datos a PostgreSQL, luego invoca SchemaExpMain.main() con -exp para exportar toda la base de datos a target/pf-dump.xml. La anotación @Test está comentada porque esta prueba requiere una base de datos PostgreSQL activa y poblada — no puede ejecutarse en CI sin un fixture de base de datos.

El archivo XML resultante puede tener cientos de megabytes para una base de datos de producción, conteniendo todas las entidades (usuarios, grupos, direcciones, hojas de tiempo, tareas, facturas, entradas de historial) serializadas mediante la librería Genome JPA XML Dump con la ReferenceByIdMarshallingStrategy de XStream.

//  @Test                           // Comentado — requiere BD activa
public void testExp() {
  System.getProperties().setProperty("projectForgeDs", "postgres");
  SchemaExpMain.main(new String[] { "-exp", "target/pf-dump.xml" });
}

Línea 8: Establece la propiedad del sistema projectForgeDs a "postgres" — esto selecciona qué bean de DataSource de Spring activar. El valor postgres corresponde a la base de datos de desarrollo principal definida en local-settings.properties (#4101).

Línea 9: Pasa dos argumentos: -exp (el indicador de operación de exportación) y target/pf-dump.xml (la ruta de salida, relativa al directorio de compilación de Maven). El indicador -exp es analizado por SchemaExpMain.parseOption() que establece op = Operation.Export, luego delega a SchemaExpService.doExport() que llama a jpaXmlDumpService.dumpToXml().

Conclusiones clave

  • NO para CI: El @Test comentado es intencional. Descomentar solo cuando se disponga de una base de datos PostgreSQL poblada.
  • Par Exportación → Importación: Exportar con esta prueba, importar con FromXmlTest (#4106). Juntos forman un flujo de trabajo completo de migración.
  • La ruta es relativa: target/pf-dump.xml asume que el directorio de trabajo es la raíz de la herramienta. Ejecutar desde el directorio incorrecto crea el archivo en otro lugar.
  • Librería Genome: La serialización real utiliza de.micromata.genome.db.jpa.xmldump.api.JpaXmlDumpService — no XStream puro. La librería Genome añade metadatos de entidad JPA al XML para un manejo correcto de las relaciones.
