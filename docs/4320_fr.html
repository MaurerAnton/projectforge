Ce qu'il fait

Il s'agit du test développeur côté export — l'homologue de FromXmlTest (#4106). Il initialise un contexte Spring, remplace la source de données par PostgreSQL, puis appelle SchemaExpMain.main() avec -exp pour exporter l'intégralité de la base de données vers target/pf-dump.xml. L'annotation @Test est commentée car ce test nécessite une base de données PostgreSQL active et peuplée — il ne peut pas être exécuté dans l'IC sans un environnement de base de données dédié.

Le fichier XML résultant peut atteindre des centaines de mégaoctets pour une base de production, contenant toutes les entités (utilisateurs, groupes, adresses, feuilles de temps, tâches, factures, entrées d'historique) sérialisées via la bibliothèque Genome JPA XML Dump avec la stratégie ReferenceByIdMarshallingStrategy de XStream.

//  @Test                           // Commenté — nécessite une base de données active
public void testExp() {
  System.getProperties().setProperty("projectForgeDs", "postgres");
  SchemaExpMain.main(new String[] { "-exp", "target/pf-dump.xml" });
}

Ligne 8 : Définit la propriété système projectForgeDs à "postgres" — cela sélectionne le bean DataSource Spring à activer. La valeur postgres correspond à la base de développement principale définie dans local-settings.properties (#4101).

Ligne 9 : Passe deux arguments : -exp (l'indicateur d'opération d'export) et target/pf-dump.xml (le chemin de sortie, relatif au répertoire de construction Maven). L'indicateur -exp est analysé par SchemaExpMain.parseOption() qui définit op = Operation.Export, puis délègue à SchemaExpService.doExport() qui appelle jpaXmlDumpService.dumpToXml().

Points clés à retenir

  • PAS pour l'IC : Le @Test commenté est intentionnel. Ne décommentez que lorsque vous disposez d'une base de données PostgreSQL peuplée.
  • Paire Export → Import : Exportez avec ce test, importez avec FromXmlTest (#4106). Ensemble, ils forment un workflow de migration complet.
  • Chemin relatif : target/pf-dump.xml suppose que le répertoire de travail est la racine de l'outil. L'exécution depuis un autre répertoire crée le fichier ailleurs.
  • Bibliothèque Genome : La sérialisation réelle utilise de.micromata.genome.db.jpa.xmldump.api.JpaXmlDumpService — pas du XStream brut. La bibliothèque Genome ajoute les métadonnées des entités JPA au XML pour une gestion correcte des relations.
