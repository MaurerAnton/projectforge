Что это делает

Это тест разработчика для стороны экспорта — аналог FromXmlTest (#4106). Он инициализирует контекст Spring, переопределяет источник данных на PostgreSQL, затем вызывает SchemaExpMain.main() с -exp для экспорта всей базы данных в target/pf-dump.xml. Аннотация @Test закомментирована, поскольку этот тест требует работающей, заполненной базы данных PostgreSQL — он не может выполняться в CI без фикстуры базы данных.

Результирующий XML-файл может занимать сотни мегабайт для производственной базы данных, содержа все сущности (пользователи, группы, адреса, табели учета времени, задачи, счета, записи истории), сериализованные с помощью библиотеки Genome JPA XML Dump и стратегии ReferenceByIdMarshallingStrategy от XStream.

//  @Test                           // Закомментировано — требует работающей БД
public void testExp() {
  System.getProperties().setProperty("projectForgeDs", "postgres");
  SchemaExpMain.main(new String[] { "-exp", "target/pf-dump.xml" });
}

Строка 8: Устанавливает системное свойство projectForgeDs в "postgres" — это выбирает, какой бин Spring DataSource активировать. Значение postgres соответствует основной базе данных разработки, определенной в local-settings.properties (#4101).

Строка 9: Передает два аргумента: -exp (флаг операции экспорта) и target/pf-dump.xml (путь вывода, относительно каталога сборки Maven). Флаг -exp разбирается методом SchemaExpMain.parseOption(), который устанавливает op = Operation.Export, затем делегирует выполнение SchemaExpService.doExport(), который вызывает jpaXmlDumpService.dumpToXml().

Ключевые выводы

  • НЕ для CI: Закомментированный @Test — это намеренно. Раскомментируйте только при наличии доступной заполненной базы данных PostgreSQL.
  • Пара экспорт → импорт: Экспорт с помощью этого теста, импорт с помощью FromXmlTest (#4106). Вместе они образуют полный рабочий процесс миграции.
  • Путь относительный: target/pf-dump.xml предполагает, что рабочим каталогом является корень инструмента. Запуск из неправильного каталога создаст файл в другом месте.
  • Библиотека Genome: Фактическая сериализация использует de.micromata.genome.db.jpa.xmldump.api.JpaXmlDumpService — не сырой XStream. Библиотека Genome добавляет метаданные сущностей JPA в XML для корректной обработки связей.
