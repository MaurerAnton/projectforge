#433: SHType.java

Java enum — Soll/Haben type (Debit/Credit type). Values: SOLL (debit — left side of T-account), HABEN (credit — right side). Used in accounting postings to determine which side of the ledger an amount goes on. German accounting terminology — Soll/Haben instead of Debit/Credit.
