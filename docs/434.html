#434: KundeDao.java

Java DAO — customer (Kunde) master data. Extends BaseDao<KundeDO>. Provides getKundeByNumber(), searchByName(), getAllActive(). Customers are a key dimension in the fibu system — orders, invoices, and cost assignments all reference a customer. One of the core entity DAOs.
