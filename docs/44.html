Plugin architecture pattern

ProjectForge plugins follow a convention: each lives under plugins/org.projectforge.plugins.<name>/, applies the shared conventions plugin, explicitly sets JVM 17 (matching #4), and declares minimal dependencies. The banking plugin is one of ~10 plugins providing modular feature sets (banking, CalDAV, data transfer, team calendar, etc.).
