#441: PaymentStatus.java

Java enum — I18nEnum. Values: UNPAID, PAID, PARTLY_PAID. Used on RechnungDO and EingangsrechnungDO. Controls the "Paid" filter on invoice lists and the paid/unpaid toggle in the invoice edit form. PARTLY_PAID allows tracking invoices with multiple partial payments.
