#451: RechnungUIStatus.java

Java enum — invoice UI status. Computed display status: UNBEKANNT, OFFEN, BEZAHLT, STORNIERT, UEBERFAELLIG (overdue). Not stored in DB — calculated from RechnungStatus + PaymentStatus + dueDate at display time. UI-only concept like AuftragUIStatus.
