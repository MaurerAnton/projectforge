#455: GanttChartData.java

Java model — Gantt chart in-memory representation. Contains: tasks (list of GanttTask with id, name, startDate, endDate, duration, progress, dependencies), chartTitle, projectName. Built by GanttChartDao.getTaskTree() — converts flat DB records to a renderable Gantt data structure. Used by JFreeChart rendering and MS Project export.
