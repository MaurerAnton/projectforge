#456: TaskTree.kt

Service / Cache, projectforge-business/src/main/java/org/projectforge/business/task/TaskTree.kt

Core service managing the hierarchical task structure in memory. Extends AbstractCache (1-hour refresh). Maintains a tree of TaskNode objects, supports ancestor/descendant traversal, project/kost2 assignment resolution, order position references, and total duration aggregation. Thread-safe via synchronized blocks. 934 lines.

Architecture

Singleton accessed via TaskTree.instance. Core features: getTaskNodeById() with HashMap O(1) lookup, getPathToRoot() ancestor traversal, getProjekt()/getKost2List() hierarchical resolution, addOrUpdateTaskNode() with cycle detection, order position person-days aggregation, and timesheet bookable status caching. Refresh loads all tasks, group access, and projects from DB in one transaction.
