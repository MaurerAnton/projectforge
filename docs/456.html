#456: GanttChart.java

Java service — Gantt chart builder/rendering engine. Creates JFreeChart from GanttChartData: renders task bars (start→end with progress fill), dependency arrows, milestones (diamonds), today-line (red vertical), and weekend highlighting (gray background). Supports zoom/pan and color-coded task types. The core visualization engine — JFreeChart-based Gantt charts.
