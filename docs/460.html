#460: GanttChartXLabelBarRenderer.java

Java custom renderer — JFreeChart bar renderer extension for Gantt task bars. Adds: task labels inside bars (name + progress %), color coding by task type, dependency arrow rendering, and proper bar positioning for left-to-right time axis. Extends XYBarRenderer with custom drawItem() override for text label placement inside bars.
