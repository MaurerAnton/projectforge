#463: GanttTaskImpl.java

Java model — concrete Gantt task implementation. Implements GanttTask interface. Fields: id, name, startDate, endDate, duration, progress (0-100%), dependencies (list of GanttRelation with predecessor ID + type), children (sub-tasks for WBS). Used by GanttChartData (#455) as the in-memory task representation.
