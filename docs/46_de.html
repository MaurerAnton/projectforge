Was es tut

Ein REST-Datenübertragungsobjekt für Bankkonten – es vermittelt zwischen der BankAccountDO-Entität (#48) und dem REST-API-JSON-Format. Erweitert BaseDTO<BankAccountDO>, das einfache Felder (Name, IBAN, BIC usw.) automatisch zwischen DO und DTO abbildet. Die manuelle Konvertierung kümmert sich um die 6 Zugriffslisten, die in der Datenbank als CSV-Ganzzahlen gespeichert, in der API jedoch als strukturierte JSON-Arrays bereitgestellt werden.

Physisches vs. logisches Paket

Die Datei befindet sich unter plugins/.../banking/BankAccount.kt, deklariert aber package org.projectforge.rest.dto – das DTO lebt im Plugin-Quellcode, gehört aber zum REST-DTO-Paket. Dieses Muster hält DTOs in der Nähe ihrer Plugin-Module, während sie für eine konsistente API-Serialisierung einen Namensraum mit allen anderen DTOs teilen.
