Qué hace

Un Objeto de Transferencia de Datos REST para cuentas bancarias: actúa como puente entre la entidad BankAccountDO (#48) y el formato JSON de la API REST. Extiende BaseDTO<BankAccountDO>, que asigna automáticamente campos simples (nombre, IBAN, BIC, etc.) entre DO y DTO. La conversión manual maneja las 6 listas de acceso que se almacenan como enteros CSV en la base de datos, pero se exponen como arreglos JSON estructurados en la API.

Paquete físico vs. lógico

El archivo está en plugins/.../banking/BankAccount.kt pero declara package org.projectforge.rest.dto — el DTO reside con el código fuente del plugin, pero pertenece al paquete de DTOs REST. Este patrón mantiene los DTOs ubicados junto con sus módulos de plugin, mientras comparten un espacio de nombres con todos los demás DTOs para mantener la coherencia en la serialización de la API.
