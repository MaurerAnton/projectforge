Ce qu'il fait

Un objet de transfert de données REST pour les comptes bancaires — fait le pont entre l'entité BankAccountDO (#48) et le format JSON de l'API REST. Étend BaseDTO<BankAccountDO> qui mappe automatiquement les champs simples (nom, iban, bic, etc.) entre DO et DTO. La conversion manuelle gère les 6 listes d'accès qui sont stockées sous forme d'entiers CSV dans la base de données mais exposées sous forme de tableaux JSON structurés dans l'API.

Paquet physique vs logique

Le fichier se trouve dans plugins/.../banking/BankAccount.kt mais déclare package org.projectforge.rest.dto — le DTO réside avec le code source du plugin mais appartient au paquet des DTO REST. Ce modèle maintient les DTO colocalisés avec leurs modules plugin tout en partageant un espace de noms avec tous les autres DTO pour la cohérence de la sérialisation API.
