Назначение

REST-объект передачи данных для банковских счетов — связывает сущность BankAccountDO (#48) с форматом JSON REST API. Расширяет BaseDTO<BankAccountDO>, который автоматически отображает простые поля (name, iban, bic и т.д.) между DO и DTO. Ручное преобразование обрабатывает 6 списков доступа, которые хранятся в базе данных как CSV-целые числа, но в API представляются как структурированные JSON-массивы.

API JSON База данных (DO) "fullAccessGroups": [ fullAccessGroupIds = "12,45,78" {"id": 12, "name": "Финансы"}, {"id": 45, "name": "Админы"} ] copyFrom() ▼ copyTo() ▲ "fullAccessUsers": [ fullAccessUserIds = "3,7" {"id": 3, "name": "Алиса"}, {"id": 7, "name": "Боб"} ]

Физический vs логический пакет

Файл находится в plugins/.../banking/BankAccount.kt, но объявляет package org.projectforge.rest.dto — DTO располагается в исходниках плагина, но принадлежит пакету REST DTO. Такой подход позволяет DTO находиться рядом с модулями плагинов, но при этом использовать общее пространство имён с другими DTO для единообразия сериализации в API.
