Назначение

JPA-сущность для балансов банковских счетов — запись баланса счёта на определённую дату. Расширяет DefaultBaseDO (базовый класс сущностей ProjectForge, предоставляющий id, created, lastUpdate, deleted). Использует 4 уровня аннотаций: JPA (персистентность), Hibernate Search (полнотекстовое индексирование), Jackson (JSON-сериализация) и пользовательские аннотации ProjectForge (@PropertyInfo для метаданных UI).

Интеграция с Hibernate Search

@Indexed + @FullTextField на comment включает полнотекстовый поиск по всем записям балансов. @IndexedEmbedded(includeDepth = 1) на bankAccount индексирует поля банковского счёта на один уровень вглубь — поиск "IBAN" в полнотекстовом индексе найдёт родительский BankAccountDO. ReindexOnUpdate.SHALLOW означает, что изменение BankAccountDO автоматически переиндексирует его записи балансов.
