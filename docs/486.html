#486: LdapConfig.java

Java config — LDAP connection settings. Fields: serverUrl (ldaps://dc.example.com:636), baseDN (dc=example,dc=com), bindUser/bindPassword (service account), userBaseDN (ou=users,...), groupBaseDN (ou=groups,...), sslTrustAll (dev only!), masterSlaveMode (read from LDAP vs write to LDAP). Stored in ProjectForge config XML.
