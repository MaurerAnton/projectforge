#487: LdapConnector.java

Java connector — LDAP connection management. Creates and pools JNDI LdapContext connections. Handles: SSL/TLS (LDAPS), StartTLS, connection pooling (Apache Commons Pool), health checks (periodic BIND test), failover (primary/secondary LDAP server), and SASL/GSSAPI (Kerberos) authentication. The single point of entry for all LDAP operations — used by all Ldap*Dao classes.
