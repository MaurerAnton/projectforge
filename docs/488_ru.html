projectforge-business/src/main/java/org/projectforge/business/ldap/LdapConfig.java Java-класс, projectforge-business/src/main/java/org/projectforge/business/ldap/LdapConfig.java 312 строк · 154 кода · 117 комментариев · 41 пустая
Контейнер конфигурации для настроек подключения LDAP. Поля включают: `serverUrl` (например, `ldaps://dc.example.com:636`), `baseDN`, `bindUser`/`bindPassword` (учётные данные сервисной учётной записи), `userBaseDN`, `groupBaseDN`, `sslTrustAll` (только для разработки) и `masterSlaveMode` (управляет направлением чтения из LDAP и записи в LDAP). Хранится в конфигурационном XML ProjectForge.
