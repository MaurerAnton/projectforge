Java DAO — LDAP group operations. CRUD for groupOfNames / posixGroup entries. Methods: createGroup(), updateGroup(), deleteGroup(), addMember()/removeMember(), getMembers(). Manages the member / memberUid attribute for group membership synchronization between ProjectForge groups and LDAP directory groups.
