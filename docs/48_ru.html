Что делает

Объект доступа к данным для балансов банковских счетов — первый фактический исходный файл Kotlin в документации. Следует стандартному шаблону DAO ProjectForge: заголовок GPLv3 (строки 1-22), расширяет BaseDao<T> (строка 38), реализует hasAccess() для авторизации (строки 42-69), предоставляет метод именованного запроса getByTimePeriod() (строки 75-83). Аннотирован @Service для внедрения зависимостей Spring.

Архитектура

38 class BankAccountBalanceDao : BaseDao<BankAccountBalanceDO>(BankAccountBalanceDO::class.java)

Ключевые выводы

  • 84 строки, стандартный шаблон DAO: Расширяет BaseDao, переопределяет hasAccess и newInstance, добавляет бизнес-специфичные методы запросов.
  • Трёхуровневая проверка доступа: Целостность объекта → членство в группе → разрешение родительского объекта — вложенный шаблон авторизации, общий для всех DAO.
  • FINANCE_GROUP: Только члены финансовой команды могут получать доступ к балансам банковских счетов — ролевая авторизация, жёстко заданная в DAO, а не в аннотациях Spring Security.
  • KotlinLogging: Использует mu.KotlinLogging из #33 (kotlin-logging 3.0.5) — стандартная структура логирования во всех исходных файлах Kotlin.
