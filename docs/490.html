#490: LdapGroup.java

Java model — LDAP group DTO. Fields: dn (distinguished name), cn (common name), description, members (list of member DNs), gidNumber (POSIX group ID). Mapped to/from LDAP attributes by LdapGroupDao. Not a JPA entity — pure DTO representing LDAP entries in memory.
