#495: LdapOrganizationalUnitDao.java

Java DAO — LDAP OU management. Creates/deletes organizationalUnit entries in the LDAP tree. Used by the LDAP setup wizard to create the initial OU structure: ou=users,dc=..., ou=groups,dc=.... Also manages OU hierarchy for department-based grouping.
