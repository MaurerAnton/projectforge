#496: LdapPersonDao.java

Java DAO — LDAP person operations. CRUD for person entries across multiple object classes: inetOrgPerson, organizationalPerson, person, posixAccount, shadowAccount. Deals with name, email, phone, address, POSIX UID/GID, home directory, login shell. The main user-facing LDAP DAO — called by LdapDao for person-specific operations.
