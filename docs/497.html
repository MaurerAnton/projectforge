#497: LdapPerson.java

Java model — LDAP person DTO. Fields: dn, uid, cn, givenName, sn, mail, telephoneNumber, title, uidNumber (POSIX), gidNumber (POSIX), homeDirectory, loginShell, sambaNTPassword, sambaLMPassword. The richest LDAP DTO — covers both enterprise directory and POSIX/Samba fields.
