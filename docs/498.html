#498: LdapPosixAccountsConfig.java

Java config — POSIX account configuration. Fields: uidNumberStart (starting UID, e.g. 10000), gidNumber (default GID), homeDirectoryPrefix (/home/), loginShell (/bin/bash), sambaEnabled (generate Samba hashes?). Used when creating UNIX/POSIX user accounts in LDAP for Samba file server authentication.
