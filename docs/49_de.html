Was es tut

Die JPA-Entität für Bankkonten – die übergeordnete Entität von BankAccountBalanceDO (#46). Im Gegensatz zu #46, das DefaultBaseDO erweitert, erweitert diese Klasse BaseUserGroupRightsDO – eine umfangreichere Basisklasse, die objektbezogene Benutzer-/Gruppenberechtigungszuweisungen unterstützt. Aus diesem Grund kann BankAccountDao (#47) BaseUserGroupRightUtils.hasAccess() für eine feingranulare Zugriffskontrolle aufrufen.

Bemerkenswerte Details

54 open class BankAccountDO : BaseUserGroupRightsDO(), DisplayNameCapable
55   override val displayName: String
56     @Transient get() { return "$iban $title" }

DisplayNameCapable stellt einen berechneten Anzeigenamen (IBAN + Name) bereit, der in UI-Dropdowns und Suchergebnissen verwendet wird. displayName ist @Transient – wird nicht in der Datenbank gespeichert, sondern zur Laufzeit berechnet.

72 @get:Transient override var owner: PFUserDO? = null  // "Unbenutztes Feld"

BaseUserGroupRightsDO erfordert ein owner-Feld, aber Bankkonten haben keine einzelnen Eigentümer – das Feld wird als @Transient überschrieben (nicht gespeichert) und ist immer null.

50 @TypeBinding(binder = TypeBinderRef(type = HibernateSearchUsersGroupsTypeBinder::class))

Die Hibernate-Search-Brücke indiziert, welche Benutzer/Gruppen Rechte an jedem Bankkonto haben – dies ermöglicht Volltextsuchabfragen wie „finde alle Bankkonten, die für Benutzer 42 sichtbar sind“. Zeile 49 zeigt die alte @ClassBridge-Syntax (auskommentiert), die durch den neueren @TypeBinding-Ansatz ersetzt wurde.
