Qué hace

La entidad JPA para cuentas bancarias — la clase padre de BankAccountBalanceDO (#46). A diferencia de #46 que extiende DefaultBaseDO, esta extiende BaseUserGroupRightsDO — una clase base más rica que soporta asignaciones de permisos por objeto para usuario/grupo. Es por esto que BankAccountDao (#47) puede llamar a BaseUserGroupRightUtils.hasAccess() para un control de acceso detallado.

DisplayNameCapable proporciona un nombre para mostrar calculado (IBAN + nombre) utilizado en listas desplegables de la UI y resultados de búsqueda. displayName es @Transient — no se almacena en la base de datos, se calcula en tiempo de ejecución.

72 @get:Transient override var owner: PFUserDO? = null  // "Campo no utilizado"

BaseUserGroupRightsDO requiere un campo owner pero las cuentas bancarias no tienen propietarios individuales — el campo se sobrescribe como @Transient (no almacenado) y siempre es nulo.

50 @TypeBinding(binder = TypeBinderRef(type = HibernateSearchUsersGroupsTypeBinder::class))

El puente de Hibernate Search indexa qué usuarios/grupos tienen derechos sobre cada cuenta bancaria — permitiendo consultas de búsqueda de texto completo como "encontrar todas las cuentas bancarias visibles para el usuario 42". La línea 49 muestra la sintaxis antigua @ClassBridge (comentada) reemplazada por el enfoque más nuevo @TypeBinding.
