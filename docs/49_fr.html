Ce qu'il fait

L'entité JPA pour les comptes bancaires — le parent de BankAccountBalanceDO (#46). Contrairement à #46 qui étend DefaultBaseDO, celle-ci étend BaseUserGroupRightsDO — une classe de base plus riche qui prend en charge les affectations de permissions utilisateur/groupe par objet. C'est pourquoi BankAccountDao (#47) peut appeler BaseUserGroupRightUtils.hasAccess() pour un contrôle d'accès fin.

DisplayNameCapable fournit un nom d'affichage calculé (IBAN + nom) utilisé dans les listes déroulantes de l'interface utilisateur et les résultats de recherche. displayName est @Transient — non stocké dans la base de données, calculé à l'exécution.

72 @get:Transient override var owner: PFUserDO? = null  // "Champ inutilisé"

BaseUserGroupRightsDO nécessite un champ owner mais les comptes bancaires n'ont pas de propriétaires individuels — le champ est redéfini comme @Transient (non stocké) et toujours nul.

50 @TypeBinding(binder = TypeBinderRef(type = HibernateSearchUsersGroupsTypeBinder::class))

Le pont Hibernate Search indexe quels utilisateurs/groupes ont des droits sur chaque compte bancaire — permettant des requêtes de recherche en texte intégral comme "trouver tous les comptes bancaires visibles par l'utilisateur 42". La ligne 49 montre l'ancienne syntaxe @ClassBridge (commentée) remplacée par la nouvelle approche @TypeBinding.
