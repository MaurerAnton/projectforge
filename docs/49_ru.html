Назначение

JPA-сущность для банковских счетов — родительская для BankAccountBalanceDO (#46). В отличие от #46, которая расширяет DefaultBaseDO, эта расширяет BaseUserGroupRightsDO — более богатый базовый класс, поддерживающий назначение прав для пользователей/групп на уровне объекта. Именно поэтому BankAccountDao (#47) может вызывать BaseUserGroupRightUtils.hasAccess() для детального контроля доступа.

Примечательные детали

54 open class BankAccountDO : BaseUserGroupRightsDO(), DisplayNameCapable
55   override val displayName: String
56     @Transient get() { return "$iban $title" }

DisplayNameCapable предоставляет вычисляемое отображаемое имя (IBAN + name), используемое в выпадающих списках UI и результатах поиска. displayName является @Transient — не хранится в базе данных, вычисляется во время выполнения.

72 @get:Transient override var owner: PFUserDO? = null  // "Неиспользуемое поле"

BaseUserGroupRightsDO требует поле owner, но банковские счета не имеют индивидуальных владельцев — поле переопределено как @Transient (не сохраняется) и всегда равно null.

50 @TypeBinding(binder = TypeBinderRef(type = HibernateSearchUsersGroupsTypeBinder::class))

Мост Hibernate Search индексирует, какие пользователи/группы имеют права на каждый банковский счёт — обеспечивая полнотекстовые запросы вида "найти все банковские счета, видимые пользователю 42". Строка 49 показывает старый синтаксис @ClassBridge (закомментирован), заменённый новым подходом @TypeBinding.
