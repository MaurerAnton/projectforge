#502: LdapSambaAccountsUtils.java

Java utility — Samba attribute computation. Generates: sambaSID (from domain SID + RID), sambaNTPassword (NT hash via Md4), sambaLMPassword (LM hash), sambaAcctFlags (account flags: U=user, D=disabled), sambaHomeDrive, sambaHomePath. Uses LdapSambaAccountsConfig and SmbEncrypt.
