#508: LdapUserValues.java

Java model — LDAP user attribute values for writing. Fields: uid, cn, sn, givenName, mail, userPassword (hashed), uidNumber, gidNumber, homeDirectory, loginShell, sambaNTPassword, sambaLMPassword, sambaSID. Decouples read model (LdapUser) from write model (LdapUserValues) — same pattern as LdapGroupValues.
