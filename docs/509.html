#509: LdapUtils.java

Java utility — LDAP helper methods. escapeDN() (sanitizes distinguished names), escapeFilter() (sanitizes LDAP search filters — prevents LDAP injection), parseDN() (extracts RDN from full DN), getAttributeValue() (null-safe JNDI attribute extraction). Critical for security — the filter escaping prevents LDAP injection attacks.
