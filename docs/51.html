File #51: BankAccountRecordDao.kt

Path: ./plugins/.../BankAccountRecordDao.kt · Source: GitHub

DAO for bank account records (individual transactions). Same pattern as BankAccountBalanceDao (#45): extends BaseDao, 3-tier auth (object integrity → FINANCE_GROUP → parent delegation), named query getByTimePeriod(). The !! on bankAccountDao.find(accountId) is the same pattern as #45 line 76 — validates account existence for access checking.

Auth asymmetry: Uses accessChecker.isLoggedInUserMemberOfGroup() (current logged-in user) rather than checking the passed user parameter — different from BankAccountDao (#47) which checks isUserMemberOfGroup(user, ...) explicitly.
