#510: MyTrustManager.java

Java SSL trust manager — custom X509 certificate trust manager for LDAP TLS/SSL connections. Implements X509TrustManager. Three modes: TRUST_ALL (dev only — accepts any certificate, warns in logs), TRUST_SYSTEM (delegates to default Java trust store), TRUST_CUSTOM (loaded from a trustStoreFile path configured in LdapConfig). Critical when connecting to LDAP servers with self-signed or internal CA certificates.
