#511: PFUserDOConverter.java

Java converter — PFUserDO → LDAP attributes. Converts ProjectForge user to LdapUserValues: maps username → uid, firstName + lastName → cn, email → mail, passwordHash → userPassword (with {SSHA} prefix). Handles the full user-to-LDAP attribute mapping including POSIX and Samba fields from user settings.
