#513: LoginDefaultHandler.java

Java handler — default database login. Implements LoginHandler. Authenticates against the local database: bcrypt password comparison with PFUserDO.password. Performs: brute-force check (LoginProtection), account status check (active/inactive/locked), password expiry check, and "stay logged in" cookie generation. The standard login path — used when no LDAP/IDP is configured.
