#516: LoginProtectionMap.java

Java utility — stores failed login attempts per (username × IP) key. ConcurrentHashMap with: attempt count, first attempt timestamp, last attempt timestamp. Used by LoginProtection for brute-force detection. Entries expire after configurable cooldown (default 15 min). Thread-safe — handles concurrent login attempts from multiple IPs.
