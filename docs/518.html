#518: LoginResultStatus.java

Java enum — I18nEnum. Values: SUCCESS, FAILED, LOGIN_TIME_OFFSET (locked out), ACCOUNT_INACTIVE, PASSWORD_EXPIRED, PASSWORD_QUALITY_FAILED. Each has a localizedMessage property. Used by DataTransferPublicSession and the React/Wicket login pages to display appropriate error messages.
