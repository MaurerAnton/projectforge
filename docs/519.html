#519: PasswordCheckResult.java

Java model — password quality check result. Fields: valid, warnings (list of i18n messages), errors (hard failures). Checks: minimum length (8 chars), complexity (uppercase + lowercase + digit + special char), no common passwords (from dictionary file), no username in password, no consecutive characters. Used during password change — blocks weak passwords.
