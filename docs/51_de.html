Was es tut

Der REST-Controller für Bankkonto-CRUD — generiert List-/Erstellungs-/Bearbeitungs-/Lösch-Endpunkte unter ${Rest.URL}/bankAccount. Erweitert AbstractDTOPagesRest, das automatisch REST-Endpunkte für die gepaarten DO/DTO/DAO-Typen generiert. Definiert UI-Layouts (Listen- + Bearbeitungsseiten) programmatisch über ProjectForge's UI-DSL — keine HTML-Vorlagen, das React-Frontend liest das Layout-JSON und rendert entsprechend.

Generierte Endpunkte

AbstractDTOPagesRest generiert automatisch diese REST-Endpunkte aus den Typparametern:

MethodeEndpunktZweck
GET/bankAccountLayout der Listenseite + Daten
GET/bankAccount/{id}Layout der Bearbeitungsseite + geladene Entität
POST/bankAccountNeues Bankkonto erstellen
PUT/bankAccount/{id}Vorhandenes Bankkonto aktualisieren
DELETE/bankAccount/{id}Bankkonto weich löschen

Wichtige Erkenntnisse

  • 190 Zeilen, vollständiger CRUD + UI: Eine Klasse generiert den gesamten Listen-/Bearbeitungs-/Löschablauf ohne HTML-Vorlagen.
  • UI-DSL über JSON: ProjectForge's UILayout/UIFieldset/UISelect-API generiert JSON, das das React-Frontend dynamisch rendert.
  • 6 Zugriffsauswahlen: Benutzer + Gruppen × (Vollzugriff + Lesezugriff) in einem 2-Spalten-Raster — Minimalzugriff nicht enthalten.
  • AG-Grid-Integration: agGridSupport konfiguriert automatisch Sortierung, Filterung und Paginierung.
  • Import-Ablagezone: UIDropArea akzeptiert Kontoauszugsdateien — hochgeladen an BankingServicesRest.import/{id}.
