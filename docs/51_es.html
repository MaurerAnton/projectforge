Qué hace

El controlador REST para CRUD de cuentas bancarias — genera endpoints de listar/crear/editar/eliminar en ${Rest.URL}/bankAccount. Extiende AbstractDTOPagesRest que genera automáticamente endpoints REST para los tipos DO/DTO/DAO emparejados. Define diseños de UI (páginas de lista + edición) programáticamente mediante el DSL de UI de ProjectForge — sin plantillas HTML, el frontend React lee el JSON de diseño y lo renderiza en consecuencia.

Endpoints generados

AbstractDTOPagesRest genera automáticamente estos endpoints REST a partir de los parámetros de tipo:

MétodoEndpointPropósito
GET/bankAccountDiseño de página de lista + datos
GET/bankAccount/{id}Diseño de página de edición + entidad cargada
POST/bankAccountCrear nueva cuenta bancaria
PUT/bankAccount/{id}Actualizar cuenta bancaria existente
DELETE/bankAccount/{id}Eliminación suave de cuenta bancaria

Conclusiones clave

  • 190 líneas, CRUD completo + UI: Una clase genera todo el flujo de listar/editar/eliminar sin plantillas HTML.
  • DSL de UI sobre JSON: La API UILayout/UIFieldset/UISelect de ProjectForge genera JSON que el frontend React renderiza dinámicamente.
  • 6 selectores de acceso: Usuarios + Grupos × (Acceso completo + Acceso solo lectura) en una cuadrícula de 2 columnas — Acceso mínimo no incluido.
  • Integración con AG Grid: agGridSupport configura ordenamiento, filtrado y paginación automáticamente.
  • Zona de arrastre para importación: UIDropArea acepta archivos de extractos bancarios — se suben a BankingServicesRest.import/{id}.
