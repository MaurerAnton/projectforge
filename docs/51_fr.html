Ce qu'il fait

Le contrôleur REST pour le CRUD des comptes bancaires — génère les points d'accès de liste/création/édition/suppression à ${Rest.URL}/bankAccount. Étend AbstractDTOPagesRest qui génère automatiquement les points d'accès REST pour les types DO/DTO/DAO appariés. Définit les mises en page UI (pages liste + édition) de manière programmatique via le DSL UI de ProjectForge — pas de modèles HTML, le frontend React lit le JSON de mise en page et le rend en conséquence.

Points d'accès générés

AbstractDTOPagesRest génère automatiquement ces points d'accès REST à partir des paramètres de type :

MéthodePoint d'accèsObjectif
GET/bankAccountMise en page de la liste + données
GET/bankAccount/{id}Mise en page d'édition + entité chargée
POST/bankAccountCréer un nouveau compte bancaire
PUT/bankAccount/{id}Mettre à jour un compte bancaire existant
DELETE/bankAccount/{id}Suppression logicielle du compte bancaire

Points clés à retenir

  • 190 lignes, CRUD complet + UI : Une seule classe génère l'ensemble du flux liste/édition/suppression sans modèles HTML.
  • DSL UI sur JSON : L'API UILayout/UIFieldset/UISelect de ProjectForge génère du JSON que le frontend React rend dynamiquement.
  • 6 sélecteurs d'accès : Utilisateurs + Groupes × (Accès complet + Accès en lecture seule) dans une grille à 2 colonnes — Accès minimal non inclus.
  • Intégration AG Grid : agGridSupport configure le tri, le filtrage et la pagination automatiquement.
  • Zone de dépôt d'importation : UIDropArea accepte les fichiers de relevés bancaires — téléchargés vers BankingServicesRest.import/{id}.
