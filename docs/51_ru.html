Назначение

REST-контроллер для CRUD-операций с банковскими счетами — генерирует конечные точки для списка/создания/редактирования/удаления по адресу ${Rest.URL}/bankAccount. Расширяет AbstractDTOPagesRest, который автоматически генерирует REST-эндпоинты для пар DO/DTO/DAO. Определяет UI-макеты (страницы списка и редактирования) программно с помощью UI DSL ProjectForge — без HTML-шаблонов, React-фронтенд читает JSON макета и отображает соответствующим образом.

Сгенерированные конечные точки

AbstractDTOPagesRest автоматически генерирует следующие REST-эндпоинты на основе параметров типа:

МетодЭндпоинтНазначение
GET/bankAccountМакет страницы списка + данные
GET/bankAccount/{id}Макет страницы редактирования + загруженная сущность
POST/bankAccountСоздание нового банковского счета
PUT/bankAccount/{id}Обновление существующего банковского счета
DELETE/bankAccount/{id}Мягкое удаление банковского счета

Ключевые выводы

  • 190 строк, полный CRUD + UI: Один класс генерирует весь поток списка/редактирования/удаления без HTML-шаблонов.
  • UI DSL через JSON: API UILayout/UIFieldset/UISelect ProjectForge генерирует JSON, который динамически отображается React-фронтендом.
  • 6 селекторов доступа: Пользователи + Группы × (Полный доступ + Только чтение) в сетке из 2 столбцов — Минимальный доступ не включён.

  • Зона для импорта: UIDropArea принимает файлы банковских выписок — загружаются в BankingServicesRest.import/{id}.
