#521: ContractDO.kt

Entity / DO, projectforge-business/src/main/kotlin/org/projectforge/business/orga/ContractDO.kt

JPA entity mapped to T_CONTRACT. Represents a legal contract with dual-party fields (co-contractor A/B, contract person A/B, signer A/B), dates (signing, validity from/until), status, type, text, reference, filing, resubmission, and JCR attachments. Supports number-based uniqueness validation. 176 lines.

Architecture

Extends DefaultBaseDO and implements AttachmentsInfo for JCR document storage. Named queries: FIND_OTHER_BY_NUMBER (uniqueness check), SELECT_MIN_MAX_DATE (year range). Fields annotated with @PropertyInfo for auto-generated UIs. Attachment fields excluded from history via @NoHistory.
