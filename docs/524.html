#524: PostausgangDao.java

DAO / Service, projectforge-business/src/main/java/org/projectforge/business/orga/PostausgangDao.java

Data access service for PostausgangDO. Extends BaseDao with user right ORGA_OUTGOING_MAIL. Provides auto-completion for sender, person, and content fields. select() filters by year/month and orders by date desc, recipient asc. 83 lines.

Architecture

Standard BaseDao pattern. ENABLED_AUTOCOMPLETION_PROPERTIES controls typeahead for UI. select() wraps filter in PostFilter and uses QueryFilter.setYearAndMonth. getYears() uses named query + SQLHelper.
