#529: VisitorbookFilter.java

Filter, projectforge-business/src/main/java/org/projectforge/business/orga/VisitorbookFilter.java

Search filter for visitor book entries. Supports date range filtering (startDay/stopDay) with UTC conversion and showOnlyActiveEntries flag. XStream alias for serialization.

Architecture

Extends BaseSearchFilter. getUTCStartTime()/getUTCStopTime() convert LocalDate to UTC via PFDay. Note: getUTCStopTime() uses startDay instead of stopDay — appears to be a bug.
