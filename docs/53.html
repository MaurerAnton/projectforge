File #53: BankAccountRecordImportPageRest.kt

Path: ./plugins/.../BankAccountRecordImportPageRest.kt · Source: GitHub

REST controller for the bank statement import workflow. Extends AbstractImportPageRest — handles CSV/MT940 file upload, field mapping, preview, and final import via BankingImportJob. AG Grid columns include a diffCell renderer (line ~20) for highlighting matched/updated fields during import review. The import runs as a background job (JobHandler.addJob) for large bank statements.

Import flow: upload → parse → preview (AG Grid with diff) → select entries → BankingImportJob runs asynchronously → navigate back to bank account page.
