#530: PasswordQualityServiceImpl.java

Java service impl — enforces password quality checks. Implements PasswordQualityService. Checks: minimum length (8), complexity (3 of 4: uppercase, lowercase, digit, special), no dictionary words (from /usr/share/dict/words), no username in password (case-insensitive), no 3+ consecutive identical characters, no keyboard patterns (qwerty, 123456). Integrates with PasswordCheckResult. Called during password change and user creation.
