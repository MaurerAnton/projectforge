#532: ExportJson.java

Java utility — JSON export for Groovy scripts. Converts any Java object to JSON using Jackson ObjectMapper. Provides scripting-friendly API: ExportJson.toJson(myObject). Handles Hibernate proxy unwrapping, date formatting, and lazy-loading edge cases — essential for Groovy script authors who need JSON output from JPA entities.
