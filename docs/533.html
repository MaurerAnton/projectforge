#533: GroovyExecutor.java

Java engine — Groovy script execution engine. Compiles and runs Groovy scripts with project DAOs available as variables. Provides: execute(scriptText) → script result, sandboxed execution (restricted imports), timeout (30s default), output capture (System.out → string), and variable injection (each registered DAO becomes a script variable, e.g. todoDao, rechnungDao). The foundation of ProjectForge's scripting/automation system — used by scheduled jobs, mail templates, and the scripting console.
