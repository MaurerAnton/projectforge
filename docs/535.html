#535: NullObject.java

Java model — null-safe value holder for scripts. Wraps potentially null DAO results so Groovy scripts don't throw NullPointerException. Implements Groovy's asBoolean() — evaluates to false when null. Used by GroovyExecutor to return safe values from DAO queries: def user = userDao.getById(999) → NullObject if not found, not null.
