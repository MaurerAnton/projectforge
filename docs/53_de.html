JPA-Entität für einzelne Bankkontobuchungen (Datensätze). 15 Felder, die die Standarddaten eines Kontoauszugs abdecken: Betrag, Datum, Valuta, Typ, Betreff, Währung, SEPA-Felder (Gläubiger-ID, Mandatsreferenz, Kundenreferenz, Inkassoreferenz), Empfänger/Absender, IBAN, BIC. Zusätzlich ein Prüfsummenfeld zur Erkennung von Manipulationen nach dem Import.

fun buildCheckSum(): String {
  sb.append(amount?.setScale(2)).append('|')
  sb.append(StringHelper.removeNonDigitsAndNonASCIILetters(subject)).append('|')
  ... // 8 Felder, mit | getrennt verkettet
  return DigestUtils.sha256Hex(sb.toString())
}

buildCheckSum() berechnet einen SHA-256-Hash über 8 normalisierte Felder. ensureChecksum (berechnete Eigenschaft) erzeugt die Prüfsumme automatisch, falls sie null ist. Wird von BankAccountRecordPagesRest (#55) zur Dublettenerkennung verwendet: Zwei Datensätze mit identischer Prüfsumme, aber unterschiedlichen IDs werden als potenzielle Duplikate markiert. Dient auch zur Erkennung manueller Manipulationen importierter Datensätze.
