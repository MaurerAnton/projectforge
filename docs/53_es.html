Qué hace

Entidad JPA para transacciones bancarias individuales (registros). 15 campos que cubren datos estándar de extractos bancarios: importe, fecha, fechaValor, tipo, concepto, moneda, campos SEPA (idAcreedor, referenciaMandato, referenciaCliente, referenciaCobro), receptor/remitente, IBAN, BIC. Además, un campo de suma de verificación para detectar manipulaciones posteriores a la importación.

Integridad de la suma de verificación

fun buildCheckSum(): String {
  sb.append(amount?.setScale(2)).append('|')
  sb.append(StringHelper.removeNonDigitsAndNonASCIILetters(subject)).append('|')
  ... // 8 campos concatenados con separador |
  return DigestUtils.sha256Hex(sb.toString())
}

buildCheckSum() calcula un hash SHA-256 sobre 8 campos normalizados. ensureChecksum (propiedad calculada) genera automáticamente la suma de verificación si es nula. Utilizado por BankAccountRecordPagesRest (#55) para detección de duplicados: dos registros con sumas de verificación idénticas pero IDs diferentes se marcan como posibles duplicados. También se usa para detectar manipulación manual de registros importados.
