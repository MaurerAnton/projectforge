Назначение

JPA-сущность для отдельных банковских транзакций (записей). 15 полей, охватывающих стандартные данные банковской выписки: сумма, дата, дата валютирования, тип, назначение, валюта, поля SEPA (идентификатор получателя, ссылка на мандат, ссылка на клиента, ссылка на инкассо), получатель/отправитель, IBAN, BIC. Плюс поле контрольной суммы для обнаружения изменений после импорта.

Целостность контрольной суммы

fun buildCheckSum(): String {
  sb.append(amount?.setScale(2)).append('|')
  sb.append(StringHelper.removeNonDigitsAndNonASCIILetters(subject)).append('|')
  ... // 8 полей, объединённых разделителем |
  return DigestUtils.sha256Hex(sb.toString())
}

buildCheckSum() вычисляет SHA-256 хеш по 8 нормализованным полям. ensureChecksum (вычисляемое свойство) автоматически генерирует контрольную сумму, если она равна null. Используется в BankAccountRecordPagesRest (#55) для обнаружения дублей: две записи с одинаковой контрольной суммой, но разными ID помечаются как потенциальные дубликаты. Также используется для обнаружения ручного изменения импортированных записей.
