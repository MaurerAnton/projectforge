File #54: BankAccountRecord.kt

Path: ./plugins/.../BankAccountRecord.kt · Source: GitHub

REST DTO for bank account records — extends BaseDTO with ImportPairEntry.Modified for import diff support. Implements a fuzzy matching algorithm (matchScore()) that pairs imported records with existing DB records by scoring field similarity on the same date.

properties override defines which fields are checked for modifications during import. normalizeString() strips to a-z/0-9 for case/diacritic-insensitive comparison. The getScore() overloads handle both String and BigDecimal comparison — 1 point per matching field, 0 for non-matching, -1 if dates differ (immediate disqualification).
