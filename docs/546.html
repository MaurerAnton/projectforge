#546: TeamCalDao.kt

DAO / Service, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/admin/TeamCalDao.kt

Kotlin DAO for TeamCalDO (team calendars). Extends BaseDao. select() filters by owner type (ALL/OWN/OTHERS/ADMIN) and access level (full/readonly/minimal). afterInsertOrModify invalidates cache and manages external subscription updates. 199 lines.

Architecture

Uses TeamCalRight for access checks on each calendar during selection. External subscription handling: sets minimum 15-minute interval, triggers cache update on URL change, cleans up on subscription removal. Search fields include usersgroups, owner.username/firstname/lastname.
