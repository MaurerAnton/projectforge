#547: TeamCalDO.kt

Entity / DO, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/admin/model/TeamCalDO.kt

JPA entity mapped to T_CALENDAR. Represents a team calendar with: title, owner, description, external subscription fields (URL, hash, binary data, update interval), leave-day inclusion users/groups, and base user-group rights. Implements BaseUserGroupRightsDO for group-based access. 201 lines.

Architecture

Hibernate Search-indexed with custom HibernateSearchUsersGroupsTypeBinder for usersgroups field. External subscription: externalSubscriptionCalendarBinary is lazily loaded BLOB, externalSubscriptionUrlAnonymized truncates URL after domain. Custom equals()/hashCode() based on id and title. JSON deserialization via @JsonCreator.
