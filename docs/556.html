#556: TeamEventRight.java

Access Control, projectforge-business/src/main/java/org/projectforge/business/teamcal/event/right/TeamEventRight.java

Access rights for team events, delegating to TeamCalRight. Event access derives from calendar ownership: owners and full-access users can update/delete; readonly users can select; minimal-access users see cleared fields. External subscription calendars are read-only. 206 lines.

Architecture

Extends UserRightAccessCheck for TeamEventDO. Composes TeamCalRight for calendar-level permission checks. hasUpdateAccess() blocks modifications to external subscription calendars. hasMinimalAccess() triggers field-clearing for privacy (subject, location, attendees, reminders hidden). Demo users have full update access as a development convenience.
