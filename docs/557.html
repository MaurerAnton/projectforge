#557: TeamEventDao.kt

DAO / Service, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/TeamEventDao.kt

Core Kotlin DAO for TeamEventDO. Key features: recurrence event rolling (rollOutRecurrenceEvents), series modification handling (single/future/all modes), external subscription integration, attendee management, all-day event UTC normalization, sequence increment on changes, and location auto-completion. 770 lines.

Architecture

Largest DAO in the codebase. Recurrence: handleSeriesUpdates() manages single/future series modifications using transient attributes; rollOutRecurrenceEvents() calculates recurring instances with exdate filtering via ical4j Recur. External subscriptions via TeamEventExternalSubscriptionCache. Query building: date range extensions for all-day events, recurrence vs non-recurrence queries. Attendee cleanup: removeAttendeeByAddressIdFromAllEvents().
