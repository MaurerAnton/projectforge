#558: TeamEventDO.kt

Entity / DO, projectforge-business/src/main/kotlin/org/projectforge/business/teamcal/event/model/TeamEventDO.kt

JPA entity mapped to T_PLUGIN_CALENDAR_EVENT. iCal-compatible event with: RFC5545 recurrence (RRULE, EXDATE, RECURRENCE-ID, UNTIL), attendees, attachments, reminders (duration + action type), organizer, sequence tracking, and owner-timezone-aware recurrence data parsing. Unique constraint on (uid, calendar_fk). 1005 lines.

Architecture

Implements ICalendarEvent. Core iCal: RRULE-based recurrence with Recur object caching, exdate CSV parsing, recurrence reference for series splitting. setRecurrence() overloads accept RRule or TeamEventRecurrenceData. getRecurrenceData() reverse-parses RRULE. clearFields() for minimal-access privacy. mustIncSequence() compares all fields. clone() deep-copies attendees and attachments. Creator defaults to calendar owner.
