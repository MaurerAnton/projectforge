#558: AlarmConverter.java

Java converter — iCalendar VALARM ↔ TeamEvent alarm property. Converts between RFC 5545 VALARM (TRIGGER, ACTION=DISPLAY/AUDIO, DESCRIPTION) and TeamEvent's alarm model (minutes before event, email/notification type). Used when importing/exporting .ics files and for iCal feed generation.
