#561: EventHandle.java

Java interface — iCal VEVENT handler contract. Parses a VEVENT from the ical4j component tree and converts it to a TeamEvent. Handles: DTSTART/DTEND, SUMMARY, LOCATION, DESCRIPTION, RRULE (recurrence), EXDATE (exceptions), ATTENDEE. Implemented by RecurringEventHandle and single-event handler.
