#563: ICalHandler.java

Java engine — main iCal import/export handler. Uses ical4j library. importICS(inputStream) → parses VCALENDAR, iterates VEVENT components, delegates to VEventComponentConverter for each event. exportICS(events) → generates complete .ics file with VCALENDAR wrapper. Handles: timezone conversion (TZID → Java TimeZone), charset encoding, line folding (RFC 5545 §3.1), and multi-calendar import (multiple VCALENDAR blocks in one file).
