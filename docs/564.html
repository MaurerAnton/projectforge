#564: RecurringEventHandle.java

Java handler — handles recurring VEVENTs with RRULE. Parses recurrence rule (FREQ=DAILY/WEEKLY/MONTHLY/YEARLY, INTERVAL, COUNT/UNTIL), expansion dates (generates all occurrences from RRULE), and exception dates (EXDATE). Converts a single RRULE-bearing VEVENT to multiple TeamEvent instances — one per occurrence. Handles edge cases: DTSTART with time vs all-day, BYDAY/BYMONTHDAY rules, RDATE (additional occurrences).
