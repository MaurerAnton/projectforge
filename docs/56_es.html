Qué hace

Controlador REST para lista/edición de registros de cuentas bancarias — la clase PagesRest con más funcionalidades del plugin bancario. Añade filtros mágicos (período, selección múltiple de cuentas, duplicados, errores de checksum), post-procesamiento (detección de duplicados mediante checksum, validación de checksum, estadísticas) y coloreado de filas en AG Grid (verde para montos positivos/ingresos).

Filtros mágicos

addMagicFilterElements():
  period:          Filtro DATE (rango de fechas)
  accounts:        Selección múltiple de cuentas bancarias (cargadas desde bankAccountDao)
  doublets:        BOOLEAN — mostrar solo registros con checksums coincidentes
  checksumErrors:  BOOLEAN — mostrar solo registros con checksums incorrectos

Post-procesamiento

postProcessResultSet():
  si filtro doublets → filtrar lista por isDoublet()
  si checksumErrors → filtrar por isChecksumError()
  añadir estadísticas → BankAccountRecordStatistics (suma de montos como Markdown)

isDoublet(): registros con el mismo buildCheckSum() pero diferentes IDs
isChecksumError(): checksum != buildCheckSum()

Detección de duplicados y verificación de checksum son filtros en memoria posteriores a la consulta — no pueden expresarse como SQL/JPA. Los duplicados usan BankAccountRecordDO.buildCheckSum() (#52) para detectar entradas idénticas de extractos bancarios que fueron importadas dos veces. Las estadísticas muestran montos totales como Markdown (renderizados en la interfaz de usuario).
