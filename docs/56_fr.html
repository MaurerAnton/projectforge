Ce qu'il fait

Contrôleur REST pour la liste/édition des enregistrements de comptes bancaires — la classe PagesRest la plus riche en fonctionnalités du plugin bancaire. Ajoute des filtres magiques (période, sélection multiple de comptes, doublons, erreurs de somme de contrôle), un post-traitement (détection de doublons via somme de contrôle, validation de somme de contrôle, statistiques) et un colorisation des lignes AG Grid (vert pour les montants positifs/entrants).

Filtres magiques

addMagicFilterElements() :
  période :          filtre DATE (plage de dates)
  comptes :        Sélection multiple de comptes bancaires (chargés depuis bankAccountDao)
  doublons :        BOOLÉEN — afficher uniquement les enregistrements avec des sommes de contrôle correspondantes
  erreursChecksum :  BOOLÉEN — afficher uniquement les enregistrements avec des sommes de contrôle erronées

Post-traitement

postProcessResultSet() :
  si filtre doublons → filtrer la liste pour isDoublet()
  si erreursChecksum → filtrer pour isChecksumError()
  ajouter statistiques → BankAccountRecordStatistics (somme des montants en Markdown)

isDoublet() : enregistrements avec le même buildCheckSum() mais des ID différents
isChecksumError() : checksum != buildCheckSum()

Détection de doublons et vérification de somme de contrôle sont des filtres en mémoire après requête — ils ne peuvent pas être exprimés en SQL/JPA. Les doublons utilisent BankAccountRecordDO.buildCheckSum() (#52) pour détecter les entrées de relevé bancaire identiques qui ont été importées deux fois. Les statistiques affichent les montants totaux en Markdown (rendu dans l'interface utilisateur).
