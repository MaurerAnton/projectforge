Что делает

REST-контроллер для списка/редактирования записей банковских счетов — самый функционально насыщенный класс PagesRest в плагине банкинга. Добавляет магические фильтры (период, множественный выбор счетов, дубликаты, ошибки контрольной суммы), постобработку (обнаружение дубликатов по контрольной сумме, проверка контрольной суммы, статистика) и раскраску строк AG Grid (зелёный для положительных сумм/входящих платежей).

Магические фильтры

addMagicFilterElements():
  period:          Фильтр DATE (диапазон дат)
  accounts:        Множественный выбор банковских счетов (загружается из bankAccountDao)
  doublets:        BOOLEAN — показывать только записи с совпадающими контрольными суммами
  checksumErrors:  BOOLEAN — показывать только записи с нарушенными контрольными суммами

Постобработка

postProcessResultSet():
  если фильтр doublets → отфильтровать список по isDoublet()
  если checksumErrors → отфильтровать по isChecksumError()
  добавить статистику → BankAccountRecordStatistics (сумма сумм в Markdown)

isDoublet(): записи с одинаковым buildCheckSum(), но разными ID
isChecksumError(): контрольная сумма != buildCheckSum()

Обнаружение дубликатов и проверка контрольной суммы выполняются после запроса в памяти — их невозможно выразить через SQL/JPA. Дубликаты используют BankAccountRecordDO.buildCheckSum() (#52) для обнаружения одинаковых записей выписок, импортированных дважды. Статистика отображает общие суммы в Markdown (рендерится в интерфейсе).
