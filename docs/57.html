File #57: BankingImportJob.kt

Path: ./plugins/.../BankingImportJob.kt · Source: GitHub

Async background job for importing bank records. Extends AbstractImportJob with 600s timeout, REFUSE_PER_QUEUE strategy (prevents concurrent imports for the same bank account). Iterates over selected ImportPairEntry items: inserts new records, updates existing ones, or marks unmatched DB records as deleted. Each record gets a checksum computed after import. Access checks delegate to bankAccountDao.
