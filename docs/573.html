#573: RecurrenceFrequencyModeTwo.java

Java model — positional recurrence: "2nd Monday of every month" or "last Friday". Maps to RFC 5545 BYDAY with numeric prefix (+2MO = 2nd Monday, -1FR = last Friday) + BYSETPOS. More complex than ModeOne. Used for events like "team meeting on 3rd Wednesday of each month".
