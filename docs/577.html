#577: TeamEventServiceImpl.java

Java service impl — calendar event business logic. Implements TeamEventService. Handles: event CRUD with attendee notification, recurrence expansion (single RRULE event → multiple occurrences), conflict detection (overlapping events with same attendees), calendar sync (iCal feed generation + external subscription import). The most complex calendar service — coordinates between DAO, iCal converters, and mail system.
