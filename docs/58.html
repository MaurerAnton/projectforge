File #58: BankingImportStorage.kt

Path: ./plugins/.../BankingImportStorage.kt · Source: GitHub

Import storage with matching algorithm. doReconcileImportStorage() pairs imported transactions with existing DB records day-by-day using a score matrix: computes matchScore() from BankAccountRecord (#54) for every read×DB pair, then greedily picks the highest-scoring matches. Unmatched imports become new records; unmatched DB records stay as-is. Includes IBAN validation: imported records with wrong IBAN get an error flag. Maximum 1M records (paranoia counter).
