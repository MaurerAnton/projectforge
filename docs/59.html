File #59: BankingPlugin.kt

Path: ./plugins/.../BankingPlugin.kt · Source: GitHub

Plugin registration entry point. Extends AbstractPlugin: registers the DAO with a plugin ID, creates a menu item under FIBU (MenuItemDefId.FIBU) pointing to ${Constants.REACT_APP_PATH}bankAccount, and loads the BankingI18nResources bundle for translations. Access-checked via bankAccountDao.hasLoggedInUserSelectAccess() — the menu item is hidden if the user lacks FINANCE_GROUP membership.
