#595: TeamCalResponseServlet.java

Java servlet — serves iCal feed requests at /calendar/feed/*. Parses the encrypted token from URL, decrypts it via CryptService, validates user + calendar permissions, generates iCal output via ICalHandler, and streams the .ics file with proper Content-Type (text/calendar). No authentication required — the token itself carries enough info. The entry point for external calendar apps.
