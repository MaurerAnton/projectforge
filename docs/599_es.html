Enumeración para la dirección de ordenamiento utilizada en consultas de partes de horas. Valores: ASC (ascendente) y DESC (descendente).

Arquitectura

Este es un enum de Java mínimo en el paquete de dominio de partes de horas. Proporciona las dos direcciones de ordenamiento estándar utilizadas por el DAO de partes de horas y la capa de filtrado. La clase es utilizada por filtros de búsqueda, cláusulas ORDER BY en consultas de base de datos y ordenamiento de columnas en tablas de la interfaz de usuario. Al estar en el paquete business.timesheet, es específico para el ordenamiento relacionado con partes de horas, pero sigue el mismo patrón que enumeraciones similares en toda la base de código de ProjectForge (por ejemplo, en informes y otros módulos de negocio).

Este archivo no ha tenido cambios funcionales más allá de las actualizaciones anuales de encabezados de derechos de autor desde su commit inicial, lo que indica una API estable y bien definida.
