Énumération pour le sens de tri utilisé dans les requêtes de feuilles de temps. Valeurs : ASC (croissant) et DESC (décroissant).

Architecture

Il s'agit d'une énumération Java minimale dans le package du domaine des feuilles de temps. Elle fournit les deux sens de tri standard utilisés par le DAO des feuilles de temps et la couche de filtrage. La classe est utilisée par les filtres de recherche, les clauses ORDER BY dans les requêtes de base de données et le tri des colonnes des tableaux de l'interface utilisateur. Étant dans le package business.timesheet, elle est spécifique au tri lié aux feuilles de temps mais suit le même modèle que les énumérations similaires présentes dans l'ensemble du code source de ProjectForge (par exemple dans les rapports et autres modules métier).

Ce fichier n'a subi aucune modification fonctionnelle au-delà des mises à jour annuelles des en-têtes de droits d'auteur depuis son commit initial, ce qui indique une API stable et bien définie.
