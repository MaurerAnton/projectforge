Was es tut

CLAUDE.md ist eine Agenten-Anweisungsdatei — sie wird von Claude Code automatisch gelesen, wenn die KI mit diesem Repository interagiert. Betrachten Sie es als das Onboarding-Dokument für KI-Agenten.

Ohne diese Datei müsste Claude Build-Befehle, Codestil und Konventionen durch Lesen von build.gradle.kts, buildSrc/ und vorhandenen Quelldateien selbst ermitteln. Mit ihr kennt der Agent sofort:

  • Wie zu bauen ist (./gradlew build) und wie die Anwendung ausgeführt wird (./gradlew bootRun)
  • Wie ein einzelner Test ausgeführt wird (./gradlew test --tests "...")
  • Den Technologie-Stack (Kotlin JVM 17, Spring Boot, JUnit 5)
  • Code-Konventionen (camelCase, PascalCase, nullable Typen, 4-Leerzeichen-Einrückung)

Abschnitt für Abschnitt

Build-/Test-Befehle (Zeilen 5–11)

Alles bauen:           ./gradlew build
Bauen ohne Tests:      ./gradlew build -x test
Anwendung starten:     ./gradlew bootRun
Einzelner Test:        ./gradlew test --tests "org.projectforge.package.ClassName.methodName"
Paket-Tests:           ./gradlew test --tests "org.projectforge.package.*"
Modul-Tests:           ./gradlew :projectforge-business:test

Sechs Befehle, die die häufigsten Operationen abdecken. Der --tests-Filter ist besonders nützlich — er führt eine einzelne Testmethode aus, ohne die gesamte Testsuite zu starten (was Minuten dauern kann).

Hinweis: Diese funktionieren, weil das root-build.gradle.kts über allprojects { } für alle Unterprojekte gilt.

Beziehung zum Rest des Projekts

Diese Datei ist die Übersetzungsschicht zwischen menschenlesbaren Konventionen und dem, was das Build-System tatsächlich durchsetzt:

CLAUDE.md sagtDurchgesetzt von
"Kotlin JVM Ziel 17"Convention-Plugin Zeile 28: options.release.set(17)
"JUnit 5 für Tests"Convention-Plugin Zeile 38: useJUnitPlatform()
"kotlin-logging"Convention-Plugin Zeile 60: api("kotlin-logging")
"Alles bauen"Root build.gradle.kts: gilt für alle Unterprojekte

CLAUDE.md sagt der KI, was zu tun ist; die Build-Dateien erzwingen es.

Warum es existiert

Diese Datei wurde speziell für Claude Code hinzugefügt — den KI-Codierungsassistenten von Anthropic. Sie folgt der CLAUDE.md-Konvention, bei der der Agent diese Datei zu Beginn jeder Sitzung automatisch liest. Sie wurde wahrscheinlich von demselben Entwickler hinzugefügt, der die KI-gestützte Entwicklung in das Projekt eingeführt hat.

Das Äquivalent für GitHub Copilot wäre .github/copilot-instructions.md oder Inline-Kommentare. Für Cursor wäre es .cursor/rules.md.

Bemerkenswerterweise erwähnt die Datei Kotlin Coroutines (Zeile 22) — aber die aktuelle Codebasis verwendet an mehreren Stellen immer noch Thread (z.B. IdpLoginHandler.kt). Das bedeutet, dass CLAUDE.md eher den gewünschten Stil beschreibt als die aktuelle Realität.
