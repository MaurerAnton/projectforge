Qué hace

CLAUDE.md es un archivo de instrucciones para agentes — es leído automáticamente por Claude Code cuando la IA interactúa con este repositorio. Piense en él como el documento de incorporación para agentes de IA.

Sin este archivo, Claude tendría que descubrir los comandos de compilación, el estilo de código y las convenciones leyendo build.gradle.kts, buildSrc/ y los archivos fuente existentes. Con él, el agente sabe de inmediato:

  • Cómo compilar (./gradlew build) y ejecutar (./gradlew bootRun)
  • Cómo ejecutar una sola prueba (./gradlew test --tests "...")
  • La pila tecnológica (Kotlin JVM 17, Spring Boot, JUnit 5)
  • Convenciones de código (camelCase, PascalCase, tipos anulables, sangría de 4 espacios)

Sección por sección

Comandos de compilación/prueba (líneas 5–11)

Compilar todo:           ./gradlew build
Compilar saltando pruebas: ./gradlew build -x test
Ejecutar aplicación:     ./gradlew bootRun
Prueba individual:       ./gradlew test --tests "org.projectforge.package.ClassName.methodName"
Pruebas de paquete:      ./gradlew test --tests "org.projectforge.package.*"
Pruebas de módulo:       ./gradlew :projectforge-business:test

Seis comandos que cubren las operaciones más comunes. El filtro --tests es especialmente útil: ejecuta un único método de prueba sin ejecutar todo el conjunto (lo que lleva minutos).

Nota: Estos funcionan porque el build.gradle.kts raíz se aplica a todos los subproyectos mediante allprojects { }.

Cómo se relaciona con el resto del proyecto

Este archivo es la capa de traducción entre las convenciones legibles por humanos y lo que el sistema de compilación realmente aplica:

CLAUDE.md diceAplicado por
"Kotlin JVM target 17"Plugin de convención línea 28: options.release.set(17)
"JUnit 5 para pruebas"Plugin de convención línea 38: useJUnitPlatform()
"kotlin-logging"Plugin de convención línea 60: api("kotlin-logging")
"Compilar todo"build.gradle.kts raíz: se aplica a todos los subproyectos

CLAUDE.md le dice a la IA qué hacer; los archivos de compilación lo aplican.

Por qué existe

Este archivo se añadió específicamente para Claude Code — el asistente de codificación de IA de Anthropic. Sigue la convención CLAUDE.md donde el agente lee automáticamente este archivo al inicio de cada sesión. Probablemente fue añadido por el mismo desarrollador que introdujo el desarrollo asistido por IA en el proyecto.

El equivalente para GitHub Copilot sería .github/copilot-instructions.md o comentarios en línea. Para Cursor, sería .cursor/rules.md.

Notablemente, el archivo menciona Corrutinas de Kotlin (línea 22) — pero el código base actual todavía usa Thread en varios lugares (por ejemplo, IdpLoginHandler.kt). Esto significa que CLAUDE.md describe el estilo deseado más que la realidad actual.
