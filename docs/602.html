#602: ProjectForgeGroup.java

Java enum — hardcoded system group constants. Values: ADMIN_GROUP, FINANCE_GROUP, HR_GROUP, MARKETING_GROUP, ORGA_GROUP, CONTROLLING_GROUP, PROJECT_MANAGER_GROUP, USER_GROUP. Maps each to its group name in the database. The foundation of ProjectForge's RBAC system — every access check references these constants. If a group doesn't exist in the DB, the corresponding features are hidden.
