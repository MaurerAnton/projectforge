#603: UserPreferencesHelper.java

Java helper — user preferences serialization. Stores/loads UserPrefDO entries as XML (via XStream). Handles: area-specific preferences (e.g. calendar view settings, timesheet column widths), type-safe conversion (String to Integer/Boolean/LocalDate using UserXmlPreferencesBaseDOSingleValueConverter), and preference inheritance (user → group → default).
