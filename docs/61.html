File #61: TransactionsImporter.kt

Path: ./plugins/.../TransactionsImporter.kt · Source: GitHub

Thin @Service wrapper that orchestrates the import pipeline after file upload. Called by BankingServicesRest (#60) after CSV parsing. Analyzes read transactions (sorts by date, sets fromDate/untilDate), calls reconcileImportStorage() to run the scoring algorithm from BankingImportStorage (#58), stores the import storage in the HTTP session with 20-minute expiry, then clears the DB transaction cache to free memory before the background job picks up the import.
