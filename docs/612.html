#612: UserRightAccessCheck.java

Java abstract base — THE foundation of ProjectForge's access control. All plugin rights extend this. Defines: hasAccess(user, obj, oldObj, operationType) → boolean for row-level checks, hasSelectAccess(user) for list-level access, hasHistoryAccess(user, obj) for change log visibility. Holds rightId, category, defaultValue. Used by every *Right.java file in the project. 138 lines of the most reused code in the entire codebase.
