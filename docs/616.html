#616: UserRightServiceImpl.java

Java service impl — user right management engine. Implements UserRightService. Central service that evaluates all registered rights. For a given (user, entity, operation), checks: (1) is the right enabled for this user? (2) does the right's hasAccess() return true? (3) is the user in an admin group? Caches results per session. This is the single point where all access control decisions are made.
