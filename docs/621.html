#621: UserXmlPreferencesBaseDOSingleValueConverter.java

Lines: 100 · Type: Java XStream SingleValueConverter

XStream converter for BaseDO objects in user preferences XML. Converts between database entity objects (BaseDO subclasses) and their ID strings during XML serialization/deserialization. When serializing: BaseDO → its id.toString(). When deserializing: id string → objects loaded from DAO via ApplicationContext. Used by UserXmlPreferencesService to marshal entity references (Konto, Kost1, Projekt, Kunde) in user preferences XML. Without this converter, XStream would try to serialize the full entity graph — this keeps preferences XML compact by storing only IDs.
