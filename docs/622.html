#622: BaseFormatter.java

Lines: 59 · Type: Java abstract formatter

Abstract base for domain formatters. Provides shared formatting infrastructure: locale resolution (from ThreadLocalUserContext), date/time formatting, number formatting. Extended by CurrencyFormatter, ProjektFormatter, KostFormatter, etc. Uses DateFormat with the user's locale for consistent formatting across the application.
