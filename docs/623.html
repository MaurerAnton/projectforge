#623: CurrencyFormatter.java

Lines: 93 · Type: Java formatter

Locale-aware currency formatter. Extends BaseFormatter. Formats BigDecimal and Integer amounts with: currency symbol (€/$/£ from config via ConfigurationServiceAccessor), thousand separators, 2 decimal places, negative values with minus sign. Handles precision — NumberHelper for rounding to configured scale. Used in every invoice, order, and cost display in the application. Supports configurable currency via system settings (EUR default).
