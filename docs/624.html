#624: HtmlDateTimeFormatter.java

Lines: 120 · Type: Java formatter

Date/time formatter for HTML output. Formats java.util.Date, LocalDate, and LocalDateTime for Wicket HTML pages. Supports multiple format styles: FULL (long), MEDIUM (standard), SHORT (compact), TIME_ONLY. Uses DateTimeFormatter with the user's locale and timezone. Wraps formatted output in <span class="no-wrap"> to prevent line breaking in table cells. 120 lines — the most comprehensive date formatter in the business layer.
