#625: HtmlHelper.java

Lines: 172 · Type: Java HTML utility

HTML/XSS-safe string conversion utilities. 172 lines. Key methods:

  • escapeHtml(str, createLineBreaks) — escapes HTML entities (< → &lt;) using StringEscapeUtils.escapeHtml4(). Optionally converts \n to <br/> for multi-line text display
  • escapeXml(str) — XML-safe escaping via escapeXml11() — specifically for FOP (Formatting Objects Processor) PDF rendering compatibility
  • formatTextarea(str) — formats plain text for HTML textarea display: escapes HTML, converts tabs to spaces (TAB_WIDTH=8), handles \r\n → <br/>
  • formatJsString(str) — escapes strings for safe embedding in JavaScript: quotes, backslashes, newlines, unicode escapes
  • encodeUrl(str) — URLEncoder.encode() with UTF-8, catching UnsupportedEncodingException (should never happen)
  • abbreviate(str, maxLength) — truncates with "..." using StringUtils.abbreviate()

Used across the Wicket UI layer to safely render user-supplied text in HTML pages — critical for XSS prevention. Also used by email templates for the same escaping.
