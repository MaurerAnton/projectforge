#626: HtmlTagBuilder.java

Lines: 140 · Type: Java HTML builder

Fluent API for constructing HTML tags. 140 lines. Provides methods: setName("div"), addAttribute("class", "header"), writeOpen() → <div class="header">, writeClose() → </div>, writeSelfClosing() → <br/>. Supports nested builder pattern with writeText() for content between open/close tags. Used by HtmlHelper and Wicket components to generate HTML programmatically — replaces raw String concatenation for tag generation. Stores attributes as Collection<KeyValueBean<String, String>>.
