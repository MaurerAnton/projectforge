#628: VacationMenuCounterCache.java

Java cache — counts pending vacation requests for menu badge. Queries VacationDao.getPendingCount(userId). Invalidated on vacation create/update/delete. Shows e.g. "Urlaub (3)" in the menu — the number of pending requests the user needs to act on. Same pattern as StatisticsCache.
