#630: XYChartBuilder.java

Lines: 220 · Type: Java JFreeChart builder base

Base class for XY time-series chart construction. 220 lines. Wraps JFreeChart's ChartFactory.createTimeSeriesChart() with ProjectForge conventions: DateAxis for X-axis (with DateTickMarkPosition and date format from user locale), NumberAxis for Y-axis, PlotOrientation.VERTICAL, anti-aliasing (rendering hints), custom color palette, legend with border. Provides addDataset(), setRenderer(), setDateRange() for subclasses. Used by LiquidityChartBuilder and Gantt chart rendering. The chart is rendered as a PNG image via JFreeChart.getBufferedImage() for embedding in Wicket pages via JFreeChartImage component.
