Lines: 39 · Author: Kai Reinhard · Type: Java interface — org.projectforge.database package

Interface representing a single column value in a query result. 39 lines, 3 methods. Part of the raw JDBC result abstraction layer (DatabaseExecutor → DatabaseResultRow → DatabaseResultRowEntry).

Methods:

  • getType() → int — the JDBC column type from java.sql.Types (e.g. Types.VARCHAR=12, Types.INTEGER=4, Types.TIMESTAMP=93). Stored for type-aware formatting but rarely used by callers — most consumers just call getValue().toString().
  • getValue() → Object — the raw value from ResultSet.getObject(columnIndex). Can be String, Integer, Long, BigDecimal, Timestamp, or null. Callers must cast based on known column type.
  • getName() → String — the column name from ResultSetMetaData.getColumnName(). Case-sensitive, matches the SQL query's AS alias or the table column name. Used for name-based lookup via DatabaseResultRow.getEntry(name).

Implementation: DatabaseResultRowEntryImpl — a simple POJO holding all three values. No Hibernate involvement — pure JDBC metadata.
