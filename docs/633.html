#633: DatabaseResultRow.java

Lines: 46 · Author: Kai Reinhard · Type: Java interface — org.projectforge.database package

Interface representing one row of a raw SQL query result. 46 lines, 4 methods. The middle layer between DatabaseExecutor.query() (returns List<DatabaseResultRow>) and DatabaseResultRowEntry (single column values).

Methods:

  • getEntries() → List<DatabaseResultRowEntry> — all columns in order (left to right as they appear in the SQL query). The column order matches ResultSetMetaData iteration order.
  • getEntry(int index) — access by 0-based column index. The Javadoc explicitly states "Starts with 0" — important because JDBC ResultSet columns start at 1. This is a translation layer.
  • getEntry(String name) — access by column name. Case-sensitive, matches the SQL alias or table column name. Used when callers want to read by semantic name rather than position.
  • add(DatabaseResultRowEntry entry) — mutable collection; entries are added during result set iteration. Called only by DatabaseExecutorImpl during while(rs.next()) loop — consumers typically only read via getEntry/getEntries.

Implementation: DatabaseResultRowImpl — backed by a LinkedList of entries with index/name lookup.
