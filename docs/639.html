#639: AttrColumnDescription.java

Lines: 85 · Author: blumenstein (2016) · Type: Java POJO — org.projectforge.export package

Excel column metadata descriptor for attribute-based exports. 85 lines. Created by blumenstein on 24.11.2016 — part of the employee billing export system. Bridges between the @PropertyInfo annotation on DO fields and the Excel export column model (I18nExportColumn).

Fields:

  • groupName (final String) — logical group for column organization (e.g. "employee", "project", "billing"). Used to group related columns in the export header
  • propertyName (final String) — the Java field/attribute name from the DO (e.g. "firstName", "grossSum")
  • i18nKey (final String) — for localized column header text
  • colWidth (int, default 20) — column width in Excel character units. Two constructors: one with default 20, one with explicit width

Key method — getCombinedName() → groupName + propertyName: This composite key is used as the unique identifier for column mapping in both Excel export (I18nExportColumn) and Excel import (ExcelImport → EmployeeBillingExcelRow → AttrRow). The concatenation without a separator means groupName="emp" + propertyName="Name" → "empName" — callers must ensure group names don't create ambiguous concatenations.

toI18nExportColumn(): Converts to I18nExportColumn(getCombinedName(), i18nKey, colWidth) — this is the factory method that transforms the attribute description into a proper export column object. Used by ExportConfig to build the export schema from annotated DO fields.

Use in imports: The same combinedName is used during Excel import to match columns from the spreadsheet to DO properties — the importer looks up combinedName in the attribute map and writes the cell value to the corresponding DO field.
