#642: ExportJFreeChart.java

Lines: 100 · Type: Java utility

Renders JFreeChart objects to raster image streams. 100 lines. Used whenever a JFreeChart (Gantt, liquidity forecast, timesheet statistics) needs to be embedded in an Excel export or served as a downloadable image.

Constructor: ExportJFreeChart(JFreeChart, int width, int height) — stores the chart, dimensions, and default image type.

Key method — write(OutputStream out): Uses ChartUtils.writeChartAs{type}(out, chart, width, height) from JFreeChart to render the chart. The image type (JFreeChartImageType) controls the output format:

  • PNG — writeChartAsPNG() — lossless, larger file, preferred for embedding in Excel (Apache POI supports PNG natively)
  • JPEG (default) — writeChartAsJPEG() — lossy, smaller file, better for web display
  • SVG — unsupported by this method (SVG would need Batik, not ChartUtils)

Returns the file extension string ("png" or "jpg") for the caller to append to the filename. The chart is rendered at the constructor-defined dimensions — no automatic scaling to fit the image type. Anti-aliasing is enabled by default in JFreeChart's ChartUtils.

Setter: setImageType(JFreeChartImageType) — allows switching from default JPEG to PNG before writing. Callers typically set PNG when exporting to Excel (POI image API accepts PNG byte arrays) and JPEG for standalone image download.
