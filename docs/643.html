#643: ExportZipFile.java

Lines: 59 · Type: Java value object

Simple DTO pairing a filename with an exported object. 59 lines. Described as "Represents an export object including the desired filename" — used when multiple exports need to be bundled into a single ZIP download.

Fields: filename (final String — e.g. "employees.csv", "invoices.xlsx"), exportObject (final Object — the actual export data: could be byte[], InputStream, File, or any exporter's output). The Object type allows flexibility — the ZIP writer examines the type at runtime to determine whether to write bytes directly (byte[]), copy a stream (InputStream), or serialize (Serializable). All-args constructor + getters only — immutable value object.

Usage: Created in export service methods and collected into a List<ExportZipFile>, then passed to a ZIP utility that iterates the list and creates a ZipOutputStream with one ZipEntry per ExportZipFile, writing the exportObject contents. Used by bulk exports (multi-sheet Excel, multi-image chart exports, DataTransfer "download all" feature).
