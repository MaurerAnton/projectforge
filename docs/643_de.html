projectforge-business/src/main/java/org/projectforge/export/DOListExcelExporter.java Zeilen: 85 · Typ: Java — erweitert MyExcelExporter 85 Zeilen · 34 Code · 44 Kommentare · 7 leer

Basisklasse für alle DO-Listen-basierten Excel-Exporte. 85 Zeilen. Erweitert durch DOGetterListExcelExporter und praktisch jeden Entitätslisten-Export in der Anwendung (Aufträge, Rechnungen, Mitarbeiter, Kontakte usw.). Beschrieben als „MyExcelExporter mit kleinen Optimierungen für AbstractListPage“ – dies ist die Exportebene für Wicket-Listenseiten.

Konstruktor — DOListExcelExporter(String filenameIdentifier): Erzeugt einen Dateinamen im Format "ProjectForge-{identifier}_{yyyymmdd}.xls". Verwendet DateHelper.getDateAsFilenameSuffix(new Date()), das einen kompakten Datumsstring ohne Trennzeichen zurückgibt. Standard-Identifier: "export". Die Erweiterung .xls ist fest codiert – obwohl das tatsächliche Format XLSX ist (erzeugt von POIs XSSFWorkbook), wurde die Erweiterung vor dem XLSX-Übergang festgelegt und nie aktualisiert. In der Praxis öffnen Excel und LibreOffice die Datei unabhängig von der Erweiterung korrekt.

Überschreibung — putFieldFormat(ContentProvider, Field, PropertyInfo, ExportColumn): Ruft super.putFieldFormat() auf, um die Standardformatierung anzuwenden, und prüft dann, ob der Feldname "deleted" ist – falls ja, wird die Spaltenbreite auf 8 gesetzt (schmale Spalte für boolesche Kontrollkästchenanzeige). Dies ist ein Beispiel für eine feldspezifische Anpassung in der Export-Pipeline – jeder spezifische Exporteur kann diese Methode überschreiben, um Spaltenbreiten basierend auf der Feldsemantik anzupassen.

isExcelAutoFilter() — gibt true zurück: Aktiviert den Excel-Autofilter in der ersten Zeile (der Kopfzeile). Wenn Benutzer die exportierte Datei öffnen, erhält jede Spaltenüberschrift einen Dropdown-Filterpfeil – sie können Daten direkt in Excel filtern, ohne die ProjektForge-Listenseitenfilter zu benötigen. Dies ist eine Optimierung der Benutzererfahrung, die nichts kostet und für alle DO-Listenexporte aktiviert ist.

onBeforeDownload() — leerer Hook: Unterklassen können diese Methode überschreiben, um zusätzliche Blätter oder Daten hinzuzufügen, bevor die Arbeitsmappe geschrieben wird. Beispielsweise könnte ein Mitarbeiterabrechnungsexport ein Zusammenfassungsblatt mit Summen hinzufügen. Standardmäßig tut es nichts – folgt dem Template-Method-Muster für Erweiterungspunkte.

Hinweise zum Dateinamen: Fest codierte Erweiterung ".xls" und Präfix "ProjectForge-". Der Zeitstempel-Suffix stellt eindeutige Dateinamen sicher – wenn ein Benutzer am selben Tag zweimal exportiert, erhält er ProjectForge-employees_20250124.xls für beide Exporte, was potenziell zu Überschreibungen führt. Die Granularität yyyyMMdd bedeutet, dass Exporte innerhalb desselben Tages denselben Dateinamen teilen – keine Uhrzeit-Komponente.
