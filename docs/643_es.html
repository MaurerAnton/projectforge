projectforge-business/src/main/java/org/projectforge/export/DOListExcelExporter.java Líneas: 85 · Tipo: Java — extiende MyExcelExporter 85 líneas · 34 código · 44 comentarios · 7 en blanco

Clase base para todas las exportaciones Excel basadas en listas DO. 85 líneas. Extendida por DOGetterListExcelExporter y prácticamente todas las exportaciones de listas de entidades en la aplicación (pedidos, facturas, empleados, contactos, etc.). Descrita como "MyExcelExporter con optimizaciones menores para AbstractListPage" — esta es la capa de exportación para las páginas de lista de Wicket.

Constructor — DOListExcelExporter(String filenameIdentifier): Genera un nombre de archivo con el formato "ProjectForge-{identificador}_{aaaammdd}.xls". Utiliza DateHelper.getDateAsFilenameSuffix(new Date()) que devuelve una cadena de fecha compacta sin separadores. Identificador predeterminado: "export". La extensión .xls está codificada — aunque el formato real es XLSX (generado por XSSFWorkbook de POI), la extensión se estableció antes de la transición a XLSX y nunca se actualizó. En la práctica, Excel y LibreOffice abren el archivo correctamente independientemente de la extensión.

Sobrescritura — putFieldFormat(ContentProvider, Field, PropertyInfo, ExportColumn): Llama a super.putFieldFormat() para aplicar el formato estándar, luego verifica si el nombre del campo es "deleted" — si es así, establece el ancho de columna en 8 (columna estrecha para visualización de casilla de verificación booleana). Este es un ejemplo de personalización por campo en el proceso de exportación — cada exportador específico puede sobrescribir este método para ajustar los anchos de columna según la semántica del campo.

isExcelAutoFilter() — devuelve true: Activa el autofiltro de Excel en la primera fila (la fila de encabezado). Cuando los usuarios abren el archivo exportado, cada encabezado de columna obtiene una flecha de filtro desplegable — pueden filtrar datos directamente en Excel sin necesidad de los filtros de página de lista de ProjectForge. Esta es una optimización de experiencia de usuario que no cuesta nada añadir y está habilitada para todas las exportaciones de listas DO.

onBeforeDownload() — gancho vacío: Las subclases pueden sobrescribir para añadir hojas o datos adicionales antes de que se escriba el libro de trabajo. Por ejemplo, una exportación de facturación de empleados podría añadir una hoja de resumen con totales. No hace nada por defecto — sigue el patrón Template Method para puntos de extensión.

Notas sobre el nombre de archivo: Extensión ".xls" codificada y prefijo "ProjectForge-". El sufijo de marca de tiempo asegura nombres de archivo únicos — si un usuario exporta dos veces el mismo día, obtiene ProjectForge-employees_20250124.xls para ambas exportaciones, potencialmente sobrescribiendo. La granularidad yyyyMMdd significa que las exportaciones dentro del mismo día comparten el mismo nombre de archivo — sin componente de hora del día.
