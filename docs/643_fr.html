projectforge-business/src/main/java/org/projectforge/export/DOListExcelExporter.java Lignes : 85 · Type : Java — étend MyExcelExporter 85 lignes · 34 code · 44 commentaires · 7 vides

Classe de base pour toutes les exportations Excel basées sur des listes DO. 85 lignes. Étendue par DOGetterListExcelExporter et pratiquement toutes les exportations de listes d’entités de l’application (commandes, factures, employés, contacts, etc.). Décrite comme « MyExcelExporter avec des optimisations mineures pour AbstractListPage » — c’est la couche d’exportation pour les pages de listes Wicket.

Constructeur — DOListExcelExporter(String filenameIdentifier) : Génère un nom de fichier au format "ProjectForge-{identifiant}_{aaaammjj}.xls". Utilise DateHelper.getDateAsFilenameSuffix(new Date()) qui retourne une chaîne de date compacte sans séparateurs. Identifiant par défaut : "export". L’extension .xls est codée en dur — même si le format réel est XLSX (généré par XSSFWorkbook de POI), l’extension a été définie avant la transition vers XLSX et n’a jamais été mise à jour. En pratique, Excel et LibreOffice ouvrent tous deux le fichier correctement, quelle que soit l’extension.

Surcharge — putFieldFormat(ContentProvider, Field, PropertyInfo, ExportColumn) : Appelle super.putFieldFormat() pour appliquer le formatage standard, puis vérifie si le nom du champ est "deleted" — si c’est le cas, définit la largeur de colonne à 8 (colonne étroite pour l’affichage de la case à cocher booléenne). C’est un exemple de personnalisation par champ dans le pipeline d’exportation — chaque exportateur spécifique peut surcharger cette méthode pour ajuster les largeurs de colonne en fonction de la sémantique des champs.

isExcelAutoFilter() — retourne true : Active le filtre automatique d’Excel sur la première ligne (la ligne d’en-tête). Lorsque les utilisateurs ouvrent le fichier exporté, chaque en-tête de colonne obtient une flèche de filtre déroulante — ils peuvent filtrer les données directement dans Excel sans avoir besoin des filtres de page de liste de ProjectForge. C’est une optimisation de l’expérience utilisateur qui ne coûte rien à ajouter et qui est activée pour toutes les exportations de listes DO.

onBeforeDownload() — hook vide : Les sous-classes peuvent surcharger pour ajouter des feuilles ou des données supplémentaires avant que le classeur ne soit écrit. Par exemple, une exportation de facturation des employés pourrait ajouter une feuille récapitulative avec des totaux. Ne fait rien par défaut — suit le modèle de méthode Template pour les points d’extension.

Remarques sur le nom de fichier : Extension ".xls" codée en dur et préfixe "ProjectForge-". Le suffixe temporel garantit des noms de fichier uniques — si un utilisateur exporte deux fois le même jour, il obtient ProjectForge-employes_20250124.xls pour les deux exportations, avec un risque d’écrasement. La granularité yyyyMMdd signifie que les exportations effectuées le même jour partagent le même nom de fichier — pas de composante horaire.
