#643: DOListExcelExporter.java

projectforge-business/src/main/java/org/projectforge/export/DOListExcelExporter.java Строк: 85 · Тип: Java — расширяет MyExcelExporter 85 строк · 34 кода · 44 комментария · 7 пустых

Базовый класс для всех Excel-экспортов на основе DO-списков. 85 строк. Расширяется классами DOGetterListExcelExporter и практически любым экспортом списков сущностей в приложении (заказы, счета, сотрудники, контакты и т.д.). Описан как «MyExcelExporter с небольшими оптимизациями для AbstractListPage» — это слой экспорта для Wicket-страниц со списками.

Конструктор — DOListExcelExporter(String filenameIdentifier): Генерирует имя файла в формате "ProjectForge-{идентификатор}_{ггггммдд}.xls". Использует DateHelper.getDateAsFilenameSuffix(new Date()), который возвращает компактную строку даты без разделителей. Идентификатор по умолчанию: "export". Расширение .xls жёстко задано — хотя фактический формат XLSX (создаётся POI-классом XSSFWorkbook), расширение было установлено до перехода на XLSX и никогда не обновлялось. На практике Excel и LibreOffice корректно открывают файл независимо от расширения.

Переопределение — putFieldFormat(ContentProvider, Field, PropertyInfo, ExportColumn): Вызывает super.putFieldFormat() для применения стандартного форматирования, затем проверяет, является ли имя поля "deleted" — если да, устанавливает ширину столбца 8 (узкий столбец для отображения булева флажка). Это пример настройки отдельных полей в конвейере экспорта — каждый конкретный экспортёр может переопределить этот метод для регулировки ширины столбцов на основе семантики поля.

isExcelAutoFilter() — возвращает true: Активирует автофильтр Excel в первой строке (строке заголовка). Когда пользователи открывают экспортированный файл, в каждом заголовке столбца появляется стрелка выпадающего фильтра — они могут фильтровать данные прямо в Excel без необходимости использовать фильтры страниц списков ProjectForge. Это оптимизация пользовательского опыта, которая ничего не стоит и включена для всех экспортов DO-списков.

onBeforeDownload() — пустой хук: Подклассы могут переопределить его, чтобы добавить дополнительные листы или данные перед записью книги. Например, экспорт счетов сотрудников может добавить сводный лист с итогами. По умолчанию ничего не делает — следует шаблону «Шаблонный метод» для точек расширения.

Примечания к имени файла: Жёстко заданные расширение ".xls" и префикс "ProjectForge-". Суффикс с временной меткой обеспечивает уникальность имён — если пользователь экспортирует дважды за один день, он получит ProjectForge-employees_20250124.xls для обоих экспортов, что потенциально приведёт к перезаписи. Гранулярность yyyyMMdd означает, что экспорты в течение одного дня имеют одинаковое имя файла — компонент времени суток отсутствует.
