#644: JFreeChartImageType.java

Java enum — image types for JFreeChart export: PNG, JPEG. Used by ExportJFreeChart to select the output format. PNG is lossless and preferred for embedding in Excel files; JPEG is lossy with better compression for web downloads. Note: SVG is not an option here — SVG rendering uses a separate BatikImageRenderer path (#711).
