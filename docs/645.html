#645: MyExcelExporter.java

Lines: 102 · Type: Java — extends ExcelExporter · Most extended export class

ProjectForge-specific extension of ExcelExporter — the most reused base class in the export system. 102 lines. Almost every Excel exporter in the project extends either this class directly, or DOListExcelExporter which extends this. Adds: date formatting based on @PropertyInfo annotations, custom content provider creation, and a naming convention ("My" prefix = "my version" — a common naming pattern in older ProjectForge Java code).

Constructor: MyExcelExporter(String filename) — passes the filename to ExcelExporter (#384). The filename includes extension (typically .xls despite XSSF format).

addSheet(String sheetTitle) — sheet creation with custom provider: Creates an anonymous MyXlsContentProvider subclass with a no-op getCustomizedCellFormat() override (returns null = no custom formatting). This is the default content provider for simple DO-based exports. Subclasses can override to provide per-cell customization (e.g. negative numbers in red, bold totals rows).

Key method — putFieldFormat(ContentProvider, Field, PropertyInfo, ExportColumn): This is the date formatting engine for Excel exports. Examines the PropertyInfo.type() annotation on each DO field and applies the appropriate Excel date format:

PropertyType.DATEWidth 10, date format (e.g. "DD.MM.YYYY")
PropertyType.DATE_TIMEWidth 10, date+time to minutes (e.g. "DD.MM.YYYY HH:MM")
PropertyType.DATE_TIME_SECONDSWidth 16, with seconds
PropertyType.DATE_TIME_MILLISWidth 18, with milliseconds
PropertyType.UNSPECIFIEDFalls back to Java type:
  • java.sql.Date → DATE format, width 10
  • java.util.Date → DATE_TIME_MINUTES, width 16
  • Other types → delegates to super.putFieldFormat()

For all other property types (STRING, CURRENCY, BOOLEAN, etc.), delegates to the parent class. This method is called once per DO field during export setup — it configures the Excel cell format before any data is written.

Design pattern: This is the Template Method pattern in ExcelExporter — putFieldFormat() is called during export initialization for each field, and subclasses override it to customize formatting. The chain is: ExcelExporter → MyExcelExporter (adds date formats) → DOListExcelExporter (adds auto-filter + "deleted" column width) → specific exporters (custom column widths, formula columns, chart embedding).
