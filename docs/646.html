#646: MyXlsContentProvider.java

Lines: 117 · Type: Java — extends XlsContentProvider

Domain-aware Excel content provider — the bridge between ProjectForge domain objects and Excel cell values. 117 lines. Extended by anonymous subclasses in MyExcelExporter.addSheet(). This is where domain entities get converted to displayable strings for Excel cells.

Width constants (public static): LENGTH_KOSTENTRAEGER=11, LENGTH_USER=20, LENGTH_ZIPCODE=7 — these are used by specific exporters to set column widths for known fields.

Constructor: Creates a MyXlsExportContext and sets default cell formats: PFDateTime → "YYYY-MM-DD" with auto-date precision, DayHolder → DATE format. These defaults apply to all cells unless overridden by getCustomizedCellFormat().

Key method — getCustomizedValue(Object value): Converts domain objects to strings for Excel display. Chain of instanceof checks:

  • PFUserDO → user.getFullname() (e.g. "Reinhard, Kai")
  • I18nEnum → localized string via ThreadLocalUserContext.getLocalizedString(). Any enum implementing I18nEnum (ToDoStatus, PaymentStatus, etc.) gets its localized label
  • KontoDO → konto.formatKonto() (e.g. "1000 - Kasse")
  • Kost1DO / Kost2DO → OldKostFormatter.format() (legacy cost object formatting)
  • KundeDO → KundeFormatter.formatKundeAsString(customer, null)
  • ProjektDO → ProjektFormatter.formatProjektKundeAsString(project) — shows project with customer name
  • EmployeeDO → employee.getUser().getFullname() — falls back to "???" if user is null
Returns null for unrecognized types — the default string representation (toString()) is used. This method is called for every cell by the Excel rendering engine during addDataRow().

Key method — getCustomizedCellFormat(CellFormat, Object): Dynamic date format selection based on PFDateTime.getPrecision(). If the default format has autoDatePrecision=true (set in constructor), examines the value's precision:

  • DAY → DATE format (e.g. "DD.MM.YYYY")
  • SECOND → DATE_TIME_SECONDS
  • MILLISECOND → DATE_TIME_MILLIS
  • HOUR_OF_DAY / MINUTE / MINUTE_15 / null → DATE_TIME_MINUTES (default)
This allows a single column to show cells with different date formats — e.g. a "created" column could display "01.01.2025" for daily resolution entries and "01.01.2025 14:30" for minute-precision entries, based on the actual data rather than a fixed format.
