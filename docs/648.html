#648: SVGColor.java

Lines: 44 · Type: Java enum

Named SVG colors for programmatic SVG generation. 44 lines. 7 values: BLACK, DARK_BLUE, DARK_RED, LIGHT_BLUE, LIGHT_GRAY, NONE (transparent), RED. Each maps to the corresponding SVG color name string (black, darkblue, etc.) via getName(). Used by SVGHelper for Gantt chart arrow colors and by ExportJFreeChart for chart color palette mapping. The NONE value corresponds to SVG's "none" fill attribute — renders as transparent. Limited palette — no hex colors — because SVG generation predates the full Batik integration and uses only standard SVG color names.
