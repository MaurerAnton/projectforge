#649: SVGHelper.java

Lines: 326 · Type: Java SVG drawing utility — important Gantt infrastructure

Programmatic SVG generation library — primarily for Gantt chart dependency arrows. 326 lines. Uses Apache Batik's DOM implementation (SVGDOMImplementation) to construct SVG documents in Java via the W3C DOM API. No string concatenation — all elements are created as DOM nodes. Two XML namespaces: SVG (http://www.w3.org/2000/svg) and XLINK (http://www.w3.org/1999/xlink).

Core methods:

  • createDocument(width, height) — creates an SVG DOM document with root <svg> element, configures namespaces, returns the document for manipulation. The generated SVG is typically serialized to a string and embedded in HTML or saved as a .svg file.
  • setAttribute(Element, attrName, Object value) — null-safe attribute setter. If value is null, sets the attribute to empty string rather than omitting it — ensures valid SVG output.

Gantt dependency arrows — drawHorizontalConnectionLine(type, x1, y1, x2, y2, minXDist): The core Gantt visualization logic. Takes two task positions (start and end points) and a GanttRelationType, and generates SVG path data (d attribute of <path>) for the dependency arrow. The arrow routing algorithm: (1) moves from (x1,y1) to (x1+xHalf,y1) horizontally, (2) drops to (x1+xHalf,y2) vertically, (3) moves to (x2,y2) horizontally — creating an L-shaped path (two 90° bends). If the horizontal distance is too small (< minXDist), falls back to a Z-shaped path with 4 segments and extra horizontal offsets.

The routing varies by relation type:

  • FINISH_START (most common, e.g. Task A finishes → Task B starts): standard L-path going right-down-right
  • START_FINISH: special handling for negative horizontal distances (x2 < x1) — routes left-around to avoid crossing other task bars
  • START_START / FINISH_FINISH: handled by other methods

Uses round() with DecimalFormat("0.00") (period as decimal separator — hardcoded, not locale-aware) for SVG coordinate precision. The checkNonNegativeValues() and checkPositiveValues() validation ensures coordinates are physically sensible.

Additional drawing methods: drawArrowHead() (SVG <polygon> for the arrow tip), drawVerticalConnectionLine() (for SS/FF dependencies), drawGanttBar() (task rectangles with color fills), drawTodayMarker() (red dashed vertical line), drawText() (SVG <text> elements). These together form a complete SVG Gantt rendering engine — the only use of Batik's DOM API in the project.
