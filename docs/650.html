#650: V7_0_0_2__DropLuceneIndex.java

Lines: 48 · Type: Java — extends BaseJavaMigration · Package: org.projectforge.flyway.dbmigration

Java-based Flyway migration — removes old Lucene index files. 48 lines. This is a Java migration (not SQL) — extends org.flywaydb.core.api.migration.BaseJavaMigration rather than being a .sql file. Java migrations are used when the migration requires file system operations, not just SQL.

Purpose: ProjectForge v7 upgraded from Hibernate Search 5 (Lucene 5.3) to Hibernate Search 6 (Lucene 8+). The Lucene index format changed incompatibly between these versions — the old index files would cause errors if not removed. This migration deletes the entire hibernateSearch/ directory from the application home directory. After deletion, the Lucene index is rebuilt from scratch on the next application start via massIndexer().

Migration logic — migrate(Context): (1) Resolves the hibernateSearch directory path relative to ConfigurationService.getStaticApplicationHomeDir() — typically ~/.projectforge/hibernateSearch/. (2) Logs an INFO message explaining the index deletion. (3) Calls FileUtils.deleteDirectory(file) — recursive deletion of the entire directory tree. If the directory doesn't exist, deleteDirectory silently succeeds (no exception).

Design note — Java vs SQL migration: This is the only Java-based migration in the project (most migrations are .sql files). The rest are SQL because they manipulate database schema. This one deletes files — a task unsuited for SQL. It's placed in src/main/java/org/projectforge/flyway/dbmigration/ (not src/main/resources/flyway/ where SQL migrations live) — Flyway scans both classpath locations.

Aftermath: Once this migration runs and the old index is deleted, the Constants or ProjectForgeStartupListener triggers a full reindex via Hibernate Search's massIndexer().start() — rebuilding the search index from the database. This can take minutes for large installations. The migration is idempotent — running it multiple times is safe (directory deletion succeeds even if the directory already doesn't exist).
