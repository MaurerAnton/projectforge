#655: AccessException.java

Lines: 246 · Author: Kai Reinhard · Type: Java — extends UserException

I18n-aware access denial exception with full context information. 246 lines. Extends UserException (which itself extends RuntimeException — unchecked, so callers don't need throws clauses). Extends UserException rather than RuntimeException directly to get i18n message resolution support — the error message shown to users is localized.

Fields (context for error messages): user (PFUserDO — who was denied), taskId (Long — WBS task context, if applicable), accessType (READ/WRITE/DEPLOY), operationType (CREATE/READ/UPDATE/DELETE/INSERT), clazz (the entity class for which access was attempted), message (optional custom error message).

I18n keys: I18N_KEY_STANDARD = "access.exception.standard" — used when no task context, e.g. "User John was denied WRITE access to Invoice." I18N_KEY_STANDARD_WITH_TASK = "access.exception.standardWithTask" — used when task context exists, e.g. "User John was denied READ access to task 'Web Platform'."

getMessageArgs() — two overloads: One returns MessageParam[] (ProjectForge's i18n param type), the other returns Object[] (Java's legacy ResourceBundle API). Both resolve the task ID to a displayable name via TaskTree.getInstance().getTaskById(taskId) — converts a numeric ID to a human-readable task title. If the task isn't found, falls back to the raw ID.

Constructors — 5 overloads: With various combinations of (user, taskId, accessType, operationType, i18nKey, params). All constructors log the exception at INFO level — log.info("AccessException: " + this). The toString() method uses ToStringBuilder to produce structured log output: "user=42:jdoe, task=15:Web Platform, accessType=WRITE, operationType=UPDATE, class=RechnungDO, i18nKey=access.exception.standardWithTask".

UserException base class: Provides getI18nKey(), getParams() for i18n message resolution. The framework catches UserException and renders a user-friendly error page with the localized message. AccessException is the most frequently thrown exception in ProjectForge's access control layer — every denied operation creates one.
