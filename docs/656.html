#656: AccessFilter.java

Lines: 147 · Author: Kai Reinhard · Type: Java — extends BaseSearchFilter

Search filter for WBS task-tree-based access control queries. 147 lines. Extends BaseSearchFilter with three filtering dimensions: taskId, groupId, and userId. All setters return this for fluent chaining. This filter is used when querying which entities a user can access based on their task assignments — the DAO layer uses these criteria to construct HQL with JOINs to task/groups tables.

Task-tree traversal flags: includeAncestorTasks and includeDescendentTasks control whether the task match should include parent/child tasks in the WBS hierarchy. For example, if a user has access to task 15 (a sub-project), and includeAncestorTasks=true, they also see entities assigned to task 1 (the root project). inherit=true means the access check should propagate up the task tree — if a child task has access, the parent inherits it.

userId: When set, the filter restricts results to entities where the specified user has access via one of the registered rights. This is used by the admin "view as user" feature and by scheduled jobs that need to query what a specific user can see.
