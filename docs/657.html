#657: AccessType.java

Lines: 73 · Type: Java enum — implements I18nEnum

Enum defining the categories of protected resources. 73 lines. 5 values. Contains a notable TODO Designbug: Domains has to be explicit listed. comment — the author acknowledges that the enum hardcodes domain types rather than using a registration mechanism, meaning adding new access-controlled domains requires changing this enum.

Values: GROUP (general group membership check — used as constructor arg for AccessException), TASKS (select/insert/update/delete of WBS tasks — the most commonly checked type), TASK_ACCESS_MANAGEMENT (who can configure task-level access rights themselves — administrative, separate from TASKS access), TIMESHEETS (access to other users' timesheet data — for managers/supervisors), OWN_TIMESHEETS (access to own timesheets only — for regular employees).

I18n: Keys under access.type.group, access.type.tasks, etc. The Javadoc for getI18nKey() erroneously says "fibu.auftrag.status." but the code returns "access.type." + key — the comment is a copy-paste error from another enum.
