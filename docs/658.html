CRUD operation enum — determines what kind of operation is being access-checked. 74 lines. 5 values: SELECT (read/list), INSERT (create new), UPDATE (modify existing), DELETE (soft delete), UNDELETE (restore soft-deleted). Every call to AccessChecker.hasAccess() includes an OperationType — it's the operationType parameter that rights evaluate to determine row-level permissions.

Helper methods: isWriteType() — returns true for INSERT/UPDATE/DELETE/UNDELETE. Used when checking whether a demo/restricted user can perform an operation (they cannot do any writes). isReadType() — returns true only for SELECT. isIn(OperationType... type) — varargs multi-value match, used internally by the above helpers.

toString(): Returns the key string (e.g. "select", "update") — used for logging and error messages. The i18n key pattern is "access.type.select" etc. — same Javadoc copy-paste error as AccessType (says "fibu.auftrag.status." but actually returns "access.type.").
