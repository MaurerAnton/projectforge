#659: ConfigureHoliday.java

Lines: 137 · Author: Kai Reinhard · Type: Java XmlObject — config.xml model

Holiday definition model for config.xml — allows admins to (re-)define public holidays. 137 lines. Annotated @XmlObject(alias = "holiday") — this class maps to <holiday> elements in ProjectForge's XML configuration file. Each holiday can either reference a pre-defined holiday (HolidayDefinition enum like NEW_YEAR, CHRISTMAS) or specify a custom date via year/month/dayOfMonth.

Fields: label (display name in calendar, @XmlField(asAttribute=true) — serialized as XML attribute), id (reference to HolidayDefinition pre-defined enum), ignore (disable this holiday — allows suppressing pre-defined holidays), year/month/dayOfMonth (custom date if not a pre-defined holiday; year null = repeats every year), workingDay (if true, it's a regular work day despite being a holiday), workFraction (BigDecimal, e.g. 0.5 for half-day on Christmas Eve or New Year's Eve).

Important version note: The getMonth() Javadoc says "Since 7.0 (X-mas), month values are 1 based (were 0-based before)." — the month numbering changed from 0-based (January=0) to 1-based (January=1) in ProjectForge v7. Configurations from pre-v7 would have incorrect months after upgrade. The migration for this is handled by Flyway.

toString(): Uses ReflectionToStringBuilder — every field is included in the string representation for debugging.
