#662: HolidayDefinition.java

Lines: 184 · Type: Java enum

Pre-defined holiday catalog with Easter-relative and fixed-date holidays. 184 lines. Contains the full set of German public holidays plus movable religious holidays computed relative to Easter. Each enum value has: an i18nKey (for localized names), a dayOffset relative to Easter (positive → after Easter, negative → before Easter), or month+day for fixed-date holidays, and an isWorkingDay flag (half-day or work-for-pay day like Xmas Eve).

Easter-relative holidays (computed via dayOffset): SHROVE_MONDAY (-48), SHROVE_TUESDAY (-47), ASH_WEDNESDAY (-44), PALM_SUNDAY (-7), MAUNDY_THURSDAY (-3), GOOD_FRIDAY (-2), EASTER_SUNDAY (0), EASTER_MONDAY (+1), ASCENSION (+39), WHIT_SUNDAY (+49), WHIT_MONDAY (+50), CORPUS_CHRISTI (+60). All computed from Easter Sunday using the Gauss algorithm (implemented elsewhere).

Fixed-date holidays: NEW_YEAR (Jan 1), LABOR_DAY (May 1), GERMAN_UNITY_DAY (Oct 3), ALL_SAINTS (Nov 1), REPENTANCE_DAY (Nov, Wednesday before Nov 23 — unique: fixed month + weekday rule), XMAS_EVE (Dec 24, half/free day), FIRST_XMAS_DAY (Dec 25), SECOND_XMAS_DAY (Dec 26), NEW_YEARS_EVE (Dec 31, half/free day).

Enum methods: getDayForYear(int year) — computes the actual date for a specific year (resolves Easter-relative offsets). getLabel() — returns the i18n key or a custom label if configured. isMovable() — returns true for Easter-relative holidays. Referenced by ConfigureHoliday for config.xml holiday configuration and by the calendar engine for rendering public holidays.
