#663: Holiday.java

Lines: 93 · Author: Kai Reinhard

Runtime holiday instance — a specific holiday for a specific year. 93 lines. Created from HolidayDefinition + year computation. Holds the resolved date (dayOfMonth, month, year as an independent DayMonthYearHolder), workingDay flag (is it a regular work day despite being marked as holiday?), workFraction (BigDecimal — e.g. 0.5 for half-day, null for full day), i18nKey (for localized display), label (custom override). Provides compareTo() by date for sorting. Used in calendar views to mark non-working days with colored background and to calculate working hours in vacation/timesheet calculations.
