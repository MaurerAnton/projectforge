#664: ICal4JUtils.java

Lines: 242 · Author: Kai Reinhard

Utility class bridging ical4j library with ProjectForge calendar models. 242 lines. One of the most heavily used calendar utilities. Wraps ical4j's complex API with ProjectForge-specific convenience methods.

Timezone: Static TimeZoneRegistry from TimeZoneRegistryFactory — a singleton that caches ical4j TimeZone objects. getUserTimeZone() converts the Java TimeZone from ThreadLocalUserContext to ical4j's TimeZone for iCal property generation.

Key methods: getCalendar(events, timeZone) — builds a complete ical4j Calendar from a list of team events. Adds VCALENDAR wrapper, PRODID, VERSION:2.0, X-WR-CALNAME, X-WR-TIMEZONE. getVEvent(event, timeZone) — converts a TeamEvent to ical4j VEvent with all properties. getRRule(frequency, interval, until) — builds an RRule (Recurrence Rule) from ProjectForge's RecurrenceFrequencyModeOne/ModeTwo models, mapping between ProjectForge recurrence fields and RFC 5545 RRULE parameters (FREQ, INTERVAL, BYDAY, BYMONTHDAY, UNTIL). parseRRule(rrule) — reverses the mapping: ical4j RRule → ProjectForge recurrence model.

Date formatting: Uses DateTime / Date from ical4j (not java.time) — the ical4j library pre-dates Java 8. All date conversions go through java.util.Date for compatibility. Uses UTC internally with timezone offset applied during serialization.
