#666: WeekHolder.java

Lines: 111 · Author: Kai Reinhard · Type: Java Serializable

Calendar week container — holds 7 days for a calendar grid row. 111 lines. Part of the MonthHolder → WeekHolder → PFDay calendar model hierarchy. Constructor takes any date in the desired month, finds the beginning of that week (PFDay.getBeginOfWeek() — Monday by default, configurable to Sunday), and populates a 7-element PFDay[] array. Days from adjacent months (previous/next) are included as padding — there's a TODO comment at line 55 noting they should be marked as such (day.setMarker(true)) but this was never implemented.

Fields: days (PFDay[7] — Monday through Sunday), weekOfYear (int — ISO week number), objects (Map — arbitrary data attached to the week, used by calendar rendering for caching). The objects map provides a flexible extension point — calendar views store per-week rendering data (holidays, event counts, color highlights) without subclassing.
