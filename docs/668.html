#668: ConfigurationData.java

In-memory representation of the ProjectForge configuration. Holds all config entries from the t_configuration database table and config.xml file. Provides typed accessors: getStringValue(key), getIntValue(key), getBooleanValue(key). Used by ConfigurationService as the runtime config cache — changes are committed to DB first, then this in-memory representation is updated.
