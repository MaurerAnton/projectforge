File #67: META-INF/services/AbstractPlugin

Path: plugins/.../META-INF/services/org.projectforge.plugins.core.AbstractPlugin · Source: GitHub

Java ServiceLoader configuration — the single line org.projectforge.plugins.banking.BankingPlugin tells the JVM's service discovery mechanism to load BankingPlugin (#59) at startup. Without this file, the plugin exists on the classpath but is never activated — no menu items appear, no DAOs are registered. Every plugin in ProjectForge needs a ServiceLoader file for its AbstractPlugin subclass.
