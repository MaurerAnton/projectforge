#672: ConfigXml.java

Java model — reads/writes the config.xml file for system settings. Uses XStream for serialization. Contains: holiday definitions, SMTP settings, LDAP configuration, base URL, security settings, and all system-wide parameters that aren't in the database. Located in the application home directory. Annotated @XmlObject for the custom XStream-based XML framework (not JAXB). SecretField properties are encrypted before writing and decrypted after reading.
