#675: PFSpringConfiguration.java

Java @Configuration — Spring configuration class. Loads ConfigXml from the application home directory at startup, decrypts secret fields, and exposes config values as Spring @Beans. Also loads database configuration from t_configuration table. The bridge between ProjectForge's custom config system and Spring Boot's property system — makes config values available to @Value("${...}") and @ConfigurationProperties.
