#677: AbstractFormatter.java

Java abstract class — base for all i18n-aware formatters. Provides: locale resolution from ThreadLocalUserContext, ResourceBundle loading for the current locale, and a translate(key, params) method that wraps I18nService. Extended by domain formatters (date, currency, numbers). The translate() method supports MessageFormat parameter substitution with {0}, {1} placeholders.
