#678: I18nKeyAndParams.java

Java DTO — bundles an i18n message key with its formatting parameters. Fields: key (e.g. "plugins.todo.status.open"), params (varargs Object for MessageFormat). Used when i18n needs to be deferred — the key+params are stored and resolved later when the locale is available. Used by the notification system and email templates.
