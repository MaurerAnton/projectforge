#679: I18nService.java

Java @Service — the central i18n translation engine. Provides translate(key, locale) and translate(key, params, locale). Loads .properties resource bundles from all modules via Java ResourceBundle with fallback chain: key_de → key_en → key. If a key is not found in any bundle, returns the key itself (surrounded by ??? for visibility). Used by every Wicket page, every email template, every REST response that needs localized text. Registered with the Spring context and also available statically via a convenience facade.
