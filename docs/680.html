#680: InternalErrorException.java

Java RuntimeException — wraps internal server errors with i18n messages. Extends UserException. Used when unexpected errors occur (database failures, NPEs, service failures) that should be shown to the user with a localized error message. Constructed with an i18n key and optional params. Logged at ERROR level with stack trace, but the user sees only the translated message — not the technical details.
