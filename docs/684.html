#684: IDao.java

Lines: 37 · Type: Java generic interface — the DAO contract

The most reused interface in the entire persistence layer. 37 lines. Defines the contract for all DAOs: getList(filter) → List<T>, load(id) → T, save(obj), update(obj), delete(obj), undelete(obj), newInstance() → T. Every BaseDao implements this. The <T extends BaseDO<?>> type parameter ensures only proper entity types are used. Implements Serializable — DAOs are injected by Spring but must be serializable for Wicket session replication in clustered deployments. The 37-line interface is deceptively small — the actual implementation in BaseDao is hundreds of lines with access control, history tracking, Hibernate Search indexing, and caching.
