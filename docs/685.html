#685: ReindexSettings.java

Java model — configuration for Hibernate Search / Lucene mass indexing. Fields: batchSize (entities per transaction, default 50), threadsToLoadObjects (parallelism, default 1), entityTypes (which entity classes to reindex — null = all). Used by BaseDaoReindexRegistry (#698) and the hourly reindex job (#481). Controls the performance vs. resource trade-off during full reindex operations.
