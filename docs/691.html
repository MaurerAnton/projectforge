#691: UserRightService.java

Java interface — user rights service contract. Defines: getUserRight(rightId) → UserRight, hasRight(user, rightId, value), getUserRights(user) → all rights for a user, setUserRight(user, rightId, value), getAllRightIds(). The API consumed by AccessCheckerImpl. Implemented by UserRightServiceImpl (#616) — the central authorization data store backed by UserRightDO entities.
