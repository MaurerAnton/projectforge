#693: SchemaExport.java

Java utility — generates DDL from Hibernate entity mappings. Uses Hibernate's SchemaExport tool to produce CREATE TABLE statements for all annotated entities. Run during development to see the generated schema, and during the initial setup wizard to create database tables. Outputs the DDL to a file (schema.sql) and optionally executes it against the database. Superseded by Flyway for production schema management — this is a development/testing tool.
