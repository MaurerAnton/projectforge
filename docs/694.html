#694: StatisticsCache.java

Java abstract class — base for caches that store precomputed dashboard statistics. Defines: refresh() (recalculate), getLastRefreshTime(), isExpired() (time-based invalidation). Implemented by VacationMenuCounterCache, SkillStatisticsCache, ToDoCache. Uses ConcurrentHashMap internally with timestamp-based expiration. Pattern: compute-on-first-access with periodic background refresh.
