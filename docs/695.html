#695: UserPrefAreaSingleValueConverter.java

Java XStream SingleValueConverter — converts UserPrefArea enum (#699) to/from string for XML serialization in user preferences. Implements SingleValueConverter (XStream interface): toString(area) → enum name, fromString(str) → UserPrefArea.valueOf(str). Required because XStream doesn't natively handle Java enums for historical reasons in this codebase.
