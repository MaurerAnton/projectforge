#698: BaseDaoReindexRegistry.java

Java registry — maintains the list of DAOs that support full-text reindexing. Each DAO implementing SearchDao registers itself via register(dao). Used by the hourly reindex job (#481) to iterate all registered DAOs and rebuild their Lucene indexes. The registry ensures that only indexing-enabled DAOs are included in the reindex cycle.
