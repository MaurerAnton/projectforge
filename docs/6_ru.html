Назначение

Собирает Docker-образ ProjectForge — 43-строчный Dockerfile, который создаёт минимальный, не-root контейнер с Java 17 и томом для постоянных данных. Образ содержит 4 компонента, связанных через entrypoint.sh:

Компоненты Dockerfile: ┌─────────────────────────────────────────────┐ │ /app/application.jar ← строка 12 │ │ /app/entrypoint.sh ← строка 13 │ │ /ProjectForge/ ← строка 31 (VOLUME) │ │ ├─ environment.sh ← строка 34 │ │ └─ projectforge.properties (во время выполнения)│ └─────────────────────────────────────────────┘

По разделам

Строки 1–7: Базовый образ и настройка

1  FROM openjdk:17-slim
4  ARG JAR_FILE
7  WORKDIR /app

openjdk:17-slim: Облегчённая версия исключает ненужные пакеты (компиляторы, документацию) — меньше поверхность для атак и быстрее загрузка. ARG JAR_FILE — аргумент времени сборки, передаваемый через --build-arg JAR_FILE=... в docker build, обычно задаётся в build.gradle.kts для указания на собранный fat JAR.

Строки 9–16: Копирование файлов

9  RUN mkdir -p /app
12 COPY ${JAR_FILE} /app/application.jar        ← fat JAR из сборки
13 COPY docker/entrypoint.sh /app/entrypoint.sh  ← скрипт запуска
16 RUN chmod +x /app/entrypoint.sh               ← сделать исполняемым

Скопировано два файла: fat JAR Spring Boot (переименован в application.jar) и скрипт entrypoint.sh (сделан исполняемым). ARG JAR_FILE из строки 4 подставляется здесь во время сборки.

Строка 19: Открытие порта

19 EXPOSE 8080

8080 — это стандартный порт Spring Boot. Обратите внимание, что EXPOSE — это только документация, он не публикует порт. Фактическое сопоставление портов выполняется в docker-compose.yml, строка 12 (ports: - "8080:8080").

Строки 22–27: Не-root пользователь + procps

22 RUN addgroup --system projectforge && \
      adduser --system --ingroup projectforge projectforge
27 RUN apt-get update && apt-get install -y procps && \
      rm -rf /var/lib/apt/lists/*

Безопасность: запуск от имени не-root пользователя (projectforge:projectforge). Флаг --system создаёт системную учётную запись (без домашней папки, без оболочки входа, UID < 1000). Пакет procps предоставляет pgrep, необходимый для функции checkStopped() в entrypoint.sh (строка 14). Очистка rm -rf /var/lib/apt/lists/* — стандартная практика Docker: удаляет кеш пакетов для уменьшения размера образа.

Строки 30–32: Том

31 RUN mkdir -p /ProjectForge && chown -R projectforge:projectforge /ProjectForge
32 VOLUME /ProjectForge

Объявление VOLUME указывает Docker, что этот каталог содержит постоянные данные — файл конфигурации projectforge.properties, встроенную базу данных HSQLDB и логи. Без тома все данные будут потеряны при перезапуске контейнера. Каталог принадлежит не-root пользователю, чтобы процесс Java мог в него записывать.

Строка 34: Шаблон окружения

34 COPY docker/environment.sh /ProjectForge

Копирует шаблон из docker/environment.sh в том. Поскольку /ProjectForge — это VOLUME, файлы, скопированные сюда во время сборки, будут видны только при первом запуске — если смонтирован внешний том, он переопределяет эту копию. Это сделано намеренно: шаблон предназначен для первоначальной настройки, но затем вступает в действие настроенная администратором версия.

Строки 37–43: Точка входа

37 USER projectforge:projectforge                  ← переключение на не-root
40 ENTRYPOINT ["/app/entrypoint.sh"]               ← JSON exec форма
41 # ENTRYPOINT ["java", "-jar", "/app/application.jar"]  ← обход (закомментировано)
43 LABEL maintainer="Micromata"

Строка 40: Используется JSON exec форма ENTRYPOINT (синтаксис массива) — это не вызывает оболочку, поэтому сигналы передаются напрямую в entrypoint.sh. Строка 41 закомментирована: раскомментируйте её, чтобы обойти логику завершения в entrypoint.sh и запускать Java напрямую (полезно для отладки).

Ключевые выводы

  • 43 строки, минимализм: К базовому Java-образу добавлен только procps (для pgrep).
  • Без root: Запуск от имени projectforge:projectforge — хорошая практика безопасности Docker.
  • Три копирования, один том: JAR + entrypoint → /app (неизменяемо), environment.sh → /ProjectForge (постоянно).
  • Облегчённая JRE: openjdk:17-slim — полный JDK не требуется во время выполнения.
  • Переключатель обхода: Раскомментируйте строку 41, чтобы пропустить entrypoint.sh для прямого запуска Java.
