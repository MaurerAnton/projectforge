#700: UserPrefParameter.java

Java annotation — marks a DO field as a user-configurable preference. Placed on JPA entity fields alongside @PropertyInfo. The annotation system discovers all fields annotated with this and registers them as available user preferences in the user settings page. Each parameter belongs to a UserPrefArea and has an i18nKey for the settings page label. Used by UserPrefAreaRegistry.
