projectforge-business/src/main/java/org/projectforge/framework/renderer/CellHolder.java Contenedor de datos, projectforge-business/src/main/java/org/projectforge/framework/renderer/CellHolder.java 91 líneas · 46 código · 32 comentarios · 13 en blanco
Bean simple para almacenar el contenido, colspan y rowspan de una celda de tabla. Utilizado por el pipeline de renderizado XSL-FO / PDF para componer datos tabulares.

Estructura

Un bean Java simple (POJO) con tres campos:

CampoTipoValor por defectoDescripción
contentStringnull ("" si se construye con null)El contenido textual de la celda. toString() devuelve esto directamente.
colspanint1Número de columnas que abarca esta celda.
rowspanint1Número de filas que abarca esta celda.

Constructores

  • Sin argumentos: Los campos permanecen con valores por defecto.
  • CellHolder(String content): Establece el contenido; si el argumento es null, el contenido se convierte en cadena vacía.

Comportamiento notable

El constructor seguro contra null garantiza que getContent() nunca devuelva null, evitando NPEs en el renderizado de plantillas. Se proporcionan getters/setters estándar para todos los campos. No se realiza validación en los valores de colspan/rowspan.
