#714: CellHolder.java

projectforge-business/src/main/java/org/projectforge/framework/renderer/CellHolder.java Хранитель данных, projectforge-business/src/main/java/org/projectforge/framework/renderer/CellHolder.java 91 строка · 46 кода · 32 комментария · 13 пустых
Простой bean для хранения содержимого одной ячейки таблицы, а также значений colspan и rowspan. Используется конвейером рендеринга XSL-FO / PDF для формирования табличных данных.

Структура

Обычный Java bean (POJO) с тремя полями:

ПолеТипПо умолчаниюОписание
contentStringnull ("" если создан с null)Текстовое содержимое ячейки. toString() возвращает его напрямую.
colspanint1Количество столбцов, которые занимает эта ячейка.
rowspanint1Количество строк, которые занимает эта ячейка.

Конструкторы

  • Без аргументов: Поля остаются со значениями по умолчанию.
  • CellHolder(String content): Устанавливает содержимое; если аргумент равен null, содержимое становится пустой строкой.

Примечательное поведение

Конструктор с защитой от null гарантирует, что getContent() никогда не вернёт null, предотвращая NPE при рендеринге шаблонов. Для всех полей предоставлены стандартные геттеры/сеттеры. Проверка значений colspan/rowspan не выполняется.
