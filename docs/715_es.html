#715: FontMap.java

projectforge-business/src/main/java/org/projectforge/framework/renderer/FontMap.java Cargador de fuentes para renderizado PDF, projectforge-business/src/main/java/org/projectforge/framework/renderer/FontMap.java 65 líneas · 33 código · 26 comentarios · 6 en blanco
Carga archivos de fuentes AFM (Adobe Font Metrics) desde un directorio en un mapa indexado por nombre de fuente PostScript. Utilizado por el pipeline de renderizado PDF FOP/XSL-FO para proporcionar fuentes incrustables.

Arquitectura

FontMap mantiene un Map<String, BaseFont> interno (HashMap) que asigna nombres de fuente PostScript a objetos BaseFont de iText. El único método público loadFonts(File fontDir) escanea recursivamente el directorio dado en busca de archivos .afm y carga cada uno.

Proceso de carga

  1. Utiliza FileUtils.listFiles(fontDir, ["afm"], true) para recopilar recursivamente todos los archivos AFM.
  2. Para cada archivo, llama a BaseFont.createFont(path, BaseFont.CP1252, BaseFont.EMBEDDED) para crear una fuente iText con codificación CP1252 e incrustación habilitada.
  3. Extrae el nombre de la fuente PostScript mediante font.getPostscriptFontName() y lo almacena en el mapa.
  4. Los errores durante la carga de fuentes (por ejemplo, archivo corrupto) se registran mediante SLF4J y la fuente problemática se omite (mediante continue).

Detalles clave

  • Codificación: CP1252 (Windows-1252). Todas las fuentes se cargan con esta codificación independientemente de su codificación real.
  • Incrustación: BaseFont.EMBEDDED — las fuentes se incrustan en el PDF de salida, garantizando un renderizado consistente en cualquier sistema.
  • Manejo de duplicados: si dos archivos AFM producen el mismo nombre PostScript, gana el último cargado (comportamiento estándar de HashMap.put).
  • Sin getter público: el campo fontMap es de paquete privado (no se muestra ningún accesor en esta fuente). Otras clases en el paquete renderer pueden acceder directamente a él.

Dependencias

  • iText 2: com.itextpdf.text.pdf.BaseFont para creación e incrustación de fuentes.
  • Apache Commons IO: FileUtils.listFiles() para escaneo recursivo de directorios.
  • Apache Commons Collections 4: CollectionUtils.isNotEmpty() para verificación de vacío segura contra nulos.
