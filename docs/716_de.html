projectforge-business/src/main/java/org/projectforge/framework/renderer/ImageFormat.java Enum, projectforge-business/src/main/java/org/projectforge/framework/renderer/ImageFormat.java 43 Zeilen · 14 Code · 27 Kommentare · 2 leer
Aufzählung der unterstützten Ausgabebildformate für die SVG-Rendering. Werte: JPEG, PNG, PDF, SVG. Bietet eine Varargs-Mitgliedschaftstestmethode.

Struktur

WertBeschreibung
JPEGRaster-JPEG-Ausgabe über Batik JPEGTranscoder
PNGRaster-PNG-Ausgabe über Batik PNGTranscoder
PDFVektor-PDF-Ausgabe über FOP PDFTranscoder
SVGRohe SVG-Bytes, keine Transcodierung

isIn(ImageFormat... formate)

Eine Varargs-Komfortmethode, die true zurückgibt, wenn this einem der angegebenen Formate entspricht. Wird von BatikImageRenderer.getByteArray() verwendet, um zu prüfen, ob das angeforderte Format ein Rastertyp (PNG oder JPEG) ist.
