projectforge-business/src/main/java/org/projectforge/framework/renderer/ImageFormat.java Enum, projectforge-business/src/main/java/org/projectforge/framework/renderer/ImageFormat.java 43 líneas · 14 código · 27 comentarios · 2 en blanco
Enumeración de los formatos de imagen de salida admitidos para el renderizado SVG. Valores: JPEG, PNG, PDF, SVG. Proporciona un método de prueba de pertenencia con argumentos variables.

Estructura

ValorDescripción
JPEGSalida raster JPEG mediante JPEGTranscoder de Batik
PNGSalida raster PNG mediante PNGTranscoder de Batik
PDFSalida vectorial PDF mediante PDFTranscoder de FOP
SVGBytes SVG sin procesar, sin transcodificación

isIn(ImageFormat... formats)

Un método de conveniencia con argumentos variables que devuelve true si this es igual a alguno de los formatos proporcionados. Utilizado por BatikImageRenderer.getByteArray() para verificar si el formato solicitado es un tipo raster (PNG o JPEG).
