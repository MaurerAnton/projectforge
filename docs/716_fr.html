projectforge-business/src/main/java/org/projectforge/framework/renderer/ImageFormat.java Enum, projectforge-business/src/main/java/org/projectforge/framework/renderer/ImageFormat.java 43 lignes · 14 code · 27 commentaires · 2 vides
Énumération des formats d'image de sortie pris en charge pour le rendu SVG. Valeurs : JPEG, PNG, PDF, SVG. Fournit une méthode de test d'appartenance avec varargs.

Structure

ValeurDescription
JPEGSortie raster JPEG via Batik JPEGTranscoder
PNGSortie raster PNG via Batik PNGTranscoder
PDFSortie vectorielle PDF via FOP PDFTranscoder
SVGOctets SVG bruts, sans transcodage

isIn(ImageFormat... formats)

Méthode pratique avec varargs qui renvoie true si this est égal à l'un des formats fournis. Utilisée par BatikImageRenderer.getByteArray() pour vérifier si le format demandé est un type raster (PNG ou JPEG).
