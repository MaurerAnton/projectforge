projectforge-business/src/main/java/org/projectforge/framework/renderer/ImageFormat.java Перечисление, projectforge-business/src/main/java/org/projectforge/framework/renderer/ImageFormat.java 43 строки · 14 кода · 27 комментариев · 2 пустых
Перечисление поддерживаемых выходных форматов изображений для рендеринга SVG. Значения: JPEG, PNG, PDF, SVG. Предоставляет метод проверки принадлежности с переменным числом аргументов.

Структура

ЗначениеОписание
JPEGРастровый вывод JPEG через Batik JPEGTranscoder
PNGРастровый вывод PNG через Batik PNGTranscoder
PDFВекторный вывод PDF через FOP PDFTranscoder
SVGСырые байты SVG, без транскодирования

isIn(ImageFormat... formats)

Удобный метод с переменным числом аргументов, возвращающий true, если this равен любому из переданных форматов. Используется в BatikImageRenderer.getByteArray() для проверки, является ли запрошенный формат растровым (PNG или JPEG).
