#718: DateHelper.java

Date Parsing / Formatting Utility, projectforge-business/src/main/java/org/projectforge/framework/time/DateHelper.java
Comprehensive date formatting, parsing, and comparison utility. Provides thread-safe DateFormat accessors, ISO format helpers, week-of-year calculations, same-day comparisons, date-of-year range checks, and filename-suffix date generation. Central to all date display across ProjectForge.

Historical Evolution

This class has undergone heavy migration from java.util.Calendar and Joda-Time to java.time (via PFDay/PFDateTime). Several methods are now @Deprecated with migration notes. Week-of-year computation has changed from locale-dependent to globally configurable (v7.0.0, Dec 2020). Month values transitioned from 0-based to 1-based throughout 2019-2020.
