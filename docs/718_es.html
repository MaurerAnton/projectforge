Enumera los motores de tecnología de renderizado. Valores: FOP (XSL-FO mediante Apache FOP) y HTML.

Estructura

ValorDescripción
FOPPipeline de renderizado Apache FOP XSL-FO, que produce salida PDF
HTMLPipeline de renderizado de plantillas HTML, que produce salida HTML

Este enum se utiliza para seleccionar el motor de renderizado en tiempo de ejecución. Ambos valores indican qué pipeline de transformación invocar para una solicitud de generación de informe o documento determinada. No tiene métodos más allá de los métodos predeterminados del enum — puramente un discriminador de tipo.
