Перечисляет серверные части технологии рендеринга. Значения: FOP (XSL-FO через Apache FOP) и HTML.

Структура

ЗначениеОписание
FOPКонвейер рендеринга Apache FOP XSL-FO, создающий вывод PDF
HTMLКонвейер рендеринга HTML-шаблонов, создающий вывод HTML

Это перечисление используется для выбора серверной части рендеринга во время выполнения. Оба значения указывают, какой конвейер преобразования следует вызвать для данного запроса на создание отчёта или документа. Методы отсутствуют, кроме стандартных методов перечисления — исключительно дискриминатор типа.
