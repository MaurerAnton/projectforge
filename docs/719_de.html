#719: RowHolder.java

projectforge-business/src/main/java/org/projectforge/framework/renderer/RowHolder.java Datenhalter, projectforge-business/src/main/java/org/projectforge/framework/renderer/RowHolder.java 47 Zeilen · 14 Code · 28 Kommentare · 5 leer
Einfacher Bean, der eine Tabellenzeile als Liste von CellHolder-Objekten repräsentiert. Wird von der XSL-FO / PDF-Rendering-Pipeline verwendet, um tabellarische Daten zeilenweise zusammenzustellen.

Struktur

FeldTypStandardBeschreibung
cellsList<CellHolder>Leere ArrayListGeordnete Liste der Zellen in dieser Zeile

API

  • addCell(CellHolder cell) — Fügt der Zeile eine Zelle hinzu
  • getCells() — Gibt die Zellenliste zurück (direkte Referenz, veränderbar)

Arbeitet zusammen mit CellHolder (#712). Eine Tabelle wird erstellt, indem RowHolder-Instanzen angelegt und CellHolder-Objekte zu jeder hinzugefügt werden. Keine Validierung der Spaltenanzahl-Konsistenz zwischen Zeilen; keine zeilenbezogenen Attribute (Stil, Höhe usw.). Minimaler Wrapper um ArrayList<CellHolder>.
