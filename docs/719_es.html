Bean simple que representa una fila de tabla como una lista de objetos CellHolder. Utilizado por el pipeline de renderizado XSL-FO / PDF para componer datos tabulares fila por fila.

Estructura

CampoTipoValor por defectoDescripción
cellsList<CellHolder>ArrayList vacíoLista ordenada de celdas en esta fila

API

  • addCell(CellHolder cell) — Agrega una celda a la fila
  • getCells() — Devuelve la lista de celdas (referencia directa, mutable)

Trabaja en conjunto con CellHolder (#712). Una tabla se construye creando instancias de RowHolder y añadiendo objetos CellHolder a cada una. Sin validación de consistencia en el número de columnas entre filas; sin atributos a nivel de fila (estilo, altura, etc.). Envoltorio mínimo alrededor de ArrayList<CellHolder>.
