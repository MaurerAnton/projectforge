#719: RowHolder.java

projectforge-business/src/main/java/org/projectforge/framework/renderer/RowHolder.java Хранитель данных, projectforge-business/src/main/java/org/projectforge/framework/renderer/RowHolder.java 47 строк · 14 кода · 28 комментариев · 5 пустых
Простой bean, представляющий строку таблицы в виде списка объектов CellHolder. Используется конвейером рендеринга XSL-FO / PDF для построчного формирования табличных данных.

Структура

ПолеТипПо умолчаниюОписание
cellsList<CellHolder>Пустой ArrayListУпорядоченный список ячеек в этой строке

API

  • addCell(CellHolder cell) — Добавляет ячейку в строку
  • getCells() — Возвращает список ячеек (прямая ссылка, изменяемый)

Работает в связке с CellHolder (#712). Таблица строится путём создания экземпляров RowHolder и добавления объектов CellHolder в каждый из них. Проверка согласованности количества столбцов между строками не выполняется; атрибуты уровня строки (стиль, высота и т.д.) отсутствуют. Минимальная обёртка вокруг ArrayList<CellHolder>.
