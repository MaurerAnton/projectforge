#721: DayHolder.java

Java model — pre-Java-8 day wrapper. Wraps java.util.Date for date-only operations (no time component). Provides: getBeginOfWeek(), getEndOfWeek(), getBeginOfMonth(), isWeekend(), daysBetween(other). The predecessor to PFDay — still used by Wicket calendar widgets that predate the Java 8 time migration.
