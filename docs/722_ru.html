Форматтер-одиночка (расширяет AbstractFormatter), предоставляющий форматирование даты, времени, метки времени, недели года и длительности с учётом локали пользователя. Основной слой отображения между внутренними объектами даты и выводом UI, использующий шаблоны i18n из DateFormats.

Шаблон Одиночка

Реализует шаблон одиночки через статическое поле instance и метод доступа instance(). Расширяет AbstractFormatter, который предоставляет getI18nMessage() для локализованных меток единиц (день, час).

Константы длительности

КонстантаЗначениеИспользуется в
DEFAULT_HOURS_OF_DAY8getPrettyFormattedDuration(long)
DEFAULT_MIN_HOURS4DAY_SEPARATION24getPrettyFormattedDuration(long)

Настраиваемое поле durationOfWorkingDay (по умолчанию 8, можно задать) используется методами длительности без «красивого» форматирования.

Форматирование длительности

МетодПример вывода

«Красивая» длительность

Создаёт вывод в двойном формате, показывая общее и разделённое по дням представление:

МетодПример
getPrettyFormattedDuration(long millis)"12д 1:00ч (97:00ч)"

Вторая часть (в скобках) появляется только когда minHours4DaySeparation равен -1 (показывает общее количество часов без разделения по дням). «Красивый» метод отображает оба формата — с разделением по дням и общее количество часов — рядом, когда они различаются.

Вычисление длительности

Оба метода делегируют выполнение TimePeriod.getDurationFields(millis, hoursOfDay, minHours4DaySeparation), который возвращает int[3]: [дни, часы, минуты]. Метод getFormattedDuration строит локализованную строку с сокращёнными метками единиц из i18n ("calendar.unit.day", "calendar.unit.hour"). Минуты дополняются ведущим нулём до 2 цифр.
