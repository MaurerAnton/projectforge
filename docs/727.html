#727: Crypt.kt

Kotlin utility — AES encryption/decryption using javax.crypto. Methods: encrypt(plaintext, key) → Base64-encoded ciphertext, decrypt(ciphertext, key) → plaintext. Uses AES-256-CBC with PKCS5Padding and random IV. Used by ConfigXmlSecretField for config.xml field encryption and CryptServiceImpl for calendar feed token encryption.
