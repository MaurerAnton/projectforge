File #73: DataTransferAreaDao.kt

Path: ./plugins/datatransfer/.../DataTransferAreaDao.kt · Source: GitHub

The central DAO for the Data Transfer plugin — the longest DAO documented so far. Key features:

  • Personal boxes: Every user has an auto-created private file share (PERSONAL_BOX_AREA_NAME). ensurePersonalBox() creates one on demand.
  • External access: Anonymous users access areas via 30-char random token + 10-char password. Tokens are auto-generated when external download/upload is enabled.
  • Observer notifications: Implements AttachmentsEventListener — fires audit events on upload/download/delete, triggering email notifications to observers.
  • Capacity management: Spring config property projectforge.plugin.datatransfer.maxFileSize (default 100MB), 10 file size options (20MB–10GB), expired files auto-deleted after expiryDays.
  • Security: Personal boxes are hardened — no external access, admin-only, 60-day default expiry. External credentials are stripped from objects returned to non-admin users.
