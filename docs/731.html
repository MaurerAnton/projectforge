#731: ExceptionStackTracePrinter.kt

Lines: 76 · Author: Kai Reinhard · Type: Kotlin object (singleton) — org.projectforge.framework.utils

Purpose

Produces compact, readable stack traces focused on ProjectForge's own code. Standard Java stack traces (from ex.printStackTrace() or log.error(ex.message, ex)) include hundreds of framework-level frames — Spring internals, Hibernate proxy generation, Tomcat request processing — that are irrelevant to diagnosing ProjectForge bugs. This utility filters those out and shows only org.projectforge.* frames, with a configurable depth limit.

The Javadoc explains the motivation clearly: "Prints stack-trace without foreign packages in much shorter form than log.error(ex.message, ex) does." This is critical for production log readability — when an exception occurs, the log shows 10 lines of relevant ProjectForge code instead of 200 lines of framework noise.

Architecture: Kotlin object singleton

Uses Kotlin's object keyword — this creates a thread-safe singleton at class-load time. All methods are @JvmStatic + @JvmOverloads, making them callable from Java as static methods. The @JvmOverloads annotation generates overloaded Java-compatible methods for each default parameter combination — this means Java callers can write ExceptionStackTracePrinter.toString(ex) (using all defaults) or ExceptionStackTracePrinter.toString(ex, true, true, 20) (overriding depth).

The toString() method — 4 parameters

fun toString(
    ex: Throwable,
    showExceptionMessage: Boolean = true,
    stopBeforeForeignPackages: Boolean = true,
    depth: Int = 10,
    vararg showPackagesOnly: String
): String
  • ex — the exception to format
  • showExceptionMessage — prepend the exception class name + message? Example: "NullPointerException: user was null\n" followed by stack frames. Default true
  • stopBeforeForeignPackages — if true (default), stops the trace entirely at the first non-ProjectForge frame. If false, skips foreign frames but continues showing ProjectForge frames further up. The difference matters for exceptions thrown from ProjectForge code but whose stack includes Spring/Hibernate layers in the middle
  • depth — maximum number of stack frames to show. Default 10. This prevents the output from growing too large — even with only ProjectForge frames, a deep call chain could produce dozens of lines
  • showPackagesOnly — varargs override for which packages count as "own". Default: arrayOf("org.projectforge."). When left empty, uses the built-in constant. Used when a plugin wants to show its own package too (e.g. "org.projectforge.", "com.mycompany.")

Algorithm walkthrough

  1. Header: If showExceptionMessage=true, writes "ClassName:message\n" — uses Kotlin's ::class.java.name (the full qualified Java name) and ex.message (may be null)
  2. Package resolution: Uses PROJECTFORGE_PACKAGES constant if no showPackagesOnly provided — currently just {"org.projectforge."}
  3. Frame iteration: loops through ex.stackTrace (which returns StackTraceElement[] — the JVM's standard representation)
    1. Foreign package: if the frame's class name doesn't start with any of the showPackages prefixes, it's a "foreign" frame
      • If stopBeforeForeignPackages=true and we've already seen at least one own frame, prints "...following foreign packages are hidden..." and breaks the loop entirely — no further frames shown
      • If stopBeforeForeignPackages=false, prints a placeholder "...(foreign packages are hidden)..." (only once, guarded by placeHolderPrinted) and continues — later ProjectForge frames will still be shown
    2. Own package: sets ownStackelementsPrinted=true (so the after logic knows own frames were found), then formats the frame: "at ClassName.methodName (FileName:lineNumber)\n"
    3. Depth limit: increments counter on each printed frame (not on skipped foreign frames). When counter >= depth, breaks

Key design decisions

  • Placeholder printing only once: The placeHolderPrinted flag prevents spamming "...(foreign packages are hidden)..." multiple times when stopBeforeForeignPackages=false — the placeholder appears once at the boundary between own and foreign frames
  • Hardcoded package prefix: "org.projectforge." is the only default. Extensions like "de.micromata." (Merlin library) are not included by default — callers can pass them via showPackagesOnly if they're relevant to the error being investigated
  • No output for empty exception: If showExceptionMessage=false and there are no ProjectForge frames, the method returns an empty string — the caller must handle this (typically "No stack trace available" is shown)

Usage in the codebase

Primarily used by Groovy scripting (GroovyExecutor) — when a user's Groovy script throws an exception, the script output pane shows a cleaned stack trace via this utility so the user can see where in their script the problem occurred, rather than being buried in Groovy runtime internals. Also used by the LogViewerPageRest (admin log viewer) to format exception details in a compact form, and by email templates that include stack traces in error notification emails.
