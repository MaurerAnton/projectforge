Zweck

Das Label/Wert-Muster – eine zentrale UI-Abstraktion, die überall in ProjectForge verwendet wird, um Dropdown-Menüs, Auswahllisten und Autocomplete-Widgets zu befüllen. Jede Combobox, jede Mehrfachauswahl, jede Radiobutton-Gruppe in Wicket und React baut ihre Optionen letztlich auf Objekten auf, die dieses Interface implementieren.

Das Interface hat nur zwei Methoden: getLabel() (was der Benutzer sieht – der Anzeigetext, typischerweise lokalisiert) und getValue() (was das System speichert – typischerweise eine Datenbank-ID oder ein Enum-Konstante). Die generischen Typen <L, V> erlauben es, dass Label und Wert unterschiedliche Typen haben – z.B. LabelValueBean<String, Long> für eine Benutzerauswahl (Label = "Max Mustermann", Wert = 42L).

Das "I"-Präfix ist ProjectForges ungarische Namenskonvention für Interfaces (I = Interface), die in älteren Java-Codebasen üblich ist. Die Implementierung ist LabelValueBean.

Warum zwei Typparameter?

Die meisten Label/Wert-Beans im Einsatz verwenden String, String – der Wert ist eine als String dargestellte ID. ProjectForge hat sich für separate generische Typen entschieden, damit der Wert seinen nativen Typ behält. Das ist wichtig, weil:

  • Wenn V = Long ist, erhält der Submit-Handler des Dropdowns direkt einen Long – kein Parsen nötig
  • Wenn V = MyEnum ist, trägt der Wert Typsicherheit – man kann nicht versehentlich einen String übergeben, wo ein Enum erwartet wird
  • Wickets IChoiceRenderer und Select2Choice können die generischen Typen zur Laufzeit untersuchen, um eine korrekte Typkonvertierung bereitzustellen

Verwendungsmuster in ProjectForge

  • Wicket-Dropdowns: DropDownChoice<ILabelValueBean<String, Long>> – eine Benutzerauswahl, die vollständige Namen mit Benutzer-IDs als Werte anzeigt
  • React Select2: Der REST-Controller serialisiert eine List<LabelValueBean<String, String>> als JSON für die <Select>-Komponenten des React-Frontends
  • HTML-Tag-Attribute: HtmlTagBuilder verwendet KeyValueBean<String, String> (ein verwandtes Interface) für den Aufbau von HTML-Attributen – addAttribute("class", "header")
  • Menüeinträge: Das Hauptnavigationsmenü baut seine Einträge als Label/Wert-Paare auf, die auf Wicket-Seitenklassen verweisen

Dieses Interface ist für ProjectForge das, was Map.Entry für Java-Collections ist – ein einfaches Zwei-Element-Tupel, das überall in der UI-Schicht vorkommt.
