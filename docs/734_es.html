Propósito

El patrón Etiqueta/Valor — una abstracción central de la interfaz de usuario utilizada en todas partes en ProjectForge para poblar menús desplegables, listas de selección y widgets de autocompletado. Cada combobox, cada selección múltiple, cada grupo de botones de radio en Wicket y React construye sus opciones a partir de objetos que implementan esta interfaz.

La interfaz tiene solo dos métodos: getLabel() (lo que el usuario ve — el texto mostrado, típicamente localizado) y getValue() (lo que el sistema almacena — típicamente un ID de base de datos o una constante de enumeración). Los tipos genéricos <L, V> permiten que la etiqueta y el valor sean de tipos diferentes — p. ej. LabelValueBean<String, Long> para un selector de usuario (etiqueta = "Juan Pérez", valor = 42L).

El prefijo "I" es la convención de nomenclatura al estilo húngaro de ProjectForge para interfaces (I = Interfaz), común en bases de código Java más antiguas. La implementación es LabelValueBean.

¿Por qué dos parámetros de tipo?

La mayoría de los beans de etiqueta/valor en el mundo real usan String, String — el valor es un ID convertido a cadena. ProjectForge eligió tipos genéricos separados para que el valor mantenga su tipo nativo. Esto importa porque:

  • Cuando V = Long, el manejador de envío del desplegable recibe un Long directamente — sin necesidad de parseo
  • Cuando V = MyEnum, el valor lleva seguridad de tipos — no puedes pasar accidentalmente un String donde se espera un enum
  • El IChoiceRenderer y Select2Choice de Wicket pueden inspeccionar los tipos genéricos en tiempo de ejecución para proporcionar una conversión de tipos adecuada

Patrones de uso en ProjectForge

  • Desplegables Wicket: DropDownChoice<ILabelValueBean<String, Long>> — un selector de usuario que muestra nombres completos con IDs de usuario como valores
  • React Select2: El controlador REST serializa una List<LabelValueBean<String, String>> como JSON para los componentes <Select> del frontend React
  • Atributos de etiquetas HTML: HtmlTagBuilder usa KeyValueBean<String, String> (una interfaz relacionada) para la construcción de atributos HTML — addAttribute("class", "header")
  • Elementos de menú: El menú de navegación principal construye sus elementos como pares etiqueta/valor que apuntan a clases de página de Wicket

Esta interfaz es para ProjectForge lo que Map.Entry es para las colecciones de Java — una tupla simple de dos elementos que aparece en todas partes en la capa de interfaz de usuario.
