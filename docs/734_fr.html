Objectif

Le modèle Label/Valeur — une abstraction d'interface utilisateur centrale utilisée partout dans ProjectForge pour alimenter les menus déroulants, les listes de sélection et les widgets d'autocomplétion. Chaque combobox, chaque sélection multiple, chaque groupe de boutons radio dans Wicket et React construit finalement ses options à partir d'objets implémentant cette interface.

L'interface comporte seulement deux méthodes : getLabel() (ce que l'utilisateur voit — le texte affiché, généralement localisé) et getValue() (ce que le système stocke — généralement un ID de base de données ou une constante d'énumération). Les types génériques <L, V> permettent au label et à la valeur d'être de types différents — par exemple LabelValueBean<String, Long> pour un sélecteur d'utilisateur (label = "Jean Dupont", valeur = 42L).

Le préfixe "I" est la convention de nommage de style hongrois de ProjectForge pour les interfaces (I = Interface), courante dans les anciens codebases Java. L'implémentation est LabelValueBean.

Pourquoi deux paramètres de type ?

La plupart des beans label/valeur dans la nature utilisent String, String — la valeur est un ID converti en chaîne. ProjectForge a choisi des types génériques séparés afin que la valeur conserve son type natif. Cela est important car :

  • Lorsque V = Long, le gestionnaire de soumission du menu déroulant reçoit un Long directement — aucun analyse nécessaire
  • Lorsque V = MyEnum, la valeur est typée de manière sécurisée — vous ne pouvez pas passer accidentellement une String là où une énumération est attendue
  • Le IChoiceRenderer et Select2Choice de Wicket peuvent inspecter les types génériques à l'exécution pour fournir une conversion de type appropriée

Modèles d'utilisation dans ProjectForge

  • Menus déroulants Wicket : DropDownChoice<ILabelValueBean<String, Long>> — un sélecteur d'utilisateur affichant les noms complets avec les ID utilisateur comme valeurs
  • React Select2 : Le contrôleur REST sérialise une List<LabelValueBean<String, String>> en JSON pour les composants <Select> du frontend React
  • Attributs de balises HTML : HtmlTagBuilder utilise KeyValueBean<String, String> (une interface apparentée) pour la construction d'attributs HTML — addAttribute("class", "header")
  • Éléments de menu : Le menu de navigation principal construit ses éléments comme des paires label/valeur pointant vers des classes de page Wicket

Cette interface est pour ProjectForge ce que Map.Entry est pour les collections Java — un simple tuple à deux éléments qui apparaît partout dans la couche d'interface utilisateur.
