Назначение

Паттерн «Метка/Значение» — основная UI-абстракция, используемая повсеместно в ProjectForge для заполнения выпадающих меню, списков выбора и виджетов автодополнения. Каждый комбобокс, каждый мультиселект, каждая группа радиокнопок в Wicket и React в конечном итоге строит свои опции из объектов, реализующих этот интерфейс.

Интерфейс имеет всего два метода: getLabel() (то, что видит пользователь — отображаемый текст, обычно локализованный) и getValue() (то, что хранит система — обычно ID базы данных или константа перечисления). Обобщённые типы <L, V> позволяют метке и значению быть разных типов — например, LabelValueBean<String, Long> для выбора пользователя (метка = "Иван Петров", значение = 42L).

Префикс «I» — это венгерская нотация ProjectForge для интерфейсов (I = Interface), распространённая в старых Java-кодовых базах. Реализация находится в LabelValueBean.

Зачем два параметра типа?

Большинство бинов «метка/значение» в мире используют String, String — значение представляет собой ID в виде строки. ProjectForge выбрал отдельные обобщённые типы, чтобы значение сохраняло свой нативный тип. Это важно, потому что:

  • Когда V = Long, обработчик отправки выпадающего списка получает Long напрямую — без необходимости парсинга
  • Когда V = MyEnum, значение несёт типобезопасность — вы не сможете случайно передать String туда, где ожидается перечисление
  • IChoiceRenderer и Select2Choice из Wicket могут анализировать обобщённые типы во время выполнения для обеспечения правильного преобразования типов

Шаблоны использования в ProjectForge

  • Выпадающие списки Wicket: DropDownChoice<ILabelValueBean<String, Long>> — выбор пользователя с отображением полных имён и ID пользователей в качестве значений
  • React Select2: REST-контроллер сериализует List<LabelValueBean<String, String>> в JSON для компонентов <Select> на фронтенде React
  • Атрибуты HTML-тегов: HtmlTagBuilder использует KeyValueBean<String, String> (связанный интерфейс) для построения HTML-атрибутов — addAttribute("class", "header")
  • Пункты меню: Основное навигационное меню строит свои элементы как пары метка/значение, указывающие на классы страниц Wicket

Этот интерфейс для ProjectForge — то же самое, что Map.Entry для коллекций Java: простой двухэлементный кортеж, который встречается повсюду в UI-слое.
