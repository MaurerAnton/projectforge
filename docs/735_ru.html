Назначение

Представляет объединение целочисленных интервалов — преобразует строки вида "1,3-5,10-15,20" в структурированный набор диапазонов и отдельных значений, после чего предоставляет метод doesMatch(value) для проверки принадлежности. Это целочисленная специализация абстрактного базового класса Ranges<T> (#742).

Конкретный сценарий использования — фильтрация номеров недель в табеле учёта времени. Когда администратор настраивает «показывать табели для недель 1–5, 10 и 20–25», эта строка конфигурации передаётся в new IntRanges("1-5,10,20-25"), и номер недели каждой записи табеля проверяется с помощью ranges.doesMatch(weekNumber). Это проще и читаемее, чем построение сложных SQL-выражений WHERE week IN (...), особенно когда список диапазонов настраивается для каждого пользователя.

Иерархия классов

Ranges<T extends Comparable<T>>  (абстрактный, 176 строк)
  └── IntRanges extends Ranges<Integer>  (54 строки, данный файл)

Ranges обрабатывает всю логику разбора — разделение по запятым/точкам с запятой (separatorChars = ";,"), обнаружение дефисов как разделителей диапазонов (rangesSeparatorChar = '-') и построение списка объектов Range<T> плюс отдельных значений. IntRanges предоставляет только конкретный метод parseValue(String), преобразующий строку в Integer — это шаблон «Шаблонный метод»: абстрактный базовый класс определяет алгоритм, а подкласс — преобразование типов.

Алгоритм разбора (в базовом классе Ranges)

Для входной строки "1-5,10,20-25":

  1. Разделение по , или ; → ["1-5", "10", "20-25"]
  2. Для каждой части проверяется наличие -:
    • Если есть: разделение по -, разбор обеих сторон → Range(1, 5) или Range(20, 25)
    • Если нет: разбор как одиночного значения → добавление 10 в список values

Метод doesMatch(value) проверяет все диапазоны (через Range.doesMatch(), который проверяет min <= value <= max) и все отдельные значения (через Comparable.compareTo() для точного совпадения). Флаг nullRangeMatchesAlways управляет поведением, когда не указано ни диапазонов, ни значений (по умолчанию false — ничего не совпадает).

Ключевые детали проектирования

  • Символы-разделители: Принимаются как запятая (,), так и точка с запятой (;) — корректная обработка скопированных из разных источников данных
  • Отрицательные числа: Разбор поддерживает отрицательные целые числа (например, "-5--1" означает «от -5 до -1»), поскольку Integer.valueOf() обрабатывает знак минус. Дефис как разделитель диапазона конфликтует со знаком минуса, но парсер проверяет наличие двух последовательных дефисов (--) как диапазон с отрицательными границами
  • Устойчивость к пробелам: Парсер обрезает пробелы вокруг значений, поэтому "1 - 5, 10" работает так же, как "1-5,10"
  • Обработка дубликатов: Допускается многократное добавление одного и того же значения или пересекающегося диапазона — doesMatch() возвращает true при первом совпадении, поэтому дубликаты не приводят к неверным результатам, хотя тратят небольшой объём памяти
  • Простота в 54 строки: Весь файл состоит из конструктора, вызывающего super(rangesString), и переопределения parseValue() в 3 строки. Вся сложность находится в абстрактном базовом классе Ranges — это идеальное применение наследования: подкласс предоставляет только преобразование, специфичное для типа, и ничего больше

Использование в кодовой базе

В основном используется в модуле табеля учёта времени для фильтрации по номерам недель. Фильтр табеля (#598) позволяет фильтровать по номерам недель — администратор или пользователь вводит выражение диапазона, например "1-10, 15, 20-25", которое разбирается в экземпляр IntRanges. При отображении табелей номер недели каждой записи проверяется на соответствие диапазонам для определения видимости. Интерфейс Serializable (унаследованный от Ranges) позволяет сохранять диапазоны в XML-файлах пользовательских настроек.
