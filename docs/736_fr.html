Objectif

Une paire clé-valeur générique, similaire à java.util.Map.Entry mais autonome et comparable. Utilisée partout dans ProjectForge lorsque deux données doivent voyager ensemble — options de liste déroulante, paramètres de configuration, attributs de balises HTML, critères de tri, étiquettes de graphiques, etc. 82 lignes.

La classe possède deux paramètres de type : KeyType (non contraint) et ValueType extends Comparable<ValueType> (doit être comparable — car le bean lui-même implémente Comparable basé sur la valeur). Ceci diffère de ILabelValueBean — cette interface n'exige pas la comparabilité ; cette classe le fait, car elle est utilisée dans des collections triées.

Comportement Comparable

La méthode compareTo() compare uniquement par la valeur, ignorant complètement la clé. La valeur doit implémenter Comparable — imposé au niveau du type. Cela signifie que deux KeyValueBean avec des clés différentes mais des valeurs égales sont considérés comme égaux à des fins de tri. Ce comportement est correct pour les listes déroulantes triées (où l'on trie par le texte affiché, pas par l'ID), mais surprenant si vous utilisez KeyValueBean comme clé de HashMap (où equals/hashCode importent davantage — et ceux-ci sont hérités de Object, non redéfinis). Il s'agit d'un compromis de conception délibéré : KeyValueBean est principalement destiné à l'affichage ordonné, pas au stockage dans une carte.

Constructeurs

  • KeyValueBean() — constructeur vide pour les frameworks qui en ont besoin (sérialisation Wicket, XStream)
  • KeyValueBean(clé) — clé uniquement (la valeur par défaut est null). Utilisé lorsque la clé elle-même est l'information d'affichage
  • KeyValueBean(clé, valeur) — constructeur complet. Le plus couramment utilisé

Relation avec ILabelValueBean

Clé-valeur vs étiquette-valeur — même motif, sémantique différente :

  • ILabelValueBean<L,V> — l'étiquette est ce que l'utilisateur voit, la valeur est l'ID système. Utilisé pour les listes déroulantes de l'interface utilisateur. Les deux types sont non contraints
  • KeyValueBean<K, V> — la clé est un identifiant système, la valeur est une donnée comparable quelconque. Utilisé pour les structures de données. La valeur doit être Comparable

Ils suivent conceptuellement le même motif mais sont utilisés dans des contextes différents. La distinction de nommage (Étiquette vs Clé) était intentionnelle — elle aide les lecteurs à comprendre le domaine : étiquette/valeur pour l'interface utilisateur, clé/valeur pour les structures de données internes.
