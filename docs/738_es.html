Propósito

Serializa pares clave-valor en formato de texto separado por comas — el inverso de KeyValuePairParser. Convierte una secuencia de llamadas write(clave, valor) en una sola línea como nombre="ProjectForge",version=8.0,maxUsuarios=100. 157 líneas.

El escritor maneja comillas adecuadas: los valores de cadena siempre se envuelven entre comillas dobles, y cualquier " dentro del valor se escapa duplicándolo (" → "") — la misma convención CSV que espera el analizador. Los números y fechas se escriben sin comillas. El carácter separador por defecto es la coma, pero es configurable mediante setCsvSeparator().

Métodos write() sobrecargados — 4 variantes

  • write(clave, long valor) — escribe como número simple: maxUsuarios=100. Sin comillas — seguro porque los números no contienen caracteres especiales
  • write(clave, Date valor) — escribe como cadena entrecomillada en formato "yyyy-MM-dd HH:mm:ss.SSS". El formato de fecha es configurable mediante setDateFormat(). Ejemplo: ultimaActualizacion="2025-01-24 14:30:00.000"
  • write(clave, String s) — escribe como cadena entrecomillada con manejo de escape. Itera cada carácter: si el carácter es ", lo escribe dos veces ("" → comilla escapada). Ejemplo: descripcion="Hallo, das ist ein ""Test""." → esto se codifica como Hallo, das ist ein "Test". al ser analizado
  • write(clave, Object valor) — respaldo para cualquier tipo. Usa String.valueOf(valor) — sin comillas. Adecuado para tipos donde toString() produce una representación segura y sin comillas. No recomendado para cadenas (use la sobrecarga de String en su lugar — este método no escapa comillas)

Lógica del separador

El método writeSeparator() implementa el clásico patrón de primera entrada: si esta es la primera entrada, no se escribe ningún separador; de lo contrario, se inserta una coma antes de la entrada actual. Esto evita una coma final al final de la línea. El booleano firstEntry se reinicia con cada nueva línea (el EOL del analizador desencadena una nueva instancia del escritor o un reinicio).

Constante de separador predeterminado

DEFAULT_SEPARATOR_CHAR = ',' es público — usado por KeyValuePairParser para establecer su pairsSeparatorChar por defecto. Tanto el analizador como el escritor usan coma por defecto, y ambos permiten cambiarlo. La constante asegura que comiencen con el mismo valor predeterminado.
