Назначение

Сериализует пары ключ-значение в текстовый формат с разделителями-запятыми — обратная операция для KeyValuePairParser. Преобразует последовательность вызовов write(key, value) в одну строку вида name="ProjectForge",version=8.0,maxUsers=100. 157 строк.

Запись обрабатывает правильное экранирование: строковые значения всегда заключаются в двойные кавычки, а любые " внутри значения экранируются удвоением (" → "") — та же CSV-конвенция, которую ожидает парсер. Числа и даты записываются без кавычек. Символ-разделитель по умолчанию — запятая, но его можно изменить через setCsvSeparator().

Перегруженные методы write() — 4 варианта

  • write(key, long value) — записывает как голое число: maxUsers=100. Без кавычек — безопасно, так как числа не содержат специальных символов
  • write(key, Date value) — записывает как строку в кавычках в формате "yyyy-MM-dd HH:mm:ss.SSS". Формат даты настраивается через setDateFormat(). Пример: lastUpdate="2025-01-24 14:30:00.000"
  • write(key, String s) — записывает как строку в кавычках с обработкой экранирования. Перебирает каждый символ: если символ — ", записывает его дважды ("" — экранированная кавычка). Пример: description="Hallo, das ist ein ""Test""." → при парсинге декодируется как Hallo, das ist ein "Test".
  • write(key, Object value) — запасной вариант для любого типа. Использует String.valueOf(value) — без кавычек. Подходит для типов, где toString() даёт безопасное представление без кавычек. Не рекомендуется для строк (используйте перегрузку для String — этот метод не экранирует кавычки)

Логика разделителя

Метод writeSeparator() реализует классический шаблон первой записи: если это первая запись, разделитель не записывается; в противном случае перед текущей записью вставляется запятая. Это позволяет избежать висячей запятой в конце строки. Логический флаг firstEntry сбрасывается с каждой новой строкой (парсер с помощью EOL инициирует новый экземпляр записи или сброс).

Константа разделителя по умолчанию

DEFAULT_SEPARATOR_CHAR = ',' является публичной — используется KeyValuePairParser для установки значения по умолчанию для pairsSeparatorChar. И парсер, и запись по умолчанию используют запятую, и оба позволяют её изменить. Константа гарантирует, что они начинают работу с одинаковым значением по умолчанию.
