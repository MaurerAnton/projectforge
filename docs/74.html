File #74: DataTransferAreaDO.kt

Path: ./plugins/datatransfer/.../DataTransferAreaDO.kt · Source: GitHub

Entity for data transfer areas (file sharing workspaces). Extends AbstractBaseDO<Long> (not DefaultBaseDO — uses LONG PK instead of INTEGER). Key features:

  • Access control: CSV lists for admin/observer/accessGroup/accessUser IDs — same pattern as BankAccountDO (#48).
  • External sharing: externalDownloadEnabled/externalUploadEnabled toggles + externalAccessToken (30 chars) + externalPassword (10 chars). Links shared via /datatransfer/dynamic/.
  • Attachments metadata: attachmentsNames, attachmentsIds, attachmentsCounter, attachmentsSize — JCR-backed file storage with denormalized metadata for fast queries.
  • Personal box detection: isPersonalBox() checks areaName == <PERSONAL_BOX> — a sentinel value. Password masked in toString().
  • Expiry: Files auto-deleted after expiryDays (7 default, 60 for personal boxes).
