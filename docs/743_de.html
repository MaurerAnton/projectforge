Zweck

Ein generisches geschlossenes Intervall [minValue, maxValue] mit einer doesMatch(value)-Enthaltenseinsprüfung. 102 Zeilen. Funktioniert mit jedem Typ, der Comparable implementiert — Ganzzahlen, Datumsangaben, Zeichenketten, BigDecimals usw. Der Konstruktor sortiert automatisch die beiden Grenzwerte — new Range(5, 1) erzeugt minValue=1, maxValue=5 unabhängig von der Argumentreihenfolge. Die Methode doesMatch(value) prüft minValue <= value <= maxValue mittels compareTo().

Dies ist Teil des Bereichsabgleichs-Frameworks: Range<T> (einzelnes Intervall) → Ranges<T> (Vereinigung von Intervallen) → IntRanges (#735, Ganzzahl-Spezialisierung). Verwendet für Zeiterfassungswochenfilter, Datumsbereichsabgleich und numerische Wertvalidierung.

Fließende API

Die Setter setMinValue() und setMaxValue() geben this für Verkettung zurück: new Range<>(1, 10).setMinValue(2).setMaxValue(9). Hinweis: Das Ändern von min/max nach der Konstruktion sortiert nicht neu — wenn Sie min=100 und max=1 setzen, gibt doesMatch() immer false zurück (kein Wert kann gleichzeitig >= 100 und <= 1 sein). Die automatische Sortierung erfolgt nur im Konstruktor.
