Propósito

Un intervalo cerrado genérico [minValue, maxValue] con una verificación de contención doesMatch(value). 102 líneas. Funciona con cualquier tipo que implemente Comparable — enteros, fechas, cadenas, BigDecimals, etc. El constructor ordena automáticamente los dos valores límite — new Range(5, 1) produce minValue=1, maxValue=5 independientemente del orden de los argumentos. El método doesMatch(value) verifica minValue <= value <= maxValue usando compareTo().

Esto es parte del marco de coincidencia de rangos: Range<T> (intervalo único) → Ranges<T> (unión de intervalos) → IntRanges (#735, especialización para enteros). Se utiliza para filtrado de semanas en hojas de tiempo, coincidencia de rangos de fechas y validación de valores numéricos.

API fluida

Los setters setMinValue() y setMaxValue() devuelven this para encadenamiento: new Range<>(1, 10).setMinValue(2).setMaxValue(9). Nota: cambiar min/max después de la construcción no reordena — si estableces min=100 y max=1, doesMatch() siempre devolverá falso (ningún valor puede ser simultáneamente >= 100 y <= 1). La ordenación automática solo ocurre en el constructor.
