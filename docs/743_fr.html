Objectif

Un intervalle fermé générique [minValue, maxValue] avec une vérification d'appartenance doesMatch(value). 102 lignes. Fonctionne avec tout type implémentant Comparable — entiers, dates, chaînes, BigDecimals, etc. Le constructeur trie automatiquement les deux valeurs limites — new Range(5, 1) produit minValue=1, maxValue=5 quel que soit l'ordre des arguments. La méthode doesMatch(value) vérifie minValue <= value <= maxValue en utilisant compareTo().

Cela fait partie du cadre de correspondance d'intervalles : Range<T> (intervalle unique) → Ranges<T> (union d'intervalles) → IntRanges (#735, spécialisation entière). Utilisé pour le filtrage des semaines de feuilles de temps, la correspondance de plages de dates et la validation de valeurs numériques.

API fluide

Les setters setMinValue() et setMaxValue() retournent this pour le chaînage : new Range<>(1, 10).setMinValue(2).setMaxValue(9). Remarque : modifier min/max après la construction ne réordonne pas — si vous définissez min=100 et max=1, doesMatch() retournera toujours faux (aucune valeur ne peut être simultanément >= 100 et <= 1). Le tri automatique n'a lieu que dans le constructeur.
