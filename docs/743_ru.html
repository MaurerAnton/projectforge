Назначение

Закрытый обобщённый интервал [minValue, maxValue] с проверкой вхождения doesMatch(value). 102 строки. Работает с любым типом, реализующим Comparable — целые числа, даты, строки, BigDecimal и т.д. Конструктор автоматически сортирует два граничных значения — new Range(5, 1) создаёт minValue=1, maxValue=5 независимо от порядка аргументов. Метод doesMatch(value) проверяет minValue <= value <= maxValue с помощью compareTo().

Это часть фреймворка сопоставления диапазонов: Range<T> (один интервал) → Ranges<T> (объединение интервалов) → IntRanges (#735, специализация для целых чисел). Используется для фильтрации недель в табелях, сопоставления диапазонов дат и проверки числовых значений.

Текучий API (Fluent API)

Сеттеры setMinValue() и setMaxValue() возвращают this для цепочечного вызова: new Range<>(1, 10).setMinValue(2).setMaxValue(9). Примечание: изменение min/max после создания не вызывает повторную сортировку — если установить min=100 и max=1, doesMatch() всегда будет возвращать false (ни одно значение не может быть одновременно >= 100 и <= 1). Автосортировка происходит только в конструкторе.
