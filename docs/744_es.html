Propósito

Unión de múltiples intervalos con análisis desde cadena de texto. Clase abstracta de 176 líneas. Toma una cadena como "1-5,10,20-25", la analiza en una lista de objetos Range<T> más valores individuales, y proporciona doesMatch(valor) para probar pertenencia. El complemento de Range — mientras que Range maneja un único intervalo, Ranges maneja múltiples intervalos y valores provenientes de entrada de texto proporcionada por el usuario.

Patrón de método plantilla: la subclase solo necesita implementar parseValue(String) → T. La base abstracta maneja toda la lógica de análisis, división y coincidencia. IntRanges es la implementación concreta para Integer.

Formato de entrada

"1-5,10,20-25"

Dividir por , o ; (separatorChars = ";,") → partes ["1-5", "10", "20-25"]. Cada parte contiene - (intervalo) o no (valor único). Los intervalos se almacenan como List<Range<T>>, los valores únicos como List<T>. doesMatch(valor) verifica primero los intervalos, luego los valores únicos — devuelve true en la primera coincidencia. Si la cadena de entrada está vacía o es nula, nullRangeMatchesAlways (por defecto false) determina el comportamiento.

Comportamientos clave

  • Intervalos negativos: "-5--1" → intervalo de -5 a -1. El analizador distingue el signo negativo del separador de intervalo verificando si hay dos guiones consecutivos
  • Intervalos superpuestos: permitidos — "1-5,3-7" coincide con ambos. doesMatch(4) devuelve true (primera coincidencia en la lista de intervalos)
  • Serializable: implementa Serializable — puede almacenarse en XML de preferencias de usuario. Los intervalos persisten entre sesiones
