Objectif

Union de plusieurs intervalles avec analyse syntaxique à partir d'une chaîne. Classe abstraite de 176 lignes. Prend une chaîne comme "1-5,10,20-25", l'analyse en une liste d'objets Range<T> plus des valeurs individuelles, et fournit doesMatch(valeur) pour tester l'appartenance. Le complément de Range — alors que Range gère un seul intervalle, Ranges gère plusieurs intervalles et valeurs à partir d'une entrée textuelle fournie par l'utilisateur.

Patron de méthode Template : la sous-classe doit seulement implémenter parseValue(String) → T. La classe de base abstraite gère toute la logique d'analyse, de fractionnement et de correspondance. IntRanges est l'implémentation concrète pour Integer.

Format d'entrée

"1-5,10,20-25"

Fractionnement sur , ou ; (separatorChars = ";,") → parties ["1-5", "10", "20-25"]. Chaque partie contient soit - (intervalle) soit non (valeur unique). Les intervalles sont stockés sous forme de List<Range<T>>, les valeurs uniques sous forme de List<T>. doesMatch(valeur) vérifie d'abord les intervalles, puis les valeurs uniques — retourne true dès la première correspondance. Si la chaîne d'entrée est vide ou nulle, nullRangeMatchesAlways (par défaut false) détermine le comportement.

Comportements clés

  • Intervalles négatifs : "-5--1" → intervalle de -5 à -1. L'analyseur distingue le signe négatif du séparateur d'intervalle en vérifiant la présence de deux traits d'union consécutifs
  • Intervalles chevauchants : autorisés — "1-5,3-7" correspond aux deux. doesMatch(4) retourne true (première correspondance dans la liste des intervalles)
  • Sérialisable : implémente Serializable — peut être stocké dans les préférences utilisateur XML. Les intervalles persistent entre les sessions
