Назначение

Объединение нескольких интервалов с разбором из строки. Абстрактный класс на 176 строк. Принимает строку вида "1-5,10,20-25", разбирает её в список объектов Range<T> плюс отдельные значения и предоставляет метод doesMatch(value) для проверки принадлежности. Дополнение к Range — в то время как Range обрабатывает один интервал, Ranges обрабатывает несколько интервалов и значений из текстового ввода пользователя.

Шаблонный метод: подклассу нужно реализовать только parseValue(String) → T. Абстрактная база обрабатывает весь разбор, разделение и логику сопоставления. IntRanges — конкретная реализация для Integer.

Формат ввода

"1-5,10,20-25"

Разделение по , или ; (separatorChars = ";,") → части ["1-5", "10", "20-25"]. Каждая часть либо содержит - (диапазон), либо нет (одиночное значение). Диапазоны хранятся как List<Range<T>>, одиночные значения — как List<T>. doesMatch(value) сначала проверяет диапазоны, затем одиночные значения — возвращает true при первом совпадении. Если входная строка пуста или равна null, поведение определяется nullRangeMatchesAlways (по умолчанию false).

Ключевые особенности

  • Отрицательные диапазоны: "-5--1" → диапазон от -5 до -1. Парсер отличает знак минуса от разделителя диапазона, проверяя наличие двух последовательных дефисов
  • Перекрывающиеся диапазоны: допускаются — "1-5,3-7" соответствует обоим. doesMatch(4) возвращает true (первое совпадение в списке диапазонов)
  • Сериализуемость: реализует Serializable — может храниться в XML-настройках пользователя. Диапазоны сохраняются между сеансами
