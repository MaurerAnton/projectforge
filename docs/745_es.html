projectforge-business/src/main/java/org/projectforge/framework/utils/RecentQueue.java Líneas: 137 · Autor: Kai Reinhard · Tipo: FIFO genérico acotado en Java 137 líneas · 82 código · 39 comentarios · 16 en blanco

Propósito

Cola acotada de "usados recientemente" — la estructura de datos detrás de cada menú desplegable de "Elementos recientes" en ProjectForge. 137 líneas. Almacena hasta maxSize (por defecto 25) entradas, con la más reciente en la posición 0. Cuando una entrada se vuelve a añadir, se mueve al frente en lugar de duplicarse. Las entradas más antiguas se eliminan. Seguro para hilos mediante synchronized(this) en las mutaciones. Serializado a XML a través de XStream para persistencia en preferencias de usuario.

Métodos clave

  • append(T entrada) — el mutador principal. Si la entrada ya existe (encontrada por indexOf() → usa equals()), la elimina primero (deduplicación). Si está al máximo de capacidad, elimina la entrada más antigua (al final de la lista). Inserta en la posición 0. Devuelve this para encadenamiento
  • getRecent() — devuelve get(0) (la más reciente) o null si está vacía
  • get(Integer pos) — seguro contra null — devuelve null para posiciones inválidas en lugar de lanzar IndexOutOfBoundsException. También maneja pos == null devolviendo get(0). Este diseño defensivo es para casos extremos de serialización de Wicket
  • addOnly(T entrada) — añade sin expulsión (ignora maxSize). Se usa al inicializar desde XML guardado — la cola ya fue truncada al guardarse, por lo que volver a añadir no debe expulsar

Compatibilidad con XStream

Anotado @XStreamAlias("recents") en el campo recentList (nótese el error tipográfico "recents" no "recent" — es intencional). El comentario dice: "Se llamaba recents en la versión anterior (antes del 2020-04-05)" — esto es un alias de compatibilidad hacia atrás. El XML de preferencias antiguo usaba <recents> como nombre del elemento; cuando el campo se renombró a recentList, el alias preservó el formato XML antiguo para que las preferencias de usuario existentes no se rompieran.
