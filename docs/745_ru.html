Назначение

Ограниченная очередь «недавно использованных» — структура данных, лежащая в основе каждого выпадающего списка «Недавние элементы» в ProjectForge. 137 строк. Хранит до maxSize (по умолчанию 25) записей, причём самая новая находится на позиции 0. Когда запись добавляется повторно, она перемещается в начало, а не дублируется. Самые старые записи удаляются. Потокобезопасность обеспечивается через synchronized(this) при изменениях. Сериализуется в XML через XStream для сохранения в пользовательских настройках.

Ключевые методы

  • append(T entry) — основной метод изменения. Если запись уже существует (определяется через indexOf() → использует equals()), сначала удаляет её (дедупликация). Если достигнут лимит, удаляет самую старую запись (в конце списка). Вставляет на позицию 0. Возвращает this для цепочечного вызова
  • getRecent() — возвращает get(0) (самую новую) или null, если пусто
  • get(Integer pos) — безопасный по null — возвращает null для недопустимых позиций вместо выбрасывания IndexOutOfBoundsException. Также обрабатывает pos == null, возвращая get(0). Такая защитная конструкция предназначена для граничных случаев сериализации Wicket
  • addOnly(T entry) — добавляет без удаления (игнорирует maxSize). Используется при инициализации из сохранённого XML — очередь уже была усечена при сохранении, поэтому повторное добавление не должно удалять записи

Совместимость с XStream

Поле recentList аннотировано @XStreamAlias("recents") (обратите внимание на опечатку «recents» вместо «recents» — это сделано намеренно). В комментарии сказано: «Было названо recents в предыдущей версии (до 2020-04-05)» — это псевдоним для обратной совместимости. В старом XML настроек использовался элемент <recents>; когда поле было переименовано в recentList, псевдоним сохранил старый формат XML, чтобы существующие пользовательские настройки не сломались.
