projectforge-business/src/main/java/org/projectforge/framework/utils/ReflectionHelper.java Líneas: 86 · Tipo: Utilidad Java — reflexión solo para constructores 86 líneas · 35 código · 45 comentarios · 6 en blanco

Propósito

Invocación de constructores basada en reflexión — llama a constructores con argumentos tipados en tiempo de ejecución. 86 líneas. Utilizado por el motor de importación Excel (ClassFactory → #380) y otros lugares donde se necesitan instanciar objetos a partir de nombres de clase y parámetros determinados en tiempo de ejecución (por ejemplo, instanciar clases ContentProvider a partir de cadenas de configuración de importación).

Proporciona sobrecargas para constructores de 1 y 2 argumentos como métodos de conveniencia, además de un newInstance(Class, Class[], Object[]) general para cualquier número de argumentos. Todos los métodos envuelven NoSuchMethodException, InvocationTargetException, etc. en RuntimeException (no verificada) para que los llamadores no necesiten try-catch — este es el patrón estándar de ProjectForge: los errores de reflexión se consideran errores internos, no excepciones recuperables.
