projectforge-business/src/main/java/org/projectforge/framework/utils/ReflectionHelper.java Строк: 86 · Тип: Утилита Java — отражение только для конструкторов 86 строк · 35 кода · 45 комментариев · 6 пустых

Назначение

Вызов конструкторов через рефлексию — вызывает конструкторы с типизированными аргументами во время выполнения. 86 строк. Используется механизмом импорта Excel (ClassFactory → #380) и другими местами, где объекты необходимо создавать из имён классов и параметров, определяемых во время выполнения (например, создание экземпляров классов ContentProvider из строк конфигурации импорта).

Предоставляет перегруженные методы для конструкторов с 1 и 2 аргументами в качестве удобных методов, а также общий newInstance(Class, Class[], Object[]) для любого количества аргументов. Все методы оборачивают NoSuchMethodException, InvocationTargetException и т.д. в RuntimeException (непроверяемое), чтобы вызывающим сторонам не требовался try-catch — это стандартный шаблон ProjectForge: ошибки отражения считаются внутренними ошибками, а не восстанавливаемыми исключениями.
