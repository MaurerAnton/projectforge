Propósito

Envoltorio de resultado genérico utilizado como valor de retorno de métodos de servicio. 106 líneas. Combina un estado (ResultHolderStatus: OK/WARNING/ERROR/FAILED) con una lista de mensajes. Esta es la versión de ProjectForge del patrón Result — en lugar de que los métodos devuelvan un valor o lancen excepciones, devuelven un ResultHolder con mensajes acumulados.

Clases internas — el modelo de mensaje

  • IMessage — interfaz con getMessage()
  • Message — almacena un mensaje de cadena sin formato (texto estático)
  • I18nMessage — almacena una clave de i18n + parámetros opcionales. getMessage() resuelve la clave mediante ThreadLocalUserContext.getLocalizedString() con sustitución de parámetros MessageFormat. Esta es la variante más utilizada — la mayoría de los resultados de operaciones necesitan mensajes internacionalizados

Patrón de uso

ResultHolder resultado = miServicio.hacerAlgo();
if (resultado.getStatus() == ResultHolderStatus.ERROR) {
    mostrarErrores(resultado.getMessages());
}

El contenedor acumula mensajes a través de addMessage() — se pueden recopilar múltiples errores de validación antes de devolverlo. Utilizado por validadores de formularios, operaciones de importación y pasos del asistente de configuración donde se deben informar múltiples problemas a la vez en lugar de fallar en el primer error.
