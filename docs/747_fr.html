Objectif

Wrapper de résultat générique utilisé comme valeur de retour des méthodes de service. 106 lignes. Combine un statut (ResultHolderStatus : OK/WARNING/ERROR/FAILED) avec une liste de messages. Il s'agit de la version ProjectForge du modèle Result — au lieu que les méthodes retournent une valeur ou lèvent des exceptions, elles retournent un ResultHolder avec des messages accumulés.

Classes internes — le modèle de message

  • IMessage — interface avec getMessage()
  • Message — stocke un message textuel brut (texte statique)
  • I18nMessage — stocke une clé i18n + paramètres optionnels. getMessage() résout la clé via ThreadLocalUserContext.getLocalizedString() avec substitution de paramètres MessageFormat. Il s'agit de la variante la plus couramment utilisée — la plupart des résultats d'opération nécessitent des messages internationalisés

Modèle d'utilisation

ResultHolder result = myService.doSomething();
if (result.getStatus() == ResultHolderStatus.ERROR) {
    showErrors(result.getMessages());
}

Le holder accumule les messages via addMessage() — plusieurs erreurs de validation peuvent être collectées avant le retour. Utilisé par les validateurs de formulaire, les opérations d'importation et les étapes de l'assistant de configuration où plusieurs problèmes doivent être signalés en une seule fois plutôt que d'échouer sur la première erreur.
