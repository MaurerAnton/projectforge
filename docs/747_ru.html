Назначение

Универсальная обёртка результата, используемая как возвращаемое значение из методов сервиса. 106 строк. Объединяет статус (ResultHolderStatus: OK/WARNING/ERROR/FAILED) со списком сообщений. Это версия ProjectForge паттерна Result — вместо того чтобы методы возвращали значение или выбрасывали исключения, они возвращают ResultHolder с накопленными сообщениями.

Внутренние классы — модель сообщения

  • IMessage — интерфейс с getMessage()
  • Message — хранит сырое строковое сообщение (статический текст)
  • I18nMessage — хранит i18n-ключ + необязательные параметры. getMessage() разрешает ключ через ThreadLocalUserContext.getLocalizedString() с подстановкой параметров MessageFormat. Это более часто используемый вариант — большинству результатов операций нужны интернационализированные сообщения

Шаблон использования

ResultHolder result = myService.doSomething();
if (result.getStatus() == ResultHolderStatus.ERROR) {
    showErrors(result.getMessages());
}

Холдер накапливает сообщения через addMessage() — можно собрать несколько ошибок валидации перед возвратом. Используется валидаторами форм, операциями импорта и шагами мастера настройки, где нужно сообщить о нескольких проблемах сразу, а не останавливаться на первой ошибке.
