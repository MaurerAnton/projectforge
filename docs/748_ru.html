Назначение

Четырёхуровневый статус результата для ResultHolder. Значения: OK (успех), WARNING (успех с замечаниями — операция выполнена, но есть что-то достойное внимания), ERROR (ошибка — операция не может быть завершена), FAILED (фатальная ошибка — критический сбой, вероятно, баг или системная проблема). Ключи интернационализации: common.resultholder.ok и т.д. Имеет вспомогательный метод с переменным числом аргументов isIn(ResultHolderStatus...) для проверки нескольких значений.

Различие между ERROR и FAILED тонкое: ERROR означает «запрос пользователя не может быть выполнен» (ошибка валидации, отказ в доступе), тогда как FAILED означает «произошло то, чего не должно было случиться» (NullPointerException, сбой подключения к базе данных). В интерфейсе сообщения ERROR отображаются как красные баннеры ошибок; FAILED может показывать общую страницу «внутренняя ошибка».
