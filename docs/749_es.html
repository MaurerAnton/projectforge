#749: StackTraceHolder.java

projectforge-business/src/main/java/org/projectforge/framework/utils/StackTraceHolder.java Líneas: 75 · Autor: Kai Reinhard · Tipo: Java Serializable 75 líneas · 39 código · 28 comentarios · 8 en blanco

Propósito

Captura el stack trace del hilo actual en el momento de la construcción y lo almacena para su inspección posterior. 75 líneas. Es una utilidad de depuración/auditoría — se usa para registrar dónde se creó un objeto, de modo que si más tarde causa problemas, se pueda identificar el lugar de creación. El constructor llama a Thread.currentThread().getStackTrace() y almacena los primeros depth elementos (por defecto 10). El método toString() lo formatea como una cadena de stack trace estándar.

¿Por qué no usar ExceptionStackTracePrinter (#731)? Esa utilidad trabaja sobre objetos Throwable. Esta clase funciona sin una excepción — captura el stack trace en el punto de creación del objeto, antes de que ocurra cualquier error. Es una técnica de depuración preventiva: envuelve un valor sospechoso en StackTraceHolder durante la construcción, y si el valor causa un error más tarde, el stack trace revela de dónde vino.
