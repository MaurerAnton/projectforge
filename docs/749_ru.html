Назначение

Захватывает стек вызовов текущего потока в момент создания и сохраняет его для последующего анализа. 75 строк. Это утилита для отладки/аудита — используется для записи места создания объекта, чтобы в случае возникновения проблем в будущем можно было определить точку создания. Конструктор вызывает Thread.currentThread().getStackTrace() и сохраняет первые depth элементов (по умолчанию 10). Метод toString() форматирует результат в виде стандартной строки стектрейса.

Почему не использовать ExceptionStackTracePrinter (#731)? Эта утилита работает с объектами Throwable. Данный класс работает без исключения — он захватывает стек вызовов в момент создания объекта, до того, как произошла ошибка. Это превентивная техника отладки: оберните подозрительное значение в StackTraceHolder при создании, и если значение вызовет ошибку позже, стек вызовов покажет, откуда оно взялось.
