File #75: DataTransferAuditDao.kt

Path: ./plugins/datatransfer/.../DataTransferAuditDao.kt · Source: GitHub

Audit log DAO for data transfer events. Records every file upload, download, and delete. Key features:

  • Batched notifications: removeFromQueue() marks audit entries as notified in chunks of 50.
  • 10-minute debounce: internalGetQueuedEntriesByAreaId() returns null if any non-download event is newer than 10 minutes — prevents notification spam during bulk uploads.
  • Download filtering: Download events bypass notifications (downloadEventTypes exclude DOWNLOAD/DOWNLOAD_MULTI/DOWNLOAD_ALL) — only uploads and deletes trigger alerts.
  • Access-aware queries: getEntriesByAreaId() checks user access before returning audit data — personal box owners can't see each other's audit logs.
  • Cleanup: deleteOldEntries() purges old audit records by timestamp.
