projectforge-business/src/main/java/org/projectforge/framework/xmlstream/AliasMap.java Líneas: 54 · Tipo: Java — mapeo bidireccional Clase ↔ alias 54 líneas · 24 código · 22 comentarios · 8 en blanco

Propósito

Mapa bidireccional entre clases Java y nombres de alias XML para el framework personalizado XmlStream de ProjectForge (una alternativa ligera a XStream). 54 líneas. Mantiene dos HashMaps: Clase → alias (para serialización — saber qué etiqueta XML usar para una clase dada) y alias → Clase (para deserialización — saber qué clase instanciar a partir de una etiqueta XML).

Este es el mismo concepto que el método alias() de XStream pero implementado manualmente. Se utiliza para traducir entre nombres de clase Java como org.projectforge.business.user.PFUserDO y nombres de etiqueta XML como <user>. El método put() asegura que ambas direcciones se mantengan sincronizadas — no puedes tener una dirección sin la otra.
