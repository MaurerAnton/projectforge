Objectif

Correspondance bidirectionnelle entre les classes Java et les noms d'alias XML pour le framework XmlStream personnalisé de ProjectForge (une alternative légère à XStream). 54 lignes. Maintient deux HashMap : Classe → alias (pour la sérialisation — savoir quelle balise XML utiliser pour une classe donnée) et alias → Classe (pour la désérialisation — savoir quelle classe instancier à partir d'une balise XML).

C'est le même concept que la méthode alias() de XStream, mais implémenté manuellement. Il est utilisé pour traduire entre les noms de classes Java comme org.projectforge.business.user.PFUserDO et les noms de balises XML comme <user>. La méthode put() garantit que les deux directions restent synchronisées — vous ne pouvez pas avoir une direction sans l'autre.
