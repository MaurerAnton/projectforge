projectforge-business/src/main/java/org/projectforge/framework/xmlstream/AliasMap.java Строк: 54 · Тип: Java — двунаправленное отображение Class ↔ alias 54 строки · 24 кода · 22 комментария · 8 пустых

Назначение

Двунаправленное отображение между Java-классами и XML-псевдонимами для собственного фреймворка XmlStream ProjectForge (лёгкая альтернатива XStream). 54 строки. Поддерживает два HashMap: Class → alias (для сериализации — знает, какой XML-тег использовать для данного класса) и alias → Class (для десериализации — знает, какой класс создать из XML-тега).

Это та же концепция, что и метод alias() в XStream, но реализованная вручную. Используется для перевода между именами Java-классов, такими как org.projectforge.business.user.PFUserDO, и именами XML-тегов, например <user>. Метод put() гарантирует синхронизацию обоих направлений — нельзя иметь одно направление без другого.
