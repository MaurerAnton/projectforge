#756: XmlObject.java

Lines: 44 · Author: Kai Reinhard · Type: Java annotation · Retention: RUNTIME · Target: TYPE

Что это

Аннотация уровня класса — маркер того что класс может быть сериализован/десериализован фреймворком XmlStream. 44 строки. Это аналог JAXB's @XmlRootElement и XStream's неявного соглашения (любой класс может быть сериализован). В отличие от них, XmlStream требует явной аннотации — класс без @XmlObject не будет обработан ни XmlObjectReader ни XmlObjectWriter. Это сделано для безопасности: только явно разрешённые классы участвуют в сериализации.

Единственный параметр — alias()

Переопределяет имя корневого XML-элемента. По умолчанию (пустая строка) используется полное квалифицированное имя класса: org.projectforge.business.user.PFUserDO → <org.projectforge.business.user.PFUserDO>. С алиасом: @XmlObject(alias = "user") → <user>. Алиасы регистрируются в AliasMap (#750) при инициализации XmlRegistry (#776).

Разница с @XmlField(alias): @XmlObject.alias задаёт имя корневого элемента (тег, оборачивающий весь объект), а @XmlField.alias — имя дочернего элемента или атрибута (конкретного поля).

Как используется в рантайме

  1. XmlRegistry при старте приложения сканирует classpath (или конфигурационный файл) и находит все классы с @XmlObject
  2. Для каждого такого класса регистрирует его в AliasMap: Class → alias и alias → Class
  3. XmlObjectReader.newInstance() при встрече XML-элемента ищет соответствующий класс в AliasMap.getClassForAlias(tagName)
  4. Если класс найден — создаёт экземпляр через Class.newInstance() и рекурсивно заполняет поля (используя @XmlField)
  5. Если класс не найден — возвращает Status.IGNORE (#752)

XmlObject vs XStream @XStreamAlias

Ключевое отличие: @XmlObject — это не просто алиас, это явное разрешение на сериализацию. Класс без @XmlObject вообще не участвует в процессе. XStream же по умолчанию сериализует любой класс — это создаёт риск случайной утечки данных (например, сериализация Hibernate прокси с паролями). XmlStream безопаснее, но требует больше ручной работы по разметке.
