#757: XmlObjectReader.java

Lines: 514 · Author: Kai Reinhard · Type: Java — движок десериализации XmlStream · Library: dom4j

Что это

Ядро десериализации фреймворка XmlStream — превращает XML (в виде dom4j Element дерева) обратно в Java-объекты с заполненными полями. 514 строк. Это самый большой файл в XmlStream-фреймворке. Javadoc: "Parses objects serialized by the XmlObjectWriter. Uses the dom4j." Работает в паре с XmlObjectWriter — Writer сериализует объекты в XML, Reader десериализует XML обратно в объекты.

Архитектура — state machine с backtracking

Reader — это stateful объект (в отличие от stateless Writer). Он хранит состояние во время одного сеанса чтения:

  • processedElements (Set<Element>) — какие XML-элементы были успешно прочитаны. После завершения чтения, все элементы НЕ из этого сета считаются "проигнорированными" и попадают в warnings
  • processedAttributes (Map<Element, Set<String>>) — какие атрибуты каждого элемента были прочитаны. Аналогично для предупреждений
  • referenceObjects (Map<String, Object>) — кэш десериализованных объектов по их o-id. Используется для дедупликации: если два XML-элемента ссылаются на один объект, он десериализуется один раз, а второй раз — возвращается из кэша
  • warnings (String) — накопленные предупреждения о проигнорированных элементах/атрибутах

Входные точки — два метода read()

read(String xml) — публичный API

Принимает сырую XML-строку. Парсит её через XmlHelper.fromString() → dom4j Element. Очищает состояние (processedElements, processedAttributes, warnings). Вызывает внутренний read(Element). После чтения запускает checkForIgnoredElements() — если в XML остались необработанные теги/атрибуты, они попадают в warnings. Возвращает корневой десериализованный объект.

read(Element el) — внутренний API

Берёт dom4j Element, по имени тега находит класс (через getClass()), и вызывает рекурсивный read(Class<?> clazz, Element el, ...). Если класс не найден — возвращает null.

Трёхуровневый поиск класса — getClass(String elementName)

При встрече XML-тега, Reader ищет соответствующий Java-класс в трёх местах (в порядке приоритета):

  1. AliasMap (свой): this.aliasMap.getClassForAlias(name) — если был явно задан через setAliasMap()
  2. XmlRegistry (глобальный): xmlRegistry.getClassForAlias(name) — из XmlRegistry, куда классы регистрируются при старте
  3. Class.forName() (fallback): попытка загрузить класс по полному квалифицированному имени. Если класс — интерфейс, проверяет implementationMapping (интерфейс → конкретный класс). Если класс не найден — логирует ошибку и возвращает null (элемент будет проигнорирован)

Эта трёхуровневая система позволяет гибко управлять маппингом: AliasMap для локальных переопределений, XmlRegistry для глобальных правил, Class.forName для обратной совместимости со старыми XML-файлами где теги были полными именами классов.

Основной рекурсивный метод — read(Class, Element, attrName, attrValue)

Это сердце всего Reader'а. Принимает тип поля, XML-элемент, и опционально имя/значение атрибута (если значение пришло из атрибута а не из текста элемента). Логика — цепочка проверок типа:

  1. Reference check: если у элемента есть атрибут o-ref-id — это ссылка на уже десериализованный объект. Ищет в referenceObjects и возвращает кэшированный объект (дедупликация). Если ref-id не найден — логирует ошибку
  2. Converter check: если для типа зарегистрирован IConverter (через xmlRegistry.getConverter(clazz)) — вызывает converter.fromString(). Это для простых типов: String, Integer, Date, BigDecimal, Boolean
  3. Enum check: если класс — enum, вызывает enumFromString(). Пытается Enum.valueOf(clazz, val). При IllegalArgumentException делает вторую попытку с toUpperCase() — это для обратной совместимости со старыми XML где enum'ы были в нижнем регистре. Значение "null" трактуется как null
  4. Collection check: если класс — Collection (List/Set/SortedSet), создаёт соответствующую реализацию (ArrayList/HashSet/TreeSet), и рекурсивно читает все дочерние XML-элементы как элементы коллекции. Если ignoreEmptyCollections=true и коллекция пуста — оставляет поле null
  5. Complex object: для всех остальных типов (классы с @XmlObject) — создаёт экземпляр через BeanHelper.newInstance(), проверяет наличие o-id атрибута (сохраняет в referenceObjects для будущих ref-id ссылок), и вызывает read(obj, el) для рекурсивного заполнения полей

Заполнение полей — read(Object obj, Element el)

Обходит все поля объекта (через BeanHelper.getAllDeclaredFields() — כולя унаследованные), делает их accessible (reflection), и для каждого XML-атрибута и дочернего элемента ищет соответствующее поле:

  • Сначала проверяет @XmlOmitField — если есть, поле пропускается
  • Ищет @XmlField аннотацию. Сравнивает имя тега/атрибута с именем поля (case-sensitive) и с alias'ом из аннотации
  • Если поле найдено — вызывает read(field.getType(), element, key, attrValue) для десериализации значения, затем field.set(obj, value) для присвоения
  • Если поле НЕ найдено — логирует warning "Field '...' not found.". Элемент остаётся непомеченным в processedElements и попадёт в warnings

Важно: поля o-id и ref-id (XML-атрибуты Writer'а) явно пропускаются — они не ищутся среди полей объекта.

Предупреждения — checkForIgnoredElements()

После чтения всего XML, Reader проверяет: все ли элементы из исходного XML-дерева были помечены как processed? Если нет — значит в XML были теги, для которых не нашлось полей в Java-классе. Это может означать:

  • XML создан более новой версией ProjectForge (новые поля есть в XML но нет в коде)
  • Опечатка в имени поля или alias'е
  • Класс был изменён (поле удалено или переименовано)

Все непомеченные элементы и атрибуты собираются в warnings строку. Если строка > 500 символов — обрезается (ABBREVIATE_WARNING=500) чтобы не забивать логи.

Хуки для подклассов — Template Method

Три protected-метода могут быть переопределены в подклассах:

  • newInstance(Class, Element, String, String) — перехват создания объекта. Если возвращает Status.IGNORE, объект пропускается. По умолчанию возвращает null (создавать стандартно)
  • addCollectionEntry(Collection, Object, Element) — перехват добавления в коллекцию. Если возвращает true, объект НЕ добавляется автоматически. По умолчанию false
  • setField(Field, Object, Object, Element, String, String) — перехват присвоения поля. По умолчанию вызывает field.set(obj, value)

Эти хуки позволяют наследникам модифицировать поведение без переписывания всей логики — например, пропускать определённые поля, фильтровать коллекции, или выполнять пост-обработку объектов.

initialize(Class) — предварительное сканирование

Может быть вызван перед чтением чтобы заранее зарегистрировать все @XmlObject-классы в AliasMap. Рекурсивно обходит дерево типов: для класса с @XmlObject регистрирует алиас, затем для каждого не-примитивного поля рекурсивно вызывает initialize(). Использует processed Set для предотвращения бесконечной рекурсии при циклических ссылках. Это позволяет не указывать все классы вручную — достаточно передать корневой класс, и Reader сам найдёт все вложенные типы.
