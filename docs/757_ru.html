#757: XmlOmitField.java

Строк: 39 · Автор: Kai Reinhard · Тип: Java marker annotation · Пакет: org.projectforge.framework.xmlstream

Что это

Маркерная аннотация — помечает поле Java-класса как не подлежащее XML-сериализации. 39 строк, из которых 21 — GPL-лицензия. Это полный аналог transient из Java Serialization API и @XmlTransient из JAXB, но для фреймворка XmlStream. Проверяется в XmlObjectWriter.writeField() и в XmlObjectReader.read().

Почему отдельная аннотация, а не transient?

Java ключевое слово transient исключает поле из всех видов сериализации. @XmlOmitField даёт гранулярный контроль: поле может быть НЕ-transient (участвует в Java-сериализации сессии) но всё равно исключено из XML.

Пример безопасности: поле password в PFUserDO. transient (безопасность сессии) + @XmlOmitField (безопасность XML) — двойная защита от утечки паролей в экспорт.
