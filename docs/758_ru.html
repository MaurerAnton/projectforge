#758: AliasMap.java

Строк: 40 · Автор: Kai Reinhard · Тип: Java утилита — двунаправленный маппинг Class↔XML-alias · Пакет: org.projectforge.framework.xmlstream

Что это

Двунаправленный маппинг между Java-классами и XML-именами тегов. 40 строк. Поддерживает две HashMap — одну для Class → alias и другую для alias → Class — обеспечивая O(1) поиск в обоих направлениях. Это центральный реестр "как Java-классы отображаются на XML-теги" в фреймворке XmlStream. Используется XmlObjectWriter (запись правильного имени тега) и XmlObjectReader (поиск класса по тегу в XML).

Дизайн — двунаправленный HashMap

  • aliasMap1: Map<Class<?>, String> — Class → alias для сериализации
  • aliasMap2: Map<String, Class<?>> — alias → Class для десериализации

Обе карты заполняются одновременно через put(Class, String). Простой и эффективный паттерн — не нужен Guava BiMap, только два обычных HashMap. Двойная память за быстрый двунаправленный поиск, но при типичных размерах (десятки-сотни записей) накладные расходы пренебрежимо малы.

Использование в конвейере XmlStream

  1. Регистрация: XmlRegistry и XmlObjectReader.initialize() заполняют AliasMap для всех классов с @XmlObject
  2. Сериализация (Writer): XmlObjectWriter.write() вызывает aliasMap.getAliasForClass(type)
  3. Десериализация (Reader): XmlObjectReader.getClass() вызывает aliasMap.getClassForAlias(elementName)

Почему не Guava BiMap?

AliasMap предшествует широкому использованию Guava в ProjectForge. Подход с двумя HashMap проще, избегает внешней зависимости, а уникальность значений обеспечивается вызывающим кодом (XmlRegistry), а не структурой данных.
