File #76: DataTransferAuditDO.kt

Path: ./plugins/datatransfer/.../DataTransferAuditDO.kt · Source: GitHub

Entity for data transfer audit log entries. Tracks UPLOAD, DOWNLOAD, DELETE, MODIFIED events with: byUser (internal) / byExternalUser (anonymous), uploadByUser (original uploader for notification), filename / filenameOld (for rename tracking), notified flag (observer emails sent). 6 named queries for finding, deleting, and updating notification status. Computed properties: timeAgo (human-readable) and eventAsString (i18n).
