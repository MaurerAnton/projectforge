Lines: 248 · Author: Kai Reinhard · Type: Java — центральный реестр фреймворка XmlStream (Singleton + наследуемый)

Что это

Центральный реестр фреймворка XmlStream — хранит маппинги Class↔Alias, Class↔Converter, и список типов-по-умолчанию-атрибутов. 248 строк. Реализован как Singleton с наследованием: есть один глобальный экземпляр (baseRegistry), но можно создать дочерние реестры которые сначала ищут в себе, а при отсутствии — делегируют в baseRegistry. Это позволяет плагинам регистрировать свои типы не модифицируя глобальный реестр.

Singleton + Delegation паттерн

Статический блок static { baseRegistry = new XmlRegistry(); baseRegistry.initializeDefaultRegistry(); } создаёт глобальный синглтон при загрузке класса. Все lookup-методы (getConverter, getAliasForClass, getClassForAlias, asAttributeAsDefault) следуют одному шаблону: сначала ищут в себе, если нет — проверяют this == baseRegistry (чтобы избежать рекурсии), и если это дочерний реестр — делегируют в baseRegistry. Пример:

public IConverter getConverter(Class clazz) {
    if (converterRegistry != null) {
        IConverter conv = converterRegistry.get(clazz);     // поиск в себе
        if (conv != null) return conv;
        for (Class cls : converterRegistry.keySet()) {      // поиск по иерархии
            if (cls.isAssignableFrom(clazz)) { ... }
        }
    }
    if (this == baseRegistry) return null;                   // стоп-условие
    return baseRegistry.getConverter(clazz);                 // делегация
}

initializeDefaultRegistry() — что регистрируется по умолчанию

Приватный метод, вызывается один раз при загрузке класса. Регистрирует 3 категории:

  1. asAttributeAsDefault (14 типов): BigDecimal, Boolean, Date, Double, Integer, Long, Short, TimeZone, Locale, Version — все они по умолчанию пишутся как XML-атрибуты а не элементы (компактнее). Включает и примитивы, и обёртки
  2. Alias'ы (15 типов): BigDecimal→"decimal", Boolean→"boolean", Double→"double", Integer→"int", Long→"long", Short→"short", TimeZone→"timeZone", Locale→"locale", Version→"version". Без алиасов в XML были бы полные имена классов
  3. Converter'ы (14 типов): BooleanConverter, DoubleConverter, IntConverter, LongConverter, ShortConverter, ByteArrayConverter, BigDecimalConverter, ClassConverter, DateConverter, StringConverter, TimeZoneConverter, LocaleConverter, VersionConverter, LocalDateConverter. Каждый конвертер умеет преобразовывать значение в строку и обратно

getConverter — поиск с учётом иерархии классов

Простой поиск converterRegistry.get(clazz) находит только точное совпадение. Но часто нужен конвертер для подкласса. Поэтому если точного совпадения нет, Registry ищет родительский класс через cls.isAssignableFrom(clazz) — например, для java.sql.Date (подкласс java.util.Date) будет найден DateConverter. Найденный конвертер кэшируется для класса через internalRegisterConverter(clazz, conv) чтобы не повторять поиск.
