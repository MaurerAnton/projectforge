Lines: 37 · Author: Kai Reinhard · Type: Java abstract generic — база для всех конвертеров XmlStream

Что это

Абстрактный базовый класс для всех конвертеров значений в XmlStream. 37 строк. Реализует IConverter<T>. Предоставляет реализацию toString(Object) по умолчанию (через String.valueOf()) и оставляет fromString(String) абстрактным. Все 12+ конвертеров в пакете converter/ наследуют этот класс.

Почему не интерфейс с default-методами?

Код написан до Java 8 (или в стиле до-Java-8). В современном Kotlin/Java это был бы interface IConverter<T> с default-реализацией fun toString(obj: Any?) = obj?.toString(). Но абстрактный класс даёт возможность добавить общую логику позже (например, общий handling null) без изменения всех подклассов.
