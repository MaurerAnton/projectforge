#762: BigDecimalConverter.java

Lines: 48 · Type: Java — extends AbstractValueConverter<BigDecimal>

Конвертер BigDecimal ↔ String для XmlStream. fromString() использует new BigDecimal(str) — принимает любой валидный BigDecimal-формат (целые, десятичные, экспоненциальная нотация). toString() наследуется от AbstractValueConverter: String.valueOf(obj) который для BigDecimal вызывает BigDecimal.toString() — возвращает строку без форматирования (всегда с десятичной точкой, без группировки разрядов). Зарегистрирован в XmlRegistry как конвертер для BigDecimal.class.
