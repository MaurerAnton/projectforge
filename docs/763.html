Lines: 33 · Type: Java — extends AbstractValueConverter<Boolean>

Конвертер Boolean ↔ String. fromString() использует Boolean.valueOf(str) — возвращает true только для строки "true" (case-insensitive), всё остальное → false. Это стандартное поведение Java Boolean.parseBoolean. toString() наследуется: String.valueOf(obj) → "true" или "false". Зарегистрирован в XmlRegistry для Boolean.class и boolean.class.
