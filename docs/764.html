#764: ByteArrayConverter.java

Lines: 64 · Type: Java — extends AbstractValueConverter<byte[]>

Конвертер byte[] ↔ Base64-encoded String. 64 строки — самый большой из простых конвертеров. toString() переопределён: кодирует byte[] в Base64 через java.util.Base64.getEncoder().encodeToString() — стандартное Java 8+ API. fromString() декодирует Base64 обратно в byte[]. Используется для сериализации бинарных данных (например, содержимое файлов) в XML — Base64 гарантирует что бинарные данные не сломают XML-структуру. Зарегистрирован в XmlRegistry для byte[].class.
