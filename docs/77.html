File #77: DatatransferAuditJob.kt

Path: ./plugins/datatransfer/.../DatatransferAuditJob.kt · Source: GitHub

Scheduled job running every 5 minutes. Steps: (1) check plugin is active, (2) iterate all areas, (3) fetch queued (unnotified, non-download) audit entries per area, (4) send observer notification emails, (5) mark entries as notified, (6) purge audit entries older than 30 days. Runs in a background thread to avoid blocking the scheduler.
