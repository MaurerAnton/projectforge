XML stream value converter between String and java.util.Locale. Extends AbstractValueConverter<Locale> for use in the xmlstream serialization framework.

Architecture

This is one of several xmlstream converters in the framework responsible for bidirectional conversion between Java types and their XML stream representations. The LocaleConverter:

  • Deserialization (fromString): Parses a locale string (e.g. "de_DE", "en_US") into a java.util.Locale using the standard Locale string constructor. Returns null for blank input.
  • Serialization (toString): Inherited from AbstractValueConverter — simply calls obj.toString().

The xmlstream framework serves as a lightweight XML serialization layer (historically named xstream, renamed in commit cd27dd997). All xmlstream converters extend AbstractValueConverter<T> and provide fromString()/toString() implementations. The converters are auto-discovered by the framework's scanning mechanism.
