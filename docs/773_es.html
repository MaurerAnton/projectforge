Convertidor de valor de flujo XML entre String y java.util.Locale. Extiende AbstractValueConverter<Locale> para su uso en el marco de serialización xmlstream.

Arquitectura

Este es uno de varios convertidores xmlstream en el marco responsables de la conversión bidireccional entre tipos de Java y sus representaciones de flujo XML. El LocaleConverter:

  • Deserialización (fromString): Analiza una cadena de configuración regional (ej. "de_DE", "en_US") en un java.util.Locale usando el constructor estándar de cadena Locale. Devuelve null para entrada en blanco.
  • Serialización (toString): Heredado de AbstractValueConverter — simplemente llama a obj.toString().

El marco xmlstream sirve como una capa ligera de serialización XML (históricamente llamada xstream, renombrada en el commit cd27dd997). Todos los convertidores xmlstream extienden AbstractValueConverter<T> y proporcionan implementaciones de fromString()/toString(). Los convertidores son descubiertos automáticamente por el mecanismo de escaneo del marco.
