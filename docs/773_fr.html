Convertisseur de flux XML entre String et java.util.Locale. Étend AbstractValueConverter<Locale> pour une utilisation dans le cadre de sérialisation xmlstream.

Architecture

Ceci est l'un des nombreux convertisseurs xmlstream du framework responsables de la conversion bidirectionnelle entre les types Java et leurs représentations en flux XML. Le LocaleConverter :

  • Désérialisation (fromString) : Analyse une chaîne de paramètres régionaux (par ex. "de_DE", "en_US") en un java.util.Locale en utilisant le constructeur standard de chaîne Locale. Renvoie null pour une entrée vide.
  • Sérialisation (toString) : Héritée de AbstractValueConverter — appelle simplement obj.toString().

Le framework xmlstream sert de couche de sérialisation XML légère (historiquement nommée xstream, renommée dans le commit cd27dd997). Tous les convertisseurs xmlstream étendent AbstractValueConverter<T> et fournissent des implémentations de fromString()/toString(). Les convertisseurs sont automatiquement découverts par le mécanisme de balayage du framework.
