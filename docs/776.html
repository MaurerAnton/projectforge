#776: StringConverter.java

Converter: String ↔ String (identity). toString() возвращает obj как есть. fromString(): если строка равна "null" (константа XmlConstants.NULL_IDENTIFIER), возвращает null; иначе возвращает строку без изменений. Единственный конвертер с обработкой null-маркера.
