Convertidor de flujo XML entre String y org.projectforge.Version de ProjectForge. Analiza cadenas de versión (ej. "7.4.0") en objetos Version.

Arquitectura

Parte del marco de convertidores xmlstream. Este convertidor maneja la deserialización de cadenas de versión:

  • fromString(String) — Construye un objeto Version a partir de una cadena de versión mediante new Version(str). La clase Version analiza cadenas como "7.4.0" o "8.0.0-SNAPSHOT".
  • Serialización (toString): Heredada de AbstractValueConverter — delega en Version.toString().

La clase Version es un objeto de valor específico de ProjectForge para representar números de versión semánticos. Este convertidor permite que los campos de versión en los DO se serialicen/deserialicen de forma transparente a/desde XML sin necesidad de análisis manual en el código de la aplicación.
