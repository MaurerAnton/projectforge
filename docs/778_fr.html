Convertisseur de flux XML entre String et org.projectforge.Version de ProjectForge. Analyse les chaînes de version (ex. "7.4.0") en objets Version.

Architecture

Partie du cadre de convertisseurs xmlstream. Ce convertisseur gère la désérialisation des chaînes de version :

  • fromString(String) — Construit un objet Version à partir d'une chaîne de version via new Version(str). La classe Version analyse des chaînes comme "7.4.0" ou "8.0.0-SNAPSHOT".
  • Sérialisation (toString) : Héritée de AbstractValueConverter — délègue à Version.toString().

La classe Version est un objet valeur spécifique à ProjectForge pour représenter des numéros de version sémantiques. Ce convertisseur permet aux champs de version dans les DO d'être sérialisés/désérialisés de manière transparente vers/depuis XML sans analyse manuelle dans le code applicatif.
