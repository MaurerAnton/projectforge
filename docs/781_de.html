#781: MailFilter.java

projectforge-business/src/main/java/org/projectforge/mail/MailFilter.java Mail-Filter-Dienst, projectforge-business/src/main/java/org/projectforge/mail/MailFilter.java 47 Zeilen · 13 Code · 30 Kommentare · 4 leer
Konfigurationsfilter für das Abrufen von E-Mails vom Server. Steuert, ob nur aktuelle (ungelesene) Nachrichten vom Mailserver abgerufen werden. Standard: Alle Nachrichten werden abgerufen (onlyRecent = false).

Architektur

Dies ist eine einfache Konfigurations-Datenklasse im Paket org.projectforge.mail, Teil der internen Mail-Integration von ProjectForge. Sie stellt ein einzelnes boolesches Flag bereit:

  • onlyRecent — Wenn true, ruft der Mail-Client nur ungelesene (aktuelle) Nachrichten vom POP3/IMAP-Server ab. Bei false (Standard) werden alle Nachrichten abgerufen.

Das Mail-Paket enthält außerdem MailClient, SendMail und weitere Mail-Infrastrukturklassen. MailFilter ist ein Parameterobjekt, das an Methoden von MailClient übergeben wird, um das Server-Interaktionsverhalten zu steuern. Die Klasse folgt dem einfachen JavaBean-Muster mit Getter-/Setter-Methoden.
