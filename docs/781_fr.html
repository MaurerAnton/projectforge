#781: MailFilter.java

projectforge-business/src/main/java/org/projectforge/mail/MailFilter.java Service de filtrage des e-mails, projectforge-business/src/main/java/org/projectforge/mail/MailFilter.java 47 lignes · 13 code · 30 commentaires · 4 vides
Filtre de configuration pour l'interrogation du serveur de messagerie. Contrôle si seuls les messages récents (non lus) sont récupérés depuis le serveur de messagerie. Par défaut : tous les messages sont récupérés (onlyRecent = false).

Architecture

Il s'agit d'une classe de données de configuration simple dans le package org.projectforge.mail, faisant partie de l'intégration de messagerie interne de ProjectForge. Elle fournit un seul indicateur booléen :

  • onlyRecent — Lorsqu'il est à true, le client de messagerie récupère uniquement les messages non lus (récents) du serveur POP3/IMAP. Lorsqu'il est à false (par défaut), tous les messages sont récupérés.

Le package de messagerie contient également MailClient, SendMail et d'autres classes d'infrastructure de messagerie. MailFilter est un objet paramètre passé aux méthodes de MailClient pour contrôler le comportement d'interaction avec le serveur. La classe suit un modèle JavaBean simple avec des méthodes getter/setter.
