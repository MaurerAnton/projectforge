#781: MailFilter.java

projectforge-business/src/main/java/org/projectforge/mail/MailFilter.java Сервис фильтрации почты, projectforge-business/src/main/java/org/projectforge/mail/MailFilter.java 47 строк · 13 кода · 30 комментариев · 4 пустых
Фильтр конфигурации для опроса почтового сервера. Управляет тем, извлекаются ли с почтового сервера только новые (непросмотренные) сообщения. По умолчанию извлекаются все сообщения (onlyRecent = false).

Архитектура

Это простой класс данных конфигурации в пакете org.projectforge.mail, часть внутренней почтовой интеграции ProjectForge. Он предоставляет один логический флаг:

  • onlyRecent — Если true, почтовый клиент извлекает только непросмотренные (новые) сообщения с POP3/IMAP-сервера. Если false (по умолчанию), извлекаются все сообщения.

Пакет mail также содержит классы MailClient, SendMail и другие классы почтовой инфраструктуры. MailFilter — это объект параметров, передаваемый методам MailClient для управления поведением взаимодействия с сервером. Класс следует простому шаблону JavaBean с методами getter/setter.
