#783: Registry.java

Обобщённый реестр — base class для всех реестров в ProjectForge. Хранит упорядоченный список RegistryEntry. Поддерживает поиск по ID, получение по индексу, проверку наличия. Используется для регистрации DAO в скриптовом движке, плагинов, UserRight'ов и конфигурационных параметров.
