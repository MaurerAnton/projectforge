Interface Java exposant les champs du compte comptable (Sachkonto) pour le moteur de reporting. Implémentée par KontoDO.

Architecture

L'interface Konto fait partie de la couche d'abstraction de reporting dans org.projectforge.reporting. Elle reflète KontoDO (l'entité JPA) mais masque les détails de persistance, permettant au moteur de reporting de travailler avec un contrat propre. Les modèles de reporting consomment ces interfaces plutôt que les entités directement.

Quatre méthodes d'accès sont définies :

  • getId() — Clé primaire unique synthétique de la base de données.
  • getNummer() — Le numéro de compte DATEV (Integer), importé depuis les données comptables externes.
  • getBezeichnung() — Libellé/désignation du compte provenant de DATEV ; la description comptable allemande d'origine.
  • getDescription() — Champ de description en texte libre modifiable dans ProjectForge, enrichissant les données DATEV pour un usage interne.
