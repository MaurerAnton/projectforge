projectforge-business/src/main/java/org/projectforge/reporting/Konto.java Интерфейс отчетности, projectforge-business/src/main/java/org/projectforge/reporting/Konto.java 50 строк · 8 кода · 36 комментариев · 6 пустых
Интерфейс Java, предоставляющий поля G/L счета (Sachkonto) для механизма отчетности. Реализуется KontoDO.

Архитектура

Интерфейс Konto является частью уровня абстракции отчетности в org.projectforge.reporting. Он отражает KontoDO (сущность JPA), но скрывает детали сохранения, позволяя механизму отчетности работать с чистым контрактом. Шаблоны отчетности используют эти интерфейсы напрямую, а не сущности.

Определены четыре метода доступа:

  • getId() — Синтетический, уникальный первичный ключ базы данных.
  • getNummer() — Номер счета DATEV (Integer), импортированный из внешних бухгалтерских данных.
  • getBezeichnung() — Наименование/обозначение счета из DATEV; оригинальное немецкое бухгалтерское описание.
  • getDescription() — Текстовое поле описания, редактируемое в ProjectForge, дополняющее данные DATEV для внутреннего использования.
