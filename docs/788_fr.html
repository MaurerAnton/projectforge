Interface Java pour le centre de coûts 2 (Kostenträger 2) dans le moteur de reporting. Implémentée par Kost2DO.

Architecture

Kost2 est le centre de coûts facturable qui relie les projets aux catégories de coûts. Il suit la même structure à 8 chiffres (N.BBB.TT.EE) que Kost1 mais diverge au niveau du suffixe : les chiffres 7–8 ne sont pas un simple entier mais un objet Kost2Art définissant le type de catégorie de coûts (par exemple, si les réservations sont facturables au client).

Méthodes :

  • getId() — Clé de base de données synthétique.
  • getKostentraegerStatus() — Statut actif/inactif.
  • getNummernkreis() — Chiffre 1.
  • getBereich() — Chiffres 2–4 (correspond au numéro client lorsqu'il est lié à un projet).
  • getTeilbereich() — Chiffres 5–6 (correspond au numéro de projet).
  • getKost2Art() — Chiffres 7–8 sous forme de référence Kost2Art ; le lien clé vers le système de types de coûts.
  • getProjekt() — Affectation facultative à un projet (peut être nul).
  • getDescription(), getComment() — Champs de texte libre.
  • getFormattedString() — Rendu sous la forme 1.234.56.78.
