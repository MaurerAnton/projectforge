Java-Schnittstelle für Kostentyp-2-Kategorien (Kost2Art). Implementiert durch Kost2ArtDO. Stellt die letzten beiden Ziffern einer Kost2-Kostenstelle dar.

Architektur

Kost2Art (Kostentyp-2-Kategorie) definiert, welche Art von Kosten eine Kost2 repräsentiert – z. B. Beratung, Hardware, Reisen. Die zweistellige ID (00–99) bildet die Ziffern 7–8 der 8-stelligen Kost2-Kennung.

Wichtige Methoden:

  • getId() — Zweistellige numerische ID (Long).
  • getName() — Anzeigename, der in Auswahlfeldern angezeigt wird.
  • getDescription() — Freitext-Beschreibung.
  • isFakturiert() — Gibt an, ob Buchungen unter diesem Kostentyp dem Endkunden in Rechnung gestellt werden (beeinflusst Finanzberichterstattung und Fakturierungslogik).
  • getFormattedId() — Nullaufgefüllte zweistellige Zeichenkette: 00, 01, …, 99.
  • isDeleted() — Kennzeichen für weiches Löschen.
  • isSelected() / isExistsAlready() — UI-Statusflags, die von ProjektListAction beim Zuweisen von Kost2Art-Einträgen zu Projekten verwendet werden.
  • isProjektStandard() — Gibt an, ob diese Kategorie als Projektstandard markiert ist und in Projektübersichten und Detailansichten visuell hervorgehoben wird.
