Interface Java pour les catégories de type de coût 2 (Kost2Art). Implémentée par Kost2ArtDO. Représente les deux derniers chiffres d'un centre de coût Kost2.

Architecture

Kost2Art (catégorie de type de coût 2) définit le type de coût qu'un Kost2 représente — par exemple, conseil, matériel, déplacement. L'identifiant à deux chiffres (00–99) constitue les chiffres 7–8 de l'identifiant Kost2 à 8 chiffres.

Méthodes clés :

  • getId() — Identifiant numérique à deux chiffres (Long).
  • getName() — Nom affiché dans les listes de sélection.
  • getDescription() — Description en texte libre.
  • isFakturiert() — Indique si les réservations sous ce type de coût sont facturées au client final (impacte le reporting financier et la logique de facturation).
  • getFormattedId() — Chaîne à deux chiffres avec zéro non significatif : 00, 01, …, 99.
  • isDeleted() — Indicateur de suppression logicielle.
  • isSelected() / isExistsAlready() — Indicateurs d'état de l'interface utilisateur utilisés par ProjektListAction lors de l'affectation des entrées Kost2Art aux projets.
  • isProjektStandard() — Indique si cette catégorie est marquée comme projet par défaut, recevant un accent visuel dans les aperçus de projet et les vues détaillées.
