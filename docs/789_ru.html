Интерфейс Java для категорий типа затрат 2 (Kost2Art). Реализован Kost2ArtDO. Представляет последние две цифры центра затрат Kost2.

Архитектура

Kost2Art (категория типа затрат 2) определяет, какой вид затрат представляет Kost2 — например, консалтинг, оборудование, командировки. Двузначный идентификатор (00–99) образует цифры 7–8 восьмизначного идентификатора Kost2.

Ключевые методы:

  • getId() — Двузначный числовой идентификатор (Long).
  • getName() — Отображаемое имя, показываемое в выпадающих списках.
  • getDescription() — Описание в свободной форме.
  • isFakturiert() — Выставляются ли счета конечному клиенту по операциям в этой категории затрат (влияет на финансовую отчетность и логику выставления счетов).
  • getFormattedId() — Двузначная строка с ведущими нулями: 00, 01, …, 99.
  • isDeleted() — Флаг мягкого удаления.
  • isSelected() / isExistsAlready() — Флаги состояния пользовательского интерфейса, используемые ProjektListAction при назначении записей Kost2Art проектам.
  • isProjektStandard() — Отмечена ли эта категория как стандартная для проекта, получая визуальное выделение в обзорах проектов и детальных представлениях.
