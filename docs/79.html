File #79: DatatransferJCRCleanUpJob.kt

Path: ./plugins/datatransfer/.../DatatransferJCRCleanUpJob.kt · Source: GitHub

Hourly scheduled job that deletes expired attachments from JCR storage. Logic: (1) check plugin active, (2) iterate areas, (3) for each attachment, compare lastUpdate + expiryDays against current time — delete if expired, (4) scan JCR node tree for orphaned nodes (areas deleted but files remain), (5) call repoService.cleanup(). Events fire through AttachmentsEventListener so DataTransferAuditDao (#75) logs deletions. Returns deleted count for test assertions.
