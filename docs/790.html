#790: Kunde.java

Reporting interface, projectforge-business/src/main/java/org/projectforge/reporting/Kunde.java
Java interface for customer (Kunde) reporting. Implemented by KundeDO. Supplies customer details to the reporting engine without exposing persistence internals.

Architecture

The Kunde interface is part of ProjectForge's financial reporting abstraction. It sits between the JPA entity (KundeDO) and reporting templates, providing a stable contract for customer data.

Accessor methods:

  • getId() — Customer number (Kundennummer), a 3-digit value (000–999) that also serves as digits 2–4 of the linked Kost2 cost center. Note: while the method returns Long, the actual range is constrained to 3 digits.
  • getName() — Customer display name.
  • getDivision() — Department/division within the customer organization. Each division may have its own customer number, allowing granular billing.
  • getStatus() — Active/inactive/etc. via KundeStatus enum.
  • getDescription() — Free-text notes on the customer.

The customer number (getId()) forms the bereich component of Kost2 identifiers, linking financial bookings to specific customers.
