#792: ReportBwa.java

Java модель — BWA (Betriebswirtschaftliche Auswertung) — отчёт для управленческого учёта. Содержит список строк BWA с доходами/расходами, сгруппированными по стандартным позициям (выручка, материальные затраты, затраты на персонал и т.д.). Используется контроллерами для ежемесячной отчётности.
