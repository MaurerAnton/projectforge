Définit le contrat pour une ligne dans la BWA (Betriebswirtschaftliche Auswertung) — le rapport P&L standard utilisé dans la comptabilité allemande (norme DATEV). Chaque ligne possède un numéro de ligne DATEV, un libellé, un niveau d'indentation pour l'affichage hiérarchique, une priorité pour l'ordonnancement et une valeur monétaire. Implémentée par BuchungssatzImpl et utilisée par ReportBwa pour construire le rapport P&L structuré.

Contexte DATEV

La BWA est un format de rapport financier standardisé défini par DATEV, le principal éditeur de logiciels comptables en Allemagne. Les numéros de ligne suivent le schéma de numérotation DATEV (SKR03/SKR04). La structure hiérarchique (indentation) reflète la façon dont le rapport est imprimé : catégories de premier niveau (revenus, coûts) avec des sous-éléments en retrait en dessous. Cette interface est la représentation Java d'une ligne unique dans cette structure standardisée.
