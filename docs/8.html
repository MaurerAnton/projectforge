What it does

This 15-line file is a documentation redirect. It exists solely to tell anyone who finds this file in the repository: "the real documentation lives at https://projectforge.org/docs/development/".

The actual developer documentation is in site/_docs — a directory processed by the ProjectForge website build pipeline (not served from the repo).

📖 Real documentation: projectforge.org/docs/development/
Local source: site/_docs

Why documentation was moved out of the repo

Large documentation files (>100KB) in the repository:

  • Slow down git clone — every developer downloads the full doc history whether they need it or not
  • Create merge conflicts — if documentation is auto-generated from templates, PRs constantly conflict on doc files
  • Aren't versioned meaningfully — documentation tends to describe the latest state, not a specific commit

Moving to a dedicated website (projectforge.org) with source in site/_docs solves all three: the site is built separately from the application, the docs live in a CMS-friendly structure, and the repo stays lean.

This pattern — redirect file in repo, full docs on website — is used by many projects: VS Code (README.md → code.visualstudio.com/docs), Kubernetes (CHANGELOG → kubernetes.io/docs), etc.
