File #80: DatatransferJCRNotificationBeforeDeletionJob.kt

Path: ./plugins/datatransfer/.../DatatransferJCRNotificationBeforeDeletionJob.kt · Source: GitHub

Nightly job (cron: 0 30 4 * * * = 4:30 AM) that warns observers about impending file deletions. Skips weekends/holidays. Notification lead time by expiry: ≤10 days → no notification, ≤30 → 7 days before, ≤90 → 14 days, >90 → 30 days. Groups notifications per observer (one email containing all their expiring files). Uses UserLocale for language-aware email subjects.
