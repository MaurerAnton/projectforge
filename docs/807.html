#807: WicketSupport.java

Мост между Spring DI и Wicket. Предоставляет статические методы WicketSupport.get(Class) для получения Spring-бинов из Wicket-компонентов (которые не управляются Spring). Использует ApplicationContextProvider (#667) для доступа к Spring-контексту. Ключевой класс для гибридной Spring+Wicket архитектуры.
