#808: UserAgentBrowser.java

projectforge-business/src/main/java/org/projectforge/web/session/UserAgentBrowser.java Enum, projectforge-business/src/main/java/org/projectforge/web/session/UserAgentBrowser.java 55 líneas · 27 código · 23 comentarios · 5 en blanco
Enumeración de navegadores web reconocidos extraídos del encabezado HTTP User-Agent. Almacenada en MySession para la diferenciación de navegadores a nivel de sesión.

Arquitectura

El enum define 12 valores de navegador: IE, MOZILLA, SAFARI, KONQUEROR, OPERA, FIREFOX, CHROME, OMNIWEB, ICAB, CAMINO, NETSCAPE y UNKNOWN.

Dos métodos de utilidad:

  • isIn(UserAgentBrowser...) — Prueba la pertenencia a un conjunto de argumentos variables, utilizado para condicionales de grupo de navegadores.
  • getBrowserFromUserAgentString(String) — Fábrica estática que analiza una cadena User-Agent. Actualmente una implementación simplificada: verifica "Version" → Safari y "Chrome" → Chrome. Si no coincide, retorna UNKNOWN. Un comentario TODO indica que esto debería ampliarse con más reglas de detección de navegadores.

Funciona junto con UserAgentDevice y UserAgentDetectionBrowser en el subsistema de detección de sesión. La clase auxiliar UserAgentDetectionBrowser contiene los patrones de expresión regular (identity, versionSearch) que se asignan a cada valor del enum, permitiendo una coincidencia más sofisticada en el pipeline de detección.
