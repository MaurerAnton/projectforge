File #81: DataTransferNotificationMailService.kt

Path: ./plugins/datatransfer/.../DataTransferNotificationMailService.kt · Source: GitHub

Email notification service with two mail types: observer alerts (on upload/modify/delete events, filters out own actions, checks recipient has access) and pre-deletion warnings (files expiring soon). Uses Groovy templates (mail/dataTransferMail.html, mail/dataTransferFilesBeingDeletedMail.html) for HTML rendering. Determines recipient locale for i18n messages. registerRecipients() intelligently adds: (a) observers for non-download events, (b) original uploader if another user modified/deleted their file.
