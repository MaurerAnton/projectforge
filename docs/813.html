#813: Constants.kt

Lines: 158 · Type: Kotlin object — центральные константы всего проекта

Что это

Центральный репозиторий констант для всего ProjectForge. 158 строк. Kotlin object (синглтон). Используется везде: JPA-entity'ами для @Column(length = Constants.LENGTH_TITLE), валидаторами, форматтерами. Javadoc: "Defines different constants (typical length of string columns) usable by plugins and core package."

Категории констант

  • Длины строк для БД: LENGTH_TEXT=4000, LENGTH_COMMENT=4000, LENGTH_SUBJECT=1000, LENGTH_TITLE=1000, COMMENT_LENGTH=4000 (дубликат). Используются в @Column(length=...) на полях всех entity-классов. Стандартизация длин гарантирует консистентность схемы БД
  • Большие числа: TEN_BILLION и TEN_BILLION_NEGATIVE — предельные значения для денежных полей (BigDecimal с precision=12, scale=2). HUNDRED_BD — для процентных расчётов
  • Размеры данных: KB=1024, MB=1024*KB, GB=1024*MB, TB=1024L*GB (Long). Используются для форматирования размеров файлов и валидации лимитов загрузки

Почему object а не class?

Kotlin object — это потокобезопасный синглтон, создаваемый при первом обращении. Константы (const val) компилируются в статические поля JVM и встраиваются на месте вызова (inline). @JvmField на BigDecimal-полях делает их доступными из Java-кода как Constants.TEN_BILLION (без геттеров).
