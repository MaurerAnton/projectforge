Kotlin singleton object holding a system-wide alert message string. Displayed to all logged-in users on every page. Set and cleared via the admin page; lost on application restart.

Architecture

SystemAlertMessage is a Kotlin object (singleton) in the root org.projectforge package, making it accessible globally across all modules. It contains a single mutable property:

  • alertMessage: String? — When non-null, this message is rendered as a banner alert on every page for every authenticated user. When null, no alert is shown.

The alert is volatile (in-memory only) — it is lost on application restart. This is intentional: system alerts are intended for temporary operational notices (e.g. "Maintenance window from 10:00 to 10:30"), not for persistent configuration.

Usage Context

This object was extracted from WicketApplication (commit 7def05f87) to make the alert mechanism available to the REST/JSON API layer, which runs outside the Wicket application context. Before this refactoring, alerts were coupled to the Wicket session and inaccessible from REST endpoints. The admin page provides UI controls to set the message (stored in this singleton) and clear it (sets alertMessage to null).
