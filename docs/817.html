#817: SystemStatus.kt

@Component — Spring singleton, projectforge-business/src/main/kotlin/org/projectforge/SystemStatus.kt
Spring-managed component holding application-wide runtime state: version info, build metadata, configuration flags, and lifecycle status.

Architecture

SystemStatus is a Kotlin @Component that aggregates version/build constants from ProjectForgeVersion with runtime configuration from ConfigurationService and DatabaseService. It is the single source of truth for whether the system is operational, undergoing setup, or pending an update.

Version & Build Metadata (immutable, from ProjectForgeVersion)

  • appname — Application identifier (APP_ID).
  • version — Full version string.
  • buildTimestamp, buildDate — When the artifact was built.
  • releaseYear — Current release year.
  • scmIdFull, scmId — Git commit identifiers (full hash and abbreviated).
  • copyRightYears — Copyright year range.

Runtime State (initialized in @PostConstruct)

  • messageOfTheDay — Admin message from ConfigurationParam.MESSAGE_OF_THE_DAY.
  • logoFile — Custom logo filename from ConfigurationService.syntheticLogoName.
  • developmentMode — Injected via @Value("${projectforge.development.mode}").
  • setupRequiredFirst — True if no database tables with entries exist (first-run detection).
  • updateRequiredFirst — True if a database schema update is pending.
  • upAndRunning — Manually set to true after startup completes; guards request processing.
  • startTimeMillis — System.currentTimeMillis() at component instantiation.

Companion Object

Provides static access to development mode via isDevelopmentMode() and a test hook internalSet4JunitTests(Boolean) for unit tests that simulate production vs. development environments.
