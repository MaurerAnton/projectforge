Проектные решения

  • Quartz Job с внедрением Spring через AutowiringSpringBeanJobFactory. Должен быть идемпотентным — возможны перекрывающиеся выполнения при нагрузке.
  • Контроль доступа отделён от бизнес-логики. Проверки авторизации выполняются до операций DAO, что обеспечивает централизованную безопасность.

Ошибки и подводные камни

  • Задачи по умолчанию не являются Spring-бинами. Внедрение через @Autowired требует AutowiringSpringBeanJobFactory в контексте планировщика quartz.
