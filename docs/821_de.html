Zweck

JPA-Entität, die eine Adresse (Kontakt) im System repräsentiert. Mappt auf die Tabelle T_ADDRESS. Erweitert DefaultBaseDO und implementiert DisplayNameCapable. Mit @Indexed für Hibernate-Search-Volltextabfragen annotiert.

Berechnete Eigenschaften (Transient)

  • fullName — firstName + fullLastName + organization
  • fullLastName — name mit optionalem "ehemals birthName"-Suffix
  • fullNameWithTitleAndForm — lokalisierte Anrede + Titel + firstName + fullLastName
  • mailingAddressText/Text2/ZipCode/City/Country/State — Fallback-Kette: postalisch → Standard → privat
  • transientImage — transientes Attribut für vCard-Export (gesetzt über setTransientImage())
