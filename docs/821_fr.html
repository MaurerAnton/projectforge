Objectif

Entité JPA représentant une adresse (contact) dans le système. Mappe la table T_ADDRESS. Étend DefaultBaseDO et implémente DisplayNameCapable. Annotée avec @Indexed pour les requêtes full-text Hibernate Search.

Propriétés calculées (Transitoires)

  • fullName — prénom + nomComplet + organisation
  • fullLastName — nom avec suffixe optionnel "anciennement nomDeNaissance"
  • fullNameWithTitleAndForm — forme localisée + titre + prénom + nomComplet
  • mailingAddressText/Text2/CodePostal/Ville/Pays/État — chaîne de repli : postal → défaut → privé

Relations

Contraintes
