Назначение

JPA-сущность, представляющая адрес (контакт) в системе. Отображается на таблицу T_ADDRESS. Расширяет DefaultBaseDO и реализует DisplayNameCapable. Аннотирована @Indexed для полнотекстовых запросов Hibernate Search.

Вычисляемые свойства (транзиентные)

  • fullName — firstName + fullLastName + organization
  • fullLastName — name с необязательным суффиксом "ранее birthName"
  • fullNameWithTitleAndForm — локализованная форма + title + firstName + fullLastName
  • mailingAddressText/Text2/ZipCode/City/Country/State — цепочка резервирования: postal → default → private
  • transientImage — транзиентный атрибут для экспорта vCard (устанавливается через setTransientImage())

Связи

  • @ManyToMany addressbookList — соединительная таблица t_addressbook_address, сериализуется только как ID

Ограничения

Уникальное ограничение на столбец uid. Индекс по uid. Индексы по обоим внешним ключам таблицы t_addressbook_address.
