#822: AddressDao.kt

@Service — DAO layer, projectforge-business/src/main/kotlin/org/projectforge/business/address/AddressDao.kt
Primary data access service for AddressDO entities. Extends BaseDao<AddressDO> and manages the full lifecycle: querying, filtering, access control, vCard export, phone lookup, duplicate detection, birthdays, and cascade deletion.

Architecture

Dependencies

  • AddressbookDao / AddressbookCache — Address book management and caching.
  • AddressImageDao — Lazy-initialized via ApplicationContext to avoid circular dependency (AddressImageDao depends on AddressDao).
  • PersonalAddressDao — Personal address book entries (favorites, vCard).
  • SipgateDeleteContactService — SIP telephony contact cleanup on deletion.
  • TeamEventDao — Removes address-based attendees from events on deletion.
  • BirthdayCache — Cached birthday queries built in @PostConstruct.
  • AddressbookRight — Per-addressbook access control rules.

Querying & Filtering

The select(BaseSearchFilter) override is the main entry point. It instantiates or reuses an AddressFilter and applies filter criteria:

  • Newest — Quick path via getNewest() returning records ordered by creation time descending.
  • Favorites — Quick path returning only the current user's personally bookmarked addresses.
  • Search string — Wildcard-padded numeric searches.
  • Contact status — Multi-select filter: ACTIVE, NON_ACTIVE, UNINTERESTING, DEPARTED, PERSONA_INGRATA.
  • Address status — Multi-select filter: UPTODATE, OUTDATED, LEAVED.
  • Address book restriction — Joins addressbookList and limits to books the user has SELECT access to (including the global address book).
  • Doublets — Post-query filtering by normalized full name.

Access Control

hasAccess() iterates over address books linked to the address. For SELECT operations, any book with SELECT access grants the right. For other operations (INSERT, UPDATE, DELETE), full access to at least one linked book is required. Throws AccessException on denial.

beforeInsertOrModify() ensures new addresses default to the global address book and prevents users from removing address books they lack access to.

Deletion Cascade

onDelete() runs in a single transaction and performs: 1. Deletes all PersonalAddressDO references via personalAddressDao.internalDeleteAll(). 2. Removes the address as attendee from all TeamEventDO entries. 3. Deletes the SIP telephony contact via sipgateDeleteContactService. 4. Bulk-deletes all images via named query DELETE_ALL_IMAGES_BY_ADDRESS_ID. 5. Notifies registered AddressDeletionListener instances.

vCard Export

exportFavoriteVCards() writes vCard 3.0 strings for all favorited entries. exportVCard() handles single-address export, automatically fetching and embedding the address image via AddressImageDao. VCardUtils.buildVCardString() performs the actual formatting.

Additional Capabilities

  • getBirthdays(fromDate, toDate, all) — Delegates to BirthdayCache for optimized date-range queries.
  • findByUid(uid) — Lookup by vCard UID for import deduplication.
  • internalPhoneLookUp(number) — Searches for a phone number match, returning the newest entry's full name and organization.
  • findByNameAndFirstName(name, firstName) — Exact (case-insensitive) duplicate search for new address validation.
  • getUsedCommunicationLanguages() — JPQL distinct query returning all Locales in use.
