File #83: DataTransferSanityCheckJob.kt

Path: ./plugins/datatransfer/.../DataTransferSanityCheckJob.kt · Source: GitHub

Integrity check job for JCR attachments. Validates: (1) attachment counter matches actual JCR file count, (2) all IDs in attachmentsIds exist in JCR, (3) no orphaned files in JCR without DB record, (4) empty files (size=0). Reports via JobExecutionContext — errors for missing files, warnings for orphans and misaligned counters. Registered with CronSanityCheckJob at startup.
