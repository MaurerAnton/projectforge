#832: AddressNewResultFilter.kt

CustomResultFilter, projectforge-business/src/main/kotlin/org/projectforge/business/address/AddressNewResultFilter.kt
Post-query CustomResultFilter that restricts address results to recently created entries, queried from the entity history table by creation timestamp.

Architecture

Implements CustomResultFilter<AddressDO>, ProjectForge's interface for applying in-memory filtering after the database query returns. Unlike database-side filters (QueryFilter), custom result filters run in Java/Kotlin space and can incorporate complex logic that would be cumbersome in JPQL.

Filter Logic

The filter queries the HistoryEntryDO table for address entities (entityName = AddressDO) sorted by created timestamp descending. It collects the first N entity IDs — the most recently created addresses — into a Set<Long>. The match() method then accepts an address only if its ID is in the set.

Pattern Context

This class follows the same structural pattern as sibling filters:

  • AddressMyEntriesResultFilter — Filters by modified history entries for the current user.
  • FavoritesResultFilter — Filters to the user's personal address list.
  • DoubletsResultFilter — Detects potential duplicate address entries by normalized name comparison.

Where AddressMyEntriesResultFilter queries the history table for modification records by a specific user, AddressNewResultFilter queries for creation records across all users, providing a "what's new" view of the address database.

Usage

Registered in AddressDao.select(QueryFilter, checkAccess) alongside other custom filters. Activated when a dedicated UI toggle or query parameter requests the "newest addresses" view. The filter operates on the already-returned result list, refining it to only the most recently created entries.
