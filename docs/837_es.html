#837: FavoritesResultFilter.kt

projectforge-business/src/main/kotlin/org/projectforge/business/address/FavoritesResultFilter.kt Filtro de resultados Kotlin — filtro de favoritos específico del usuario para la lista de direcciones. Implementa CustomResultFilter<AddressDO> para mostrar solo los contactos marcados como favoritos por el usuario actual. Ubicación: projectforge-business/src/main/kotlin/org/projectforge/business/address/FavoritesResultFilter.kt 34 líneas · 8 código · 22 comentarios · 4 en blanco
Propósito: Cada usuario puede marcar contactos como "favoritos" — estos se almacenan en la tabla PersonalAddressDO (una extensión por usuario de AddressDO). El filtro de favoritos permite que la interfaz de la lista de direcciones alterne entre "todos los contactos" y "solo favoritos" con un solo clic, produciendo un conjunto de resultados que contiene solo los contactos destacados del usuario.

Arquitectura

El filtro es sin estado después de la construcción — captura una instantánea de la lista de ID de direcciones favoritas del usuario en el momento de la construcción y la utiliza para todas las llamadas a match(). Esta instantánea es una List<Long?> obtenida de PersonalAddressDao.favoriteAddressIdList, que es una lista prevalidada de ID de direcciones que el usuario actual ha marcado como favoritas.

La implementación de match() es trivial: favoriteAddressIds.contains(element.id) — O(n) por elemento donde n es el número de favoritos. Para un usuario típico con 10–100 favoritos y un conjunto de resultados de 1000+ direcciones, esto es aceptablemente rápido ya que List.contains() es lineal pero el tamaño de la lista es pequeño.

Se eligió el enfoque de filtro de resultados porque la página de lista de direcciones utiliza una tubería de filtros: filtro de búsqueda → filtro de favoritos → filtro de duplicados → filtro de imágenes. Componer filtros posteriores es más simple que construir SQL dinámico con múltiples cláusulas WHERE opcionales. Para el caso específico de favoritos, la diferencia de rendimiento es insignificante ya que la lista de favoritos es pequeña.
