projectforge-business/src/main/kotlin/org/projectforge/business/address/FavoritesResultFilter.kt Фильтр результатов Kotlin — пользовательский фильтр избранного для списка адресов. Реализует CustomResultFilter<AddressDO> для отображения только контактов, отмеченных как избранные текущим пользователем. Расположение: projectforge-business/src/main/kotlin/org/projectforge/business/address/FavoritesResultFilter.kt 34 строки · 8 кода · 22 комментария · 4 пустых
Назначение: Каждый пользователь может помечать контакты как «избранные» — они хранятся в таблице PersonalAddressDO (расширение AddressDO для каждого пользователя). Фильтр избранного позволяет интерфейсу списка адресов переключаться между «всеми контактами» и «только избранными» одним щелчком мыши, возвращая набор результатов, содержащий только отмеченные пользователем контакты.

Архитектура

Фильтр является не сохраняющим состояние после создания — он захватывает снимок списка идентификаторов избранных адресов пользователя во время создания и использует его для всех вызовов match(). Этот снимок представляет собой List<Long?>, полученный из PersonalAddressDao.favoriteAddressIdList, который представляет собой предварительно проверенный список идентификаторов адресов, добавленных текущим пользователем в избранное.

Реализация match() тривиальна: favoriteAddressIds.contains(element.id) — O(n) на элемент, где n — количество избранных элементов. Для типичного пользователя с 10–100 избранными и набором результатов из 1000+ адресов это приемлемо быстро, поскольку List.contains() является линейным, но размер списка невелик.

Подход с фильтром результатов был выбран, потому что страница списка адресов использует конвейер фильтров: фильтр поиска → фильтр избранного → фильтр дублей → фильтр изображений. Компоновка пост-фильтров проще, чем построение динамического SQL с несколькими необязательными условиями WHERE. В конкретном случае избранного разница в производительности незначительна, поскольку список избранного невелик.

Дубли (#829)DoubletsResultFilterНакопительное (множества растут с каждым элементом)O(n²) ретроактивная очистка — самая сложная

Все три реализуют один и тот же интерфейс CustomResultFilter, но служат разным UX-целям: «Избранное» показывает личные выборки пользователя, «Дубли» помогают администраторам очищать дубликаты, а «Изображения» выделяют контакты с фотографиями. Они образуют конвейер фильтров, который можно независимо включать/выключать на панели инструментов списка адресов.
