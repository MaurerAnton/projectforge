Architecture

Purpose

Standalone CLI client (Kotlin main function) for debugging the CardDAV server. Connects via Apache HttpClient 5.

Usage

CardDavTestClient <username> <dav-token> [--fetch-all]

Key Features

  • Authentication via DAV token
  • --fetch-all flag retrieves all VCards to /tmp/carddav-vcards/
  • Includes Wireshark setup notes for macOS debugging
  • Uses Apache HttpClient 5 (CloseableHttpClient, ClassicRequestBuilder)
