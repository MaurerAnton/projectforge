Автономный CLI тестовый клиент (функция `main`) для отладки CardDAV сервера. Использует Apache HttpClient 5 для подключения, аутентификации и опционально загружает все VCard в `/tmp/carddav-vcards/`.

Архитектура

Назначение

Автономный CLI клиент (функция Kotlin main) для отладки CardDAV сервера. Подключается через Apache HttpClient 5.

Использование

CardDavTestClient <имя_пользователя> <dav-токен> [--fetch-all]

Ключевые возможности

  • Аутентификация через DAV токен
  • Флаг --fetch-all загружает все VCard в /tmp/carddav-vcards/
  • Включает заметки по настройке Wireshark для отладки на macOS
  • Использует Apache HttpClient 5 (CloseableHttpClient, ClassicRequestBuilder)
