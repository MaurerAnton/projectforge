Проектные решения

  • Quartz Job с внедрением Spring через AutowiringSpringBeanJobFactory. Должен быть идемпотентным — возможны перекрывающиеся выполнения при высокой нагрузке.

Ошибки и подводные камни

  • По умолчанию Job'ы не являются Spring-бинами. Для внедрения через @Autowired требуется AutowiringSpringBeanJobFactory в контексте планировщика quartz.
