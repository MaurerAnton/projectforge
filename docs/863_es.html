Propósito: Calcula colores de fondo y texto para eventos de calendario basados en un color base configurable
Ruta de origen: projectforge-business/src/main/kotlin/org/projectforge/business/calendar/CalendarStyle.kt 161 líneas · 103 código · 38 comentarios · 20 en blanco

CalendarStyle toma un color de fondo base (cadena hexadecimal), calcula un color de texto coincidente y deriva una variación de fondo semitransparente para la representación de eventos de calendario. El color del texto se calcula del lado del servidor utilizando manipulación del espacio de color HSB para garantizar un contraste adecuado. Los resultados se almacenan en caché en un ColorCache (que extiende AbstractCache con caducidad de 1 hora) para evitar recalcular las mismas conversiones repetidamente. Se admiten dos esquemas de color: el modo predeterminado (moderno) con colores derivados de HSB y un modo CLASSIC que conserva el comportamiento original v6 de negro sobre blanco o blanco sobre oscuro.

Detalles del algoritmo de color

Para el esquema moderno, el color del texto se calcula mediante:

  1. Convertir el hexadecimal de fondo a java.awt.Color.
  2. Extraer valores HSB (Tono, Saturación, Brillo) mediante Color.RGBtoHSB().
  3. Restar 0.6 del brillo, limitando el límite inferior a 0.3. Esto produce un tono notablemente más oscuro del mismo matiz.
  4. Convertir de nuevo a RGB mediante Color.HSBtoRGB() y formatear como "#rrggbb".
  5. El código comentado tenía un aumento adicional de saturación para colores casi grises que fue deshabilitado.

El esquema CLASSIC es más simple: los fondos oscuros obtienen texto blanco ("#fff"), los fondos claros obtienen texto gris oscuro ("#444"), con el umbral en brillo 180.

Justificación del diseño

El cálculo de color del lado del servidor es una decisión arquitectónica deliberada. Al calcular los colores de texto y fondo en el servidor (en lugar del frontend React), los mismos valores de color están disponibles tanto para la representación de eventos de FullCalendar como para los menús desplegables de selección de formularios, evitando inconsistencias. El algoritmo basado en HSB produce colores que están perceptualmente relacionados con el fondo (mismo tono, brillo ajustado) en lugar de simplemente invertir — esto crea un diseño visual más cohesivo. El ColorCache evita recalcular las mismas combinaciones de color repetidamente (el estilo de cada calendario se usa para muchos eventos), y la caducidad de 1 hora mediante AbstractCache permite que los cambios de tema se propaguen sin reiniciar. El modo CLASSIC se agregó retroactivamente (commit 5a2c98523) como una opción de usuario para aquellos que prefieren el enfoque de alto contraste más simple de versiones anteriores.
