#863: CalendarStyle.kt

projectforge-business/src/main/kotlin/org/projectforge/business/calendar/CalendarStyle.kt Тип: Класс Kotlin (утилита стилизации)
Назначение: Вычисляет цвета фона и текста для событий календаря на основе настраиваемого базового цвета
Путь к исходнику: projectforge-business/src/main/kotlin/org/projectforge/business/calendar/CalendarStyle.kt 161 строка · 103 кода · 38 комментариев · 20 пустых

CalendarStyle принимает базовый цвет фона (шестнадцатеричная строка), вычисляет соответствующий цвет текста и создаёт полупрозрачный вариант фона для отображения событий календаря. Цвет текста рассчитывается на стороне сервера с использованием манипуляций в цветовом пространстве HSB для обеспечения достаточного контраста. Результаты кэшируются в ColorCache (расширяет AbstractCache с временем жизни 1 час), чтобы избежать повторных вычислений одних и тех же преобразований. Поддерживаются две цветовые схемы: режим по умолчанию (современный) с цветами на основе HSB и режим CLASSIC, который сохраняет исходное поведение v6: чёрный на белом или белый на тёмном.

Свойства

bgColor: String

Базовый цвет фона. Инициализируется из параметра конструктора, возвращаясь к "#777" (нейтральный серый). Сохраняется как каноническое шестнадцатеричное значение и не должен использоваться напрямую для отрисовки — используйте getBackgroundColor().

Публичные методы

getTextColor(colorScheme: CalendarEventColorScheme?): String

Возвращает вычисленный цвет текста для заданной цветовой схемы. Делегирует вызов colorCache.getTextColor(bgColor, colorScheme).

getBackgroundColor(calendarEventColorScheme: CalendarEventColorScheme?): String

Возвращает цвет фона, скорректированный для цветовой схемы:

  • Режим CLASSIC: Возвращает bgColor без изменений (непрозрачный).
  • Современный режим (по умолчанию): Добавляет альфа-прозрачность — "3" для короткого шестнадцатеричного кода ("#7773" → ~20% непрозрачности) или "33" для полного шестнадцатеричного кода ("#77777733" → ~20% непрозрачности). Это создаёт полупрозрачные события календаря, которые смешиваются с фоном.

Объект-компаньон — Движок вычисления цветов

Внутренний класс RGB(r: Int, g: Int, b: Int)

Простой класс данных, хранящий значения каналов RGB (0–255).

Внутренний класс ColorCache : AbstractCache()

Кэш с TTL 1 час, который хранит вычисленные цвета текста, ключом является шестнадцатеричная строка, что позволяет избежать избыточных преобразований HSB. Поддерживает отдельные карты для стандартной и классической цветовых схем. Потокобезопасен благодаря блокам synchronized на карте каждой схемы.

Детали алгоритма цветов

Для современной схемы цвет текста вычисляется следующим образом:

  1. Преобразование шестнадцатеричного кода фона в java.awt.Color.
  2. Извлечение значений HSB (Тон, Насыщенность, Яркость) с помощью Color.RGBtoHSB().
  3. Вычитание 0.6 из яркости с ограничением нижней границы до 0.3. Это даёт заметно более тёмный оттенок того же тона.
  4. Обратное преобразование в RGB через Color.HSBtoRGB() и форматирование как "#rrggbb".
  5. Закомментированный код содержал дополнительное повышение насыщенности для почти серых цветов, которое было отключено.

Классическая схема проще: тёмные фоны получают белый текст ("#fff"), светлые фоны — тёмно-серый текст ("#444"), с порогом яркости 180.

Обоснование дизайна

Вычисление цветов на стороне сервера — это осознанное архитектурное решение. Рассчитывая цвета текста и фона на сервере (а не на фронтенде React), одни и те же значения цветов доступны как для отображения событий FullCalendar, так и для выпадающих списков выбора форм, что позволяет избежать несоответствий. Алгоритм на основе HSB создаёт цвета, которые воспринимаются как связанные с фоном (тот же тон, скорректированная яркость), а не просто инвертированные — это создаёт более целостный визуальный дизайн. ColorCache предотвращает повторное вычисление одних и тех же комбинаций цветов (стиль каждого календаря используется для многих событий), а время жизни в 1 час через AbstractCache позволяет изменениям темы распространяться без перезапуска. Режим CLASSIC был добавлен ретроспективно (коммит 5a2c98523) как опция для пользователей, предпочитающих более простой высококонтрастный подход из ранних версий.
