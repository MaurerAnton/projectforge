Objectif : Mappe les modes d'affichage du calendrier ProjectForge aux clés d'affichage FullCalendar

CalendarView est une énumération qui fait le pont entre les concepts d'affichage du calendrier de ProjectForge et les conventions de nommage des vues de la bibliothèque JavaScript FullCalendar. Chaque valeur d'énumération possède une propriété key qui est la chaîne utilisée pour demander une vue spécifique à FullCalendar. L'objet compagnon fournit une méthode fabrique from() qui résout à la fois les noms d'énumération et les clés FullCalendar, avec un repli sur MONTH.

Valeurs de l'énumération

Valeur d'énumérationClé FullCalendarDescription
MONTHdayGridMonthVue grille mensuelle standard.
WORK_MONTHdayGridWorkingMonthGrille mensuelle affichant uniquement les jours ouvrés (extension personnalisée).
WEEKtimeGridWeekSemaine complète avec grille horaire (7 jours, créneaux horaires).
WORK_WEEKtimeGridWorkingWeekSemaine ouvrée — généralement du lundi au vendredi — avec grille horaire.
DAYtimeGridDayJour unique avec grille horaire (créneaux horaires).
WEEK_LISTdayGridWeekSemaine affichée sous forme de grille journalière (sans créneaux horaires), utile comme liste compacte.
AGENDAlistWeekVue liste/agenda pour une semaine unique.
MONTH_AGENDAlistMonthVue liste/agenda couvrant un mois complet.

Objet compagnon

from(name: String?): CalendarView

Recherche un CalendarView soit par son nom d'énumération (par exemple, "WEEK") soit par sa clé FullCalendar (par exemple, "timeGridWeek"). Si l'entrée est nulle ou introuvable, retourne MONTH comme valeur par défaut sécurisée. Cela le rend résistant aux discordances entre les préférences d'affichage stockées et les définitions actuelles de l'énumération.

Justification de la conception

La recherche à double clé from() (acceptant à la fois les noms d'énumération et les clés FullCalendar) offre une flexibilité tant pour la sérialisation que pour la migration. Lorsque les préférences stockées utilisent la clé FullCalendar (comme cela pourrait être le cas après une mise à niveau de la bibliothèque), l'énumération se résout toujours correctement. Le repli par défaut sur MONTH évite les plantages dus à des valeurs non reconnues, garantissant que le calendrier affiche toujours quelque chose. La propriété key sur chaque valeur d'énumération est la source unique de vérité pour la manière dont les vues FullCalendar sont adressées, centralisant ce qui autrement seraient des constantes de chaîne dispersées dans le code frontend et backend.
