#865: CalendarView.kt

projectforge-business/src/main/kotlin/org/projectforge/business/calendar/CalendarView.kt Тип: Kotlin enum class
Назначение: Сопоставляет режимы просмотра календаря ProjectForge с ключами представлений FullCalendar
Путь к исходнику: projectforge-business/src/main/kotlin/org/projectforge/business/calendar/CalendarView.kt 54 строки · 19 кода · 25 комментариев · 10 пустых

CalendarView — это перечисление, которое связывает концепции представлений календаря ProjectForge с соглашениями об именах представлений JavaScript-библиотеки FullCalendar. Каждое значение перечисления содержит свойство key — строку, используемую для запроса конкретного представления из FullCalendar. Объект-компаньон предоставляет фабричный метод from(), который разрешает как имена перечислений, так и ключи FullCalendar, с запасным вариантом MONTH.

Значения перечисления

Значение перечисленияКлюч FullCalendarОписание
MONTHdayGridMonthСтандартное представление месяца в виде сетки.
WORK_MONTHdayGridWorkingMonthСетка месяца, показывающая только рабочие дни (пользовательское расширение).
WEEKtimeGridWeekПолная неделя с временной сеткой (7 дней, часовые слоты).
WORK_WEEKtimeGridWorkingWeekРабочая неделя — обычно с понедельника по пятницу — с временной сеткой.
DAYtimeGridDayОдин день с временной сеткой (часовые слоты).
WEEK_LISTdayGridWeekНеделя, отображаемая в виде дневной сетки (без временных слотов), удобна как компактный список.
AGENDAlistWeekПредставление в виде списка/повестки на одну неделю.
MONTH_AGENDAlistMonthПредставление в виде списка/повестки на целый месяц.

Объект-компаньон

from(name: String?): CalendarView

Ищет CalendarView либо по имени перечисления (например, "WEEK"), либо по ключу FullCalendar (например, "timeGridWeek"). Если входное значение равно null или не найдено, возвращает MONTH как безопасное значение по умолчанию. Это обеспечивает устойчивость к несоответствиям между сохранёнными настройками представления и текущими определениями перечисления.

Обоснование дизайна

Двухключевой поиск в методе from() (принимающий как имена перечислений, так и ключи FullCalendar) обеспечивает гибкость как при сериализации, так и при миграции. Когда сохранённые настройки используют ключ FullCalendar (как это может быть после обновления библиотеки), перечисление всё равно разрешается корректно. Запасной вариант по умолчанию MONTH предотвращает сбои из-за нераспознанных значений, гарантируя, что календарь всегда что-то отображает. Свойство key каждого значения перечисления является единственным источником истины для того, как адресуются представления FullCalendar, централизуя то, что в противном случае было бы строковыми константами, разбросанными по коду фронтенда и бэкенда.
