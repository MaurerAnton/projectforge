Extiende TeamCalendar con CalendarStyle (color, apariencia) y una bandera visible. Se utiliza para decorar objetos de calendario de equipo con metadatos de renderizado para la interfaz de usuario del calendario, sin modificar el modelo central del calendario de equipo.

Jerarquía de clases

StyledTeamCalendar hereda de TeamCalendar (ver #862) pasando los atributos id, title y access del padre a través del constructor. Este es un patrón similar a clase de datos de Kotlin: la clase es open pero efectivamente es un envoltorio de valor.

Objeto complementario

map()

fun map(calendars: List<TeamCalendar>, styleMap: CalendarStyleMap): List<StyledTeamCalendar>

Toma una lista de objetos TeamCalendar y un CalendarStyleMap indexado por ID de calendario. Produce una lista correspondiente de instancias de StyledTeamCalendar, cada una decorada con su estilo del mapa. Utiliza calendars.find { it.id == cal.id } para buscar el calendario fuente coincidente para cada entrada.

Fundamento del diseño

La separación en TeamCalendar (datos puros) y StyledTeamCalendar (decorado con metadatos de interfaz de usuario) sigue un patrón decorador limpio. La clase base TeamCalendar permanece sin conocimiento de los aspectos de representación. La búsqueda en CalendarStyleMap se aplica en lote mediante la función complementaria map, manteniendo la lógica de transformación centralizada.
