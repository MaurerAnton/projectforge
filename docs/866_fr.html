#866: StyledTeamCalendar.kt

projectforge-business/src/main/kotlin/org/projectforge/business/calendar/StyledTeamCalendar.kt Type : Classe de données · Objectif : Calendrier avec style · Source : projectforge-business/src/main/kotlin/org/projectforge/business/calendar/StyledTeamCalendar.kt 45 lignes · 14 code · 28 commentaires · 3 vides
Étend TeamCalendar avec CalendarStyle (couleur, apparence) et un indicateur visible. Utilisé pour décorer les objets de calendrier d'équipe avec des métadonnées de rendu pour l'interface utilisateur du calendrier, sans modifier le modèle de calendrier d'équipe principal.

Hiérarchie des classes

StyledTeamCalendar hérite de TeamCalendar (voir #862) en passant les id, title et access du parent via le constructeur. Il s'agit d'un modèle de type classe de données Kotlin — la classe est open mais constitue effectivement un wrapper de valeur.

Objet compagnon

map()

fun map(calendars: List<TeamCalendar>, styleMap: CalendarStyleMap): List<StyledTeamCalendar>

Prend une liste d'objets TeamCalendar et une CalendarStyleMap indexée par l'ID du calendrier. Produit une liste correspondante d'instances StyledTeamCalendar, chacune décorée avec son style issu de la carte. Utilise calendars.find { it.id == cal.id } pour rechercher le calendrier source correspondant pour chaque entrée.

Justification de la conception

La séparation en TeamCalendar (données pures) et StyledTeamCalendar (décoré avec des métadonnées d'interface utilisateur) suit un modèle de décorateur propre. La classe de base TeamCalendar reste ignorante des préoccupations de rendu. La recherche dans CalendarStyleMap est appliquée par lot via la fonction compagnon map, ce qui centralise la logique de transformation.
