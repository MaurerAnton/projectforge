#866: StyledTeamCalendar.kt

projectforge-business/src/main/kotlin/org/projectforge/business/calendar/StyledTeamCalendar.kt Тип: Класс данных · Назначение: Календарь со стилизацией · Исходник: projectforge-business/src/main/kotlin/org/projectforge/business/calendar/StyledTeamCalendar.kt 45 строк · 14 кода · 28 комментариев · 3 пустых
Расширяет TeamCalendar с помощью CalendarStyle (цвет, внешний вид) и флага visible. Используется для декорирования объектов командного календаря метаданными рендеринга для пользовательского интерфейса календаря, без изменения основной модели командного календаря.

Иерархия классов

StyledTeamCalendar наследуется от TeamCalendar (см. #862) путём передачи id, title и access родительского класса через конструктор. Это шаблон Kotlin, похожий на класс данных — класс является открытым, но по сути представляет собой обёртку значений.

СвойствоТипОписание
idLong?Унаследовано от TeamCalendar
titleString?Унаследовано от TeamCalendar
accessACCESS?Унаследовано от TeamCalendar
styleCalendarStyle?Визуальный стиль (цвет и т.д.) для рендеринга календаря
visibleBooleanВиден ли календарь (по умолчанию true)

Объект-компаньон

map()

fun map(calendars: List<TeamCalendar>, styleMap: CalendarStyleMap): List<StyledTeamCalendar>

Принимает список объектов TeamCalendar и CalendarStyleMap, индексированный по идентификатору календаря. Создаёт соответствующий список экземпляров StyledTeamCalendar, каждый из которых декорирован своим стилем из карты. Использует calendars.find { it.id == cal.id } для поиска соответствующего исходного календаря для каждой записи.

Обоснование дизайна

Разделение на TeamCalendar (чистые данные) и StyledTeamCalendar (декорированный метаданными пользовательского интерфейса) следует чистому шаблону декоратора. Базовый класс TeamCalendar остаётся независимым от вопросов рендеринга. Поиск в CalendarStyleMap применяется пакетно через функцию-компаньон map, что сохраняет логику преобразования централизованной.
