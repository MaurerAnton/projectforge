#867: TeamCalendar.kt

projectforge-business/src/main/kotlin/org/projectforge/business/calendar/TeamCalendar.kt Typ: Offene Datenklasse · Zweck: Kalenderzugriffsmodell · Quelle: projectforge-business/src/main/kotlin/org/projectforge/business/calendar/TeamCalendar.kt 73 Zeilen · 37 Code · 28 Kommentare · 8 leer
Zentrales Domänenobjekt, das einen Teamkalender mit Benutzerzugriffsrechten repräsentiert. Wird entweder aus rohen Eigenschaften oder aus einer JPA-Entität (TeamCalDO) mit Zugriffsauflösung über TeamCalCache erstellt. Dient als Basisklasse für StyledTeamCalendar (siehe #861).

Eigenschaften

EigenschaftTypStandardBeschreibung
idLong?—Eindeutige Kalenderkennung
titleString?—Anzeigename des Kalenders
accessACCESS?nullZugriffsstufe des Benutzers auf diesen Kalender
externalSubscriptionBooleanfalseGibt an, ob dies ein extern abonnierter Kalender ist

ACCESS-Enum

Spiegelt DataobjectAccessType wider, ist jedoch auf Kalenderebene beschränkt.
WertBedeutung
OWNERBenutzer ist der Besitzer des Kalenders
FULLVoller Lese-/Schreibzugriff
READNur-Lese-Zugriff
MINIMALMinimaler Zugriff (z. B. nur Zeiten, keine Details)
NONEKein Zugriff (nur Administratoren erhalten dies)

Konstruktoren

Primärkonstruktor

TeamCalendar(id: Long?, title: String?, access: ACCESS? = null, externalSubscription: Boolean = false)

Direkte Konstruktion mit expliziten Eigenschaftswerten.

Sekundärkonstruktor (aus TeamCalDO)

constructor(teamCalDO: TeamCalDO, userId: Long, teamCalCache: TeamCalCache)

Erstellt einen TeamCalendar aus einer JPA-Entität. Löst die Zugriffsstufe des Benutzers durch Aufruf von teamCalCache.teamCalRight.getAccessType(teamCalDO, userId) auf und bildet das DataobjectAccessType-Ergebnis auf die ACCESS-Enum ab. Liest auch externalSubscription aus der Entität.

Begleitobjekt

Pseudo-Kalender-Konstanten

KonstanteWertZweck
BIRTHDAYS_FAVS_CAL_ID-2LID für den Pseudo-Kalender „Geburtstage der Favoriten“
BIRTHDAYS_ALL_CAL_ID-3LID für den Pseudo-Kalender „Geburtstage aller Personen“

Factory-Methoden

fun createFavoritesBirthdaysPseudoCalendar(): TeamCalendar

Gibt einen TeamCalendar mit ID -2, lokalisiertem Titel „calendar.birthdays.favorites“ und ACCESS.READ zurück.

fun createAllBirthdaysPseudoCalendar(): TeamCalendar

Gibt einen TeamCalendar mit ID -3, lokalisiertem Titel „calendar.birthdays.all“ und ACCESS.READ zurück.

Beziehung zu StyledTeamCalendar

TeamCalendar ist die Basisklasse für StyledTeamCalendar (#861), welches CalendarStyle und ein visible-Flag hinzufügt. Diese Trennung folgt dem Dekorator-Muster: TeamCalendar enthält Kerndaten und Zugriffslogik, während StyledTeamCalendar UI-Rendering-Metadaten hinzufügt.
