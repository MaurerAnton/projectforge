#867: TeamCalendar.kt

projectforge-business/src/main/kotlin/org/projectforge/business/calendar/TeamCalendar.kt Тип: Открытый класс данных · Назначение: Модель доступа к календарю · Исходник: projectforge-business/src/main/kotlin/org/projectforge/business/calendar/TeamCalendar.kt 73 строки · 37 кода · 28 комментариев · 8 пустых
Основной объект домена, представляющий командный календарь с правами доступа пользователя. Создаётся либо из сырых свойств, либо из JPA-сущности (TeamCalDO) с разрешением доступа через TeamCalCache. Служит базовым классом для StyledTeamCalendar (см. #861).

Свойства

СвойствоТипПо умолчаниюОписание
idLong?—Уникальный идентификатор календаря
titleString?—Отображаемое имя календаря
accessACCESS?nullУровень доступа пользователя к этому календарю
externalSubscriptionBooleanfalseЯвляется ли этот календарь внешней подпиской

Перечисление ACCESS

Отражает DataobjectAccessType, но ограничено семантикой уровня календаря.
ЗначениеСмысл
OWNERПользователь является владельцем календаря
FULLПолный доступ на чтение и запись
READДоступ только на чтение
MINIMALМинимальный доступ (например, только время, без деталей)
NONEНет доступа (получают только администраторы)

Конструкторы

Основной конструктор

TeamCalendar(id: Long?, title: String?, access: ACCESS? = null, externalSubscription: Boolean = false)

Прямое создание с явными значениями свойств.

Вторичный конструктор (из TeamCalDO)

constructor(teamCalDO: TeamCalDO, userId: Long, teamCalCache: TeamCalCache)

Строит TeamCalendar из JPA-сущности. Определяет уровень доступа пользователя, вызывая teamCalCache.teamCalRight.getAccessType(teamCalDO, userId) и сопоставляя результат DataobjectAccessType с перечислением ACCESS. Также считывает externalSubscription из сущности.

Фабричные методы

fun createFavoritesBirthdaysPseudoCalendar(): TeamCalendar

Возвращает TeamCalendar с ID -2, локализованным заголовком «calendar.birthdays.favorites» и ACCESS.READ.

fun createAllBirthdaysPseudoCalendar(): TeamCalendar

Возвращает TeamCalendar с ID -3, локализованным заголовком «calendar.birthdays.all» и ACCESS.READ.

Связь со StyledTeamCalendar

TeamCalendar является базовым классом для StyledTeamCalendar (#861), который добавляет CalendarStyle и флаг visible. Это разделение следует шаблону «декоратор»: TeamCalendar содержит основные данные и логику доступа, а StyledTeamCalendar добавляет метаданные для отображения в интерфейсе.
