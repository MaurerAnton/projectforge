projectforge-business/src/main/kotlin/org/projectforge/business/common/AutoCompletionUtils.kt Tipo: Utilidad (objeto + companion) · Propósito: Búsqueda/filtro de cadenas para autocompletado · Fuente: projectforge-business/src/main/kotlin/org/projectforge/business/common/AutoCompletionUtils.kt 47 líneas · 22 código · 22 comentarios · 3 en blanco
Proporciona un filtro de búsqueda simple, insensible a mayúsculas/minúsculas y de múltiples palabras para autocompletado y sugerencias en interfaces de usuario. Divide la consulta de búsqueda por espacios en blanco y luego devuelve solo las cadenas de la lista de entrada que contienen todos los tokens de búsqueda.

API

filter(list: List<String>?, search: String?): List<String>

@JvmStatic punto de entrada público.

  • Devuelve emptyList() si list es null.
  • Devuelve la list completa si search es nulo o está en blanco.
  • De lo contrario, divide search en tokens por espacios, filtra list a los elementos que contienen cada token (sin distinción de mayúsculas/minúsculas) y devuelve el resultado ordenado lexicográficamente.

containsAll(str: String, strings: List<String>): Boolean

Ayudante internal. Itera sobre la lista de tokens; devuelve false tan pronto como cualquier token no se encuentre en str (ignorando mayúsculas/minúsculas). Devuelve true si todos los tokens coinciden.

Justificación del diseño

El diseño de filtro AND de múltiples palabras es adecuado para autocompletado donde los usuarios escriben múltiples términos (ej., "proyecto acme" que coincide con "Acme Proyecto 2024"). La visibilidad internal de containsAll mantiene la lógica interna comprobable dentro del módulo sin exponerla. La anotación @JvmStatic asegura que los llamadores Java puedan usar AutoCompletionUtils.filter(...) sin acceder al objeto companion.

Este filtro realiza una coincidencia de subcadena ingenua (String.contains), no una coincidencia tokenizada o basada en prefijos. Es adecuado para conjuntos de datos pequeños a medianos cargados del lado del cliente, pero puede no escalar para conjuntos de datos grandes.
