projectforge-business/src/main/kotlin/org/projectforge/business/common/AutoCompletionUtils.kt Type : Utilitaire (objet + companion) · Objectif : Recherche/filtre de chaînes pour l'autocomplétion · Source : projectforge-business/src/main/kotlin/org/projectforge/business/common/AutoCompletionUtils.kt 47 lignes · 22 code · 22 commentaires · 3 vides
Fournit un filtre de recherche multi-mots simple, insensible à la casse, pour les interfaces d'autocomplétion et de suggestions. Divise la requête de recherche sur les espaces, puis ne renvoie que les chaînes de la liste d'entrée qui contiennent tous les jetons de recherche.

API

filter(list: List<String>?, search: String?): List<String>

@JvmStatic point d'entrée public.

  • Renvoie emptyList() si list est null.
  • Renvoie la list complète si search est null ou vide.
  • Sinon, divise search sur les espaces en jetons, filtre list pour ne conserver que les éléments contenant chaque jeton (insensible à la casse), et renvoie le résultat trié par ordre lexicographique.

containsAll(str: String, strings: List<String>): Boolean

Méthode utilitaire internal. Parcourt la liste de jetons ; renvoie false dès qu'un jeton n'est pas trouvé dans str (en ignorant la casse). Renvoie true si tous les jetons correspondent.

Justification de la conception

La conception du filtre ET multi-mots est adaptée à l'autocomplétion où les utilisateurs saisissent plusieurs termes (par exemple, « projet acme » correspondant à « Acme Projet 2024 »). La visibilité internal de containsAll permet de tester la logique interne au sein du module sans l'exposer. L'annotation @JvmStatic garantit que les appelants Java peuvent utiliser AutoCompletionUtils.filter(...) sans accéder à l'objet companion.

Ce filtre effectue une correspondance naïve de sous-chaîne (String.contains), et non une correspondance tokenisée ou basée sur un préfixe. Il convient aux ensembles de données de petite à moyenne taille chargés côté client, mais peut ne pas passer à l'échelle pour de grands ensembles de données.
