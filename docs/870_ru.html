#870: AutoCompletionUtils.kt

projectforge-business/src/main/kotlin/org/projectforge/business/common/AutoCompletionUtils.kt Тип: Утилита (object + companion) · Назначение: Поиск/фильтрация строк для автодополнения · Исходник: projectforge-business/src/main/kotlin/org/projectforge/business/common/AutoCompletionUtils.kt 47 строк · 22 кода · 22 комментария · 3 пустых
Предоставляет простой, нечувствительный к регистру многословный фильтр поиска для автодополнения и интерфейсов предложений. Разделяет поисковый запрос по пробелам, затем возвращает только те строки из входного списка, которые содержат все токены поиска.

API

filter(list: List<String>?, search: String?): List<String>

@JvmStatic публичная точка входа.

  • Возвращает emptyList(), если list равен null.
  • Возвращает полный list, если search равен null или пуст.
  • В противном случае разделяет search по пробелам на токены, фильтрует list, оставляя элементы, содержащие каждый токен (без учёта регистра), и возвращает результат, отсортированный лексикографически.

containsAll(str: String, strings: List<String>): Boolean

internal вспомогательный метод. Перебирает список токенов; возвращает false, как только любой токен не найден в str (игнорируя регистр). Возвращает true, если все токены совпадают.

Обоснование дизайна

Многословный AND-фильтр подходит для автодополнения, когда пользователи вводят несколько терминов (например, "project acme" соответствует "Acme Project 2024"). Видимость internal для containsAll позволяет тестировать внутреннюю логику в рамках модуля, не раскрывая её. Аннотация @JvmStatic гарантирует, что вызывающие из Java могут использовать AutoCompletionUtils.filter(...) без обращения к объекту companion.

Этот фильтр выполняет наивное сопоставление подстрок (String.contains), а не токенизированное или префиксное сопоставление. Он подходит для наборов данных малого и среднего размера, загружаемых на стороне клиента, но может не масштабироваться для больших наборов данных.
