Abstrakte Basisklasse für Domänenobjekte mit benutzer- und gruppenspezifischen Zugriffsrechten. Erweitert UserRightAccessCheck und bietet konkrete Implementierungen von CRUD-Zugriffsprüfungen (Select, Insert, Update, Delete, History) durch Delegation an BaseUserGroupRightUtils. Unterstützt die Zugriffsstufen Besitzer, Vollzugriff, Nur-Lesen und Minimal.

Klassenhierarchie

UserRightAccessCheck<T>
  └── BaseUserGroupRight<T : BaseUserGroupRightsDO?>

Der generische Parameter T ist auf nullable BaseUserGroupRightsDO-Subtypen eingeschränkt (#865).

Zugriffsprüfungsmethoden

Select-Zugriff

MethodeVerhalten
hasSelectAccess(user: PFUserDO?)Gibt immer true zurück (allgemeiner Select erlaubt)
hasSelectAccess(user, obj)Gibt true zurück, wenn der Benutzer Besitzer, Admin oder über Gruppen-/Benutzerrechte Vollzugriff/Nur-Lesen/Minimalzugriff hat

Insert-Zugriff

MethodeVerhalten
hasInsertAccess(user: PFUserDO)Gibt immer true zurück (allgemeiner Insert erlaubt)
hasInsertAccess(user, obj)Gibt true zurück, wenn der Benutzer Besitzer oder Admin ist

Update- & Delete-Zugriff

Sowohl hasUpdateAccess(user, obj, oldObj) als auch hasDeleteAccess(user, obj, oldObj) delegieren an hasInsertAccess(user, oldObj) – d. h. der Benutzer muss Besitzer oder Admin des alten Objekts sein.

History-Zugriff

hasHistoryAccess(user, obj) gibt true zurück, wenn der Benutzer Insert-Zugriff auf das Objekt hat oder wenn das Objekt null ist (Standard true).

Delegierte Hilfsmethoden

Alle diese Methoden delegieren an BaseUserGroupRightUtils (#867):

isOwner(user, obj)Prüft, ob der Benutzer der Besitzer des Objekts ist
isOwner(userId, obj)Prüft anhand der Benutzer-ID
hasReadAccess(obj, userId, throwException)Lesezugriffsprüfung mit optionaler Ausnahme
hasWriteAccess(obj, userId, throwException)Schreibzugriffsprüfung mit optionaler Ausnahme
getAccessType(obj, userId)Gibt einen der Werte NONE, MINIMAL, READONLY oder FULL zurück
hasFullAccess(obj, userId)True, wenn der Zugriffstyp Vollzugriff ist
hasReadonlyAccess(obj, userId)True, wenn der Zugriffstyp READONLY ist
hasMinimalAccess(obj, userId)True, wenn der Zugriffstyp MINIMAL ist

Entwurfsbegründung

Diese Klasse verbindet die Framework-Abstraktion UserRightAccessCheck mit den domänenspezifischen Benutzer-/Gruppenrechten, die in BaseUserGroupRightsDO gespeichert sind. Durch die Auslagerung der eigentlichen Logik in das eigenständige Objekt BaseUserGroupRightUtils ist die Berechtigungsberechnung zugänglich, ohne eine vollständige BaseUserGroupRight-Instanz konstruieren zu müssen (z. B. aus dem TeamCalCache).

Allgemeiner Select und Insert geben immer true zurück, da die Filterung auf Objektebene nachgelagert von der konkreten DAO-/Service-Schicht durchgeführt wird – diese Klasse prüft nur den objektspezifischen Zugriff.
