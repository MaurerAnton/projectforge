Абстрактный базовый класс для объектов предметной области, поддерживающих права доступа для пользователей и групп. Расширяет UserRightAccessCheck и предоставляет конкретные реализации проверок доступа CRUD (выборка, вставка, обновление, удаление, история) путем делегирования BaseUserGroupRightUtils. Поддерживает уровни доступа: владелец, полный, только чтение и минимальный.

Иерархия классов

UserRightAccessCheck<T>
  └── BaseUserGroupRight<T : BaseUserGroupRightsDO?>

Обобщённый параметр T ограничен nullable-подтипами BaseUserGroupRightsDO (#865).

Методы проверки доступа

Доступ на выборку

МетодПоведение

hasSelectAccess(user, obj)Возвращает true, если пользователь является владельцем, администратором или имеет полный/только чтение/минимальный доступ через права группы/пользователя

Доступ на вставку

МетодПоведение
hasInsertAccess(user: PFUserDO)Всегда возвращает true (общая вставка разрешена)
hasInsertAccess(user, obj)Возвращает true, если пользователь является владельцем или администратором

Доступ на обновление и удаление

Оба метода hasUpdateAccess(user, obj, oldObj) и hasDeleteAccess(user, obj, oldObj) делегируют выполнение hasInsertAccess(user, oldObj) — т.е. пользователь должен быть владельцем или администратором старого объекта.

Доступ к истории

hasHistoryAccess(user, obj) возвращает true, если пользователь имеет доступ на вставку объекта, или если объект равен null (по умолчанию true).

Обоснование дизайна

Этот класс связывает абстракцию UserRightAccessCheck уровня фреймворка с правами пользователей/групп на уровне предметной области, хранящимися в BaseUserGroupRightsDO. Благодаря размещению фактической логики в автономном объекте BaseUserGroupRightUtils, расчёт прав становится доступным без создания полного экземпляра BaseUserGroupRight (например, из TeamCalCache).

Общие методы выборки и вставки всегда возвращают true, поскольку фильтрация на уровне объектов применяется нижележащим конкретным уровнем DAO/сервисов — данный класс ограничивает только доступ к конкретному объекту.
