Servicio Spring que proporciona métodos getter/setter para los campos CSV de derechos de acceso en objetos BaseUserGroupRightsDO. Resuelve cadenas de ID sin procesar a colecciones ordenadas de GroupDO y PFUserDO a través de GroupService y UserService. Mantiene una instancia singleton instance mediante @PostConstruct para acceso estático.

Objeto Compañero

@JvmStatic. Convierte una colección de IdObject<Long> en una cadena ordenada de IDs separados por comas. Filtra nulos, ordena numéricamente, une con ",". Retorna null si la colección es nula o vacía.

// Ejemplo: [Group(3), Group(1), Group(2)] → "1,2,3"

asSortedIdStrings(idString)

@JvmStatic. Analiza una cadena CSV, extrae valores Long válidos, los ordena y retorna la cadena CSV normalizada. Filtra entradas en blanco/inválidas. Retorna null para entrada nula.

instance

@JvmStatic lateinit var con setter privado. Inicializado en @PostConstruct. Proporciona acceso estático global al singleton gestionado por Spring para contextos de utilidad donde la inyección de dependencias no está disponible.

Justificación del Diseño

El patrón getter/setter asegura que las cadenas CSV sin procesar se mantengan siempre ordenadas y normalizadas. Las dos sobrecargas por setter (colección vs. cadena) soportan tanto la edición impulsada por UI (donde una selección múltiple produce una colección de entidades) como la edición programática/impulsada por API (donde se proporcionan cadenas de ID sin procesar).

El patrón singleton instance es un puente pragmático entre Spring DI y el código de utilidad estático más antiguo. El código más nuevo debería preferir la inyección por constructor de BaseUserGroupRightService.
