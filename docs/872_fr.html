Service Spring fournissant des méthodes getter/setter pour les champs CSV des droits d'accès sur les objets BaseUserGroupRightsDO. Résout les chaînes d'ID brutes en collections triées GroupDO et PFUserDO via GroupService et UserService. Maintient une instance singleton via @PostConstruct pour un accès statique.

Objet compagnon

asSortedIdStrings(collection)

@JvmStatic. Convertit une collection de IdObject<Long> en une chaîne triée d'ID séparés par des virgules. Filtre les nulls, trie numériquement, joint avec ",". Retourne null si la collection est nulle ou vide.

// Exemple : [Group(3), Group(1), Group(2)] → "1,2,3"

asSortedIdStrings(idString)

@JvmStatic. Analyse une chaîne CSV, extrait les valeurs Long valides, les trie et retourne la chaîne CSV normalisée. Filtre les entrées vides/invalides. Retourne null pour une entrée nulle.

instance

@JvmStatic lateinit var avec setter privé. Initialisé dans @PostConstruct. Fournit un accès statique global au singleton géré par Spring pour les contextes utilitaires où l'injection de dépendances n'est pas disponible.

Justification de la conception

Le modèle getter/setter garantit que les chaînes CSV brutes sont toujours triées et normalisées. Les deux surcharges par setter (collection vs. chaîne) prennent en charge à la fois l'édition pilotée par l'interface utilisateur (où une sélection multiple produit une collection d'entités) et l'édition programmatique/pilotée par API (où des chaînes d'ID brutes sont fournies).

Le modèle singleton instance est un pont pragmatique entre l'ID Spring et le code utilitaire statique plus ancien. Le code plus récent devrait préférer l'injection par constructeur de BaseUserGroupRightService.
