projectforge-business/src/main/kotlin/org/projectforge/business/common/BaseUserGroupRightService.kt Тип: Spring @Service · Назначение: CRUD-помощник для прав пользователей/групп · Исходник: projectforge-business/src/main/kotlin/org/projectforge/business/common/BaseUserGroupRightService.kt 230 строк · 91 код · 112 комментариев · 27 пустых
Spring-сервис, предоставляющий методы getter/setter для CSV-полей прав доступа на объектах BaseUserGroupRightsDO. Преобразует сырые строки ID в отсортированные коллекции GroupDO и PFUserDO через GroupService и UserService. Поддерживает синглтон instance через @PostConstruct для статического доступа.

Зависимости

ЗависимостьТипНазначение
GroupService@AutowiredПреобразует ID групп в сущности GroupDO
UserService@AutowiredПреобразует ID пользователей в сущности PFUserDO

Каждый уровень доступа (полный, только чтение, минимальный) × тип сущности (группы, пользователи) имеет соответствующий getter:

Каждый уровень доступа × тип сущности имеет две перегрузки — одна принимает Collection<IdObject<Long>?>?, другая — сырую String? с ID, разделёнными запятыми:

Все методы setter изменяют только поле DO в памяти. Ни один из них не инициирует сохранение в базу данных — вызывающий код отвечает за сохранение сущности.

Объект-компаньон

asSortedIdStrings(collection)

@JvmStatic. Преобразует коллекцию IdObject<Long> в отсортированную строку ID, разделённых запятыми. Фильтрует null, сортирует численно, объединяет через ",". Возвращает null, если коллекция null или пуста.

// Пример: [Group(3), Group(1), Group(2)] → "1,2,3"

asSortedIdStrings(idString)

@JvmStatic. Разбирает CSV-строку, извлекает корректные значения Long, сортирует их и возвращает нормализованную CSV-строку. Фильтрует пустые/некорректные записи. Возвращает null для null-входных данных.

instance

@JvmStatic lateinit var с приватным сеттером. Инициализируется в @PostConstruct. Обеспечивает глобальный статический доступ к управляемому Spring синглтону для контекстов утилит, где недоступно внедрение зависимостей.

Обоснование дизайна

Шаблон getter/setter гарантирует, что сырые CSV-строки всегда остаются отсортированными и нормализованными. Две перегрузки для каждого setter (коллекция vs строка) поддерживают как редактирование через UI (где мультивыбор создаёт коллекцию сущностей), так и программное/API-редактирование (где предоставляются сырые строки ID).

Шаблон синглтона instance — прагматичный мост между Spring DI и старым статическим утилитарным кодом. В новом коде следует предпочитать конструкторное внедрение BaseUserGroupRightService.
