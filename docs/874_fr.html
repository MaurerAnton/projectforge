@MappedSuperclass JPA qui stocke les droits d'accès basés sur l'utilisateur et le groupe sous forme de chaînes d'ID séparées par des virgules dans les colonnes de la base de données. Étendu par les entités de domaine nécessitant un contrôle d'accès au niveau des lignes. Définit trois niveaux d'accès : complet, lecture seule et minimal — chacun avec des colonnes distinctes pour les ID de groupe et les ID d'utilisateur.

Niveaux d'accès

Accès complet

Les groupes/utilisateurs listés dans fullAccessGroupIds / fullAccessUserIds disposent d'un accès illimité en lecture/écriture.

Accès en lecture seule

Les groupes/utilisateurs dans readonlyAccessGroupIds / readonlyAccessUserIds peuvent voir toutes les données mais pas les modifier.

Accès minimal

Les groupes/utilisateurs dans minimalAccessGroupIds / minimalAccessUserIds voient uniquement un sous-ensemble minimal (par exemple, les heures de début/fin d'une entrée de calendrier sans détails comme le lieu ou les notes).

Important : Tous les champs d'ID d'accès sont des chaînes CSV brutes stockées avec une longueur de colonne de 4000. La manipulation directe est déconseillée — utilisez BaseUserGroupRightService (#866) pour les opérations get/set afin de garantir un tri et un formatage corrects.

Justification de la conception

Stocker les ID de groupe/utilisateur sous forme de chaînes CSV dans des colonnes (plutôt que des tables de jointure) évite les problèmes de requêtes N+1 et maintient les données d'accès colocalisées avec la ligne d'entité. La contrepartie est une limite pratique du nombre de groupes/utilisateurs pouvant se voir accorder l'accès par entité (~4000 caractères). Le modificateur open sur toutes les propriétés est requis pour les proxies de chargement différé d'Hibernate en Kotlin.

Le owner est déclaré comme abstract @Transient afin que les sous-classes concrètes puissent définir leur propre résolution du propriétaire (par exemple, le propriétaire d'une feuille de temps pourrait être son utilisateur, le propriétaire d'un calendrier d'équipe pourrait être l'administrateur du calendrier).
