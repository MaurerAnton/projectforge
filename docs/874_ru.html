projectforge-business/src/main/kotlin/org/projectforge/business/common/BaseUserGroupRightsDO.kt Тип: Абстрактный @MappedSuperclass (JPA) · Назначение: Объект данных прав пользователей/групп · Исходник: projectforge-business/src/main/kotlin/org/projectforge/business/common/BaseUserGroupRightsDO.kt 95 строк · 26 кода · 57 комментариев · 12 пустых
JPA @MappedSuperclass, который хранит права доступа на основе пользователей и групп в виде строк с идентификаторами, разделёнными запятыми, в столбцах базы данных. Расширяется сущностями предметной области, которым требуется контроль доступа на уровне строк. Определяет три уровня доступа: полный, только для чтения и минимальный — каждый с отдельными столбцами для идентификаторов групп и пользователей.

Наследование

  └── BaseUserGroupRightsDO

Расширяет DefaultBaseDO, наследуя стандартные поля (id, created, lastUpdate и т.д.). Помечен как @MappedSuperclass, поэтому подклассы JPA наследуют сопоставления столбцов.

Уровни доступа

Полный доступ

Группы/пользователи, перечисленные в fullAccessGroupIds / fullAccessUserIds, имеют неограниченный доступ на чтение/запись.

Доступ только для чтения

Группы/пользователи в readonlyAccessGroupIds / readonlyAccessUserIds могут просматривать все данные, но не изменять их.

Минимальный доступ

Группы/пользователи в minimalAccessGroupIds / minimalAccessUserIds видят только минимальный поднабор (например, время начала/окончания записи календаря без деталей, таких как местоположение или заметки).

Важно: Все поля идентификаторов доступа представляют собой необработанные CSV-строки, хранящиеся в столбцах длиной 4000. Прямое манипулирование не рекомендуется — используйте BaseUserGroupRightService (#866) для операций получения/установки, чтобы обеспечить правильную сортировку и форматирование.

Обоснование дизайна

Хранение идентификаторов групп/пользователей в виде CSV-строк в столбцах (вместо таблиц связей) позволяет избежать проблем с N+1 запросами и сохраняет данные доступа совместно со строкой сущности. Оборотная сторона — практическое ограничение на количество групп/пользователей, которым может быть предоставлен доступ на одну сущность (~4000 символов). Модификатор open для всех свойств требуется для прокси-объектов ленивой загрузки Hibernate в Kotlin.

owner объявлен как abstract @Transient, чтобы конкретные подклассы могли определять собственное разрешение владельца (например, владельцем табеля учёта времени может быть его пользователь, владельцем командного календаря — администратор календаря).
