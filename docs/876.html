#876: ListData.kt

Type: Kotlin abstract class — Generic paginated API response wrapper

Purpose: Wraps paginated list responses from the D-velop REST API, providing a typed data list along with pagination metadata (current position and total count).

Source path: projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/ListData.kt

A generic abstract class modeling D-velop's standard paginated API response envelope. The D-velop API returns lists in a uniform format with data, pos, and total_count fields. This class enables Jackson deserialization into type-safe Kotlin objects. A concrete subclass TradingPartnerListData is provided for the trading partner endpoint.

Generic Parameters

ParameterDescription
TThe type of items in the paginated list (e.g., TradingPartner)

Properties

PropertyTypeJSON MappingDescription
dataList<T>?dataThe list of result items for the current page
posLong?posCursor position / offset of the current page
totalCountLong?total_count (via @JsonProperty)Total number of items across all pages

Concrete Subclass

class TradingPartnerListData: ListData<TradingPartner>()

A concrete instantiation for D-velop's trading partner list endpoint. No additional fields — it simply binds the generic parameter T to TradingPartner.

Architecture Notes

  • Uses @JsonProperty("total_count") to map the snake_case JSON field to the camelCase Kotlin property
  • The abstract modifier prevents direct instantiation of the untyped ListData base class
  • Pattern is extensible: more subclasses like CustomFieldDefListData could be added for other D-velop endpoints
