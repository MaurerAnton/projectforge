Bidirektionale Hibernate Search ValueBridge<Number, String>, die numerische Entitätsfelder für die Volltextindizierung in Zeichenketten umwandelt und beim Lesen aus dem Index zurück in Zahlen konvertiert. Ermöglicht textbasierte Suchabfragen, die numerische Felder abgleichen.

Brückensignatur

class NumberToStringValueBridge : ValueBridge<Number, String>
  • Eingabetyp: Number (beliebiger numerischer Typ aus der Entität: Int, Long, Double, usw.)
  • Indizierter Typ: String (die durchsuchbare Darstellung im Index)
  • Bidirektional: Implementiert sowohl toIndexedValue als auch fromIndexedValue

Methoden

toIndexedValue(value, context): String?

Konvertiert die Number in ihre Zeichenkettendarstellung mittels value?.toString(). Gibt bei null-Eingabe null zurück.

fromIndexedValue(value, context): Number?

Rekonstruiert eine Number aus der indizierten Zeichenkette. Versucht die Analyse in dieser Reihenfolge:

  1. toLongOrNull() — behandelt ganzzahlige Werte (häufigster Fall für IDs)
  2. toDoubleOrNull() — behandelt Dezimalwerte
  3. toIntOrNull() — Rückfall für Werte, die nicht in die obigen passen

Gibt null zurück, wenn keine Analyse erfolgreich ist.

toString(): String

Gibt "NumberToStringValueBridge" zur Brückenidentifikation in Logs/Debug-Ausgaben zurück.

Anwendungsfall

Wird verwendet, wenn numerische Entitätsfelder (z. B. Rechnungsnummern, Geldbeträge, Mengen) über Hibernate Search Volltextabfragen durchsuchbar sein müssen. Ohne diese Brücke wären für numerische Felder separate Bereichsabfragen oder Exaktmatch-Filter erforderlich. Durch die Umwandlung in Zeichenketten können Benutzer z. B. nach "100" suchen und Datensätze finden, bei denen amount = 100.0 oder invoiceNumber = 100 ist.
