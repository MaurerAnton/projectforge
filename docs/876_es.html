ValueBridge bidireccional de Hibernate Search ValueBridge<Number, String> que convierte campos numéricos de entidades a cadenas para indexación de texto completo y de vuelta a números al leer desde el índice. Permite que las consultas de búsqueda basadas en texto coincidan con campos numéricos.

Firma del puente

class NumberToStringValueBridge : ValueBridge<Number, String>
  • Tipo de entrada: Number (cualquier tipo numérico de la entidad: Int, Long, Double, etc.)
  • Tipo indexado: String (la representación buscable en el índice)
  • Bidireccional: Implementa tanto toIndexedValue como fromIndexedValue

Métodos

toIndexedValue(value, context): String?

Convierte el Number a su representación de cadena mediante value?.toString(). Devuelve null para entrada nula.

fromIndexedValue(value, context): Number?

Reconstruye un Number a partir de la cadena indexada. Intenta analizar en este orden:

  1. toLongOrNull() — maneja valores enteros (caso más común para IDs)
  2. toDoubleOrNull() — maneja valores decimales
  3. toIntOrNull() — respaldo para valores que no encajan en los anteriores

Devuelve null si ninguno se analiza correctamente.

toString(): String

Devuelve "NumberToStringValueBridge" para identificación del puente en registros/salida de depuración.

Caso de uso

Se utiliza cuando los campos numéricos de entidades (por ejemplo, números de factura, cantidades monetarias, cantidades) necesitan ser buscables mediante consultas de texto completo de Hibernate Search. Sin este puente, los campos numéricos requerirían consultas de rango separadas o filtros de coincidencia exacta. Al convertir a cadenas, los usuarios pueden buscar, por ejemplo, "100" y encontrar registros donde amount = 100.0 o invoiceNumber = 100.
