ValueBridge bidirectionnelle Hibernate Search ValueBridge<Number, String> qui convertit les champs numériques d'entités en chaînes pour l'indexation plein texte et les reconvertit en nombres lors de la lecture depuis l'index. Permet aux requêtes de recherche textuelle de correspondre aux champs numériques.

Signature du pont

class NumberToStringValueBridge : ValueBridge<Number, String>
  • Type d'entrée : Number (tout type numérique de l'entité : Int, Long, Double, etc.)
  • Type indexé : String (la représentation consultable dans l'index)
  • Bidirectionnel : Implémente à la fois toIndexedValue et fromIndexedValue

Méthodes

toIndexedValue(value, context) : String?

Convertit le Number en sa représentation textuelle via value?.toString(). Retourne null pour une entrée nulle.

fromIndexedValue(value, context) : Number?

Reconstruit un Number à partir de la chaîne indexée. Tente l'analyse dans cet ordre :

  1. toLongOrNull() — gère les valeurs entières (cas le plus courant pour les ID)
  2. toDoubleOrNull() — gère les valeurs décimales
  3. toIntOrNull() — solution de repli pour les valeurs qui ne correspondent pas aux précédentes

Retourne null si aucune analyse n'aboutit.

toString() : String

Retourne "NumberToStringValueBridge" pour l'identification du pont dans les logs/sorties de débogage.

Cas d'utilisation

Utilisé lorsque les champs numériques d'entités (ex. : numéros de facture, montants monétaires, quantités) doivent être consultables via les requêtes plein texte Hibernate Search. Sans ce pont, les champs numériques nécessiteraient des requêtes par plage ou des filtres de correspondance exacte. En convertissant en chaînes, les utilisateurs peuvent rechercher par ex. "100" et trouver les enregistrements où montant = 100.0 ou numéroFacture = 100.
