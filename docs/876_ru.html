Двунаправленный мост Hibernate Search ValueBridge<Number, String>, который преобразует числовые поля сущностей в строки для полнотекстовой индексации и обратно в числа при чтении из индекса. Позволяет текстовым поисковым запросам сопоставляться с числовыми полями.

Сигнатура моста

class NumberToStringValueBridge : ValueBridge<Number, String>
  • Входной тип: Number (любой числовой тип сущности: Int, Long, Double и т.д.)
  • Индексируемый тип: String (поисковое представление в индексе)
  • Двунаправленный: Реализует как toIndexedValue, так и fromIndexedValue

Методы

toIndexedValue(value, context): String?

Преобразует Number в строковое представление через value?.toString(). Возвращает null для нулевого входного значения.

fromIndexedValue(value, context): Number?

Восстанавливает Number из индексированной строки. Пытается выполнить парсинг в следующем порядке:

  1. toLongOrNull() — обрабатывает целочисленные значения (наиболее частый случай для ID)
  2. toDoubleOrNull() — обрабатывает десятичные значения
  3. toIntOrNull() — запасной вариант для значений, не подходящих под вышеуказанные

Возвращает null, если ни один из вариантов не распарсился успешно.

toString(): String

Возвращает "NumberToStringValueBridge" для идентификации моста в логах/отладочном выводе.

Сценарий использования

Используется, когда числовые поля сущностей (например, номера счетов, денежные суммы, количества) должны быть доступны для поиска через полнотекстовые запросы Hibernate Search. Без этого моста числовые поля требовали бы отдельных запросов по диапазону или фильтров точного совпадения. Преобразуя в строки, пользователи могут искать, например, "100" и находить записи, где amount = 100.0 или invoiceNumber = 100.
