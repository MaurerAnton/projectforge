#879: CustomField.kt

projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/CustomField.kt

Typ: Kotlin-Klasse — DTO mit berechneter Logik

Zweck: Stellt eine einzelne Instanz eines benutzerdefinierten Feldes mit seinem Wert dar, verwendet in der D-velop-API zur Synchronisation entitätsspezifischer benutzerdefinierter Daten (z. B. der DATEV-Kontonummer bei einem TradingPartner).

Quellpfad: projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/CustomField.kt

40 Zeilen · 12 Code · 25 Kommentare · 3 Leerzeilen

Modelliert ein benutzerdefiniertes Feld-Wert-Objekt, wie es von der D-velop-REST-API gesendet/empfangen wird. Jedes benutzerdefinierte Feld hat eine configID (verweist per UUID auf eine CustomFieldDef), einen name und einen polymorphen value. Zusätzliche Metadaten wie label, type und selectOptionDtos unterstützen die UI-Darstellung. Wird hauptsächlich innerhalb von TradingPartner.customFields verwendet, um die DATEV-Kontonummer (datevKonto) auf die API-Repräsentation benutzerdefinierter Felder von D-velop abzubilden.

Architekturnotizen

Diese Klasse vermischt DTO-Belange (Datentransfer zur/von der D-velop-JSON-API) mit UI-Belangen (label, selectOptionDtos). Das Feld value ist als Any? typisiert, um polymorphe Deserialisierung zu unterstützen. Das begleitende Enum Type ist in dieser Version minimal gehalten — nur NUMBER wird für den DATEV-Konto-Anwendungsfall benötigt.
