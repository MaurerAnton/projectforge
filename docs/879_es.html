projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/CustomField.kt

Propósito: Representa una instancia de campo personalizado con su valor, utilizada en la API de D-velop para sincronizar datos personalizados de entidades (p. ej., el número de cuenta DATEV en un TradingPartner).

Ruta de origen: projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/CustomField.kt

40 líneas · 12 código · 25 comentarios · 3 en blanco

Modela un objeto de valor de campo personalizado tal como se envía/recibe por la API REST de D-velop. Cada campo personalizado tiene un configID (referencia a un CustomFieldDef por UUID), un name y un value polimórfico. Metadatos adicionales como label, type y selectOptionDtos facilitan la representación en la interfaz de usuario. Se utiliza principalmente dentro de TradingPartner.customFields para mapear el número de cuenta DATEV (datevKonto) a la representación de la API de campos personalizados de D-velop.

nameString?Parámetro del constructor — Nombre del campo personalizado (p. ej., "datevKonto")

Enum interno: Type

ValorDescripción
NUMBEREl único tipo definido — indica que el campo personalizado contiene un valor numérico

Notas de arquitectura

Esta clase mezcla preocupaciones de DTO (transferencia de datos hacia/desde la API JSON de D-velop) con preocupaciones de interfaz de usuario (label, selectOptionDtos). El campo value está tipado como Any? para soportar deserialización polimórfica. El enum complementario Type es mínimo en esta versión — solo se necesita NUMBER para el caso de uso de la cuenta Datev.
