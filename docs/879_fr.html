Objectif : Représente une instance de champ personnalisé unique avec sa valeur, utilisée dans l'API D-velop pour synchroniser les données personnalisées propres à une entité (par exemple, le numéro de compte DATEV sur un TradingPartner).

Modélise un objet valeur de champ personnalisé tel qu'envoyé/reçu par l'API REST D-velop. Chaque champ personnalisé possède un configID (référence un CustomFieldDef par UUID), un name et une value polymorphe. Des métadonnées supplémentaires comme label, type et selectOptionDtos facilitent le rendu de l'interface utilisateur. Principalement utilisé dans TradingPartner.customFields pour mapper le numéro de compte DATEV (datevKonto) à la représentation de l'API de champ personnalisé de D-velop.

Notes d'architecture

Cette classe mélange les préoccupations de DTO (transfert de données vers/depuis l'API JSON D-velop) avec les préoccupations d'interface utilisateur (label, selectOptionDtos). Le champ value est typé comme Any? pour prendre en charge la désérialisation polymorphe. L'énumération compagnon Type est minimale dans cette version — seul NUMBER est nécessaire pour le cas d'utilisation du compte Datev.
