projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/CustomField.kt

Тип: Класс Kotlin — DTO с вычисляемой логикой

Назначение: Представляет экземпляр одного пользовательского поля с его значением, используется в API D-velop для синхронизации специфичных для сущности пользовательских данных (например, номер счета DATEV для TradingPartner).

Путь к исходнику: projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/CustomField.kt

40 строк · 12 кода · 25 комментариев · 3 пустых

Моделирует объект значения пользовательского поля, отправляемый/получаемый через REST API D-velop. Каждое пользовательское поле имеет configID (ссылается на CustomFieldDef по UUID), name и полиморфное value. Дополнительные метаданные, такие как label, type и selectOptionDtos, поддерживают отрисовку в UI. В основном используется внутри TradingPartner.customFields для сопоставления номера счета DATEV (datevKonto) с представлением пользовательского поля API D-velop.

Архитектурные заметки

Этот класс смешивает задачи DTO (передача данных в/из JSON API D-velop) с задачами UI (label, selectOptionDtos). Поле value типизировано как Any? для поддержки полиморфной десериализации. Вспомогательное перечисление Type минимально в этой версии — для случая использования счёта Datev требуется только NUMBER.
