File #88: DataTransferArea.kt (rest/)

Path: plugins/datatransfer/.../rest/DataTransferArea.kt · Source: GitHub

REST DTO for data transfer areas. Extends BaseDTO + AttachmentsSupport + IDataTransferArea. Key features: (1) externalLink computed property = base URL + token for anonymous access, (2) copyFrom() converts CSV user/group IDs to object lists, detects personal boxes, strips external password for security, (3) copyTo() reverses conversion but preserves PERSONAL_BOX_AREA_NAME, (4) transformFromDB() companion factory restores display names and computes capacity object. Attachment createdByUser strings are translated from #EXTERNAL# markers to readable labels.
