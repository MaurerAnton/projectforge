Un DTO de serialización simple para las definiciones de campos personalizados de D-velop. Cuando ProjectForge se sincroniza con D-velop, obtiene la lista de esquemas de campos personalizados disponibles. Cada definición tiene un id (el identificador de la API), un name (etiqueta legible para humanos) y una entity (el tipo de objeto de dominio de D-velop al que pertenece, por ejemplo, "trading_partner"). Esta clase se utiliza durante el arranque de integración con D-velop para descubrir qué campos personalizados existen.

Propiedades

PropiedadTipoDescripción
idString?Identificador único de la definición del campo personalizado en D-velop (ej., UUID)
nameString?Nombre legible para humanos del campo personalizado (ej., "datevKonto")
entityString?El tipo de entidad al que pertenece este campo (ej., "trading_partner")

Notas de arquitectura

Este es un objeto de transferencia de datos puro sin lógica de negocio. Todas las propiedades se declaran como parámetros del constructor con valores null predeterminados, lo que lo hace compatible con la deserialización de Jackson desde las respuestas JSON de la API de D-velop y con la instanciación de argumentos con nombre de Kotlin.
