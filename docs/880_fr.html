Un DTO de sérialisation simple pour les définitions de champs personnalisés de D-velop. Lorsque ProjectForge se synchronise avec D-velop, il récupère la liste des schémas de champs personnalisés disponibles. Chaque définition possède un id (l'identifiant API), un name (libellé lisible par l'humain) et une entity (le type d'objet de domaine D-velop auquel elle appartient, par exemple "trading_partner"). Cette classe est utilisée lors de l'amorçage de l'intégration D-velop pour découvrir quels champs personnalisés existent.

Propriétés

PropriétéTypeDescription
idString?Identifiant unique de la définition du champ personnalisé dans D-velop (ex. UUID)
nameString?Nom lisible du champ personnalisé (ex. "datevKonto")
entityString?Le type d'entité auquel ce champ appartient (ex. "trading_partner")

Notes d'architecture

Il s'agit d'un pur objet de transfert de données sans logique métier. Toutes les propriétés sont déclarées comme paramètres du constructeur avec des valeurs par défaut null, ce qui le rend compatible avec la désérialisation Jackson des réponses JSON de l'API D-velop et l'instanciation par arguments nommés de Kotlin.
