projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/DvelopConfiguration.kt

Propósito: Almacena la configuración de conexión y autenticación para la integración D-velop de ProjectForge (URI base, clave API y nombre de organización).

Ruta de origen: projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/DvelopConfiguration.kt

56 líneas · 19 código · 31 comentarios · 6 en blanco

Una clase de configuración Spring que lee los ajustes de conectividad D-velop desde el archivo de propiedades de la aplicación. La integración D-velop permite la sincronización bidireccional de TradingPartners (clientes, proveedores, socios) entre ProjectForge y la plataforma D-velop. Esta clase sirve como un contenedor simple de propiedades con un método de conveniencia isConfigured() utilizado para controlar las funciones de D-velop.

Propiedades

PropiedadOrigenTipoDescripción
baseUriprojectforge.dvelop.baseUriStringLa URL base del endpoint de la API REST de D-velop
apiKeyprojectforge.dvelop.apiKeyStringLa clave API utilizada para autenticarse contra la API de D-velop
organizationNameprojectforge.dvelop.organizationStringSi se proporciona, todas las entidades TradingPartner se asignarán a esta organización de D-velop por ID

Método clave

fun isConfigured(): Boolean

Devuelve true solo si tanto baseUri como apiKey no están en blanco. Esta es la puerta que determina si las funciones de sincronización D-velop están activas. Todos los servicios D-velop deben verificar esto antes de intentar llamadas a la API.

Notas de arquitectura

  • Anotada con @Configuration (no @ConfigurationProperties), lo que la convierte en un bean gestionado por Spring con inyección directa de @Value
  • Todas las propiedades son lateinit var — deben proporcionarse en el archivo de propiedades de la aplicación para que esta se inicie
  • El comentario de la propiedad organizationName dice "referido por ID" pero el campo se llama "Name" — esta es una pequeña inconsistencia de nomenclatura conocida
  • Esta clase estaba originalmente en projectforge-rest y luego se movió a projectforge-business
