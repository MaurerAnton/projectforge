Objectif : Contient la configuration de connexion et d'authentification pour l'intégration D-velop de ProjectForge (URI de base, clé API et nom d'organisation).

56 lignes · 19 code · 31 commentaires · 6 lignes vides

Une classe de configuration Spring qui lit les paramètres de connectivité D-velop depuis le fichier de propriétés de l'application. L'intégration D-velop permet la synchronisation bidirectionnelle des TradingPartners (clients, fournisseurs, partenaires) entre ProjectForge et la plateforme D-velop. Cette classe sert de simple conteneur de propriétés avec une méthode pratique isConfigured() utilisée pour activer ou désactiver les fonctionnalités D-velop.

Propriétés

PropriétéSourceTypeDescription
baseUriprojectforge.dvelop.baseUriStringL'URL de base du point de terminaison de l'API REST D-velop
apiKeyprojectforge.dvelop.apiKeyStringLa clé API utilisée pour l'authentification auprès de l'API D-velop
organizationNameprojectforge.dvelop.organizationStringSi fourni, toutes les entités TradingPartner seront attribuées à cette organisation D-velop par son ID

Méthode clé

fun isConfigured(): Boolean

Retourne true uniquement si baseUri et apiKey ne sont pas vides. C'est le point de contrôle qui détermine si les fonctionnalités de synchronisation D-velop sont actives. Tous les services D-velop doivent vérifier ceci avant d'effectuer des appels API.

Notes d'architecture

  • Annotée avec @Configuration (et non @ConfigurationProperties), ce qui en fait un bean géré par Spring avec injection directe via @Value
  • Toutes les propriétés sont lateinit var — elles doivent être fournies dans le fichier de propriétés de l'application pour que celle-ci démarre
  • Le commentaire de la propriété organizationName indique « référencé par ID » mais le champ est nommé « Name » — c'est une incohérence mineure de nommage connue
  • Cette classe se trouvait initialement dans projectforge-rest et a ensuite été déplacée dans projectforge-business
