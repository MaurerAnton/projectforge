#884: Option.kt

projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/Option.kt

Typ: Kotlin-Datenklasse — DTO

Zweck: Repräsentiert einen auswählbaren Eintrag / Listenwert im D-velop-System, der für Dropdown-Felder (z. B. Kontakttyp, Partnertyp) in der D-velop-Oberfläche und API verwendet wird.

Quellpfad: projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/Option.kt

33 Zeilen · 6 Code · 25 Kommentare · 2 Leer

Ein minimales DTO für D-velops Optionen-/Listenwert-Modell. Jede Option besitzt eine id (der interne Schlüssel), einen value (die Anzeigebezeichnung) und eine optionale color für die UI-Darstellung. Wird verwendet, wenn ProjectForge seine internen Enum-Werte während der Synchronisation auf D-velop-Options-IDs abbilden muss.

Eigenschaften

EigenschaftTypBeschreibung
idString?Eindeutige Kennung der Option in D-velop (z. B. UUID für einen Listenwert-Eintrag)
valueString?Der menschenlesbare Anzeigewert
colorString?Optionale Farbe, die der Option für die UI-Darstellung zugeordnet ist

Architekturhinweise

Alle drei Eigenschaften sind Konstruktorparameter mit Standardwerten null, was die Kompatibilität mit der Jackson-Deserialisierung aus D-velops JSON-API gewährleistet. Keine Geschäftslogik – reine Datenübertragung. Wird wahrscheinlich im D-velop-Integrationscode verwendet, der Options-IDs für Felder wie type, contactType und active bei TradingPartner auflösen muss.
