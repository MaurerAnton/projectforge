Un DTO mínimo para el modelo de opción/lista de valores de D-velop. Cada opción tiene un id (la clave interna), un value (la cadena de visualización) y un color opcional para el renderizado en la interfaz de usuario. Se utiliza cuando ProjectForge necesita mapear sus valores de enumeración internos a los IDs de opción de D-velop durante la sincronización.

Propiedades

PropiedadTipoDescripción
idString?Identificador único de la opción en D-velop (ej., UUID para una entrada de lista de valores)
valueString?El valor de visualización legible por humanos
colorString?Color opcional asociado con la opción para el renderizado en la interfaz de usuario

Notas de arquitectura

Las tres propiedades son parámetros del constructor con valores predeterminados null, lo que hace que esto sea compatible con la deserialización de Jackson desde la API JSON de D-velop. Sin lógica de negocio — transferencia de datos pura. Probablemente se utiliza en el código de integración de D-velop que necesita resolver IDs de opción para campos como type, contactType y active en TradingPartner.
