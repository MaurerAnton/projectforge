Objectif : Représente une option sélectionnable / entrée de liste de valeurs dans le système D-velop, utilisée pour les listes déroulantes de champs (ex. type de contact, type de partenaire commercial) dans l'interface utilisateur et l'API D-velop.

Un DTO minimal pour le modèle d'option/liste de valeurs de D-velop. Chaque option possède un id (la clé interne), une value (la chaîne affichée) et une color optionnelle pour le rendu UI. Utilisé lorsque ProjectForge doit mapper ses valeurs d'énumération internes aux identifiants d'option de D-velop lors de la synchronisation.

Propriétés

PropriétéTypeDescription
idString?Identifiant unique de l'option dans D-velop (ex. UUID pour une entrée de liste de valeurs)
valueString?La valeur d'affichage lisible par l'humain
colorString?Couleur optionnelle associée à l'option pour le rendu UI

Notes d'architecture

Les trois propriétés sont des paramètres du constructeur avec des valeurs par défaut null, ce qui les rend compatibles avec la désérialisation Jackson depuis l'API JSON de D-velop. Aucune logique métier — pur transfert de données. Probablement utilisé dans le code d'intégration D-velop qui doit résoudre les identifiants d'option pour des champs comme type, contactType et active sur TradingPartner.
