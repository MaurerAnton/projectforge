#884: Option.kt

projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/Option.kt

Тип: Kotlin data class — DTO

Назначение: Представляет выбираемый вариант / запись из списка значений в системе D-velop, используется для выпадающих списков полей (например, тип контакта, тип торгового партнёра) в UI и API D-velop.

Путь к исходнику: projectforge-business/src/main/kotlin/org/projectforge/business/dvelop/Option.kt

33 строки · 6 кода · 25 комментариев · 2 пустых

Минимальный DTO для модели варианта/списка значений D-velop. Каждый вариант имеет id (внутренний ключ), value (отображаемая строка) и опциональный color для отрисовки в UI. Используется, когда ProjectForge необходимо сопоставить свои внутренние значения перечисления с идентификаторами вариантов D-velop во время синхронизации.

Свойства

СвойствоТипОписание
idString?Уникальный идентификатор варианта в D-velop (например, UUID для записи списка значений)
valueString?Человекочитаемое отображаемое значение
colorString?Опциональный цвет, связанный с вариантом для отрисовки в UI

Архитектурные заметки

Все три свойства являются параметрами конструктора со значениями по умолчанию null, что обеспечивает совместимость с десериализацией Jackson из JSON API D-velop. Без бизнес-логики — чистая передача данных. Вероятно, используется в коде интеграции с D-velop, которому требуется разрешать идентификаторы вариантов для таких полей, как type, contactType и active в TradingPartner.
