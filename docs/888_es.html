Clase base abstracta para entidades de posición de factura en ProjectForge. Sirve como superclase compartida tanto para posiciones de factura emitidas (RechnungsPositionDO) como para posiciones de factura recibidas (EingangsrechnungsPositionDO). Proporciona campos comunes como número de posición, texto, cantidad (menge), precio unitario neto (einzelNetto) y tasa de IVA (vat), junto con la lógica para gestionar asignaciones de costos (KostZuweisungDO).

Jerarquía de clases

Extiende DefaultBaseDO, implementa DisplayNameCapable y IRechnungsPosition. Anotada con @MappedSuperclass por lo que no es una tabla de base de datos por sí misma — las subclases concretas proporcionan sus propios mapeos JPA.

Gestión de asignación de costos

La clase proporciona métodos para gestionar las asignaciones de costos KostZuweisungDO vinculadas a cada posición de factura:

  • addKostZuweisung(kostZuweisung) — Agrega una asignación de costo con índice autoincrementado
  • deleteKostZuweisung(idx) — Elimina una asignación de costo en el índice dado (solo se puede eliminar si aún no está persistida, es decir, id == null)
  • ensureAndGetKostzuweisungen() — Devuelve la lista mutable, inicializándola de forma perezosa si es nula
  • isKostZuweisungDeletable() — Protege contra la eliminación de asignaciones de costos ya persistidas
  • getKostZuweisung(idx) — Devuelve la asignación de costo en el índice dado o nulo

Igualdad y código hash

La igualdad se basa en number y rechnungId (el ID de la factura padre). rechnungId es una propiedad abstracta implementada por las subclases concretas.

Notas de diseño

  • La propiedad info está marcada con @CandHIgnore para evitar que CandH (Copia e Historial) intente manejarla, ya que no siempre está inicializada.
  • Todas las propiedades mapeadas por JPA se declaran open para soportar proxies de carga diferida de Hibernate.
  • El método abstracto checkKostZuweisungId permite a las subclases validar que una asignación de costo pertenece a esta posición.
