Абстрактный базовый класс для сущностей позиций счетов в ProjectForge. Служит общим суперклассом как для позиций исходящих счетов (RechnungsPositionDO), так и для позиций входящих счетов (EingangsrechnungsPositionDO). Предоставляет общие поля, такие как номер позиции, текст, количество (menge), цена за единицу нетто (einzelNetto) и ставка НДС (vat), а также логику для управления назначениями затрат (KostZuweisungDO).

Иерархия классов

Расширяет DefaultBaseDO, реализует DisplayNameCapable и IRechnungsPosition. Аннотирован @MappedSuperclass, поэтому сам по себе не является таблицей базы данных — конкретные подклассы предоставляют собственные JPA-маппинги.

Управление назначениями затрат

Класс предоставляет методы для управления назначениями затрат KostZuweisungDO, привязанными к каждой позиции счета:

  • addKostZuweisung(kostZuweisung) — Добавляет назначение затрат с автоматически увеличивающимся индексом
  • deleteKostZuweisung(idx) — Удаляет назначение затрат по указанному индексу (удаление возможно только если оно ещё не сохранено, т.е. id == null)
  • ensureAndGetKostzuweisungen() — Возвращает изменяемый список, лениво инициализируя его, если он равен null
  • isKostZuweisungDeletable() — Защищает от удаления уже сохранённых назначений затрат
  • getKostZuweisung(idx) — Возвращает назначение затрат по указанному индексу или null

Равенство и HashCode

Равенство основано на number и rechnungId (идентификатор родительского счёта). rechnungId — это абстрактное свойство, реализуемое конкретными подклассами.

Замечания по дизайну

  • Свойство info помечено @CandHIgnore, чтобы предотвратить попытки CandH (Copy-and-History) обработать его, так как оно не всегда инициализировано.
  • Все JPA-маппированные свойства объявлены как open для поддержки прокси ленивой загрузки Hibernate.
  • Абстрактный метод checkKostZuweisungId позволяет подклассам проверять, принадлежит ли назначение затрат данной позиции.
