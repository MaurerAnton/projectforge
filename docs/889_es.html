Calculadora de estadísticas abstracta para facturas. Agrega métricas financieras en un conjunto de facturas (emitidas o recibidas): bruto (brutto), neto (netto), con descuento por pronto pago (bruttoMitSkonto), pagado (gezahlt), pendiente (offen), vencido (ueberfaellig) y montos de descuento (skonto). También realiza un seguimiento de los promedios de plazos de pago y proporciona salida con formato Markdown para la interfaz de usuario Wicket. Soporta conversión de múltiples monedas con seguimiento de advertencias.

Parámetro de tipo

T : AbstractRechnungDO? — El tipo de factura concreto (ej., RechnungDO o EingangsrechnungDO).

Método principal: add(rechnung: T)

El punto de entrada principal. Por cada factura agregada:

  1. Recupera la información de factura en caché mediante rechnungCache.getRechnungInfo(rechnung)
  2. Convierte todos los montos a la moneda configurada del sistema usando currencyConversionService.convert()
  3. Si la conversión de moneda falla para alguna factura, se acumula un mensaje de advertencia en currencyConversionWarnings y se usa el monto original (sin convertir) como respaldo
  4. Acumula montos brutos, netos, brutos con descuento, pagados, pendientes y vencidos
  5. Calcula el descuento por pronto pago (skonto) cuando el monto pagado es menor que el bruto
  6. Realiza un seguimiento de los promedios de plazos de pago: contractual (zahlungsZielSum) y real (tatsaechlichesZahlungsZiel)
  7. Detecta facturas vencidas mediante rechnungInfo.isUeberfaellig

Conversión de moneda

El método privado convertToSystemCurrency() maneja escenarios de múltiples monedas:

  • Omite la conversión si las monedas de origen y destino coinciden (sin distinción de mayúsculas/minúsculas)
  • Usa useFallbackToOldestRate = true para facturas históricas donde puede no existir un tipo de cambio exacto
  • Construye mensajes de advertencia para mostrar en el formato: "invoiceRef (fecha): USD → EUR"
  • Utiliza el monto original como respaldo cuando la conversión no está disponible

Dependencias del objeto complementario

El objeto complementario contiene referencias de servicio lateinit que deben establecerse externamente antes de su uso:

  • rechnungCache: RechnungCache — proporciona RechnungInfo para cada factura
  • currencyConversionService: CurrencyConversionService — maneja la conversión de montos en múltiples monedas
  • configurationService: ConfigurationService — proporciona la moneda predeterminada del sistema
