Calculateur abstrait de statistiques pour les factures. Agrège les indicateurs financiers d'un ensemble de factures (sortantes ou entrantes) : brut (brutto), net (netto), avec escompte (bruttoMitSkonto), payé (gezahlt), ouvert (offen), en retard (ueberfaellig) et montants d'escompte (skonto). Suit également les moyennes des délais de paiement et fournit une sortie formatée en Markdown pour l'affichage dans l'interface Wicket. Prend en charge la conversion multi-devises avec suivi des avertissements.

Paramètre de type

T : AbstractRechnungDO? — Le type concret de facture (par ex., RechnungDO ou EingangsrechnungDO).

Méthode principale : add(rechnung: T)

Le point d'entrée principal. Pour chaque facture ajoutée :

  1. Récupère les informations de facture mises en cache via rechnungCache.getRechnungInfo(rechnung)
  2. Convertit tous les montants dans la devise configurée du système à l'aide de currencyConversionService.convert()
  3. Si la conversion de devise échoue pour une facture, un message d'avertissement est accumulé dans currencyConversionWarnings et le montant d'origine (non converti) est utilisé comme solution de repli
  4. Accumule les montants brut, net, brut avec escompte, ainsi que les montants payés/ouverts/en retard
  5. Calcule l'escompte (skonto) lorsque le montant payé est inférieur au brut
  6. Effectue le suivi des moyennes des délais de paiement : contractuel (zahlungsZielSum) et réel (tatsaechlichesZahlungsZiel)
  7. Détecte les factures en retard via rechnungInfo.isUeberfaellig

Conversion de devise

La méthode privée convertToSystemCurrency() gère les scénarios multi-devises :

  • Ignore la conversion si les devises source et cible correspondent (insensible à la casse)
  • Utilise useFallbackToOldestRate = true pour les factures historiques où un taux de change exact peut ne pas exister
  • Construit des messages d'avertissement pour l'affichage au format : "invoiceRef (date) : USD → EUR"
  • Revient au montant d'origine lorsque la conversion n'est pas disponible

Dépendances de l'objet compagnon

L'objet compagnon contient des références de service lateinit qui doivent être définies de manière externe avant utilisation :

  • rechnungCache: RechnungCache — fournit RechnungInfo pour chaque facture
  • currencyConversionService: CurrencyConversionService — gère la conversion des montants multi-devises
  • configurationService: ConfigurationService — fournit la devise par défaut du système
