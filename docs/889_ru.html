Абстрактный калькулятор статистики для счетов. Агрегирует финансовые показатели по набору счетов (исходящих или входящих): валовая сумма (brutto), нетто (netto), с учётом скидки за наличный расчёт (bruttoMitSkonto), оплачено (gezahlt), открыто (offen), просрочено (ueberfaellig) и суммы скидок (skonto). Также отслеживает средние сроки оплаты и предоставляет вывод в формате Markdown для отображения в Wicket UI. Поддерживает мультивалютную конвертацию с отслеживанием предупреждений.

Параметр типа

T : AbstractRechnungDO? — Конкретный тип счёта (например, RechnungDO или EingangsrechnungDO).

Основной метод: add(rechnung: T)

Основная точка входа. Для каждого добавленного счёта:

  1. Извлекает кэшированную информацию о счете через rechnungCache.getRechnungInfo(rechnung)
  2. Конвертирует все суммы в валюту системы с помощью currencyConversionService.convert()
  3. Если конвертация валюты для какого-либо счёта не удалась, накапливается предупреждение в currencyConversionWarnings, и используется исходная (неконвертированная) сумма в качестве запасного варианта
  4. Накапливает валовую сумму, нетто, валовую сумму со скидкой, а также оплаченные/открытые/просроченные суммы
  5. Вычисляет скидку за наличный расчёт (skonto), когда оплаченная сумма меньше валовой
  6. Отслеживает средние сроки оплаты: договорные (zahlungsZielSum) и фактические (tatsaechlichesZahlungsZiel)
  7. Определяет просроченные счета через rechnungInfo.isUeberfaellig

Конвертация валюты

Приватный метод convertToSystemCurrency() обрабатывает мультивалютные сценарии:

  • Пропускает конвертацию, если исходная и целевая валюты совпадают (без учёта регистра)
  • Использует useFallbackToOldestRate = true для исторических счетов, для которых может не существовать точного обменного курса
  • Формирует предупреждающие сообщения для отображения в формате: "invoiceRef (дата): USD → EUR"
  • Использует исходную сумму в качестве запасного варианта, когда конвертация недоступна

Вычисляемые свойства

Зависимости объекта-компаньона

Объект-компаньон содержит ссылки на сервисы с lateinit, которые должны быть установлены извне перед использованием:

  • rechnungCache: RechnungCache — предоставляет RechnungInfo для каждого счёта
  • currencyConversionService: CurrencyConversionService — обрабатывает мультивалютную конвертацию сумм
  • configurationService: ConfigurationService — предоставляет валюту системы по умолчанию
