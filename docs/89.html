File #89: DataTransferAreaPagesRest.kt

Path: plugins/datatransfer/.../rest/DataTransferAreaPagesRest.kt · Source: GitHub

REST controller for data transfer area CRUD. Extends AbstractDTOPagesRest with JCR attachment support. Key features: (1) JCR integration via enableJcr() with DataTransferAccessChecker, (2) renew token/password endpoints, (3) list page with 12 columns including external access toggles and capacity, (4) edit page with admin/observer/access selectors, external sharing section (link + password + renew buttons), (5) validation: token format, password length ≥6, expiry day values, max upload size ≤ global upload size, (6) watch fields — auto-generates token/password when external access is enabled.
