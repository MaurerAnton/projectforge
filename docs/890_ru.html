Общий вспомогательный объект, предоставляющий построители критериев фильтрации базы данных и логику проверки, используемые как AuftragDao (заказы), так и RechnungDao (счета). Централизует общие шаблоны, такие как фильтрация по периоду выполнения, построение запросов с диапазоном дат и проверка при сохранении счета (расчет срока погашения, согласованность даты/суммы платежа).

Публичные методы

createCriterionForPeriodOfPerformance(myFilter)

Возвращает: Optional<DBPredicate>

Строит предикат для фильтрации по пересечению периода выполнения. Использует periodOfPerformanceStartDate и periodOfPerformanceEndDate фильтра. Логика проверяет пересечение диапазонов дат:

  • Обе даты заданы → popEnd >= startDate AND popBegin <= endDate
  • Только startDate → popEnd >= startDate
  • Только endDate → popBegin <= endDate
  • Ни одной → пусто

createQueryFilterWithDateRestriction(myFilter)

Возвращает: QueryFilter

Создает QueryFilter из RechnungFilter, добавляя ограничения по диапазону дат для поля "datum" (дата счета). Поддерживает фильтрацию от даты, до даты или обеих с использованием операторов between, ge и le.

onSaveOrModify(rechnung)

Параметр: AbstractRechnungDO

Основной метод проверки, вызываемый перед сохранением любого счета. Делегирует выполнение трем приватным вспомогательным методам:

  • checkAndCalculateFaelligkeit() — Автоматически вычисляет faelligkeit (срок погашения) из rechnungsDatum + zahlungsZielInTagen, но только если срок погашения равен null и установлен срок оплаты
  • checkAndCalculateDiscountMaturity() — Автоматически вычисляет discountMaturity из rechnungsDatum + discountZahlungsZielInTagen, только когда процент скидки не равен null/нулю и срок скидки равен null
  • validateBezahlDatumAndZahlBetrag() — Обеспечивает взаимную согласованность: если установлен bezahlDatum, то zahlBetrag должен быть установлен (и не равен нулю), и наоборот. Выбрасывает UserException с конкретными ключами i18n при нарушениях

Примечания по дизайну

  • Все методы помечены @JvmStatic для бесшовной совместимости с Java
  • Использует интерфейс SearchFilterWithPeriodOfPerformance для полиморфной обработки фильтров
  • Даты погашения вычисляются с помощью PFDateTime (для срока погашения) и PFDay (для срока скидки)
  • Срок скидки вычисляется только когда discountPercent не равен нулю; если ноль, срок скидки не устанавливается
