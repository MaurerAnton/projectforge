L'entité domaine principale représentant une commande (Auftrag) ou un devis (Angebot) dans le module de carnet de commandes de ProjectForge. Un devis peut être rejeté ou remplacé — il ne devient pas nécessairement une commande réelle. Tous les champs sont historisés, de sorte que les modifications capturent des informations précieuses telles que l'historique de commande (par exemple, LOI le 05/03/2022 par M. Müller, confirmation écrite le 04/04/2022 par les achats). Mappé à la table de base de données t_fibu_auftrag.
