Ein CustomResultFilter<AuftragDO>, der Aufträge basierend auf ihrem Rechnungsstatus filtert. Verwendet Enum-Werte von AuftragFakturiertFilterStatus, um zu bestimmen, welche Aufträge den Filter passieren. Gibt derzeit true für alle nicht ausgeschlossenen Status zurück, mit einer Warnmeldung, dass die vollständige Implementierung noch nicht abgeschlossen ist.

Klassendefinition

class AuftragFakturiertFilter(val values: List<AuftragFakturiertFilterStatus>) : CustomResultFilter<AuftragDO>

Übereinstimmungslogik

Die Methode match(list, element) gibt true zurück, wenn:

  • values leer ist, oder
  • values den Wert AuftragFakturiertFilterStatus.ALL enthält

Andernfalls wird ein Fehler protokolliert, dass der Filter "Noch nicht implementiert" ist, und es wird weiterhin true zurückgegeben. Die eigentliche Filterung nach Rechnungsstatus wird separat in AuftragFilter.filterFakturiert() behandelt.

Begleitobjekt-Factory

create(valuesAsStrings: Array<String>) wandelt ein Array von Zeichenfolgenrepräsentationen in eine AuftragFakturiertFilter-Instanz um, indem jede Zeichenfolge als Enum-Wert von AuftragFakturiertFilterStatus geparst wird. Ungültige Werte werden als Fehler protokolliert und stillschweigend ignoriert.
