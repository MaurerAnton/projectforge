Un CustomResultFilter<AuftragDO> que filtra pedidos según su estado de facturación. Utiliza los valores del enumerado AuftragFakturiertFilterStatus para determinar qué pedidos pasan el filtro. Actualmente devuelve true para todos los estados no excluidos, con un registro de advertencia de que la implementación completa aún no está terminada.

Definición de la clase

class AuftragFakturiertFilter(val values: List<AuftragFakturiertFilterStatus>) : CustomResultFilter<AuftragDO>

Lógica de coincidencia

El método match(list, element) devuelve true si:

  • values está vacío, o
  • values contiene AuftragFakturiertFilterStatus.ALL

De lo contrario, registra un error indicando que el filtro "aún no está implementado" y sigue devolviendo true. El filtrado real por estado de facturación se maneja por separado en AuftragFilter.filterFakturiert().

Fábrica del objeto complementario

create(valuesAsStrings: Array<String>) convierte un arreglo de representaciones de cadena en una instancia de AuftragFakturiertFilter analizando cada cadena como un valor del enumerado AuftragFakturiertFilterStatus. Los valores no válidos se registran como errores y se ignoran silenciosamente.
