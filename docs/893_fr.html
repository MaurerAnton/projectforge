Un CustomResultFilter<AuftragDO> qui filtre les commandes en fonction de leur statut de facturation. Utilise les valeurs de l'énumération AuftragFakturiertFilterStatus pour déterminer quelles commandes passent le filtre. Actuellement, retourne true pour tous les statuts non exclus, avec un avertissement indiquant que l'implémentation complète n'est pas encore terminée.

Définition de la classe

class AuftragFakturiertFilter(val values: List<AuftragFakturiertFilterStatus>) : CustomResultFilter<AuftragDO>

Logique de correspondance

La méthode match(list, element) retourne true si :

  • values est vide, ou
  • values contient AuftragFakturiertFilterStatus.ALL

Sinon, elle enregistre une erreur indiquant que le filtre n'est « Pas encore implémenté » et retourne toujours true. Le filtrage réel par statut de facturation est géré séparément dans AuftragFilter.filterFakturiert().

Fabrique d'objet compagnon

create(valuesAsStrings: Array<String>) convertit un tableau de représentations textuelles en une instance de AuftragFakturiertFilter en analysant chaque chaîne comme une valeur de l'énumération AuftragFakturiertFilterStatus. Les valeurs invalides sont enregistrées comme erreurs et ignorées silencieusement.
