CustomResultFilter<AuftragDO>, который фильтрует заказы на основе статуса их выставления счетов. Использует значения перечисления AuftragFakturiertFilterStatus для определения того, какие заказы проходят фильтр. В настоящее время возвращает true для всех неисключённых статусов с предупреждающим логом о том, что полная реализация ещё не завершена.

Определение класса

class AuftragFakturiertFilter(val values: List<AuftragFakturiertFilterStatus>) : CustomResultFilter<AuftragDO>

Логика соответствия

Метод match(list, element) возвращает true, если:

  • values пуст, или
  • values содержит AuftragFakturiertFilterStatus.ALL

В противном случае он записывает в лог ошибку о том, что фильтр «ещё не реализован», и всё равно возвращает true. Фактическая фильтрация по статусу выставления счетов обрабатывается отдельно в AuftragFilter.filterFakturiert().

Фабрика объекта-компаньона

create(valuesAsStrings: Array<String>) преобразует массив строковых представлений в экземпляр AuftragFakturiertFilter путём разбора каждой строки как значения перечисления AuftragFakturiertFilterStatus. Недопустимые значения записываются в лог как ошибки и молча игнорируются.
