Hauptsuchfilter für das Auftragsbuch. Erweitert BaseSearchFilter, implementiert Serializable und SearchFilterWithPeriodOfPerformance. Unterstützt das Filtern von Aufträgen nach Benutzerzuweisung, Datumsbereichen, Leistungszeitraum, Auftragsstatus, Positionstyp (AuftragsPositionsArt), Positionszahlungsart, Rechnungsstatus und Projektzugehörigkeit. Wird sowohl vom Backend-DAO für Datenbankabfragen als auch vom Frontend für programmatische Ergebnisfilterung über match() verwendet.

Match-Methoden (Programmatische Filterung)

match(auftrag): Boolean

Prüft, ob ein Auftrag alle aktiven Filter passiert. Auswertung in folgender Reihenfolge:

  1. matchUser — Benutzerzuweisung
  2. Erstellungsdatumsbereich (erfassungsDatum gegen startDate/endDate)
  3. Überlappung des Leistungszeitraums
  4. matchProjectList — Projektzugehörigkeit
  5. matchAuftragsStatus — Statusabgleich
  6. matchAuftragsPositionsArten — Positionsartabgleich

Kurzschluss: Gibt sofort false beim ersten nicht übereinstimmenden Kriterium zurück.

matchUser(auftrag): Boolean

Gibt true zurück, wenn der user des Filters null ist oder wenn die Benutzer-ID mit einer der folgenden übereinstimmt: projectManager.id, headOfBusinessManager.id, contactPerson.id oder salesManager.id.

matchProjectList(auftrag): Boolean

Gibt true zurück, wenn projectList null oder leer ist, oder wenn die projekt.id des Auftrags in der Liste gefunden wird.

matchAuftragsStatus(auftrag): Boolean

Gibt true zurück, wenn auftragsStatuses leer ist, oder wenn der status des Auftrags übereinstimmt, oder wenn der Status einer nicht gelöschten Position übereinstimmt.

matchAuftragsPositionsArten(auftrag): Boolean

Gibt true zurück, wenn auftragsPositionsArten leer ist, oder wenn eine nicht gelöschte Position eine passende art hat.

Filterung nach Rechnungsstatus

filterFakturiert(list): List<AuftragDO> — Filtert eine Ergebnisliste nach Rechnungsstatus unter Verwendung von AuftragsCache:
