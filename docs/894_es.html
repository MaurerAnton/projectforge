Filtro de búsqueda principal para el libro de pedidos (Auftragsbuch). Extiende BaseSearchFilter, implementa Serializable y SearchFilterWithPeriodOfPerformance. Soporta el filtrado de pedidos por asignación de usuario, rangos de fechas, período de ejecución, estado del pedido, tipo de posición (AuftragsPositionsArt), tipo de pago de posición, estado de facturación y pertenencia a proyecto. Se utiliza tanto por el DAO del backend para consultas a la base de datos como por el frontend para el filtrado programático de resultados mediante match().

Métodos de coincidencia (filtrado programático)

match(auftrag): Boolean

Comprueba si un pedido pasa todos los filtros activos. Evalúa en orden:

  1. matchUser — asignación de usuario
  2. Rango de fecha de creación (erfassungsDatum contra startDate/endDate)
  3. Superposición del período de ejecución
  4. matchProjectList — pertenencia a proyecto
  5. matchAuftragsStatus — coincidencia de estado
  6. matchAuftragsPositionsArten — coincidencia de tipo de posición

Cortocircuitos: devuelve false inmediatamente en el primer criterio que no coincida.

matchUser(auftrag): Boolean

Devuelve true si el user del filtro es null, o si el ID del usuario coincide con alguno de: projectManager.id, headOfBusinessManager.id, contactPerson.id o salesManager.id.

matchProjectList(auftrag): Boolean

Devuelve true si projectList es null o está vacía, o si el projekt.id del pedido se encuentra en la lista.

matchAuftragsStatus(auftrag): Boolean

Devuelve true si auftragsStatuses está vacía, o si el status del pedido coincide, o si el estado de alguna posición no eliminada coincide.

matchAuftragsPositionsArten(auftrag): Boolean

Devuelve true si auftragsPositionsArten está vacía, o si alguna posición no eliminada tiene un art coincidente.
