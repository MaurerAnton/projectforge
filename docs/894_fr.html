Filtre de recherche principal pour le livre des commandes (Auftragsbuch). Étend BaseSearchFilter, implémente Serializable et SearchFilterWithPeriodOfPerformance. Permet de filtrer les commandes par affectation d'utilisateur, plages de dates, période d'exécution, statut de la commande, type de poste (AuftragsPositionsArt), type de paiement du poste, statut de facturation et appartenance à un projet. Utilisé à la fois par le DAO backend pour les requêtes en base de données et par le frontend pour le filtrage programmatique des résultats via match().

Méthodes de correspondance (filtrage programmatique)

match(auftrag) : Boolean

Vérifie si une commande passe tous les filtres actifs. Évalue dans l'ordre :

  1. matchUser — affectation de l'utilisateur
  2. Plage de dates de création (erfassungsDatum par rapport à startDate/endDate)
  3. Chevauchement de la période d'exécution
  4. matchProjectList — appartenance au projet
  5. matchAuftragsStatus — correspondance du statut
  6. matchAuftragsPositionsArten — correspondance du type de poste

Court-circuits : retourne false immédiatement dès le premier critère non satisfait.

matchUser(auftrag) : Boolean

Retourne true si le user du filtre est null, ou si l'ID de l'utilisateur correspond à l'un des : projectManager.id, headOfBusinessManager.id, contactPerson.id, ou salesManager.id.

matchProjectList(auftrag) : Boolean

Retourne true si projectList est null ou vide, ou si le projekt.id de la commande se trouve dans la liste.

matchAuftragsStatus(auftrag) : Boolean

Retourne true si auftragsStatuses est vide, ou si le status de la commande correspond, ou si le statut d'un poste non supprimé correspond.

matchAuftragsPositionsArten(auftrag) : Boolean

Retourne true si auftragsPositionsArten est vide, ou si un poste non supprimé a un art correspondant.
