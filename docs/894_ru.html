Основной фильтр поиска для книги заказов (Auftragsbuch). Расширяет BaseSearchFilter, реализует Serializable и SearchFilterWithPeriodOfPerformance. Поддерживает фильтрацию заказов по назначению пользователя, диапазонам дат, периоду выполнения, статусу заказа, типу позиции (AuftragsPositionsArt), типу оплаты позиции, статусу выставления счета и членству в проекте. Используется как в бэкенд DAO для запросов к базе данных, так и во фронтенде для программной фильтрации результатов через match().

Методы сопоставления (программная фильтрация)

match(auftrag): Boolean

Проверяет, проходит ли заказ через все активные фильтры. Вычисляется по порядку:

  1. matchUser — назначение пользователя
  2. Диапазон дат создания (erfassungsDatum относительно startDate/endDate)
  3. Пересечение периода выполнения
  4. matchProjectList — членство в проекте
  5. matchAuftragsStatus — сопоставление статуса
  6. matchAuftragsPositionsArten — сопоставление типа позиции

Короткое замыкание: возвращает false немедленно при первом несовпадающем критерии.

matchUser(auftrag): Boolean

Возвращает true, если user фильтра равен null, или если ID пользователя совпадает с любым из: projectManager.id, headOfBusinessManager.id, contactPerson.id или salesManager.id.

matchProjectList(auftrag): Boolean

Возвращает true, если projectList равен null или пуст, или если projekt.id заказа найден в списке.

matchAuftragsStatus(auftrag): Boolean

Возвращает true, если auftragsStatuses пуст, или если status заказа совпадает, или если статус любой неудаленной позиции совпадает.

matchAuftragsPositionsArten(auftrag): Boolean

Возвращает true, если auftragsPositionsArten пуст, или если любая неудаленная позиция имеет совпадающий art.
