Énumération définissant comment les ventes de commandes sont réparties dans les prévisions. Lorsque les ventes d'une commande sont réparties, ce type détermine si les ventes sont facturées/prévues dans le mois en cours ou le mois suivant. La valeur par défaut est FOLLOWING_MONTH.
