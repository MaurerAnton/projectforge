Propósito: Proporciona acceso a base de datos de solo lectura de alto rendimiento para pedidos (AuftragDO), posiciones de pedido (AuftragsPositionDO) y calendarios de pago (PaymentScheduleDO) utilizando consultas nativas de tuplas JPQL. Evita la hidratación completa de entidades y la sobrecarga de carga diferida seleccionando solo las columnas necesarias para la representación de listas y la población de caché.

Arquitectura y Diseño

Declaración del Servicio

La clase está anotada con @Service y depende de PfPersistenceService mediante @Autowired. Todos los métodos usan runIsolatedReadOnly para ejecutar consultas en un contexto de persistencia nuevo, evitando la contaminación de la caché de sesión del llamante.

DependenciaTipoRol
PfPersistenceServiceFrameworkProporciona contextos JPA aislados de solo lectura para consultas rápidas de tuplas

Métodos

selectAuftragsList(): List<AuftragDO>

Devuelve todos los pedidos (incluyendo eliminados) con un conjunto de columnas seleccionadas. Mapea cada Tuple a un AuftragDO parcialmente poblado usando los helpers getter de TupleUtils. Las claves foráneas (kundeId, projektId, contactPersonId) se resuelven mediante em.getReference() para evitar consultas adicionales — Hibernate devuelve un proxy perezoso sin acceder a la base de datos.

selectNonDeletedAuftragsPositions(): List<AuftragsPositionDO>

Devuelve posiciones de pedido no eliminadas. Patrón de mapeo de tuplas similar con una optimización de rendimiento adicional: bemerkung (comentario) se abrevia a 30 caracteres mediante abbreviate(30), reduciendo la huella de memoria para las vistas de lista. La referencia de tarea (taskId) crea un stub TaskDO con solo el ID establecido.

selectNonDeletedPaymentSchedules(): List<PaymentScheduleDO>

Devuelve calendarios de pago no eliminados, creando objetos AuftragDO stub (solo ID) para la referencia de clave foránea auftragId.

Definiciones de Consultas (Objeto Compañero)

Tres consultas JPQL se definen como constantes private val en el objeto compañero, usando interpolación ${AuftragDO::class.simpleName} para referencias de entidad seguras en cuanto a tipos:

ConstanteEntidad DestinoFiltro
SELECT_ORDERSAuftragDONinguno (todos los registros, incluidos eliminados)
SELECT_POSITIONSAuftragsPositionDOWHERE deleted = false
SELECT_PAYMENTS_SCHEDULESPaymentScheduleDOWHERE deleted = false

Estrategia de Rendimiento

  • Las consultas de tuplas seleccionan solo las columnas necesarias; no se cargan grafos de entidad completos.
  • em.getReference() crea proxies perezosos para asociaciones FK, evitando JOINs.
  • runIsolatedReadOnly asegura que cada llamada tenga un contexto de persistencia limpio, evitando interferencias con la transacción activa del llamante.
  • La llamada abbreviate(30) en bemerkung minimiza la presión del montón para campos de comentarios grandes durante la representación de listas.
