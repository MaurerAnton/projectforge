Назначение: Обеспечивает высокопроизводительный доступ к базе данных только для чтения для заказов (AuftragDO), позиций заказов (AuftragsPositionDO) и графиков платежей (PaymentScheduleDO) с использованием нативных JPQL-запросов кортежей. Избегает полной гидратации сущностей и накладных расходов на ленивую загрузку, выбирая только столбцы, необходимые для отображения списков и заполнения кэша.

Архитектура и дизайн

Объявление сервиса

Класс аннотирован @Service и зависит от PfPersistenceService через @Autowired. Все методы используют runIsolatedReadOnly для выполнения запросов в новом контексте персистентности, предотвращая загрязнение кэша сессии вызывающего кода.

ЗависимостьТипРоль
PfPersistenceServiceФреймворкПредоставляет изолированные JPA-контексты только для чтения для быстрых запросов кортежей

Методы

selectAuftragsList(): List<AuftragDO>

Возвращает все заказы (включая удалённые) с подобранным набором столбцов. Преобразует каждый Tuple в частично заполненный AuftragDO с помощью вспомогательных методов получения TupleUtils. Внешние ключи (kundeId, projektId, contactPersonId) разрешаются через em.getReference(), чтобы избежать дополнительных запросов — Hibernate возвращает ленивый прокси без обращения к базе данных.

selectNonDeletedAuftragsPositions(): List<AuftragsPositionDO>

Возвращает неудалённые позиции заказов. Аналогичный шаблон преобразования кортежей с дополнительной оптимизацией производительности: bemerkung (комментарий) сокращается до 30 символов через abbreviate(30), уменьшая потребление памяти для представлений списков. Ссылка на задачу (taskId) создаёт заглушку TaskDO только с установленным ID.

selectNonDeletedPaymentSchedules(): List<PaymentScheduleDO>

Возвращает неудалённые графики платежей, создавая объекты-заглушки AuftragDO (только ID) для ссылки внешнего ключа auftragId.

Определения запросов (объект-компаньон)

Три JPQL-запроса определены как private val константы в объекте-компаньоне, с использованием интерполяции ${AuftragDO::class.simpleName} для типобезопасных ссылок на сущности:

КонстантаЦелевая сущностьФильтр
SELECT_ORDERSAuftragDOНет (все записи, включая удалённые)
SELECT_POSITIONSAuftragsPositionDOWHERE deleted = false
SELECT_PAYMENTS_SCHEDULESPaymentScheduleDOWHERE deleted = false

Стратегия производительности

  • Запросы кортежей выбирают только необходимые столбцы; полные графы сущностей не загружаются.
  • em.getReference() создаёт ленивые прокси для ассоциаций внешних ключей, избегая JOIN'ов.
  • runIsolatedReadOnly гарантирует, что каждый вызов имеет чистый контекст персистентности, предотвращая вмешательство в активную транзакцию вызывающего кода.
  • Вызов abbreviate(30) для bemerkung минимизирует нагрузку на кучу для больших полей комментариев при отображении списков.

Связанные классы

  • Потребляется: AuftragsCache — использует эти результаты кортежей для построения кэша книги заказов в памяти
  • Использует: TupleUtils — типобезопасные аксессоры столбцов кортежей (getLong, getString, getBigDecimal и т.д.)
  • Использует: PfPersistenceService — абстракция персистентности фреймворка
