Перечисление из трёх значений, которое классифицирует заказы/позиции по бизнес-категориям: POTENTIAL (фаза привлечения), COMMISSIONED (подтверждён/заказан) или LOST (проигран). Используется для сводной статистики в книге заказов и прогнозных представлениях. Переименовано из "ORDERED" в "COMMISSIONED" для лучшего отражения бизнес-терминологии.

Значения перечисления

ЗначениеСмысл
POTENTIALЗаказ/позиция находится в фазе привлечения/воронки — ещё не подтверждён
COMMISSIONEDЗаказ/позиция официально поручен/заказан клиентом
LOSTЗаказ/позиция не был выигран

Методы

  • isIn(vararg state: AuftragsOrderState): Boolean — проверяет, соответствует ли это значение любому из заданных состояний. Используется в условной логике при обработке заказов.
