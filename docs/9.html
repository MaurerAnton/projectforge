What it does

This is the landing page for the doc/ directory. When someone opens doc/ on GitHub, the GitHub AsciiDoc renderer automatically displays this file as the directory entry point (similar to how README.md works for the root directory).

It links to three documents: installation, development, and the GPLv3 license. Two of them are redirects (see file #8), one contains the actual license text.
