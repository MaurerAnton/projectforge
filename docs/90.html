File #90: DataTransferAttachmentsActionListener.kt

Path: plugins/datatransfer/.../rest/DataTransferAttachmentsActionListener.kt · Source: GitHub

Listener that updates the data transfer area's capacity statistics after file uploads. Extends AttachmentsActionListener — on attachment events (upload/delete), fetches the fresh DB version of the area and returns a DataTransferArea DTO with updated attachmentsSize, attachmentsCounter, and capacity display. Also provides download filename using displayName.
