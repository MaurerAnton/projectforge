projectforge-business/src/main/kotlin/org/projectforge/business/fibu/AuftragsPositionsArtFilter.kt Type : Implémentation de CustomResultFilter · Objectif : Filtre les commandes par type de classification de position · Paquetage : org.projectforge.business.fibu

Un CustomResultFilter<AuftragDO> qui filtre les commandes lorsqu'au moins une de leurs positions (non supprimées) possède un AuftragsPositionsArt correspondant à l'une des valeurs de filtre configurées. Une liste de valeurs vide correspond à toutes les commandes. Construction basée sur des chaînes avec journalisation gracieuse des erreurs pour les noms d'énumération invalides.

Logique de filtrage

  • Si values est vide → correspond à toutes les commandes (return true)
  • Sinon → parcourt element.positionenExcludingDeleted et retourne true si l'art d'une position est contenu dans l'ensemble de valeurs du filtre

Objet compagnon

create(valuesAsStrings: Array<String>) — analyse un tableau de chaînes en valeurs d'énumération AuftragsPositionsArt, en journalisant et en ignorant les entrées inconnues via KotlinLogging.
