Реализация CustomResultFilter<AuftragDO>, которая сопоставляет заказы, если хотя бы одна из их (неудалённых) позиций имеет AuftragsPositionsArt, соответствующий одному из настроенных значений фильтра. Пустой список значений сопоставляется со всеми заказами. Конструктор на основе строк с корректным логированием ошибок для недопустимых имён перечислений.

Логика фильтра

  • Если values пуст → сопоставляются все заказы (return true)
  • В противном случае → перебирает element.positionenExcludingDeleted и возвращает true, если art любой позиции содержится в наборе значений фильтра

Объект-компаньон

create(valuesAsStrings: Array<String>) — разбирает массив строк в значения перечисления AuftragsPositionsArt, логируя и пропуская неизвестные записи через KotlinLogging.
