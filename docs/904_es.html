Un CustomResultFilter<AuftragDO> que coincide con pedidos cuando al menos una de sus posiciones (no eliminadas) tiene un AuftragsPositionsPaymentType que coincide con uno de los valores de filtro configurados. Una lista de valores vacía coincide con todos los pedidos. Ofrece dos métodos de fábrica: uno a partir de un único valor enum, otro a partir de un arreglo de cadenas con análisis tolerante a errores.

Lógica del filtro

  • Si values está vacío → coincide con todos los pedidos
  • Itera element.positionenExcludingDeleted, devuelve true si el paymentType de alguna posición coincide con un valor de filtro

Objeto complementario

  • create(value: AuftragsPositionsPaymentType?) (@JvmStatic) — envuelve un único valor enum; entrada nula produce un filtro de paso directo
  • create(valuesAsStrings: Array<String>) — analiza un arreglo de cadenas, registra valores desconocidos, devuelve filtro con el conjunto enum coincidente
