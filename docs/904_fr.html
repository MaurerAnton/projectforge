Un CustomResultFilter<AuftragDO> qui filtre les commandes lorsqu'au moins une de leurs positions (non supprimées) possède un AuftragsPositionsPaymentType correspondant à l'une des valeurs de filtre configurées. Une liste de valeurs vide correspond à toutes les commandes. Propose deux méthodes d'usine : une à partir d'une seule valeur d'énumération, une à partir d'un tableau de chaînes avec analyse tolérante aux erreurs.

Logique de filtrage

  • Si values est vide → correspond à toutes les commandes
  • Parcourt element.positionenExcludingDeleted, renvoie true si le paymentType d'une position correspond à une valeur de filtre

Objet compagnon

  • create(value: AuftragsPositionsPaymentType?) (@JvmStatic) — encapsule une seule valeur d'énumération ; une entrée nulle produit un filtre de passage
  • create(valuesAsStrings: Array<String>) — analyse un tableau de chaînes, enregistre les valeurs inconnues, renvoie un filtre avec l'ensemble d'énumérations correspondant
