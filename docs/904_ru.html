Реализация CustomResultFilter<AuftragDO>, которая сопоставляет заказы, если хотя бы одна из их (неудалённых) позиций имеет AuftragsPositionsPaymentType, соответствующий одному из настроенных значений фильтра. Пустой список значений сопоставляет все заказы. Предлагает два фабричных метода: один из одного значения перечисления, другой из массива строк с устойчивым к ошибкам парсингом.

Логика фильтра

  • Если values пуст → сопоставляет все заказы
  • Перебирает element.positionenExcludingDeleted, возвращает true, если paymentType любой позиции соответствует значению фильтра

Объект-компаньон

  • create(value: AuftragsPositionsPaymentType?) (@JvmStatic) — оборачивает одно значение перечисления; null на входе создаёт сквозной фильтр
  • create(valuesAsStrings: Array<String>) — парсит массив строк, логирует неизвестные значения, возвращает фильтр с набором сопоставленных перечислений
