Путь к исходнику: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/AuftragsPositionsStatusFilter.kt 57 строк · 30 кода · 22 комментария · 5 пустых
Реализация CustomResultFilter<AuftragDO>, которая сопоставляет заказы, если хотя бы одна из их (неудалённых) позиций имеет AuftragsStatus, соответствующий одному из заданных значений фильтра. Пустой список значений соответствует всем заказам. Конструктор на основе строк с устойчивым к ошибкам парсингом и логированием неизвестных названий статусов.

Логика фильтрации

  • Если values пуст → соответствует всем заказам
  • Перебирает element.positionenExcludingDeleted, возвращает true, если status любой позиции содержится в значениях фильтра

Объект-компаньон

create(valuesAsStrings: Array<String>) — преобразует массив строк в значения перечисления AuftragsStatus, логируя неизвестные записи. Статусы, которые могут быть сопоставлены, включают полный жизненный цикл AuftragsStatus: POTENZIAL, IN_ERSTELLUNG, GELEGT, LOI, BEAUFTRAGT, ESKALATION, ABGESCHLOSSEN и ABGELEHNT.
