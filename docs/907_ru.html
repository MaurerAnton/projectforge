Класс-аккумулятор, реализующий Serializable, который суммирует денежные значения и подсчитывает количество по нескольким экземплярам AuftragDO. Используется в книге заказов и представлениях прогнозов для отображения агрегированных показателей воронки. Делегирует расчёт по каждому заказу методу AuftragsCache.getOrderInfo(), который возвращает объект OrderInfo с предварительно вычисленными суммами. Предоставляет отдельные сводки по категориям: привлечение (потенциал), заказы в работе, выставленные счета, ещё не выставленные счета и подлежащие выставлению, а также соответствующие счётчики.

Инициализация

Все суммы инициализируются значением BigDecimal.ZERO, а все счётчики — значением 0 в блоке init.

Основной метод: add(auftrag: AuftragDO)

Для каждого заказа получает OrderInfo через WicketSupport.get(AuftragsCache::class.java).getOrderInfo(auftrag). OrderInfo содержит предварительно вычисленные разбивки (akquiseSum, commissionedNetSum, notYetInvoicedSum, toBeInvoicedSum, invoicedSum, netSum). Для каждой суммы > BigDecimal.ZERO аккумулятор статистики увеличивает соответствующий счётчик и добавляет сумму с помощью NumberHelper.add() (безопасное сложение BigDecimal, обрабатывающее null-значения).

Расчётная семантика

  • notYetInvoicedSum — представляет открытые суммы: общая сумма нетто минус уже выставленные счета. Это сумма, которая ещё должна быть выставлена.
  • toBeInvoiced — более узкое подмножество: только заказы со статусом ABGESCHLOSSEN (завершён), но ещё не vollstaendigFakturiert (полностью выставлены) или с недостигнутыми графиками платежей. Представляет кандидатов для немедленного выставления счёта.
  • akquiseSum — по заказам в статусах воронки (POTENZIAL, IN_ERSTELLUNG, GELEGT)
  • beauftragtSum — по заказам, которые фактически поручены (LOI, BEAUFTRAGT, ESKALATION)

Сериализация

Реализует Serializable с serialVersionUID = -5486964211679100585L для сериализации страниц Wicket. Модификатор private set для всех полей обеспечивает доступ на чтение извне, предотвращая прямое изменение (только метод add() изменяет состояние).
