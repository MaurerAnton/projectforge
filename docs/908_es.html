Enumera los estados del ciclo de vida de un Auftrag (pedido/proyecto) en el módulo de contabilidad financiera (Fibu). Cada estado se asigna a un AuftragsOrderState agregado para fines de informes y filtrado. Implementa I18nEnum para etiquetas de visualización internacionalizadas.

Diseño

Integración i18n

Cada estado tiene una propiedad key utilizada para construir la clave i18n completa como "fibu.auftrag.status.{key}".

Objeto Compañero

safeValueOf(nombre) busca de forma segura una constante de enum por nombre, devolviendo null si no se encuentra en lugar de lanzar una excepción.

Métodos de Conveniencia

  • isIn(vararg estado) — comprueba si este estado está entre el conjunto dado.
  • isNotIn(vararg estado) — forma negada de isIn.

Agregación de Estado del Pedido

La propiedad calculada orderState asigna los estados en tres grupos:

  • POTENCIAL — preventas / pipeline
  • COMISIONADO — activo o completado
  • PERDIDO — rechazado o reemplazado
