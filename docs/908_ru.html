Перечисляет состояния жизненного цикла Auftrag (заказ/проект) в модуле финансового учёта (Fibu). Каждый статус сопоставляется с агрегированным AuftragsOrderState для отчётов и фильтрации. Реализует I18nEnum для интернационализированных отображаемых меток.

Дизайн

Интеграция i18n

Каждый статус имеет свойство key, используемое для построения полного i18n-ключа как "fibu.auftrag.status.{key}".

Объект-компаньон

safeValueOf(name) безопасно ищет константу перечисления по имени, возвращая null, если не найдено, вместо выбрасывания исключения.

Удобные методы

  • isIn(vararg status) — проверяет, входит ли данный статус в указанный набор.
  • isNotIn(vararg status) — отрицательная форма isIn.

Агрегация состояний заказа

Вычисляемое свойство orderState группирует статусы в три категории:

  • POTENTIAL — предпродажи / воронка
  • COMMISSIONED — активные или завершённые
  • LOST — отклонённые или заменённые
