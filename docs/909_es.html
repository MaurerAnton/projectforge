Un caché en memoria para pares de divisas y sus tasas de conversión. Extiende AbstractCache, implementando el patrón de caché de ProjectForge con actualización diferida. También actúa como un BaseDOModifiedListener para CurrencyPairDO para invalidar el caché en inserciones/actualizaciones. Proporciona búsqueda bidireccional de tasas con cálculo automático de tasa inversa.

Arquitectura

Herencia e Interfaces

  • AbstractCache — proporciona checkRefresh()/refresh()/setExpired()
  • BaseDOModifiedListener<CurrencyPairDO> — invalida el caché cuando los pares de divisas cambian

Estructuras de Datos Internas

Estrategia de Actualización

El método refresh() se ejecuta dentro de una transacción de solo lectura a través de persistenceService.runIsolatedReadOnly(). Carga todas las entradas CurrencyPairDO no eliminadas y todas sus tasas no eliminadas (ordenadas por validFrom DESC). Las tasas se agrupan por id del par de divisas y se asignan a la lista transitoria rates del par.

Búsqueda de Tasa Inversa

findCurrencyPairForConversion(source, target) primero intenta una búsqueda directa (ej. EUR→USD). Si no se encuentra, intenta la dirección inversa (USD→EUR) y devuelve un CurrencyPairLookup con useInverseRate=true, indicando al llamante que use 1/tasa.

Respaldo a la Tasa Más Antigua

findActiveRate() con useFallbackToOldestRate=true registrará una advertencia y devolverá la tasa más antigua disponible cuando ninguna tasa sea válida para la fecha solicitada. Esto está explícitamente documentado como potencialmente no conforme para la contabilidad financiera.

Ciclo de Vida

  1. @PostConstruct: se registra con currencyPairDao como oyente y almacena el singleton en el objeto complementario.
  2. En el primer acceso al caché a través de cualquier método público, checkRefresh() activa refresh().
  3. Cuando se modifica un CurrencyPairDO, afterInsertOrModify() llama a setExpired().
  4. Todas las operaciones a nivel de tasa (en CurrencyConversionServiceSupport) también llaman a cache.setExpired() directamente.
