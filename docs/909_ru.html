Кэш в памяти для валютных пар и их курсов конвертации. Расширяет AbstractCache, реализуя шаблон кэширования ProjectForge с ленивым обновлением. Также выступает в роли BaseDOModifiedListener для CurrencyPairDO, чтобы инвалидировать кэш при вставках/обновлениях. Предоставляет двунаправленный поиск курса с автоматическим вычислением обратного курса.

Архитектура

Наследование и интерфейсы

  • AbstractCache — предоставляет checkRefresh()/refresh()/setExpired()
  • BaseDOModifiedListener<CurrencyPairDO> — инвалидирует кэш при изменении валютных пар

Стратегия обновления

Метод refresh() выполняется в транзакции только для чтения через persistenceService.runIsolatedReadOnly(). Он загружает все неудалённые записи CurrencyPairDO и все их неудалённые курсы (отсортированные по validFrom DESC). Курсы группируются по id валютной пары и присваиваются временному списку rates пары.

Поиск обратного курса

findCurrencyPairForConversion(source, target) сначала пытается выполнить прямой поиск (например, EUR→USD). Если не найдено, он пробует обратное направление (USD→EUR) и возвращает CurrencyPairLookup с useInverseRate=true, сигнализируя вызывающему коду использовать 1/rate.

Запасной вариант на самый старый курс

findActiveRate() с useFallbackToOldestRate=true запишет предупреждение и вернёт самый старый доступный курс, если ни один курс не действителен для запрошенной даты. Это явно задокументировано как потенциально несоответствующее требованиям финансового учёта.

Жизненный цикл

  1. @PostConstruct: регистрирует себя в currencyPairDao как слушатель и сохраняет синглтон в сопутствующем объекте.
  2. При первом обращении к кэшу через любой публичный метод checkRefresh() запускает refresh().
  3. Когда CurrencyPairDO изменяется, afterInsertOrModify() вызывает setExpired().
  4. Все операции на уровне курсов (в CurrencyConversionServiceSupport) также напрямую вызывают cache.setExpired().
