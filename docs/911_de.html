Der öffentlich zugängliche Service für Währungsumrechnungsoperationen. Delegiert Datenbank-Lese-/Schreiboperationen an CurrencyConversionServiceSupport und das Caching an CurrencyConversionCache. Bietet eine übergeordnete convert()-Methode, die in einem einzigen Aufruf die No-Op bei gleicher Währung, die bidirektionale Paarsuche, den Kursabruf und die Multiplikation behandelt. Stellt über das Companion-Objekt ein statisches Singleton bereit.

Architektur

Abhängigkeiten

AbhängigkeitRolle
CurrencyPairDaoZugriffskontrolle und Währungspaarsuche für Kurs-CRUD
CurrencyConversionCacheIm-Cache-Suche von Paaren, Kursen und aktiven Kursdaten im Arbeitsspeicher
CurrencyConversionServiceSupportInterne Datenbankoperationen (finden, einfügen, aktualisieren, löschen, validieren)
ConfigurationServiceStellt die systemweite Standardwährung bereit (z. B. "EUR")

Methodenkategorien

Kursabfrage-Operationen

MethodeBeschreibung
findRate(id)Findet einen einzelnen Kurs anhand der ID, delegiert an die Support-Klasse
selectAllRates(pairId)Listet Kurse auf; verwendet den Cache für aktive, die DB für gelöschte Kurse
getConversionRate(pair, date)Ermittelt den numerischen Kursfaktor für ein Paar zu einem Datum
getConversionRateDate(pair, date)Ermittelt das Gültig-von-Datum des aktiven Kurses

Umrechnung

MethodeBeschreibung
convert(betrag, ziel, quelle?, datum?, skala?, rundung?)Kernmethode. Rechnet einen Betrag zwischen Währungen um. Bei gleicher Währung unverändert. Verwendet die systemweite Standardwährung, wenn sourceCurrency null ist. Unterstützt konfigurierbare Skalierung und Rundungsmodus. Fällt optional auf den ältesten Kurs zurück (mit Compliance-Hinweisen).

Kurs-CRUD-Operationen

MethodeBeschreibung
validateRate(kurs)Validiert die Eindeutigkeit; gibt eine Fehlermeldung als String oder null zurück
insertRate(pairId, kurs)Fügt einen neuen Kurs für ein Währungspaar ein
updateRate(pairId, kurs)Aktualisiert einen vorhandenen Kurs
markRateAsDeleted(pairId, kursId)Löscht einen Kurs per Soft-Delete

Umrechnungsablauf

  1. Null-/Leer-Prüfungen für betrag und zielWährung
  2. Ermittlung der effektiven Quellwährung (Parameter oder Systemstandard)
  3. Prüfung auf gleiche Währung: Betrag unverändert mit angewandter Skalierung zurückgeben
  4. Bidirektionale Paarsuche via cache.findCurrencyPairForConversion()
  5. Kurs aus dem Cache abrufen (Inverse anwenden, wenn die Suche das umgekehrte Paar gefunden hat)
  6. betrag * kurs → skalieren mit Rundungsmodus

Lebenszyklus

@PostConstruct speichert das Singleton in Companion.instance für den statischen Zugriff durch andere Dienste (z. B. statistische Berechnungen).
