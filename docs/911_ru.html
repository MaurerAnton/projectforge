Публичный сервис для операций конвертации валют. Делегирует операции чтения/записи в БД классу CurrencyConversionServiceSupport, а кэширование — CurrencyConversionCache. Предоставляет высокоуровневый метод convert(), который обрабатывает холостой вызов для одной валюты, двунаправленный поиск пары, получение курса и умножение за один вызов. Предоставляет статический синглтон через объект-компаньон.

Конвертация

МетодОписание
convert(amount, target, source?, date?, scale?, rounding?)Основной метод. Конвертирует сумму между валютами. Для одной валюты возвращает без изменений. Использует валюту системы по умолчанию, если sourceCurrency равен null. Поддерживает настраиваемый масштаб и режим округления. Опционально использует самый старый курс (с оговорками о соответствии требованиям).

Процесс конвертации

  1. Проверка amount и targetCurrency на null/пустое значение
  2. Определение фактической исходной валюты (параметр или системная по умолчанию)
  3. Проверка на одну валюту: возврат суммы без изменений с применением масштаба
  4. Двунаправленный поиск пары через cache.findCurrencyPairForConversion()
  5. Получение курса из кэша (с применением инверсии, если найдена обратная пара)
  6. amount * rate → масштабирование с режимом округления

Жизненный цикл
