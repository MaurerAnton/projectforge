Repräsentiert ein Währungspaar für den Devisenumrechnung (z. B. USD → EUR). Jedes Paar verknüpft eine Quellwährung mit einer Zielwährung. Das Paar selbst enthält keine Umrechnungskurse – diese werden von untergeordneten CurrencyConversionRateDO-Entitäten mit Gültigkeitszeiträumen verwaltet. Eine transiente rates-Liste wird von CurrencyConversionCache für den speicherinternen Zugriff befüllt.

Gleichheit

equals() und hashCode() wurden überschrieben, um das id-Feld zu verwenden. Wenn die ID null ist, wird auf die DefaultBaseDO-Implementierung zurückgegriffen.

Zugriffskontrolle

Mit @AUserRightId("FIBU_CURRENCY_CONVERSION") annotiert, verknüpft diese Entität mit dem Benutzerrecht FIBU_CURRENCY_CONVERSION für Zugriffskontrollprüfungen in der gesamten Persistenzschicht.
