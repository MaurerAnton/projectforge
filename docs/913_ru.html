Представляет валютную пару для конвертации иностранной валюты (например, USD → EUR). Каждая пара связывает исходную валюту с целевой валютой. Сама пара не содержит курсов конвертации — они хранятся в дочерних сущностях CurrencyConversionRateDO с периодами действия. Транзиентный список rates заполняется CurrencyConversionCache для доступа в памяти.

Наследование и интерфейсы

  • DefaultBaseDO — предоставляет стандартные поля DO (pk, created, lastUpdate, deleted и т.д.)
  • DisplayNameCapable — предоставляет displayName в формате "USD → EUR"

Равенство

equals() и hashCode() переопределены для использования поля id. Если id равен null, используется реализация DefaultBaseDO.

Контроль доступа

Аннотировано @AUserRightId("FIBU_CURRENCY_CONVERSION"), что связывает эту сущность с правом пользователя FIBU_CURRENCY_CONVERSION для проверок контроля доступа на уровне персистентности.
