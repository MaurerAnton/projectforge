DAO для сущностей CurrencyPairDO. Расширяет BaseDao<CurrencyPairDO>, наследуя стандартные CRUD-операции, контроль доступа и поиск. Предоставляет объединённую историю, также загружая записи истории из дочерних записей CurrencyConversionRateDO.

Архитектура

Наследование

  • BaseDao<CurrencyPairDO> — стандартный DAO с фильтрацией, сортировкой, историей, проверками доступа

Зависимости

ЗависимостьРоль
CurrencyConversionServiceИспользуется в addOwnHistoryEntries() для загрузки всех дочерних курсов для объединения истории

Сортировка по умолчанию

По sourceCurrency, затем по targetCurrency.

Автодополнение

Включено для полей sourceCurrency и targetCurrency (трёхбуквенные коды валют).

Объединение истории

addOwnHistoryEntries() перебирает все дочерние записи CurrencyConversionRateDO (включая удалённые) и объединяет их историю в контекст истории родительской записи. Это обеспечивает единую аудиторскую цепочку, показывающую изменения как на уровне пары, так и на уровне курса.

Контроль доступа

Защищён с помощью UserRightId.FIBU_CURRENCY_CONVERSION, установленного в init.

Фабрика

newInstance() возвращает пустой CurrencyPairDO().
