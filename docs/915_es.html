Un caché dedicado para facturas entrantes (Eingangsrechnungen). Extiende AbstractRechnungCache con EingangsrechnungDO como tipo de entidad. Existe como un caché separado de RechnungCache (facturas salientes) para aislamiento de rendimiento — los datos de facturas entrantes y salientes se pueden almacenar en caché y actualizar de forma independiente.

Arquitectura

Herencia

AbstractRechnungCache(EingangsrechnungDO::class, rechnungJdbcService) — hereda toda la lógica de caché de la clase base abstracta compartida.

Dependencias

DependenciaRol
RechnungJdbcServiceProporciona carga de caché basada en JDBC para datos de facturas (información de pago, fechas de vencimiento, etc.)

Visibilidad

Marcado como internal — no está destinado para uso fuera del paquete fibu. Se accede a través de EingangsrechnungDao mediante métodos de AbstractRechnungCache como getEingangsrechnungInfo() y ensureRechnungInfo().

Propósito

El caché separado proporciona:

  • Aislamiento de rendimiento: el caché de facturas entrantes se puede actualizar independientemente de las facturas salientes.
  • Seguridad de tipos: el parámetro de tipo EingangsrechnungDO asegura que las entradas del caché estén limitadas a facturas entrantes.
  • Almacenamiento en caché del estado de pago: almacena objetos RechnungInfo precalculados con estado de pago (pagado, vencido, pendiente).
