Un cache dédié pour les factures entrantes (Eingangsrechnungen). Étend AbstractRechnungCache avec EingangsrechnungDO comme type d'entité. Existe en tant que cache séparé de RechnungCache (factures sortantes) pour l'isolation des performances — les données des factures entrantes et sortantes peuvent être mises en cache et actualisées indépendamment.

Architecture

Héritage

AbstractRechnungCache(EingangsrechnungDO::class, rechnungJdbcService) — hérite de toute la logique de cache de la classe de base abstraite partagée.

Dépendances

DépendanceRôle
RechnungJdbcServiceFournit le chargement du cache basé sur JDBC pour les données des factures (informations de paiement, dates d'échéance, etc.)

Visibilité

Marqué internal — non destiné à être utilisé en dehors du paquetage fibu. Accédé via le EingangsrechnungDao par les méthodes de AbstractRechnungCache comme getEingangsrechnungInfo() et ensureRechnungInfo().

Objectif

Le cache séparé fournit :

  • Isolation des performances : le cache des factures entrantes peut être actualisé indépendamment de celui des factures sortantes.
  • Sécurité de type : le paramètre de type EingangsrechnungDO garantit que les entrées du cache sont limitées aux factures entrantes.
  • Mise en cache du statut de paiement : stocke des objets RechnungInfo précalculés avec le statut de paiement (payé, en retard, impayé).
