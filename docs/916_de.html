Stellt eine Eingangsrechnung dar – eine von einem Gläubiger erhaltene Rechnung. Erweitert AbstractRechnungDO und erbt allgemeine Rechnungsfelder (Datum, Netto-/Bruttobeträge, Zahlungsinformationen, Status). Fügt eingangsspezifische Felder wie Gläubigerdetails, Bankkontoinformationen (IBAN/BIC) und eine gläubigerseitige Referenznummer hinzu. Die Entität wird von Hibernate Search indiziert und implementiert Comparable für die Sortierung.

Positionsverwaltung

Erbt von AbstractRechnungDO und spezialisiert die Positionsliste als MutableList<EingangsrechnungsPositionDO>, annotiert mit:

  • @JsonManagedReference — JSON-Serialisierung, Elternseite der bidirektionalen Beziehung
  • @SoftDeleteCollection — Unterstützung für weiches Löschen von Positionen
  • @PersistenceBehavior(autoUpdateCollectionEntries = true) — Hibernate-Kaskadierung für Kindeinträge
  • @OneToMany(mappedBy = "eingangsrechnung", cascade = PERSIST, MERGE, REFRESH, DETACH) — keine REMOVE-Kaskade (orphanRemoval = false)
  • @OrderColumn(name = "number") / @ListIndexBase(1) — 1-basierte Positionsnummerierung
