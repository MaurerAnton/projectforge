Representa una factura de entrada (Eingangsrechnung) — una factura recibida de un acreedor. Extiende AbstractRechnungDO, heredando campos comunes de factura (fecha, montos neto/bruto, información de pago, estado). Añade campos específicos de factura de entrada como detalles del acreedor, información de cuenta bancaria (IBAN/BIC) y un número de referencia del acreedor. La entidad está indexada por Hibernate Search e implementa Comparable para ordenamiento.

Gestión de Posiciones

Hereda de AbstractRechnungDO y especializa la lista de posiciones como MutableList<EingangsrechnungsPositionDO>, anotada con:

  • @JsonManagedReference — lado padre de serialización JSON de la relación bidireccional
  • @SoftDeleteCollection — soporte de eliminación lógica para posiciones
  • @PersistenceBehavior(autoUpdateCollectionEntries = true) — cascada de Hibernate para entradas hijas
  • @OneToMany(mappedBy = "eingangsrechnung", cascade = PERSIST, MERGE, REFRESH, DETACH) — sin cascada REMOVE (orphanRemoval = false)
  • @OrderColumn(name = "number") / @ListIndexBase(1) — numeración de posiciones basada en 1
