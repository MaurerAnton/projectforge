Представляет входящий счёт (Eingangsrechnung) — счёт, полученный от кредитора. Расширяет AbstractRechnungDO, наследуя общие поля счёта (дата, суммы нетто/брутто, платёжная информация, статус). Добавляет специфические для входящего счёта поля, такие как данные кредитора, банковские реквизиты (IBAN/BIC) и ссылочный номер со стороны кредитора. Сущность индексируется Hibernate Search и реализует Comparable для сортировки.

Управление позициями

Наследуется от AbstractRechnungDO и специализирует список позиций как MutableList<EingangsrechnungsPositionDO>, аннотированный:

  • @JsonManagedReference — родительская сторона двунаправленной связи для JSON-сериализации
  • @SoftDeleteCollection — поддержка мягкого удаления для позиций
  • @PersistenceBehavior(autoUpdateCollectionEntries = true) — каскадирование Hibernate для дочерних записей
  • @OneToMany(mappedBy = "eingangsrechnung", cascade = PERSIST, MERGE, REFRESH, DETACH) — без каскада REMOVE (orphanRemoval = false)
  • @OrderColumn(name = "number") / @ListIndexBase(1) — нумерация позиций, начиная с 1
