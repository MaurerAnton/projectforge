DAO pour EingangsrechnungDO (factures fournisseurs). Étend BaseDao<EingangsrechnungDO> en fournissant les opérations CRUD, le listage filtré, la fusion d'historique et le filtrage par état de paiement. Collabore avec EingangsrechnungCache pour les requêtes haute performance sur l'état des paiements et CurrencyConversionService pour les statistiques multi-devises.

Architecture

Héritage

  • BaseDao<EingangsrechnungDO> — DAO standard avec filtrage, tri, historique et contrôles d'accès

Dépendances

DépendanceRôle
EingangsrechnungCacheRecherche en cache de l'état de paiement via RechnungJdbcService
KontoDaoDéfinit le compte (Konto) sur les enregistrements de factures fournisseurs
CurrencyConversionServiceConversion de devises pour les statistiques
ConfigurationServiceDevise par défaut du système pour les statistiques

Contrôle d'accès

Protégé par UserRightId.FIBU_EINGANGSRECHNUNGEN, défini dans init.

Méthodes clés

Plage d'années

La propriété years exécute une requête nommée EingangsrechnungDO.SELECT_MIN_MAX_DATE (sélectionnant min(datum) et max(datum)) et convertit le résultat en IntArray via getYearsByTupleOfLocalDate().

Statistiques

buildStatistik(list) crée un accumulateur EingangsrechnungsStatistik et y ajoute chaque facture. Avant le traitement, il initialise les services statiques currencyConversionService et configurationService sur la classe de base partagée AbstractRechnungsStatistik (motif d'injection de dépendance par objet compagnon).

Attribution du compte

setKonto(eingangsrechnung, kontoId) recherche le KontoDO via kontoDao.findOrLoad() et l'assigne. Si kontoId est nul, le compte est défini à null.

Listage filtré (select)

Encapsule le filtre dans un EingangsrechnungListFilter si nécessaire. Crée un QueryFilter avec des restrictions de date et des filtres de type de paiement. Trie par datum DESC, puis kreditor DESC. Après la requête, applique un post-filtrage sur l'état de paiement basé sur RechnungInfo provenant du cache :

  • isShowUnbezahlt — filtre pour les factures impayées
  • isShowBezahlt — filtre pour les factures payées
  • isShowUeberFaellig — filtre pour les factures en retard

Points d'ancrage du cycle de vie

Point d'ancrageComportement
afterLoad(obj)Définit obj.info à partir du cache via rechnungCache.ensureRechnungInfo(obj)
onInsertOrModify(obj, opType)Délègue à AuftragAndRechnungDaoHelper.onSaveOrModify() ; met à l'échelle zahlBetrag à 2 décimales ; appelle recalculate() ; garantit au moins une position existante (lève une UserException si vide) ; supprime les positions vides en fin de liste ; écrit le statut UI en XML.
afterInsertOrModify(obj, opType)Appelle rechnungCache.update(obj) pour rafraîchir le cache

Fusion d'historique

addOwnHistoryEntries() itère sur toutes les positions et leurs affectations de coûts (KostZuweisungDO), fusionnant l'historique de chaque enfant dans le contexte parent. getHistoryPropertyPrefix() fournit des préfixes contextuels : numéros de position et "kost #N" pour les affectations de coûts.

Requêtes supplémentaires

MéthodeDescription

Champs de recherche supplémentaires

Inclut "positionen.text" dans les requêtes de recherche, permettant une recherche en texte intégral dans les lignes de facture.

Objets de recherche d'historique supplémentaires

Inclut EingangsrechnungsPositionDO pour les recherches d'historique inter-entités.

Saisie automatique

Activée pour "kreditor" (nom du créancier).
