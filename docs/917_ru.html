DAO для EingangsrechnungDO (входящие счета). Расширяет BaseDao<EingangsrechnungDO>, предоставляя CRUD, фильтрованный список, слияние истории и фильтрацию по статусу оплаты. Взаимодействует с EingangsrechnungCache для высокопроизводительных запросов статуса оплаты и CurrencyConversionService для мультивалютной статистики.

Архитектура

Наследование

  • BaseDao<EingangsrechnungDO> — стандартный DAO с фильтрацией, сортировкой, историей, проверками доступа

Зависимости

ЗависимостьРоль
EingangsrechnungCacheКэшированный поиск статуса оплаты через RechnungJdbcService
KontoDaoУстанавливает счёт (Konto) для записей входящих счетов
CurrencyConversionServiceКонвертация валют для статистики
ConfigurationServiceСистемная валюта по умолчанию для статистики

Контроль доступа

Защищён с помощью UserRightId.FIBU_EINGANGSRECHNUNGEN, установленного в init.

Ключевые методы

Диапазон лет

Свойство years выполняет именованный запрос EingangsrechnungDO.SELECT_MIN_MAX_DATE (выбирает min(datum) и max(datum)) и преобразует результат в IntArray через getYearsByTupleOfLocalDate().

Статистика

buildStatistik(list) создаёт аккумулятор EingangsrechnungsStatistik и добавляет в него каждый счёт. Перед обработкой инициализирует статические currencyConversionService и configurationService в общем базовом классе AbstractRechnungsStatistik (шаблон внедрения зависимостей через объект-компаньон).

Назначение счёта

setKonto(eingangsrechnung, kontoId) ищет KontoDO через kontoDao.findOrLoad() и назначает его. Если kontoId равен null, счёт устанавливается в null.

Фильтрованный список (select)

При необходимости оборачивает фильтр в EingangsrechnungListFilter. Создаёт QueryFilter с ограничениями по дате и фильтрами по типу оплаты. Сортирует по datum DESC, затем kreditor DESC. После запроса применяет пост-фильтрацию по статусу оплаты на основе RechnungInfo из кэша:

  • isShowUnbezahlt — фильтр неоплаченных счетов
  • isShowBezahlt — фильтр оплаченных счетов
  • isShowUeberFaellig — фильтр просроченных счетов

Хуки жизненного цикла

ХукПоведение
afterLoad(obj)Устанавливает obj.info из кэша через rechnungCache.ensureRechnungInfo(obj)
onInsertOrModify(obj, opType)Делегирует AuftragAndRechnungDaoHelper.onSaveOrModify(); масштабирует zahlBetrag до 2 знаков после запятой; вызывает recalculate(); гарантирует наличие хотя бы одной позиции (выбрасывает UserException, если пусто); удаляет конечные пустые позиции; записывает статус UI в XML.
afterInsertOrModify(obj, opType)Вызывает rechnungCache.update(obj) для обновления кэша

Слияние истории

addOwnHistoryEntries() перебирает все позиции и их назначения затрат (KostZuweisungDO), объединяя историю каждого дочернего элемента в родительский контекст. getHistoryPropertyPrefix() предоставляет контекстные префиксы: номера позиций и "kost #N" для назначений затрат.

Дополнительные поля поиска

Включает "positionen.text" в поисковые запросы, обеспечивая полнотекстовый поиск по строкам счёта.

Дополнительные объекты поиска по истории

Включает EingangsrechnungsPositionDO для поиска по истории между сущностями.

Автодополнение

Включено для "kreditor" (имя кредитора).
