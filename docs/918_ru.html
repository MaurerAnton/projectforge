Основная доменная сущность, представляющая отдельную позицию/строку во входящем счёте. Расширяет AbstractRechnungsPositionDO и устанавливает связь с родительским EingangsrechnungDO, а также с назначениями затрат (KostZuweisungDO). Индексировано Hibernate-search для полнотекстового поиска.

Архитектура / Дизайн

Наследование и JPA-маппинг

Расширяет AbstractRechnungsPositionDO (общий базовый класс для позиций как входящих, так и исходящих счетов). Объявлен как open (требуется Kotlin + Hibernate для прокси-объектов с ленивой загрузкой). Аннотация @Table маппится на t_fibu_eingangsrechnung_position с составным уникальным ограничением на (eingangsrechnung_fk, number) — гарантирует уникальность номеров позиций в пределах одного счёта.

ПолеТипJPA / Примечания
eingangsrechnungEingangsrechnungDO?@ManyToOne(LAZY) — ссылка на родительский счёт. Использует @JsonBackReference для разрыва цикла сериализации. Сериализуется только как ID через @JsonSerialize(IdOnlySerializer).
rechnungIdLong?@Transient — удобный геттер, делегирующий вызов к eingangsrechnung?.id. Переопределяет абстрактное свойство из AbstractRechnungsPositionDO.
kostZuweisungenMutableList<KostZuweisungDO>?@OneToMany(mappedBy="eingangsrechnungsPosition") с @OrderColumn(name="index"). @JsonManagedReference («владеющая» сторона JSON-пары). Аннотировано @PersistenceBehavior(autoUpdateCollectionEntries=true).

Ключевые методы

  • checkKostZuweisungId() — Проверяет, что назначение затрат принадлежит этой позиции, сравнивая FK-ссылку позиции.
  • newClone() — Создаёт глубокую копию (без ID), включая все назначения затрат. Использует copyValuesFrom() с исключением "id" и "kostZuweisungen", затем клонирует каждый KostZuweisungDO индивидуально.
  • newInstance() — Фабричный метод, возвращающий новый пустой EingangsrechnungsPositionDO.

Стратегия JSON-сериализации

Использует @JsonBackReference на eingangsrechnung и @JsonManagedReference на kostZuweisungen для обработки двунаправленных связей без бесконечной рекурсии. Родительский счёт сериализуется только как ID, что делает JSON-ответы компактными.
