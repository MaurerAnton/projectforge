#919: EmployeeDao.kt

Type: Spring Service / DAO · Purpose: Data access layer for Employee entities · Path: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeDao.kt
Extends BaseDao<EmployeeDO> providing all standard CRUD operations plus employee-specific queries (by user, by name, by staff number, active status filtering). Manages the relationship between EmployeeDO and PFUserDO / Kost1DO. Auto-populates time-dependent attributes via EmployeeCache. User right: HR_EMPLOYEE.

Architecture & Design

Dependencies

DependencyRole
Kost1DaoResolves cost center (Kost1DO) when setting kost1 on an employee.
UserDaoResolves PFUserDO for the setUser() method.
EmployeeCachePopulates time-dependent fields (status, annualLeave, weeklyWorkingHours) on fetched entities.
EmployeeServiceInjected by EmployeeService.postConstruct() to avoid circular dependency. Used for getEmployeeStatus() and isEmployeeActive() checks.

Query Methods

  • findByUserId(userId) — Uses named query EmployeeDO.FIND_BY_USER_ID. Auto-sets time-dependent attrs.
  • findEmployeeIdByUserId(userId) — Uses named query EmployeeDO.GET_EMPLOYEE_ID_BY_USER_ID. Returns only the PK for efficiency.
  • findByName(fullname) — Parses "lastname, firstname" format. Uses FIND_BY_LASTNAME_AND_FIRST_NAME named query. Validates exactly 2 tokens.
  • findByStaffnumber(staffnumber) — Uses a dynamic JPQL query with NoResultException handling (returns null).
  • selectWithActiveStatus(filter, checkAccess, showOnlyActive, showRecentlyLeavers) — Core filtering method: first fetches all matching employees, then post-filters using EmployeeService.isEmployeeActive(). Supports recently-left-employees mode (within 3 months).

Select Override

select(filter) wraps any BaseSearchFilter in EmployeeFilter if needed, then optionally post-filters by active flag and always calls employeeCache.setTimeDependentAttrs().

History Integration

addOwnHistoryEntries() extends the employee's history by loading and merging all EmployeeValidSinceAttrDO history entries — this ensures changes to time-dependent attributes (annual leave, weekly hours, status) appear in the employee's combined history timeline.

Autocompletion

Only abteilung and position properties are enabled for autocompletion via ENABLED_AUTOCOMPLETION_PROPERTIES.

Additional Search Fields

Extends full-text search to include nested user fields (user.firstname, user.lastname, user.username, user.description, user.organization) and Kost1 fields (kost1.nummer, kost1.name).

Sort Properties

Default sort: user.firstname ASC, user.lastname ASC.
