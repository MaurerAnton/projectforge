#919: EmployeeActiveFilter.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeActiveFilter.kt Typ: Benutzerdefinierter Ergebnisfilter · Zweck: Filtert eine Liste auf nur aktive Mitarbeiter · Pfad: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeActiveFilter.kt 42 Zeilen · 13 Code · 25 Kommentare · 4 leer
Implementiert CustomResultFilter<EmployeeDO>. Wird verwendet, um Mitarbeiterlisten auf diejenigen zu filtern, die derzeit aktiv sind. Delegiert an EmployeeService.isEmployeeActive() mit showRecentlyLeavers=true. Bezieht den EmployeeService-Bean über Springs ApplicationContextProvider zur Klassenladezeit (gespeichert in einem Companion-Objekt).

Entwurf

Die einzelne Methode match(list, element) delegiert vollständig an die Service-Ebene. Der träge initialisierte employeeService wird einmal abgerufen und statisch gehalten. Dieser Filter ist nützlich an Stellen wie Urlaubsverwaltungsoberflächen, an denen nur aktive Mitarbeiter auswählbar sein sollen.
