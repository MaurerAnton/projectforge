#919: EmployeeActiveFilter.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeActiveFilter.kt Type : Filtre de résultat personnalisé · Objectif : Filtre une liste pour ne conserver que les employés actifs · Chemin : projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeActiveFilter.kt 42 lignes · 13 lignes de code · 25 commentaires · 4 lignes vides
Implémente CustomResultFilter<EmployeeDO>. Utilisé pour filtrer les listes d'employés afin de ne conserver que ceux actuellement actifs. Délègue à EmployeeService.isEmployeeActive() avec showRecentlyLeavers=true. Obtient le bean EmployeeService via le ApplicationContextProvider de Spring au moment du chargement de la classe (stocké dans un objet compagnon).

Conception

La méthode unique match(list, element) délègue entièrement à la couche service. Le employeeService paresseux est obtenu une fois et conservé de manière statique. Ce filtre est utile dans des endroits comme les interfaces de gestion des congés où seuls les employés actifs doivent être sélectionnables.
