#919: EmployeeActiveFilter.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeActiveFilter.kt Тип: Пользовательский фильтр результатов · Назначение: Фильтрует список, оставляя только активных сотрудников · Путь: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeActiveFilter.kt 42 строки · 13 кода · 25 комментариев · 4 пустых
Реализует CustomResultFilter<EmployeeDO>. Используется для фильтрации списков сотрудников, оставляя только тех, кто в настоящее время активен. Делегирует выполнение EmployeeService.isEmployeeActive() с параметром showRecentlyLeavers=true. Получает bean EmployeeService через Spring ApplicationContextProvider во время загрузки класса (хранится в объекте-компаньоне).

Дизайн

Единственный метод match(list, element) полностью делегирует выполнение сервисному слою. Ленивый employeeService получается один раз и хранится статически. Этот фильтр полезен в таких местах, как интерфейсы управления отпусками, где должны быть доступны для выбора только активные сотрудники.
