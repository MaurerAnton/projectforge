File #92: DataTransferPageRest.kt

Path: plugins/datatransfer/.../rest/DataTransferPageRest.kt · Source: GitHub

Main data transfer file view page. Features: (1) UIAttachmentList with upload/delete/download, (2) download all (hidden if >1GB total), (3) observer toggle checkbox — users can subscribe/unsubscribe to area notifications, (4) external sharing panel with copyable link + password, (5) capacity display, (6) audit log modal button, (7) edit button for admins. id=-1 resolves to personal box. Downloads audit events via DataTransferRestUtils.multiDownload().
