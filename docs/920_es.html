Caché de alto rendimiento que mantiene una instantánea de todos los empleados no eliminados junto con su status, annualLeave y weeklyWorkingHours actuales — calculados a partir de las entradas EmployeeValidSinceAttrDO. Extiende AbstractCache que proporciona la infraestructura de actualización/caducidad. Expuesto como un singleton @Component accesible a través de EmployeeCache.instance.

Arquitectura y Diseño

Almacenamiento en Caché

El employeeMap interno es un Map<Long, EmployeeDO> indexado por la clave primaria de la base de datos del empleado. No está sincronizado — solo se escribe durante refresh() y se reemplaza atómicamente mediante asignación. El acceso de solo lectura desde múltiples hilos es seguro porque cada actualización crea una nueva instancia del mapa.

Estrategia de Actualización

El método refresh() (llamado por AbstractCache / CacheHelper con sincronización) se ejecuta dentro de una transacción aislada de solo lectura:

  1. Cargar todos los empleados no eliminados: from EmployeeDO t where deleted=false
  2. Aplicar entradas STATUS: Consultar las entradas validSinceEff más recientes de tipo STATUS, agrupadas por ID de empleado, tomando el primer registro por grupo.
  3. Aplicar entradas ANNUAL_LEAVE: Mismo patrón de agrupación — resuelve los días de vacaciones anuales vigentes hoy.
  4. Aplicar entradas WEEKLY_HOURS: Misma agrupación — resuelve las horas de trabajo semanales.
  5. Reemplazar mapa: El mapa final se asigna a this.employeeMap.

Resolución de Atributos Dependientes del Tiempo

El método getLatestValidSinceEntries(type) ejecuta una consulta JPQL ordenando por employee.id, validSince DESC, luego agrupa por ID de empleado usando groupBy de Kotlin. Se selecciona el primer elemento de cada grupo (el validSince más reciente). Un comentario en la fuente señala que un enfoque basado en subconsultas (SELECT MAX(validSince)) falló bajo PostgreSQL con entradas faltantes, lo que llevó a este enfoque de agrupación posterior a la consulta.

Consulta Nombrada

El objeto complementario define queryAllValidSinceValues — una cadena JPQL utilizada por getLatestValidSinceEntries():

SELECT t FROM EmployeeValidSinceAttrDO t
WHERE t.type=:type AND t.deleted=false
ORDER BY t.employee.id, t.validSince DESC
