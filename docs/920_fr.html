Cache haute performance qui maintient un instantané de tous les employés non supprimés ainsi que leur statut, congéAnnuel et heuresHebdomadaires actuels — calculés à partir des entrées EmployeeValidSinceAttrDO. Étend AbstractCache qui fournit l'infrastructure de rafraîchissement/expiration. Exposé en tant que singleton @Component accessible via EmployeeCache.instance.

Architecture & Conception

Stockage du cache

Le employeeMap interne est un Map<Long, EmployeeDO> indexé par la clé primaire de l'employé en base de données. Il n'est pas synchronisé — seulement écrit pendant refresh() et remplacé atomiquement par affectation. L'accès en lecture seule depuis plusieurs threads est sûr car chaque rafraîchissement crée une nouvelle instance de map.

Stratégie de rafraîchissement

La méthode refresh() (appelée par AbstractCache / CacheHelper avec synchronisation) s'exécute dans une transaction en lecture seule isolée :

  1. Charger tous les employés non supprimés : from EmployeeDO t where deleted=false
  2. Appliquer les entrées STATUS : Interroger les dernières entrées validSinceEff de type STATUS, groupées par ID employé, en prenant le premier enregistrement par groupe.
  3. Appliquer les entrées ANNUAL_LEAVE : Même modèle de regroupement — résout les jours de congé annuel valides aujourd'hui.
  4. Appliquer les entrées WEEKLY_HOURS : Même regroupement — résout les heures de travail hebdomadaires.
  5. Remplacer la map : La map finale est assignée à this.employeeMap.

Résolution des attributs dépendants du temps

La méthode getLatestValidSinceEntries(type) exécute une requête JPQL en ordonnant par employee.id, validSince DESC, puis groupe par ID employé en utilisant groupBy de Kotlin. Le premier élément de chaque groupe (le validSince le plus récent) est sélectionné. Un commentaire dans la source note qu'une approche basée sur une sous-requête (SELECT MAX(validSince)) a échoué sous PostgreSQL avec des entrées manquantes, conduisant à cette approche de regroupement post-requête.

Requête nommée

L'objet compagnon définit queryAllValidSinceValues — une chaîne JPQL utilisée par getLatestValidSinceEntries() :

SELECT t FROM EmployeeValidSinceAttrDO t
WHERE t.type=:type AND t.deleted=false
ORDER BY t.employee.id, t.validSince DESC
