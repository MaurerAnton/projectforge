Высокопроизводительный кэш, который хранит снимок всех неудалённых сотрудников вместе с их текущими status, annualLeave и weeklyWorkingHours — вычисленными из записей EmployeeValidSinceAttrDO. Расширяет AbstractCache, который предоставляет инфраструктуру обновления/истечения срока действия. Предоставляется как синглтон @Component, доступный через EmployeeCache.instance.

Архитектура и дизайн

Хранилище кэша

Внутренний employeeMap представляет собой Map<Long, EmployeeDO> с ключом по первичному ключу сотрудника в БД. Он не синхронизирован — запись происходит только во время refresh() и атомарно заменяется через присваивание. Доступ только для чтения из нескольких потоков безопасен, так как каждый refresh создаёт новый экземпляр карты.

Стратегия обновления

Метод refresh() (вызываемый AbstractCache / CacheHelper с синхронизацией) выполняется в изолированной транзакции только для чтения:

  1. Загрузить всех неудалённых сотрудников: from EmployeeDO t where deleted=false
  2. Применить записи STATUS: Запросить последние записи validSinceEff типа STATUS, сгруппированные по ID сотрудника, взяв первую запись в каждой группе.
  3. Применить записи ANNUAL_LEAVE: Та же группировка — определяет дни ежегодного отпуска, действительные на сегодня.
  4. Применить записи WEEKLY_HOURS: Та же группировка — определяет еженедельные рабочие часы.
  5. Заменить карту: Итоговая карта присваивается this.employeeMap.

Разрешение зависимых от времени атрибутов

Метод getLatestValidSinceEntries(type) выполняет JPQL-запрос с сортировкой по employee.id, validSince DESC, затем группирует по ID сотрудника с помощью Kotlin groupBy. Выбирается первый элемент каждой группы (самый последний validSince). В комментарии к исходному коду отмечается, что подход на основе подзапроса (SELECT MAX(validSince)) не сработал в PostgreSQL из-за пропущенных записей, что привело к использованию этого подхода с группировкой после запроса.

Именованный запрос

Объект-компаньон определяет queryAllValidSinceValues — строку JPQL, используемую getLatestValidSinceEntries():

SELECT t FROM EmployeeValidSinceAttrDO t
WHERE t.type=:type AND t.deleted=false
ORDER BY t.employee.id, t.validSince DESC
