projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeDO.kt Typ: JPA-Entität (Datenobjekt) · Zweck: Repräsentiert einen Mitarbeiter – die Verbindung zwischen einem ProjectForge-Benutzer und Finanz-/Personal-Daten · Pfad: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeDO.kt 230 Zeilen · 156 Code · 52 Kommentare · 22 leer
Zentrale Entität, die einen PFUserDO (Benutzerkonto) mit Finanz-, Personal- und Zeiterfassungsdaten verbindet. Abgebildet auf Tabelle t_fibu_employee. Implementiert Comparable (nach Benutzernachname/-vorname) und DisplayNameCapable (delegiert an den vollständigen Namen des Benutzers). Als open deklariert für Hibernate-Proxy-Unterstützung und Test-Mocking (VacationServiceTest).

Benannte Abfragen

  • EmployeeDO_FindByUserId — from EmployeeDO where user.id=:userId
  • EmployeeDO_GetEmployeeIdByUserId — select id from EmployeeDO where user.id=:userId
  • EmployeeDO_FindByLastnameAndFirstname — from EmployeeDO where user.lastname=:lastname and user.firstname=:firstname

Berechnete Eigenschaften

  • displayName — Delegiert an user.getFullname(). Implementiert DisplayNameCapable.
  • active — Gibt true zurück, wenn: nicht gelöscht, Eintrittsdatum nicht in der Zukunft und Austrittsdatum nicht in der Vergangenheit. Basiert auf LocalDate.now().

Vergleich & Gleichheit

  • equals() — Basiert auf ID-Gleichheit. Andere Typen geben false zurück.
  • hashCode() — 31 * id.hashCode() wenn id nicht null ist; andernfalls Delegation an super.
  • compareTo() — Vergleicht nach user.lastname dann user.firstname mittels StringUtils.compare(). Null-Benutzer werden zuerst sortiert.

Werte kopieren

copyValuesFrom()-Überschreibung schließt timeableAttributes vom Kopieren aus. Protokolliert eine Warnung, dass das Kopieren zeitabhängiger Attribute noch nicht implementiert ist.
