projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeDO.kt Type : Entité JPA (objet de données) · Objectif : Représente un employé — le lien entre un utilisateur ProjectForge et les données financières/RH · Chemin : projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeDO.kt 230 lignes · 156 code · 52 commentaires · 22 vides
Entité centrale reliant un PFUserDO (compte utilisateur) aux données financières, RH et de suivi du temps. Mappée à la table t_fibu_employee. Implémente Comparable (par nom/prénom de l'utilisateur) et DisplayNameCapable (délègue au nom complet de l'utilisateur). Déclarée open pour le support des proxies Hibernate et le mock de tests (VacationServiceTest).

Requêtes nommées

  • EmployeeDO_FindByUserId — from EmployeeDO where user.id=:userId
  • EmployeeDO_GetEmployeeIdByUserId — select id from EmployeeDO where user.id=:userId
  • EmployeeDO_FindByLastnameAndFirstname — from EmployeeDO where user.lastname=:lastname and user.firstname=:firstname

Propriétés calculées

  • displayName — Délègue à user.getFullname(). Implémente DisplayNameCapable.
  • active — Renvoie vrai si : non supprimé, la date d'entrée n'est pas dans le futur et la date de sortie n'est pas dans le passé. Basé sur LocalDate.now().

Comparaison & Égalité

  • equals() — Basé sur l'égalité des ID. Les autres types renvoient faux.
  • hashCode() — 31 * id.hashCode() si l'ID est non nul ; sinon délègue à super.
  • compareTo() — Compare par user.lastname puis user.firstname en utilisant StringUtils.compare(). Les utilisateurs nuls sont triés en premier.

Copie des valeurs

La redéfinition de copyValuesFrom() exclut timeableAttributes de la copie. Enregistre un avertissement indiquant que la copie des attributs temporalisés n'est pas encore implémentée.
