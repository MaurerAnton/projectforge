projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeDO.kt Тип: JPA-сущность (объект данных) · Назначение: Представляет сотрудника — связь между пользователем ProjectForge и финансовыми/HR-данными · Путь: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeDO.kt 230 строк · 156 кода · 52 комментария · 22 пустых
Центральная сущность, связывающая PFUserDO (учётная запись пользователя) с финансовыми, HR-данными и данными учёта времени. Отображается на таблицу t_fibu_employee. Реализует Comparable (по фамилии/имени пользователя) и DisplayNameCapable (делегирует полному имени пользователя). Объявлена как open для поддержки Hibernate-прокси и тестового мокинга (VacationServiceTest).

Именованные запросы

  • EmployeeDO_FindByUserId — from EmployeeDO where user.id=:userId
  • EmployeeDO_GetEmployeeIdByUserId — select id from EmployeeDO where user.id=:userId
  • EmployeeDO_FindByLastnameAndFirstname — from EmployeeDO where user.lastname=:lastname and user.firstname=:firstname

Вычисляемые свойства

  • displayName — Делегирует user.getFullname(). Реализует DisplayNameCapable.
  • active — Возвращает true, если: не удалён, дата поступления не в будущем и дата увольнения не в прошлом. Основано на LocalDate.now().

Сравнение и равенство

  • equals() — Основано на равенстве ID. Другие типы возвращают false.
  • hashCode() — 31 * id.hashCode(), если id не null; иначе делегирует super.
  • compareTo() — Сравнивает по user.lastname, затем user.firstname с использованием StringUtils.compare(). Пользователи с null сортируются первыми.

Копирование значений

Переопределение copyValuesFrom() исключает timeableAttributes из копирования. Логирует предупреждение, что копирование атрибутов времени ещё не реализовано.
