projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryDO.kt Typ: JPA-Entität (Datenobjekt) · Zweck: Monatlicher Gehaltsdatensatz für einen festangestellten Mitarbeiter · Pfad: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryDO.kt 127 Zeilen · 73 Code · 41 Kommentare · 13 leer
Stellt einen einzelnen monatlichen Gehaltseintrag für einen Mitarbeiter dar. Mappt auf T_FIBU_EMPLOYEE_SALARY mit einer eindeutigen Einschränkung auf (employee_id, year, month) — ein Gehaltsdatensatz pro Mitarbeiter und Monat. Hibernate-Search-indiziert.
