#924: EmployeeSalaryDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryDao.kt Тип: Spring Service / DAO · Назначение: Доступ к данным для ежемесячных записей о зарплате сотрудников · Путь: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryDao.kt 151 строка · 104 кода · 33 комментария · 14 пустых
Расширяет BaseDao<EmployeeSalaryDO>. Управляет ежемесячными записями о зарплате сотрудников с проверкой уникальности по (employee, year, month). Включает поддержку навигации по годам через запрос минимального/максимального года. Право пользователя: HR_EMPLOYEE_SALARY.

Архитектура и дизайн

Фильтрация

select(filter) оборачивает любой фильтр в EmployeeSalaryFilter и применяет ограничения равенства по году и месяцу. Результаты всегда сортируются по year DESC, month DESC (сначала новые).

Проверка уникальности (onInsertOrModify)

При вставке (id==null): проверяет, существует ли уже запись о зарплате для той же комбинации (employee, year, month). При обновлении: та же проверка, исключая ID текущей записи. Выбрасывает UserException("fibu.employee.salary.error.salaryAlreadyExist"), если обнаружен дубликат.

Диапазон лет

Свойство years возвращает IntArray всех лет, присутствующих в таблице зарплат, вычисляемый из именованного запроса EmployeeSalaryDO.SELECT_MIN_MAX_YEAR через SQLHelper.getYearsByTupleOfYears(). Используется для навигации по годам в интерфейсе.

Дополнительные поля

Поиск распространяется на employee.user.lastname, employee.user.firstname и employee.staffNumber.
