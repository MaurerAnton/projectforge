#926: EmployeeSalaryService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryService.kt Tipo: Servicio Spring · Propósito: Capa de servicio para consultar registros de salarios de empleados · Ruta: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryService.kt 45 líneas · 19 código · 22 comentarios · 4 en blanco
Capa de servicio delgada que envuelve PfPersistenceService. Proporciona un único método de consulta para recuperar todos los registros de salario de un año y mes determinados. Diseñado para escenarios de informes (resumen de salario mensual). Utiliza transacciones de solo lectura.

Arquitectura y Diseño

Método Único

selectByMonth(year: Int, month: Month): List<EmployeeSalaryDO> — Ejecuta la consulta nombrada EmployeeSalaryDO.SELECT_SALARIES_BY_MONTH dentro de una transacción de solo lectura a través de persistenceService.runReadOnly. El parámetro de enumeración Month se convierte a su valor entero (1-12).

Nota de Diseño

Este es un servicio separado (no parte de EmployeeSalaryDao) para una separación limpia: el DAO maneja CRUD, mientras que este servicio maneja consultas masivas para informes. Utiliza directamente PfPersistenceService en lugar de la capa DAO, accediendo a consultas nombradas definidas en EmployeeSalaryDO.
