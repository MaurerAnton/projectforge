projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryService.kt Type : Service Spring · Objectif : Couche de service pour interroger les enregistrements de salaire des employés · Chemin : projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryService.kt 45 lignes · 19 code · 22 commentaires · 4 vides
Couche de service légère encapsulant PfPersistenceService. Fournit une seule méthode de requête pour récupérer tous les enregistrements de salaire pour une année et un mois donnés. Conçue pour les scénarios de reporting (aperçu mensuel des salaires). Utilise des transactions en lecture seule.

Architecture & Conception

Méthode unique

selectByMonth(year: Int, month: Month): List<EmployeeSalaryDO> — Exécute la requête nommée EmployeeSalaryDO.SELECT_SALARIES_BY_MONTH dans une transaction en lecture seule via persistenceService.runReadOnly. Le paramètre d'énumération Month est converti en sa valeur entière (1-12).

Note de conception

Il s'agit d'un service séparé (ne faisant pas partie de EmployeeSalaryDao) pour une séparation claire : le DAO gère le CRUD, tandis que ce service gère les requêtes groupées pour le reporting. Il utilise directement PfPersistenceService plutôt que la couche DAO, accédant aux requêtes nommées définies sur EmployeeSalaryDO.
