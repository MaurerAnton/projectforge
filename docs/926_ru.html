#926: EmployeeSalaryService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryService.kt Тип: Spring-сервис · Назначение: сервисный слой для запросов записей о зарплате сотрудников · Путь: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/EmployeeSalaryService.kt 45 строк · 19 кода · 22 комментария · 4 пустых
Тонкий сервисный слой, оборачивающий PfPersistenceService. Предоставляет единственный метод запроса для получения всех записей о зарплате за указанные год и месяц. Предназначен для сценариев формирования отчётов (ежемесячный обзор зарплат). Использует транзакции только для чтения.

Архитектура и дизайн

Единственный метод

selectByMonth(year: Int, month: Month): List<EmployeeSalaryDO> — выполняет именованный запрос EmployeeSalaryDO.SELECT_SALARIES_BY_MONTH в рамках транзакции только для чтения через persistenceService.runReadOnly. Параметр перечисления Month преобразуется в целочисленное значение (1-12).

Примечание по дизайну

Это отдельный сервис (не часть EmployeeSalaryDao) для чистого разделения: DAO отвечает за CRUD, а этот сервис — за массовые запросы для отчётности. Он напрямую использует PfPersistenceService, а не слой DAO, обращаясь к именованным запросам, определённым в EmployeeSalaryDO.
