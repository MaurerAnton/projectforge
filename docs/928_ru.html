Прокси для скриптов, оборачивающий EmployeeService и предоставляющий доступ только для чтения к бизнес-логике сотрудников для скриптов Groovy/Kotlin. Доступен в скриптах как: employeeService. Предоставляет поиск атрибутов, зависящих от времени, проверку статуса активности, поиск сотрудников и генерацию ежемесячных отчётов. Это новый, предпочтительный интерфейс для скриптов по сравнению с EmployeeScriptingDao.

Архитектура и дизайн

Паттерн делегирования

Каждый метод напрямую делегирует выполнение базовому экземпляру EmployeeService (внедрённому через конструктор как __employeeService). Прокси следует тому же паттерну, что и ScriptingDao, но оборачивает сервис, а не DAO — предоставляя бизнес-логику, а не просто доступ к сущностям.

Обоснование дизайна

Скриптам нужен доступ к бизнес-логике, такой как «получить недельные часы для сотрудника на дату X» или «активен ли этот сотрудник?» — а не только CRUD. Этот прокси предоставляет только методы для чтения. Скрипты не должны изменять данные через этот интерфейс; изменения выполняются через выделенные DAO для скриптов.
