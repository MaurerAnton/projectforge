La API pública principal para la lógica de negocio de empleados. Actúa como fachada sobre EmployeeServiceSupport (implementación interna), EmployeeDao, EmployeeCache y TimesheetDao. Expuesto como singleton a través de EmployeeService.instance. Registra un adaptador de historial para EmployeeValidSinceAttrDO en la inicialización.

Lógica de Estado Activo

isEmployeeActive(employee, showRecentlyLeavers): Devuelve verdadero si:

  • Sin fecha de baja: El empleado está activo si el usuario no está ni eliminado ni desactivado (usuario nulo = activo, para pruebas).
  • Con fecha de baja: El empleado está activo si la fecha de baja es igual o posterior a la fecha de referencia (ahora, o ahora menos 3 meses si showRecentlyLeavers=true).

Métodos de Atributos Dependientes del Tiempo

Todos los métodos dependientes del tiempo iteran a través de las entradas ValidSinceAttrDO ordenadas por validSince DESC y seleccionan la entrada cuyo validSince es igual o anterior a la fecha de referencia. Los métodos están organizados por tipo de atributo:

  • Vacaciones anuales: getAnnualLeaveDays() (con/sin fecha), selectAnnualLeaveDayEntries() (por empleado o ID), insertAnnualLeaveDays()
  • Horas semanales: getWeeklyWorkingHours() (con/sin fecha), selectWeeklyWorkingHoursEntries() (por empleado o ID), insertWeeklyHours()
  • Estado: getEmployeeStatus(), selectStatusEntries(), insertStatus()

Operaciones CRUD de ValidSinceAttr

El servicio proporciona una superficie CRUD completa para EmployeeValidSinceAttrDO:

  • insert() — Insertar con ID de empleado o entidad, delega en EmployeeServiceSupport
  • updateValidSinceAttr() — Actualizar con semántica de copia (maneja la reutilización de entradas eliminadas)
  • markValidSinceAttrAsDeleted() — Eliminación suave
  • undeleteValidSinceAttr() — Recuperar/restaurar
  • validate() — Devuelve un mensaje de error o nulo si es válido

Informe Mensual de Empleados

getReportOfMonth(year, month, user) crea un MonthlyEmployeeReport, inicializa los límites de fecha, consulta los partes de horas a través de TimesheetFilter para el usuario y rango de mes dados, añade cada parte de horas (con información de verificación de acceso) y calcula las duraciones agregadas por Kost2.
