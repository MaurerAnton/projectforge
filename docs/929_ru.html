Основной публичный API для бизнес-логики сотрудников. Служит фасадом над EmployeeServiceSupport (внутренняя реализация), EmployeeDao, EmployeeCache и TimesheetDao. Предоставляется как синглтон через EmployeeService.instance. При инициализации регистрирует адаптер истории для EmployeeValidSinceAttrDO.

Архитектура и дизайн

Зависимости и инициализация

ЗависимостьРоль
PfCachesДоступ к UserGroupCache для разрешения пользователей (используется в isEmployeeActive()).
EmployeeDaoПоиск сущностей и операции выборки. Циклическая зависимость разрешена: EmployeeService устанавливает себя в EmployeeDao.employeeService во время @PostConstruct.
EmployeeServiceSupportВнутренний сервис, содержащий фактическую логику реализации (валидация, вставка, обновление, поиск). Имеет видимость internal.
HistoryFormatServiceРегистрирует EmployeeValidSinceAttrHistoryAdapter для отображения истории атрибутов, зависящих от времени.
TimesheetDaoИспользуется getReportOfMonth() для агрегации данных табеля по сотруднику/месяцу.

Логика активности

isEmployeeActive(employee, showRecentlyLeavers): Возвращает true, если:

  • Нет даты увольнения: Сотрудник активен, если пользователь не удалён и не деактивирован (null-пользователь = активен, для тестов).
  • Есть дата увольнения: Сотрудник активен, если дата увольнения наступила не раньше референсной даты (now или now минус 3 месяца, если showRecentlyLeavers=true).

Методы атрибутов, зависящих от времени

Все методы, зависящие от времени, проходят по записям ValidSinceAttrDO, отсортированным по validSince DESC, и выбирают запись, чьё validSince не позднее референсной даты. Методы сгруппированы по типу атрибута:

  • Ежегодный отпуск: getAnnualLeaveDays() (с датой/без даты), selectAnnualLeaveDayEntries() (по сотруднику или ID), insertAnnualLeaveDays()
  • Недельные часы: getWeeklyWorkingHours() (с датой/без даты), selectWeeklyWorkingHoursEntries() (по сотруднику или ID), insertWeeklyHours()
  • Статус: getEmployeeStatus(), selectStatusEntries(), insertStatus()

CRUD-операции ValidSinceAttr

Сервис предоставляет полный CRUD для EmployeeValidSinceAttrDO:

  • insert() — Вставка с ID сотрудника или сущностью, делегирует EmployeeServiceSupport
  • updateValidSinceAttr() — Обновление с семантикой копирования (обрабатывает повторное использование удалённых записей)
  • markValidSinceAttrAsDeleted() — Мягкое удаление
  • undeleteValidSinceAttr() — Восстановление
  • validate() — Возвращает строку с сообщением об ошибке или null, если данные валидны

Ежемесячный отчёт по сотрудникам

getReportOfMonth(year, month, user) создаёт MonthlyEmployeeReport, инициализирует границы дат, запрашивает табели через TimesheetFilter для указанного пользователя и диапазона месяцев, добавляет каждый табель (с информацией о проверке доступа) и вычисляет агрегированные длительности по Kost2.
