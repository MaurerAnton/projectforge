File #94: DataTransferPersonalBoxPageRest.kt

Path: plugins/datatransfer/.../rest/DataTransferPersonalBoxPageRest.kt · Source: GitHub

Personal box navigation page. Shows a user picker — admins/managers can select any user to view their personal box files (via DataTransferPageRest). The selected user ID is persisted in userPrefService ("datatransfer/personalbox"). ensurePersonalBox() auto-creates the box if needed. Back button returns to the area list. "Next" button navigates to the selected user's file page.
