#940: Kost1DO.kt

Type: JPA Entity (DO) · Purpose: Kost1 cost center master data entity · Source: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/kost/Kost1DO.kt
Represents a Kost1 cost center — the 8-digit cost carrier used in ProjectForge's financial accounting system. Kost1 is the coarser cost granularity (compared to Kost2), identified by a 4-part numeric code: Nummernkreis (1 digit), Bereich (3 digits), Teilbereich (2 digits), Endziffer (2 digits).

Persistence Details

  • Mapped to table T_FIBU_KOST1 with a 4-column unique constraint on (nummernkreis, bereich, teilbereich, endziffer)
  • Extends DefaultBaseDO — inherits id, created, lastUpdate, deleted
  • Implements DisplayNameCapable — provides automatic display name for lists
  • Hibernate Search indexed via @Indexed with @FullTextField on description
  • Equals/hashCode based on the 4 numeric components (business key)

Caching Integration

Kost1DO instances are cached in KostCache (keyed by ID in kost1Map). The cache is updated via KostCache.updateKost1() after insert/modify operations. Lookup methods support finding Kost1 by numeric string or by index components.
