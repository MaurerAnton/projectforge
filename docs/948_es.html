#948: IRechnung.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnung.kt Tipo: Interfaz · Propósito: Contrato abstracto para objetos similares a facturas utilizados por RechnungCalculator · Fuente: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnung.kt 35 líneas · 7 código · 25 comentarios · 3 en blanco
Interfaz principal necesaria para RechnungCalculator en cálculos polimórficos de facturas. Proporciona una API unificada sobre facturas emitidas (RechnungDO) y facturas recibidas (EingangsrechnungDO), exponiendo el monto del pago, las posiciones y la moneda.

Diseño de la interfaz

PropiedadTipoDescripción
zahlBetragBigDecimal?Monto total del pago (anulable)
positionenList?Lista de posiciones de la factura
currencyString?Código de moneda ISO (ej. "EUR", "USD")

Implementaciones

  • AbstractRechnungDO — clase base tanto para facturas emitidas como recibidas
  • RechnungDO — facturas emitidas a clientes
  • EingangsrechnungDO — facturas recibidas de proveedores

Justificación del diseño

Introducida junto con IRechnungsPosition para desacoplar el RechnungCalculator de los tipos de entidad concretos. Esto permite que la misma lógica de cálculo (sumas netas/brutas, IVA, conversión de moneda) opere sobre cualquier DTO similar a una factura sin dependencias de entidades JPA. El campo currency se agregó posteriormente para soportar el procesamiento de facturas en múltiples monedas.

Análisis de arquitectura

Reside en projectforge-business, el módulo central que contiene lógica de dominio, servicios y persistencia. Define un contrato/interfaz que múltiples implementaciones pueden satisfacer, permitiendo comportamiento polimórfico y capacidad de prueba.
