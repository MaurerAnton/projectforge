#948: IRechnung.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnung.kt Type : Interface · Objectif : Contrat abstrait pour les objets de type facture utilisés par RechnungCalculator · Source : projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnung.kt 35 lignes · 7 code · 25 commentaires · 3 vides
Interface centrale nécessaire à RechnungCalculator pour les calculs de factures polymorphes. Fournit une API unifiée pour les factures sortantes (RechnungDO) et les factures entrantes (EingangsrechnungDO), exposant le montant du paiement, les positions et la devise.

Conception de l'interface

PropriétéTypeDescription
zahlBetragBigDecimal?Montant total du paiement (nullable)
positionenList?Liste des positions de la facture
currencyString?Code devise ISO (ex. "EUR", "USD")

Implémentations

  • AbstractRechnungDO — classe de base pour les factures entrantes et sortantes
  • RechnungDO — factures sortantes vers les clients
  • EingangsrechnungDO — factures entrantes des fournisseurs

Justification de la conception

Introduite avec IRechnungsPosition pour découpler le RechnungCalculator des types d'entités concrets. Cela permet à la même logique de calcul (totaux nets/bruts, TVA, conversion de devises) de fonctionner sur n'importe quel DTO de type facture sans dépendances d'entités JPA. Le champ currency a été ajouté ultérieurement pour prendre en charge le traitement des factures multi-devises.

Analyse architecturale

Réside dans projectforge-business, le module central contenant la logique métier, les services et la persistance. Définit un contrat/interface que plusieurs implémentations peuvent satisfaire, permettant un comportement polymorphe et une testabilité.
