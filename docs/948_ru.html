#948: IRechnung.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnung.kt Тип: Интерфейс · Назначение: Абстрактный контракт для объектов, подобных счетам, используемых RechnungCalculator · Источник: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnung.kt 35 строк · 7 кода · 25 комментариев · 3 пустых
Основной интерфейс, необходимый RechnungCalculator для полиморфных расчётов по счетам. Предоставляет единый API для исходящих счетов (RechnungDO) и входящих счетов (EingangsrechnungDO), раскрывая сумму платежа, позиции и валюту.

Дизайн интерфейса

СвойствоТипОписание
zahlBetragBigDecimal?Общая сумма платежа (может быть null)
positionenList?Список позиций счёта
currencyString?Код валюты ISO (например, "EUR", "RUB")

Реализации

  • AbstractRechnungDO — базовый класс для входящих и исходящих счетов
  • RechnungDO — исходящие счета клиентам
  • EingangsrechnungDO — входящие счета от поставщиков

Обоснование дизайна

Введён вместе с IRechnungsPosition для отделения RechnungCalculator от конкретных типов сущностей. Это позволяет одной и той же логике расчёта (нетто/брутто суммы, НДС, конвертация валют) работать с любым DTO, подобным счёту, без зависимостей от JPA-сущностей. Поле currency было добавлено позже для поддержки обработки счетов в нескольких валютах.

Анализ архитектуры

Находится в projectforge-business, основном модуле, содержащем доменную логику, сервисы и персистентность. Определяет контракт/интерфейс, который могут реализовать несколько реализаций, обеспечивая полиморфное поведение и тестируемость.
