projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnungsPosition.kt Tipo: Interfaz · Propósito: Contrato abstracto para elementos de posición de factura utilizados por RechnungCalculator · Fuente: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnungsPosition.kt 34 líneas · 9 código · 22 comentarios · 3 en blanco
Interfaz principal que define el contrato para elementos de línea individuales dentro de una factura. Funciona en conjunto con IRechnung para desacoplar el motor de cálculo de facturas de los tipos de entidad JPA concretos.

Diseño de la Interfaz

PropiedadTipoDescripción
idLong?Identificador de base de datos (nullable para posiciones nuevas)
deletedBooleanIndicador de borrado lógico
mengeBigDecimal?Cantidad del elemento de línea
einzelNettoBigDecimal?Precio unitario neto de un solo artículo
vatBigDecimal?Tasa de IVA como porcentaje (ej. 19.00)

Implementadores

  • AbstractRechnungsPositionDO — clase base que implementa IRechnungsPosition
  • RechnungsPositionDO — posición de factura de salida
  • EingangsrechnungsPositionDO — posición de factura de entrada

Justificación del Diseño

Introducida junto con IRechnung (commit 07cb34acb) para permitir que RechnungCalculator calcule totales netos/brutos, montos de IVA y resúmenes de costos sin depender de tipos de entidad concretos. La propiedad deleted permite que el calculador omita posiciones con borrado lógico. El uso de BigDecimal para montos financieros garantiza precisión (sin errores de punto flotante).

Análisis de Arquitectura

Reside en projectforge-business, el módulo central que contiene lógica de dominio, servicios y persistencia. Define un contrato/interfaz que múltiples implementaciones pueden satisfacer, permitiendo comportamiento polimórfico y capacidad de prueba.
