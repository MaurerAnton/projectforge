#949: IRechnungsPosition.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnungsPosition.kt Type : Interface · Objectif : Contrat abstrait pour les postes de facture utilisés par RechnungCalculator · Source : projectforge-business/src/main/kotlin/org/projectforge/business/fibu/IRechnungsPosition.kt 34 lignes · 9 code · 22 commentaires · 3 vides
Interface centrale définissant le contrat pour les lignes individuelles d'une facture. Fonctionne de concert avec IRechnung pour découpler le moteur de calcul de facturation des types d'entités JPA concrets.

Conception de l'interface

PropriétéTypeDescription
idLong?Identifiant en base de données (nullable pour les nouvelles positions)
deletedBooleanIndicateur de suppression logique
mengeBigDecimal?Quantité de l'article
einzelNettoBigDecimal?Prix unitaire net d'un article
vatBigDecimal?Taux de TVA en pourcentage (ex. 19.00)

Implémentations

  • AbstractRechnungsPositionDO — classe de base implémentant IRechnungsPosition
  • RechnungsPositionDO — position de facture sortante
  • EingangsrechnungsPositionDO — position de facture entrante

Justification de la conception

Introduite parallèlement à IRechnung (commit 07cb34acb) pour permettre à RechnungCalculator de calculer les totaux brut/net, les montants de TVA et les résumés de coûts sans dépendre de types d'entités concrets. La propriété deleted permet au calculateur d'ignorer les positions supprimées logiquement. L'utilisation de BigDecimal pour les montants financiers garantit la précision (pas d'erreurs de virgule flottante).

Analyse architecturale

Réside dans projectforge-business, le module central contenant la logique métier, les services et la persistance. Définit un contrat/interface que plusieurs implémentations peuvent satisfaire, permettant un comportement polymorphe et la testabilité.
