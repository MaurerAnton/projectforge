File #95: DataTransferRestUtils.kt

Path: plugins/datatransfer/.../rest/DataTransferRestUtils.kt · Source: GitHub

Utility object for multi-file download with audit trail. Wraps AttachmentsRestUtils.multiDownload() and additionally inserts an audit entry (DOWNLOAD_MULTI or DOWNLOAD_ALL) via DataTransferAuditDao. Lazily obtains the audit DAO from Spring context to avoid circular dependency issues.
