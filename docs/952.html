#952: RechnungDO.kt

Type: JPA Entity (DO) · Purpose: Outgoing invoice entity (Ausgangsrechnung) · Source: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungDO.kt
Represents an outgoing invoice issued to a customer. Extends AbstractRechnungDO to inherit common invoice properties (date, payment amount, etc.) and implements IRechnung via the abstract parent. Contains the invoice-specific fields: sequential number, customer reference, project link, status, type, and child positions.

Inheritance Hierarchy

  • DefaultBaseDO → AbstractRechnungDO → RechnungDO
  • Implements Comparable<RechnungDO> — ordered by date then number
  • AbstractRechnungDO provides: datum, zahlBetrag, zahlungsZielInTagen, faelligkeit, counter, currency, bemerkung, uiStatus, plus recalculate() and position management

Persistence Details

  • Mapped to t_fibu_rechnung with indexes on konto_id, kunde_id, projekt_id
  • Named queries: SELECT_MIN_MAX_DATE (for year range), FIND_OTHER_BY_NUMMER (duplicate check)
  • @JsonManagedReference on positionen — outward side of the bidir relationship
  • @ListIndexBase(1) — position numbering starts at 1
  • FetchType.LAZY on all associations for performance
  • All Kotlin properties declared open for Hibernate proxy support

Position Management

The entity provides position list management inherited from AbstractRechnungDO:

  • ensureAndGetPositionen() — lazy-initializes the list if null
  • addPositionWithoutCheck(position) — adds and sets back-reference
  • setAbstractRechnung(position) — sets the parent reference (polymorphic)
