#954: RechnungsPositionDO.kt

Type: JPA Entity (DO) · Purpose: Outgoing invoice line item (position) · Source: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungsPositionDO.kt
Represents a single line item (position) within an outgoing invoice. Extends AbstractRechnungsPositionDO for shared position logic (number, title, quantity, net price, VAT). Adds outgoing-invoice-specific fields: back-reference to the parent RechnungDO, optional link to an order position (AuftragsPositionDO), and per-position period of performance settings.

Persistence Details

  • Mapped to t_fibu_rechnung_position with unique constraint on (rechnung_fk, number)
  • Indexes on auftrags_position_fk and rechnung_fk
  • Cost assignments fetched LAZY with @JsonManagedReference (parent side of bidir)
  • checkKostZuweisungId() validates that a cost assignment belongs to this position
  • newClone() creates a deep copy including cloned cost assignments (for invoice cloning)

Period of Performance

Each position can have its own period of performance, controlled by periodOfPerformanceType: - SEEABOVE: Inherits from the parent invoice's period - EXACT: Uses periodOfPerformanceBegin / periodOfPerformanceEnd - NONE: No period specified

@Entity @Indexed @Table(name = "t_fibu_rechnung_position", ...)
open class RechnungsPositionDO : AbstractRechnungsPositionDO() {
    @JsonBackReference @ManyToOne(fetch = LAZY)
    @JoinColumn(name = "rechnung_fk", nullable = false)
    open var rechnung: RechnungDO? = null

    @ManyToOne(fetch = LAZY) @JoinColumn(name = "auftrags_position_fk")
    open var auftragsPosition: AuftragsPositionDO? = null

    @Enumerated(STRING) @Column(name = "period_of_performance_type")
    open var periodOfPerformanceType: PeriodOfPerformanceType? = SEEABOVE
    open var periodOfPerformanceBegin: LocalDate? = null
    open var periodOfPerformanceEnd: LocalDate? = null

    @OneToMany(mappedBy = "rechnungsPosition", fetch = LAZY)
    @OrderColumn(name = "index") @JsonManagedReference
    override var kostZuweisungen: MutableList<KostZuweisungDO>? = null

    fun newClone(): RechnungsPositionDO {
        val clone = newInstance()
        clone.copyValuesFrom(this, "id", "kostZuweisungen")
        this.kostZuweisungen?.forEach {
            clone.addKostZuweisung(it.newClone())
        }
        return clone
    }
}
