#956: ReportBwa

Type: Java Interface  |  Purpose: BWA (Betriebswirtschaftliche Auswertung) report structure
Source: projectforge-business/src/main/java/org/projectforge/reporting/ReportBwa.java
Note: Specified as .kt but actually exists as .java under org.projectforge.reporting.

Defines the contract for the German BWA (Betriebswirtschaftliche Auswertung — operational economic analysis) report. This interface exposes 23 line items representing the standardized DATEV BWA schema, covering revenue, cost categories, and profit calculation for financial reporting.

Architecture & Design

ReportBwa is a pure interface that defines getter methods for each BWA line. Each method returns a ReportBwaZeile object. Implementations are responsible for populating the BWA columns with computed financial data. The 23 line items form a complete income statement (GuV) structure:

Relationship to ReportBwaZeile

Each method returns a ReportBwaZeile (doc #957) which encapsulates the line number, indentation, label, BWA value, and priority. This two-interface design separates the structural schema from the individual cell data.
