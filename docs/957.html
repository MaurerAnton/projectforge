#957: ReportBwaZeile

Type: Java Interface  |  Purpose: Single line item in a BWA report
Source: projectforge-business/src/main/java/org/projectforge/reporting/ReportBwaZeile.java
Note: Specified as .kt but actually exists as .java under org.projectforge.reporting.

Represents a single row in the DATEV BWA (operational economic analysis) report. Each instance holds the line number, label, indentation, priority, and the computed BWA monetary value for that line. Used exclusively as the return type of ReportBwa (doc #956) getter methods.

Architecture & Design

This is a simple data-bearing interface with five properties:

MethodReturn TypeDescription
getPriority()Priority (enum)Priority/severity from org.projectforge.common.i18n.Priority. Used for color-coding or flagging in reports.
getZeile()intThe DATEV BWA line number (Datev-Zeilennummer) from the standardized BWA schema. Maps to the official DATEV chart line.
getBezeichnung()StringHuman-readable label for the BWA line (e.g. "Umsatzerlöse").
getIndent()intIndentation depth, matching the DATEV Excel export format. Controls visual hierarchy in reports.
getBwaWert()BigDecimalThe computed monetary value for this BWA line as a high-precision decimal.

Design Rationale

The interface-based design (rather than a concrete class) allows implementations to lazily compute getBwaWert(), deferring database queries until the value is actually accessed. The Priority field enables highlighting of exceptional values (e.g., negative margins) in the rendered report. The indent property mirrors the hierarchical structure of the official DATEV BWA format.

Relationship to ReportBwa

Each of the 23 methods in ReportBwa (doc #956) returns a ReportBwaZeile. Since this is an interface, concrete implementations are typically provided by report data providers that compute actual financial values from the general ledger.
