File #96: DataTransferPublicAccessChecker.kt

Path: plugins/datatransfer/.../restPublic/DataTransferPublicAccessChecker.kt · Source: GitHub

Public (anonymous) access checker. Session-based ownership — files uploaded by an anonymous user are tracked in DataTransferPublicSession. When externalDownloadEnabled=false, filterAttachments() only returns the user's own uploaded files. When enabled, all files are visible. Delete/update access requires both externalUploadEnabled=true AND session ownership of the file. Internal check methods (checkSelectAccess, etc.) are empty — all security is handled by hasDownloadAccess/hasDeleteAccess methods.
