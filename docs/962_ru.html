#962: OrderInfo.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/OrderInfo.kt Модель информации о заказе/выставлении счетов, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/OrderInfo.kt 340 строк · 221 код · 85 комментариев · 34 пустых
Сериализуемый информационный объект для заказа (AuftragDO) с рассчитанными финансовыми сводками. Отслеживает чистую сумму, заказанную чистую сумму, сумму аквизиции, сумму по выставленным счетам, сумму к выставлению, человеко-дни и статус графика платежей. Содержит внутренний класс PaymentScheduleInfo и методы calculateAll(), calculateInvoicedSum(), calculateToBeInvoicedSum() и calculateIsVollstaendigFakturiert() для определения статуса полной выставленности счетов на основе позиций и графиков платежей.
