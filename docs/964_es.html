Entidad JPA mapeada a la tabla T_FIBU_PAYMENT_SCHEDULE. Representa un hito de pago dentro de un pedido. Campos: fecha de programación, importe, comentario, indicador de alcanzado e indicador vollstaendigFakturiert (totalmente facturado). Tiene una relación muchos a uno con AuftragDO y un positionNumber opcional que lo vincula a una posición de pedido específica. Implementa DisplayNameCapable y DefaultBaseDO. Migrado originalmente desde Java (2019-06-19).
