#967: AbstractKost2PagesRest

Type: Planned · Abstract REST controller (not yet in codebase)
Intended path: projectforge-business/src/main/kotlin/org/projectforge/business/fibu/rest/AbstractKost2PagesRest.kt

This file does not exist in the current codebase and has no git history. Based on naming, it is intended as an abstract base class for Kost2 (cost center type 2 / sub-cost center) REST pages, analogous to AbstractKost1PagesRest (doc #966) but for the Kost2 entity hierarchy.

Design (Inferred)

Kost2 entities reference a parent Kost1 and a Kost2Art (cost type category). This abstract class would provide:

  • Kost1 dependency handling: Logic for loading the parent Kost1 when transforming Kost2 DOs to DTOs and vice versa.
  • Kost2Art filtering: Filter dropdowns populated from Kost2ArtDO values.
  • Active status filtering: Similar to Kost1 but with Kost2-specific inactive status handling.
  • Formatted display names: Kost2 identifiers formatted via KostFormatter (e.g., "1.2.3 - Description").
