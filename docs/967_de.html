projectforge-business/src/main/kotlin/org/projectforge/business/fibu/ProjektDO.kt JPA-Entität, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/ProjektDO.kt 253 Zeilen · 165 Code · 60 Kommentare · 28 leer
JPA-Entität, die auf die Tabelle T_FIBU_PROJEKT abgebildet wird und ein Projekt innerhalb von KOST2 (Ziffern 5-6) repräsentiert. Schlüsselfelder: nummer, name, identifier, internKost2_4, status (ProjektStatus-Enum), description. Besitzt lazy-geladene Beziehungen zu KundeDO, PFUserDO (Projektleiter, Hauptgeschäftsführer, Vertriebsleiter), GroupDO (Projektleiter-Gruppe), TaskDO und KontoDO. Gültige Kostenstellenbereiche: 4xxxxx (intern, kein Kunde) und 5xxxxx (Kundenprojekt). Volltextindiziert über Hibernate Search mit einem benutzerdefinierten HibernateSearchProjectKostTypeBinder.
