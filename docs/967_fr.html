#967: ProjektDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/ProjektDO.kt Entité JPA, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/ProjektDO.kt 253 lignes · 165 code · 60 commentaires · 28 vides
Entité JPA mappée à la table T_FIBU_PROJEKT représentant un projet dans KOST2 (chiffres 5-6). Champs clés : nummer, name, identifier, internKost2_4, status (enum ProjektStatus), description. Possède des relations chargées paresseusement vers KundeDO, PFUserDO (projectManager, headOfBusinessManager, salesManager), GroupDO (projektManagerGroup), TaskDO et KontoDO. Plages de centres de coûts valides : 4xxxxx (interne, sans kunde) et 5xxxxx (projet client). Indexé en texte intégral via Hibernate Search avec un HibernateSearchProjectKostTypeBinder personnalisé.
