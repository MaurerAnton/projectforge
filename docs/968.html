#968: AddressPagesRest

Type: REST Controller (Spring)  |  Purpose: Address book CRUD, import/export, VCF parsing, duplicate detection, image handling
Source: projectforge-rest/src/main/kotlin/org/projectforge/rest/AddressPagesRest.kt
Extends: AbstractDTOPagesRest<AddressDO, Address, AddressDao>
Endpoint: /rs/address

The primary REST controller for the address book module — one of the largest and most feature-rich controllers in ProjectForge. Handles full CRUD, duplicate detection, VCF (vCard) import/export, address text parsing, image upload/preview, favorite management, filter-based Excel export, and CardDAV integration. This is the most actively developed controller with 200+ commits in its history.

Key Features

  • Duplicate Detection: onWatchFieldsUpdate() monitors name/firstName changes and queries the DAO for potential duplicates. Uses markdown-formatted alert messages.
  • VCF Import Reconciliation: reconcileImportStorageAfterAddressChange() synchronizes the import storage state after CRUD operations, marking entries as IMPORTED.
  • Modal Edit Flow: onAfterEdit() returns CLOSE_MODAL when editing in modal context, with updated import entries for VCF import context.
  • Text Parser: parseText() endpoint delegates to AddressTextImportService to parse email signatures/address blocks. applyParsedData() applies selected parsed fields to the address DTO.
  • Image Handling: onAfterSaveOrUpdate() manages image lifecycle — deleting when imageDeleted flag is set, uploading from session attributes when provided.
  • VCF Image Support: applyParsedData() handles Base64-encoded VCF images forwarded to the frontend for upload.
  • Excel Export: exportAsExcel() generates an Excel file of address data including favorite information.
  • Validation: Requires at least one of name, firstName, or organization; requires at least one address book assignment.
  • Magic Filters: Supports myFavorites, doublets, images, and myEntries as synthetic custom result filters.

List Layout (AG-Grid)

Uses AGGridSupport.prepareUIGrid4ListPage() with columns: edit icon (modal), isFavoriteCard (star), name, firstName, lastUpdate, addressStatus, contactStatus, imagePreview, organization, email, phoneNumbers (custom renderer), addressbookList. Multi-row selection support for mass operations. Row click opens the address view page in a modal.

Edit Layout

Complex multi-fieldset layout with business/private/postal address sections, text parser collapse panel, duplicate warning alert, image upload component, and public key fields. Watch fields on name/firstName trigger duplicate checks.

Menu Items

Injects CardDAV info, vCard export, vCard import, Apple Script download, and custom GEO context menu entries into the layout menu.
