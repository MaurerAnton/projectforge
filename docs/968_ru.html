#968: ProjektDao.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/ProjektDao.kt Объект доступа к данным (DAO), projectforge-business/src/main/kotlin/org/projectforge/business/fibu/ProjektDao.kt 228 строк · 158 кода · 45 комментариев · 25 пустых
Spring @Service DAO, расширяющий BaseDao<ProjektDO> для операций CRUD над проектами. Управляет связями проект-клиент, проект-задача и проект-менеджер-группа. Поддерживает полнотекстовый поиск по имени клиента, подразделения, менеджера. Обрабатывает фильтрацию по статусу завершён/не завершён и предоставляет методы для setKunde, setTask, setProjektManagerGroup и getProjekt по клиенту+номеру или internKost2_4+номеру. Интегрирует записи истории из дочерних элементов Kost2DO. Доступ контролируется через UserRightId.PM_PROJECT.
