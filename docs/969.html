#969: AuftragPagesRest

Type: REST Controller (Spring)  |  Purpose: Order (Auftrag) list and attachment management
Source: projectforge-rest/src/main/kotlin/org/projectforge/rest/fibu/AuftragPagesRest.kt
Extends: AbstractDTOPagesRest<AuftragDO, Auftrag, AuftragDao>
Endpoint: /rs/order

REST controller for Auftrag (order/project order) management. Provides a list page with financial summaries and filtering, and an edit page primarily for attachment management. The full order edit form is still under construction (the _createEditLayoutUnderConstruction method shows planned layout). JCR (content repository) is enabled for file attachments.

Magic Filters

Implements sophisticated custom result filtering using synthetic filter entries:

  • positionsArt → AuftragsPositionsArtFilter
  • positionsStatus → AuftragsPositionsStatusFilter
  • positionsPaymentType → AuftragsPositionsPaymentTypeFilter
  • fakturiert → AuftragFakturiertFilter
  • status (default filter) → Standard enum filter

All position-based filters are marked as synthetic = true so they bypass Hibernate query generation and are applied in-memory via CustomResultFilter implementations.

Edit Layout

The current edit page is attachment-only: shows order summary (number, customer, project, net sum) as read-only fields and an attachment upload/list component. Delete/update/cancel are disabled. This is a deliberate simplification — the full order editing features are planned in _createEditLayoutUnderConstruction() which defines a comprehensive layout with customer, project, managers, dates, positions list, and payment schedules.

DTO Conversion

Uses straightforward copyTo()/copyFrom() between AuftragDO and Auftrag DTO. The @PostConstruct enables JCR attachment support via enableJcr().
