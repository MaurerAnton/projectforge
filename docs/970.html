#970: BookPagesRest

Type: REST Controller (Spring)  |  Purpose: Book library CRUD with lending management
Source: projectforge-rest/src/main/kotlin/org/projectforge/rest/BookPagesRest.kt
Extends: AbstractDTOPagesRest<BookDO, Book, BookDao>
Endpoint: /rs/book

REST controller for the book library module. Manages books with full CRUD, signature uniqueness validation, lending/return tracking, and JCR attachments. New books default to status PRESENT and type BOOK.

Edit Layout

Two-column layout with: title, authors, type, status, year, signature (left column); ISBN, publisher, editor (right column); keywords. Lending section (shown only for existing books) with a custom UICustomized("book.lendOutComponent") and comment field. Attachment section at the bottom.

Validation

  • Year range: yearOfPublishing validated between Constants.MINYEAR and Constants.MAXYEAR.
  • Signature uniqueness: doesSignatureAlreadyExist() check prevents duplicate library signatures.

Jackson Configuration

Registers unknown properties statusAsString and typeAsString on the Book DTO to prevent deserialization errors for AG-Grid formatted values.
