@Component Spring étendant AbstractRechnungCache<RechnungDO>. Met en cache les informations de facture (RechnungInfo) et les informations de poste de facture (RechnungPosInfo) pour les factures sortantes (RechnungDO) et entrantes (EingangsrechnungDO). Fait le pont entre les postes de facture et les postes de commande via AuftragsCache et AuftragsRechnungCache. Détecte automatiquement le type de facture à l'exécution. Sur @PostConstruct, s'enregistre comme instance singleton pour RechnungCalculator et AbstractRechnungsStatistik.
