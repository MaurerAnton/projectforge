This file does not exist in the current codebase and has no git history. Based on naming, it is intended as a REST controller for managing Buchungssatz (booking/journal entry) records — the core financial transaction entity in the ProjectForge double-entry bookkeeping system.

Design (Inferred)

Existing BuchungssatzDO and BuchungssatzDao exist in projectforge-business/src/main/kotlin/org/projectforge/business/fibu/kost/. The REST controller would provide:

  • CRUD operations: Create, read, update, delete booking entries (debit/credit pairs).
  • List with AG-Grid: Columns for date, debit account, credit account, amount, cost center (Kost1/Kost2), description, and document reference.
  • Filtering: By date range, account, cost center, amount range, and text search.
  • Import integration: Works with BuchungssatzExcelImporter for DATEV-format imports.
  • Validation: Double-entry balancing (sum of debits must equal sum of credits).
  • Extends: Likely AbstractDTOPagesRest<BuchungssatzDO, Buchungssatz, BuchungssatzDao>.
