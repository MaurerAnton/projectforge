#971: RechnungCalculator.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungCalculator.kt Berechnungs-Hilfsobjekt, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungCalculator.kt 229 Zeilen · 176 Code · 39 Kommentare · 14 leer
Kotlin object, das alle finanziellen Berechnungen für Rechnungen durchführt. Berechnet RechnungInfo aus AbstractRechnungDO: Nettosumme, Mehrwertsteuerbetrag (nach Steuersatz summiert, dann gemäß deutschem Recht gerundet), Bruttosumme, Bruttosumme mit Rabatt (falls innerhalb der Rabattfrist) sowie Kostenverteilung Netto-/Bruttosummen. Jede Position erhält berechnete Nettosumme, Mehrwertsteuer, Bruttosumme und Kostenverteilungssummen. Erkennt, ob die Rechnung bezahlt oder überfällig ist, und behandelt Rundungen auf Positionsebene oder Summenebene. Verweist auf RechnungCache und AuftragsCache für die Verknüpfung von Auftragspositionen.
