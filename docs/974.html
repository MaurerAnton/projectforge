Design (Inferred)

Existing currency infrastructure in projectforge-business/src/main/kotlin/org/projectforge/business/fibu/ includes:

  • CurrencyConversionService / CurrencyConversionServiceSupport
  • CurrencyConversionRateDO — Stores exchange rates per currency pair and date
  • CurrencyPairDO / CurrencyPairDao — Defines supported currency pairs
  • CurrencyConversionCache — Caches rates for performance
  • ExchangeRateApiService — Fetches live rates from external API

The REST controller would provide:

  • CRUD for currency pairs: Adding/removing supported currency pairs.
  • Exchange rate management: Viewing, editing, and importing historical exchange rates.
  • Live rate fetch: Triggering manual updates from external exchange rate APIs.
  • Extends: Likely AbstractDTOPagesRest for both CurrencyPairDO and CurrencyConversionRateDO.
