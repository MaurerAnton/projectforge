#974: RechnungInfo.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungInfo.kt Rechnungsinfo-Modell (DTO), projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungInfo.kt 118 Zeilen · 54 Code · 41 Kommentare · 23 leer
Serialisierbares DTO mit berechneten Informationen zu einer Rechnung – unterstützt sowohl RechnungDO (ausgehend) als auch EingangsrechnungDO (eingehend). Berechnet von RechnungCalculator. Felder: netSum, grossSum, vatAmount, grossSumWithDiscount (oder tatsächlich gezahlter Betrag), kostZuweisungenNetSum, kostZuweisungenFehlbetrag. Status-Flags: isBezahlt, isUeberfaellig. Abgeleitete Felder: faelligkeitOrDiscountMaturity, sortierte Listen von Kost1DO und Kost2DO aus allen Positionskostenzuweisungen. Companion stellt Hilfsfunktionen zur Zeichenkettenformatierung bereit.
