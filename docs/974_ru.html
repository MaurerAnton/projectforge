#974: RechnungInfo.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungInfo.kt Модель информации о счете (DTO), projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungInfo.kt 118 строк · 54 кода · 41 комментарий · 23 пустых
Сериализуемый DTO, содержащий расчётную информацию о счете — поддерживает как RechnungDO (исходящий), так и EingangsrechnungDO (входящий). Вычисляется с помощью RechnungCalculator. Поля: netSum, grossSum, vatAmount, grossSumWithDiscount (или фактически оплаченная сумма), kostZuweisungenNetSum, kostZuweisungenFehlbetrag. Флаги статуса: isBezahlt, isUeberfaellig. Производные поля: faelligkeitOrDiscountMaturity, отсортированные списки Kost1DO и Kost2DO из всех позиционных распределений затрат. Компаньон предоставляет вспомогательные функции форматирования строк.
