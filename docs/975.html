#975: CustomerPagesRest

Type: REST Controller (Spring)  |  Purpose: Customer (Kunde) CRUD with account selection and duplicate check
Source: projectforge-rest/src/main/kotlin/org/projectforge/rest/fibu/CustomerPagesRest.kt
Extends: AbstractDTOPagesRest<KundeDO, Customer, KundeDao>
Endpoint: /rs/customer

REST controller for customer master data (Kunde). Manages customer accounts with automatic customer number assignment, debtor account (Konto) selection via auto-completion, duplicate number detection via watch fields, and status tracking. The edit page has a TODO note indicating ongoing work on Konto selection UX.

Architecture & Design

DTO Conversion

Simple copyTo()/copyFrom() mapping between KundeDO and Customer DTO. Jackson registers statusAsString as an allowed unknown property on the DTO.

Edit Layout

Single-row layout with: number (read-only for existing, input for new), name (autofocus), Konto (with auto-completion URL account/acDebitors?search=:search), identifier, division, description, status.

Watch Fields & Validation

When nummer changes (new customers only), onWatchFieldsUpdate() checks for duplicate numbers via doesNumberAlreadyExist() and returns HTTP 406 (NOT_ACCEPTABLE) with a validation error if a conflict is found.

Auto-Completion

Search fields: name, identifier. Used globally for customer lookup throughout the application.
