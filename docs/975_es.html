#975: RechnungJdbcService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungJdbcService.kt Servicio JDBC, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungJdbcService.kt 179 líneas · 143 código · 28 comentarios · 8 en blanco
Spring @Service que utiliza JDBC puro (a través de JdbcTemplate) en lugar de Hibernate para acceso masivo a datos de alto rendimiento. Contiene dos consultas SQL principales: SELECT_RECHNUNG_WITH_KOST (une t_fibu_rechnung → t_fibu_rechnung_position → t_fibu_kost_zuweisung) y SELECT_EINGANGS_RECHNUNG_WITH_KOST (lo mismo para facturas entrantes). El método selectRechnungInfos() ensambla objetos completos RechnungInfo a partir de resultados JDBC planos. También proporciona selectRechnungsPositionenWithAuftragPosition() para obtener posiciones con sus posiciones de pedido vinculadas. Utilizado por AbstractRechnungCache para construir datos de caché.
