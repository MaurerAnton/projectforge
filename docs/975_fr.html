#975 : RechnungJdbcService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungJdbcService.kt Service JDBC, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungJdbcService.kt 179 lignes · 143 code · 28 commentaires · 8 vides
@Service Spring qui utilise du JDBC brut (via JdbcTemplate) au lieu d'Hibernate pour un accès aux données par lots à haute performance. Contient deux requêtes SQL principales : SELECT_RECHNUNG_WITH_KOST (joint t_fibu_rechnung → t_fibu_rechnung_position → t_fibu_kost_zuweisung) et SELECT_EINGANGS_RECHNUNG_WITH_KOST (identique pour les factures entrantes). La méthode selectRechnungInfos() assemble des objets RechnungInfo complets à partir des résultats JDBC plats. Fournit également selectRechnungsPositionenWithAuftragPosition() pour récupérer les positions avec leurs positions de commande liées. Utilisé par AbstractRechnungCache pour construire les données du cache.
