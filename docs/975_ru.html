#975: RechnungJdbcService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungJdbcService.kt JDBC Сервис, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungJdbcService.kt 179 строк · 143 кода · 28 комментариев · 8 пустых
Spring @Service, использующий чистый JDBC (через JdbcTemplate) вместо Hibernate для высокопроизводительного пакетного доступа к данным. Содержит два основных SQL-запроса: SELECT_RECHNUNG_WITH_KOST (объединяет t_fibu_rechnung → t_fibu_rechnung_position → t_fibu_kost_zuweisung) и SELECT_EINGANGS_RECHNUNG_WITH_KOST (то же самое для входящих счетов). Метод selectRechnungInfos() собирает полные объекты RechnungInfo из плоских результатов JDBC. Также предоставляет selectRechnungsPositionenWithAuftragPosition() для получения позиций с их связанными позициями заказов. Используется AbstractRechnungCache для построения кэш-данных.
