#976: EmployeePagesRest

Type: REST Controller (Spring)  |  Purpose: Employee master data with time-dependent attributes (status, hours, leave)
Source: projectforge-rest/src/main/kotlin/org/projectforge/rest/fibu/EmployeePagesRest.kt
Extends: AbstractDTOPagesRest<EmployeeDO, Employee, EmployeeDao>
Endpoint: /rs/employee

REST controller for employee master data. The most feature-rich controller in the fibu REST package, supporting employee creation with auto-redirect to edit, time-dependent attribute management (status history, weekly working hours, annual leave), modal sub-pages for attribute editing, active-employee filtering, and caches integration for Kost1 and user data.

Architecture & Design

Dependencies

DependencyPurpose
PfCachesInitializes lazy-loaded associations on DO before DTO conversion
EmployeeCacheSets time-dependent attributes on the DO
EmployeeServiceSelects status entries, weekly hours entries, annual leave entries
KostCacheResolves Kost1 for DTO display
UserGroupCacheResolves user details (firstname, lastname) for DTO

DTO Transformation

transformFromDB() is comprehensive: initializes caches, copies from DO, resolves user details (firstname/lastname) via UserGroupCache, resolves Kost1 via KostCache, sets time-dependent attrs, and populates status/weeklyHours/annualLeave.

Time-Dependent Attributes

onBeforeGetItemAndLayout() loads three collections of EmployeeValidSinceAttr entries from EmployeeService:

  • statusEntries — Employment status changes over time
  • weeklyWorkingHoursEntries — Changes in weekly working hours
  • annualLeaveEntries — Changes in annual leave entitlement

Magic Filter

Adds an "only active entries" boolean filter (default: true). The preProcessMagicFilter() marks it as synthetic and adds an EmployeeActiveFilter custom result filter. The commented-out status list filter suggests planned future enhancement.

Edit Layout

Two sections:

  1. Top: User, Kost1, Department, Position, Staff number, Entry/exit dates, Comment
  2. Below actions (new employees only): Info alert about subsequent attribute setup
  3. Below actions (existing employees only): Three AG-Grid tables for annual leave entries, weekly hours entries, and status entries — each with row-click modal navigation via EmployeeValidSinceAttrPageRest and an "Add" button opening the same page in create mode.

Post-Save Redirect

onAfterSave() redirects to the edit page after insert, enabling the user to add status, vacation, and weekly hours entries.

Auto-Completion

Search fields: user.username, user.firstname, user.lastname, user.email. Overrides queryAutocompleteObjects() to use selectWithActiveStatus() showing only active and recently departed employees.
