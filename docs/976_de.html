Serialisierbares DTO, das berechnete Informationen zu einer einzelnen Rechnungsposition (AbstractRechnungsPositionDO) enthält. Berechnet von RechnungCalculator. Kopiert Rohdaten (number, text, menge, einzelNetto, vat) und enthält berechnete Felder: netSum, grossSum, vatAmount, kostZuweisungNetSum, kostZuweisungGrossSum, kostZuweisungNetFehlbetrag. Verweist zurück auf die Auftragsposition über auftragsPositionId, auftragsId, auftragsPositionNummer. Implementiert Comparable zur Sortierung nach Rechnungsnummer, dann Positionsnummer. Hinweis: Importiert org.jetbrains.kotlin.ir.types.IdSignatureValues.result (wahrscheinlich ein Tippfehler/Fehler in Zeile 28).
