DTO sérialisable contenant les informations calculées sur une position de facture unique (AbstractRechnungsPositionDO). Calculé par RechnungCalculator. Copie les données brutes (number, text, menge, einzelNetto, vat) et contient les champs calculés : netSum, grossSum, vatAmount, kostZuweisungNetSum, kostZuweisungGrossSum, kostZuweisungNetFehlbetrag. Lien retour vers la position de commande via auftragsPositionId, auftragsId, auftragsPositionNummer. Implémente Comparable pour le tri par numéro de facture puis numéro de position.
