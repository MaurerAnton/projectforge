#977: EmployeeSalaryPagesRest

Type: REST Controller (Spring)  |  Purpose: Employee salary records (monthly payroll data)
Source: projectforge-rest/src/main/kotlin/org/projectforge/rest/fibu/EmployeeSalaryPagesRest.kt
Extends: AbstractDTOPagesRest<EmployeeSalaryDO, EmployeeSalary, EmployeeSalaryDao>
Endpoint: /rs/employeeSalary

REST controller for employee salary records. Manages monthly salary entries per employee, tracking salary type, gross amount (including employer contributions), and comments. The edit page has a TODO note indicating an unfinished month/year selector implementation.

Edit Layout

Simple single-row layout with employee name (last/first as read-only labels), a TODO UILabel placeholder for month/year selector, type, gross amount, and comment. The TODO indicates this page is still under construction.

DTO Conversion

Standard copyTo()/copyFrom() between EmployeeSalaryDO and EmployeeSalary DTO.

Notes

  • No magic filters, validation, or custom auto-completion are implemented — this is a relatively simple controller.
  • The EmployeeSalaryDO entity includes fields for month, salary type (EmployeeSalaryType enum), gross with employer share, and references to the employee DO.
  • Integration with DATEV salary import exists via EmployeeSalaryExcelImporter and EmployeeSalaryImportService.
