#977: RechnungService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungService.kt Service (Tupel-Abfrage), projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungService.kt 154 Zeilen · 122 Code · 25 Kommentare · 7 leer
Spring @Service unter Verwendung von JPA-Tupelabfragen zum Batch-Abruf von Rechnungspositionen und Kostenverteilungen. fetchPositionen() lädt Positionen für eine Liste von Rechnungen (sowohl RechnungDO als auch EingangsrechnungDO) in einer einzigen Abfrage massenhaft, um Hibernate-Lazy-Loading-N+1-Probleme zu vermeiden. selectKostzuweisungen() ruft Kostenzuweisungsdaten über mehrere Rechnungen hinweg ab und löst Kost1DO/Kost2DO über KostCache auf. Beide Methoden verwenden runIsolatedReadOnly für die Transaktionsisolierung. SQL-Vorlagen verwenden einfache Kotlin-Klassennamen und parametrisierte IN-Klauseln für die Batch-Effizienz.
