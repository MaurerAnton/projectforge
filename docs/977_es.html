#977: RechnungService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungService.kt Servicio (Consulta de Tuplas), projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungService.kt 154 líneas · 122 código · 25 comentarios · 7 en blanco
Spring @Service que utiliza consultas de tuplas JPA para la obtención por lotes de posiciones de factura y asignaciones de costos. fetchPositionen() carga en bloque las posiciones para una lista de facturas (tanto RechnungDO como EingangsrechnungDO) en una sola consulta para evitar problemas N+1 de carga diferida de Hibernate. selectKostzuweisungen() obtiene datos de asignación de costos entre facturas, resolviendo Kost1DO/Kost2DO a través de KostCache. Ambos métodos utilizan runIsolatedReadOnly para aislamiento transaccional. Las plantillas SQL utilizan nombres simples de clase Kotlin y cláusulas IN parametrizadas para eficiencia por lotes.
