#977: RechnungService.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungService.kt Сервис (Tuple Query), projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungService.kt 154 строки · 122 кода · 25 комментариев · 7 пустых
Spring @Service, использующий JPA tuple-запросы для пакетной загрузки позиций счетов и назначений затрат. fetchPositionen() массово загружает позиции для списка счетов (как RechnungDO, так и EingangsrechnungDO) в одном запросе, чтобы избежать проблем N+1 при ленивой загрузке Hibernate. selectKostzuweisungen() извлекает данные о назначении затрат по всем счетам, разрешая Kost1DO/Kost2DO через KostCache. Оба метода используют runIsolatedReadOnly для транзакционной изоляции. SQL-шаблоны используют краткие имена классов Kotlin и параметризованные предложения IN для эффективности пакетной обработки.
