This file does not exist in the current codebase and has no git history. Based on naming, it is intended as a REST controller serving data for a Gantt chart visualization of project orders (Auftrag) and their positions, likely for project management and resource planning dashboards.

Design (Inferred)

A Gantt view in the ProjectForge context would visualize orders/positions over time. Expected functionality:

  • Data source: Queries AuftragDO and AuftragsPositionDO entities filtered by date range, project, and/or customer.
  • Timeline: Uses periodOfPerformanceBegin and periodOfPerformanceEnd from order positions as bar start/end dates.
  • Grouping: Hierarchical grouping by project → order → position, or by assigned employee.
  • Color coding: Based on order status (open, in progress, completed, invoiced) or position type (internal, external).
  • Resource view: Option to show employee assignments per time period.
  • API format: Likely returns JSON structured for a JavaScript Gantt library (e.g., DHTMLX Gantt, AnyGantt, or Frappe Gantt).
  • Extends: Could extend AbstractPagesRest or be a specialized service controller rather than a CRUD pages rest.
