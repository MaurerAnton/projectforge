#979: HRPlanningPagesRest

Type: REST Controller (Spring)  |  Purpose: Human resources planning overview
Source: projectforge-rest/src/main/kotlin/org/projectforge/rest/hr/HRPlanningPagesRest.kt
Extends: AbstractDOPagesRest<HRPlanningDO, HRPlanningDao>
Endpoint: /rs/hrPlanning

REST controller for HR planning — provides a high-level overview of employee resource allocation. Note that unlike most other controllers, this extends AbstractDOPagesRest (working directly with DOs) rather than AbstractDTOPagesRest (which uses DTOs). The edit page is a placeholder with a TODO label, indicating this is a work-in-progress.

Architecture & Design

Class Hierarchy

AbstractPagesRest
  └─ AbstractDOPagesRest<HRPlanningDO, HRPlanningDao>
       └─ HRPlanningPagesRest

Unlike DTO-based controllers, this directly exposes HRPlanningDO without a DTO transformation layer.

List Layout

ColumnField
Useruser
Total hours (sum)totalHours
Unassigned hours (rest)totalUnassignedHours

The list shows per-user totals: how many hours are planned/assigned and how many remain unassigned, providing a quick capacity overview.
