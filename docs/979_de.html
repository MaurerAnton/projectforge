#979: RechnungsPositionDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungsPositionDO.kt JPA-Entität, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungsPositionDO.kt 122 Zeilen · 78 Code · 32 Kommentare · 12 leer
JPA-Entität, die auf die Tabelle t_fibu_rechnung_position abgebildet wird und eine Position innerhalb einer Ausgangsrechnung repräsentiert. Erweitert AbstractRechnungsPositionDO. Besitzt eine @JsonBackReference-Many-to-One-Beziehung zu RechnungDO (eindeutige Einschränkung auf rechnung_fk + Nummer). Verknüpft mit einer Auftragsposition über auftragsPosition (Many-to-One zu AuftragsPositionDO, lazy). Unterstützt einen eigenständigen Leistungszeitraum über periodOfPerformanceType, periodOfPerformanceBegin, periodOfPerformanceEnd. Kostenverteilungen sind @JsonManagedReference-One-to-Many zu KostZuweisungDO, geordnet nach Index. Stellt newClone() für das tiefe Klonen mit Kostenverteilungen bereit. Ursprünglich aus Java migriert (2019-06-12).
