Entidad JPA mapeada a la tabla t_fibu_rechnung_position que representa una línea de detalle dentro de una factura emitida. Extiende AbstractRechnungsPositionDO. Tiene una relación muchos-a-uno con @JsonBackReference hacia RechnungDO (restricción única en rechnung_fk + número). Se vincula a una posición de pedido mediante auftragsPosition (muchos-a-uno con AuftragsPositionDO, lazy). Soporta período de ejecución independiente mediante periodOfPerformanceType, periodOfPerformanceBegin, periodOfPerformanceEnd. Las asignaciones de costos son @JsonManagedReference uno-a-muchos hacia KostZuweisungDO ordenadas por índice. Proporciona newClone() para clonación profunda con asignaciones de costos. Migrado originalmente desde Java (2019-06-12).
