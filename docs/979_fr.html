projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungsPositionDO.kt Entité JPA, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungsPositionDO.kt 122 lignes · 78 code · 32 commentaires · 12 vides
Entité JPA mappée à la table t_fibu_rechnung_position représentant une ligne d'écriture dans une facture sortante. Étend AbstractRechnungsPositionDO. Possède une relation many-to-one @JsonBackReference vers RechnungDO (contrainte unique sur rechnung_fk + numéro). Liée à une position de commande via auftragsPosition (many-to-one vers AuftragsPositionDO, lazy). Prend en charge une période d'exécution indépendante via periodOfPerformanceType, periodOfPerformanceBegin, periodOfPerformanceEnd. Les affectations de coûts sont @JsonManagedReference one-to-many vers KostZuweisungDO ordonnées par index. Fournit newClone() pour un clonage profond avec les affectations de coûts. Migré à l'origine depuis Java (2019-06-12).
