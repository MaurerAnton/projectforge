#979: RechnungsPositionDO.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungsPositionDO.kt JPA-сущность, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungsPositionDO.kt 122 строки · 78 кода · 32 комментария · 12 пустых
JPA-сущность, сопоставленная с таблицей t_fibu_rechnung_position, представляющая позицию строки в исходящем счете. Расширяет AbstractRechnungsPositionDO. Имеет связь многие-к-одному с RechnungDO с аннотацией @JsonBackReference (уникальное ограничение на rechnung_fk + number). Связывается с позицией заказа через auftragsPosition (многие-к-одному с AuftragsPositionDO, ленивая загрузка). Поддерживает независимый период выполнения через periodOfPerformanceType, periodOfPerformanceBegin, periodOfPerformanceEnd. Назначения затрат — @JsonManagedReference один-ко-многим с KostZuweisungDO, упорядоченные по индексу. Предоставляет newClone() для глубокого клонирования с назначениями затрат. Изначально мигрирован из Java (2019-06-12).
