#980: Kost1PagesRest

Type: REST Controller (Spring)  |  Purpose: Cost center type 1 (Kost1) management with formatted numbers and smart filtering
Source: projectforge-rest/src/main/kotlin/org/projectforge/rest/fibu/kost/Kost1PagesRest.kt
Extends: AbstractDTOPagesRest<Kost1DO, Kost1, Kost1Dao>
Endpoint: /rs/cost1

REST controller for Kost1 (main cost centers / Kostenträger Stufe 1). Manages cost center master data with formatted number display, active/inactive status filtering, and smart auto-completion that filters by active status unless searching by number. Integrates with KostFormatter for display formatting.

Architecture & Design

DTO Transformation

transformFromDB() uses a convenience constructor Kost1(obj) rather than copyFrom(), providing direct construction from the DO.

List Layout

ColumnField
Cost center numberformattedNumber
Descriptiondescription
StatuskostentraegerStatus

Uses classic UITable (not AG-Grid). Links to the Wicket-based classic list page via classicsLinkListUrl returning "wa/cost1List".

Edit Layout

Simple layout with a UICustomized("cost.number") component (handles the structured cost center number input), description, and status dropdown.

Smart Auto-Completion

queryAutocompleteObjects() implements intelligent filtering:

  • Default: Filters to only active cost centers (KostentraegerStatus.ACTIVE or null).
  • Number search: When the search string contains only digits and dots (isDigitsAndDotsOnly), does not filter by active status — allowing lookup of inactive cost centers by their number.
  • Display formatting: Each result's displayName is set to KostFormatter.formatKost1(..., FormatType.LONG) for user-friendly display.

Auto-Completion Search Fields

description, nummer, rawNumberString — searches by description text, numeric number, or raw string representation.

KostFormatter Integration

The KostFormatter service (injected via @Autowired) handles the structured display of cost center numbers (e.g., "1.2.3 - Description") with different format types.
