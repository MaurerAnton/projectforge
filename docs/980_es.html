Orquesta la generación de XML de Transferencia SEPA (pain.001.001.03) a partir de facturas de ProjectForge. Coordina todo el pipeline: carga de facturas, validación de IBAN/Konto, agrupación por deudor, construcción de XML mediante SEPAXmlBuilder y empaquetado del resultado en SEPATransferResult.

Arquitectura

Pipeline Principal

El generador sigue un pipeline de múltiples etapas:

  1. Selección de Entrada: Recibe una lista de IDs de facturas u objetos RechnungDO para procesar.
  2. Validación: Verifica que cada factura tenga un IBAN/BIC válido y un Konto asociado para los datos bancarios. Filtra facturas ya exportadas.
  3. Agrupación: Agrupa facturas por deudor (Kunde) para transferencias por lotes cuando sea posible.
  4. Generación de XML: Delega en SEPAXmlBuilder para construir el XML en formato pain.001.
  5. Ensamblado del Resultado: Empaqueta el XML generado, los recuentos de facturas procesadas y cualquier error en SEPATransferResult.

Grafo de Dependencias

El generador depende en gran medida de la capa de caché de fibu (ProjektCache, KundeCache, KontoCache) para resolver las relaciones de las facturas sin consultas adicionales a la base de datos. Utiliza RechnungDao para la persistencia de facturas y para marcarlas como exportadas.

Decisiones de Diseño

  • Idempotencia: Omite facturas ya marcadas con una fecha de exportación SEPA para evitar transferencias duplicadas.
  • Acumulación de Errores: Recopila todos los errores de validación en lugar de fallar en el primero, proporcionando un informe de errores completo.
  • Formato XML: Utiliza pain.001.001.03 (ISO 20022) como estándar de Transferencia SEPA, compatible con bancos de la UE.
  • Precisión de Fecha/Hora: Genera IDs de mensaje únicos por ejecución de exportación usando marcas de tiempo, garantizando la trazabilidad.
