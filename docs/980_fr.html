Orchestre la génération XML de virement SEPA Credit Transfer (pain.001.001.03) à partir des factures ProjectForge. Coordonne l'ensemble du pipeline : chargement des factures, validation IBAN/Compte, regroupement par débiteur, construction XML via SEPAXmlBuilder, et conditionnement du résultat dans SEPATransferResult.

Architecture

Pipeline principal

Le générateur suit un pipeline en plusieurs étapes :

  1. Sélection des entrées : Reçoit une liste d'identifiants de factures ou d'objets RechnungDO à traiter.
  2. Validation : Vérifie que chaque facture possède un IBAN/BIC valide et un compte associé pour les coordonnées bancaires. Filtre les factures déjà exportées.
  3. Regroupement : Regroupe les factures par débiteur (Kunde) pour des virements groupés lorsque c'est possible.
  4. Génération XML : Délègue à SEPAXmlBuilder la construction du XML au format pain.001.
  5. Assemblage du résultat : Conditionne le XML généré, les compteurs de factures traitées et les éventuelles erreurs dans SEPATransferResult.

Graphe de dépendances

Le générateur dépend fortement de la couche cache fibu (ProjektCache, KundeCache, KontoCache) pour résoudre les relations entre factures sans requêtes supplémentaires à la base de données. Il utilise RechnungDao pour la persistance des factures et le marquage des factures comme exportées.

Décisions de conception

  • Idempotence : Ignore les factures déjà marquées avec une date d'exportation SEPA pour éviter les virements en double.
  • Accumulation d'erreurs : Collecte toutes les erreurs de validation plutôt que d'échouer sur la première, fournissant ainsi un rapport d'erreurs complet.
  • Format XML : Utilise pain.001.001.03 (ISO 20022) comme standard de virement SEPA Credit Transfer, compatible avec les banques de l'UE.
  • Précision date/heure : Génère des identifiants de message uniques par exécution d'exportation à l'aide d'horodatages, garantissant la traçabilité.
