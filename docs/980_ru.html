#980: SEPATransferGenerator.kt

Оркестрирует генерацию XML для SEPA Credit Transfer (pain.001.001.03) на основе счетов ProjectForge. Координирует полный конвейер: загрузку счетов, проверку IBAN/счета, группировку по дебиторам, построение XML через SEPAXmlBuilder и упаковку результата в SEPATransferResult.

Архитектура

Основной конвейер

Генератор следует многоэтапному конвейеру:

  1. Выбор входных данных: Получает список ID счетов или объектов RechnungDO для обработки.
  2. Проверка: Убеждается, что каждый счёт имеет действительные IBAN/BIC и связанный счёт для банковских реквизитов. Отфильтровывает уже экспортированные счета.
  3. Группировка: Группирует счета по дебитору (Kunde) для пакетных переводов, когда это возможно.
  4. Генерация XML: Делегирует SEPAXmlBuilder построение XML в формате pain.001.
  5. Сборка результата: Упаковывает сгенерированный XML, количество обработанных счетов и возможные ошибки в SEPATransferResult.

Граф зависимостей

Генератор сильно зависит от кэш-слоя fibu (ProjektCache, KundeCache, KontoCache) для разрешения связей счетов без дополнительных запросов к базе данных. Он использует RechnungDao для сохранения счетов и отметки их как экспортированных.

Проектные решения

  • Идемпотентность: Пропускает счета, уже отмеченные датой экспорта SEPA, чтобы предотвратить дублирование переводов.
  • Накопление ошибок: Собирает все ошибки проверки, а не останавливается на первой, предоставляя полный отчёт об ошибках.
  • Формат XML: Использует pain.001.001.03 (ISO 20022) как стандарт SEPA Credit Transfer, совместимый с банками ЕС.
  • Точность даты/времени: Генерирует уникальные ID сообщений для каждого запуска экспорта с использованием временных меток, обеспечивая отслеживаемость.
