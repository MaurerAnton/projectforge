#981: SEPATransferGeneratorUtils.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/SEPATransferGeneratorUtils.kt Вспомогательные функции SEPA, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/SEPATransferGeneratorUtils.kt 45 строк · 15 кода · 25 комментариев · 5 пустых
Набор статических вспомогательных функций для генерации SEPA-переводов: проверка IBAN/BIC, форматирование валюты, очистка специальных символов и извлечение данных банковского счёта из счетов и контрагентов ProjectForge.

Дизайн

Данный класс утилит на основе companion object предоставляет методы без сохранения состояния, используемые SEPATransferGenerator и SEPAXmlBuilder. Основные обязанности:

  • Форматирование IBAN: Удаление пробелов, проверка контрольной суммы IBAN и преобразование в стандартный формат SEPA.
  • Очистка символов: Удаление символов, не входящих в разрешённый набор SEPA (a-z, A-Z, 0-9, пробел и ограниченные знаки препинания по ISO 20022).
  • Форматирование суммы: Преобразование сумм BigDecimal в десятичные строки, совместимые с SEPA (максимум 2 знака после запятой, разделитель — точка).
  • Определение банковского счёта: Извлечение IBAN, BIC и данных счёта из цепочек ProjektDO → KontoDO с обработкой резервных сценариев.
  • Идентификация дебитора: Определение имён и адресов кредиторов/дебиторов из объектов KundeDO для блоков идентификации сторон SEPA.
