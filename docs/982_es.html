Clase de datos que contiene el resultado de una ejecución de generación de transferencia SEPA: contenido XML generado, lista de facturas procesadas y no procesadas, mensajes de error y metadatos de exportación (conteos, totales).

Estructura

Un contenedor de datos simple con los siguientes campos:

CampoTipoPropósito
xmlContentString?El documento XML SEPA pain.001 generado
processedInvoicesList<RechnungDO>Facturas incluidas exitosamente en la transferencia
unprocessedInvoicesList<RechnungDO>Facturas excluidas debido a errores de validación
errorMessagesList<String>Mensajes de error legibles para cada problema
totalAmountBigDecimal?Suma total de todas las transferencias en el XML
numberOfTransactionsIntConteo de transacciones de pago SEPA individuales
