Класс данных, содержащий результат выполнения генерации SEPA-перевода: сгенерированное XML-содержимое, список обработанных и необработанных счетов, сообщения об ошибках и метаданные экспорта (количество, итоги).

Структура

Простой контейнер данных со следующими полями:

ПолеТипНазначение
xmlContentString?Сгенерированный XML-документ SEPA pain.001
processedInvoicesList<RechnungDO>Счета, успешно включённые в перевод
unprocessedInvoicesList<RechnungDO>Счета, исключённые из-за ошибок валидации
errorMessagesList<String>Понятные человеку сообщения об ошибках для каждой проблемы
totalAmountBigDecimal?Общая сумма всех переводов в XML
numberOfTransactionsIntКоличество отдельных платежных транзакций SEPA
