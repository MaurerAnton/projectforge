Construye documentos XML ISO 20022 pain.001.001.03 para la iniciación de Transferencias de Crédito SEPA. Maneja el encabezado de grupo, la información de pago y la generación de bloques XML a nivel de transacción con una gestión adecuada de espacios de nombres.

Arquitectura

Estructura XML

El constructor produce una estructura XML jerárquica de tres niveles según el esquema pain.001.001.03:

  1. Encabezado de Grupo (<GrpHdr>): ID del mensaje, fecha/hora de creación, identificación de la parte iniciadora, número de transacciones, suma de control.
  2. Información de Pago (<PmtInf>): Método de pago (TRF), indicador de procesamiento por lote, fecha de ejecución solicitada, cuenta del deudor (IBAN/BIC), agente del deudor (banco).
  3. Información de Transacción (<CdtTrfTxInf>): Por factura: ID extremo a extremo, importe, datos del acreedor (nombre, IBAN, BIC), información de remesa (número de factura).

Decisiones de Diseño

  • Precisión de Espacios de Nombres: Utiliza prefijos de espacio de nombres explícitos para evitar XML ambiguo que algunos sistemas bancarios rechazan. La declaración xmlns a nivel de encabezado cubre todos los elementos secundarios.
  • Escapado de Caracteres: Todos los nodos de texto pasan por una sanitización (a través de SEPATransferGeneratorUtils) antes de ser incrustados, asegurando que solo aparezcan caracteres permitidos por SEPA en el XML.
  • Formato de Fecha: Utiliza el formato de fecha ISO 8601 (YYYY-MM-DD) según lo requerido por el estándar pain.001.
  • Lote vs Individual: Soporta tanto lotes de un solo deudor como transacciones individuales por factura, controlado por la lógica de agrupación en SEPATransferGenerator.
