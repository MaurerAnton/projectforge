Construit des documents XML ISO 20022 pain.001.001.03 pour l'initiation de virements SEPA. Gère l'en-tête de groupe, les informations de paiement et la génération de blocs XML au niveau des transactions avec une gestion appropriée des espaces de noms.

Architecture

Structure XML

Le constructeur produit une structure XML hiérarchique à trois niveaux selon le schéma pain.001.001.03 :

  1. En-tête de groupe (<GrpHdr>) : Identifiant du message, date et heure de création, identification de la partie initiatrice, nombre de transactions, somme de contrôle.
  2. Informations de paiement (<PmtInf>) : Méthode de paiement (TRF), indicateur de traitement par lot, date d'exécution demandée, compte débiteur (IBAN/BIC), agent débiteur (banque).
  3. Informations de transaction (<CdtTrfTxInf>) : Par facture : identifiant de bout en bout, montant, coordonnées du créancier (nom, IBAN, BIC), informations de remise (numéro de facture).

Décisions de conception

  • Précision des espaces de noms : Utilise des préfixes d'espace de noms explicites pour éviter les XML ambigus que certains systèmes bancaires rejettent. La déclaration xmlns au niveau de l'en-tête couvre tous les éléments enfants.
  • Échappement des caractères : Tous les nœuds de texte passent par une désinfection (via SEPATransferGeneratorUtils) avant l'incorporation, garantissant que seuls les caractères autorisés par SEPA apparaissent dans le XML.
  • Formatage des dates : Utilise le format de date ISO 8601 (AAAA-MM-JJ) comme requis par la norme pain.001.
  • Lot ou unique : Prend en charge à la fois les lots à débiteur unique et les transactions individuelles par facture, contrôlé par la logique de regroupement dans SEPATransferGenerator.
