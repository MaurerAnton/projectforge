#983: SEPAXmlBuilder.kt

projectforge-business/src/main/kotlin/org/projectforge/business/fibu/SEPAXmlBuilder.kt SEPA XML Builder, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/SEPAXmlBuilder.kt 242 строки · 159 кода · 51 комментарий · 32 пустых
Формирует XML-документы ISO 20022 pain.001.001.03 для инициирования кредитовых переводов SEPA. Обрабатывает заголовок группы, платёжную информацию и генерацию XML-блоков на уровне транзакций с правильным управлением пространствами имён.

Архитектура

XML-структура

Построитель создаёт трёхуровневую иерархическую XML-структуру в соответствии со схемой pain.001.001.03:

  1. Заголовок группы (<GrpHdr>): Идентификатор сообщения, дата и время создания, идентификация стороны-инициатора, количество транзакций, контрольная сумма.
  2. Платёжная информация (<PmtInf>): Способ платежа (TRF), флаг пакетной обработки, запрашиваемая дата исполнения, счёт дебитора (IBAN/BIC), агент дебитора (банк).
  3. Информация о транзакции (<CdtTrfTxInf>): По каждому счёту: сквозной идентификатор, сумма, реквизиты кредитора (наименование, IBAN, BIC), информация о перечислении (номер счёта).

Проектные решения

  • Точность пространства имён: Используются явные префиксы пространств имён, чтобы избежать неоднозначного XML, который некоторые банковские системы могут отклонить. Объявление xmlns на уровне заголовка охватывает все дочерние элементы.
  • Экранирование символов: Все текстовые узлы проходят санитарную обработку (через SEPATransferGeneratorUtils) перед встраиванием, что гарантирует наличие в XML только символов, разрешённых стандартом SEPA.
  • Форматирование даты: Используется формат даты ISO 8601 (ГГГГ-ММ-ДД) в соответствии с требованиями стандарта pain.001.
  • Пакетный и одиночный режимы: Поддерживаются как пакеты с одним дебитором, так и отдельные транзакции по каждому счёту; управляется логикой группировки в SEPATransferGenerator.
