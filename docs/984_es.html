Agrega las propiedades periodOfPerformanceStartDate / periodOfPerformanceEndDate a cualquier filtro de búsqueda. Utilizado por los filtros de facturas y pedidos para acotar consultas a una ventana de servicio específica, distinta de la fecha de factura o fecha de pedido. La interfaz se extrajo del código duplicado en varias clases de filtro (PROJECTFORGE-3069).

Arquitectura

Esta es una interfaz mixin al estilo Kotlin: dos propiedades de solo lectura sin implementación. Las clases de filtro que necesitan filtrado por rango de período de ejecución simplemente implementan esta interfaz junto con su interfaz de filtro existente. El código consumidor (normalmente endpoints REST o métodos select() de DAO) verifica if (filter is SearchFilterWithPeriodOfPerformance) y aplica las restricciones de fecha.

El período de ejecución se distingue de otros conceptos de fecha:
• Fecha de factura: cuándo se emitió la factura
• Fecha de pedido: cuándo se realizó el pedido
• Período de ejecución: cuándo se realizó el trabajo real (importante para la contabilidad de costes y el reconocimiento de ingresos)
