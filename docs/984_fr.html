projectforge-business/src/main/kotlin/org/projectforge/business/fibu/SearchFilterWithPeriodOfPerformance.kt Interface Kotlin — contrat mixin pour les filtres de recherche prenant en charge le filtrage par plage de dates via la période d'exécution. Ajoute les propriétés periodOfPerformanceStartDate / periodOfPerformanceEndDate à tout filtre de recherche. Utilisé par les filtres de factures et de commandes pour restreindre les requêtes à une fenêtre de prestation spécifique — distincte de la date de facture ou de la date de commande. L'interface a été extraite du code dupliqué dans plusieurs classes de filtre (PROJECTFORGE-3069).

Architecture

Il s'agit d'une interface mixin dans le style Kotlin — deux propriétés en lecture seule sans implémentation. Les classes de filtre qui nécessitent un filtrage par plage de période d'exécution implémentent simplement cette interface en plus de leur interface de filtre existante. Le code consommateur (généralement les points de terminaison REST ou les méthodes select() des DAO) vérifie if (filter is SearchFilterWithPeriodOfPerformance) et applique les contraintes de date.

La période d'exécution est distincte des autres concepts de date :
• Date de facture : date d'émission de la facture
• Date de commande : date de passation de la commande
• Période d'exécution : période pendant laquelle le travail a été effectué (importante pour la comptabilité analytique et la constatation des revenus)
