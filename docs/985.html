#985: PaymentType.kt

Enum, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/PaymentType.kt
I18n-backed enum defining payment types for invoices and order positions: BANK_TRANSFER, DEBIT, CREDIT_CARD, CASH, SALARY, CREDIT. Each has an i18n key under fibu.payment.type.*. Provides isIn() for multi-value checks and a safeValueOf() companion factory that returns null for unknown names instead of throwing.
