Importa Buchungssätze (registros contables / asientos de diario) desde libros de Excel utilizando el framework Merlin Excel. Cada hoja de Excel representa un mes (nombre de hoja = número de mes 01–12). Lee 12 columnas con validadores y resuelve entidades referenciadas (Konto, Kost1, Kost2) durante la importación.

Flujo de importación

  1. doImport(workbook) itera todas las hojas (0..N).
  2. El nombre de la hoja se analiza como entero de mes (01 para enero). Si falla el análisis, la hoja se omite.
  3. Las columnas se registran con validadores a través del framework Merlin.
  4. Columnas de verificación de filas vacías: DATUM, SATZNR, BETRAG, KONTO, GEGENKONTO, KOST1, KOST2.
  5. sheet.analyze(true) valida todos los datos.
  6. importBuchungssaetze(sheet, month) itera las filas de datos:
    • Analiza la fecha mediante PFDay; valida consistencia del año (todas las entradas deben estar en el mismo año).
    • Valida el mes: las entradas no pueden ser futuras en relación al mes de la hoja.
    • Resuelve Konto y Gegenkonto mediante kontoDao.getKonto() — se registran errores si no se encuentran.
    • Resuelve Kost1 y Kost2 mediante los DAO respectivos — se registran errores si no se encuentran.
    • Llama a satz.calculate(true) para el cálculo final.
    • Envuelve en MyImportedElement para soporte de diferencias/reconciliación.

Validación de fecha

Utiliza ExcelColumnDateValidator con formatos de fecha alemanes. Rango: 1990-01-01 a 2100-12-31.
