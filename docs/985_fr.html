Importe les Buchungssätze (écritures comptables / pièces de journal) à partir de classeurs Excel en utilisant le framework Merlin Excel. Chaque feuille Excel représente un mois (nom de la feuille = numéro du mois 01–12). Lit 12 colonnes avec validateurs et résout les entités référencées (Konto, Kost1, Kost2) pendant l'import.

Flux d'import

  1. doImport(workbook) parcourt toutes les feuilles (0..N).
  2. Le nom de la feuille est interprété comme un entier de mois (01 pour janvier). Si l'analyse échoue, la feuille est ignorée.
  3. Les colonnes sont enregistrées avec des validateurs via le framework Merlin.
  4. Colonnes de vérification des lignes vides : DATUM, SATZNR, BETRAG, KONTO, GEGENKONTO, KOST1, KOST2.
  5. sheet.analyze(true) valide toutes les données.
  6. importBuchungssaetze(sheet, month) parcourt les lignes de données :
    • Analyse la date via PFDay ; valide la cohérence de l'année (toutes les entrées doivent être dans la même année).
    • Valide le mois : les entrées ne peuvent pas être dans le futur par rapport au mois de la feuille.
    • Résout Konto et Gegenkonto via kontoDao.getKonto() — les erreurs sont enregistrées si non trouvés.
    • Résout Kost1 et Kost2 via les DAO respectifs — les erreurs sont enregistrées si non trouvés.
    • Appelle satz.calculate(true) pour le calcul final.
    • Encapsule dans MyImportedElement pour le support de la comparaison/conciliation.

Validation des dates

Utilise ExcelColumnDateValidator avec les formats de date allemands. Plage : 1990-01-01 au 2100-12-31.
