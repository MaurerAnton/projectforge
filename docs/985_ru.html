Импортирует Buchungssätze (бухгалтерские записи / журнальные проводки) из книг Excel с использованием фреймворка Merlin Excel. Каждый лист Excel представляет один месяц (имя листа = номер месяца 01–12). Считывает 12 столбцов с валидаторами и разрешает связанные сущности (Konto, Kost1, Kost2) во время импорта.

Поток импорта

  1. doImport(workbook) перебирает все листы (0..N).
  2. Имя листа преобразуется в целое число месяца (01 для января). Если преобразование не удаётся, лист пропускается.
  3. Столбцы регистрируются с валидаторами через фреймворк Merlin.
  4. Столбцы проверки пустых строк: DATUM, SATZNR, BETRAG, KONTO, GEGENKONTO, KOST1, KOST2.
  5. sheet.analyze(true) проверяет все данные.
  6. importBuchungssaetze(sheet, month) перебирает строки данных:
    • Преобразует дату через PFDay; проверяет согласованность года (все записи должны быть в одном году).
    • Проверяет месяц: записи не могут быть в будущем относительно месяца листа.
    • Преобразует Konto и Gegenkonto через kontoDao.getKonto() — ошибки фиксируются, если не найдены.
    • Преобразует Kost1 и Kost2 через соответствующие DAO — ошибки фиксируются, если не найдены.
    • Вызывает satz.calculate(true) для окончательного вычисления.
    • Оборачивает в MyImportedElement для поддержки сравнения/сверки.

Проверка даты

Использует ExcelColumnDateValidator с немецкими форматами дат. Диапазон: 1990-01-01 — 2100-12-31.
