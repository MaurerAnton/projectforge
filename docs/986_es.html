El servicio de orquestación para importaciones de Excel estilo DATEV. Coordina el pipeline de importación tanto para Kontenplan (plan de cuentas) como para Buchungssätze (registros contables). Gestiona el ciclo de vida de la importación: analizar (importar), validar (conciliar) y persistir (confirmar). Todas las operaciones requieren el permiso de usuario FIBU_DATEV_IMPORT.

Ciclo de vida de la importación

Fase 1: Importar (Analizar Excel)

MétodoEntradaSalida
importKontenplan(inputStream, filename)InputStream de ExcelImportStorage<KontoDO>
importBuchungsdaten(inputStream, filename)InputStream de ExcelImportStorage<BuchungssatzDO>

Ambos métodos abren un ExcelWorkbook desde el flujo de entrada, crean un ImportStorage con configuración de registro, delegan en la clase importadora correspondiente (KontenplanExcelImporter / BuchungssatzExcelImporter) y devuelven el almacenamiento poblado.

Fase 2: Conciliar (Validar y Diferir)

MétodoDescripción
reconcile(storage, sheetName)Envía a reconcileKontenplan() o reconcileBuchungsdaten() según el tipo de almacenamiento. Establece numberOfCommittedElements en -1.

La conciliación compara los elementos importados con las entradas existentes en la base de datos:

  • Kontenplan: busca cada KontoDO importado por número de cuenta. Las entradas encontradas se almacenan como oldValue en el elemento de importación y su marca de tiempo created se copia a la importación (necesaria para que BaseDao determine inserción vs actualización).
  • Buchungssätze: busca por (year, month, satznr) usando buchungssatzDao.getBuchungssatz().

Fase 3: Confirmar (Persistir)

MétodoDescripción
commit(storage, sheetName)Requiere estado RECONCILED. Envía a commitKontenplan() o commitBuchungsdaten(). Establece el estado en IMPORTED.

La confirmación recoge los elementos seleccionados, establece el id de base de datos desde oldValue si la entrada ya existe, e inserta en bloque a través del DAO en grupos de 50.

Enum de tipo de importación

DatevImportService.Type: KONTENPLAN, BUCHUNGSSAETZE. Se utiliza como discriminador en ImportStorage.

Control de acceso

Todos los métodos públicos llaman a checkLoggedinUserRight() que verifica UserRightId.FIBU_DATEV_IMPORT con valor TRUE. El objeto complementario proporciona métodos auxiliares estáticos para su uso en páginas Wicket (desacoplamiento previo al servicio).
