Сервис оркестрации для импорта Excel-файлов в формате DATEV. Координирует конвейер импорта как для Kontenplan (плана счетов), так и для Buchungssätze (бухгалтерских записей). Управляет жизненным циклом импорта: разбор (импорт), проверка (согласование) и сохранение (фиксация). Все операции требуют права пользователя FIBU_DATEV_IMPORT.

Жизненный цикл импорта

Фаза 1: Импорт (разбор Excel)

МетодВходные данныеРезультат
importKontenplan(inputStream, filename)Excel InputStreamImportStorage<KontoDO>
importBuchungsdaten(inputStream, filename)Excel InputStreamImportStorage<BuchungssatzDO>

Оба метода открывают ExcelWorkbook из входного потока, создают ImportStorage с конфигурацией логирования, делегируют выполнение соответствующему классу импортёра (KontenplanExcelImporter / BuchungssatzExcelImporter) и возвращают заполненное хранилище.

Фаза 2: Согласование (проверка и сравнение)

МетодОписание
reconcile(storage, sheetName)Направляет в reconcileKontenplan() или reconcileBuchungsdaten() в зависимости от типа хранилища. Устанавливает numberOfCommittedElements в -1.

Согласование сопоставляет импортированные элементы с существующими записями в базе данных:

  • Kontenplan: ищет каждый импортированный KontoDO по номеру счета. Найденные записи сохраняются как oldValue для элемента импорта, и их временная метка created копируется в импорт (необходимо для BaseDao для определения вставки или обновления).
  • Buchungssätze: ищет по (year, month, satznr) с помощью buchungssatzDao.getBuchungssatz().

Фаза 3: Фиксация (сохранение)

МетодОписание
commit(storage, sheetName)Требует статуса RECONCILED. Направляет в commitKontenplan() или commitBuchungsdaten(). Устанавливает статус IMPORTED.

Фиксация собирает выбранные элементы, устанавливает идентификатор базы данных из oldValue, если запись уже существует, и выполняет массовую вставку через DAO блоками по 50.

Перечисление типов импорта

DatevImportService.Type: KONTENPLAN, BUCHUNGSSAETZE. Используется как дискриминатор в ImportStorage.

Контроль доступа

Все публичные методы вызывают checkLoggedinUserRight(), который проверяет UserRightId.FIBU_DATEV_IMPORT со значением TRUE. Объект-компаньон предоставляет статические вспомогательные методы для использования на страницах Wicket (до разделения сервисов).
