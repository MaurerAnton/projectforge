Importa salarios de empleados desde una hoja de libro de Excel llamada "employeeSalaries". Asigna registros de empleados por número de personal (Personalnummer), la validación incluye verificar que el empleado exista en la base de datos.

Dependencias

EmployeeServiceBúsqueda directa en base de datos si falla la caché

La columna GESAMT_BRUTTO acepta los alias "bruttoMitAgAnteil" y "Gesamt-".

Flujo de importación

  1. Abre la hoja llamada "employeeSalaries" — lanza UserException si no se encuentra.
  2. Registra dos columnas con validadores.
  3. Analiza la hoja con sheet.analyze(true).
  4. Crea un ImportedSheet con registro de nivel de advertencia.
  5. Itera las filas de datos:
    • Crea MyImportedElement para seguimiento de diferencias.
    • Crea EmployeeSalaryDO y lo rellena desde la fila mediante ImportHelper.fillBean().
    • Busca empleado por número de personal (caché primero, luego base de datos). Registra un error de validación si no se encuentra.
    • Establece year y month en el registro de salario.
    • Añade el elemento poblado a la hoja importada.

Propiedades de diferencia

Objeto complementario

Contiene la constante del nombre de la hoja NAME_OF_EXCEL_SHEET = "employeeSalaries" y SALARY_DIFF_PROPERTIES.
