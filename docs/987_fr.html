Importe les salaires des employés à partir d'une feuille de classeur Excel nommée "employeeSalaries". Associe les enregistrements des employés par numéro de personnel (Personalnummer). La validation inclut la vérification que l'employé existe dans la base de données.

Architecture

Dépendances

EmployeeCacheRecherche rapide en cache par numéro de personnel
EmployeeServiceRecherche directe en base de données en cas d'échec du cache

La colonne GESAMT_BRUTTO accepte les alias "bruttoMitAgAnteil" et "Gesamt-".

Flux d'import

  1. Ouvre la feuille nommée "employeeSalaries" — lève une UserException si elle n'est pas trouvée.
  2. Enregistre deux colonnes avec des validateurs.
  3. Analyse la feuille avec sheet.analyze(true).
  4. Crée une ImportedSheet avec une journalisation de niveau avertissement.
  5. Parcourt les lignes de données :
    • Crée MyImportedElement pour le suivi des différences.
    • Crée EmployeeSalaryDO et le remplit à partir de la ligne via ImportHelper.fillBean().
    • Recherche l'employé par numéro de personnel (cache d'abord, puis base de données). Enregistre une erreur de validation si non trouvé.
    • Définit year et month sur l'enregistrement de salaire.
    • Ajoute l'élément rempli à la feuille importée.

Propriétés de différence

SALARY_DIFF_PROPERTIES = ["bruttoMitAgAnteil"]

Objet compagnon

Contient la constante du nom de la feuille NAME_OF_EXCEL_SHEET = "employeeSalaries" et SALARY_DIFF_PROPERTIES.
