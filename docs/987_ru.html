Импортирует зарплаты сотрудников из листа книги Excel с именем "employeeSalaries". Сопоставляет записи сотрудников по табельному номеру (Personalnummer), проверка включает подтверждение существования сотрудника в базе данных.

Столбец GESAMT_BRUTTO принимает псевдонимы "bruttoMitAgAnteil" и "Gesamt-".

Поток импорта

  1. Открывает лист с именем "employeeSalaries" — выбрасывает UserException, если не найден.
  2. Регистрирует два столбца с валидаторами.
  3. Анализирует лист с помощью sheet.analyze(true).
  4. Создаёт ImportedSheet с логированием уровня предупреждений.
  5. Перебирает строки данных:
    • Создаёт MyImportedElement для отслеживания различий.
    • Создаёт EmployeeSalaryDO и заполняет из строки через ImportHelper.fillBean().
    • Ищет сотрудника по табельному номеру (сначала кэш, затем база данных). Фиксирует ошибку валидации, если не найден.
    • Устанавливает год и месяц в записи о зарплате.
    • Добавляет заполненный элемент в импортированный лист.
