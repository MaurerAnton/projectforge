Servicio de orquestación para el pipeline de importación de salarios de empleados. Sigue el mismo ciclo de vida de importación de tres fases (importar → conciliar → confirmar) establecido por DatevImportService. Coordina entre EmployeeSalaryExcelImporter (análisis), EmployeeSalaryDao (persistencia) y EmployeeSalaryService (búsqueda).

Arquitectura

Dependencias

DependenciaRol
EmployeeSalaryExcelImporterAnaliza el libro de Excel en ImportStorage<EmployeeSalaryDO>
EmployeeSalaryServiceBusca salarios existentes por mes para la conciliación
EmployeeSalaryDaoConfirmación masiva y control de acceso

Ciclo de vida de importación

Fase 1: Importar

importData(inputStream, filename, year, month) — abre un ExcelWorkbook, crea un ImportStorage, delega en EmployeeSalaryExcelImporter.doImport(). Devuelve el almacenamiento poblado.

Fase 2: Conciliar

reconcile(storage, sheetName, year, month) — busca salarios existentes para el año/mes dado a través de employeeSalaryService.selectByMonth(), luego empareja cada elemento importado con un registro existente en la BD por ID de empleado. Establece oldValue, id y la marca de tiempo created en el elemento para la fase de confirmación. Establece el estado en RECONCILED.

Fase 3: Confirmar

commit(storage, sheetName) — requiere estado RECONCILED. Recoge los elementos seleccionados, copia el id existente de oldValue para las actualizaciones, y confirma masivamente a través de employeeSalaryDao.insertOrUpdate() en bloques de 50. Establece el estado en IMPORTED.

Control de acceso

checkLoggedinUserRight() delega en employeeSalaryDao.checkLoggedInUserInsertAccess(), que verifica que el usuario tenga el derecho de inserción para salarios de empleados.

Tamaño del bloque de inserción

SALARY_INSERT_BLOCK_SIZE = 50 — controla el tamaño del lote para las operaciones de persistencia.
