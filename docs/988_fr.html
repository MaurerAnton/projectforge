Service d'orchestration pour le pipeline d'import des salaires des employés. Suit le même cycle de vie d'import en trois phases (importer → rapprocher → valider) établi par DatevImportService. Coordonne entre EmployeeSalaryExcelImporter (analyse), EmployeeSalaryDao (persistance) et EmployeeSalaryService (recherche).

Architecture

Dépendances

DépendanceRôle
EmployeeSalaryExcelImporterAnalyse le classeur Excel en ImportStorage<EmployeeSalaryDO>
EmployeeSalaryServiceRecherche les salaires existants par mois pour le rapprochement
EmployeeSalaryDaoValidation en bloc et contrôle d'accès

Cycle de vie de l'import

Phase 1 : Importer

importData(inputStream, filename, year, month) — ouvre un ExcelWorkbook, crée un ImportStorage, délègue à EmployeeSalaryExcelImporter.doImport(). Retourne le stockage rempli.

Phase 2 : Rapprocher

reconcile(storage, sheetName, year, month) — recherche les salaires existants pour l'année/mois donnés via employeeSalaryService.selectByMonth(), puis fait correspondre chaque élément importé à un enregistrement DB existant par identifiant d'employé. Définit oldValue, id et l'horodatage created sur l'élément pour la phase de validation. Définit le statut sur RECONCILED.

Phase 3 : Valider

commit(storage, sheetName) — nécessite le statut RECONCILED. Collecte les éléments sélectionnés, copie l'id existant depuis oldValue pour les mises à jour, et valide en bloc via employeeSalaryDao.insertOrUpdate() par blocs de 50. Définit le statut sur IMPORTED.

Contrôle d'accès

checkLoggedinUserRight() délègue à employeeSalaryDao.checkLoggedInUserInsertAccess(), qui vérifie que l'utilisateur dispose du droit d'insertion pour les salaires des employés.

Taille des blocs d'insertion

SALARY_INSERT_BLOCK_SIZE = 50 — contrôle la taille des lots pour les opérations de persistance.
