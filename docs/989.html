#989: ProjektFormatter.kt

Service/Formatter, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/ProjektFormatter.kt
Spring @Service extending BaseFormatter for formatting project (ProjektDO) display strings. Delegates to KostFormatter for format types FORMATTED_NUMBER and TEXT. Handles access checks and lazy-initialized project resolution via ProjektCache. Provides static formatProjektKundeAsString() methods that combine project name, customer name, and customer text into a formatted string with parts separated by "; " and " - ".
