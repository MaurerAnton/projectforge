Importiert einen Kontenplan aus einer Excel-Arbeitsmappe. Der Import erwartet ein Blatt mit dem Namen "Kontenplan" mit Kontonummern und Bezeichnungen. Verwendet das Merlin-Excel-Framework für das Parsen und die Validierung.

Architektur

Eine einfache, zustandslose Import-Klasse (kein Spring-Bean). Nimmt ImportStorage und ExcelWorkbook als Parameter entgegen.

Spaltenzuordnung (Enum: Cols)

EnumKopfzeileAliaseValidatorZieleigenschaft

BEZEICHNUNGBezeichnungBeschriftungValidator (erforderlich)bezeichnung

Importablauf

  1. doImport(storage, workbook) — ruft das Blatt mit dem Namen "Kontenplan" ab. Wirft UserException, falls nicht gefunden.
  2. importKontenplan(storage, sheet):
    • Aktiviert automatisches Trimmen von Zellwerten.
    • Registriert zwei Spalten mit Validatoren.
    • Analysiert das Blatt; überspringt, wenn keine gültige Kopfzeile gefunden wird.
    • Erstellt ImportedSheet mit Logging auf Warnstufe.
    • Iteriert über Datenzeilen und erstellt pro Zeile ein MyImportedElement und ein KontoDO.
    • Setzt nummer explizit aus dem ganzzahligen Zellenwert (anstatt über die Zieleigenschaftszuordnung von ImportHelper.fillBean).

Begleitobjekt

  • NAME_OF_EXCEL_SHEET — der erforderliche Blattname: "Kontenplan"
  • log — SLF4J-Logger
