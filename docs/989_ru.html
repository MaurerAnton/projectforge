Импортирует Kontenplan (план счетов) из книги Excel. Импорт ожидает лист с именем "Kontenplan", содержащий номера счетов и описания. Для разбора и валидации используется фреймворк Merlin Excel.

Архитектура

Простой класс импорта без сохранения состояния (не Spring bean). Принимает ImportStorage и ExcelWorkbook в качестве параметров.

Процесс импорта

  1. doImport(storage, workbook) — извлекает лист с именем "Kontenplan". Вызывает UserException, если лист не найден.
  2. importKontenplan(storage, sheet):
    • Включает автоматическое удаление пробелов для значений ячеек.
    • Регистрирует два столбца с валидаторами.
    • Анализирует лист; пропускает, если не найдена корректная строка заголовка.
    • Создаёт ImportedSheet с логированием на уровне предупреждений.
    • Перебирает строки данных, создавая MyImportedElement и KontoDO для каждой строки.
    • Устанавливает nummer явно из целочисленного значения ячейки (а не через сопоставление целевого свойства ImportHelper.fillBean).

Объект-компаньон

  • NAME_OF_EXCEL_SHEET — требуемое имя листа: "Kontenplan"
  • log — SLF4J логгер
