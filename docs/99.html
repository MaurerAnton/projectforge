File #99: DataTransferPublicPageRest.kt

Path: plugins/datatransfer/.../restPublic/DataTransferPublicPageRest.kt · Source: GitHub

Main public (anonymous) page. Two states: (1) Login form — password field + optional name/email (userInfo) field + login button, shown when no valid session exists, (2) Attachment list — with upload (if externalUploadEnabled), download, download all (if <1GB), and logout button. Login validates against the area's externalAccessToken + externalPassword. Failed login returns error alert. The access token is passed as the id parameter in the URL.
