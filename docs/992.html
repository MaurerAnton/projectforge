#992: RechnungDao.kt

Data Access Object (DAO), projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungDao.kt
Spring @Service DAO extending BaseDao<RechnungDO> for outgoing invoice CRUD. Manages invoice numbering (auto-increment from 1000), date calculation for payment terms, status transitions (GEPLANT → GESTELLT increments number, sets datum), and validation (duplicate number check, required kunde/projekt, bezahlt requires zahlBetrag). Integrates with RechnungCache on load/save. Supports period-of-performance filtering via AuftragAndRechnungDaoHelper. Full-text search across kunde name, projekt name, and positions. History includes nested RechnungsPositionDO and KostZuweisungDO entries. Access via UserRightId.FIBU_AUSGANGSRECHNUNGEN.
