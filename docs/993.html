#993: RechnungDO.kt

JPA Entity, projectforge-business/src/main/kotlin/org/projectforge/business/fibu/RechnungDO.kt
JPA entity mapped to table t_fibu_rechnung representing an outgoing invoice. Extends AbstractRechnungDO and implements Comparable. Key fields: nummer (sequential), status (GEPLANT/GESTELLT/BEZAHLT/...), typ (RECHNUNG/GUTSCHRIFTSANZEIGE_...). Has lazy relations to KundeDO, ProjektDO, and a @JsonManagedReference @OneToMany list of RechnungsPositionDO ordered by number. Additional fields: kundeText (free-text), customerref1, attachment, customerAddress, and period-of-performance dates. Invalid if deleted or status is GEPLANT/STORNIERT. Originally migrated from Java in 2019.
