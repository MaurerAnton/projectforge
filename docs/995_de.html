Definiert die Kost2-Kostenarten (Kostenarten) – die letzten beiden Ziffern (Endziffer) einer Kost2-Kostenstelle. Jede Kostenart beschreibt die Kategorie der Kosten: fakturiert/nicht fakturiert, Akquisition, Wartung usw. Verwendet ihre 2-stellige ID als natürlichen Primärschlüssel.

Entitätsdesign

FeldTypDB-SpalteBeschreibung
idLong?PK (2-stellig)2-stellige Kostenartennummer (Primärschlüssel, nicht automatisch generiert)
nameString?VARCHAR(255)Anzeigename der Kostenart
descriptionString?VARCHAR(5000)Detaillierte Beschreibung
fakturiertBooleanNOT NULLGibt an, ob diese Kostenart an Kunden fakturiert wird
workFractionBigDecimal?PRECISION(10,5)Anteil der Arbeitszuweisung für diese Art
projektStandardBooleanWenn wahr, wird sie als Standardkostenart für neue Projekte vorgeschlagen

Persistenzdetails

  • Abgebildet auf T_FIBU_KOST2ART mit der 2-stelligen ID als Primärschlüssel
  • Erweitert AbstractHistorizableBaseDO<Long> – unterstützt Historieverfolgung
  • Implementiert Comparable<Kost2ArtDO> – sortiert nach ID
  • Hibernate Search indiziert: @FullTextField auf Name und Beschreibung
  • Equals/hashCode basiert nur auf id

Geschäftssemantik

Das fakturiert-Flag ist entscheidend: Es bestimmt, ob Ausgaben unter dieser Kostenart Einnahmen generieren (über Kundenrechnungen oder Subventionen). Nicht fakturierte Kostenarten repräsentieren interne Kosten. Das projektStandard-Flag steuert das UI-Verhalten beim Erstellen neuer Projektkostenstellen.

Cache-Integration

Kost2ArtDO-Instanzen werden im KostCache in der kost2ArtMap (nach ID indiziert) zwischengespeichert. Die Methode updateKost2Arts() lädt alle nicht gelöschten Kostenarten aus der Datenbank neu. Die Liste allKost2Arts kapselt sie als Kost2ArtImpl-Objekte für Berichte.
