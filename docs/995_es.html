Define los tipos de costo Kost2 (Kostenarten) — los últimos dos dígitos (Endziffer) de un centro de costo Kost2. Cada tipo de costo describe la categoría del costo: facturado/no facturado, adquisición, mantenimiento, etc. Utiliza su ID de 2 dígitos como clave primaria natural.

Diseño de la entidad

CampoTipoColumna BDDescripción
idLong?PK (2 dígitos)Número de tipo de costo de 2 dígitos (clave primaria, no autogenerada)
nameString?VARCHAR(255)Nombre mostrado del tipo de costo
descriptionString?VARCHAR(5000)Descripción detallada
fakturiertBooleanNOT NULLIndica si este tipo de costo se factura a los clientes
workFractionBigDecimal?PRECISION(10,5)Fracción de asignación de trabajo para este tipo
projektStandardBooleanSi es verdadero, se sugiere como tipo de costo predeterminado para nuevos proyectos

Detalles de persistencia

  • Mapeado a T_FIBU_KOST2ART con el ID de 2 dígitos como clave primaria
  • Extiende AbstractHistorizableBaseDO<Long> — soporta seguimiento de historial
  • Implementa Comparable<Kost2ArtDO> — ordenado por ID
  • Indexado con Hibernate Search: @FullTextField en nombre y descripción
  • Equals/hashCode basados únicamente en id

Semántica de negocio

La bandera fakturiert es crítica: determina si los gastos bajo este tipo de costo generan ingresos (mediante facturas a clientes o subvenciones). Los tipos de costo no facturados representan costos internos. La bandera projektStandard controla el comportamiento de la interfaz de usuario al crear nuevos centros de costo de proyecto.

Integración de caché

Las instancias de Kost2ArtDO se almacenan en caché en kost2ArtMap de KostCache (clave por ID). El método updateKost2Arts() recarga todos los tipos de costo no eliminados desde la base de datos. La lista allKost2Arts los envuelve como objetos Kost2ArtImpl para informes.
