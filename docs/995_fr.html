Définit les types de coûts Kost2 (Kostenarten) — les deux derniers chiffres (Endziffer) d'un centre de coûts Kost2. Chaque type de coût décrit la catégorie de coût : facturé/non facturé, acquisition, maintenance, etc. Utilise son identifiant à 2 chiffres comme clé primaire naturelle.

Conception de l'entité

ChampTypeColonne DBDescription
idLong?PK (2 chiffres)Numéro de type de coût à 2 chiffres (clé primaire, non générée automatiquement)
nameString?VARCHAR(255)Nom affiché du type de coût
descriptionString?VARCHAR(5000)Description détaillée
fakturiertBooleanNOT NULLIndique si ce type de coût est facturé aux clients
workFractionBigDecimal?PRECISION(10,5)Fraction de l'allocation de travail pour ce type
projektStandardBooleanSi vrai, suggéré comme type de coût par défaut pour les nouveaux projets

Détails de persistance

  • Mappé à T_FIBU_KOST2ART avec l'identifiant à 2 chiffres comme clé primaire
  • Étend AbstractHistorizableBaseDO<Long> — prend en charge le suivi historique
  • Implémente Comparable<Kost2ArtDO> — trié par identifiant
  • Indexé par Hibernate Search : @FullTextField sur le nom et la description
  • Equals/hashCode basé uniquement sur id

Sémantique métier

Le drapeau fakturiert est critique : il détermine si les dépenses sous ce type de coût génèrent des revenus (via des factures clients ou des subventions). Les types de coûts non facturés représentent des coûts internes. Le drapeau projektStandard contrôle le comportement de l'interface utilisateur lors de la création de nouveaux centres de coûts de projet.

Intégration du cache

Les instances de Kost2ArtDO sont mises en cache dans KostCache's kost2ArtMap (clé par identifiant). La méthode updateKost2Arts() recharge tous les types de coûts non supprimés depuis la base de données. La liste allKost2Arts les encapsule en tant qu'objets Kost2ArtImpl pour les rapports.
