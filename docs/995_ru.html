Определяет типы затрат Kost2 (Kostenarten) — последние две цифры (Endziffer) центра затрат Kost2. Каждый тип затрат описывает категорию расходов: выставляемые/невыставляемые счета, приобретение, обслуживание и т.д. Использует свой двузначный ID в качестве естественного первичного ключа.

Детали персистентности

  • Отображается на T_FIBU_KOST2ART с двузначным ID в качестве первичного ключа
  • Расширяет AbstractHistorizableBaseDO<Long> — поддерживает отслеживание истории
  • Реализует Comparable<Kost2ArtDO> — упорядочен по ID
  • Индексирован Hibernate Search: @FullTextField по имени и описанию
  • Equals/hashCode основаны только на id

Бизнес-семантика

Флаг fakturiert критичен: он определяет, генерируют ли расходы по этому типу затрат доход (через счета клиентам или субсидии). Невыставляемые типы затрат представляют внутренние расходы. Флаг projektStandard управляет поведением UI при создании новых центров затрат проекта.

Интеграция с кэшированием

Экземпляры Kost2ArtDO кэшируются в kost2ArtMap объекта KostCache (ключ — ID). Метод updateKost2Arts() перезагружает все неудалённые типы затрат из базы данных. Список allKost2Arts оборачивает их как объекты Kost2ArtImpl для отчётности.
