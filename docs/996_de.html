Stellt eine Kost2-Kostenstelle dar – die feinere Kostenentität (im Vergleich zu Kost1). Eine Kost2 wird durch eine Kombination von 3 numerischen Komponenten (Nummernkreis, Bereich, Teilbereich = 6 Ziffern) und einer Kost2Art (Kostenart, 2 Ziffern) identifiziert. Jede Kost2 gehört zu einem Projekt und hat eine spezifische Kostenartenklassifikation.

Virtuelle Statusvererbung

Die Eigenschaft effectiveKostentraegerStatus implementiert ein zentrales Entwurfsmuster (eingeführt in Commit 8239a53ee): Wenn das verknüpfte Projekt den Status ENDED hat oder gelöscht ist, wird die Kost2 unabhängig vom eigenen Status als ENDED behandelt. Dies vermeidet Dateninkonsistenzen, wenn Projekte geschlossen werden.

Persistenzdetails

  • Gemappt auf T_FIBU_KOST2 mit eindeutiger Einschränkung auf alle 4 numerischen Komponenten
  • Indizes auf kost2_art_id und projekt_id für Join-Performance
  • Erweitert DefaultBaseDO, implementiert Comparable<Kost2DO> und DisplayNameCapable
  • Implementiert @JsonCreator-Factory zur Deserialisierung von Long-ID
  • Equals/hashCode verwendet nummernkreis, bereich, teilbereich und kost2Art
  • Alle Kotlin-Eigenschaften sind als open deklariert für Hibernate-Lazy-Loading-Proxy-Unterstützung

Quellcode (gekürzt)

@Entity @Indexed @Table(name = "T_FIBU_KOST2", ...)
open class Kost2DO : DefaultBaseDO(), Comparable<Kost2DO>, DisplayNameCapable {
    open var kostentraegerStatus: KostentraegerStatus? = null

    val effectiveKostentraegerStatus: KostentraegerStatus?
        get() {
            val projektRef = PfCaches.instance.getProjektIfNotInitialized(projekt) ?: projekt
            if (projektRef != null &&
                (projektRef.status == ProjektStatus.ENDED || projektRef.deleted))
                return KostentraegerStatus.ENDED
            return kostentraegerStatus
        }

    open var nummernkreis: Int = 0
    open var bereich: Int = 0
    open var teilbereich: Int = 0
    open var kost2Art: Kost2ArtDO? = null
    open var projekt: ProjektDO? = null
    // ... formattedNumber, rawNumberString, toolTip berechnete Eigenschaften
}
