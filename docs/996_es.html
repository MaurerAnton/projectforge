Representa un centro de costo Kost2 — la entidad de costo más detallada (en comparación con Kost1). Un Kost2 se identifica mediante una combinación de 3 componentes numéricos (Nummernkreis, Bereich, Teilbereich = 6 dígitos) y un Kost2Art (tipo de costo, 2 dígitos). Cada Kost2 pertenece a un proyecto y tiene una clasificación de tipo de costo específica.

Herencia de estado virtual

La propiedad effectiveKostentraegerStatus implementa un patrón de diseño clave (introducido en el commit 8239a53ee): si el Projekt vinculado tiene estado ENDED o está eliminado, el Kost2 se trata como ENDED independientemente de su propio estado. Esto evita inconsistencias de datos cuando los proyectos se cierran.

Detalles de persistencia

  • Mapeado a T_FIBU_KOST2 con restricción única en los 4 componentes numéricos
  • Índices en kost2_art_id y projekt_id para rendimiento de joins
  • Extiende DefaultBaseDO, implementa Comparable<Kost2DO> y DisplayNameCapable
  • Implementa fábrica @JsonCreator para deserialización desde Long ID
  • Equals/hashCode usa nummernkreis, bereich, teilbereich y kost2Art
  • Todas las propiedades Kotlin declaradas open para soporte de proxy de carga diferida de Hibernate

    open var kostentraegerStatus: KostentraegerStatus? = null

    val effectiveKostentraegerStatus: KostentraegerStatus?
        get() {
            val projektRef = PfCaches.instance.getProjektIfNotInitialized(projekt) ?: projekt
            if (projektRef != null &&
                (projektRef.status == ProjektStatus.ENDED || projektRef.deleted))
                return KostentraegerStatus.ENDED
            return kostentraegerStatus
        }
