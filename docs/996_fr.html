Représente un centre de coût Kost2 — l'entité de coût la plus fine (par rapport à Kost1). Un Kost2 est identifié par une combinaison de 3 composants numériques (Nummernkreis, Bereich, Teilbereich = 6 chiffres) et un Kost2Art (type de coût, 2 chiffres). Chaque Kost2 appartient à un projet et possède une classification de type de coût spécifique.

Héritage de statut virtuel

La propriété effectiveKostentraegerStatus implémente un modèle de conception clé (introduit dans le commit 8239a53ee) : si le Projekt lié a le statut TERMINÉ ou est supprimé, le Kost2 est traité comme TERMINÉ indépendamment de son propre statut. Cela évite les incohérences de données lorsque les projets sont clôturés.

Détails de persistance

  • Mappé à T_FIBU_KOST2 avec contrainte d'unicité sur les 4 composants numériques
  • Index sur kost2_art_id et projekt_id pour les performances de jointure
  • Étend DefaultBaseDO, implémente Comparable<Kost2DO> et DisplayNameCapable
  • Implémente une fabrique @JsonCreator pour la désérialisation depuis un ID Long
  • Equals/hashCode utilise nummernkreis, bereich, teilbereich et kost2Art
  • Toutes les propriétés Kotlin déclarées open pour le support des proxies de chargement paresseux Hibernate

        get() {
            val projektRef = PfCaches.instance.getProjektIfNotInitialized(projekt) ?: projekt
            if (projektRef != null &&
                (projektRef.status == ProjektStatus.ENDED || projektRef.deleted))
                return KostentraegerStatus.ENDED
            return kostentraegerStatus
