Представляет центр затрат Kost2 — более детальную сущность затрат (по сравнению с Kost1). Kost2 идентифицируется комбинацией 3 числовых компонентов (Nummernkreis, Bereich, Teilbereich = 6 цифр) и Kost2Art (тип затрат, 2 цифры). Каждый Kost2 принадлежит проекту и имеет определённую классификацию типа затрат.

Виртуальное наследование статуса

Свойство effectiveKostentraegerStatus реализует ключевой паттерн проектирования (введён в коммите 8239a53ee): если связанный Projekt имеет статус ENDED или удалён, Kost2 считается ENDED независимо от собственного статуса. Это предотвращает несогласованность данных при закрытии проектов.

Детали персистентности

  • Отображается на T_FIBU_KOST2 с уникальным ограничением по всем 4 числовым компонентам
  • Индексы на kost2_art_id и projekt_id для производительности соединений
  • Расширяет DefaultBaseDO, реализует Comparable<Kost2DO> и DisplayNameCapable
  • Реализует фабрику @JsonCreator для десериализации из Long ID
  • Equals/hashCode использует nummernkreis, bereich, teilbereich и kost2Art
  • Все свойства Kotlin объявлены как open для поддержки прокси-объектов ленивой загрузки Hibernate

Исходный код (сокращён)

@Entity @Indexed @Table(name = "T_FIBU_KOST2", ...)
open class Kost2DO : DefaultBaseDO(), Comparable<Kost2DO>, DisplayNameCapable {
    open var kostentraegerStatus: KostentraegerStatus? = null

    val effectiveKostentraegerStatus: KostentraegerStatus?
        get() {
            val projektRef = PfCaches.instance.getProjektIfNotInitialized(projekt) ?: projekt
            if (projektRef != null &&
                (projektRef.status == ProjektStatus.ENDED || projektRef.deleted))
                return KostentraegerStatus.ENDED
            return kostentraegerStatus
        }

    open var nummernkreis: Int = 0
    open var bereich: Int = 0
    open var teilbereich: Int = 0
    open var kost2Art: Kost2ArtDO? = null
    open var projekt: ProjektDO? = null
    // ... вычисляемые свойства formattedNumber, rawNumberString, toolTip
}
