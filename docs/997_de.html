Spring @Service zur Verwaltung von Persistenzoperationen für Kost2DO-Entitäten. Erweitert BaseDao um CRUD-, Such- und Validierungslogik. Behandelt Projektverknüpfung, Kostenartenzuweisung, Eindeutigkeitssicherung und Cache-Aktualisierungen nach dem Speichern.

Auswahl-/Filterarchitektur

Die Überschreibung select(filter) führt eine zweiphasige Abfrage durch:

  1. Datenbankabfrage: Verwendet QueryFilter mit einem Join auf kost2Art, sortiert nach allen numerischen Komponenten
  2. In-Memory-Filterung: Filtert nach effectiveKostentraegerStatus (der den ENDED-Status vom verknüpften Projekt erben kann). Unterstützt: ACTIVE, NONACTIVE, ENDED, NOT_ENDED und ALL

Validierung (onInsertOrModify)

  • Wenn ein Projekt verknüpft ist, wird überprüft, ob Nummernkreis/Bereich/Teilbereich der Kost2 mit den ID-Komponenten des Projekts übereinstimmen
  • Nummernkreis 4 oder 5 erfordert eine Projektzuordnung
  • Prüft auf doppelte Kost2-Einträge (Geschäftsschlüsselkonflikt) mittels benannter Abfragen

Abhängigkeiten

  • ProjektDao — für Projektsuche und -validierung
  • Kost2ArtDao — für Kostenartenzuweisung
  • KostCache — aktualisiert über afterInsertOrModify nach jedem Speichern
  • Zugriffsrecht: UserRightId.FIBU_COST_UNIT

Quellcode (gekürzt)

@Service
open class Kost2Dao : BaseDao<Kost2DO>(Kost2DO::class.java) {
    @Autowired private lateinit var projektDao: ProjektDao
    @Autowired private lateinit var kost2ArtDao: Kost2ArtDao
    @Autowired private lateinit var kostCache: KostCache

    override fun select(filter: BaseSearchFilter): List<Kost2DO> {
        val myFilter = if (filter is KostFilter) filter else KostFilter(filter)
        val queryFilter = QueryFilter(myFilter).apply { createJoin("kost2Art") }
        val allKost2 = select(queryFilter)
        return when {
            myFilter.isActive -> allKost2.filter {
                it.effectiveKostentraegerStatus == ACTIVE || it.effectiveKostentraegerStatus == null
            }
            myFilter.isNonActive -> allKost2.filter { it.effectiveKostentraegerStatus == NONACTIVE }
            myFilter.isEnded -> allKost2.filter { it.effectiveKostentraegerStatus == ENDED }
            myFilter.isNotEnded -> allKost2.filter { it.effectiveKostentraegerStatus != ENDED }
            else -> allKost2
        }
    }
}
