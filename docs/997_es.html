Spring @Service que gestiona operaciones de persistencia para entidades Kost2DO. Extiende BaseDao para proporcionar lógica CRUD, búsqueda y validación. Maneja vinculación de proyectos, asignación de tipos de coste, cumplimiento de unicidad y actualizaciones de caché posteriores al guardado.

Arquitectura de selección/filtrado

La sobreescritura de select(filter) realiza una consulta en dos fases:

  1. Consulta a base de datos: Usa QueryFilter con un join en kost2Art, ordenado por todos los componentes numéricos
  2. Filtrado en memoria: Filtra por effectiveKostentraegerStatus (que puede heredar el estado ENDED del proyecto vinculado). Soporta: ACTIVE, NONACTIVE, ENDED, NOT_ENDED y ALL

Validación (onInsertOrModify)

  • Si un Projekt está vinculado, verifica que el nummernkreis/bereich/teilbereich del Kost2 coincida con los componentes del ID del proyecto
  • Nummmernkreis 4 o 5 requiere una asignación de proyecto
  • Comprueba entradas Kost2 duplicadas (colisión de clave de negocio) usando consultas nombradas

Dependencias

  • ProjektDao — para búsqueda y validación de proyectos
  • Kost2ArtDao — para asignación de tipo de coste
  • KostCache — actualizado mediante afterInsertOrModify después de cada guardado
  • Derecho de acceso: UserRightId.FIBU_COST_UNIT

@Service
open class Kost2Dao : BaseDao<Kost2DO>(Kost2DO::class.java) {
    @Autowired private lateinit var projektDao: ProjektDao
    @Autowired private lateinit var kost2ArtDao: Kost2ArtDao
    @Autowired private lateinit var kostCache: KostCache

    override fun select(filter: BaseSearchFilter): List<Kost2DO> {
        val myFilter = if (filter is KostFilter) filter else KostFilter(filter)
        val queryFilter = QueryFilter(myFilter).apply { createJoin("kost2Art") }
        val allKost2 = select(queryFilter)
        return when {
            myFilter.isActive -> allKost2.filter {
                it.effectiveKostentraegerStatus == ACTIVE || it.effectiveKostentraegerStatus == null
            }
            myFilter.isNonActive -> allKost2.filter { it.effectiveKostentraegerStatus == NONACTIVE }
            myFilter.isEnded -> allKost2.filter { it.effectiveKostentraegerStatus == ENDED }
            myFilter.isNotEnded -> allKost2.filter { it.effectiveKostentraegerStatus != ENDED }
            else -> allKost2
        }
    }
}
