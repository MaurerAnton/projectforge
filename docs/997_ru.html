Spring @Service, управляющий операциями сохранения для сущностей Kost2DO. Расширяет BaseDao, предоставляя логику CRUD, поиска и валидации. Обрабатывает привязку к проекту, назначение типа затрат, обеспечение уникальности и обновление кэша после сохранения.

Архитектура выбора / фильтрации

Переопределение select(filter) выполняет двухфазный запрос:

  1. Запрос к БД: Использует QueryFilter с объединением по kost2Art, упорядоченный по всем числовым компонентам
  2. Фильтрация в памяти: Фильтрует по effectiveKostentraegerStatus (который может наследовать статус ENDED от связанного проекта). Поддерживает: ACTIVE, NONACTIVE, ENDED, NOT_ENDED и ALL

Валидация (onInsertOrModify)

  • Если связан Projekt, проверяет, что nummernkreis/bereich/teilbereich Kost2 соответствуют компонентам ID проекта
  • Nummmernkreis 4 или 5 требует назначения проекта
  • Проверяет на дубликаты записей Kost2 (коллизия бизнес-ключа) с помощью именованных запросов

Зависимости

  • ProjektDao — для поиска и валидации проекта
  • Kost2ArtDao — для назначения типа затрат
  • KostCache — обновляется через afterInsertOrModify после каждого сохранения
  • Право доступа: UserRightId.FIBU_COST_UNIT

Исходный код (сокращён)

@Service
open class Kost2Dao : BaseDao<Kost2DO>(Kost2DO::class.java) {
    @Autowired private lateinit var projektDao: ProjektDao
    @Autowired private lateinit var kost2ArtDao: Kost2ArtDao
    @Autowired private lateinit var kostCache: KostCache

    override fun select(filter: BaseSearchFilter): List<Kost2DO> {
        val myFilter = if (filter is KostFilter) filter else KostFilter(filter)
        val queryFilter = QueryFilter(myFilter).apply { createJoin("kost2Art") }
        val allKost2 = select(queryFilter)
        return when {
            myFilter.isActive -> allKost2.filter {
                it.effectiveKostentraegerStatus == ACTIVE || it.effectiveKostentraegerStatus == null
            }
            myFilter.isNonActive -> allKost2.filter { it.effectiveKostentraegerStatus == NONACTIVE }
            myFilter.isEnded -> allKost2.filter { it.effectiveKostentraegerStatus == ENDED }
            myFilter.isNotEnded -> allKost2.filter { it.effectiveKostentraegerStatus != ENDED }
            else -> allKost2
        }
    }
}
