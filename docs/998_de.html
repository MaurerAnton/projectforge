Zentrale Caching-Komponente für alle Kostenstellendaten (Kost1DO, Kost2DO, Kost2ArtDO). Erweitert AbstractCache, um das ProjectForge-Caching-Framework zu nutzen. Verwaltet synchronisierte Hash-Maps für schnelle Suche nach ID und numerischen Komponenten, wodurch wiederholte JPA-Abfragen für häufig verwendete Kostenstellendaten vermieden werden.

Aktualisierungsmechanismus

Die Methode refresh() wird von der Infrastruktur von AbstractCache aufgerufen (über checkRefresh(), das zu Beginn jeder öffentlichen Methode aufgerufen wird). Die Aktualisierung lädt alle Kost1-, Kost2- und Kost2Art-Datensätze in einer einzigen schreibgeschützten isolierten Transaktion:

  1. Lädt alle Kost1DO- und Kost2DO-Entitäten in veränderbare Maps
  2. Prüft, ob nicht gelöschte Kost2-Einträge vorhanden sind (Flag kost2EntriesExists)
  3. Baut die Liste allKost2Arts neu auf, die als Kost2ArtImpl für Berichte verpackt wird

Cache-Invalidierung

  • Nach jedem Einfügen/Ändern von Kost2: Kost2Dao.afterInsertOrModify → KostCache.updateKost2(kost2)
  • Nach jedem Einfügen/Ändern von Kost1: KostCache.updateKost1(kost1)
  • Nach jeder Änderung von Kunde: Cache abgelaufen (registrierter Listener in @PostConstruct)

Hibernate-Initialisierungsschutz

Die Methoden get*IfNotInitialized() verhindern ein kritisches Leistungsproblem: Wenn außerhalb einer Transaktion auf einen Hibernate-Lazy-Proxy zugegriffen wird, löst dies N+1-Abfragen aus. Diese Methoden verwenden HibernateUtils.isFullyInitialized(), um Proxys zu erkennen und stattdessen aus dem Cache neu zu laden. Dieser Schutz wird auf Kost1DO, Kost2DO und Kost2ArtDO angewendet.

Thread-Sicherheit

  • kost1Map und kost2Map: Veränderbar, synchronisierter Zugriff über synchronized(kost2Map)-Blöcke
  • kost2ArtMap und allKost2Arts: Werden bei Aktualisierung atomar ersetzt (nach Zuweisung schreibgeschützt)

@Component
class KostCache : AbstractCache() {
    @Autowired private lateinit var persistenceService: PfPersistenceService
    @Autowired private lateinit var kundeDao: KundeDao

    private lateinit var kost1Map: MutableMap<Long, Kost1DO>
    private lateinit var kost2Map: MutableMap<Long, Kost2DO>
    private lateinit var kost2ArtMap: Map<Long, Kost2ArtDO>

    fun getKost2(id: Long?): Kost2DO? {
        id ?: return null
        checkRefresh()
        synchronized(kost2Map) { return kost2Map[id] }
    }

    override fun refresh() {
        persistenceService.runIsolatedReadOnly { context ->
            this.kost1Map = persistenceService
                .executeQuery("from Kost1DO t", Kost1DO::class.java)
                .filter { it.id != null }
                .associateBy { it.id!! }.toMutableMap()
            this.kost2Map = persistenceService
                .executeQuery("from Kost2DO t", Kost2DO::class.java)
                .filter { it.id != null }
                .associateBy { it.id!! }.toMutableMap()
            // ... updateKost2Arts()
        }
    }
    companion object { lateinit var instance: KostCache }
}
