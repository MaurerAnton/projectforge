Componente de caché central para todos los datos de centros de coste (Kost1DO, Kost2DO, Kost2ArtDO). Extiende AbstractCache para aprovechar el framework de caché de ProjectForge. Mantiene mapas hash sincronizados para búsqueda rápida por ID y por componentes numéricos, evitando consultas JPA repetidas para datos de centros de coste de acceso frecuente.

Mecanismo de Actualización

El método refresh() es llamado por la infraestructura de AbstractCache (a través de checkRefresh() que se invoca al inicio de cada método público). La actualización carga todos los registros de Kost1, Kost2 y Kost2Art en una única transacción aislada de solo lectura:

  1. Carga todas las entidades Kost1DO y Kost2DO en mapas mutables
  2. Verifica si existen entradas Kost2 no eliminadas (bandera kost2EntriesExists)
  3. Reconstruye la lista allKost2Arts envuelta como Kost2ArtImpl para informes

Invalidación de Caché

  • Después de cualquier inserción/modificación de Kost2: Kost2Dao.afterInsertOrModify → KostCache.updateKost2(kost2)
  • Después de cualquier inserción/modificación de Kost1: KostCache.updateKost1(kost1)
  • Después de cualquier modificación de Kunde: caché expirada (listener registrado en @PostConstruct)

Guardia de Inicialización de Hibernate

Los métodos get*IfNotInitialized() previenen un problema crítico de rendimiento: cuando se accede a un proxy perezoso de Hibernate fuera de una transacción, se disparan consultas N+1. Estos métodos usan HibernateUtils.isFullyInitialized() para detectar proxies y recargar desde la caché en su lugar. Esta guardia se aplica a Kost1DO, Kost2DO y Kost2ArtDO.

Seguridad en Hilos

  • kost1Map y kost2Map: Acceso mutable y sincronizado mediante bloques synchronized(kost2Map)
  • kost2ArtMap y allKost2Arts: Reemplazados atómicamente en la actualización (solo lectura después de la asignación)

@Component
class KostCache : AbstractCache() {
    @Autowired private lateinit var persistenceService: PfPersistenceService
    @Autowired private lateinit var kundeDao: KundeDao

    private lateinit var kost1Map: MutableMap<Long, Kost1DO>
    private lateinit var kost2Map: MutableMap<Long, Kost2DO>
    private lateinit var kost2ArtMap: Map<Long, Kost2ArtDO>

    fun getKost2(id: Long?): Kost2DO? {
        id ?: return null
        checkRefresh()
        synchronized(kost2Map) { return kost2Map[id] }
    }

    override fun refresh() {
        persistenceService.runIsolatedReadOnly { context ->
            this.kost1Map = persistenceService
                .executeQuery("from Kost1DO t", Kost1DO::class.java)
                .filter { it.id != null }
                .associateBy { it.id!! }.toMutableMap()
            this.kost2Map = persistenceService
                .executeQuery("from Kost2DO t", Kost2DO::class.java)
                .filter { it.id != null }
                .associateBy { it.id!! }.toMutableMap()
            // ... updateKost2Arts()
        }
    }
    companion object { lateinit var instance: KostCache }
}
