Composant de cache central pour toutes les données de centre de coûts (Kost1DO, Kost2DO, Kost2ArtDO). Étend AbstractCache pour exploiter le framework de cache de ProjectForge. Maintient des tables de hachage synchronisées pour une recherche rapide par ID et par composants numériques, évitant ainsi les requêtes JPA répétées pour les données de centre de coûts fréquemment consultées.

Mécanisme de rafraîchissement

La méthode refresh() est appelée par l'infrastructure d'AbstractCache (via checkRefresh() qui est invoquée au début de chaque méthode publique). Le rafraîchissement charge tous les enregistrements Kost1, Kost2 et Kost2Art dans une seule transaction isolée en lecture seule :

  1. Charge toutes les entités Kost1DO et Kost2DO dans des maps mutables
  2. Vérifie si des entrées Kost2 non supprimées existent (drapeau kost2EntriesExists)
  3. Reconstruit la liste allKost2Arts encapsulée en Kost2ArtImpl pour les rapports

Invalidation du cache

  • Après toute insertion/modification de Kost2 : Kost2Dao.afterInsertOrModify → KostCache.updateKost2(kost2)
  • Après toute insertion/modification de Kost1 : KostCache.updateKost1(kost1)
  • Après toute modification de Kunde : cache expiré (écouteur enregistré dans @PostConstruct)

Protection d'initialisation Hibernate

Les méthodes get*IfNotInitialized() évitent un problème de performance critique : lorsqu'un proxy paresseux Hibernate est accédé en dehors d'une transaction, cela déclenche des requêtes N+1. Ces méthodes utilisent HibernateUtils.isFullyInitialized() pour détecter les proxies et recharger depuis le cache à la place. Cette protection est appliquée à Kost1DO, Kost2DO et Kost2ArtDO.

Sécurité des threads

  • kost1Map et kost2Map : Mutables, accès synchronisé via des blocs synchronized(kost2Map)
  • kost2ArtMap et allKost2Arts : Remplacées atomiquement lors du rafraîchissement (lecture seule après affectation)

@Component
class KostCache : AbstractCache() {
    @Autowired private lateinit var persistenceService: PfPersistenceService
    @Autowired private lateinit var kundeDao: KundeDao

    private lateinit var kost1Map: MutableMap<Long, Kost1DO>
    private lateinit var kost2Map: MutableMap<Long, Kost2DO>
    private lateinit var kost2ArtMap: Map<Long, Kost2ArtDO>

    fun getKost2(id: Long?): Kost2DO? {
        id ?: return null
        checkRefresh()
        synchronized(kost2Map) { return kost2Map[id] }
    }

    override fun refresh() {
        persistenceService.runIsolatedReadOnly { context ->
            this.kost1Map = persistenceService
                .executeQuery("from Kost1DO t", Kost1DO::class.java)
                .filter { it.id != null }
                .associateBy { it.id!! }.toMutableMap()
            this.kost2Map = persistenceService
                .executeQuery("from Kost2DO t", Kost2DO::class.java)
                .filter { it.id != null }
                .associateBy { it.id!! }.toMutableMap()
            // ... updateKost2Arts()
        }
    }
    companion object { lateinit var instance: KostCache }
}
