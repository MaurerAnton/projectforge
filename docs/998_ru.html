Центральный компонент кэширования для всех данных по центрам затрат (Kost1DO, Kost2DO, Kost2ArtDO). Расширяет AbstractCache для использования фреймворка кэширования ProjectForge. Поддерживает синхронизированные хэш-карты для быстрого поиска по ID и числовым компонентам, избегая повторных JPA-запросов к часто запрашиваемым данным центров затрат.

Механизм обновления

Метод refresh() вызывается инфраструктурой AbstractCache (через checkRefresh(), который вызывается в начале каждого публичного метода). Обновление загружает все записи Kost1, Kost2 и Kost2Art в одной изолированной транзакции только для чтения:

  1. Загружает все сущности Kost1DO и Kost2DO в изменяемые карты
  2. Проверяет, существуют ли неудалённые записи Kost2 (флаг kost2EntriesExists)
  3. Перестраивает список allKost2Arts, обёрнутый как Kost2ArtImpl для отчётности

Инвалидация кэша

  • После вставки/изменения любого Kost2: Kost2Dao.afterInsertOrModify → KostCache.updateKost2(kost2)
  • После вставки/изменения любого Kost1: KostCache.updateKost1(kost1)
  • После изменения любого Kunde: срок действия кэша истекает (зарегистрированный слушатель в @PostConstruct)

Защита от инициализации Hibernate

Методы get*IfNotInitialized() предотвращают критическую проблему производительности: когда ленивый прокси Hibernate запрашивается вне транзакции, это вызывает N+1 запросов. Эти методы используют HibernateUtils.isFullyInitialized() для обнаружения прокси и перезагрузки из кэша. Эта защита применяется к Kost1DO, Kost2DO и Kost2ArtDO.

Потокобезопасность

  • kost1Map и kost2Map: Изменяемые, синхронизированный доступ через блоки synchronized(kost2Map)
  • kost2ArtMap и allKost2Arts: Атомарно заменяются при обновлении (только для чтения после присваивания)

@Component
class KostCache : AbstractCache() {
    @Autowired private lateinit var persistenceService: PfPersistenceService
    @Autowired private lateinit var kundeDao: KundeDao

    private lateinit var kost1Map: MutableMap<Long, Kost1DO>
    private lateinit var kost2Map: MutableMap<Long, Kost2DO>
    private lateinit var kost2ArtMap: Map<Long, Kost2ArtDO>

    fun getKost2(id: Long?): Kost2DO? {
        id ?: return null
        checkRefresh()
        synchronized(kost2Map) { return kost2Map[id] }
    }

    override fun refresh() {
        persistenceService.runIsolatedReadOnly { context ->
            this.kost1Map = persistenceService
                .executeQuery("from Kost1DO t", Kost1DO::class.java)
                .filter { it.id != null }
                .associateBy { it.id!! }.toMutableMap()
            this.kost2Map = persistenceService
                .executeQuery("from Kost2DO t", Kost2DO::class.java)
                .filter { it.id != null }
                .associateBy { it.id!! }.toMutableMap()
            // ... updateKost2Arts()
        }
    }
    companion object { lateinit var instance: KostCache }
}
