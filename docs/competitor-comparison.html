4. Redmine — классика без излишеств

Французский трекер задач (GPLv2), 2006. Бесплатно навсегда. Ruby on Rails, сотни community-плагинов, SCM-интеграция (Git/SVN/Mercurial). Устаревший UI, сложный деплой, нет финансов/HR.

5. Jira (Atlassian) — корпоративный стандарт

Австралийский проприетарный трекер. 300,000+ организаций. ⚠️ Data Center поддержка — до марта 2029. Atlassian форсирует миграцию в Cloud. ~$8–16/п/м. 5,000+ приложений. Agile/Scrum мирового уровня. Self-hosted умирает — окно для OpenProject и ProjectForge.

6. Monday.com — лучший UX, только облако

Израильская SaaS-платформа. 250,000+ клиентов. Лучший UI/UX в индустрии, AI-агенты, нативные мобильные приложения. €9–19/место/мес. Нет self-hosted. Нет финансов/HR. Мгновенный старт — но нулевой контроль над данными.

7. Personio — HR-лидер DACH, не PM-конкурент

Немецкая HR-платформа (SaaS). 16,000+ компаний. Полный HR: рекрутинг, onboarding, performance, компенсации, payroll, GDPR-совместимость. Нет проектов/финансов. Индивидуальная квота. Не прямой конкурент — только HR.

8. SAP S/4HANA — enterprise ERP, мировой стандарт

Немецкий проприетарный ERP-гигант. Доминирует в Fortune 500. ABAP + Java, on-premise или Cloud (RISE with SAP). Сложнейший деплой. Финансы (FI/CO) и HR (HCM) — мировые стандарты. Цена: от €100K+/год. Где ProjectForge выигрывает: цена (€0 vs €100K+), деплой (30 сек vs месяцы), простота PM.

9. 1С:Предприятие — стандарт РФ/СНГ

Российская проприетарная ERP-платформа. Доминирует в РФ/СНГ. Собственный язык программирования. On-premise (Windows) или облако. Цена: от ~$500/лицензию. Где ProjectForge выигрывает: открытый код, кроссплатформа, PM-глубина, бесплатно.

Где ProjectForge выигрывает

  1. Самый простой деплой. Один JAR + встроенная HSQLDB. Ни у кого больше нет такого низкого порога.
  2. PM + финансы + HR + календарь в одном JAR_(file_format)">JAR. Ни один конкурент не даёт такого сочетания.
  3. Self-hosted + открытый код. Jira уходит. Monday/Personio — только облако.
  4. Немецкий инжиниринг. Детальный Gantt, WBS, учёт потребления, книга заказов.
  5. Плагинная система. 10+ встроенных плагинов + сторонние JAR-расширения.
  6. Постепенная миграция Wicket → React. Два сосуществующих фронтенда.

Где ProjectForge проигрывает

  1. Нет Agile/Scrum. OpenProject и Jira далеко впереди.
  2. Маленькое сообщество. 50K+ ★ у Odoo против небольшого у ProjectForge.
  3. Нет облачного SaaS. Только self-hosted.
  4. Нет мобильного приложения. Только адаптивный веб.
  5. Нет AI. Monday, OpenProject, Odoo уже внедрили.
  6. Нет полноценной бухгалтерии. ERPNext/Odoo дают полный учёт.
